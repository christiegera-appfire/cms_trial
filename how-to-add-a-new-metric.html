How to add a new metric

You can create your own metric or edit the existing ones. To make prioritization easier, you can select from multiple metric types:

  • ⭐️ Rating - creates 5-star rating

  • 🏷 Label - creates a set of labels with custom names and colors

  • ✏️ Short text - creates a drop-down with text values

  • 🔢 Number - creates the field that accepts a number input (non-decimal values)

Add a new metric

From the Project menu, navigate to the Priorities tab.

Image — asset pipeline pending
Foxly Priorities tab with the Customize button in the top-right corner

  1. Click +Add a new metric.

  2. Select the metric type: Label, Number, Rating, or Short text.

  3. Give the metric a name.

  4. Click Save changes.

Image — asset pipeline pending
Foxly add new metric dialog with metric type options and Save changes button

Label metric types

  1. Add at least one value by clicking +Add a new value.

  2. Assign a color, give the value a name, and select the numeric value that's going to be used for priority score calculation

Image — asset pipeline pending
Foxly label metric configuration with color, name, and numeric value fields

Number metric types

No additional action is needed. This creates a field that accepts numbers up to three decimal points.

Image — asset pipeline pending
Foxly number metric type showing a field that accepts numeric input

Rating type of metric

  1. The 5-star rating will be automatically created.

  2. Review the assigned numeric values and edit when needed - they're going to be used for Priority score calculation.

Image — asset pipeline pending
Foxly rating metric with 5-star values and assigned numeric scores

Short text type of metric

  1. Add at least one value by clicking +Add a new value.

  2. Give the value a name and select the numeric value that's going to be used for the Priority score calculation.
