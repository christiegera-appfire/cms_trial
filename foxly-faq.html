Foxly FAQ

Who can access Foxly Backlog Prioritization for Jira?

All users with access to the Jira project can access the Foxly Priority tab and edit the metrics.

Can I use the same template in multiple projects?

Yes, you can! See Change the prioritization template to choose a template or create a new one to use in multiple projects.

Where do I access Foxly Backlog Prioritization for Jira?

The main Foxly Priority Table is located in the Project menu of each project. There is also a Priority Score view available in every Jira issue.

Can I automate priority settings in Jira based on scores or metrics?

Foxly creates the custom Priority Score field automatically. You can also store metrics in custom fields. You can use these automated fields in Jira.

  • For an example of this automation, see https://jexo.io/blog/3-tips-for-better-backlog-management-in-jira-with-foxly/.

  • To enable the storing of metrics in custom fields, see Store metric in a custom field.

Can I add the Prioritization Score to the Backlog view?

For Classic projects, yes! The Priority Score is also a custom field that stays in sync with the Foxly Score. You can configure it to show in both the Backlog view and the Board view on the issue tiles. This level of customization is not available in Next-Gen projects. 

Can I keep the same Foxly Priority Scores when transferring issues to another project?

If both projects use the same Priority Score template, then the scores are transferred. However, if the project to which you’re migrating issues has a different Priority Score template, the scores will recalculate according to the new template.

To verify both projects use the same template:

  1. In the project to which you migrated issues, click the main Foxly Priorities Table.

  2. Click Customize at top right.

  3. Click the drop-down to view the selected template.

  4. If this template is different from the one used in the previous project, you can change it to restore the previous metrics and scores: Change the prioritization template.

How do I map Jira custom fields to metric labels in Foxly?

See Map Jira custom fields to label metrics.

Is it possible to rearrange the order of the metric columns?

See Rearrange the order of columns.

Is it possible to add fields as columns in Foxly?

See Add fields as columns.

Can Foxly fields be used in Advanced Roadmaps?

Currently, Foxly only supports the Priority Score field in Advanced Roadmaps. Other Foxly custom fields (metrics) are not yet supported. However, we have an improvement coming soon to add this functionality.

How do I apply a promo code/discount code for Foxly?

See Apply a promo/discount code.

Can't access a Priority Poker session?

See Ensure proper permissions for a Priority Poker session.

Can I export Priority metrics?

Yes, you can! To export a CSV file:

  • Click the Priorities tab > Export on the right above the Foxly table.

Is there a demo environment where I can try Foxly?

Sign up for a free Jira instance https://www.atlassian.com/software/free and install Foxly from https://marketplace.atlassian.com/apps/1222824/foxly-backlog-prioritization-priority-planning-poker?hosting=cloud&tab=pricing.

Jira and Foxly are free for up to 10 users, so you can invite other colleagues to try Foxly for as long as you need.
