Planning Poker for Azure DevOps feature overview

Planning Poker for Azure DevOps helps Agile teams estimate work items directly within Azure DevOps. Whether your team estimates together in live sessions or asynchronously across time zones, the app integrates with your existing work items and workflows.

What you can do with Planning Poker​

  • Run live estimation sessions.
  • Estimate asynchronously across time zones.
  • Estimate directly from Azure DevOps work items.
  • Customize estimation fields and card decks.
  • Start estimation sessions from backlogs, boards, sprints, or queries.

Interactive poker game​

Create an interactive poker game with work items that you would like to estimate with your team. Invite team members using a shareable link.

Async Poker game​

During game creation, enable the Async game flow to allow participants to estimate at their own pace with an optional interactive review process similar to the standard Poker game. Check participants' progress to know when to review estimates.

During the async estimation, you can provide comments to explain your vote.

Estimate from the Work Item view directly​

Estimate your work items on the go from the work item details view directly using the embedded interactive section.

Configurable Card Decks and Estimation Fields per Work Item Type​

Different work items can be estimated in different ways. For each work item type, you can pick which field the final estimate writes back to (for example Effort, Remaining Work, Story Points, or any other field on that type), separately from which card deck estimators vote with (Fibonacci, Modified Fibonacci, T-Shirt, S/M/L, or a fully custom deck). See Configure game settings and card decks for the full reference.

Other features​

Moderator Role​

A moderator has full control over the estimation game, including selecting work items, revealing votes, resetting votes, and ending the game. Other participants interactively follow the Moderator's actions and provide estimates.

Online Users​

Keep track of team members who are online and can contribute to the estimation process.

Start Game from your Backlog / Sprint / Query / Board directly​

Select multiple items on any work item list in Azure DevOps. Once items are selected, you can kickstart the estimation game from a context menu.
