Create a new prioritization template

When none of the default prioritization templates work for you, you can always create a new one from scratch or edit existing ones.

When creating your own prioritization templates, you need to define prioritization metrics and a formula for calculating the issue's final score.

To make your prioritization template unique, Foxly lets you select from different types of metrics. Pick the one that’s best suited for your use case.

Available metric types:

  • ⭐️ Rating - creates a 5-star rating

  • 🏷 Label - creates a set of labels with custom names and colors

  • ✏️ Short text - creates a drop-down with text values

  • 🔢 Number - creates the field that accepts a number input (supports four decimal numbers)

Create a new template

From the Project menu, navigate to the Priorities tab.

  2. Click the Select prioritization template drop-down.

  3. Select + Create a new template option.
