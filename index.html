Overview

Foxly is a backlog prioritization app for Jira Cloud that allows managers and leads to standardize the backlog prioritization process using data metrics and scoring formulas.

Foxly keeps your team and stakeholders up to date on work priorities with real-time priority scoring.

Watch the Foxly getting started video!

Main Foxly features

Project priorities table

Project issues appear in the table view together with metrics and the priority score. Click the fields to assign metrics to issues. Once all metrics are filled in for an issue, the score is automatically calculated.

Priority matrix

The priority matrix lets you analyze different priority quadrants. You can select what values you want to work with, and issues are then rendered on the chart.

Predefined priority templates

You can use one of our predefined prioritization templates to get you started quicker:

  • ICE

  • RICE

  • Value vs Effort

  • WSJF (Weighted Shortest Job First)

  • Quick Wins method

Check https://jexo.io/what-prioritization-method/ to see which template is right for you.

Prioritization Templates customization

You can use the Customize function to customize the existing prioritization template, including the scoring formula, or create a new one from scratch.
