# BigPicture teams

You can use BigPicture teams to filter time entries in Time Explorer and Approval Periods views.

## Access

Enable the [BigPicture integration](https://appfire.atlassian.net/wiki/x/zoL5r) to access this function.

## Approvals Periods

You have to have an [Admin or Manager role](https://appfire.atlassian.net/wiki/x/5QD8r) assigneded to access Approval Periods.ccess [Approval Periods](https://appfire.atlassian.net/wiki/x/EYLZr).

1. Select **Approval Periods** from the left panel**.**
2. Select **Filters** in the table header.
3. Select **BigPicture team**.
4. Choose one or more teams by checking the required checkbox. You can also filter the team list by text.
5. Now the table has only entries by the users from the chosen team or teams.

![teams-approval-periods.png](/cms_trial/assets/eb6aa989-c628-4941-83a8-a562e6bc1b42.png)

## Time Explorer

1. Select **Time Explorer** from the left panel.
2. Select **People** in the table header.
3. Select **BigPicture team.**
4. Choose one or more teams by checking the required checkbox. You can also filter the team list by text.
5. Now the table has only entries by the users from the chosen team or teams.

![times-explorer-teams.png](/cms_trial/assets/d0faaab5-4ef6-4999-a74e-0aaae5d48165.png)
