# Release Notes 19 February 2026

**Release date**: February 18, 2026

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

---

## New features

### Manager review of workload time sheets in Approvals

Managers can now review an employee's time sheet for their workload directly on the approvals page.

### Custom future work log limitations

Introduced custom rule settings that allow administrators to limit the number of days into the future for which users can enter or edit work logs.

### Time Sheet hierarchy view

The time sheet now visually represents the parent-child hierarchy of work items for better tracking and context.

### Time Sheet cell dragging and total time calculation

Users can drag to select multiple time sheet cells to view the calculated total time in a tooltip. Individual cells can also be selected using a modifier key.

### Calendar event-based work log suggestions

The Add Time Dialog is enhanced to provide calendar event suggestions when smart suggestions are unavailable, such as when recurring events or title matching are present. This feature is in beta - if you have any feedback, feel free to contact our [support team](https://appfire.atlassian.net/servicedesk/customer/portal/11).
