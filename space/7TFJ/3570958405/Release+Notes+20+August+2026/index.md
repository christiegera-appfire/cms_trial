# Release Notes 20 August 2026

**Release date**: August 20, 2026

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

---

## Configurable Jira Sync

It is now possible to define the start day for Jira to 7pace Timetracker sync up to 180 days in the past and turn the sync on and off.

For more information, check the [Jira to 7pace Timetracker](/cms_trial/space/7TFJ/3568304134/Jira+to+7pace+Timetracker+synchronization/) documentation page.

## New data residency rules

New data residency rules have been apply to the app. To find out more, check [7pace Timetracker for Jira Data Residency Policy](/cms_trial/space/7TFJ/3553100664/7pace+Timetracker+for+Jira+Data+Residency+Policy/).

## Worklog suggestions settings

You can influence how worklog suggestions are calculated by defining additional settings. To find out more, check the <https://appfire.atlassian.net/wiki/spaces/7TFJS/pages/2923135317/Worklog+suggestions#Settings> page.
