# Release Notes 5 August 2025

**Release date**: August 5, 2025

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

---

## Enhancements

## Expanded API endpoints

We’re excited to announce expanded [API](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=7tfj&title=Connect%20external%20systems%20by%20APIs&linkCreation=true&fromPageId=2253783158) capabilities 7pace for Jira!

You can now not only pull data from 7pace for your reporting needs, but you can also **push** data to 7pace! This has multiple benefits, including:

- Migrate from your existing time tracking solution to 7pace
- Automate time tracking for team members that use custom-built remote apps to interact with Jira items

Additionally, we've introduced developers' documentation where you can find all information on all available endpoints together; start coding yourself, or use this as a reference for your AI agents.

There's more in the pipeline - obtaining incremental changes and improved structure of custom time tracking fields, among others. Stay tuned!
