Add worklogs

4 min read
[Unmapped macro: aura-html — no content to fall back on]

Learn how to add worklogs and log time in Jira with 7pace Timetracker. This guide covers tracking time directly on Jira issues and via centralized views like the Timesheet or calendar. Streamline your Jira time tracking using timepicker enhancements and worklog suggestions for maximum accuracy.

With 7pace Timetracker, it takes only a few steps to track time on a Jira issue.

  1. Open a Jira work item.

  2. In the right-hand pane, scroll down to the Time Tracking section.

  3. Click +Add Time.

Complete the worklog entry to add time to the work item; see below for detailed steps.

Add time with 7pace Timetracker for Jira

Use the following steps to add time to a Jira issue:

  1. Open the Jira issue, and, in the right-hand pane, scroll down to the Time Tracking section.

  2. Click + Add Time.

  3. The Add Time window displays. From this screen:

    1. Jira admins can use the drop-down menu and assign time for another user.

    2. Non-admins are always tracking time for themselves.

  4. Specify the date and then either enter the amount of time spent on the issue or click one of the default time buttons, for example, 1 hour.

  5. Add a time tracking comment, if required, and click Save.

  1. The newly added time displays in the Time tracking summary.

7pace Timetracker's time pickers can be used to add time to existing worklogs or to combine time to apply the correct duration.

To illustrate this feature, let's open an existing worklog in Monthly view. Click the edit button. Here, we see the current duration is 2 hours. However, assume the actual time frame spent on this worklog is 4 hours. Simply click the +2 hours button, and the duration field updates.

Next, let's log time on a new issue. In the 'Add Time' window, assume we spent 3 and a half hours working on the issue. Click 2 hours, 1 hour, and .5 hours to quickly set the total duration.

To summarize, 7pace Timetracker's time pickers can be used to quickly add and edit the worklog duration field.

Add time in 7pace

You can log time directly from 7pace by choosing Add Time in:

  • Monthly view

  • Weekly view

  • Timesheet

  • Times Explorer

The option is available in the header of these views and in the time tables:

When you choose Add Time, the Add Time window is opened:

  1. Search for a Jira issue for which you want to log time. You can also use the Worklog suggestions to find an issue.

  2. Choose date. To create worklog for multiple days in bulk, switch the Select multiple days toggle. Now you can select more than one day to create the same worklog in many days. Creating multiple worklog in advance is restricted to 7 days in the future.

The multiple day selector feature is being rolled out gradually (approximately 10% of users per day) to ensure stability. It will be available to all users soon. If you require immediate access, please contact our support team.

  1. Choose start and end date (when the Timeframe toggle is switched on). You can choose duration manually or by clicking time periods (when the Timeframe toggle is switched off).
    Under the date there is information about already logged time. If you have the BigPicture integration enabled, there is also information about remaining capacity.

  2. Add comment, if needed.

  3. Choose Save.
