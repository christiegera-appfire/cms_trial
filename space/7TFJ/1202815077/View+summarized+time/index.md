# View summarized time

Use the *Time Tracking* summary to identify how much time has been logged against an issue.

## Watch a video: How to identify how much time is logged against an issue

The following video provides details for using the time tracker summary to identify how much time has been logged against an issue.

## Summarize time in 7pace Timetracker for Jira

Use the *Time tracking* summary to identify how much time has been logged against an work item.

In the example at right, two people have logged 4 hours and 25 minutes against the Jira work item.

![user-SummarizeTime1.png](/cms_trial/assets/bbce19e8-9d5b-472a-8fdc-561f13af10da.png)

As a second example, three users have logged time against the Jira work item pictured right.

![user-SummarizeTime2.png](/cms_trial/assets/69289057-84df-4588-8735-9bcb14a6a162.png)

And, if we expand the time for an individual user, a row displays the **Logged Time**, **Date**, and **Start** and **End** times. If a worklog has a comment, an icon will be displayed; hover over the icon to view the comment.

Hover over an individual row to display the **Edit** and **Delete** buttons.

![user-SummarizeTimeIndividualLogs.png](/cms_trial/assets/5c0fa4b1-7b36-4854-a001-00cfb6b5aa69.png)
