# Release Notes 12 November 2026

**Release date**: November 12, 2026

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

## New features

### What's new page

A "What's new" page shows the latest release notes in the app. A new item in the left navigation opens it and shows an indicator when there is a post you haven't seen.

![whats-new.png](/cms_trial/assets/e263a2ae-8726-4f9b-bd4e-703b6567a94c.png)

### User emails in tooltips in reporting views

User emails no longer show inline in reporting views. You see the email in a tooltip. Times Explorer and Approvals have new email columns.

### Approval email changes

The manager notification email now lists up to 10 pending submissions, including the submitter name and submission date. If there are more, the email shows how many more are waiting for approval.

### Approval manager list - No approval managers message

The submission window shows "No approval managers" in the manager list when no manager is available. The warning banner is removed.

### Turn off approvals message

When an administrator turns off Time Approval, a message tells them that approved periods stay locked.

## Fixes

### Incorrect worklog author in Jira

Fixed an issue that kept the old user on the Jira worklog after an assignee change in 7pace.

### Incorrect Add Time duration

Fixed an issue where the quick-add buttons added time to the old duration after you cleared the field with Backspace or Delete.

### Incorrect Approvals empty state

Fixed an issue where the Approvals page showed no empty state for some filters, and "Use default layout" did not work.
