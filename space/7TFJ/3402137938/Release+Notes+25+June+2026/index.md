# Release Notes 25 June 2026

**Release date**: June 25, 2026

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

---

## **New Features**

- **Big Picture Integration Enhancements:** You can now check your daily capacity, public holidays, and working hours directly in the app. Working hours are highlighted with a distinct striped pattern for better clarity.
- Rolling out **Visual Reporting:** Basic visual reporting is now available. You can group and filter time tracking data directly within custom dashboard gadgets.

- **Item View Suggestions:** Time tracking suggestions are now available in the Item View. For more details, check the [Worklog suggestion page](/cms_trial/space/7TFJ/2934210708/Worklog+suggestions/).
- **Period Approval View:** An option for filtering out users inactive for 90 days added.

**Improvements**

- **User Interface:** Improved drag-and-drop handling for popups. Suggestion feature highlights (formerly purple/violet) have been removed for a cleaner, more consistent design.

**Important Notices**

- **Connect Version Deprecation:** The Connect version of 7pace Timetracker is scheduled for full deprecation by the middle of next month. Please migrate to the latest version as soon as possible to ensure continued service.
