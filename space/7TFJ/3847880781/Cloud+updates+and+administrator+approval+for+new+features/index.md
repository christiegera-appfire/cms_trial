# Cloud updates and administrator approval for new features

As a cloud-based app, 7pace Timetracker for Jira is continuously improved. We release updates to our cloud servers every two weeks, so most changes, bug fixes, and general improvements are applied automatically, with no action required on your part.

However, because 7pace deeply integrates with Atlassian Forge, certain major enhancements require manual approval and a version update by your Jira Administrator.

## Why do some updates require administrator approval?

When we introduce new functionalities that utilize newly available Atlassian APIs, add new UI modules, or modify data permissions, Atlassian's security architecture requires administrators to explicitly consent to these changes.

While these manual updates are rare, failing to approve them means your instance will remain on a slightly older version of the app, and you will not have access to these new features.

### Recent features that require a manual app update include:

- **US Data Residency:** Enhanced control over where your data is hosted (7.0.0 v.)
- **Add Time Dialog using Context Menu:** A new, faster way to log time directly from the issue context menu in your work item view (7.0.0 v.)

## How to update 7pace Timetracker

To ensure your team has access to the latest capabilities, a Jira Administrator will need to update the app from the **Manage apps** section in Jira.

**Read the step-by-step guide here:**

- [Updating an app from the Atlassian Marketplace](http://support.atlassian.com/organization-administration/docs/managing-an-installed-app) (the **Update an app** section)
