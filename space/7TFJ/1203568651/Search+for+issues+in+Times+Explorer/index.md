## Search in Times Explorer

Use the following steps to search for worklog items in the *Times Explorer*:

1. Click **Apps** > **Timetracker** > **Times Explorer**.
2. In the **Search** box, enter terms from the following columns:

   1. Issue Title
   2. Project
   3. Date Logged
   4. Person
   5. Start
   6. End
   7. Logged Time
3. You can also search for text in the worklog comments

Note that you can also focus your search on a specific date range using the date dropdown.

![The pre-defined date drop-down menu.](/cms_trial/assets/23574d65-f517-4466-a58c-55d8e2a270a8.png)

Or, you can select a specific date range by clicking the calendar and choosing a start and end date.
