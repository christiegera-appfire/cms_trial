# Report on time

![TryItButton (2).png](/cms_trial/assets/ce0a4b0d-efdb-483b-b4da-5f62876476ef.png)

The Times Explorer enables you to report on worklogs using nearly any data point in your Jira instance. This includes creating private views you can use to repeatedly report on individual team members, entire teams, and projects, among many others.
