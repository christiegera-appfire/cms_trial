# Private views in Times Explorer

![TryItButton (2).png](/cms_trial/assets/cba7479f-9735-426f-be0c-e9e8abed1974.png)

7pace Timetracker's private views increase productivity by providing quick access to your preferred report configurations.

## Watch the video

Review the following video to learn more about private views in the Times Explorer.

## Create a private view

Use the following steps to create a private view:

1. Open the *Times Explorer*.
2. In the upper right-hand corner, note that the current view is the *Default view*. Add a filter to only see issues from the Hybrid project.

   ![image-20250110-211042.png](/cms_trial/assets/0beb92cc-6e15-4de3-a9b2-6babc09ba21b.png)
3. Now, in the upper right-hand corner, open the view drop-down and click **Save as new view**.

   ![image-20250110-211212.png](/cms_trial/assets/0febfb06-7538-42b2-bb5f-7a005312d73f.png)
4. Enter a name for the new view and click **Save layout**.

When saving a second private view, you have the option to update the existing view or save a new view.

## Delete a private view

To delete a view, click the delete button to the right of the view name.

![image-20250110-210838.png](/cms_trial/assets/8fbaf434-b939-49ca-a83c-a8537ae2bc8c.png)

Note that there is an Undo option that displays in the lower right-hand corner, just in case the private view was deleted by accident.
