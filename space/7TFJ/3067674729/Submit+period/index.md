# Submit period

When the required work is finished, you can submit it for review. To do that, choose **Submit period**. You can do this in:

- Monthly view
- Weekly view
- Timesheet.

![submit-period.png](/cms_trial/assets/85c43318-f74f-4f55-b67d-f730e3b98239.png)

Here you can choose one of the open periods. You can check the total logged hours for the period. If you enable the [BigPicture integration](/cms_trial/space/7TFJ/2106556524/BigPicture+integration/), capacity appears in the header too (the capacity can be changed only in BigPicture - not in 7pace).

Now, select the reviewer of your period and select **Submit**.

![period-reviewer.png](/cms_trial/assets/cda3a58c-324b-433c-919f-d8f7d26b98e2.png)

## Edit submission

To change the submission of the period, select **Submit period** again and select **Edit submission**:

![edit-submission.png](/cms_trial/assets/533a487c-d471-4d13-aa93-6620e1a7d19a.png)

Select **Revoke submission**:

![revoke-submission.png](/cms_trial/assets/fc40b655-d5bf-452f-a64d-180c4f3db69c.png)

Now you can select **Submit now** again.
