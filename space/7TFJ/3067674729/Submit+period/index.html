Submit period

[Unmapped macro: aura-html — no content to fall back on]

When the required work is finished, you can submit it for review. To do that, choose Submit period. You can do this in:

  • Monthly view

  • Weekly view

  • Timesheet.

Here you can choose one of the open periods. You can check the total logged hours for the period. If you enable the BigPicture integration, capacity appears in the header too (the capacity can be changed only in BigPicture - not in 7pace).

Now, select the reviewer of your period and select Submit.

Edit submission

To change the submission of the period, select Submit period again and select Edit submission:

Select Revoke submission:

Now you can select Submit now again.
