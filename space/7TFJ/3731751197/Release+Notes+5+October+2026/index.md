# Release Notes 5 October 2026

**Release date**: October 5, 2026

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

## New features

### Worklogs suggestions

The worklog suggestions are now available for Comments and Custom Fields in Timesheet and after selecting a work item in the Add Time window.

## Fixes

### Readonly Google Calendars

Google Calendars with readonly permissions, including shared team and holiday calendars, now appear in the calendar suggestions panel.

### Worklog comment synchronization

Fixed an issue that could prevent worklog comments from synchronizing correctly with Jira issue activity.

### Data Visualization field names

Data Visualization widgets now display human-readable custom field names instead of internal field IDs.

### Firefox exports

Fixed an issue that prevented worklog and timesheet exports from downloading correctly in Mozilla Firefox.

### Calendar re-authorization privacy

Improved calendar re-authorization security so another user’s mailbox address is not exposed during reconnect flows.
