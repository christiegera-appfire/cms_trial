# Weekly view

7pace Timetracker's *Weekly* view provides visual options for inputting, editing, copying, and deleting time. To access the *Weekly* view, click **Apps** > **Timetracker** > **Weekly**.

## Weekly view

### Access

7pace Timetracker's *Weekly* view provides visual options for inputting, editing, copying, and deleting time. To access the *Weekly* view, click **Apps** > **Timetracker** > **Weekly**.

### Displayed data

Here, your time is displays for each day of the week.

In the header of the table you can see Total - a sum up number of all the hours recorded in the week.

![weekly-view.png](/cms_trial/assets/fff0db42-ada5-4744-8cff-de66a4858f7e.png)

If you enable the [BigPicture integration](/cms_trial/space/7TFJ/2106556524/BigPicture+integration/), capacity appears in the header:

![weekly-capacity.png](/cms_trial/assets/66b5ec70-5f66-4454-a23a-def1b3c71379.png)

### Add time for an issue

Note that time can only be added for the current user in *Weekly* view. Use the following steps to add time:

1. Drag to specify the start and end times.

   ![Drag to define the start and end times.](/cms_trial/assets/89ad15b8-ad4d-4b10-aa6f-b3852ebd94d1.png)
2. The *Add Time* window displays.
3. Select an issue, confirm the date and duration, and then enter a comment if necessary.

   ![monthly-view-add-time.png](/cms_trial/assets/20c2591c-1573-472a-a836-99580675d5f0.png)

   In the left panel you can check smart suggestions for Jira issues to use, based on you previous time logs. For more information, check <https://appfire.atlassian.net/wiki/x/VYE7rg> .
4. Click **Save**.

### Add time for a non-issue

Use the following steps to log time against a meeting or project that isn't related to a ticket:

1. Drag to define the start and end time.
2. Enter a comment that describes the worklog.

   ![Enter a comment to describe how you spent the time.](/cms_trial/assets/ff8ac95e-71d8-4dad-a40e-d9807fd87ff8.png)
3. Click **Save**.

### Edit time

Use the following steps to edit time in the *Weekly* view:

1. Hold the pointer over a worklog and click **Edit**.

   ![Click the Edit button.](/cms_trial/assets/83c4fbc7-fb8f-43a6-abdf-6e40410ae20e.png)
2. The *Edit Time* window displays.
3. Here, update the issue, date, duration, or comment.
4. To access the **To** and **From** times, activate the **Timeframe** toggle.

   ![image-20241106-225242.png](/cms_trial/assets/63dc96d4-e319-4d22-b3f4-030756d4801d.png)
5. Click **Save**.

Alternatively, you can edit a worklog's timeframe, start time, end time, and day of the week using the drag method. To do so, simply select the worklog and drag it to a new time or date.

### Delete time

Use the following steps to delete time from the *Weekly* view:

1. Hold the pointer over the worklog and click **Delete**.

   ![Click the Delete button.](/cms_trial/assets/d191c8fd-3fe8-49fb-8de1-ee3a9afd1877.png)
2. The *Delete Worklog* message displays.
3. Click **Delete**.

   ![The Delete worklog message confirms that you want to remove the worklog.](/cms_trial/assets/eb92c535-2b5f-43fd-ba9d-df4562546e70.png)

### Copy worklog

Don’t forget about another time-saving feature in the *Weekly* View, **Copy Worklog**.

To use this feature:

1. Hold the pointer over the worklog and click **Copy**.

   ![Click the Copy button](/cms_trial/assets/a01ec98a-1142-48df-be36-61b6d2a0c8ef.png)
2. At the bottom of the page, a message indicates that the worklog can be copied by clicking on an empty area.

   ![This is the message that alerts you that you're in copy mode.](/cms_trial/assets/5348b6a4-802a-4f25-b37a-f8c8904d485d.png)
3. In this example, the one-on-one meeting will be copied to Thursday at the same time. Left-click on the 11:30 am time slot on Thursday.
4. To continue copying the worklog, click an open timeframe during the week.
5. If you accidentally select the wrong time, click the **X** and then select a new time.

   ![If you copy the worklog to an incorrect location, click the X.](/cms_trial/assets/6c7afd2c-5706-427e-9c93-36da06fdaa51.png)
6. When you are finished copying the worklog, click **Save** at the bottom of the page.

   ![Click save to complete the copy process.](/cms_trial/assets/7c5633ba-ea73-4ffc-8318-42d6b322cced.png)

### Zoom

The *Weekly* view also includes Tozoom functionality.

Click the **Zoom in** or **Zoom out** buttons to the left of the first day of the week.

![The zoom in and zoom out buttons in Weekly view.](/cms_trial/assets/e05fd77e-2379-4fe3-8077-f8aaf58d3328.png)
