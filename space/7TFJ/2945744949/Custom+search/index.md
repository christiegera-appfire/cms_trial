# Custom search

Admin can configure up to three fields for filtering results in the Add Time:

![7pace Timetracker for Jira custom search fields settings](/cms_trial/assets/9a6cb72c-628b-4c57-9542-14e22ca3393f.png)

## Settings

To set up the search result fields, go to the app settings, then choose Custom Rules:

![7pace Timetracker for Jira custom search filters settings](/cms_trial/assets/4652ecad-d269-4d96-8f3f-09da042c0048.png)

Switch the toggle and choose up to three fields from the drop-down list:

![7pace Timetracker for Jira Choose fields dialog for custom search](/cms_trial/assets/5703617d-f068-4584-8d9c-475261edd572.png)

Click **Save** to save the settings:

![7pace Timetracker for Jira Save settings button for custom search](/cms_trial/assets/6baa686c-721a-481e-8cb1-6f3fe0064583.png)

The fields are now available for filtering in the Add Time windows.
