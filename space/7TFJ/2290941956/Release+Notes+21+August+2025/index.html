Release Notes 21 August 2025

1 min read

Release date: August 21, 2025

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

Enhancements

Connect an Outlook calendar

Connecting an Outlook calendar with 7pace Timetracker helps automate the logging of hours based on scheduled events like meetings and appointments. This feature reduces the need for manual input and lowers the risk of errors. Key benefits include:

  • Reduce time spent on administrative tasks

  • Eliminate tool-switching when tracking time

  • Improve time tracking accuracy for planning and reporting

Connecting your Outlook calendar makes time tracking more efficient and less disruptive!

API version 2.0

The 7pace Timetracker API has been updated to version 2.0. Both versions of the API are still available, but you should update any processes accessing the API to include the version number in the URL. See the API pages for more information.

Updates in version 2.0 of the API include a modified and renamed version of the Worklog changes endpoint, rate limiting, and improved error handling.
