# Release Notes 15 October 2026

**Release date**: October 15, 2026

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

## Improvements

### Approval saved views

Save named groups of people on the Approvals page and apply them again later, similar to saved views in Times Explorer.

### Approval lists for active 7pace users

Approval user lists use 7pace role assignments so inactive users clutter the page less. The list caches daily and refreshes when the page updates.

### Comment and custom field suggestions

After a user selects a work item, the app suggests comment text and custom field values from that user’s recent worklogs on other items.

### Connect deprecation screen removed

Sites that still opened the legacy Connect entry no longer see the deprecation screen.

## Fixes

### Worklog comment sync to Jira

Worklogs that include comments sync to Jira again.

### Google calendars with read-only access

Google calendars shared with read permission appear in calendar integration.

### Calendar re-authorization privacy

Re-authorizing a calendar no longer exposes another user’s mailbox address.

### Calendar event visibility toggles

Calendar checkboxes correctly show or hide events after reconfiguration.

### Duplication comment layout

Multiline comments wrap correctly in the worklog duplication window.

### Duplication comment input

Users can enter multiline comments when duplicating a worklog.

### Add Time assignee picker

The assignee dropdown in Add Time loads person options instead of staying on the loading state.

### Weekly horizontal scroll

Users cannot scroll the weekly view past the current week bounds.
