# Install 7pace Timetracker for Jira

## Installation

**Note**: Jira administrator permissions are required for all steps detailed on this page.

Use the following steps to install 7pace Timetracker for Jira.

1. Access the Atlassian Marketplace: In Jira, go to **Apps** **>** **Explore more apps** or go to **Settings** > **Marketplace apps** and select **Explore apps** in the left-hand panel.
2. Search for ‘7pace’ to locate **7pace Timetracker for Jira** and open the details page.
3. Click **Try it free**.
4. Choose the Jira instance where you will install 7pace Timetracker, and click **Start free trial**.
5. Review the installation agreement, and click **Start free trial**.
6. The app installation takes a few moments. Once the installation completes, a success message will display in the lower left corner of your screen.
7. 7pace Timetracker now displays in the **Apps** section of the left sidebar, and in the tabs at the top of each Space screen.

## Updating Jira Timetracker

![Approval Periods Management function with system message about version of the app not up to date.](/cms_trial/assets/d716afdc-db89-47da-b93b-580fa80766a6.png)

You may be prompted to update 7pace Timetracker if you have not performed a necessary update. When an update is available, you will see a banner notifying you that one is available and needs to be applied (Figure 3, right). To perform the update:

1. In the left sidebar click **More actions** for **Apps**, and select **Manage apps**.
2. Click **Take me there** to go to the new app management tool.
3. Locate the 7pace Timetracker for Jira entry, or search for ‘7pace’.
4. Click **View app details**.
5. On app details age, click **Update** in the upper right corner.
6. On displayed app update modal, review any new permissions required and data management agreements and finalize the operation by clicking **Update**.

## Jira Time tracking setting

After completing the installation, the **Time tracking provider** should be set to **7pace Timetracker**. To locate this configuration, click **Jira Settings** > **Work items** and click **Time tracking** under **Work item features**.

Verify that **7pace Timetracker** is set under **Time tracking provider**. If necessary, edit the Global time tracking settings.

After installing 7pace Timetracker, Jira time tracking is no longer available on the work item page. Therefore, all time tracking will now be completed using the 7pace Timetracker app. However, any existing time tracked through native Jira time tracking will display in 7pace.
