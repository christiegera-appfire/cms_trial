# Release Notes 23 July 2026

**Release date**: July 23, 2026

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

---

## New features

- **Project-Level Custom Fields:** Administrators can now create and scope custom fields to specific spaces.   
  For more information, check the [Working with Custom Fields](/cms_trial/space/7TFJ/1355415553/Working+with+Custom+Fields/) page.

- **Jira Synchronization**: New settings for exporting worklogs from 7pace to Jira.  
  For more information, check the [7pace Timetracker to Jira syncronization](/cms_trial/space/7TFJ/3491495942/7pace+Timetracker+to+Jira+synchronization/) page.
