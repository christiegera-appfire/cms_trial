# Release Notes 29 October 2026

**Release date**: October 29, 2026

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

## Improvements

### Inactive users in person list

The person list for logging time for someone else shows deactivated users labeled as such. You cannot select them. Users removed from Jira do not appear.

### Worklog changes by the requester

Jira worklog updates and deletions use the identity of the person who makes the change. They keep working when the assignee is suspended or removed from Jira.

### Outdated app version banner

A banner tells users when their Forge app version is outdated.

## Fixes

### Safari drag and drop

Fixed an issue that prevented users from moving worklogs with drag and drop in the Weekly and Monthly views in Safari.

### Deleted worklog in Jira

Fixed an issue where a worklog deleted right after creation remained in Jira.

### Approval emails

Fixed an issue where approval reminders and daily notification emails were not delivered.

### Weekly suggestions toggle

Fixed the position of the Show suggestions toggle in the Weekly view when the Planned tasks panel is open.

### Start time history

Fixed an issue where the Audit Log recorded start-time changes when the start time didn't change.
