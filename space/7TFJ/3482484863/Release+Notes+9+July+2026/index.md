# Release Notes 9 July 2026

**Release date**: July 9, 2026

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

---

## New features

- **Save Work Items (Favorites):** Users can now "star" up to 10 issues in the Add Time dialog. Favorites persist across sessions, even if issues are closed or marked as done, ensuring quick access to essential tasks.

- **Project-Level Custom Fields:** Administrators can now create and scope custom fields to specific spaces.
- **Enhanced Settings Navigation:** We have restructured settings into "Global" and "User-wide" categories for better usability.

  - **Worklog Suggestions:** New tab for configuring duration calculations based on percentages or transition times.
- **Timesheet UI:** Added horizontal resizing capabilities for the nested work item list to improve visibility.

## **Important Notices**

- **Connect Version Deprecation:** The Connect version of 7pace Timetracker is scheduled for full deprecation by July 15, 2026 Please migrate to the latest version as soon as possible to ensure continued service.
