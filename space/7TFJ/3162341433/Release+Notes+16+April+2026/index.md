# Release Notes 16 April 2026

**Release date**: April 16, 2026

Our team is thrilled to announce the latest release of 7pace Timetracker for Jira.

---

This release focuses on improving user experience in the Timesheet and Time Explorer views, enhancing search capabilities, and strengthening the stability of our backend systems.

## Key Enhancements

**New User Feedback Form**

A new in-app user feedback form has been added, allowing us to collect immediate positive and negative feedback regarding the Worklog Suggestions function.

**Time Sheet UX Improvements**

We enhanced the time sheet view with several significant updates:

- The time sheet now accepts various Jira time formats, not just the default one.
- Smaller **Add Time** and **Submit Period** buttons now display on narrow screens.
- An issue where focus was lost when tabbing from duration to the comment field has been fixed.

**Improved Search Relevance**

- We have addressed customer requests for more flexible search, better sorting, and displaying more items:

  - The search logic is improved to find non-exact phrases and display all issues.
  - When a project filter is selected, search results are now sorted by the last updated time.

**Times Explorer User List Visibility**

- The user list is now truncated if there are over 20 users. It now includes a constantly visible link to the Times Explorer, automatically filtered by the current person and date range.
