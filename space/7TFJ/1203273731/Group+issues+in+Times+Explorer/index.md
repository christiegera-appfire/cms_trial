# Group issues in Times Explorer

![TryItButton (2).png](/cms_trial/assets/5de16aaa-bc3b-498b-9021-def72044dc78.png)

In the *Times Explorer*, you can group issues based on columns. Grouping provides you with a filtered snapshot of your data and customizable views to help you manage and analyze worklogs.

## Watch the video

Review the following video to learn how to group issues in the *Times Explorer*.

## Group issues by column

Use the following steps to group issues in the *Times Explorer*:

1. Click the group icon next to the column heading.

   ![The group icon in the column header](/cms_trial/assets/a0ffff59-30b4-4d63-9cbb-54c65a693fbb.png)
2. After creating a group, the following information displays in the header:

   1. Total number of worklogs.
   2. Total logged time for all grouped issues.

      ![Group information](/cms_trial/assets/d412b37e-335b-4c85-b0d1-bd38bb71b70b.png)
3. Click the expand icon to see individual issues for the grouped column.

   ![The expand group icon](/cms_trial/assets/6fa5a9fa-5b5a-459d-80f0-6ef3d9eba20f.png)
4. Collapse the items by clicking the same icon.

   ![Click this button to collapse the group](/cms_trial/assets/90ca308d-615f-4838-b23b-56c803825f4a.png)

## Ungroup

To ungroup issues, click the group icon.

## Group issues - Customize columns

You can also use the Customize columns window to group worklogs. Use the following steps:

1. Click settings.

   ![image-20241108-203517.png](/cms_trial/assets/d31a21ee-09f8-4d13-8d4b-5065da99f34e.png)
2. Search for the field you want to use for grouping.
3. Click the group icon next to the field name.

   ![Search for a field name and click the group icon.](/cms_trial/assets/5e8b8a9d-b4ca-4548-8990-f13a39669456.png)
4. The group is applied to the Times Explorer.

   ![Grouping is applied to the Times Explorer.](/cms_trial/assets/bf8ca524-5231-457b-b383-083c4fc410f0.png)
