# 7pace in Jira

Once the [7pace installation](https://appfire.atlassian.net/wiki/x/oAHtr) is completed, 7pace is available from the Jira installed apps panel level and from the right panel in Jira’s work item.

![7pace-in-jira.png](/cms_trial/assets/01077a73-e97b-4e15-8813-9c8745139052.png)

## Add Time

You can add time in 7pace directly from a Jira work item. Check the [Add worklogs page](/cms_trial/space/7TFJ/1202159710/Add+worklogs/) for more information.

### Total

Total number of recorded hours on the current task and all tasks lower in hierarchy.

### Exceeded

Number of hours that exceed the estimation.

### Pace on SP

Pace on Story Points.

The pace is calculated once story points have been estimated.

## Time by user

Time recorded by users for the work items.

Click a user’s row to get a detailed view of all the records of this user.

You can edit or remove records by selecting options in their rows

## Time on items

![time-on-item-hover.png](/cms_trial/assets/b1232b93-8f19-4716-8d07-01e89db7d9e7.png)

This section shows the sum of time recorded for the current task and any child tasks.

In the top-right corner of this panel, you can check the total time for the current task and all subtasks, summed and rolled up to the current level. The task tree shows one level down. If a task has more sub-levels, an icon is displayed next to it, showing the number of tasks in lower levels that contribute to the hours on the current and first sub-level.
