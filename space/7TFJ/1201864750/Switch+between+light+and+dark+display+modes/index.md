# Switch between light and dark display modes

![TryItButton (2).png](/cms_trial/assets/8134c664-be3a-4f00-bea6-44d883d594db.png)

There are three display mode themes you can select in Timetracker:

- Light mode
- Dark mode
- Match browser mode

To switch display modes, follow these steps:

1. After you install 7pace Timetracker, click your profile picture in the top-right corner of the Jira page.
2. Click **Theme**.

   ![theme_in_profile..png](/cms_trial/assets/e72af2e6-ff2e-481c-8243-5e7843ace0e2.png)
3. Click one of the three display modes:

   ![light_and_dark_modes.png](/cms_trial/assets/773abb46-63a9-402c-93e8-90bcd24f6203.png)

**Match browser** mode will automatically match the browser theme you have in your browser settings.
