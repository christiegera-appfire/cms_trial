# Admin guide

This guide covers everything you need to set up, configure, and manage in 7pace Timetracker for Azure DevOps. Choose a topic below based on what you'd like to do:

- [**Installation and Data Security**](/cms_trial/space/7TFA/1253540127/Installation+and+Data+Security/) — Learn how to install 7pace Timetracker and understand how your data is handled and protected.
- [**Authorization methods**](/cms_trial/space/7TFA/2193557481/Authorization+methods/) — Configure how users authenticate and connect to the app.
- [**API & Reporting**](/cms_trial/space/7TFA/1253540254/API+%26+Reporting/) — Access time tracking data programmatically and set up reporting capabilities.
- [**Apps**](/cms_trial/space/7TFA/1253540242/Apps/) — Manage app integrations and connected applications.
- [**App configuration**](/cms_trial/space/7TFA/3488055333/App+configuration/) — Adjust global settings, permissions, and preferences for your 7pace instance.
