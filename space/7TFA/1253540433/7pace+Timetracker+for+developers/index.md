# 7pace Timetracker for developers

**7pace Timetracker** embeds time logging directly into Azure DevOps (ADO), allowing developers to track effort on work items without breaking context or using external tools. Linking tracked time directly to completed work improves estimation accuracy, sharpens task planning, and streamlines time management.

### Key metrics and insights

- **Individual pace:** Track personal productivity and velocity over time.
- **Remaining effort:** See exact remaining time left on active tasks.
- **Sprint burndown:** Automatically update burndown charts based on real effort logged.

### Core features

- **Flexible logging:**

  - **Real-time or Retroactive:** Use live timers (search and click **Start**) or enter/edit time post-factum.
  - **Flexible work items:** Log time to specific Azure DevOps items or track effort without an ADO ID.
  - **Excel import:** Easily import externally logged time into the [Times Explorer](/cms_trial/space/7TFA/1253540013/Times+Explorer/) page.
- **Dedicated views:**

  - **Timesheet:** Features sprint board analysis, a spreadsheet-style list editor highlighting your assigned *in progress* items, and end-of-week submission workflows.
  - **Monthly calendar:** A [monthly page](/cms_trial/space/7TFA/1253540070/Monthly+view/) for manual entry, editing, and monthly approvals.
- **Cross-platform access:**

  - Native web app integrated directly within Azure DevOps.
  - Optional desktop apps for Windows and Mac that sync seamlessly or function independently.
