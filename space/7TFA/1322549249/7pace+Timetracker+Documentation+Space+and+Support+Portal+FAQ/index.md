# 7pace Timetracker Documentation Space and Support Portal FAQ

| **Question** | **Answer** |
| --- | --- |
| Why is 7pace Documentation and Support moving to a new space? | 7pace Timetracker is an Appfire product, so we’re moving its documentation and support portals into a single platform. |
| How will customers get to the new Documentation space? | - [Azure DevOps Documentation space](https://appfire.atlassian.net/wiki/spaces/7TFA) - [monday.com Documentation space](https://appfire.atlassian.net/wiki/spaces/7TFM) |
| Where will customers go to submit a support request after the new transition? | After the migration, 7pace customers will be able to raise a support ticket based on the platform they use (Azure DevOps or monday.com).  Below, you’ll find all of the links for support:   - Main Support help center: [appf.re/help-center](http://appf.re/help-center)    - Azure Dev Ops support help center: [https://appf.re/azure/support](https://urldefense.com/v3/__https://appf.re/azure/support__;!!Arz0ZkbI!AHYkPlSpMzOphLECa2gBS5whW-0sjBSlI4HipNrsrEGP1iD8bLzy-QRPQLn_8qJMe_uFTBp--ySRPqq33xn-FA$)   - monday.com support help center: <https://appf.re/monday/support> |
| How will customers get to the Support Portal? | There are a few ways:   1. Directly: <https://appfire.atlassian.net/servicedesk> 2. Via the “Technical support” tab on the Marketplace listing 3. Via the banner that will be posted on impacted instances during each migration phase 4. Via the Support section in the footer on <https://appfire.com/> |
| How will customers know about the new Documentation Space and Support Portal for 7pace Timetracker? | **Pre-Migration:**  Before the migration, a banner will be posted at the top of the current 7pace Documentation and Support page to notify customers of a change coming.  **Post-Migration:**  Right after migration, we will post an updated banner guiding customers to the new Documentation space and Support Portal. |
| Which email should customers use for support? | **Azure support email:** [supportazure@appfire.com](mailto:supportazure@appfire.com)  **monday.com** **support email:** [supportmonday@appfire.com](mailto:supportmonday@appfire.com) |
| What will happen to open customer support tickets once we migrate an instance? | 1. A banner will be posted for the instances migrating during that phase, notifying customers of the location change. 2. Any open customer tickets will have a comment added with an explanation of what has changed and where their ticket now lives within the new portal. 3. Customers will not have to create a new account as we are migrating that information as well. |
| In the past, customers could suggest new features and comment and watch the progress on those items, will this continue? | Yes, customers can view and comment on our roadmap [here](https://portal.productboard.com/7pace/2-7pace-for-azure-devops-feature-portal). Features that are in recently released, planned, and being considered are shown here. |
