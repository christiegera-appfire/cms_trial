# Use Entra ID to authorize 7pace Timetracker for ADO cloud

[Microsoft’s](https://www.microsoft.com/en-us/security/business/identity-access/microsoft-entra-id) [**Entra ID**](https://www.microsoft.com/en-us/security/business/identity-access/microsoft-entra-id) can be used to authorize 7pace Timetracker for the ADO cloud.

When using Entra ID for authorization, admin consent requests are required for each user. To bypass this step, [grant tenant-wide admin consent](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/grant-admin-consent?pivots=portal) for 7pace Timetracker.

## Authorization Steps

Use the following steps:

1. In the *Authorize 7pace Timetracker* window, select **Entra ID**.

   ![Entra ID can be used to authorize 7pace Timetracker for ADO cloud](/cms_trial/assets/360b962c-0d18-44d8-9c81-f55cb8fa2c83.png)
2. Click **Authorize.**
3. The *Microsoft Pick an account* window displays. Here, select the Microsoft account that will be used for authorization.

   ![Select the Microsoft account that will be used for authorization](/cms_trial/assets/dfaea48e-83ab-4865-a37e-609b41213839.png)
4. The app is authorized, and you can begin using 7pace Timetracker for ADO cloud.
