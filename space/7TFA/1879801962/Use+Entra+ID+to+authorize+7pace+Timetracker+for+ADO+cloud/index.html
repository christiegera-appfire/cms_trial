Use Entra ID to authorize 7pace Timetracker for ADO cloud

1 min read

Microsoft’s Entra ID can be used to authorize 7pace Timetracker for the ADO cloud.

When using Entra ID for authorization, admin consent requests are required for each user. To bypass this step, grant tenant-wide admin consent for 7pace Timetracker.

Authorization Steps

Use the following steps:

  1. In the Authorize 7pace Timetracker window, select Entra ID.

  2. Click Authorize.

  3. The Microsoft Pick an account window displays. Here, select the Microsoft account that will be used for authorization.

  4. The app is authorized, and you can begin using 7pace Timetracker for ADO cloud.
