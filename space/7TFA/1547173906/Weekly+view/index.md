## Weekly view

7pace Timetracker's *Weekly* view provides visual options for inputting, editing, copying, and deleting time. To access the Weekly view, go to the left-hand pane, and click **7pace Timetracker** > **Weekly**.

### Add time for an issue

Note that time can only be added for the current user in *Weekly* view. Use the following steps to add time:

1. Drag to specify the start and end times.
2. The *Add Time* window displays.
3. Select an issue, confirm the date and duration, and then select a category and add a comment, if necessary.

   ![Add_Time_for_Issue.png](/cms_trial/assets/0325f507-06dd-45b9-8c2f-7cf2201ea12e.png)
4. Click **Save**.

### Add time for a non-issue

Use the following steps to log time against a meeting or project that isn't related to a ticket:

1. Drag to define the start and end time.
2. Enter a comment that describes the worklog.

   ![Add_Time_for_Non_Issue.png](/cms_trial/assets/b71ad374-4e6b-488a-8f51-702a1e2d8d09.png)
3. Click **Save**.

### Edit time

Use the following steps to edit time in the *Weekly* view:

1. Hold the pointer over a worklog and click **Edit**.
2. The *Edit Time* window displays.
3. Here, update the issue, date, duration, or comment.
4. To access the **To** and **From** times, activate the **Timeframe** toggle.

   ![Edit_Time.png](/cms_trial/assets/3230cc73-4507-4bbb-8b33-7c3f02e5df3b.png)
5. Click **Save**.

Alternatively, you can edit a worklog's timeframe, start time, end time, and day of the week using the drag method. To do so, simply select the worklog and drag it to a new time or date.

### Delete time

Use the following steps to delete time from the *Weekly* view:

1. Hold the pointer over the worklog and click **Delete**.

   ![Delete_Time.png](/cms_trial/assets/9baf214f-e1f4-4a9f-8e1f-37daaf8c3ee1.png)
2. The *Delete Worklog* message displays.
3. Click **Yes**.

### Copy worklog

Don’t forget about another time-saving feature in the *Weekly* View, **Copy Worklog**.

To use this feature:

1. Hold the pointer over the worklog and click **Copy**.

   ![Copy_Worklog.png](/cms_trial/assets/b007b53c-40e5-400c-a4ae-c39e174469ad.png)
2. At the bottom of the page, a message indicates that the worklog can be copied by clicking on an empty area.

   ![Duplicate_Worklog.png](/cms_trial/assets/9c33217d-1e05-4f93-9ce0-b48d434c5016.png)
3. Left-click the desired time slot on the calendar.
4. To continue copying the worklog, simply left-click another open timeframe during the week.
5. When you are finished copying the worklog, click the Save button at the bottom of the page.

### Zoom

The *Weekly* view also includes Tozoom functionality.

Click the **Zoom in** or **Zoom out** buttons to the left of the first day of the week.

![Zoom_In_Out_Button.png](/cms_trial/assets/87f30d71-c9a1-4132-a7fa-cc7df766130f.png)
