# How to limit users based on roles, hide or make visible records from other users

### How do I limit what users can see based on roles, and how do I hide records that belong to other users?

To restrict users from seeing other people's time, please assign the **Team** role to the users who should only be able to see their own time:

![FAQ_Limit_Users.png](/cms_trial/assets/d48550f1-dcb2-44e9-99cb-90e9e372f5ab.png)

With the Team role, they will have access to only their data.

More on user roles is available here: [User roles general info](/cms_trial/space/7TFA/1253539946/Misc%3A+User+%26+Subscription+Management/).

You should keep in mind that on the work item form 7pace Timetracker tab, any user can see activity from other users, however, they see only a summary and not the exact worklogs.
