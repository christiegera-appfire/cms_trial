# User guide

This guide covers everything you need to use 7pace Timetracker for Azure DevOps — from logging your first worklog to managing team approvals and budgets. Browse the sections below to find the feature you're working with, or follow the suggested starting points based on your role.

## Accepting the 7pace Timetracker invitation email

When a new user is assigned a license for 7pace Timetracker for Azure DevOps, they receive an automated invitation email. Users must accept this invitation and agree to the policy to access the product features within Azure DevOps.

This step is easy to miss during onboarding. If a user has the correct Azure DevOps access level and a valid 7pace role but still cannot see or use 7pace, confirm that they received and accepted the invitation email.

## What you can do in 7pace Timetracker

- **Track time your way** using Monthly, Weekly, Timesheet, or the Add Time dialog
- **Work directly from Azure DevOps** through the work item form, backlog actions, and integrated tracking controls
- **Review and manage worklogs** with Times Explorer filters, grouping, layouts, import, and export
- **Assign and manage budgets** for iterations, work items, and individual worklogs
- **Submit and approve timesheets** with a structured approval workflow for team members and managers
- **Connect your calendar** to bring events into Weekly view and turn them into worklogs faster

## Choose your starting point

**I want to log my own time**

- Start with [Add Time Dialog](/cms_trial/space/7TFA/1253539966/Add+Time+Dialog/)
- Then explore [Monthly view](/cms_trial/space/7TFA/1253540070/Monthly+view/), [Weekly view](/cms_trial/space/7TFA/1547173906/Weekly+view/), or [Timesheet](/cms_trial/space/7TFA/1253540328/Timesheet/)

**I want to review or manage worklogs**

- Go to [Times Explorer](/cms_trial/space/7TFA/1253540013/Times+Explorer/)
- Use layouts, grouping, filters, and export tools

**I manage team process**

- See [Approvals](/cms_trial/space/7TFA/1253539865/Approvals/), [Budgets](/cms_trial/space/7TFA/1253540085/Budgets/), and [Iterations](/cms_trial/space/7TFA/1253540717/Iterations/)
- Track approval, billing, and sprint progress

If you work mostly in Azure DevOps, the **Work item form** is a strong place to begin. It lets you add time, start tracking, view totals, and access budget context without leaving the work item.
