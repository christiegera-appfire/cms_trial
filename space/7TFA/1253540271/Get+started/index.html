Get started

3 min read

7pace Timetracker is a professional, full-featured time recording and management solution that seamlessly integrates with Azure DevOps (ADO) Server (on-prem) and ADO Services (cloud). 7pace Timetracker allows software teams in small to enterprise-sized companies to plan, estimate, and record time directly in ADO without leaving your environment.

After installing 7pace Timetracker (cloud) to your ADO Services account, the 7pace Timetracker menu is part of your ADO Services side menu bar. 7pace Timetracker consists of a web server interface that lets you add, edit, import, export, approve, and manage the time of individual team members and the whole team. You also have the option to download either the Windows or Mac app. These apps can be installed on your local system, allowing you to select a work item and then track time spent on that particular work item using a stopwatch-style interface.

The ability to track time without associating it with specific work items is on by default, allowing users to track time on non-work-related or impromptu items. You can change this within the Settings page of 7pace Timetracker > Rules -> Tracking Details.

The web app is available in ADO, allowing you to track any work item without additional action. You can use multiple desktops, run the Windows or Mac app everywhere, or just open your browser; you'll see a synced time interface that you can control from wherever you are.

7pace Timetracker has its own permission and subscription management, is fully customizable, and will work with even the most complex work item template (WIT).

📧 Email notifications

If you leave your desk and forget to turn off time tracking, 7pace Timetracker can be configured to send an email notification when the system stops tracking due to inactivity. All users can set up their personal preferences for email notifications within the Settings page.

For more information, please see the Time Tracking article in our user documentation.

⚙️ App API

Our App API is now fully documented and available to the public. You can develop an app or connect 7pace Timetracker to existing automation in your IT landscape.

For more information, check the 7pace Timetracker API Reference.

🤖 Work item automation in 7pace Timetracker

When you click Work Item Automation within 7pace Timetracker's Settings page, you can control the integration of 7pace Timetracker with ADO's time management capabilities.

For more information, please see Work Item Automation: 7pace Timetracker.
