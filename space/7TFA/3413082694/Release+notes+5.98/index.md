# Release notes 5.98

**Release date**: July 1, 2026

This page describes the latest release of 7pace Timetracker for Azure DevOps.

---

## Changes

Starting July 1, 2026, we are updating pricing for 7pace Timetracker for Azure DevOps across Start, Team, and Ultimate plans, with existing customers receiving a 30-day grace period before changes apply. Current subscriptions will retain their billing cycle, renewal date, user tier, and subscription details unless customers choose to change them. For full details, see the [2026 pricing change page](/cms_trial/space/7TFA/3356622864/7pace+Timetracker+for+Azure+DevOps+Pricing+Changes+Effective+July+1%2C+2026/).

## New Features

We’re introducing an update that allows administrator users in selected organizations to manage user permissions without needing membership in the Project Administrator Collection.
