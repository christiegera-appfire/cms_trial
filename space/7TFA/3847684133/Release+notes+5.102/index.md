# Release notes 5.102

**Release date**: November 20, 2026

This page describes the latest release of 7pace Timetracker for Azure DevOps.

---

### Improvements

- Aligned Entra authorization with Microsoft recommendations.
- Expanding recommended approach by microsoft, to not forward tokens acquired on frontend to our backend and use server side Entra OBO flow instead.

### Bugs

- Fixed a potential XSS vulnerability and added an extra validation check to secure the client pairing process with the desktop app.
