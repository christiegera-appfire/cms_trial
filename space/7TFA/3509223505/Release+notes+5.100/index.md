# Release notes 5.100

**Release date**: August 4, 2026

This page describes the latest release of 7pace Timetracker for Azure DevOps.

## Improvements

- **Reduced "Rate Us" survey frequency**  
  The in-app "Rate Us" survey now appears once a year instead of quarterly, reducing interruptions for users.

## Bug Fixes

- **Fixed runtime errors when duplicating worklogs in weekly view**  
  Resolved unexpected errors that could occur when duplicating worklogs in the weekly view.
- **Fixed email notification links for projects with spaces in their name**  
  Email notification links now correctly handle project names that contain spaces, ensuring users are directed to the right location.

Fixed notifications to be sent out from the 7pace SendGrid account.
