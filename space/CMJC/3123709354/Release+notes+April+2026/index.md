# Release notes April 2026

**Release date**: April 14, 2026

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

## Support for outgoing email template settings

Configuration Manager for Jira Cloud now supports moving and updating outgoing email template settings for service management projects during deployment.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed a bug that caused migration to fail when the Jira API returned a null project type, now showing a clear message in the UI when a project has an empty type.
- Fixed a bug that caused custom field context updates to fail with an error when certain options were missing from the context.
- Fixed a bug that caused deployments to fail with an error when a deployed project’s keyis already used by an archived project on the destination Jira site.
