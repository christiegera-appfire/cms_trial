# Release notes December 2025

**Release date**: December 11, 2025

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

## Support for JQL queries

Configuration Manager for Jira Cloud now supports moving and updating JQL queries in *filters, quick filters, swimlanes, card color strategies, SLA goals,* and *service desk queues.*

---

## Bug fixes

The following bugs are fixed in this release:

## User transformations

Fixed a bug that occurred when trying to remap the email of a source user to that of an unmatched destination user.

## Project types

Fixed a bug that allowed you to remap a project of one type to a project of another type (e.g. mapping a *Software* project to a *Service Management* project). Now, you’ll get an error that states that CMJ cannot change the project’s type.

## Goals and locked fields

Fixed a problem that occurred when trying to deploy the Goals field, which is a locked Jira field. Now, when analyzing the destination instance data, if there’s no match found for the Goals field, you’ll get an error.
