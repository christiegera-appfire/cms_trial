# Release notes September 2026

**Release date**: September 9, 2026

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## New features

## Scheduled snapshots

You can now schedule recurring snapshots of your Jira configuration to automatically capture changes over time. Choose from daily, weekly, biweekly, or monthly schedules to keep an up-to-date record of your configuration without creating snapshots manually.

[Learn more about scheduled snapshots](/cms_trial/space/CMJC/2506522887/Create+and+manage+snapshots/)

---

## Enhancements

## Onboarding checklist

New CMJ Cloud admins can now use the **Get started** widget to complete the key setup steps, including authorizing an API token, creating their first snapshot, and deploying it.

## JSM Knowledge Base support for Server-to-Cloud migrations

CMJ Cloud now supports migrating Jira Service Management Knowledge Base configuration as part of Cloud-to-Cloud, and now, Server-to-Cloud migrations.

## Support for JSM language translations

CMJ Cloud now supports migrating JSM language settings, including portal and request type translations, notification templates, and customer notification translations.

## Improved admin permission checks

CMJ Cloud now supports permission checks for Atlassian’s centralized user management, in addition to classic site administrator roles.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed issues that could prevent field scheme changes from being deployed.
- Fixed an issue where internal system and app users appeared in Analyze Changes during cloud-to-cloud deployments.
- Fixed an issue that prevented new People custom fields from being created because they were incorrectly treated as locked fields.
- Fixed several UI issues in the onboarding and Settings pages, including incorrect links, layout problems on smaller screens, a missing Appfire icon, and outdated Get Started content.
- Fixed an issue where the Next button in the migration wizard overlapped the Rovo icon.
