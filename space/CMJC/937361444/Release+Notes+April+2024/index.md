# Release Notes April 2024

**Release date**: April 30, 2024

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

We’ve made improvements allowing Configuration Manager Manager for Jira (CMJ) Cloud to update destination workflows. Also, the app can now deploy issue layouts between Jira Cloud sites.

## Update of workflows

Now, CMJ Cloud can update destination workflows during deployment. This allows adding, deleting, or updating statuses, transitions, and rules of existing destination workflows. Also, an error appears if the deployment attempts to update a read-only workflow or delete the status of an active workflow. These errors stop the deployment in the analysis phase. This way, you can resolve the problems before deploying the configuration.

## Support for issue layouts

Cloud Migration Tool can now migrate issue layouts between Jira Cloud sites.
