# Release notes 25 August 2025

**Release date**: August 25, 2025

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

## Support for default request types

Configuration Manager for Jira Cloud now supports moving and updating default request types in JSM projects when the feature is enabled.

## Support for adding or removing fields from field configurations

Configuration Manager for Jira Cloud now supports adding or removing fields from field configurations included in your deployment.

---

## Bug fixes

The following bugs are fixed in this release:

## Status fields

Fixed a bug that caused a “*Failed to acquire lock*” error when trying to update a Status field during a deployment.

## Agile boards

Fixed a bug that allowed you to remap an agile board to another one with a private filter. Now, after such a remap occurs, you will get an error message asking you to remap to a valid agile board.
