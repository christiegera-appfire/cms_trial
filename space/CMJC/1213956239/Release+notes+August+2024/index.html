Release notes August 2024

Release date: August 15, 2024

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

Enhancements

We’ve added new messages when migrating to a Jira Cloud site with active custom domains. Also, Configuration Manager for Jira Cloud can now migrate priority schemes.

New custom domain-related messages

We’ve added messages to CMJ Cloud that appear if you have custom domains active on your Jira Cloud site or if you try to deploy to a Jira Cloud site that has custom domains active.

Support for priority schemes

Configuration Manager for Jira Cloud can now deploy priority schemes between Jira Cloud sites.
