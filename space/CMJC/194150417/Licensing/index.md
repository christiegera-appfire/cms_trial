# Licensing

## Licenses needed to deploy project configurations between Jira Cloud sites

To deploy project configurations between two Jira Cloud sites, you need to:

- install Configuration Manager for Jira (CMJ) Cloud on both sites, and
- provide a separate license token for CMJ Cloud in each Jira Cloud site.

Appfire will provide you with these tokens upon purchase. Check the deployment scenario's [prerequisites](/cms_trial/space/CMJC/193659801/Prerequisites/) and [installation](/cms_trial/space/CMJC/194183182/Installation+guide/) instructions to learn more.

## Licenses needed to migrate projects from Jira Server/DC to Jira Cloud

To migrate your projects and issues from Jira Server/DC to Jira Cloud, you need to use two apps:

- the [Cloud Migration Tool](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=CMT&title=Installation%20and%20upgrade) app, and
- the [Configuration Manager for Jira (CMJ) Cloud](/cms_trial/space/CMJC/194183182/Installation+guide/) app.

Cloud Migration Tool is **free** to use on your source Jira Server/DC instance, but you must install and **pay** for CMJ Cloud on your Jira Cloud site. You'll need a **separate license token** for each destination Jira Cloud site where you want to migrate your projects and issues.

In summary:

- **Cloud Migration Tool is a free app**. You don't need a license after installation.
- **CMJ Cloud is a licensed app.** You need to have a separate license token for each Jira Cloud site where you plan to install and use it.
