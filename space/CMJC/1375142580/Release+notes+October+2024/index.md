# Release notes October 2024

**Release date**: October 17, 2024

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

We’ve added custom domain support and new event creation messages to Configuration Manager for Jira Cloud.

## Full custom domain support

Exciting news! Configuration Manager for Jira (CMJ) Cloud now fully supports custom domains. When deploying, you can now use whichever instance link you want.

## New custom event creation messages

We’ve added messages to CMJ Cloud that appear when you try to deploy custom events. Custom event creation is not yet supported. Currently, they can only be referenced if they already exist on the destination Jira instance.
