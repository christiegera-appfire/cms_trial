# Release notes March 2025

**Release date**: March 11, 2025

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

## New and improved Analyze phase UI

We’ve redesigned the Analyze phase UI to provide a high level of detail on what will change after deployment, helping you to better understand and manage modifications. The entire deployment scope is now displayed in a card view, making it easier to navigate and review changes.

![NEWAnalyzePhaseScreen.png](/cms_trial/assets/9f28b6e7-c4aa-4aa6-b197-78ee9fa050fd.png)

Clicking any of those cards will direct you to the *Detailed Analysis Info Screen,* where you’ll see a tree view with dropdowns on the left and all the object’s info on the right. Additionally, the new interface introduces inline transformations, allowing you to make quick adjustments directly in the UI—previously only possible through a JSON file.

![NEWViewAllScreen.png](/cms_trial/assets/a99e4720-e7b9-418b-bcac-722ad1d78b65.png)

These improvements enhance visibility, streamline conflict resolution, and provide a more efficient change management experience.

[Read more about the new Analyze phase](/cms_trial/space/CMJC/193626781/Analyze+changes/)

## Bug fixes

The following bugs are fixed in this release:

## Missing objects from downloaded JSON file

Fixed a problem with downloaded JSON files for custom mapping where they didn’t include the **Resolution** and **Project role** objects.

## Custom field context deletion

Fixed a bug that was wrongly marking some custom field contexts for deletion during deployment.
