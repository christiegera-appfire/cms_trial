# Release notes July 2026

**Release date**: July 1, 2026

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## New features

### Snapshot comparison

Configuration Manager for Jira Cloud now lets you compare different versions of the same snapshot to quickly identify configuration changes over time.

The comparison view categorizes configuration elements as **Unique to source snapshot**, **Unique to destination snapshot**, **Identical**, or **Different**, making it easy to review additions, removals, and modifications. You can also inspect the details of each configuration element and compare the differences between snapshot versions.

[Read more about snapshot comparisons](https://support.appfire.com/space/CMJC/3417473252/Compare+snapshots)

---

## Enhancements

## Granular scope selection

CMJ Cloud’s snapshot creator now offers two scope options to better fit your use case.

Choose **Everything supported** to create a system snapshot containing all currently supported projects and configuration elements, or select **Specific elements** to build a custom snapshot by choosing only the projects and configuration elements you need. CMJ automatically detects and includes any required dependencies, helping ensure your deployed configurations work as expected.

[Read more about granular scope selection](https://support.appfire.com/space/CMJC/2506522887/Create+and+manage+snapshots)

---

## Bug fixes

### Permission scheme updates

Fixed a bug where updating a permission scheme could remove valid role-based permissions if an invalid project role was encountered during a bulk permission update.
