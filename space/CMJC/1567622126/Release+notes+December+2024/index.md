# Release notes December 2024

**Release date**: December 19, 2024

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

We’ve added new support for approval steps in workflow statuses and enhanced messages when migrating issue links with Configuration Manager for Jira Cloud.

## Support for approval steps in workflows

Configuration Manager for Jira Cloud now supports moving and updating approval steps in workflow statuses.

## New issue linking messages

We’ve added messages to Configuration Manager for Jira Cloud that appear when you try to deploy issue links to a destination instance that doesn’t have them enabled yet. The message you see now will remind users to enable the option on the destination instance if they want to deploy issue links.

---

## Bug fixes

The following bugs were fixed in this release:

## Custom field dependency

Fixed a bug that prevented certain custom fields from being updated during a deployment due to an issue with a security scheme dependency.

## Matching asset objects

Fixed a problem that was causing asset object custom fields to not get properly matched during a deployment.
