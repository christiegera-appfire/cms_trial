## Migrate projects and issues from Jira Server to Jira Cloud

### Jira Server-to-Cloud migrations

You can combine this app with the free [Configuration Manager Cloud Migration Tool](https://appfire.atlassian.net/wiki/spaces/CMT) to enable migrations of configurations and data from Jira Server to Jira Cloud.

Install the **Cloud Migration Tool** on your source Jira Server instance and **Configuration Manager for Jira Cloud** on your destination Jira Cloud site.

After installing the apps, use the Cloud Migration Tool’s friendly UI to create a connection to your Jira Cloud site and migrate your teams’ projects, workflows, custom fields, issues, including history, comments, attachments, links, and many more configuration elements there.

[Visit documentation](https://appfire.atlassian.net/wiki/spaces/CMT)

### Supported configuration elements

The Cloud Migration Tool and Configuration Manager for Jira apps currently support migration of Jira Core projects. Migration of Jira Software projects is supported with the exception of Agile boards and sprint data. Service Management is not yet supported.

See the [complete list](https://appfire.atlassian.net/wiki/spaces/CMT/pages/197856608) of configuration elements we’re able to migrate currently.

### Licensing

Cloud Migration Tool is a free app, and you don’t need a license to use it, but you need an active license for Configuration Manager for Jira after installing it on the destination cloud. For more information, please check out our [installation](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=CMT&title=Installation%20and%20upgrade)and [licensing](/cms_trial/space/CMJC/194150417/Licensing/) guides.
