## Get started in three steps

Once you’re ready to use CMJ Cloud, the basic process is simple: authorize the app, capture the configuration you want to move in a snapshot, and deploy that snapshot to another Jira site.

### 1. Authorize the app

Before you can start using CMJ Cloud, authorize the app to access your Jira site. You’ll need an Atlassian API token to complete the authorization.

[Learn how to authorize CMJ Cloud](/cms_trial/space/CMJC/193594026/Authorize+with+API+token/)

### 2. Create a snapshot

Create a snapshot to capture your project configuration at a specific point in time. The snapshot packages the configuration so you can save it or deploy it to another Jira site.

[Learn how to create a snapshot with CMJ Cloud](/cms_trial/space/CMJC/2506522887/Create+and+manage+snapshots/)

### 3. Deploy the snapshot

When you’re ready to move the configuration, deploy the snapshot to your target Jira site. This could be another environment, such as a sandbox or production site.

[Learn how to deploy a snapshot with CMJ Cloud](/cms_trial/space/CMJC/2507112493/Deploy+a+snapshot/)
