# Release notes 24 July 2024

**Release date**: July 24, 2024

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## New features

## Migrate Service Management Projects from Cloud to Cloud

Exciting news! Configuration Manager for Jira (CMJ) Cloud now ensures a smooth migration of your Jira Service Management (JSM) projects. You can now effortlessly migrate **request types**, **organizations**, **portal groups**, **SLAs**, **queues**, and **calendars** from one cloud to another. To transition a JSM project, CMJ Cloud will either create a new project at the destination site or merge it with an existing project there.

Future updates will support additional configurations, further enhancing your ability to manage service management projects seamlessly.

[Learn more about current JSM project migration and future plans for adding more configuration support](/cms_trial/space/CMJC/1160020327/Migrate+Service+Management+projects+to+the+Cloud/)

---

## Enhancements

## Improved migration error messaging

We’ve improved the error messaging for migration failures caused by user accounts already existing on the Cloud. Now, the error message not only lists the users not created on the destination Jira site but also provides additional details, including the possibility that the user account being migrated is suspended. This improvement ensures that admins are better informed about the reasons for migration failures.
