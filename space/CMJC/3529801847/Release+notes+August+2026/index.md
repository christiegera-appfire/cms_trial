# Release notes August 2026

**Release date**: August 6, 2026

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

### New Getting Started page

CMJ Cloud now welcomes new users with a dedicated Getting Started page. The page provides quick actions and popular use cases to help users get started with the app.

### Support for Knowledge Base links

CMJ Cloud now supports migrating Knowledge Base link configurations in cloud-to-cloud deployments. Knowledge Base links can now be successfully transferred between Jira Cloud sites within the same organization.

### Updated CMJ Cloud interface

We have refreshed parts of the CMJ Cloud interface to improve clarity and usability. Several options have been renamed, and their appearance has been updated, while their existing functionality remains unchanged.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue that could prevent deployment files from being shared with the support team when a deployment failed.
- Fixed an issue that allowed unsupported characters to be entered in the Label field when creating a snapshot.
- Fixed a bug that caused JSM deployments to fail when updating existing destination projects that were created before CMJ Cloud was installed.
- Fixed a bug that could cause migrations to fail when updating multiple priority schemes during deployment.
- Fixed a problem that caused deployments to fail when the maximum number of custom field options was exceeded. The limit is now reported during analysis instead.
- Fixed a problem that caused deployments to fail when encountering locked fields that can’t be recreated on the destination instance. The issue is now reported during analysis instead.
