# Release notes January 2025

**Release date**: January 16, 2025

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

## Support for Premium Jira Service Management (JSM) queues

Configuration Manager for Jira Cloud now supports moving and updating JSM queues in Premium Jira instances.

---

## Bug fixes

The following bugs were fixed in this release:

## Advanced IT service management projects

Fixed a bug that prevented us from deploying **Advanced IT service management** type of JSM projects.

## JSM Forms

Fixed a problem that caused the deployment to stop when it contained a form with a specific set of settings selected. Additionally, we fixed an issue where forms were not migrated if the project they were in had a project key with more than 10 characters.

## JSM Queue name duplicates

Fixed a bug that broke deployments if they contained multiple Premium JSM queues with the same name and a different work category.
