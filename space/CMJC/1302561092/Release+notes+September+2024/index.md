# Release notes September 2024

**Release date**: September 19, 2024

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

## New custom event messages

We’ve added new messages that appear if you try to deploy a custom event that’s not already present on the destination Jira instance. This way, we reduce the chances of a deployment failure.

## Support for satisfaction survey settings

Configuration Manager for Jira Cloud can now deploy satisfaction survey settings between Jira Cloud sites.

## Support for JSM portal settings

Configuration Manager for Jira Cloud can now deploy JSM portal settings between Jira Cloud sites.

## Support for JSM work categories

Configuration Manager for Jira Cloud can now deploy JSM work categories between Jira Cloud sites.

---

## Bug fixes

The following bugs were fixed in this release:

## App users

We've addressed a problem that was causing app users (the system-generated users created by your apps to perform specific actions) to appear in the analysis report.

## Issue type creation

We’ve fixed an issue that was causing failures when creating issue types during a deployment.

## Fetching request types and organizations

We’ve fixed a bug that was appearing when trying to fetch too many request types or organizations.

## Too many requests

We’ve addressed an issue that was occurring when too many requests were made to the Jira instance.

## Project component creation

We’ve fixed a bug that caused failures when creating certain project components on the destination instance during deployment.

## Project version

We’ve fixed a bug that was causing Configuration Manager for Jira Cloud to fetch the wrong project version during a migration, thus failing the migration process.
