# Release notes June 2026

**Release date**: June 18, 2026

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

## Support for field schemes

CMJ Cloud now supports Jira Cloud's new Field Scheme model. As Atlassian replaces legacy Field Layout Schemes and Field Layouts with a unified configuration structure, CMJ Cloud automatically handles the conversion during snapshot deployments, ensuring a seamless transition and continued compatibility with your existing configuration management processes.

[For more info, check out our KB article.](https://support.appfire.com/space/SUPPORT/3216478849/KB:+Understanding+the+Migration+from+Field+Layout+Schemes+to+Field+Schemes)

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed a bug that allowed deployments to proceed when CMJ Cloud was not installed on the destination Jira Cloud instance.
- Fixed a problem when deploying configurations containing Assets object fields to instances where Assets was not enabled.
- Fixed an issue that caused custom field context updates to fail when referenced field options were missing from the context.
