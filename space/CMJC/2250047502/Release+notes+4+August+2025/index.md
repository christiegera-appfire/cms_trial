# Release notes 4 August 2025

**Release date**: August 4, 2025

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

## Support for default issue schemes

Configuration Manager for Jira Cloud now supports moving and updating default issue schemes.

## Support for user share permissions for filters

Configuration Manager for Jira Cloud now supports moving and updating user share permissions for filters.

---

## Bug fixes

The following bugs are fixed in this release:

## Custom field creation

Fixed a bug that caused a migration failure because CMJC couldn’t fetch a newly created custom field due to Jira API issues.

## Service desk projects

Fixed an inconsistency that was showing service desk projects as available for deployment even when the Jira instance didn’t have a valid service desk license applied.

## Bulk transformations

Fixed a problem that was causing CMJC to reject files larger than 1MB when uploading a JSON file for bulk transformations.
