# Help and support

## Find help using Configuration Manager for Jira Cloud

This document informs you about the different channels to get help with the Configuration Manager for Jira Cloud-related questions, requests, and issues.

![contentId-258053546](/cms_trial/assets/4946923f-f907-41f6-a066-675edb16a3c2.png)

## Where to start

If you encounter any problems using or setting up **Configuration Manager for Jira (CMJ) Cloud**, please let us know — we're here to help!

- First, look for information in CMJ Cloud’s [documentation](/cms_trial/space/CMJC/193823429/Features+and+options/).
- If you need assistance, raise a support request at our [Support Portal](https://appf.re/support).

## Raise a support request

To raise a support request:

1. Visit Appfire’s [Support Portal](https://appf.re/support) and raise a support request with the **deployment ID** (error messages that appear in CMJ Cloud’s UI contain the ID).
2. Provide as much information as possible, and add screenshots if there’s an error in Jira’s UI.
