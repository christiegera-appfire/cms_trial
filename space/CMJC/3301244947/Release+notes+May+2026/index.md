# Release notes May 2026

**Release date**: May 29, 2026

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

## Support for sender name and attachment security settings

CMJ Cloud now supports migrating sender name and attachment security settings during cloud-to-cloud (C2C) migrations.

## Support for Service Desk request type restriction permissions

CMJ Cloud now supports migrating Service Desk request type restriction permissions during cloud-to-cloud (C2C) migrations.

## Support for Number custom field formatting

CMJ Cloud now supports migrating Number custom field formatting configurations. Format settings such as Number, Percentage, and Currency are deployed together with your Number custom fields.

## Added the ability to cancel long-running operations

CMJ Cloud now allows users to cancel long-running operations. This helps prevent unnecessary wait times and provides greater control when tasks are started by mistake or no longer need to be completed.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue that occurs when you have field schemes with more than 700 fields. CMJ Cloud now detects and throws an error to prevent deployment failures.
- Fixed an issue that occurs when you have custom field contexts with more than 10 groups. CMJ Cloud now detects and throws an error to prevent deployment failures.
