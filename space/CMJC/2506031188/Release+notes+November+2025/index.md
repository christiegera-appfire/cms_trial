## New features

## Snapshots have arrived at CMJ Cloud

A configuration snapshot is a structured file containing data of a Jira configuration. It is called a snapshot because, just like with a Polaroid camera, you “take a photo” of all your Jira settings and configurations at this specific moment in time.

CMJ Cloud now contains snapshot features, and the best part is that all data in the snapshot is instance-independent. This means that you can easily transfer and import the information it contains to another Jira Cloud instance.

[Read more about snapshots in CMJ Cloud](https://appfire.atlassian.net/wiki/spaces/DCMFJC/pages/2396029075/Create+and+manage+snapshots?atlOrigin=eyJpIjoiYmU3MGFlOWFiN2E1NDQ0NTk2ZDExZDY3MTBkOTU0NGMiLCJwIjoiYyJ9)
