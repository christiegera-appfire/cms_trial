# Release notes 17 July 2024

**Release date**: July 17, 2024

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

We’ve improved the mapping capabilities of Configuration Manager for Jira Cloud.

## Status mapping

With this improvement, during a deployment, CMJ Cloud looks for statuses scheduled for deletion from active workflows. If such statuses are found, we have a mapping process that allows you to select alternative statuses mid-deployment.

[Learn more about the status mapping feature](https://appfire.atlassian.net/wiki/spaces/DCMFJC/pages/1076986051/DRAFT+Status+mapping)
