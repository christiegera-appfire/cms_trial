# Release notes October 2025

**Release date**: October 2, 2025

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

## Mapping and reverting changes

Fixed a bug with mapping and reverting changes during the *Analyze* phase of the deployment.

## Deactivated users

Fixed an issue that caused the wrong change to be applied when adding an email to a deactivated user in the *Detailed analysis* *info* screen.

## Missing user emails

Fixed a bug that occurred when re-mapping users during a deployment, which showed that their emails were missing or invalid even after a re-map to a valid destination user.

## Locked custom fields

Fixed an issue that caused deployments to fail when trying to add a locked custom field from another Jira plug-in. Now, you’ll get an error before the deployment begins, telling you to install that plug-in on the destination Jira Cloud instance before deploying.

## Wrong error message

Fixed a bug that caused the wrong error message to appear when your API token expired.

## Duplicate issue types

Fixed a problem that occurred when issue type schemes with duplicate issue types within them were deployed.
