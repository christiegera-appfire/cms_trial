# Migrate projects and issues from Jira Server/DC to Jira Cloud

## Migrate from Jira Server/Data Center to Jira Cloud

![contentId-258085727](/cms_trial/assets/de42668b-3690-4c07-b900-fc2d69f18bc3.png)

Moving projects and issues from Jira Server to Jira Cloud is one of the most demanded and complex administrative tasks in Jira right now. Configuration Manager Cloud Migration Tool **paired with Configuration Manager for Jira Cloud**solves this challenge for you.

These apps working together allow you to transfer your projects and issues from Jira Server or Data Center instances to Jira Cloud sites. The apps detect and report configuration conflicts and errors that block your migration. They also suggest and offer actions to resolve problems and optimize configurations.

Visit the document below to learn how to migrate your Jira Server/Data Center projects and issues to Jira Cloud.
