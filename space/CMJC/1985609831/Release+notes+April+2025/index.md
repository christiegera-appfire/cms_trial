# Release notes April 2025

**Release date**: April 28, 2025

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

## Support for hierarchy levels

Configuration Manager for Jira Cloud now supports moving and updating issue types with set up hierarchy level properties. For now, CMJ Cloud can only deploy issue types with a hierarchy level of -1 and 0. Any issue types with a hierarchy level above that must be created manually on the destination Jira instance before deployment.

---

## Bug fixes

The following bugs are fixed in this release:

## JSM request type deployment

Fixed a bug that was causing additional default request types to be created during a JSM project deployment.

## Workflow mapping

Fixed a bug that was forcing workflows renamed during the Analyze phase to need status mapping even when no conflicts were found after the rename.
