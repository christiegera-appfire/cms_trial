# Use Cases

## Introduction

Configuration Manager for Jira (CMJ) Cloud supports a wide range of use cases for safely managing and transferring Jira configurations across environments.

Whether you're deploying configuration changes between Jira Cloud sites, migrating from Jira Server or Data Center, or maintaining consistency across multiple environments, CMJ Cloud provides the tools needed to analyze, validate, and execute changes with confidence.

Explore the use cases below to understand how CMJ Cloud can support your specific scenario.

- [**Deploy Configuration Changes from Jira Cloud to Cloud**](/cms_trial/space/CMJC/258053021/Deploy+configuration+changes+from+Jira+Cloud+to+Cloud/)
