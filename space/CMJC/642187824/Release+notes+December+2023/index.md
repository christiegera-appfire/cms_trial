## Sharing deployment data with Appfire’s support team

When support representatives from Appfire get in touch with you, you can now swiftly share deployment data with them. The purpose of this feature is to expedite the resolution of your issues. At every deployment stage, you have the option to turn data sharing on.

The choices for deployment data sharing include:

- Sharing your source Jira Cloud site configuration
- Sharing the transformations you applied to the configuration before running the migration
- Sharing configuration from the destination Jira Cloud site

[For more information and instructions, visit the documentation.](/cms_trial/space/CMJC/642220408/Share+deployment+data+with+the+support+team/)
