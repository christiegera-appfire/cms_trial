# Release notes November 2024

**Release date**: November 25, 2024

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

We’ve added support for customer notifications and forms to Configuration Manager for Jira Cloud.

## Team type migration

Jira Service Management (JSM) projects now have a field called **Team type** in the *Details* section of the *Project settings* menu. Configuration Manager for Jira (CMJ) Cloud now also transfers this field when deploying between Jira Cloud sites.

## Support for JSM customer notifications

Configuration Manager for Jira (CMJ) Cloud now supports enabling and disabling of all customer notifications. You can now freely deploy them between Jira Cloud sites.

## Support for JSM forms

Configuration Manager for Jira (CMJ) Cloud can now deploy forms between Jira Cloud sites.

---

## Bug fixes

The following bugs were fixed in this release:

## Task and Sub-task heirarchy

Fixed a bug that was causing sub-tasks to appear on the same hierarchy level as normal tasks after a deployment.

## Multi-user picker deployment

Addressed a problem that was preventing us from deploying multi-user pickers.

## Missing icon

Addressed an issue that was causing request types to not be created properly during migration due to a missing icon.

## Deployment of request types

Fixed a problem that caused request types to not be properly read and compared to their target counterparts during a deployment.
