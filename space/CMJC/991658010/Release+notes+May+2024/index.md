# Release notes May 2024

**Release date**: May 21, 2024

Our team is thrilled to announce the latest release of Configuration Manager for Jira (CMJ) Cloud.

---

## Enhancements

We’ve improved Configuration Manager for Jira Cloud’s progress reporting and security capabilities.

## Better progress reporting

We've enhanced our progress reporting during the analysis phase to provide more real-time insights, allowing you to monitor your migrations better.

## Security improvements

We've implemented security enhancements to ensure the continued safety and protection of your migrations and users.

---

## Bug fixes

The following bug was fixed in this release:

### Problem with deploying users

Previously, due to changes in Jira Cloud, new users could not be added to the destination site during deployment. This issue has been resolved, and users are now added successfully. However, these users will not automatically have access to Jira products (such as Jira Software, Work, or Service Management). You must manually assign each user to the appropriate Jira groups to manage access and Jira Cloud licensing effectively.
