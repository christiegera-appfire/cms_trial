# Features and options

## Cloud-to-cloud deployments

**Configuration Manager for Jira (CMJ) Cloud** allows you to:

- deploy entire project configurations from one Jira Cloud site to another, and
- apply changes from a Jira Cloud site to project configurations in another Jira Cloud site.

In this section, you'll find guides on deploying project configuration between Jira Cloud sites using CMJ Cloud and more information on the app's features.
