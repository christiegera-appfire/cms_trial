# Planning Poker game

A **Planning Poker game** is a collaborative estimation session where your team estimates the effort or complexity of work items using a shared card deck (Fibonacci, T-shirt sizes, S/M/L, or custom values). Participants vote privately, then reveal and discuss until the team reaches an estimate.

## Roles

- **Moderator** — controls the session: starts and flips rounds, resets votes, and submits the final estimate to Azure DevOps.
- **Estimator** — votes on work items using the configured card deck.
- **Spectator** — observes the session without voting. Typically Product Owners or stakeholders who want visibility without influencing the estimate.

## Game lifecycle

A typical Planning Poker game follows these steps:

1. Create a game.
2. Configure the session.
3. Invite participants.
4. Estimate work items.
5. Submit the agreed estimate.
