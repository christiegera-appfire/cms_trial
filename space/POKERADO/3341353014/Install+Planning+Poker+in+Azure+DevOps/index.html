Install Planning Poker in Azure DevOps

2 min read

Use this guide to install the Planning Poker extension from the Azure DevOps Marketplace into your organization. This is a standard marketplace installation flow for Azure DevOps extensions and is intended for organization administrators or users with permission to manage extensions.

Planning Poker for Azure DevOps provides a native estimation experience inside Azure DevOps, including interactive estimation sessions, async estimation, and estimation directly from work item views.

Before you begin

  • You need access to the target Azure DevOps organization.

  • You need permission to install extensions for that organization. In many environments, this requires organization admin rights.

  • Have the marketplace listing ready if you want to navigate directly to the app.

If your company restricts marketplace installs, you may need approval from your Azure DevOps administrator, procurement team, or security team before completing the installation.

Install from the Marketplace

  1. Open the Azure DevOps Marketplace.
    Go to the Marketplace and search for Planning Poker.

  2. Open the Planning Poker listing.
    Review the app overview, publisher details, permissions, and pricing or trial information shown on the listing page.

  3. Select Get it free or the current install action.
    The exact button label can vary depending on listing status, licensing model, or whether a trial is offered.

  4. Choose your Azure DevOps organization.
    If you belong to multiple organizations, select the one where you want Planning Poker installed.

  5. Confirm the installation.
    Review the requested access and proceed with the standard extension installation flow.

  6. Wait for the installation to complete.
    Once finished, Azure DevOps will confirm that the extension has been added to the selected organization.

Best practice: install the extension first in a test or sandbox Azure DevOps organization if your team uses a controlled rollout process.

Verify the installation

After installation, confirm that the extension is available in the organization.

  • Open Organization settings in Azure DevOps.

  • Go to the installed extensions area.

  • Confirm that Planning Poker appears in the list of installed extensions.

  • Open Azure Boards and check whether Planning Poker entry points are available where your team expects to estimate work.

Depending on your Azure DevOps setup and the app configuration, users may see Planning Poker features in places such as:

  • Work item details

  • Backlog or sprint-related estimation flows

  • Query-based or selected-work-item estimation flows

If the extension is visible in the installed extensions list and its UI appears in Azure DevOps, the installation was successful.

Troubleshooting

  • The install button is unavailable: you may not have permission to install extensions for the organization.

  • The organization is not listed: verify that you are signed in with the correct account and have access to the target Azure DevOps organization.

  • The extension installs but is not visible to users: refresh Azure DevOps, confirm installation under organization settings, and verify that users are accessing supported Azure DevOps areas.

  • Security review is required: review the marketplace listing and your internal approval process before installation.
