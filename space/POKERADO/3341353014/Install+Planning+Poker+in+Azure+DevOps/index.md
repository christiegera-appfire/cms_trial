# Install Planning Poker in Azure DevOps

**Estimated time:** About 3 minutes

Install the Planning Poker extension from the Azure DevOps Marketplace into your organization. This is a standard marketplace installation flow for Azure DevOps extensions and is intended for organization administrators or users with permission to manage extensions.

## Before you begin

Make sure you have:

- Access to the target **Azure DevOps organization**.
- Permission to **install extensions** for that organization. In many environments, this requires organization admin rights.
- The [marketplace listing](https://marketplace.visualstudio.com/items?itemName=SpartezSoftware.planning-poker-azure) if you want to navigate directly to the app.

If your company restricts marketplace installs, request approval from your Azure DevOps administrator, procurement team, or security team before completing the installation. See [Requested permissions](/cms_trial/space/POKERADO/660308966/Requested+permissions/) for a breakdown of exactly what each requested permission is used for.

## Install from the Marketplace

1. 1

   Open the **Azure DevOps Marketplace.** Go to the Marketplace and search for **Planning Poker**.
2. 2

   Open the Planning Poker listing. Review the app overview, publisher details, permissions, and pricing or trial information.
3. 3

   Select **Get it free** or the current install action. The exact label can vary by listing status, licensing model, or trial availability.
4. 4

   Choose your Azure DevOps organization. If you belong to multiple organizations, select the one where you want Planning Poker installed.
5. 5

   Confirm the installation. Review the requested access and proceed with the standard extension installation flow.
6. 6

   Wait for the installation to complete. Azure DevOps will confirm the extension has been added to the selected organization.

**Pro-tip!**

If your team uses a controlled rollout process, install the extension in a test or sandbox Azure DevOps organization first.

## Verify the installation

1. 1

   Open **Organization settings** in Azure DevOps.
2. 2

   Go to the installed extensions area.
3. 3

   Confirm that **Planning Poker** appears in the list of installed extensions.
4. 4

   Open Azure Boards and check whether Planning Poker entry points are available where your team expects to estimate work: work item details, backlog or sprint estimation flows, and query-based or selected-work-item flows.

The installation is complete when:

- Planning Poker appears in your organization's installed extensions.
- The extension is available in Azure DevOps.
- You can access the Planning Poker interface.

## Troubleshooting

The install button is unavailable.

You may not have permission to install extensions for the organization.

The organization is not listed.

Verify that you are signed in with the correct account and have access to the target Azure DevOps organization.

The extension installs but is not visible to users.

Refresh Azure DevOps, confirm installation under organization settings, and verify that users are accessing supported Azure DevOps areas.

Security review is required.

Review the marketplace listing and your internal approval process before installation. See [Requested permissions](/cms_trial/space/POKERADO/660308966/Requested+permissions/) for the specific permissions this app requests and why.
