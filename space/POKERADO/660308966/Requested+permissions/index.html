Requested permissions

2 min read

When you install Planning Poker, Azure DevOps asks you to approve a set of permission scopes as part of the install flow. This page explains what each scope is used for and why the app requests it. Useful if your security or approvals team wants justification before signing off on the install.

  1. vso.work: This scope provides access to read work items and related information within Azure DevOps project. It allows our application to perform queries and retrieve details about work items, such as tasks, bugs, epics, and user stories.

  2. vso.work_write: This scope extends the previous one and adds the ability to modify work items within Azure DevOps. It grants our application the capability to update work items, specifically allowing for the addition or alteration of estimation values.

  3. vso.graph: The vso.graph scope grants access to Azure DevOps Graph API. This API provides information about users and group membership information. Specifically, we utilize this API to verify user membership in the organization administrators group.

  4. vso.features: This scope grants access to feature flags within the Azure extension environment. We leverage this scope to ascertain whether our application should be visible within enabled Azure extension points, such as the Work Item details or Board view.

  5. vso.features_write: Expanding upon the vso.features scope, this permission enables your application to dynamically control the visibility of our app within the specified Azure extension points.

  6. vso.memberentitlementmanagement: Allows access to retrieve user data and license information for all users within the organization. This scope is utilized within our user management interface, enabling the selection of users authorized to use our extension.

  7. vso.identity: Enables access to read user identities within the organization. This scope allows for batch queries for specific users, offering a more targeted approach compared to retrieving all users, as done with the vso.memberentitlementmanagement scope. This targeted querying capability optimizes efficiency in user-related operations within our application.

More information about scopes description can be found here: https://learn.microsoft.com/en-us/azure/devops/extend/develop/manifest?view=azure-devops#scopes
