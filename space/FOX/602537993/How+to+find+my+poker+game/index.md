# How to find my poker game

The *Priority Poker game list* screen allows you to find the game you already created, see the list of the games you can join, or inspect the games that were already finished and prioritized issues. Once you created some poker sessions, you can view, join, or invite other people to the game.

![ Go to Priority poker screen in Foxly Jira app](/cms_trial/assets/df4948d6-d8a8-4ac1-9776-abb9fbfdec46.png)

## How to find the list of active poker games

1. In the main priorities table, click **Priority poker** in the top right.
2. Inspect the *Active games* section of the page.
3. You will find the list of all active games that weren’t yet finished by the admin with the following information: **Game name**, **Issues to prioritize**, **Poker admin**, **Created at**.

![See active priority poker games in Foxly Jira app](/cms_trial/assets/65c37b80-f180-411c-b6d8-37468c2b6374.png)

## How to work with an active poker game

1. Choose one of the active games in the list.
2. If you want to participate in an active game - click **Join**.
3. If you want to let other users in - click **Invite**.
4. Click **close the game** to finish active poker session.

Make sure to have the necessary [Foxly app permissions](/cms_trial/space/FOX/602538012/Foxly+Permissions/) in order to join, invite other users, or close the game
