# Prioritize across multiple Jira projects

If you’re looking for a way to prioritize multiple Jira projects at once, you can use **Projects filters**.

**Project filters** allow you to show issues from different projects that use the same prioritization template in the Priorities table and Priority matrix.

## How to use Project filters

The Foxly *Prioritization* tab is available in the menu of every Jira project. By default, it shows issues from that project. However, you can use **Project filter** to bring issues from different projects to the same table.

1. Go to the *Priorities* tab in the project.
2. Click **Project** in the filters area.
3. Select projects.

![Foxly priorities tab with Project filter dropdown and multiple projects selected](/cms_trial/assets/c01e6f78-706d-4030-abd0-172a0b2699e8.png)

Issues from selected projects now appear in the Priorities table.

You can only filter projects that use the same prioritization template. [Read more about prioritization templates](/cms_trial/space/FOX/602538305/Change+the+prioritization+template/) and how to change them.

## How to show projects in the Priorities table

You can show the **Project** field as a column in your Prioritization table to easily identify project issues.

1. Click **Columns**.
2. Select the **Project** field in the drop-down
3. The **Project** column appears in the table.

![Foxly priorities table with Project column displayed to identify issues across projects](/cms_trial/assets/29b831f7-9dae-4426-b86e-ed76ecfae5dc.png)
