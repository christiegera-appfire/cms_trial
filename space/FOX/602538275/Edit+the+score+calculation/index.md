# Edit the score calculation

If the scoring calculation needs improvement, you can tweak the score formula or create a completely new one. You can use simple math operators such as \* - + ( ), numbers, and metrics.

## Basic formula edit

From the Project menu, navigate to the *Priorities* tab.

1. Click **Customize** in the top-right corner.

![Screenshot of the Priority matrix showing the Customize button.](/cms_trial/assets/d71052b3-4646-4be1-b07a-92faa515cfcc.png)

1. Click in the **Score formula** field and use the `Delete`key to remove the metrics or operators, and *type* to add new ones.
2. You can click metrics and operators to change them.
3. Click **Save changes** to save your new formula.

![Screenshot of the Edit template showing the Score formula field.](/cms_trial/assets/7b04b4bc-6dba-4a5e-8004-fecf674864dc.png)

## Advanced Formula edit

If you want more flexibility when editing the Scoring formula, then you can use **Advanced edit mode**.

1. In the *Edit template* modal, click **Switch to advanced mode** under the **Score formula**.
2. Type in the field to edit it.
3. Click **Save changes** to save your new formula.

Metrics in **Advanced edit mode** need to be wrapped in the braces (curly brackets). Example: {{Reach}}

![Screenshot of the Edit template showing an example formula in the the Score formula field.](/cms_trial/assets/c53a1bf2-66b3-4625-ae2f-e5b7972c9c96.png)

If you’re using the prioritization template whose formula you’re editing, then you have the option to apply changes to all projects or create a completely new template and apply changes only to the project you’re currently in.
