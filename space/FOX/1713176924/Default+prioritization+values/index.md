# Default prioritization values

Foxly admins can use the Default prioritization values feature to customize issue templates by pre-setting metric values for new issues.

When all template metrics have default values, the app automatically calculates the priority score and positions the issue within the priority table based on the score and selected sorting method.

### Key features

- **Streamlined workflow:** Pre-setting common values minimizes manual input and saves time.
- **Establishing a baseline:** Set a default average priority score, allowing adjustments as needed.
- **Prioritizing urgency:** Assign the lowest possible score upon issue creation to highlight critical tasks.

### How to set the default prioritization value

1. Click **Customize.**
2. Open a **metrics** tab**.**
3. Set **Default value.**

   - Check the box next to a specific value to set it as default for new issues.
4. Click **Save changes.**

Nowthe preset values will automatically apply when a new issue is created.

### Example use case

If you want all new issues to have the hightest priority by default:

- Set the **Default values** to the highest priority.
- Save the template.
- Create a new issue and refresh the table.
- The issue appears with the preselected priority value.
