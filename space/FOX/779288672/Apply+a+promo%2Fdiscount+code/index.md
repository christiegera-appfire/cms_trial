# Apply a promo/discount code

This article explains how to apply an Appfire promo code to your purchase.

## Apply promo/discount codes

1. Click **Apps** > **Manage your apps** > **Promotions** > **Apply promotion codes** and enter the **promo code**.

   ![The Apply promotion codes screen in Jira's Manage your apps section](/cms_trial/assets/46f36f89-b91b-4391-a144-374e682aff30.png)

When the promo code is applied successfully, the promotion will be applied to your app on that instance. For the promo code to be applied, the Foxly app must already be installed on the instance.
