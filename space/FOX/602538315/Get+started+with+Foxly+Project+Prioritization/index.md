# Get started with Foxly Project Prioritization

Foxly is a backlog prioritization app for Jira Cloud that helps managers and leads standardize how their team scores, ranks, and manages issues. Using customizable metrics and scoring formulas, Foxly gives every issue a calculated priority score — making it easier to align stakeholders and make data-driven prioritization decisions.

## Key features

- Customizable scoring formulas and prioritization metrics
- Priority Matrix for visual quadrant-based issue management
- Priority Planning Poker for collaborative team scoring
- Saved views with shareable, project-level defaults
- Prioritization history visible directly from issue details
- Support for Jira custom fields as prioritization inputs
- Async (offline) planning poker for distributed teams
- Data residency options for EU, DE, AU, and US regions

## Use case

A product team is struggling to align on which backlog items to tackle each sprint. Everyone has opinions, but there's no consistent way to compare items across different dimensions — customer impact, effort, and strategic value all matter, but they're being weighed differently by different people.

Using Foxly, the product manager creates a prioritization template with three metrics — Impact, Effort, and Confidence — and defines a weighted scoring formula. The team runs a Priority Planning Poker session to score the top 20 items together, then reviews the results in the Priority Matrix to identify which high-impact, low-effort issues should move to the top of the backlog.

The priority scores update automatically as metrics are adjusted, and the product manager saves a Default View so every team member lands on the same filtered, sorted table when they open Foxly.
