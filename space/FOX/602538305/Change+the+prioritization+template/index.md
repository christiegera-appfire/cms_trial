# Change the prioritization template

If the selected prioritization template doesn't work for you, you can select a different one or [even create your own](/cms_trial/space/FOX/602538293/Create+a+new+prioritization+template/).

There are four predefined templates available:

- [ICE](https://jexo.io/blog/backlog-prioritization-techniques-ice-method/)
- [RICE](https://jexo.io/blog/backlog-prioritization-rice-method/)
- [Value vs Effort](https://jexo.io/blog/backlog-prioritization-techniques-the-value-vs-effort/)
- [WSJF (Weighted Shortest Job First)](https://jexo.io/blog/backlog-prioritization-techniques-the-wsjf-method/)

[See what template is best for you](https://jexo.io/what-prioritization-method/).

## Selecting a different template

From the project menu, navigate to the *Priorities*tab.

![Foxly Priorities tab with the Customize button in the top-right corner](/cms_trial/assets/62e2fd97-de01-4cb2-8e20-09dad52c2507.png)

1. Click **Customize** in the top-right corner.
2. Click the **Select prioritization template** drop-down and select the template you want to use for this project.
3. Click **Save Changes.**

![Foxly template selection dropdown showing available prioritization templates](/cms_trial/assets/410536c5-2c2f-4e6e-955b-226cd374fc27.png)

The new template is now applied to your project, and it's ready to use.
