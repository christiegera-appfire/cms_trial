# Release notes August 2024

**Release date:** August 1, 2024

This page outlines the updates included in the latest release of Foxly.

---

## New features

The following new features are included in this release:

### Prioritization history

Foxly now allows users to review the history of prioritization directly from issue details. This helps teams track and manage their prioritization decisions more effectively.

---

## Enhancements

The following enhancements are included in this release:

### Jira custom field support

Foxly now supports Jira single dropdown custom fields, enabling users to bring their fields into the prioritization process for more customizable, team-specific workflows.
