# Ensure proper permissions for a Priority Poker session

Were you invited to a Priority Poker session, but received a *Something’s gone wrong* message when attempting to access the session? It may be because you don't have access to Jira, or you don’t have project permissions

## Permissions for accessing Priority Poker sessions

To access a Priority Poker session, you must have one of the following Foxly Permissions:

- Administrator:Create and join a Poker session.
- View: Join a Poker session.
- Edit:Create and join a Poker session.
