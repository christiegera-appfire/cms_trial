# Show issue fields as additional columns in Priorities table

There is an option to **Add / Hide additional columns** with information from your Jira issue fields, such as Fix version, Epic, Sprint, and many more.

This is especially useful if you want to see more information in one view when prioritizing and have all the information you need to make a decision in one place.

## How to add additional Jira Issue information to the Priorities table

![How to add additional Jira Issue information to the Foxly Priorities table](/cms_trial/assets/2eab0f5e-e9ea-44e2-aee2-b36ff5816071.png)

1. Open the Foxly Priorities table by clicking the *Priorities* tab in the Project menu.
2. In the *Show/Hide* section, click **Columns**.
3. In the drop-down select fields

Fields now appear in the Priorities table between **Issue summary** and **Score columns**.

**Foxly remembers your last selected columns and filters,** so you don’t need to choose them every time you access the app.
