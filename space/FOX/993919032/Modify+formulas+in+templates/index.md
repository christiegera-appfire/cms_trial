# Modify formulas in templates

## Overview

This document provides instructions on altering template formulas and reverting them if necessary while retaining metric values.

## Update the current template formula

1. Go to the project tab displaying metrics.
2. Click **Customize**.
3. Modify the formula as needed, such as removing specific metrics or adjusting calculations.
4. **Save changes** to the adjusted template.

The app recalculates the score without losing previously selected metrics.

1. Ensure accuracy by comparing updated metrics and scores with the originals.

## Duplicate template for tests

1. Choose the project for testing.
2. Click **Customize**.
3. Create a new template name, indicating it's for testing.
4. Modify the formula as needed, such as removing specific metrics or adjusting calculations.
5. Click **Save as new template**.
6. Confirm that modifications to the duplicated template do not impact other projects using the original.
