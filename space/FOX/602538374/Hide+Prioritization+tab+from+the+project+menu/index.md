# Hide Prioritization tab from the project menu

The Foxly *Prioritization* tab is enabled by default in each project, but there is an option to disable it*.*

## How to disable Foxly Prioritization tab from the project menu

![Foxly project settings page with the EnableDisable prioritization app checkbox](/cms_trial/assets/38e91a16-f54e-4526-b678-7e9d5de8c958.png)

1. Navigate to:

   1. In Classic projects: **Project settings** > **Foxly Prioritization**
   2. In Next-gen projects: **Project settings** > **Apps** > **Foxly Prioritization**
2. Deselect **Enable/Disable Foxly Prioritization app in this project**.

The *Prioritization* tab is now hidden from the Project menu.
