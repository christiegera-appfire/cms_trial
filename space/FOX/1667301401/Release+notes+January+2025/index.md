## New features

The following new features are included in this release:

### Default prioritization values

Foxly admins can use the Default Prioritization Values feature to customize issue templates by pre-setting metric values for all new issues.

When all template metrics have default values, the app automatically calculates the priority score and positions the issue within the priority table based on the score and chosen sorting method.

![Default prioritization values configuration screen](/cms_trial/assets/e67480c1-452b-4fa3-acd9-c9afcb95569f.png)

This feature offers several advantages:

- **Streamlined workflow:** pre-setting common values minimizes manual input and saves time.
- **Establishing a baseline:** set a default average priority score, allowing adjustments as needed.
- **Prioritizing urgency:** assign the lowest possible score upon issue creation to highlight critical tasks.

### Support for flagged issues

Flagged issues in Foxly now behave consistently with Jira's backlog experience.

![Flagged issues displayed in the Foxly priority table](/cms_trial/assets/494e04d7-794f-4219-907d-39061972d364.png)
