# Priority planning poker

Priority Planning Poker is a technique that allows everyone on the team to contribute to the prioritization process while removing bias equally.

Here are some benefits of using priority planning poker:

- Speeds up prioritization sessions.
- Gives everyone the option to contribute to the final priorities.
- Highlights outside opinions to guide the discussion in the right direction.
- Brings fun and gamifies the prioritization meetings.

![Example Priority Poker session.](/cms_trial/assets/2369257a-ad4b-4507-b243-fbfe0457d1bd.png)

## How to play priority planning poker

The high-level steps of playing priority planning poker are:

1. Create a poker room with selected issues.
2. Invite team members.
3. Everyone votes on metrics for selected issues in real-time.
4. Present the results of the voting, together with each member’s votes.
5. Discuss when necessary and accept the votes. Or re-take the voting if outliers are prominent.

## Roles in the priority planning poker session

Everyone with Administer Foxly permission can create a poker session. When you create a session, you automatically become the Session admin.

**Session admin** controls the game, chooses issues that are currently prioritized, closes voting, reveals vote results, and accepts the votes.

**Players** can only vote on the issue selected by the Session admin at that time and view the results once voting is closed.

| **Roles** | **Session admin** | **Player** |
| --- | --- | --- |
| Vote on metrics  Skip vote | ✅  ✅ | ✅  ✅ |
| Close the voting and reveal the score | ✅ | ❌ |
| View results | ✅ | ✅ |
| Change or accept the voting results | ✅ | ❌ |
| Select the issue that is being voted on | ✅ | ❌ |
| Invite other players | ✅ | ✅ |
| Finish the game | ✅ | ❌ |
| Start the game | ✅ | ❌ |

## How to create a new priority planning poker game

To create a new priority planning poker game, access Foxly by clicking the *Priorities* tab in the Project menu.

![Foxly Priorities window with the Priority poker tab indicated.](/cms_trial/assets/26c9191d-38b8-42dc-824b-43c077f6f15a.png)

1. Click **Priority poker** in the top right.
2. Give your poker session a name.
3. Select whether you want **Real-time poker** or **Async poker.**

   - Real-time poker lets you play with your coworkers in real-time.
   - Async poker lets your team prioritize in their own time and review the results later.
4. Click **Next: Select metrics**,and select the metrics you want to prioritize in the session.
5. Click **Select issues***.*

![Create new Priority poker game screen with the Real-time poker option selected.](/cms_trial/assets/b866f374-16de-4ff8-a33b-21bdae4e92db.png)

4. Select the checkbox of the issues you want to prioritize; use filters to find the issues you need.

5. Click **Create session**.

You’ve created a new poker game. Invite other players to the game using the link, and once you’re ready, click **Start the session**to begin voting. New players can join even after the session has already started and participate in the voting process.

![Priority poker session with the issues being selected.](/cms_trial/assets/8b0692fa-9221-4cc2-914b-f544b27823a9.png)

## How to select the issues for prioritization

The session admin (creator of the game) can select the current issue to prioritize by clicking on the issue card in the**Ready for prioritization** column.

## How to vote on issue metrics

You can vote on metrics for any selected issue at the bottom of the screen.

1. You can add values to all metrics or a few only, and click **Submit my vote**.
2. You can choose to skip a turn and refrain from submitting a vote by clicking **Skip this turn**.

Wait for everyone to finish voting and for the session administrator to reveal the score.

## How to close voting and see results

Once voters submit their votes, the session admin can close voting for an issue and reveal the results by clicking **View results**in the voting panel at the bottom of the page.

Then, everyone is taken to the *Results* screen to view the average votes for each metric, alongside details of all player submissions.

Once results are revealed, no one can vote on the issue again.

![Screenshot showing the players  and how many have voted and need to finish voting, and the View results button at the bottom of the page.](/cms_trial/assets/77c3051c-c28c-4d00-8ac2-79cee5cfc767.png)

## How to accept the voting result

The session admin can accept the vote by clicking **Accept results** at the bottom of the *Results* page. Once the result is accepted, the average vote is stored as the final value for that metric, and the issue priority score is recalculated accordingly.

![Screenshot of the result page showing the Average vote graph and the vote distribution.](/cms_trial/assets/d6373258-a7ea-4cd6-afde-2158ebc31664.png)

The *Results* screen then closes, and all players are presented with the next issue to prioritize.

The session admin can overwrite the results by simply clicking and changing the value of the final average metric field on the *Results* page.

## How to retake the vote

If the team is dissatisfied with the results, the session admin can then retake the voting.

1. The session admin clicks **Retake the vote** at the bottom of the *Results* screen.
2. All players are taken back to the *Voting* screen for this issue to submit their votes.
3. The session admin clicks **View results** to see the new results.

![Screenshot showing the Retake the vote button at the bottom of the Results page.](/cms_trial/assets/ef59ec4b-7de0-424c-b8b7-6abc15116c55.png)

## What to do when the priority poker game finishes

Once all issues in the priority planning poker game are prioritized or you run out of time in your prioritization meeting, you can go back to the Foxly priorities screen and view issues with newly assigned metrics in the table.
