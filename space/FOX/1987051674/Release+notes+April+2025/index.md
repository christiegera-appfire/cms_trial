# Release notes April 2025

**Release date:** April 22, 2025

This page outlines the updates included in the latest release of Foxly.

---

## Enhancements

The following enhancements are included in this release:

Foxly now offers data residency options. Data residency gives you control over where your in-scope end-user data is hosted, allowing you to choose a defined geographic location.

The data residency option available for Foxly serves to:

- Help ensure compliance with local data protection laws.
- Enhance security by storing data within specific jurisdictions.
- Provide users with greater control over their personal information, reducing legal risks.

Available data residency realms:

- `US`: us-east-2 (Ohio) — default
- `EU` : eu-central-1 (Frankfurt)
- `DE` : eu-central-1 (Frankfurt)
- `AU` : ap-southeast-2 (Sydney)

For more details, see [Data Residency](https://appfire.atlassian.net/wiki/spaces/FOX/pages/1986887890).
