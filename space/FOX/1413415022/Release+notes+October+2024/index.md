## New features

The following new features are included in this release:

### Saved views

The Saved Views feature allows users to quickly switch between views with a defined set of parameters, including:

- Priority table: Filters, Table Layout, Sorting
- Priority matrix: X-axis, Y-axis, Bubble size, Color, Labels

Saved views can be shared with colleagues and are stored per project.

![Saved views selector in the Foxly priority table](/cms_trial/assets/c6b27547-4930-492d-9879-9a3579fcd4d4.png)

The Saved views selector is located at the top right of the Priority table and Priority matrix pages.

### Default view

Marking a Saved View as **Default** ensures that every new user visiting the project lands on that view. We recommend setting a default view for every project using Foxly.

## Enhancements

The following enhancements are included in this release:

### Share views from the address bar

The parametrized URL can now be shared with colleagues directly from the address bar.

### Filters are persistent when switching from Matrix to Table

Filters no longer reset when navigating back to the Priority table from the Priority matrix.

### New backend sorting improves performance

When sorting the Priority table by Score, a Jira custom field, or a metric aligned with a custom field, sorting is now handled on the backend. This means the table loads faster and no longer has a 1,000-issue limit. Sorting by a metric not aligned with a Jira custom field retains the previous behavior.

### UI improvements to filters and column selectors

The *Custom field* and *Metrics* selectors have been merged into a single **Columns** selector. Selected items now appear at the top for easier access.

![Columns selector showing selected custom fields and metrics at the top](/cms_trial/assets/76b7960a-6a6f-4e50-969b-eccdf1f71e00.png)

Less commonly used basic filters are now hidden under the **More filters** selector.

### Labels are no longer truncated when space allows

Long labels are now displayed in full when there is sufficient space.

### More actions menu

The *More actions* menu on the Priority table page now includes:

- History
- Open in Jira
- Clear all metrics

![More actions menu showing History, Open in Jira, and Clear all metrics options](/cms_trial/assets/176d0461-6a51-4a73-ac08-87c7c1b79c70.png)
