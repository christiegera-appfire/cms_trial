# Limit appearance in Issue Details to specific Issue Types

![Foxly project settings with option to limit Issue Details to specific issue types](/cms_trial/assets/bc588c11-c220-422e-95bb-d35b03172f9e.png)

1. Navigate to:

   1. In Classic projects: **Project settings** > **Foxly Prioritization**
   2. In Next-gen projects: **Project settings** > **Apps** > **Foxly Prioritization**
2. Select **Limit appearance in Issue Details to specific Issue Types**.
