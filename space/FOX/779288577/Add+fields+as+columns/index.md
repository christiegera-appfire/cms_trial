# Add fields as columns

You can add fields as columns easily in Foxly.

## Add fields as columns

In the Priorities table, click **Columns** and select the **field** you want to add as a column.

![Foxly app with custom field drop-down selector window](/cms_trial/assets/8ac1d158-213a-41af-aa59-6c7e7f4656b2.png)

Fields available in Foxly:

- Radio buttons
- Single select list
- Cascading select list
- Parent link
- Description

The **Description** field truncates in the row for longer descriptions**.** To see more details, click the **issue** to view the full description.
