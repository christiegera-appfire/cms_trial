# Details configuration

The **Details** section shows the rich filter's main properties: **Name**, **Description**, **Administrators**, and **Base Jira filter**.

![Details.png](/cms_trial/assets/1e50fd18-c2c3-4177-a971-5d6b7f32cb13.png)

For convenience, this section also shows who owns the Jira filter, who it is shared with, and its JQL query. These properties cannot be edited here, but you can use the links to go to their edit pages if Jira allows you to edit them.

## Editing the Details configuration

1. Navigate to the desired rich filter.
2. By default, you'll be directed to the **Details** section.
3. Edit the configuration as described in the following instructions:

### **1. Change the name, description, administrators, or base Jira filter**

Only [Rich Filter's administrators](/cms_trial/space/RFCDOC/783941839/Rights+and+Permissions/) and [Jira Administrators](https://support.atlassian.com/jira-cloud-administration/docs/manage-global-permissions/) can perform this operation.

Click any of the values to edit them.

### 2. **Duplicate a rich filter**

1. Click **Duplicate** under the **Menu** at the top of the screen.

   ![duplicate rich filter](/cms_trial/assets/162e0609-d766-490b-b3d4-8aac4f63ae4c.png)
2. Type the name of the new rich filter and click **Duplicate**.   
   A new rich filter identical to the first one, but with the name you have entered, is created.

   ![duplicate filter.png](/cms_trial/assets/7b805f37-75e7-4d15-b8e1-5c7976b4aa5e.png)

### 3. **Move a rich filter to trash**

Only [Rich Filter's administrators](/cms_trial/space/RFCDOC/783941839/Rights+and+Permissions/) and [Jira Administrators](https://support.atlassian.com/jira-cloud-administration/docs/manage-global-permissions/) can perform this operation.

Click **Move to trash** under the **Menu** at the top of the screen.

![Delete.png](/cms_trial/assets/2a6919ac-4513-489f-be0d-de6181de6b54.png)
