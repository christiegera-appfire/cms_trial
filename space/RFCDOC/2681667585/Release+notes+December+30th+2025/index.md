# Release notes December 30th 2025

**Release date**: December 30, 2025

Our team is thrilled to announce the latest release of Rich Filters for Jira Dashboards.

---

## Enhancements

## **Values displayed on more charts**

Previously, some chart layouts (such as donut, treemap, and sliced bar) displayed values directly on the chart when space allowed. Now, more chart layouts display values, giving you a more precise view of the data, without requiring you to hold the pointer over the chart or to display the quick table.

### Key improvements

- Values and percentages appear directly on the chart when the available space permits
- View values at a glance for precise analysis, with screenshots, PDF export, and more.
- Reduces the need to display tooltips or the quick table
