# Fundamentals

Our fundamentals series provides a deeper dive into rich filters. In each guide, you'll explore a core piece of functionality in detail — understanding why it is important, what it can do, and what its key use cases are — and build up an illustrative example that you can refer back to and use as inspiration for your projects.

These guides are designed to be standalone, so you can jump into topics of interest as you see fit. However, we recommend tackling them in order, and beginners to Rich Filters for Jira Dashboards should start with the first article.
