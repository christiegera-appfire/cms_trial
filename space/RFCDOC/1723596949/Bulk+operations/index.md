# Bulk operations

Bulk operations help you manage rich filters more efficiently by allowing you to perform actions on multiple filters simultaneously.

![Bulk operations .png](/cms_trial/assets/c92dcd86-ec22-40de-a6fc-ee9a8a6759fe.png)

### Operations

The following options are available:

- [**Download usage data**](/cms_trial/space/RFCDOC/1723236446/Rich+filter+usage+data/) – Retrieve insights on filter usage. *(See* [*permissions*](https://appfire.atlassian.net/wiki/spaces/RFCDOC/pages/edit-v2/1723596949#Permissions) *details below.)*
- **Move to trash** – Temporarily remove selected rich filters.
- **Restore from trash** – Recover previously deleted rich filters.
- **Delete forever** – Permanently delete selected rich filters. **This action cannot be undone.**
- [**Export to backup (Beta)**](/cms_trial/space/RFCDOC/1723924660/Export+and+import+of+rich+filters+data/) – Create a backup of selected rich filters. *(See* [*permissions*](https://appfire.atlassian.net/wiki/spaces/RFCDOC/pages/edit-v2/1723596949#Permissions) *details below.)*

### Accessing bulk operations

To perform bulk actions:

1. Go to theRich filters **Home** screen and select **Bulk ops** in the side navigation bar.

   ![Bulk ops.png](/cms_trial/assets/5af8a66e-e753-4f18-bc5a-e2fe827321ee.png)

### Permissions

By default, only **Jira admins** can perform bulk operations on rich filters. To modify these permissions:

1. Navigate to the **App Configuration** page.
2. Open the **Permissions** tab.

   ![Permissions](/cms_trial/assets/b6dfc032-20a4-41a8-b200-c935dcf985ce.png)
3. Adjust access settings as needed.

Authorized users can only perform bulk operations on rich filters with **admin permissions**.
