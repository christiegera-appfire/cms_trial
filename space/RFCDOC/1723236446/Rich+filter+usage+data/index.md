# Rich filter usage data

Rich filters let you download an Excel file with usage data for the rich filters you administer.

## For a specific rich filter

1. Go to theRich filters **Home** screen and click **Menu** (`...`) for your rich filter.

   ![download usage data. .png](/cms_trial/assets/0cca94e1-0c22-4e9e-8a08-534287cc00c7.png)
2. Click **Download usage data.**

You can also:

1. Go to your rich filter **Details** page.
2. Click the **Menu** (`...`) icon.
3. Select **Download usage data.**

   ![Download usage data  .png](/cms_trial/assets/4951764b-e777-41e5-88da-fbaf11da7465.png)

## For multiple rich filters

Use the **Download usage data** [bulk operation](/cms_trial/space/RFCDOC/1723596949/Bulk+operations/).

1. Go to theRich filters **Bulk ops** screen.
2. Check all the filters you would like to download.
3. Select **Download data usage** in the **Bulk operations** dropdown**.**

   ![Bulk download.png](/cms_trial/assets/cf6fbecd-40a0-4c75-8e61-e036b31bbf6d.png)
4. Click **Apply**.

The usage data includes details on rich filter changes (created, modified, trashed) and access (viewed, used in dashboards).
