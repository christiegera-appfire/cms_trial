## Enhancements

## Value display on charts

In a recent release, we have enhanced gadgets to display numeric values directly on the charts, making it easier to read exact figures without hovering or checking legends. In this release we have made this feature optional: a new setting **Show values** is available in the **Three-dot menu** () in the Flexi Charts, Time Series and Created vs Resolved gadgets, and in statistics gadgets when they display quick charts. When enabled, numeric values appear directly on the chart when space allows.

Supported chart types:

- Percentage bar
- Bar
- Line
- Clustered bar
- Stacked bar (shows both slice percentages and stack totals)
- Multi-line
