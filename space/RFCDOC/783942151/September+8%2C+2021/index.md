# September 8, 2021

## JQL Autocomplete

JQL filtering is an essential component of many of the features of the *Rich Filters for Jira Dashboards* app. [Static filters](/cms_trial/space/RFCDOC/783941703/Configure+static+filters/) and [smart filters](/cms_trial/space/RFCDOC/783941713/Configure+smart+filters/) are based on JQL, [custom values](/cms_trial/space/RFCDOC/783942033/Configure+custom+values/) can have an optional JQL filtering condition, rich filter gadgets can have [working queries](/cms_trial/space/RFCDOC/783942092/August+23%2C+2021/), which are also optional JQL filtering conditions, and the [controller gadgets](/cms_trial/space/RFCDOC/783941745/The+Rich+Filter+Controller+Gadget/) can be used to also filter with JQL (in addition to or instead of the preconfigured filters). In all these places, typing JQL is now much easier: as you type, the app will provide a list of *autocomplete suggestions* based on the context of your query.

We're sure you will find this feature as useful as we do. If you have any suggestions for its improvement, please [let us know](http://appf.re/support).
