# November 19, 2021

## Dynamic filters based on text and on numbers

Dynamic filtering, one of the mechanisms by which [Rich Filter Controller](/cms_trial/space/RFCDOC/783941745/The+Rich+Filter+Controller+Gadget/) gadgets allow dashboard users to easily filter issues, now supports text and number fields.

In addition to dynamic filters based on text and numeric issue fields, the following special dynamic filters are also available:

- *Contains text* – full-text search in all text fields: summary, environment, description, the comments of the issues, as well as all the custom text fields
- *Comment* – full-text search in all the comments of the issues

To use a text or a number dynamic filter, just click on it and type a search query in the text box. The *text search query* can contain one or multiple space-separated words, or it can be an [advanced query](https://support.atlassian.com/jira-work-management/docs/search-syntax-for-text-fields/) with wildcards, Boolean operators, etc. The *number search query* can contain one or multiple space-separated numeric values or ranges.

For more information about *dynamic filters*, have a look at [Configuring Dynamic Filters](/cms_trial/space/RFCDOC/783941707/Configure+dynamic+filters/).
