# Release notes December 4th 2025

**Release date**: December 4, 2025

Our team is thrilled to announce the latest release of Rich Filters for Jira Dashboards.

---

## New features

## Gadget permalinks

Gadget permalinks let you link directly to individual gadgets in their maximized view. This feature makes it easy to share or access the specific information you’re interested in, rather than the entire dashboard.

1. Maximize the gadget you want to link to by clicking the **Maximize** button () in the top right.
2. Click the **Permalink** (▢) button in the gadget footer to copy the permalink to the clipboard.

   ![2025-12-04_14-22-32.png](/cms_trial/assets/c1180851-93fd-45e5-9414-127d33b09cab.png)

When the URL is opened, the rich filter gadget is restored to the same state as when the link was generated, meaning the link maintains all current filters applied to the gadget.

## **New dynamic filter on Linked Issues**

Dynamic filtering support is now available for **Linked Issues**. The Linked Issues dynamic filter returns all the issues that are linked to the issues you select.

---

## Enhancements

## **Decimal values for constant denominators in** **custom ratio** **configuration**

In the custom ratio configuration, constant denominators now accept decimal values with up to 6 decimal places, providing greater flexibility and precision in your calculations.

## **Improvement** **when changing a gadget’s rich filter**

When changing the rich filter in the gadget configuration, the app now intelligently matches rich filter components (static filters, dynamic filters, smart filters, views, time series) by name and type, preserving your configuration wherever possible. If the two rich filters are identical, all configuration settings are retained when switching between them.
