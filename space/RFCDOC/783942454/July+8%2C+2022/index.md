# July 8, 2022

## New Gadget: Rich Filter Issue Activity Stream

This release introduces a new gadget that displays the recent activity on the issues returned by the rich filter. As with all the other rich filter gadgets, it responds to filtering in the controller gadget, thus allowing users to see the activity on the issues they're interested in.

For more information about the *Rich Filter Issue Activity Stream*gadget, look at its [documentation page](/cms_trial/space/RFCDOC/783942442/The+Rich+Filter+Issue+Activity+Stream+Gadget/).

## Advanced mode for the Rich Filter Created vs. Resolved Chart gadget

You can now configure the *Rich Filter Created vs. Resolved Chart* gadget with *custom start and finish dates* instead of the default Created and Resolved dates. This opens up new possibilities for advanced use cases. For example, you can do a more detailed analysis of your team's activity or cover complicated or non-standard workflows.

Custom start and finish dates can be any of your issues' date or date-time fields. The selected start and finish dates together with the selected value (Issue Count or any numeric field) define two series of values for which the chart will highlight the relative evolution, in the same way as for the Created and Resolved series.
