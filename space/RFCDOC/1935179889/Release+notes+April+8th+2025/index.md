# Release notes April 8th 2025

**Release date**: April 8, 2025

Our team is thrilled to announce the latest release of Rich Filters for Jira Dashboards.

## Enhancements

## New app navigation compatible with Jira’s new navigation

We've redesigned the app navigation to be more practical and intuitive, while ensuring full compatibility with the new Jira navigation currently being rolled out.  
The new layout features a sidebar with icons to access the app’s main configuration pages, and horizontal tabs to navigate within the configuration of individual rich filter objects.
