# Release notes June 29th 2026

**Release date**: June 29, 2026

This page outlines the updates included in the latest release of Rich Filters for Jira Dashboards.

---

## Features

## Results gadget: show more issues

In the Rich Filter Results gadget you can now view more issues per page when needed, without changing the configuration. The feature is available to all dashboard users.

- Click the range pill to expand up to 50 issues per page.
- Click again to reset.

  ![image-20260512-100904.png](/cms_trial/assets/098b37e4-efcc-415f-ba03-02cfed9dbbb0.png)

  To learn more, see [The Rich Filter Results Gadget](/cms_trial/space/RFCDOC/783941759/The+Rich+Filter+Results+Gadget/).

## Time display format in Custom Values

You can now display time-tracking custom values in **weeks** and **years**, in addition to days, hours, minutes, and seconds. Select your preferred format from the **Time display format** dropdown when creating custom values based on time-tracking fields.  
To learn more, see [Configure custom values](/cms_trial/space/RFCDOC/783942033/Configure+custom+values/).

![image-20260625-125439.png](/cms_trial/assets/1ae29236-90dc-4a6a-8d0d-fa6d05bbf7c2.png)

## Percentage bars in Two Dimensional Statistics gadget

We’ve added support for percentage bars in *Rich Filter Two-Dimensional Statistics* gadget, making it easier to compare proportions across both rows and columns at a glance. Similar to 1D statistics, each column can now display percentage bars that represent for each row the share of the column total.

![2026-06-25_15-13-08.png](/cms_trial/assets/376d6465-8407-4c1a-973f-01dfb09f3b5b.png)

The **Show percentage bars** option is now available in the **Vertical breakdown** section of the *Rich Filter Two-Dimensional Statistics* gadget configuration.

![2026-06-25_15-06-21.png](/cms_trial/assets/8e96554b-4185-47e4-9da1-906cdbd19282.png)

To learn more, see [The Rich Filter Two Dimensional Statistics Gadget](/cms_trial/space/RFCDOC/783941803/The+Rich+Filter+Two+Dimensional+Statistics+Gadget/).

## Link for slice "Other"

In charts that can display a slice “Other” (like donut, treemap, sliced bar, or stacked bar charts), the slice **Other** now also has a link that allows you to open the corresponding list of issues in the Issue Navigator.

- ![image-20260625-134052.png](/cms_trial/assets/2ed6ba74-2e39-41a9-97cb-37af4561e2d4.png)

  To learn more, see [The Rich Filter Flexi Charts Gadget](/cms_trial/space/RFCDOC/783941863/The+Rich+Filter+Flexi+Charts+Gadget/).
