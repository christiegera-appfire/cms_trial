# August 28, 2021

## Customizations in Rich Filter Results Views

The views displayed by the [Rich Filter Results](/cms_trial/space/RFCDOC/783941759/The+Rich+Filter+Results+Gadget/) gadgets can now be configured with display options for columns. Currently, the following settings are available in the [views configuration](/cms_trial/space/RFCDOC/783941729/Configure+views/) page:

- for any column, you can choose the header of the column among the following options:

  - no header,
  - a user-defined header,
  - the name or the initials of the Jira field, [smart filter](/cms_trial/space/RFCDOC/783941713/Configure+smart+filters/) or [custom value](/cms_trial/space/RFCDOC/783942033/Configure+custom+values/) the column is based on;
- for columns based on [smart filters](/cms_trial/space/RFCDOC/783941713/Configure+smart+filters/), you can choose whether the column should display the colored labels, only the colors, or only the labels of the smart filter clauses.

These customizations give you more control over the way data is displayed in Rich Filter Results gadgets, for instance by allowing you to choose between compactness and explicitness in each view, according to the use case and context.
