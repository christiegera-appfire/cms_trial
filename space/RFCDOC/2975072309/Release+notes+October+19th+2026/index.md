## New feature

## Support for the Formula field type

Rich Filters for Jira Dashboards now supports the **Formula** custom field type recently added by Atlassian. With the Formula field type, you can create custom fields that automatically calculate and display data using fields within a work item. To learn more, see [Create a formula field | Atlassian Support](https://support.atlassian.com/jira-cloud-administration/docs/create-a-formula-field/).

In Rich Filters, you can use a Formula field:

- as a column in views, to be displayed in Rich Filter Results gadgets;
- as a Statistic type or Value in the statistics and flexi charts gadgets;
- as a dynamic filter, allowing you to filter the issues on your dashboard.

Note that the app’s behavior for a given Formula field, for example, the behavior of a dynamic filter, depends on the Formula field’s configured output type (number, text, date, or duration).
