# January 20, 2022

## Support for statistics by single line text fields

[The Rich Filter Statistics](/cms_trial/space/RFCDOC/783941781/The+Rich+Filter+Statistics+Gadget/), [Two Dimensional Statistics](/cms_trial/space/RFCDOC/783941803/The+Rich+Filter+Two+Dimensional+Statistics+Gadget/) and [Flexi Charts](/cms_trial/space/RFCDOC/783941863/The+Rich+Filter+Flexi+Charts+Gadget/) gadgets now support *single line text fields* as statistic type. All the existing features of these gadgets (sorting, totals, *quick charts* etc.) are compatible with statistics by *single line text fields* (i.e. custom fields of the type *Text Field (single line)*).
