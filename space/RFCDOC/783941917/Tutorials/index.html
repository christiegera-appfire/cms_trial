Tutorials

2 min read

If you would like a quick intro to rich filters and to build a complete dashboard that shows what rich filters can do — say you've got 45 minutes to evaluate it or build a proof of concept — our getting started guide is for you.

These short tutorials are designed to be followed in order from start to finish:

  1. Create and access Rich Filters

  2. Build a simple interactive Jira dashboard

  3. Define views for your dashboard

  4. Use working queries in your dashboard

  5. Add dynamic filtering to your dashboard

  6. Add smart filters and smart columns to your dashboard

  7. Add Rich Filter Statistics gadgets to your dashboard

  8. Add Rich Filter Two Dimensional Statistics gadgets to your dashboard

  9. Add Rich Filter Flexi Charts gadgets to your dashboard

  10. Create presets in Rich Filter Controller

Video tutorial series

Prefer to learn by watching? Our comprehensive 20-minute video series covers all the essential scenarios with hands-on demonstrations:

Video 1: Create and filter your dashboard

Learn how to:

  • Create your first Rich Filter

  • Set up static filters for instant data filtering with clickable buttons

  • Build an interactive dashboard with Results and Controller gadgets

  • Define custom views to display your work items in different ways for different purposes

Video 2: Customize your dashboard

Discover how to:

  • Use working queries to permanently filter data

  • Create dynamic filtering

  • Build smart filters with visual highlighting columns

  • Add smart columns to your Results gadget

Video 3: Visualize your statistics

Learn how to:

  • Add statistics gadgets

  • Create interactive charts from your Jira data

  • Build two-dimensional statistics gadget that reveals complex relationships in your project data

Video 4: Flexi Charts gadgets

Learn how to:

  • Explore Flexi Charts gadgets

  • Add two-dimensional Flexi Charts

  • Create and manage filter presets for one-click access to complex filter combinations

Video 5: Custom values

Learn how to:

  • Create customized metrics like aggregated time spent, resolved story points, and average resolution time

  • Display custom values instantly across counters, statistics tables, issue lists, and flexi charts

  • Use JQL filters within individual metrics to isolate resolved issues or active deadlines

  • Track real-time durations like days remaining until an issue is due
