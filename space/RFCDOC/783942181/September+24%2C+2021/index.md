# September 24, 2021

## Charts Based on Two-Dimensional Statistics

This release introduces two new chart types based on two-dimensional statistics: clustered bar charts and stacked bar charts. These 2D chart *types* are available as *quick charts* in the [Rich Filter Two Dimensional Statistics](/cms_trial/space/RFCDOC/783941803/The+Rich+Filter+Two+Dimensional+Statistics+Gadget/) gadget and as additional chart type options in the dedicated [Rich Filter Flexi Charts](/cms_trial/space/RFCDOC/783941863/The+Rich+Filter+Flexi+Charts+Gadget/) gadget. The 2D charts support all the currently available two-dimensional statistics configurations, including [statistics on smart filters](/cms_trial/space/RFCDOC/783942007/July+20%2C+2021/) and values based on [custom values](/cms_trial/space/RFCDOC/783942033/Configure+custom+values/).

- The *2D quick charts* require no additional configuration and are directly available in the existing Rich Filter Two Dimensional Statistics gadgets. Users can switch between the table view and the chart view by clicking on the corresponding icon located at the bottom right of the gadget. In the chart view, it is possible to choose the chart type by selecting it in the corresponding field at the bottom of the gadget.

  ![contentId-783942181](/cms_trial/assets/4cc0da43-0590-46e2-9ea3-930cda2ae58c.png)

- In the configuration form of the Rich Filter Flexi Charts gadget, when you select one of the 2D chart types, the settings for a second level of breakdown appear. You will find the configuration of 2D flexi charts quite straightforward if you are familiar with the configuration of Rich Filter Two Dimensional Statistics gadgets.

As you have come to expect from rich filter dashboards, the charts are interactive, responsive, visually appealing and carefully designed.

For more information about this new feature, have a look at the [Rich Filter Two Dimensional Statistics Gadget](/cms_trial/space/RFCDOC/783941803/The+Rich+Filter+Two+Dimensional+Statistics+Gadget/) and the [Rich Filter Flexi Charts Gadget](/cms_trial/space/RFCDOC/783941863/The+Rich+Filter+Flexi+Charts+Gadget/) documentation pages.
