# Release notes June 2026

**Release date**: June 19, 2026

This page outlines the updates included in the latest release of Rich Filters for Jira Dashboards.

---

## Enhancement

### Increased limits for filters, views, and other sub-objects

We've increased the maximum number of sub-objects per rich filter to allow you to allow you to build richer configurations without hitting limits.

| Component | Previous | New |
| --- | --- | --- |
| Dynamic filters | 50 | 100 |
| Smart filters | 30 | 100 |
| Views | 50 | 100 |
| Queues | 50 | 100 |
| Custom values | 50 | 100 |
| Custom ratios | 50 | 100 |
| Time series | 80 | 100 |

As a reminder, the maximum number of static filters is 300.

### DC to Cloud migration with Forge

The Cloud app now supports DC to Cloud migration with Forge. In the near future, we plan to release a DC version that works with Forge instead of Connect. Soon thereafter, the DC to Cloud migration with Connect will be deprecated. This step will complete the transition to Forge of the Rich Filters Cloud app.
