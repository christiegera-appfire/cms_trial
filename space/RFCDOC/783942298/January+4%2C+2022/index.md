# January 4, 2022

## Custom ratios in rich filter statistics gadgets

In the [previous release](/cms_trial/space/RFCDOC/783942284/January+3%2C+2022/), we introduced custom ratios, a new type of rich filter configuration object that can be used to compute ratios of different values. Previously, the *custom ratios* were available in gauge gadgets only. Now, the *custom ratios* are also available as values in the *Rich Filter Statistics* and *Rich Filter Two Dimensional Statistics* gadgets. When selected, a *custom ratio* is displayed as a percentage followed by the ratio (numerator / denominator). All the existing features of the rich filter statistics gadgets (breakdowns, sorting, totals etc.) are compatible with *custom ratios*.
