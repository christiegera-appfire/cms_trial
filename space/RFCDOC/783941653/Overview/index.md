## Introduction

Native Jira dashboards rely on isolated gadgets locked to rigid, static JQL queries, forcing administrators to build separate boards for every small variation in data. Rich Filters for Jira Dashboards solves this by adding a smart filtering layer on top of your existing Jira filters. This lets you build a single, centralized dashboard where users can instantly adjust, color-code, and explore data across connected gadgets in real time, effectively making one dashboard do the work of dozens.

The *Rich Filters for Jira Dashboards* app for Cloud provides new gadgets (Rich Filter Gadgets) that allow you to build highly interactive and personalized [Jira dashboards](https://support.atlassian.com/jira-core-cloud/docs/what-is-a-jira-dashboard/).

Rich Filter gadgets provide functionality that redefines your experience of using Jira dashboards:

- Dynamically change the data displayed by your dashboards - every user adjusts what they see without touching the dashboard configuration.
- Tag and color-code issues - visually prioritize and categorize work at a glance.
- Build statistics and charts - create custom reports from Jira fields and user-defined criteria, no external tools needed.
- Define personalized views - one dashboard, multiple layouts for different roles or contexts.

This guide covers everything you need to configure, manage, and use Rich Filters for Jira Dashboards.

To install it, read reviews, and find out other details, such as pricing, see our [listing on the Atlassian Marketplace](https://marketplace.atlassian.com/plugins/com.qotilabs.jira.rich-filters-plugin).
