# Permalinks

## Overview

You can generate direct links to any dashboard or gadget, making it easy to share specific dashboard views with colleagues or to bookmark frequently used gadgets.

You can use the link to:

- Share specific views with team members.
- Bookmark frequently accessed reports or visualizations.
- Reference specific data views in documentation or communications.
- Create quick access shortcuts to important metrics.

## Dashboard state permalinks

Dashboard state permalinks are URLs that encode the current state of the *Rich Filter Controller* gadgets in your dashboard. When opened, these links restore the dashboard to the state it was in when the link was generated, with all quick filters in place.

To copy a dashboard permalink, click the **Permalink** icon in the footer of the *Rich Filter Controller* gadget. The link is automatically copied to the clipboard.

![permalink-for-controller](/cms_trial/assets/9fb181b9-a9aa-449b-9017-e7589a36aace.png)

The generated URL can be bookmarked or sent to another user. When the URL is opened, the rich filter gadgets are restored to the same state as when the link was generated—the same quick filters are selected in the *Rich Filter Controller* gadgets.

## Gadget permalinks

Gadget permalinks let you link directly to individual gadgets in their maximized view. This feature makes it easy to share or access the specific information you’re interested in, rather than the entire dashboard.

1. Maximize the gadget you want to link to by clicking the **Maximize** button (▢) in the top right.
2. Click the **Permalink** (▢) button in the gadget footer to copy the permalink to the clipboard.

   ![gadget-permalink](/cms_trial/assets/e3735cec-23fd-4a37-8de4-2dbdba54b3cf.png)

When the URL is opened, the rich filter gadget is restored to the same state as when the link was generated, meaning the link maintains all current filters applied to the gadget.
