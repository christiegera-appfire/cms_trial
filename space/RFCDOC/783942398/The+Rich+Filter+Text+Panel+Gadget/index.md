# The Rich Filter Text Panel Gadget

## **1. About the Rich Filter Text Panel gadget**

The *Rich Filter Text Panel* the gadget allows you to display configurable rich text directly on dashboards in order to inform and guide users and to give context to dashboards.

![contentId-783942398](/cms_trial/assets/c5906782-61e9-45d1-9bb7-77c013bea6d1.png)

## **2. Configuring the Rich Filter Text Panel gadget**

[Add](https://support.atlassian.com/jira-work-management/docs/add-and-customize-a-gadget/) a new or edit an existing *Rich Filter Text Panel* gadget in your [Jira dashboard](https://support.atlassian.com/jira-work-management/docs/what-is-a-jira-dashboard/). The configuration form of the gadget will be displayed.

![contentId-783942398](/cms_trial/assets/3d0d63fb-ba9e-4516-9f16-7e6edd9f4b7f.png)

Configuring a *Rich Filter Text Panel* is really straightforward. The gadget configuration form displays only a rich text editor. The user-friendly editor allows you to write text and to choose and combine text styles, text formatting, colors, bullet and numbered lists, links, tables, code snippets, info panels, quotes and expand/collapse sections. Once added, some of these elements can then be further refined with specific settings.

![contentId-783942398](/cms_trial/assets/aec6292b-8fe0-4fc7-a619-fbeda4fd56d7.png)

Unlike other rich filter gadgets, the *Rich Filter Text Panel* gadget is not based on a particular rich filter. The gadget will display the same text, independently of the other gadgets on the dashboard.
