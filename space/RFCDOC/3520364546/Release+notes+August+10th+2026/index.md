# Release notes August 10th 2026

**Release date**: August 10, 2026

This page outlines the updates included in the latest release of Rich Filters for Jira Dashboards.

---

## Enhancements

**Support** **for Forge custom** **number field type**

Rich Filters now supports Jira custom Forge number field type. These fields are available for the views columns picker and dynamic filters, with values displayed correctly.
