# Create and access rich filters

## Overview

This document explains how to create and access rich filters.

## Create a new rich filter

1. Open Jira’s **Apps**menu in the navigation bar and click **Rich Filters**. This will open the Rich Filters list page.

   ![Rich Filters under Apps in Jira](/cms_trial/assets/0f6dac41-823b-45b9-a834-06762b212c41.png)
2. Click **Create rich filter** at the top-right of the screen.

   ![Create rich filter ](/cms_trial/assets/464c087a-bb86-4d9a-89e4-6ace081c4c20.png)
3. In the *Create rich filter* window, enter a unique name for your rich filter and select an existing [Jira filter](https://support.atlassian.com/jira-work-management/docs/search-for-issues-in-jira/#Searchingforissues-5.Saveyoursearch) as its base.

   ![The Create new rich filter dialog](/cms_trial/assets/283f97fc-81bd-427e-a3c5-32d60242610a.png)
4. Click **Create**.

You need to have the rights to use the selected Jira filter but you don't need to be its owner.

You have now created your first rich filter.As you can see, your rich filter is based on the native Jira filter you have selected. You have been added as an administrator of the rich filter, which lets you edit it.   
**Try it out:** type a description in the corresponding field and click **Submit** to save the change.

![Getting started filter](/cms_trial/assets/cb4f0bf5-59a2-45a3-bbd3-c72b44764b78.png)

The *Rich filter* can be further configured using the menu tabs: **Details, Static filters, Dynamic filters, Smart filters, Views, Queues, Custom values, Custom ratios, Time series,** and **Misc***.* You have already seen the *Details* section, and other tutorials in this series will guide you through gradually enriching the configuration of your rich filter and thus extending its functionalities. In the next tutorial, we'll add static filters to this rich filter and use them to [build a simple interactive Jira dashboard](/cms_trial/space/RFCDOC/783941937/Build+a+simple+interactive+Jira+dashboard/).

Before we move on, let's see how you can find, view, and edit existing rich filters.

## Access existing rich filters

1. To display the list of rich filters for which you have [view permission](/cms_trial/space/RFCDOC/783941839/Rights+and+Permissions/), click **Rich Filters** under the Jira **Apps** menu, as you did at the [beginning](/cms_trial/space/RFCDOC/783941927/Create+and+access+rich+filters/) of this tutorial.

Alternatively, if you are on the *Details* page of a *rich filter*, you can click the Rich Filters *Home* link at the top left of the screen.

1. You can find the rich filter you're looking for directly in the list or by using the **Search** field at the top of the page.
2. Click any rich filter's name to open its configuration page. You can change the configuration with [admin permission](/cms_trial/space/RFCDOC/783941839/Rights+and+Permissions/) to access the rich filter.
