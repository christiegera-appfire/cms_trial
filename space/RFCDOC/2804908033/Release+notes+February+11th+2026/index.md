## Enhancements

## Streamlined footer design

We've redesigned the gadget footer to make it more consistent, intuitive, and accessible:

- **Three-dot menu** () with quick access to:

  - **Configure gadget** - opens the gadget configuration without entering dashboard edit mode
  - **Open rich filter config** - opens the rich filter configuration screen in a new tab
  - Other gadget-specific settings, like **Show presets** for the controller gadget
- **App menu** () with the following resources:

  - **Gadget documentation** - takes you to the gadget documentation page
  - **Contact support -** takes you to Appfire’s support portal
  - **Download support file** - downloads a text file with the gadget configuration details, to be sent to the support team if you encounter any issue
  - **About Rich Filters** - takes you to the app’s Marketplace listing page

- **Issue count meter**, with visual filtering indicator (▢), an informative tooltip and a gauge-like visualization of the filtered-to-total issues ratio. Just like before, you can click the issue count to open the Issue Navigator.

  ![2026-02-10_15-53-04.png](/cms_trial/assets/21419c89-cbbc-414d-a9e9-d50325f73ae3.png)

## Improved accessibility and keyboard navigation

- Use your keyboard to apply dynamic and smart filters in the *Rich Filter Controller* gadget.
- Use your keyboard to navigate the footer controls, including the issue count, Export menu, Permalink, and three-dot menu.
- Adjusted link colors so that only issue keys are displayed in blue at rest (all links remain clickable).
- Adjusted the colors of quick filters in dark mode.

## AND operator for Smart filters

You can now enable the AND operator for specific smart filters where it makes sense.

![2026-02-10_16-03-56.png](/cms_trial/assets/c446ef77-e869-4a1a-b713-358c5ed856de.png)

When the AND operator is enabled, you can use it for filtering in the *Rich Filter Controller* gadget. In the smart filter dropdown you can choose between the two operators:

- **OR** (default) – returns the issues matching any selected value
- **AND** - returns the issues matching all selected values
