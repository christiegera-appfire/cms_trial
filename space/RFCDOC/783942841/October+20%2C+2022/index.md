# October 20, 2022

## Export issues and statistics to PDF, Excel, and CSV

In a previous release, we added support for export to Excel and CSV in Rich Filter Results gadgets. In this release, we have added additional export features:

- In the [Rich Filter Results](/cms_trial/space/RFCDOC/783941759/The+Rich+Filter+Results+Gadget/) gadgets you can now also export the issues to a PDF file. As with Excel and CSV, the PDF export uses the currently selected [view](/cms_trial/space/RFCDOC/783941729/Configure+views/), so you'll get the same columns in the exported table.
- In the Rich Filter Statistics and the Rich Filter Two-Dimensional Statistics gadgets, you can now export the statistics table to PDF, Excel, or CSV. If the gadget displays a quick chart when you initiate the PDF export, the exported file will include both the chart and the statistics table.

The export is directly available by clicking on the corresponding icon in the gadget footer.
