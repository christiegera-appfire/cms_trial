# Rich Filters for Jira Dashboards (Cloud)

## Welcome to Rich Filters for Jira Dashboards!

This is the documentation for **the Cloud version** of the *Rich Filters for the Jira Dashboards* app. For the Server and Data Center version, see [Rich Filters for Jira Dashboards (Server & Data Center)](https://appfire.atlassian.net/wiki/spaces/RFP).

## Key Features

- Flexible, quick filters for dashboards
- Smart stats, charts, and reporting
- Real-time, interactive, and accessible
