# Export data

Rich filter gadgets can be exported in PDF, Excel (.xlsx), or CSV. The exported files preserve any filtering selected in the Rich Filter Controller and in the gadget configuration. Users can export the content of a single gadget or the content of all the gadgets in the dashboard.

**Export permissions**

The export options are available only to users with export permissions. For more information, please see the [Rights and Permissions](/cms_trial/space/RFCDOC/783941839/Rights+and+Permissions/) documentation page.

## Export a gadget

The content of any rich filter gadget can be exported by selecting the **Export** button located in the footer of the gadget.

![export.png](/cms_trial/assets/37450303-fa74-4b52-bf56-03456d40522f.png)

## Export the entire dashboard

The Rich Filter Controller gadget allows you to export the entire dashboard by selecting the export options located in the footer. The export options available in the *Rich Filter Controller* are PDF and Excel (.xlsx).

The exported file will contain all the rich filter gadgets available in the dashboard based on the same rich filter as the controller. Also, the exported file preserves the filtering as selected in the controller.
