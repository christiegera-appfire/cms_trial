Release notes July 30th 2026

Release date: July 30, 2026

This page outlines the updates included in the latest release of Rich Filters for Jira Dashboards.

Enhancements

Search rich filters by administrator

You can now search the Rich filters list by the administrator, making it easier to find filters on large Jira instances. A new Administrator dropdown has been added alongside the existing search box, allowing you to quickly narrow down filters by their admin.

This feature is being rolled out gradually and may not yet be available on all instances.

For details, see Find an existing rich filter.
