## Features

## Hierarchies

Rich Filters now supports issue hierarchies in the [Rich Filter Results](/cms_trial/space/RFCDOC/783941759/The+Rich+Filter+Results+Gadget/) gadget. Hierarchiesallow you to visualize issues by organizing them according to your issue type hierarchy (for example, Initiative → Epic → Story → Subtask). Instead of a flat list, issues appear in a collapsible tree structure that preserves parent-child relationships across multiple levels.

To get started, open your rich filter configuration, go to **Lists** > **Hierarchies**, and create your first hierarchy.

![Hierarchies](/cms_trial/assets/5ce6a240-6e74-439e-9041-9379755f01a3.png)

Once configured, select it in the configuration of a Rich Filter Results gadget under **Display** > **Configured lists**. The gadget can display one or several hierarchies as tabs, similar to queues.

![Rich Filter Results gadget](/cms_trial/assets/3a49788c-811a-4ce6-83e0-973de18447dd.png)
