# June 29, 2021

## Quick Charts in the Rich Filter Statistics Gadget

Dashboard users can now display charts in the *Rich Filter Statistics* gadget. These charts referred to as *quick charts*, require no additional configuration and are directly available in existing gadgets.

Users can switch between the table view and the chart view by clicking on the corresponding icon at the gadget's bottom right.

![contentId-783941857](/cms_trial/assets/c6bb73ea-9011-4073-9bca-bd1e0984eadd.png)

In the chart view, you can choose the chart type and the values of the quick chart by selecting them in the corresponding fields at the bottom right of the gadget. The following chart types are available: donut, pie, gauge, bar, and treemap.

For more information about this new feature, look at the [Rich Filter Statistics Gadget](/cms_trial/space/RFCDOC/783941781/The+Rich+Filter+Statistics+Gadget/) documentation page.
