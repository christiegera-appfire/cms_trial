# Is Dashboard Hub enterprise-ready?

## Overview

Dashboard Hub provides several features that make it the perfect tool for large teams:

## Enterprise features

## Integrations inside, and outside Atlassian

Combine data from 15+ product integrations to create a powerful Central Data Hub. Stop jumping from one tool to another changing context, losing productivity, and wasting time. In Dashboard Hub, you can centralize the data from your favorite products into a single reference point, enabling a Single Source of Truth.

Learn more about [available integrations](/cms_trial/space/RDD/146310010/Product+and+data+connections/)

## Data from different/multiple instances in the same dashboard

Unlike the default Jira dashboard that is built to work with the instance where it’s installed, Dashboard Hub connects with both the current instance and several Jira instances. This lets you use dashboards to keep your data centralized.

Create powerful dashboards combining data from different Jira instances where teams can align, stay on the same page, and get the big picture. Ideal for enterprise teams and organizations planning to migrate.

This lets you use dashboards to centralize your data and grant your team a bird’s eye view.

## Share dashboards externally with secure passwords

Jira doesn’t allow sharing dashboards externally (with users that don’t have access to your Jira instance). With Dashboard Hub, you can expand in:

- The data you report on.
- Who sees that data.
- The efficiency/transparency of your reporting.
- Security.

Dashboard Hub allows sharing dashboards with external stakeholders securely with strong **passwords**. No other data from your account is compromised.

Learn more about [public sharing](/cms_trial/space/RDD/146310576/Share+a+dashboard+with+a+public+link/)

## Advanced permissions

Organizations may want to limit access to specific information for many different reasons. Dashboard Hub allows users to create several layers of permissions to ensure absolute control over who sees what.

Learn more about [dashboard permissions](/cms_trial/space/RDD/146309693/Dashboard+permissions/)

## Custom domains

Dashboard Hub Pro supports Jira and Confluence [custom domains](https://support.atlassian.com/organization-administration/docs/add-a-custom-domain/).

Using custom domains in Jira and Confluence ultimately helps create a more integrated, professional, and user-friendly experience for your team and stakeholders.

Custom domains are available with a Jira Premium, Confluence Premium, or a Jira Service Management Standard plan.
