# Datasources

A datasource is the location and connection method that a gadget uses to pull information into a dashboard.

It consists of three core components:

- **Data host:** The specific instance or application where the data lives, for example, a Jira Cloud instance, a Confluence space, or a Big Picture or GitHub project.
- **Connection method:** The technical link used to access that data, such as a **Connector App** (for Atlassian-to-Atlassian links) or an **API Token/OAuth** (for third-party or remote links).
- **The Authentication/Permissions:** The set of credentials that determines what data the gadget is authorized to see and display.
