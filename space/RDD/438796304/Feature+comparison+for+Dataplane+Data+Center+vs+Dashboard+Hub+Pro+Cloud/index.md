# Feature comparison for Dataplane Data Center vs Dashboard Hub Pro Cloud

This page compares Dataplane Reports Data Center features and Dashboard Hub Cloud features.

Dataplane Reports is not available for Cloud, but now you can migrate your Dataplane Reports Data Center to the Cloud using Dashboard Hub Pro. You can start a [free trial of Dashboard Hub](https://marketplace.atlassian.com/apps/1223898/dashboard-hub-pro-charts-reports-time-in-status-for-jira?tab=overview&hosting=cloud) from the Atlassian marketplace.

## Dashboard Hub Pro

Dashboard Hub Pro is a reporting app that offers custom chart creation, secure external sharing, nearly 100 metrics and indicators, dynamic filtering, and more.

Due to its high compatibility with Dataplane, we’re adding Dataplane’s best features to Dashboard Hub Pro to give you a Dataplane Reports-compatible Cloud solution. We’ve also enabled the [automatic migration using Atlassian’s free Jira Cloud Migration Assistant](https://apps.appf.re/dh/demo/dataplane-migration).
