# XKCD list of comics

## Overview

Shows a list of comics from the provided variable content.

### Features

- Load data from xkcd api datasource unneeded.
- Use initial variables to input data to the report: comics with a list of numbers to show. VARIABLE required.
- Reuse styles using stylesheets.
- Some advanced layout (using standard CSS flex layout).
