# Release notes 12 November 2026

**Release date**: November 12, 2026

This page outlines the updates included in the latest release of the Dashboard Hub family of apps.

## Enhancements

## Improved datasource token management

Administrators can now revoke or rotate stored datasource tokens without deleting the datasource record. This gives you more control over stored credentials and supports a faster response if a token is compromised.

---

## Bug fixes

The following bugs are fixed in this release:

- **JCMA migrations from Dataplane to Dashboard**

  - Fixed migrations failing for gadgets owned by unlicensed Jira users, improved error reporting, and reduced redundant Jira API calls.
  - Fixed migration failures that prevented reports with certain JQL filters from importing and stopped empty valid reports from being incorrectly marked as invalid.
