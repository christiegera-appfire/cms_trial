# Comala Document Management

Dashboard Hub and Comala Document Management work together to provide a robust system for tracking and managing documents within Confluence. With Dashboard Hub’s [Document Workflow Custom Charts gadget](/cms_trial/space/RDD/874905671/Document+Workflow+Custom+Charts/), users can visualize key workflow metrics from Comala workflows, such as approval statuses, document lifecycles, and transitions. This integration supports [**CQL filtering**](/cms_trial/space/RDD/874905671/Document+Workflow+Custom+Charts/), enabling you to create targeted dashboards that track real-time compliance and team performance.

By enhancing visibility across workflows, teams can make data-driven decisions more efficiently.

To use the Document Workflow Custom Charts gadget, you need to be using Comala Document Management (CDM), a Data Center app. If you want to integrate data from Comala Document Management Cloud, you will need to use our [Custom Reports](/cms_trial/space/RDD/1529219266/Custom+Reports+-+REST+API+integration/).
