# Metal price API

## Overview

Display a table from the metal price API.

### Features:

- Load data from the metal price api datasource unneeded.
- Use initial variables to input data into the report.
- Reuse styles using stylesheets.
- Perform complex calculations on the fly to show live results.
- Some advanced layout (using standard CSS flex layout).
