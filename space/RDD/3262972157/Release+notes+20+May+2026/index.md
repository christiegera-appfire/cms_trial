# Release notes 20 May 2026

**Release date**: May 20, 2026

**Version**: `5.2.1`

This page outlines the updates included in the 5.2.1 release of the Dashboard Hub family of apps.

---

## Breaking changes

We will soon introduce a change to the permissions scope to support the upcoming release of the dashboard subscriptions feature. This scope will allow us to view user email addresses strictly to send snapshot notifications through the subscriptions feature. A manual update for the app will be required. You don’t need to do anything before the feature release date. To learn more about the upcoming change, see the [Breaking changes](/cms_trial/space/RDD/3262939446/Breaking+changes/) page.

Version 5.2.1 includes the mechanism to announce this change in the app.

## Bug fixes

The following bug is fixed in this release:

**Sprint Goals gadget**: Resolved an issue that caused an error with the gadget when used in a native Jira dashboard.
