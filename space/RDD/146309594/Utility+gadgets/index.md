# Utility gadgets

## Description

Utility gadgets don’t require a datasource and can be used in the context of any dashboard.

- [Rich Text](/cms_trial/space/RDD/146309606/Rich+Text/): Add a description or summary for dashboard contents, or offer guidance on how to use the dashboard.
- [Weather Forecast](/cms_trial/space/RDD/146309418/Weather+Forecast/): Share current weather for local or remote teams.
- [External Page](/cms_trial/space/RDD/1209073695/External+Page/): Add a URL to embed an external page in an iFrame, providing quick access to external websites without leaving the dashboard.
