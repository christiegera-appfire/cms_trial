# Add and configure gadgets

## Overview

Gadgets are the main components of a dashboard and allow you to display information using the best visual representation.

The common elements to all gadgets are:

- **Name**. You describe the function of the gadget so that everyone understands it. Be precise and concise, and not too verbose. When you connect to different Jira instances, also indicate the datasource.
- **Datasource**. This is the source of truth, the origin of the data. Review [Learn about datasources](/cms_trial/space/RDD/146309943/Learn+about+datasources/).

## How to add gadgets

To add gadgets, you have to be in **Edit** mode.  
To enter Edit mode, click **Edit** in the top right navigation bar: new controls are displayed in the middle of the top navigation bar.

1. Click ➕ Add gadget button to open the gadgets catalog menu (see [Dashboard gadgets - KPIs and metrics](/cms_trial/space/RDD/146309915/Dashboard+gadgets+-+KPIs+and+metrics/) for a complete list of available gadgets)
2. Access the set of gadgets available for each of the provided integrations (see [Product and data connections](/cms_trial/space/RDD/146310010/Product+and+data+connections/) for a complete list of available integrations), select the one you want to add to the current dashboard.
3. Fill in the configuration settings and click **Add**.

## How to configure gadgets

To configure gadgets, you have to be in **Edit** mode.

To enter Edit mode, click **Edit** in the top right navigation bar

1. Click ⚙️ to open the configuration menu, or click **Config**.
2. Name your gadget.
3. Select a datasource, **default** for the current instance, or any other (see [Add and manage datasources](/cms_trial/space/RDD/146309293/Add+and+manage+datasources/). Depending on the gadget datasource, you see different configuration options. Some of them require you to indicate a project, a board, a sprint, a queue, a time period.

![Dashboard Hub gadget configuration screen](/cms_trial/assets/a0f225db-e057-479d-a83d-07e8ed1f6914.png)

The last option before clicking **Save** is common to all gadgets: “Use this setting to configure empty compatible gadgets”. If you enable this toggle, all the gadgets with a compatible configuration will be configured equally, saving you time.

1. Click **Save**.

## How to arrange gadgets

To arrange gadgets and resize them, you have to be in **Edit** mode.

To enter Edit mode, click **Edit** in the top right navigation bar

- **Drag gadgets to a new location** within the dashboard panel.
- **Resize gadgets to increase or decrease** to fit best in the dashboard layout.
