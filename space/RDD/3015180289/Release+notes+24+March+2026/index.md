# Release notes 24 March 2026

**Release date**: March 24, 2026

Our team is thrilled to announce the latest release of the Dashboard Hub family of apps for Jira and Confluence.

---

## New features

## Worklog Insights gadget

The Worklog Insights gadget helps you understand how work is performed across your Jira spaces. You can segment your data by space, work type, user, resolution, or a custom field. Switch between a detailed table, a pie chart showing how time was distributed, or a bar chart tracking effort over time.

See [Worklog Insights](/cms_trial/space/RDD/2987327745/Worklog+Insights/) to learn more.

## Duplicate slides

You can now duplicate a dashboard slide from the *Slides* menu to create a copy of its layout and gadgets. Instead of rebuilding the same reporting page for every space, build it once, then duplicate and swap the filters. This option is only visible to users with Edit access.

To duplicate a dashboard slide, in Edit view, click **Slides** at the top of the dashboard, then click **Duplicate Slide**.

## Bug fixes

The following bug fixes are included in this release summary:

- Resolved an issue with the Jira Custom Charts gadget where the export to XLSX displayed HTML tags for line breaks in the selected column fields.
- Resolved an issue that prevented dashboard exports to PNG. You can now successfully export Dashboard Hub for Jira dashboards to PNG.
