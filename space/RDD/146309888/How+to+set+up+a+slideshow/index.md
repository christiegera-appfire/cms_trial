# How to set up a slideshow

Share your dashboard panel as set of more than one slide, each one with meaningful metrics and KPIs

## Overview

Dashboard panels are critical to transmitting information to your team. To keep individual panels as clear as possible, avoid overcluttering your dashboards with too many gadgets. When you have a lot of information that you want to share, you can use a slideshow instead. Each slide can be used to display a meaningful metric or KPI.

## Set up a slideshow

To add slides to your dashboard panel, go to your **Dashboard settings** in the top right **…** menu:

1. Select the **Slideshow** tab.
2. Set the **Default time**. This is the default length of time all slides will be displayed on the screen. When the time is up, the slides move to the next one.
3. Click **+ Add Empty Slide** to add more slides to your slideshow. You can set individual time periods for each slide.
4. If you need to remove an individual slide, click the **Delete** button.
5. Click **Save**.

### Reorder slides

To reorder the slides in your dashboard, drag the slide you want to move to your preferred order in the slideshow.

![Dashboard Hub slideshow reorder slides screen](/cms_trial/assets/f7af4d0a-2450-41af-a7f0-b457b0b55385.jpg)

## Duplicate a slide

You can duplicate a dashboard slide from the *Slides* menu to create a copy of its layout and gadgets. Instead of rebuilding the same reporting page for every space, build it once, then duplicate and swap the filters. This option is only visible to users with Edit access.

To duplicate a dashboard slide, in Edit view, click **Slides** at the top of the dashboard, then click **Duplicate Slide**.

## Slideshow mode

When you view a dashboard with more than one slide, a **Play** button appears in the middle of the top navigation bar.

Tables in the JQL Custom Charts gadget auto-scroll when the slideshow is playing, so viewers can see the content without interaction.

Enable automatic table scrolling when the slideshow is in play mode.

This is also the default mode that users see when accessing to a dashboard using a public link (see [Share a dashboard with a public link](/cms_trial/space/RDD/146310576/Share+a+dashboard+with+a+public+link/) to learn how to share a dashboard externally). It’s optimized for large screens or TVs, check [How to set up a wallboard](/cms_trial/space/RDD/146310022/How+to+set+up+a+wallboard/) for further information).
