# Dashboard gadgets - KPIs and metrics

Dashboard Hub provides over 90 gadgets to help you visualize the metrics that matter most to you, your teams, and external stakeholders. This page list all of our gadgets, grouped either by template or source product. To help you find the right gadget fast, have a look at our short gadget finder video, or to learn more about each gadget, see [Product and data connections](/cms_trial/space/RDD/146310010/Product+and+data+connections/).
