# Redirect users and groups

Define rules to filter which dashboard or wiki page is shown to either all users or a specific set of users and/or groups.

![Dashboard Hub Confluence redirect users rule](/cms_trial/assets/88e78442-f764-40e6-997c-489a4895a6e4.png)

## Benefits of redirecting users in Confluence

- **Personalized User Experience**:With user and group redirection, Confluence users are greeted with content that's tailored to their specific needs and responsibilities. Ensure users see the most relevant content upon login.
- **Increased Productivity**:By automatically directing users and groups to the appropriate dashboards or wiki pages, Dashboard Hub streamlines access to critical information. This helps users get to work faster, reduces distractions, and improves overall productivity as they can immediately access the resources they require.
- **Improved Knowledge Sharing**:User and group redirection promotes knowledge sharing and collaboration. Teams can be directed to their respective collaborative spaces or pages, ensuring that they are always up to date with the latest information and can easily contribute their insights, fostering a culture of knowledge sharing within the organization.

## How to start

Only Admins can create filter rules:

1. Go to **Dashboard Hub configuration**, in the global admin section.
2. Navigate to **Browse** > **Confluence Admin** > **Dashboard Hub** > **Dashboard Filter Rules**.
3. Start adding rules. Select the **Priority**, the **Content**, and the **Users** you want to redirect for each rule.

Learn more about the process of creating Filter Rules for Redirection in our [documentation](/cms_trial/space/RDD/146309478/Filter+Rules%3A+Display+Dashboards+by+Redirecting+Users+and%2For+Groups/).
