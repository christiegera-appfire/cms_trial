# Add and manage datasources

## Overview

After learning about datasources in [Learn about datasources](/cms_trial/space/RDD/146309943/Learn+about+datasources/), we are going to see how to add, configure and update them. We already discovered that these components are in charge of securely connect our instance with the tools and services where we will be mining our data from. Check [Product and data connections](/cms_trial/space/RDD/146310010/Product+and+data+connections/) to discover the full catalog of apps and tools that Dashboard Hub can be integrated with.

## Default datasource

The **default** datasource is called “This Jira/Confluence/Bitbucket instance”, which is the instance where the app is installed, this needs **no configuration**. You can select it right after installing the app.

## Add datasources

In the main dashboard view, access to the dashboard actions in the “**…**” menu, in the right top navigation bar. Select **Add datasource** and you’ll be able to select among all the available source products.

![Dashboard Hub Add datasource dialog](/cms_trial/assets/17dbea1b-9590-4c1a-a07c-c8f48e86bf6d.png)

The instructions for connecting to the different products are detailed on the next screen. See [Product and data connections](/cms_trial/space/RDD/146310010/Product+and+data+connections/) for more information on datasource types.

## Manage datasources

Access to the dashboard actions in the “**…**” menu, in the right top navigation bar. Select **Manage datasources** and you’ll have access to all the datasources available to the whole organization and your private datasources.

The Actions “**…**” menu displays options to delete and update the corresponding datasource.
