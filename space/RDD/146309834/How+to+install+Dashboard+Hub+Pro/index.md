# How to install Dashboard Hub Pro

Learn how to install Dashboard Hub Pro

## Overview

This page provides instructions for installing Dashboard Hub Pro from the *Apps* page in Jira Cloud.

## How to install

1. Log in to your Jira instance as an admin.
2. In the left sidebar, select **Apps** > **Explore more apps**.
3. Search for Dashboard Hub Pro, then select the app in the search results.
4. In the Marketplace listing, click **Try it free** to download and install the app.
5. In the installation confirmation message, click **Manage app**.
6. Click **Get started** to open Dashboard Hub.
