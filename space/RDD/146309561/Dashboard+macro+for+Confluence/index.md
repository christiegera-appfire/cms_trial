# Dashboard macro for Confluence

## Overview

A macro for Confluence that lets you insert a whole dashboard, so your reports look better than ever. The *Dashboard Hub dashboard* macro adds reporting capabilities to your Confluence pages by:

- Inserting any existing dashboard
- Allowing the creation of a new dashboard
- Enjoying the integration of metrics from several products: Confluence, Jira Work Management, Jira Software, Jira Service Management, Insight, Bitbucket, Opsgenie, StatusPage, Time to SLA, monday.com, Projectrak (by DEISER)…
- Displaying animated slideshows

## Basic use

To add a macro to your page:

1. In the editor toolbar in Confluence, click **Insert**.
2. Select the *Dashboard Hub dashboard* macro from the list of macros.
3. Select the required dashboard from the list that displays or create a new one.
4. Click **Add**.

Shortcuts to display the same list you see by clicking insert in the editor toolbar:

**Cloud**: Type / on the page

**Data Center**: Type { on the page

|  |  |
| --- | --- |
| Selected from the macro browser | *Dashboard Hub dashboard* |
| Markup shortcut | `/dashboard hub dashboard` |

![Dashboard Hub Dashboard macro for Confluence dashboard preview](/cms_trial/assets/3d629da0-bca7-40da-a73c-7d40107b7cb4.jpg)

- **Select dashboard**: Choose one of the existing dashboards in your instance.
- **Create dashboard**: Create a dashboard either using one of the provided templates, or from scratch.

Either of the two options allows the edition of that dashboard to add or remove metrics or charts.

![Dashboard Hub Dashboard macro for Confluence dashboard preview](/cms_trial/assets/97262e41-40f6-466c-b05d-ca98e7b3dc9d.jpg)

## Slideshow

To activate the slideshow mode, hover over the top of the dashboard and click the play button. The slides will change automatically based on the dashboard's slideshow configuration.

The slideshow mode presents the slides of a dashboard in a sequence that changes based on the intervals set in the dashboard settings. Read [How to set up a slideshow](/cms_trial/space/RDD/146309888/How+to+set+up+a+slideshow/) for more info.
