# Simple pie chart: random users per country

## Overview

Use the **Simple Pie Chart** gadget for demo purposes based on this user api. `https://tinyurl.com/mw23fjxx`

Display a pie chart with the count of users per country from the api results.

## Features

- Load from a simple rest api datasource unneeded.
- Process api results with JSON path to transform and enhance results.
- Render a pie chart.

## Setup

### Add the Custom Reports gadget

1. Navigate to your **Dashboard Hub** app.
2. If you have not created a dashboard,

   1. Click the dashboard dropdown in the left corner or in the [Blue elipse icon] action menu in the right corner, and select **Create dashboard.**
   2. Name your dashboard, and click **Create**.
   3. Click **Add Gadget.**
3. If you already have a dashboard created, click **Edit.**
4. Click **Add Gadget**.
5. Navigate to the **Custom Reports** section in the left side navigation panel.
6. Locate the **pie chart** gadget, click **Add,** and click **Open Editor**.
