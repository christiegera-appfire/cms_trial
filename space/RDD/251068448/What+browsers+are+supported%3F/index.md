# What browsers are supported?

## Overview

This page describes the supported browsers for the Dashboard Hub family of products.

It's possible that our products work with some unsupported browsers. However, we don’t prioritize issues related to errors related to unsupported browsers.

| Desktop |  |
| --- | --- |
| Microsoft(1) Edge | Latest stable version supported |
| Mozilla Firefox (all platforms) | Latest stable version supported |
| Google Chrome (Windows and Mac)(2) | Latest stable version supported |
| Safari (Mac) | Latest stable version on latest OS release supported |

**Notes**

1. Internet Explorer 11 is no longer supported.
2. Chrome doesn't have WEBDAV / plugin support.

A minimum screen resolution of 1024x768 is needed to render all web elements correctly.
