# Restrict users to access dashboards with global restrictions

To avoid the usage of Dashboard Hub Pro among some users and groups, admins can restrict access to the product. However, users without access will still be able to see dashboards shared with [public links](/cms_trial/space/RDD/146310576/Share+a+dashboard+with+a+public+link/).

Learn more about [Global Access Restrictions](/cms_trial/space/RDD/146309685/Manage+Global+Access+Restrictions/).
