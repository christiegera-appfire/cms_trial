# Use $initial and Paramtext to add prompts in a report

## Overview

This video explains how `$intital` and `paramtext` can be used to customize the results from an API call. For example, giving the report user access to customize query param values for that particular API.

- `$initial` provides input values to templates. Use it for parameterization.
- `paramtext` is a runtime node that modifies REST calls based on user input. Use it for interactive filtering at report runtime.
