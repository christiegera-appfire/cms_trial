# Gadget macro for Confluence

## Overview

Dashboard Hub's gadget macro for Confluence lets you insert an individual gadget in your pages, so your reports look better than ever. For example, insert a chart, metric, or indicator. The *Dashboard Hub gadget* macro adds reporting capabilities to your Confluence pages by:

- Inserting any gadget
- Enjoying the integration of metrics from several products: Confluence, Jira Work Management, Jira Software, Jira Service Management, Insight, Bitbucket, Opsgenie, StatusPage, Time to SLA, monday.com, and Projectrak (by DEISER).

![Dashboard Hub gadget macro embedded in a Confluence page with JQL Custom Charts](/cms_trial/assets/f9a03560-eba8-4dcb-bdde-fcf61e3acdd2.jpg)

## How to add the Dashboard Hub gadget macro

To add the macro to your page:

1. From the editor toolbar, select **Insert**.
2. Select the *Dashboard Hub gadget* macro from the list.
3. Select **Insert**.

|  |  |
| --- | --- |
| Selected from the macro browser | *Dashboard Hub gadget* |
| Markup shortcut (old editor) | *{dashboard-hub-gadget-macro}* |

Shortcuts to bring up the same list you'd see by selecting from the toolbar:

**Cloud**: Type / on the page

**Data Center**: Type { on the page
