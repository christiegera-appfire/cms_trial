# Enterprise-Ready features

## Unlimited horizontal scalability

Our dashboards allow connection to several different external instances in a single dashboard. This means you can display information from several Jira/Confluence/Bitbucket/monday.com instances at the same time by adding a datasource for each of those instances.

Atlassian regularly increases the user limits on its Cloud products, but these limits can still be overcome thanks to its unlimited horizontal scale for Cloud Enterprise clients.

## Hybrid dashboards

Ease your migration journey using hybrid dashboards. Display data from Server, Data Center, or Cloud instances equally. This means you can combine and centralize data from any type of hosting in our dashboards.

See the [Hybrid dashboards](https://roninpixels.atlassian.net/wiki/spaces/RDD/pages/301203814/Hybrid+Dashboards+Data+from+Server+Data+Center+and+Cloud+in+the+same+Dashboard) page to learn more.

## Advanced permissions in dashboards

Advanced permissions grant access to people within your organization in a granular way:

- **Anyone can view and edit**: The dashboard content is accessible to anyone in your Jira or Confluence instance.

- **Anyone can view, some can edit**: Anyone in your Jira or Confluence instance can view the dashboard content, but onlysome users/groupscan edit it.
- **Only specific people can view or edit**: Only selected users/groups in your Jira or Confluence instance can view and/or edit the dashboard content.

Enhance focus and security by restricting access, only allowing viewing and editing to those who require access.

Learn more about the [Advanced permissions in dashboards](/cms_trial/space/RDD/146309693/Dashboard+permissions/).
