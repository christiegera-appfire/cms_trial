# Release Notes 30 January 2025

**Release date**: January 30, 2025

Our team is thrilled to announce the latest release of the Dashboard Hub family of apps for Jira, Confluence, Bitbucket, and [monday.com](http://monday.com).

---

## New features

## **Datasource Viewing Modes**

We’ve introduced **Datasource Viewing Modes** to give users greater flexibility in how data is displayed in gadgets. This feature allows you to control whether data is loaded based on **user credentials, viewer permissions, or dashboard owner access.** Read [more here](/cms_trial/space/RDD/146309943/Learn+about+datasources/).

We’ve introduced **Datasource Allowlist** to give admins greater control over data retrieval sources. Read [more here](/cms_trial/space/RDD/1687716085/Configure+Datasource+Allowlist+Settings/).

## Enhancements

- **Enhanced** **JCMA** **migration** from Dataplane DC to Dashboard Hub Cloud (requires Dataplane 2.17): Migration of native Jira dashboards containing Dataplane Reports gadgets and migration of  report permissions/sharing, including restrictions by Jira project or user group.
- **UX improvements**: New message to avoid losing changes when editing a dashboard before saving it, automatic selection of default datasources, a better isual indicator to reorder or move slides
- **Custom Reports**: Responsive charts, contextual links to documentation, contextual option add datasource
- **Performance improvements**: Optimized slides loading, better handling of too many requests and sessions for open dashboards
- **Improvements for all the Custom Charts** (Confluence, BigPicture, Comala Document Management DC, monday.com): Switch between chart and data view, trend lines and the "Show values" aggregation
- Improved the space handling in DC Confluence macros
- The parent field now displays the key and summary
- New [Manage Datasources](/cms_trial/space/RDD/146309293/Add+and+manage+datasources/) screen

## Bug fixes

The following bugs are fixed in this release:

- A copied Confluence macro reacts to the original macro configuration
- The Sprint blocker gadget DC shows “blocked by” issues
- Issue displaying diacritic marks in tables
- Translation issue in the Time in Status gadget
- On-call Schedules gadget for Opsgenie displays wrong frame when a one day period is selected
- DH Bitbucket error loading
- Confluence Custom Charts gadget error in stacked bar charts
- Jira Custom Charts gadget issue with statuses in pie charts
- Atlassian Assets and Opsgenie datasource issue with permissions
