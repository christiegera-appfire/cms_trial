# Weather Forecast

## Overview

Use the Weather Forecast gadget to display the weather forecast for a specific region in your dashboard.

![Dashboard Hub weather gadget](/cms_trial/assets/09ff17af-2b28-4789-ab34-1d68c4b27f8a.png)

We are using the Weather API from <https://www.meteomatics.com/en/weather-widget/>.

## Configuration

Name your gadget meaningfully, so everyone knows at a glance what it is about and when to use it.

- **City**: Select the city for which you want to display the weather forecast information.
- **Unit**: Select the temperature unit to display; Celsius or Fahrenheit degrees. Celsius degrees are used by default.
- **Format**: Select a horizontal or vertical layout to display your weather data.

Your browser requires internet access to connect to the weather service and display the information.

## Integrations

None required.

## Dashboards

This gadget is not included in any pre-defined dashboard.
