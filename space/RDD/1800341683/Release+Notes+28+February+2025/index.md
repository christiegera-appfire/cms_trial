## Enhancements

## JCMA improvements

Dataplane DC and Dashboard Hub DC provide a migration path to Dashboard Hub Cloud

- JQL gadgets with JQL configuration are now migrated
- Several properties were not imported due to missing data

## Misc

- More clear navigation bar in main dashboards
- The Affected Services field was displayed as non-wrapping in cells leading to table overflow
- The Sprint Health gadget is now multi-sprint
- Improve empty state in the Burndown gadget
- Dilbert gadget unavailable due to a dead API. Please try the daily xkcd comic via Custom Reports instead: [Custom Reports templates](/cms_trial/space/RDD/1568374878/Custom+Reports+templates/) .

---

## Bug fixes

The following bugs are fixed in this release:

- Lead and Cycle Time gadgets individual elements overlapped and some epics were not kept.
- PDF export had issues in light mode
- Confluence Custom Charts with grouped charts and labels could return an error
- The Affected Services field was displayed as non-wrapping in cells leading to table overflow
- Custom charts tables with reduced width are not displayed in Safari
