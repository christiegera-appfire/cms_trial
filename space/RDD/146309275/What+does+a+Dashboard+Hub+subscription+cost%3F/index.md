# What does a Dashboard Hub subscription cost?

## Cloud pricing

Like [Atlassian](https://www.atlassian.com/licensing/confluence#what-does-a-confluence-cloud-standard-subscription-cost), we offer progressive monthly pricing, so we offer volume discounts as you add more users. Each user’s unit price is based on the pricing rate to which the user belongs.
