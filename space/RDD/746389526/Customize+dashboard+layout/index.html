Customize dashboard layout

1 min read

If you find the standard layout on native Jira dashboards limiting or doesn’t meet your organization’s specific needs, Dashboard Hub Pro can help by providing custom layout functionalities.

See the following table to discover how Dashboard Hub Pro overcomes native layout limitations:

Dashboard Hub Pro

Built-in Jira dashboards

The gadgets in this native dashboard are Dashboard Hub gadgets: Dashboard Hub Pro gadgets are compatible with native Jira dashboards.

✅ Gadgets can be placed in any number of columns

✅ Gadgets can be resized to fit your needs.

✅ Gadgets can be arranged in slides for better organization, including slideshow options.

❌ Gadgets can only be placed in a column or two.

❌ Gadgets can only be expanded or collapsed.

❌ Gadgets can’t be organized in slides.

Learn more about how to Create, Edit, Clone, Delete, and Export your dashboard in Dashboard Hub.
