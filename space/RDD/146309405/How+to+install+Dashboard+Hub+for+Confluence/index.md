# How to install Dashboard Hub for Confluence

Learn how to install Dashboard Hub for Confluence

## Overview

This page provides instructions for installing Dashboard Hub for Confluence from the *Confluence Apps* page.

## How to install

1. Log in to your Confluence instance as an admin.
2. In the left sidebar, select **Apps** > **Explore apps**.
3. Search for **Dashboard Hub for Confluence** and select the app in the search results.
4. In the Marketplace listing, click **Try it free**, then follow the steps to install the app.
5. In the confirmation message, click **Manage app**.
6. Click **Get started** to open Dashboard Hub.
