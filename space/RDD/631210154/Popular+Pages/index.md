# Popular Pages

## Popular Pages gadget

Use the Popular Pages gadget to display the most popular pages as a list. It lets you display the same content as shown on the right side of the default dashboard of Confluence.

![Dashboard Hub Popular pages](/cms_trial/assets/62cfa558-3ceb-44d6-bd5d-fbe38c6cc42c.png)

## Configuration

Give your gadget a meaningful name, so it is clear what it does and when to use it.

You can set the maximum number of pages to display on the gadget using the **max results** setting.

- The **maximum number of pages** of results to display.

The Popular Pages gadget is currently available only for Confluence Data Center.
