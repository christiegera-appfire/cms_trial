# How to change a dashboard owner

## Overview

This page explains how to change the owner of a dashboard.

You must be a Jira administrator to change the dashboard owner.

![Dashboard Hub change dashboard owner dialog](/cms_trial/assets/f8540ac8-7308-4e6b-a8ae-ad135a4970d9.png)

When the original dashboard creator isn’t available or no longer with an organization, you can lose the ability to update important dashboards used internally or [shared](/cms_trial/space/RDD/146310576/Share+a+dashboard+with+a+public+link/) with external stakeholders. Administrators can change the owner of any dashboard, even private dashboards:

- Bulk owner change for faster maintenance.
- Search dashboards filtering by text, with public links, by owner, or by deactivated or deleted users.
- Disable public links.
- Sort by title, owner, public link, created, and updated dates.

## Change Dashboard Owner

1. Go to Dashboard Hub App Settings.
2. Select **Change Dashboard Owner**.
3. Select the checkbox next to the dashboard you want to change.
4. Click **Change Owner** in the bottom right corner.

![Change Dashboard Owner Tab](/cms_trial/assets/39f78165-2552-4ce1-b97e-e6ec61b682de.png)

![Dashboard Hub dashboard details with Change owner button](/cms_trial/assets/12381f70-abc4-4f9a-8ff0-badbb12c343c.png)

1. Type the name of the user you would like to make the new owner.
2. Click **Change owner**.

![Dashboard Hub change owner dropdown for selecting a new dashboard owner](/cms_trial/assets/c19ad4b3-2d3a-4f12-9544-6acb301f0342.png)
