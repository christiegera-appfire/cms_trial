# Manage Restrictions on Datasource Creation

## Overview

The **Global Settings** view allows our users to decide which users of the instance can create new datasources in Dashboard Hub.

### Enable Datasource Creation Restrictions

The datasource restrictions must be configured in the Global Settings section. To configure, follow these steps:

1. Select the **More** drop-down.
2. Click **Apps.**
3. Click **Manage your apps.**
4. In the left sidebar, click **Global Settings.**
5. In the *Datasource Restrictions* tab*,*use the toggle to enable **Datasource creation restrictions**.
6. Add users or groups that you want to give permission to create new data sources.

![Dashboard Hub datasource creation restrictions page](/cms_trial/assets/0a31c462-9299-4edc-b7e2-367a2658a1af.png)

If a user doesn’t have permissions to create datasources:

- The **Add datasource** and **Manage datasources** options will appear as disabled from the **Dashboard** drop-down menu.
- The **Add datasource** option is removed from the **datasource selector**.

This ensures that only authorized users can create new datasources.
