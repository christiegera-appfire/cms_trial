# Display data from different instances/accounts in a single dashboard

Unlike the default Jira/monday.com dashboard that is built to work with the instance/account where it’s installed, Dashboard Hub connects with both the current instance as well as several Jira/monday.com instances. This lets you use dashboards to keep your data centralized.

Create powerful dashboards combining data from different Jira instances or monday accounts, where teams can align, stay on the same page, and get the big picture. Ideal for enterprise teams and organizations planning to migrate.

Learn more about [hybrid dashboards](/cms_trial/space/RDD/146310618/Hybrid+hostings+dashboards/).
