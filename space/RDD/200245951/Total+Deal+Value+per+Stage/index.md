# Total Deal Value per Stage

## Overview

A customer relationship management (CRM) system can help identify opportunities for closing more sales. Our sales pipeline consists of multiple stages, and different salespeople have different skills for advancing deals through these stages. By quickly reviewing which stages have higher sales volumes, we can quickly respond and utilize our best skills to take advantage of these opportunities.

This gadget works with monday.com Sales CRM but also with monday.com Work Management if you use the [Basic CRM template](https://monday.com/templates/template/81773/basic-crm)

This gadget displays the total value of deals in each stage and compares it to the previous period.

## Configuration

Name your gadget meaningfully, so everyone knows at a glance what it is about and when to use it. Fill out the rest of the fields as applicable, namely:

- The **datasource**: Indicate the monday.com account where you want to fetch the data from.
- The **workspace** and the **board** where the deals are located. The workspace has to be from monday.com *sales CRM*, and the board *Deals*.
- The **filter** for the board items. You can filter the items on the Deals board using the filter feature; the selected values will be displayed in the chart.

![Dashboard Hub Total Deal Value per Stage filter configuration](/cms_trial/assets/46c09eca-5861-47a5-8100-0cd03a53b7d4.png)

- The **Filter by deal date**, select the period of time where the deals to be displayed occurred.
- Finally, indicate if you want to use the current settings for all the compatible gadgets in the dashboard. This option eases the pain of configuring one by one the rest of the gadgets with the same default configuration
