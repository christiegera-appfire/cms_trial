# Release notes 1 September 2026

**Release date**: September 1, 2026

This page outlines the updates included in the latest release of the Dashboard Hub family of apps.

---

## Enhancements

## UI update

We updated the user interface to include current Atlassian Design System tokens, accessibility improvements, dark mode support, and the latest platform services.

## Time to SLA gadgets

- We added a toggle to the Met vs Breached SLA and Breach Watch gadgets to display only breached SLA items/cycles in the chart or list.
- Time period in Time to SLA gadgets now supporting rolling windows for the last 30, 90, and 365 days.
- Met vs Breached SLA gadget now includes field-based grouping in addition to the day/week/month/quarter/year options.

## Dataplane migrations with JCMA

This release includes multiple updates to improve the overall experience when migrating from Dataplane to Dashboard using JCMA.

---

## Bug fixes

The following bugs are fixed in this release:

- **Progress Tracker gadget**: Fixed an issue where work item icons were not rendered correctly in the gadget.
- **Dataplane migrations to Dashboard Hub with JCMA**: Fixed an issue with JQL time period mappings. Year-to-date boundaries are now preserved in JQL cloud instead of applying a rolling 365-day window.
