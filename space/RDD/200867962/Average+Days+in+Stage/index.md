# Average Days in Stage

## Overview

There are several strategies and best practices for improving our sales pipeline process, including tracking key metrics, prioritizing the most promising leads, and reducing the length of the sales cycle. To maximize the efficiency of our team and resources, it's essential to minimize the time spent in each stage of the pipeline. To do this, we can assign more salespeople, identify bottlenecks, and analyze the root causes of slow-moving deals.

This gadget works with monday.com Sales CRM, but also with monday.com Work Management if you use the [Basic CRM template](https://monday.com/templates/template/81773/basic-crm)

This gadget displays the average number of days that deals remain in each stage and compares it to the previous period.

## Configuration

Name your gadget meaningfully, so everyone knows at a glance what it is about and when to use it. Fill out the rest of the fields as applicable, namely:

- The **datasource**: Indicate the monday.com account where you want to fetch the data from.
- The **workspace** and the **board** where the deals are located. The workspace has to be from monday.com *sales CRM*, and the board *Deals*.
- The **filter** for the board items. You can filter the items of the Deals board using the filter feature; the selected values will be the ones displayed in the chart.

![Dashboard Hub Average Days in Stage filter configuration](/cms_trial/assets/02208b2d-78ad-4be6-939e-ccff3e16234a.png)

- The **Filter by deal date**: Select the period of time during which the deals to be displayed occurred.
- Finally, indicate if you want to use the current settings for all the compatible gadgets in the dashboard. This option eases the pain of configuring one by one the rest of the gadgets with the same default configuration
