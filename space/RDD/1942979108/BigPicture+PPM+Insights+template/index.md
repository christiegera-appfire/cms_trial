# BigPicture PPM Insights template

## Overview

Dashboard Hub can expand your BigPicture portfolio for full visibility and transparency.

- **Advanced insights and full visibility:** Gain critical insights into your project portfolio with BigPicture custom charts.
- **Centralized reporting:** Consolidate reporting by combining BigPicture and Jira data—even across multiple instances—and integrating data from external tools.
- **Streamlined collaboration:** Seamless reporting by sharing reports outside Jira with password-protected links.

See, [Reporting in BigPicture: Dashboard Hub Pro vs. built-in BigPicture reports](/cms_trial/space/RDD/1132953605/Reporting+in+BigPicture%3A+Dashboard+Hub+Pro+vs.+built-in+BigPicture+reports/) to learn more about the benefits of reporting on BigPicture data with Dashboard Hub.

Customize data visualization according to your organization’s unique requirements. This integration is powered by the [***BigPicture Custom Charts***](/cms_trial/space/RDD/629873831/BigPicture+Custom+Charts/) gadget, available in Dashboard Hub. It lets you build flexible, tailored charts using BigPicture data—bringing project portfolio insights right into your Jira dashboards.

## Current integrations

This dashboard template comes with a set of gadgets from different product integrations that you can organize as you see fit: Configure, remove, or add more gadgets. See [Add and configure gadgets](/cms_trial/space/RDD/146310019/Add+and+configure+gadgets/) to learn more.

The only BigPicture gadget used in this dashboard is the [*BigPicture Custom Charts*](/cms_trial/space/RDD/629873831/BigPicture+Custom+Charts/) gadget. This example highlights how a single, flexible gadget can adapt to a wide range of use cases and visualization needs—making it easy to build exactly the reports you want.
