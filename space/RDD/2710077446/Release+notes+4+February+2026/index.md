# Release notes 4 February 2026

**Release date**: February 4, 2026

Our team is thrilled to announce the latest release of the Dashboard Hub family of apps for Jira and Confluence.

## New features

## Dynamic Filter Bar for embedded dashboards in Confluence

You can now apply dynamic filters to dashboards embedded in Confluence pages with a dashboard macro. To learn more about the filtering options, see [Dynamic filters](https://appfire.atlassian.net/wiki/x/rYG4C).

---

## Enhancements

## Statistics shown in status gadgets

You can now configure status-type gadgets to display statistics to users. This applies to the following gadgets: Time in Status, Status Transition Count, Transition Time From Status, and Work Items Entering Status by Date. All applicable statistics are shown to users by default.

![Time in Status gadget with all statistics selected in the configuration page.](/cms_trial/assets/58455f3e-796b-4a63-88ed-9049b9453fb0.png)

## Dark mode

Enhanced dark mode compatibility to support the dark mode option in Confluence and Jira.

## Additional languages added for improved internationalization

We added the following languages to support internationalization of gadget View Mode texts:

- Arabic
- Chinese
- French
- German
- Japanese
- Spanish
- Romanian
- Russian

## Migrations using the Jira Cloud Migration Assistant (JCMA)

This release includes updates to improve the experience of migrating Dashboard Hub Data Center to the Cloud using JCMA.

---

## Bug fixes

The following bug fix is included in this release summary:

- Fixed an issue where dashboard gadgets incorrectly displayed the warning, `This gadget hasn't been configured yet` when a user updated a previously configured gadget.
