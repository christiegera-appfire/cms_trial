# DevOps software team template

## Overview

DevOps is about communication and collaboration between development, IT, and operations teams. At the heart of the DevOps movement are practices like continuous integration and delivery, integration, automation, and deployment. Each of these practices produces outputs that require constant monitoring.

This dashboard groups gadgets to help monitor all the processes involved in the DevOps chain. By combining all the involved tools into a single source of truth, teams can deliver value more quickly and efficiently.

![Dashboard Hub DevOps software team template gadget thumbnail](/cms_trial/assets/3b50e021-fb64-4d37-83bf-6db10af53fb4.jpg)

Transmit to the involved teams information about the last deployments, critical incidents, or who is on-call duty when an alert or a service is down. Combine these gadgets with others from the [Scrum software team template](/cms_trial/space/RDD/146310016/Scrum+software+team+template/) or the [IT Service Management team template](/cms_trial/space/RDD/146309962/IT+Service+Management+team+template/).
