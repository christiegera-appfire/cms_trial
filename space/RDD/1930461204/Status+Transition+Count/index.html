Status Transition Count

3 min read

Overview

Track the number of times issues move into, out of, or between specific statuses over selected dates. Monitor workflow trends and identify bottlenecks.

  • Identifies repeated transitions: Highlights tickets that repeatedly move between statuses, identifying areas for improvement.

  • Improves forecasting: Shows historical patterns to better estimate issue resolution timelines.

  • Supports SLA management: Tracks how often tickets leave and re-enter critical statuses, impacting time-based commitments.

  • Streamlines workflows: Informs data-driven adjustments to reduce unnecessary transitions.

Configure your transitions

Select which status transitions to include in the report.

Using blank fields to track flexible transitions

You can leave the From or To status fields blank to represent any status. This lets you track broader transition patterns without specifying both ends. Leave a field blank by clicking[X icon] in the field box.

Example: → In Progress

Leave the From status blank to track all transitions into In Progress, regardless of the previous status.

Example: To Do →

Leave the To status blank to track all transitions out of To Do, regardless of the next status.

Leaving one end blank lets you measure all transitions from or to a given status.

Report type

Report by issue

Understand individual issues and their status progression through their lifecycle. Select any number of status transitions to display a list of issues with their transition count.

Report by date

Track issue transition counts for each status over a specific period of time (day, week, month, quarter, year). This allows teams to track and analyze status changes across the whole portfolio.

Select any of the four view types: Multi-Line chart, Stacked Area chart, Stacked Bar chart, or Grouped Bar chart.

Switch between chart and table view

A switch in the gadget header lets users choose to display the chart or a table with the underlying data. [table data icon] to switch to the chart view and [chart table icon] to switch to the table view.

This option is available in the gadget’s main view when the dashboard is in view mode.

Configuration

History to retrieve

Enhance the precision of your report by trimming the history of your issues. This lets you filter out historical data within a specified timeframe.

Format

You can display the time in five different formats: day, week, month, quarter, and year.

Measure

Use the cumulative data toggle to show the total number of status transitions over a selected time period.

Show statistics

You can select which statistics to display in the report. All available statistics are shown by default.

Customizations

Custom colors

The color picker lets you select the color for each segment or value using hexadecimal code, RGB, or our predefined 24-color palette (selected for optimal contrast and tone).

Hide segments

When you click the 👁 eye icon, the corresponding segment is hidden (or shown) in the chart.

Reorder segments

Drag and drop any segment or value from the six dots on the left side of the segments and move it upwards or downwards to the correct place, and the chart will be updated accordingly.

Dashboards

This gadget is not included in any pre-defined dashboard.
