# Github user repos

## Overview

Shows the logged user’s GitHub private repositories.

### Features

- Load from Github authenticated rest api datasource required.

  ![Dashboard Hub GitHub user repositories datasource](/cms_trial/assets/e31705ad-da91-4dc1-9721-88f723ab6880.png)
- Reuse styles using stylesheets.
- Render a list of cards with custom view.
