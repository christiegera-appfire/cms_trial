# Advanced pie chart: random users per country with colors

## Overview

Advanced pie chart for demo purposes based on the user api, `https://tinyurl.com/mw23fjxx`, and colors from <https://www.thecolorapi.com/>.

Based on the API results, this template displays a pie chart showing the number of users per country.

## Features

- Load data from 2 different APIs to work together datasource unneeded.
- Process api results with JSON path to transform and enhance results.
- Render a piechart.

## Setup

1. Click **Add gadget.**
2. In the side navigation bar, select **Custom Reports**.
3. Select **Advanced pie chart**.

See [Custom report example](/cms_trial/space/RDD/2110030119/Custom+report+example/) a video walkthrough for how to customize your reports.
