# Jira licenses info

## Overview

Display a Jira issue table with the add-ons installed and their license status.

## Features

- Load from a Jira datasource: datasource required.
- Render a table.
- Customize certain cells to render some flexible representation (name column).

## Setup

1. Add datasource. See [Configure a REST API datasource for Custom Reports](/cms_trial/space/RDD/1550352515/Configure+a+REST+API+datasource+for+Custom+Reports/).
2. Click **Add Gadget**.
3. Select **Custom Reports** in the side navigation.
4. Select **Jira license table**.

See [Custom report example](/cms_trial/space/RDD/2110030119/Custom+report+example/) for a video walkthrough of how to customize your report.
