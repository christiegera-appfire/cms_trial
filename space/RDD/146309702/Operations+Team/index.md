# Operations Team

## Overview

This gadget displays the members of a specific response team together with their roles.

![Dashboard Hub Operations Team](/cms_trial/assets/4d952732-7e4f-473f-8e72-27cfcd160cd9.png)

## Configuration

Name your gadget meaningfully, so everyone knows at a glance what it is about and when to use it. Fill out the rest of the fields as applicable, namely:

- The **datasource**, select an Opsgenie datasource (see [Add and manage datasources](/cms_trial/space/RDD/146309293/Add+and+manage+datasources/)).
- Select the **team** you want to show the members from.
- Finally, indicate if you want to use the current settings for all the compatible gadgets in the dashboard. This option eases the pain of configuring each of the remaining gadgets individually with the same default configuration.
