# BigPicture template configuration

## Overview

This template requires an initial configuration that will be shared by all [BigPicture Custom Charts](/cms_trial/space/RDD/629873831/BigPicture+Custom+Charts/) created with it. This configuration consists of the datasource and the selection and filtering of boxes.

## Add BigPicture template

Open your Jira dashboard.

1. Open Dashboard Hub.
2. Select **Create dashboard.**
3. Click **Start from a template** under **Get started.**
4. Select the **BigPicture PPM Insights** template.
5. Open the **Select datasource** dropdown and select the data source that best fits your reporting needs.

See, [Add and manage datasources](/cms_trial/space/RDD/146309293/Add+and+manage+datasources/).

1. Click the **Select and filter your boxes** dropdown to select and filter the scope of your data.
2. Click **Apply.**
3. Optional: Use the **Type**, **Status**, and **Filter by dates** dropdowns to refine the displayed data.
4. Click **Apply.**
5. Click **Save.**

See, [BigPicture Custom Charts](/cms_trial/space/RDD/629873831/BigPicture+Custom+Charts/) for more details on further configuration.
