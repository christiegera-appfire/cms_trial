# Jira table

## Overview

Display a Jira issue table for demo purposes, showing the relevant information from the selected project.

## Features

- Requires a variable **project** with the project key to load VARIABLE required.
- Load from a Jira datasource datasource required.
- Render a table.
- Customize certain cells to render some flexible representation (name column).

## Setup

1. Add a datasource. See: [Configure a REST API datasource for Custom Reports](/cms_trial/space/RDD/1550352515/Configure+a+REST+API+datasource+for+Custom+Reports/).
2. Click **Add gadget**.
3. In the side navigation, click **Custom Reports**.
4. Select **Jira Table**.

See [Custom report example](/cms_trial/space/RDD/2110030119/Custom+report+example/) for a video walkthrough on how to customize your report.
