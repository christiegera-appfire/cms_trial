# Sprint Goals

## Overview

The sprint goal is probably the most important aspect to consider in a sprint. It is the main reason the team works together during the sprint length: A commonly agreed outcome of the iteration, and how the planned work provides business value.

This gadget displays the sprint goal, a lighthouse guiding the team to focus on getting their goal.

![Dashboard Hub sprint goals gadget](/cms_trial/assets/4fba5e6c-7789-4279-a67b-ef39f56f09f8.png)![Dashboard Hub sprint goals future sprint](/cms_trial/assets/c0e8142a-a2ce-4509-96d1-63fd22267f5c.png)

Sprints in Jira Software have a field to describe the sprint goal, which only accepts plain text. If your team works with several sprint goals to make sure all stakeholders are in the same page, then, add a sprint goal per line:

- Starting by \* will render the current number of the goal (1)
- Starting by (/) will render the green ticket ✅, when the goal was met
- Starting by (x) will render the red cross ❌, when the goal was not met

![Dashboard Hub sprint goals format](/cms_trial/assets/b2adb3ec-6a4d-4dd1-8224-9a13f5cfb96a.png)

## Configuration

Name your gadget meaningfully, so everyone knows at a glance what it is about and when to use it. Fill out the rest of the fields as applicable, namely:

- The **datasource**, where **Current** indicates the Jira instance where the app is installed.
- Getting issues by (active or future sprints, but parallel sprints are not supported yet):

  - Boards. The **project** and the **board** where the sprint is.
  - Sprints. Just select the **sprint**.
- Finally, indicate if you want to use the current settings for all the compatible gadgets in the dashboard. This option eases the pain of configuring one by one the rest of the gadgets with the same default configuration
