# Display a calendar in a dashboard

Use the [External Page](/cms_trial/space/RDD/1209073695/External+Page/) gadget to display a calendar by inserting a URL to embed a webpage in a dashboard. It uses an iframe for this purpose.

![Dashboard Hub calendar gadget added to a dashboard](/cms_trial/assets/020407b7-022b-407f-a11f-a3d5ef9e2de0.png)

## How to display a calendar in a dashboard

1. Click **Add gadget**.
2. Select the **External Page** gadget.

   ![Dashboard Hub calendar gadget configuration screen](/cms_trial/assets/35c1c6bf-018c-48f1-9a85-4deb1969eb11.png)
3. Name your gadget.
4. Insert the URL for the calendar you would like to display.

Make sure that you are using the correct URL. It should be the public URL that can most likely be found in your calendar app settings.
