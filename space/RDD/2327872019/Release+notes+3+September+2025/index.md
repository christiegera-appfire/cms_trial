## Enhancements

## Miscellaneous improvements

- Improved experience with horizontal tables and charts
- Custom Portal: when a user click on a chart from the Customer Portal UI, it will now display only the related requests from the chart and not the entire list or requests
- Support for global templates: users can now store their own reports as templates, enabling them to select them later for reuse or modification
- Connect data from a Google spreadsheet in minutes, using global templates

## Bug fixes

The following bugs are fixed in this release:

- Jira Custom Charts: grouping dates by week now start the week in the day configured in Jira as first day
- Now when a datasource is reopened for editing, all previously configured query parameters and headers are displayed in the UI
- The assets gadget (AQL Search) supports viewing multiple people in a single column
- Jira Custom Charts: the custom field “issueFunction” from ScriptRunner plugin, is now hidden from the fields selector
- Jira Custom Charts Gadget: fixed rounding error
- SLAByField gadget: issue with field names fixed
- Jira Custom Charts: cumulative timetracking fields are now showing their values in human readable representation
