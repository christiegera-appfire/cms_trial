# Add advanced gadgets to native Jira dashboards

In Dashboard Hub Pro, you create and work on dashboards in a separate area in the *Apps* section, not in the *Dashboards* section (where native Jira dashboards are located). However, if you still need to work with native dashboards, all Dashboard Hub Pro gadgets can be added to native Jira dashboards.

Upgrade your native Jira dashboards with nearly 100 powerful metrics and 10 product integrations.

Learn more about adding Dashboard Hub Pro gadgets into native dashboards in the [documentation](/cms_trial/space/RDD/146309298/Jira+dashboards%3A+native+gadgets+and+product+integrations/) or in this [blog post](https://hub.appfire.com/business-intelligence-and-reporting/dashboard-hubs-70-original-gadgets-can-now-be-added-to-native-jira-dashboards/).
