# Manage Data Refresh - Client Cache

The client cache introduces a few changes that users will notice, alongside improved perceived performance. Below are the key updates:

### Gadget Refresh button

A new button has been added to each gadget, allowing users to refresh gadget data manually. This feature is particularly useful when working with dynamic data that requires frequent updates.

Hovering over the refresh button displays a tooltip that indicates how old the currently displayed data is. This helps users quickly assess **whether a data refresh is necessary** without further interacting with the gadget.

![Dashboard Hub client cache data refresh management settings](/cms_trial/assets/9fb9c9e6-e0d9-4f99-adfc-d4d61daae770.png)

### Dashboard Actions: Refresh All Gadgets

Users can now refresh all gadgets on the dashboard using a new option in the dashboard actions menu.

**Pro Tip:** Use the ‘Refresh Dashboard’ button sparingly! Frequent refreshing can impact performance, so it’s best to use it only when necessary to get the latest data.

![Dashboard Hub Manage Data Refresh Client Cache dashboard preview](/cms_trial/assets/eb7b0067-26e0-4748-9436-bd6a0660a2f0.jpg)

### Browser refresh update

Refreshing the browser no longer fetches fresh data, as was previously mentioned under the Admin > Global Settings in the **Performance Options** tab.

![Dashboard Hub Manage Data Refresh Client Cache Global settings refresh settings](/cms_trial/assets/021a8d7c-a47d-45fb-9374-f9fe7f14604d.jpg)

Adjusting the refresh time in the global settings is recommended to improve application performance. This advice can be referenced when discussing the new gadget refresh feature.
