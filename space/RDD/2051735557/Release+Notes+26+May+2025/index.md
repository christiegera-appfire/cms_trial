# Release Notes 26 May 2025

**Release date**: May 26, 2025

Our team is thrilled to announce the latest release of the Dashboard Hub family of apps for Jira, Confluence, Bitbucket and monday.com.

## Enhancements

## JCMA: Dataplane to Dashboard Hub

The automatic process through JCMA now migrates Dataplane’s Time from Status to Status reports to Dashboard Hub Cloud.

## Performance Improvements

- Optimization of requests, compression of some API calls, improved fetch strategies.

## Misc

- Update datasources doesn’t require the introduction of tokens each time.
- Better position of the color picker for gadgets with reduced space when opening the configuration.
- Improved explanation for DC admins configuring the Allowlist for datasources.
- Updated some French incorrect translations.

---

## Bug fixes

The following bugs are fixed in this release:

- None segment appeared empty for Assets fields.
- Unable to export large dashboards.
- Gadget titles overlap with charts in native Jira dashboards.
