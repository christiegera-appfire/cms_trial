# Upgrade your Confluence pages with custom chart macros

Level up your Confluence documents with custom dashboard and chart macros that display dynamic and live data.

![Dashboard Hub custom chart macro embedded in a Confluence page](/cms_trial/assets/4072e56f-e98f-409c-8eaf-0c404a8f4590.png)

## Benefits of Custom Chart macros

- **Real-Time Data Visualization:** By embedding custom dashboards and charts, you can showcase real-time data, providing up-to-the-minute insights to your team in Confluence. This ensures that stakeholders always have access to the latest information, enhancing decision-making based on the most current data.
- **Powerful Data Representation:** The charts displayed by the macro are built with the Dashboard Hub app – which means that your documents can be strengthened with nearly 100 powerful metrics, pre-defined templates, custom charts, formula cards, and much more.
- **Automation and Efficiency:** Integrating live data eliminates the need for manual data updates and chart generation. This automation not only saves time but also reduces the risk of data entry errors.

## How to start

1. From a Confluence page, search for the Dashboard Hub macro.
2. Then, you can either select one of your already **existing dashboards** or **create a new one**.
3. When you have selected the dashboard you want to embed, click **Save**.
4. Resize the macro however you prefer to represent it.

We recommend using Confluence layouts to embed the Custom Chart macro in a beautiful way. Learn more about the macro in our [documentation.](/cms_trial/space/RDD/146309561/Dashboard+macro+for+Confluence/)
