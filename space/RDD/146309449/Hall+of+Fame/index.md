# Hall of Fame

## Overview

Use the Hall of Fame gadget to showcase a team’s success. The gadget displays the last successful pipeline events, including tests, deployments, and builds, as well as the team member responsible.

Alternatively, if you want to highlight issues with pipeline events or encourage team accountability, you could use the [Hall of Shame](/cms_trial/space/RDD/146309596/Hall+of+Shame/) gadget.

![Dashboard Hub Hall of Fame](/cms_trial/assets/1c3ba0e1-1a05-4d10-8306-6bc4ccc6631c.png)

## Configuration

Name your gadget meaningfully, so everyone knows at a glance what it is about and when to use it. Fill out the rest of the fields as applicable, namely:

- The **datasource** to connect to Bitbucket Pipelines. See [Integrations with Bitbucket](/cms_trial/space/RDD/2381316116/Integration+with+Bitbucket/) to learn more.
- The **repository** where your continuous integration and delivery pipelines run.
- Finally, indicate if you want to use the current settings for all the compatible gadgets in the dashboard. This option eases the pain of configuring one by one the rest of the gadgets with the same default configuration
