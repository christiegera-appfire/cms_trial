# External Page

## Overview

This gadget allows users to insert a URL to embed a webpage in a dashboard. It uses an iframe for this purpose. This gadget is useful for integrating external web content directly into dashboards, providing quick access to external websites without leaving the dashboard.

![Dashboard Hub External Page gadget configuration](/cms_trial/assets/d104558c-008c-4893-bc46-7d06b5f81a79.png)

## Configuration

1. Enter a **Name** for the gadget.
2. Enter the URL for the external page you’d like to include on your dashboard and click **Save**.

![Dashboard Hub External Page gadget preview](/cms_trial/assets/400a65f1-987b-4a97-8865-ff654df31520.png)

**Security Compliance**  
This gadget automatically blocks URLs that restrict embedding due to security settings, for example, X-Frame-Options or Content-Security-Policy headers.
