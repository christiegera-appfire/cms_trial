# Dashboard Hub

## Welcome to Dashboard Hub

Dashboard Hub is a visualization tool and a central hub for your organization's data. Create and share powerful dashboards and charts that display metrics and key performance indicators (KPIs) using gadgets. This lets teams centralize data from different products and instances for a unified view.

## Key features

- Dashboard Hub is a visualization tool for an organization's data, metrics, and key performance indicators (KPIs).
- Gadgets are the individual components within a dashboard that display data fetched from a datasource.
- To help you get started, Dashboard Hub offers pre-defined dashboard templates.
- Integrate data from various tools and services.
- Dashboards can be shared internally within the organization or externally with a public link.
- Dashboard Hub provides advanced options to restrict access and control who can view and/or edit dashboards within the organization.
