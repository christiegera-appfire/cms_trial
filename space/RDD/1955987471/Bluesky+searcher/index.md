# Bluesky searcher

## Overview

The Bluesky search tool displays results in a card list.

### Features:

- Load data from bluesky api datasource unneeded.
- Display a resizable card list.
- Reuse styles using stylesheets.
- Customize external svgs for icons.
- Some advanced layout (using standard CSS flex layout).
