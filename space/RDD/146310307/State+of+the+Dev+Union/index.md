# State of the Dev Union

## Overview

This gadget displays the number of developers involved in your repositories, the number of repositories they work on, and the PRs merged.

![Dashboard Hub State of the Dev Union](/cms_trial/assets/ec4d0b2b-a3bf-4e42-8e90-4fb4e93824b1.png)

## Configuration

Name your gadget meaningfully, so everyone knows at a glance what it is about and when to use it. Fill out the rest of the fields as applicable, namely:

- The **datasource**, select a Bitbucket datasource (see [Add and manage datasources](/cms_trial/space/RDD/146309293/Add+and+manage+datasources/)).
- Finally, indicate if you want to use the current settings for all the compatible gadgets in the dashboard. This option eases the pain of configuring one by one the rest of the gadgets with the same default configuration.

## Dashboards

This gadget appears in the following dashboard: [DevOps software team template](/cms_trial/space/RDD/146309250/DevOps+software+team+template/).
