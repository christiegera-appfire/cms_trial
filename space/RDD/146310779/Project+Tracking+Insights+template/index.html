Project Tracking Insights template

2 min read

Overview

This dashboard template marks the first collaboration with DEISER and their innovative app, Projectrak. Projectrak is a powerful project tracking solution for Jira available in the Atlassian Marketplace. It gives your team the ability to add essential project information without any complex configuration, thanks to custom fields at project level. With this project's metadata, you’ll be able to make informed decisions based on the data.

This dashboard provides several gadgets to keep track to multiple projects, get insights on project metrics like time analysis, stakeholders' workload, project timelines, or KPIs.

Project tracking and visual insights are now easier than ever with the Project Custom Charts, so you can create your own charts based on the Project Query Language (PQL), which is like JQL, but for Projectrak. The Timeline allows you to visualize your entire project portfolio at a single glance.

Gadgets

This dashboard template comes with a set of gadgets that you can organize as you see fit: Configure, remove or add more gadgets (see Add and configure gadgets).

PROJECT BY STATUS

Display the percentage of projects per status in a pie chart

PROJECT TIMESHEET

Display the timesheet of a list of projects with their estimated and logged times

PROJECT TIMELINE

Display the timeline of a given set of projects

PROJECT LEADERS WORKLOAD

Display the leaders ranked by the number of projects they are leading

PROJECT STAKEHOLDERS WORKLOAD

Display the stakeholders ranked by the number of projects they are involved in

The following gadget is not included in the dashboard template, but it allows you to create custom charts out of Projectrak data:

PQL CUSTOM CHARTS

Create custom charts based on Projectrak PQL
