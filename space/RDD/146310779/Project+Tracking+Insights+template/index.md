# Project Tracking Insights template

## Overview

This dashboard template marks the first collaboration with [DEISER](https://www.deiser.com/) and their innovative app, [Projectrak](https://marketplace.atlassian.com/apps/1210816/projectrak-project-tracking-for-jira?hosting=cloud&tab=overview). Projectrak is a powerful project tracking solution for Jira available in the Atlassian Marketplace. It gives your team the ability to add essential project information without any complex configuration, thanks to custom fields at project level. With this project's metadata, you’ll be able to make informed decisions based on the data.

This dashboard provides several gadgets to keep track to multiple projects, get insights on project metrics like time analysis, stakeholders' workload, project timelines, or KPIs.

![Dashboard Hub Project Tracking Insights template template preview](/cms_trial/assets/a16f04d1-5a59-41a5-867b-1f5d8b9d18cd.png)

Project tracking and visual insights are now easier than ever with the Project Custom Charts, so you can create your own charts based on the [Project Query Language (PQL)](https://confluence.deiser.com/projectrakcloud/advanced-search-with-pql-project-query-language-110955414.html), which is like JQL, but for Projectrak. The Timeline allows you to visualize your entire project portfolio at a single glance.
