# Sprint Goals - monday.com

## Overview

Why are we doing what we do? Let’s look at the goals for this sprint! The sprint goal is a key element to consider during a sprint because it serves as the **main objective that the team is working towards**. It is a mutually agreed-upon outcome that represents the value that the planned work will bring to the business.

The gadget that displays the sprint goals acts as a beacon, helping the team to stay focused on achieving their goal. It serves as a reminder of the team's purpose and helps to keep everyone on track.

![Dashboard Hub sprint goals](/cms_trial/assets/8d12d0bb-33f3-4dee-b908-317b220faecd.png)

In monday.com dev, the board *Sprints Metadata* contains a column *Sprint Goals*. This column is where teams write their goals per sprint.

![Dashboard Hub sprint goals board](/cms_trial/assets/f19f669b-988d-471d-9556-1151b2f354d0.png)

Write a goal per line with the following syntax:

- Starting by \* will render the current number of the goal (1)
- Starting by (/) will render a green ticket ✅ that is, the goal was met
- Starting by (x) will render a red cross ❌ that is, the goal was not met

![Dashboard Hub sprint goals syntax](/cms_trial/assets/4eb4537c-e15b-41d9-9505-66ecedd0ddf8.png)

## Configuration

Name your gadget meaningfully, so everyone knows at a glance what it is about and when to use it. Fill out the rest of the fields as applicable, namely:

- The **datasource**, indicate the monday.com account where you want to fetch the data from.
- The **workspace** where the sprint goals are located. The workspace has to be from monday.com *dev*, and the board *Sprint Metadata* is required.
- Finally, indicate if you want to use the current settings for all the compatible gadgets in the dashboard. This option eases the pain of configuring one by one the rest of the gadgets with the same default configuration
