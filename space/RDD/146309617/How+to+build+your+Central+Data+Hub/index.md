# How to build your Central Data Hub

## Centralize your data

Wouldn’t it be more convenient and time-saving if you could view and access all of your information in a central location?

Dashboard Hub addresses this by automatically becoming a Central Data Hub. Unlike the default Jira dashboard that is built to work with the instance where it’s installed, Dashboard Hub connects with both the current instance as well as several Jira instances. This lets you use dashboards to keep your data centralized.

## Single reference point

Centralizing key metrics in a single display provides you with a bird’s eye view of what is happening in your organization, plus saves you the inconvenience of jumping between platforms to check on the status of your projects and teams.

Dashboard Hub gives your team a single reference point where they can analyze key statistics and be kept up-to-date on the relevant project information.
