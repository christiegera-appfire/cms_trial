# Use filter rules to redirect users and groups

Define rules to filter which dashboard is shown to either all users or a specific set of users and/or groups:

- Replace the Confluence native dashboard with a custom one defined on a wiki page or by one of the dashboards created in Dashboard Hub.
- Display unique dashboards for each team by defining filter rules for selected users and groups.

Learn more about [Filter Rules](/cms_trial/space/RDD/146309478/Filter+Rules%3A+Display+Dashboards+by+Redirecting+Users+and%2For+Groups/).
