## Platform updates

## New URL format for internal links

Internal links are URLs used to share dashboards within your Jira or Confluence instance with users who have access to it. Due to ongoing changes to Atlassian’s Cloud platform, previously generated internal links to your dashboards no longer work. To support dashboard sharing in the meantime, we have provided a link migration tool to convert internal links to the new format.  
This change does not affect public links, which use a different format.

When a user tries to access a dashboard with an old-format URL, the link migration message displays, with links to go directly to the dashboard and to copy the new URL and manually update it.

![The link migration tool as described on this page.](/cms_trial/assets/22892010-7dd4-4ff9-9c9b-25c52ae20557.png)

To manually update the internal link:

1. Click **Copy URL**.
2. Go to the dashboard in Dashboard Hub.
3. Click **Share Dashboard**.
4. Paste the URL in the **Internal Link** field.

   ![The Share Dashboard internal link input field.](/cms_trial/assets/6f11ba69-44c2-42f4-a9ee-bf7d1eee7a8f.png)
