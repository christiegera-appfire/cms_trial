## Feature management

Navigate to the global settings, to the Dashboard Hub section, and navigate to **Feature Management**.

### Legacy features

#### Jira Custom Charts

Roll back to the legacy version of Jira Custom Charts: As part of the release, we introduced an improved engine for rendering charts. Given the wide range of use cases it supports, we’ve included a toggle that allows you to roll back to the previous version when our support team advises you to do so.
