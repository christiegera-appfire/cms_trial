# Simple table: users

## Overview

Create a **Simple Table** for demo purposes based on the api `https://tinyurl.com/mw23fjxx`.

Display a mix of raw and customized cells to demonstrate rendering custom elements inside a table, such as a formatted name column.

## Features

- Load from a simple public rest api datasource unneeded.
- Render a table.
- Customize certain cells to render some flexible representation (for example, name column).

## Setup

### Add the Custom Reports gadget

1. Navigate to your **Dashboard Hub** app.
2. If you have not created a dashboard,

   1. Click the dashboard dropdown in the left corner or in the [Blue elipse icon] action menu in the right corner, and select **Create dashboard.**
   2. Name your dashboard, and click **Create**.
   3. Click **Add Gadget.**
3. If you already have a dashboard created, click **Edit.**
4. Click **Add Gadget**.
5. Navigate to the **Custom Reports** section in the left side navigation panel.
6. Locate the **Simple Table** gadget, click **Add,** and click **Open Editor**.
