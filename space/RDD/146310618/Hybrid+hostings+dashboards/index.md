# Hybrid hostings dashboards

## Hybrid dashboards

A hybrid dashboard in Dashboard Hub displays data from multiple Jira instances, whether hosted on Jira Data Center or Cloud.

## When to use a hybrid dashboard

### Migration to Cloud

Atlassian announced the end of sales and support of server licenses, increasing the number of organizations making the move to Cloud. Atlassian, Solution Partners, and Marketplace Partners are making efforts to make this journey as smooth as possible.

Companies in this stage can leverage hybrid dashboards to keep track of all their projects and teams from day one.

Are you thinking of moving to cloud? Check out the [Atlassian Migration Program](https://www.atlassian.com/migration/cloud)

### Organizations with hybrid hosting

Not all organizations are moving to cloud; some are taking advantage of the benefits of different types of hosting:

- Key data can be behind their own firewalls in data center instances for increased security. or meeting regulatory requirements for compliance.
- Cloud instances can support environments where scalability is on demand, new features to improve processes are available, or sometimes due to cost concerns.

Follow the video walkthrough to learn how to set up a hybrid dashboard.

## Datasources to create a hybrid dashboard in Jira or Confluence

Creating a hybrid dashboard requires datasources for the different types of hosting, for example, you would use a Jira Cloud datasource to connect to a cloud instance.

1. Select a datasource labelled Cloud, like the *Jira Cloud* datasource type. You can then connect to a cloud instance.
2. Select a datasource labelled Data Center like the *Confluence Server/Data Center* datasource type. You can then connect to a Server or Data Center instance.
