# Deployments

## Overview

No matter if just a few chosen engineers can deploy your code, artifacts or apps, the visibility of each environment’s changes is useful for the whole team.

This gadget displays the current status of the deployment environments of the selected repositories.

## Configuration

Name your gadget meaningfully, so everyone knows at a glance what it is about and when to use it. Fill out the rest of the fields as applicable, namely:

- The **datasource**, select a Bitbucket datasource (see [Add and manage datasources](/cms_trial/space/RDD/146309293/Add+and+manage+datasources/)).
- The **repositories** where your deployment data is located.
- Finally, indicate if you want to use the current settings for all the compatible gadgets in the dashboard. This option eases the pain of configuring each of the remaining gadgets individually with the same default configuration.
