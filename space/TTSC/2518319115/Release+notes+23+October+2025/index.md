# Release notes 23 October 2025

**Release date**: October 23, 2025

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### French translation update

We adjusted the French translation for the term `breached`. The terminology has now been corrected to reflect the proper meaning.

### Filter search improvements

Previously, filter searches in two gadgets and the Reporting section used only partial matches. This often resulted in an unnecessarily high number of returned filters. We fixed this, improving search efficiency and performance.

---

## Bug fixes

The following bugs are fixed in this release:

- Some customers experienced an `Invalid Time Value` error. This issue has been fixed to ensure more reliable time-based operations.
- We addressed an error occurring during permission checks. The fix ensures consistent and accurate permission validation across the app.
