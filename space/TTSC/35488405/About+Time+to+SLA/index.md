## Why choose Time to SLA?

Time to SLA combines simplicity with enterprise-grade flexibility, without the limitations of native Jira SLAs.

- [**Built-in templates**](/cms_trial/space/TTSC/35456108/Get+started+with+Time+to+SLA+for+Cloud/): Get started instantly with ready-made SLA configurations like *Time to resolution*, *Time to first response*, and *Time in progress*.
- **No artificial limits**: Define as many SLAs and SLA goals as you need.
- **Cross-project coverage**: Manage SLAs across multiple projects effortlessly.
- [**Automation-ready**](/cms_trial/space/TTSC/1464075666/Use+SLA+actions+with+Jira+automation/): Trigger Jira automations directly from SLA events for escalations or workflow actions.
- [**Smart notifications**](/cms_trial/space/TTSC/35881090/Actions/): Notify assignees or managers before an SLA breach.
- [**REST API access**](/cms_trial/space/TTSC/36209134/REST+APIs/): Retrieve and manage SLA data programmatically.
- [**Powerful reporting**](/cms_trial/space/TTSC/36012079/Reports/): Track performance with visual reports and dashboard gadgets.

## **Who is it for?**

Time to SLA is designed for any team that manages work in Jira: from IT and support to software delivery and operations.

Time to SLA lets you:

- Start with predefined SLA templates or create an SLA from scratch.
- Apply SLA configurations across Jira projects.
- Define working calendars, holidays, and calendar exceptions.
- Configure start, pause, resume, reset, and stop conditions.
- Configure SLA actions to send email or Slack notifications and to perform supported Jira actions when SLA events occur.
- Display SLA information on Jira work items and, when configured, on linked work items.
- Recalculate SLA data for existing work items.
- Create Summary, Detail, Durations, Status, scheduled, and Executive Reports.
- Retrieve and manage supported Time to SLA data through the REST API.
