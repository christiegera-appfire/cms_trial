# Release notes 20 June 2024

**Release date**: June 20, 2024

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## New features

### Simplified SLA configuration

We’ve made the SLA issue selection process more intuitive. From now on, when defining an SLA, you only need to select the projects to which the SLA will apply. You can further refine the issues by specifying additional details like issue type, request type, assignee, and JQL in the **SLA Goals** step. Look for the **Goal Issues** section to make your selection.

![Time to SLA release notes June 2024 showing SLA chart update](/cms_trial/assets/a7a5c847-b81b-4b78-b33f-8c81074bea0f.png)

![Time to SLA release notes June 2024 showing configuration dialog](/cms_trial/assets/d479e07f-a3b3-4da4-bbca-30eda45dbe10.png)

**Please note:**

- When creating new SLAs, don’t miss the *Goal Issues* section and the *+More* button if you want a more targeted selection. Since we’ve removed the *SLA Context* section, you must refine your issues using the *Goal Issues* section.
- SLAs created using the old interface will function as usual. When you edit them, you’ll see the old interface.
- SLAs created using the old interface (created before June 20) **cannot be cloned**. Please create new ones using the new SLA creation system.

Refer to the related documentation: [**Defining SLAs**](/cms_trial/space/TTSC/35651691/Define+SLAs/), [**Creating SLA Goals**](/cms_trial/space/TTSC/35390901/SLA+goals/)

### Default notifications

We have now automatically enabled email notifications for newly created SLA configurations, effective from June 20. When an SLA is created and starts counting down on an issue, you’ll receive notifications when:

1. **SLA reaches 50% of its duration**
2. **SLA reaches 75% of its duration**

If you wish to change the frequency of these notifications or edit them, follow these steps:

1. Open the **SLAs** page.
2. Select the SLA for which you want to edit notifications.
3. Click **Notifiers**.

   ![Time to SLA release notes June 2024 showing SLA table update](/cms_trial/assets/6d018807-8fab-4e6a-9a77-81b9431c5d88.png)
4. Edit the notification by clicking **Edit**. You can also disable it, or create new notifications by clicking the **+** **Add New SLA Notification** button.

   ![Time to SLA release notes June 2024 showing dashboard gadget update](/cms_trial/assets/26ce2e0b-0972-45c5-ab95-a5301c5fc1a7.png)

Refer to the related documentation: [**Set a Notifier for an SLA**](/cms_trial/space/TTSC/35881090/Actions/)
