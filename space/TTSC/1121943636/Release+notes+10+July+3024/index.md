## Enhancements

### Filter Option for SLA/Assignee Performance Gadget

A highly requested feature to improve user experience and flexibility is now available. Users can now filter issues displayed in the SLA/Assignee Performance gadget to help avoid timeouts.

![Time to SLA release notes July 2024 showing feature configuration](/cms_trial/assets/b526cec9-9103-4a14-a983-9d667716e9c4.png)

**How?**

When adding the **TTS SLA/Assignee Performance Gadget** to your dashboard, a configuration screen will appear. On this screen, you can choose to group issues by SLA or Assignee. Previously, you only could filter issues by SLAs and issue filters. From now on, selecting either option will activate the **Filter** dropdown menu. From the dropdown menu, you can select filters specific to your Jira instance to narrow down the displayed issues based on assignees.

Refer to the related documentation: [SLA/Assignee Performance gadget](/cms_trial/space/TTSC/182780060/SLA%2FAssignee+Performance+gadget/)
