## New features

### Use SLA notifications to trigger Jira automation rules

Introducing the Trigger a Jira Automation Rule feature, now available in Time to SLA! This enhancement allows you to seamlessly connect your SLA notifications with Jira automation rules, enabling powerful workflows to be triggered automatically based on SLA events.

#### Key highlights

- **Easy setup:** Follow our [step-by-step guide](/cms_trial/space/TTSC/1464075666/Use+SLA+actions+with+Jira+automation/) to integrate SLA notifications with Jira automation, using an incoming webhook to trigger rules effortlessly.
