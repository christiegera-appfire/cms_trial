# Release notes 2 October 2025

**Release date**: October 2, 2025

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- We’ve resolved an issue that caused an error when exporting SLAs containing a **Trigger automation rule** notification. The issue was related to a secret value used in the configuration. You can now export SLAs successfully, even when this notification type is included.
- We fixed a problem where group recipients in the notifier were automatically removed if the groups hadn’t fully loaded yet. Group recipients now remain intact once the groups are properly loaded.
- Previously, SLA history showed the goal as 1d 1h instead of 1d when using a calendar set to 00:00–23:59. This issue has been corrected; SLA history now accurately reflects the goal.
