# Release notes April 2024

**Release date**: April 26, 2024

Our team is excited to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in these releases:

April 25, 2024

- Fixed a vulnerability where users with limited permissions could access private project issue information.
- Fixed an issue where the screen would go blank when editing a condition containing a date field.
- Resolved a bug that prevented disabling the `Linked issue SLA` setting in the new SLA view.
- Addressed a network error that caused notification failures.
- Fixed an error that occurred while moving `issueSLA` during JCMA migration.
- Resolved an error encountered while creating SLA configurations due to non-iterable error rules.
- Improved the handling of shared holidays to ensure they are correctly factored into calculation.

April 26, 2024

- Fixed an error that occurred while moving `issueSLA` during JCMA migration.
