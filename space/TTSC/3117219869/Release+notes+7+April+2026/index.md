# Release notes 7 April 2026

**Release date**: April 7, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- We fixed an issue in the Jira Dashboard SLA gadget where links for tickets matching the “Remaining Duration is less than X amount” condition redirected to an invalid address. These links now open the correct list of matching issues.
- We fixed a problem where exporting reports with several thousand issues could load indefinitely after the report was generated. Large report exports now complete as expected.
