# Release notes 10 June 2025

**Release date**: June 10, 2025

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### Pagination added to project list on SLAs page

We implemented pagination for fetching projects on the *SLAs* page. This improves performance and ensures all projects are accessible, even in large Jira instances.

---

## Bug fixes

The following bugs are fixed in this release:

- We fixed an issue where users encountered an `ETIMEDOUT` error during permission checks. Permission checks now complete reliably without timeout errors.
- We updated the logging mechanism to include the user-defined log level when evaluating log level settings. Logs now reflect the correct level as expected.
