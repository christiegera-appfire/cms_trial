# Installation

This page explains how to install Time to SLA on a Jira Cloud site.

## Before you begin

- You need permission to install Marketplace apps on the Jira Cloud site. [Atlassian allows](https://confluence.atlassian.com/adminjiracloud/managing-global-permissions-776636359.html) organization admins and site admins to install and manage Marketplace apps.
- Time to SLA is a paid Marketplace app. You can start a free trial when you install the app. See the [**Time to SLA Marketplace listing**](https://marketplace.atlassian.com/apps/1211843/time-to-sla?hosting=cloud&tab=pricing) for current pricing and trial information.

If you don't have permission to install Marketplace apps, you can request Time to SLA from the Marketplace. Your site administrator must approve the request before the app can be installed.

## Install Time to SLA for Jira Cloud

1. Open [**Time to SLA**](https://marketplace.atlassian.com/apps/1211843/time-to-sla?hosting=cloud&tab=installation&utm_source=chatgpt.com) on the Atlassian Marketplace.
2. Click **Try it free**.
3. Select the Jira Cloud site where you want to install Time to SLA.
4. Click **Review**.
5. Review the app details, then select **Start free trial**.

A confirmation message appears when Time to SLA is installed.

If you open Time to SLA before its initial setup finishes, you may see Time To SLA is finalizing setup. Wait for setup to complete before you begin configuring the app. Time to SLA checks again automatically.
