# Release notes 21 January 2025

**Release date**: January 21, 2025

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Resolved an issue where the target date field was not set when a goal was not configured during issue SLA creation.
- Fixed a problem causing the *Customer Portal* page under project settings to return a blank page.
- Addressed an issue where background/periodic reports did not display issues for SLAs with a dynamic calendar.
- Corrected an error preventing SLA generation on issue creation or commenting.
- Fixed the SLA panel configuration issue where *Exclude/Include* options were not loading in the UI.
- Resolved a problem where customer-created tickets lacked an SLA panel when the start condition was set to "Issue Created."
- Fixed an intermittent issue where the multi-endpoint returned an empty array randomly.
