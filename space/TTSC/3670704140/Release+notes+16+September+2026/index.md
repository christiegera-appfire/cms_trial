# Release notes 16 September 2026

**Release date**: September 16, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira Cloud.

---

## New features

### SLA actions now support percentages up to 200%

You can now configure SLA actions to trigger at percentages up to 200%, matching the behavior available in Time to SLA for Data Center. This also ensures migrated actions using percentages above 100% continue to work as expected.

### Clearer SLA action trigger wording

We renamed the **is started** trigger to **is first started** to clarify that the action runs only the first time an SLA starts, not every time it starts again in a new cycle.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue where saving a Workflow Intelligence report after running Summary or Export could fail when using a preset date range. Equivalent preset and custom date ranges are now handled consistently.
- Fixed an issue that could cause the **Edit report** modal to crash for users without the calendars permission.
