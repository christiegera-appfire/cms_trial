# Release notes 29 April 2026

**Release date**: April 29, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Resolved an issue that could cause the SLA panel to disappear after issue updates when using the **SLA Calculation scope**.
- Fixed an issue affecting the **Where is my SLA?** helper so it now handles SLA scope-related cases more accurately.
- Fixed an issue that prevented updating the **Display value** of an **SLA Date** field.
- Improved the reliability of API-triggered SLA recalculations, including cases that could get stuck during processing.
- Fixed an issue where an invalid **DelaySeconds** value could prevent the SLA panel from appearing without recalculation.
- Resolved a problem that stopped scheduled report subscriptions from being sent.
- Fixed an issue where the **Where is my SLA?** pop-up could appear blank.
- Fixed an issue that prevented selecting a project in the *Recipients* section while configuring a report subscription.
- Fixed an issue that caused an unexpected pop-up when clicking the SLA panel on the goal creation screen.
