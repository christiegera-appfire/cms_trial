# Release notes 11 November 2026

**Release date**: November 11, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira Cloud.

---

## New features

### Define SLA goals using Atlassian Assets

You can now configure SLA goals based on Atlassian Assets objects and their attributes.

The new **Asset Criteria** filter lets you select object schemas, types, individual objects, and attribute values to determine which work items an SLA goal applies to.

![Screenshot 2026-11-10 at 23.17.58.png](/cms_trial/assets/d7a0e087-f7d6-45c2-81cc-44f27201f2f2.png)

For more information, see [Assets Criteria](/cms_trial/space/TTSC/35390901/SLA+goals/).

### Compare dates when configuring SLA goals

You can now use date comparisons to determine which SLA goal applies to a work item.

This gives you more flexibility when configuring SLA goals that depend on date information.

![Date Comparison, Condition options.](/cms_trial/assets/53e64d12-c645-4c6b-84ed-6e5a610cdde8.png)

![A Date Comparison filter applied.](/cms_trial/assets/2a0dd9d1-6d11-4040-80ff-1ff9770c77a1.png)

For more information, see [Date Comparison](/cms_trial/space/TTSC/35390901/SLA+goals/).

### View Time in Status directly on work items

You can now view Time in Status information directly from the Jira work item view.

![image-20261110-235005.png](/cms_trial/assets/8279225b-a6a6-455e-97e7-e9b8a6ff43d6.png)

The new glance provides a visual breakdown of how long a work item has spent in different statuses, helping you identify delays and repeated status transitions without opening a separate report.

For more information, see [Time in Status panel](https://appfire.atlassian.net/wiki/spaces/TTSC/pages/3843883120).

### Display SLAs from linked work items

You can now display SLA information across linked Jira work items using two configuration options:

![image-20261111-003314.png](/cms_trial/assets/df9608fc-7515-4ab9-96b2-5d439a385279.png)

- **Share this SLA on linked issues:** Display the current work item's SLA on linked work items.
- **Display linked issues' SLAs:** Display SLA information from linked work items on the current work item.

Choose the option that best fits your workflow and configure the relevant link types and directions. For more information, see [SLA fields](/cms_trial/space/TTSC/2875654192/SLA+fields/).

## Enhancements

### Improved REST API reference

We've updated the public REST API reference to make it easier to find accurate endpoint information.

The updated reference includes improved navigation, anonymized examples, and corrections to the available endpoints, including previously undocumented functionality.

### Improved API token management

We've redesigned the API token management page to make it easier to review and manage your tokens.

![image-20261111-004140.png](/cms_trial/assets/7db9b53f-6ea1-4fcc-ad53-33ad13fb300e.png)

The new **Last used** information helps you identify when a token was last used, making it easier to review tokens that may no longer be needed.
