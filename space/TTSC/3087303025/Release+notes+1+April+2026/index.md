# Release notes 1 April 2026

**Release date**: April 1, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### Performance improvements

We’ve made several optimizations to improve speed and responsiveness:

- Faster loading on the SLA configuration and recalculation pages
- Improved SLA calculation performance by reducing unnecessary data fetching

### Security improvements

We’ve addressed several security vulnerabilities to better protect your data:

- Improved validation for webhooks and notification URLs
- Fixed issues that could potentially expose SLA or issue data to unauthorized access

### Behind the scenes

We also made infrastructure and reliability improvements to support better performance and scalability. These changes are not directly visible but help ensure a smoother experience overall.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue where SLAs were not generated due to a webhook problem.
- Fixed cases where Slack notifications were sent multiple times.
- Fixed an issue where labels didn’t appear correctly in SLA conditions.
