# Release notes 24 November 2026

**Release date**: November 24, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue where SLA recalculation failed when using a saved Jira filter in a JQL query.
- Fixed an issue where configuring a holiday that covered an entire year could cause SLA calculations to time out and the SLA panel to remain stuck loading.
- Fixed an issue where recalculating selected SLAs could incorrectly clear the SLA Indicator field or cause the SLA panel to disappear, even when other SLAs were still running.
