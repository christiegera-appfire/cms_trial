# Release notes 16 December 2024

**Release date**: December 16, 2024

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### Support for Issue Link Webhook

Introduced functionality to listen to the issue link webhook. Please note that an issue refresh is required for the changes to take effect.

---

## Bug fixes

The following bugs are fixed in this release:

- Resolved an issue where changes made in SLA panel settings were not reflected in issues with existing SLAs. Updates are now correctly applied to all affected issues.
- Addressed a limitation in the `/api/issue-sla/multi` endpoint where it did not return the calendar object or the `inNonWorkingDays` field when a dynamic calendar was used. The endpoint now provides complete and accurate data for dynamic calendar configurations.
