# Release notes 10 July 2026

**Release date**: July 10, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue where some reports were incorrectly flagged as too large and redirected to background generation, even when they were below the supported SLA data limit.
- Fixed an issue where removing a Dynamic Calendar custom field selection from a work item did not clear the stored calendar reference, which could cause errors if the calendar was later deleted or referenced in REST API calls.
