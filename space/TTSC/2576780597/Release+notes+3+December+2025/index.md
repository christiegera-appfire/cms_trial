# Release notes 3 December 2025

**Release date**: December 3, 2025

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### Upcoming Forge-related changes

As part of our transition to Atlassian Forge, Time to SLA will undergo an important UI change: SLA panels will no longer appear automatically on work item screens.

### What this means for you

- There is no action required right now. Your existing SLA panels will continue working until the migration is complete.
- After the migration, the admins will need to add the SLA panel to the work item manually, which will be a quick, one-time configuration.

With this update, we added an info box in the app to give you early visibility into this change and help you prepare in advance.

To learn more about the upcoming changes, check out our [full documentation](/cms_trial/space/TTSC/2513797296/Changes+after+the+Forge+migration/).
