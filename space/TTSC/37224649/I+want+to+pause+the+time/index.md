# I want to pause the time

🤔 **Context:** A Procurement Manager has decided that SLA counters must be paused if purchase requests are assigned to an external supplier.

🌧️ **User problem:** As a Procurement Manager, I want to pause the SLA counters when purchase requests are waiting for an external supplier so that we can avoid “false” SLA breaches.

☔ **Solution:** Using Time to SLA’s built-in pause menu!

With Time to SLA, it’s possible to pause SLA counters depending on numerous statuses and field values. Check out the example below to get a glimpse of your numerous options:
