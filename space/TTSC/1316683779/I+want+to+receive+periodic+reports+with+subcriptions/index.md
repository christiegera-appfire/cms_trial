# I want to receive periodic reports with subcriptions

🤔 **Context:** A team lead needs to provide stakeholders with regular SLA performance reports without manually generating them each time.

🌧️ **User Problem:** Generating and sending SLA reports every week is repetitive and takes up valuable time. I need a way to automate the process so reports are sent out without my constant involvement.

☔ **Solution:** Time to SLA allows you to set up periodic reporting with subscriptions, so stakeholders receive regular performance reports automatically.

You can use Time to SLA’s periodic reports feature to create report subscriptions that are issued at regular intervals. They can be presented as project deliverables and help with decision-making.
