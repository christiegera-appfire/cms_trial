Release notes 9 April 2026

1 min read

Release date: April 9, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira Cloud.

Bug fixes

The following bugs are fixed in this release:

  • Fixed an issue where issue filter search could return inaccurate results and make some filters hard to find.

  • Fixed an issue where Time to SLA custom fields, such as the Duration field, could show the error Failed to load SLA values instead of SLA information.
