# Release notes 27 September 2024

**Release date**: September 27, 2024

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Exporting SLAs with pagination was failing. This has now been resolved, ensuring seamless exports.
- Users were encountering issues when attempting to access reports. This has been corrected.
- Improved the UI of the Met/Exceeded gadget and fixed an issue where it incorrectly redirected users to the SLA report.
