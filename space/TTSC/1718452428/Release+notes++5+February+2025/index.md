# Release notes  5 February 2025

**Release date**: February 5, 2025

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### Consistent date format

In SLA reports, the `Updated` date format now matches the `Created` date format (for example, `03/Apr/24 12:51 AM`). Previously, the `Updated` date was displayed in a different format.

---

## Bug fixes

The following bugs are fixed in this release:

- If you selected *Remaining issues in the selected projects* without removing the JQL scope, the SLA calculation still considered the JQL scope. We've fixed this so that JQL is properly removed when switching to *Remaining issues* scope.
- The SLA panel was not appearing in the Jira mobile app. We've resolved this, ensuring it now displays as expected.
