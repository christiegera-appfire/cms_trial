# Workflow Intelligence report

Workflow Intelligence reports help you understand how work moves through your Jira workflows. Use them to compare time across assignees, statuses, and time periods, identify bottlenecks, and investigate the work item activity behind your SLA performance.

You can create a report from scratch or start with a template for a common analysis scenario. After generating a report, you can:

- Review how long individual work items spent across the selected workflow dimensions.
- Generate a summary of workflow trends and SLA performance.
- Expand a work item to view its workflow or SLA breakdown.
- Save the report’s point-in-time results for later reference.

The summary and expanded details adapt to the fields and SLAs selected in the report configuration.

## Access Workflow Intelligence

In Product, go to **Reports** and select **Workflow Intelligence** from the report catalog or the sidebar.
