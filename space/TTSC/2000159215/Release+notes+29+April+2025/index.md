# Release notes 29 April 2025

**Release date**: ​April 29, 2025

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### Improved webhook functionality

We've added the `slaState` property to the notifier webhook payload. This lets you receive more detailed SLA information when using webhook-based automations or integrations.

---

## Bug fixes

The following bugs are fixed in this release:

- We resolved a bug where leaving filters empty would break the large background report generation. Reports now handle empty filters gracefully.
- We addressed an issue that prevented Time to SLA pages from loading due to inconsistencies in Jira's date-time format. TTS pages should now load reliably across different formats.
