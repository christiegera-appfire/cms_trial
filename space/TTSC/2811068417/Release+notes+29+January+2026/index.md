# Release notes 29 January 2026

**Release date**: January 29, 2026

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Resolved an issue where some work items were missing during SLA recalculation due to a 502 error when fetching work item data. The API cache now refreshes data *before* it expires, ensuring more reliable and consistent responses.
- Fixed incorrect SLA calculations caused by break time settings when importing calendars from Data Center to Cloud.
- Fixed an *Internal server error* that could occur after generating a report in the UI. This was caused by a bulk fetch timeout and has now been resolved.
