# Release notes 8 May 2024

**Release date**: May 8, 2024

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Partial releases

We are excited to partially introduce some improvements to the SLA setup. This change is currently being tested with a select group of users to gather feedback and ensure the best possible user experience. This means some users will see the new feature while others will continue with the existing experience.

### Simplified SLA Context

We've improved the overall SLA setup flow, renaming "SLA Scope" to "Context" for easier setup and simplifying the process.

### Better Setup Flow

A clear call to action has been added within the SLA setup section, ensuring the users know the next steps following the initial SLA creation.

### Automated SLA Notifications

We've automatically enabled email notifiers, with a frequency ranging from 50% to 75% based on SLA.

### Preconfigured Start and Finish Conditions

We’ve preset Start and Finish conditions to make creating SLAs easier.

---

## Bug fixes

The following bugs are fixed in this release:

- Resolved an error on the SLA History tab.
- Fixed SLAs that weren't stopping properly due to missing triggering events.
- Removed an unrelated item from the top-right corner of the SLA Panel on the Customer Portal.
