# Release notes 5 July 2024

**Release date**: July 5, 2024

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue where multiple SLA goals with the same JQL could lead to unexpected behavior during recalculations. Previously, the goal matching logic wasn't correctly considering cases where an issue matched the JQL scope of multiple goals that also included non-JQL scopes. This has been fixed to ensure accurate SLA goal matching.
