# Release notes 18 September 2025

**Release date**: September 18, 2025

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue that prevented SLA recalculation after migration due to outdated API usage. To resolve this problem, deprecated API calls were removed from several pages, ensuring recalculation works as expected post-migration.
