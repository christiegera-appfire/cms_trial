# SLA configuration

This page helps you set up and manage SLAs' core components. It will walk you through the key steps to configure SLAs, define calendars, set conditions and goals, and create notifications to streamline your SLA workflows.

## 1. Calendars

First, you must create a calendar. Calendars define the working hours and holidays that SLAs follow. Proper calendar setup ensures that SLA metrics are accurate and align with your team’s schedule.

- [Create calendars](/cms_trial/space/TTSC/35750012/Create+calendars/): Learn how to set up working hours, weekends, and holidays.
- [FAQ: Calendars](/cms_trial/space/TTSC/35881031/FAQ%3A+Calendars/): Common questions and solutions related to calendars.

## 2. Define an SLA

SLAs track the time taken to resolve work items or meet specific goals. To define an SLA, you must configure conditions, goals, and more.

1. [Define SLAs](/cms_trial/space/TTSC/35651691/Define+SLAs/): Understand the basics of setting up SLAs in your system.

   - [SLA conditions](/cms_trial/space/TTSC/35456221/SLA+conditions/): Specify the criteria (for example, work item type, priority) that trigger an SLA.
   - [SLA goals](/cms_trial/space/TTSC/35390901/SLA+goals/): Set time-bound targets for SLA compliance, like "Time to Resolution."
   - [Calculation methods](/cms_trial/space/TTSC/35456295/Calculation+methods/): Choose how SLA time is calculated—continuous or based on working calendars.
2. [FAQ: SLAs](/cms_trial/space/TTSC/34932181/FAQ%3A+SLAs/): Troubleshoot common work items when configuring SLAs.
