# Release notes 25 September 2026

**Release date**: September 25, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### Faster SLA configuration page loading

We’ve optimized the SLA configurations page to load only the information you need when you need it, reducing unnecessary requests and improving page load times.

### Optimized report generation

We’ve improved how report requests are handled when a report is too large to display directly, reducing unnecessary requests while the report is generated in the background.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue on the **Recalculation** page where selected SLAs could appear unselected after switching to the **Unchecked** view and then returning to **All** or **Checked**.
- Fixed an issue that could cause **JCMA migrations to get stuck** when migrating to a Cloud site that already contained Time to SLA data, such as SLA calendars.
- Fixed an issue where the **Use existing configuration / Use filter** pop-up was missing from the report page.
