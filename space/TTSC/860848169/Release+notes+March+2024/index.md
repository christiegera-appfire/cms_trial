# Release notes March 2024

**Release date**: March 18, 2024

Our team is excited to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Users were encountering a 403 error when attempting to access the Export/Import page. This bug has been fixed.
- Users were unable to save SLAs in portal configuration settings. The issue has been fixed, ensuring that SLAs can now be properly saved.
- Users were able to save holidays in the calendar without specifying a name. The calendar functionality has been updated to require a name for holidays, ensuring proper identification and organization.
- Some users were experiencing difficulties editing SLAs on Time to SLA Cloud after the JCMA migration. The issue preventing SLA editing after the JCMA migration has been resolved, restoring full functionality for SLA management.
