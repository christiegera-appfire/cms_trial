# FAQ: Recalculation

Below are some answers to questions we're commonly asked about creating SLA reports. If you need help with something we haven't addressed, [please contact us](https://appfire.atlassian.net/servicedesk/customer/portals).

#### ***Why am I getting an error when I try to recalculate my work items?***

That might happen because you have too many work items. Please separate your work items and try again.

#### ***When should I tick “Exclude Finished SLAs”?***

To better understand this, let’s say you’ve decided to change the priority of a work item from 6h to 4h. If you were to recalculate an SLA that is met at 5h in that case, it would now appear as **EXCEEDED**. This would be an incorrect value. **Exclude Finished SLAs** is useful for making sure such cases don’t happen.
