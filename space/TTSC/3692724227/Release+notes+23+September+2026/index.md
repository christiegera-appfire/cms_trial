# Release notes 23 September 2026

**Release date**: September 23, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### Clearer AND/OR options for SLA conditions

We’ve made the options for combining SLA conditions easier to recognize, so you can more clearly define whether all conditions (AND) or any condition (OR) must be met.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue where SLAs migrated from Data Center without a space scope could prevent the SLAs page from loading correctly.
- Fixed an issue that could cause JCMA migrations to time out.
- Fixed an issue where requests made without the required Time to SLA permissions returned `401 Unauthorized` instead of `403 Forbidden`. REST API integrations that specifically handle `401` responses may need to account for `403` responses instead.
