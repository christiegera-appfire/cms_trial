# Release notes 22 July 2024

**Release date**: July 22, 2024

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

July 22, 2024

- Implemented user impersonation to mitigate 429 errors encountered during calls to the JQL `/match` endpoint.

July 19, 2024

- We improved the SLA History response time.

July 18, 2024

- Fixed a bug that caused a required field error for the default calendar.
- Resolved an issue that broke the functionality of dark and light themes.
- Corrected a date error that was displayed incorrectly in the summary report.
- Improved the SLA/Assignee Performance gadget by fixing an issue where the issue filter was not showing on the report page.

July 11, 2024

- Some users experienced data loss related to the SLA Goal when editing for the first time after the latest update. We’ve fixed this issue.
