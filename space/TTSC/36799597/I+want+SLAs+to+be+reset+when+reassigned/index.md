# I want SLAs to be reset when reassigned

🤔 **Context:** A Senior Software Engineer wants SLAs to be reset when they are reassigned to another assignee.

🌧️ **User problem:** As a Senior Software Engineer, I need our SLAs to be reset when they are reassigned to another assignee in our team so that we can better track how much time is spent on all stages.

☔ **Solution:** Using Time to SLA’s built-in reset function!

With Time to SLA, you can make sure your SLAs are reset when they are reassigned, among many other options. To solve the problem described above, you can add an SLA reset condition to your SLA, configured as shown below:
