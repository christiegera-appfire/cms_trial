# Release notes 31 December 2025

**Release date**: December 31, 2025

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### Easier access to Dynamic Calendar fields

We updated the Dynamic Calendar Field APIs so that all users can select the field without issues.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed issues that caused `Too many requests` errors when checking permissions or loading app settings.
- Resolved a timeout issue that occurred when using the *Where is my SLA* feature.
- Fixed an issue where half-day holidays were incorrectly migrated as full working days.
- Fixed a problem where SLA updates triggered by Jira automation didn’t run as expected due to an impersonation issue.
- Fixed a migration issue where the process got stuck at 99%, causing SLAs not to migrate even though calendars were completed.
