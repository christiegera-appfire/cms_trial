# Track SLAs

You can monitor and track internal response goals, external service level commitments, and more using the SLA panel, the Details panel view, and the SLA History tab.

## SLA panel

The SLA panel displays all SLA metrics in one handy place with a customizable design. The panel appears in work item view screens if a work item meets the conditions for an SLA. To learn more about it, refer to [this page](/cms_trial/space/TTSC/35815658/SLA+panel/).

![Time to SLA Track SLAs panel showing SLA status on a work item](/cms_trial/assets/09eb8d3f-2238-4458-a1d3-f3139a2cccef.png)

## Details panel view

The *Details* panel view lets you access detailed SLA information directly from the work item view. When you click **SLA Panel**, you can see all the SLAs that apply to the work item, along with their current status and progress.

![Time to SLA Track SLAs page with SLA status configuration](/cms_trial/assets/5e46b809-5190-4e48-bde4-174576f6663c.png)

## History tab

Always visible in the work item’s main view, the SLA History tab displays the SLA's history within the issue. To learn more about it, refer to [this page](/cms_trial/space/TTSC/35456368/SLA+History+tab/).

![Time to SLA Track SLAs dialog showing SLA details](/cms_trial/assets/f7cca021-23b8-4668-942a-562eaa33afb7.png)
