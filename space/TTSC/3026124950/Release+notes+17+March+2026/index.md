# Release notes 17 March 2026

**Release date**: March 17, 2026

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## New features

### New SLA Duration custom field

We introduced a new custom field that stores the calculated duration of selected SLA metrics, showing how long each SLA has been running (or ran), giving you more flexibility in reporting and analysis.

![Time to SLA release notes March 2026 showing SLA configuration update](/cms_trial/assets/203222e3-e830-4e58-a298-1be9703be579.png)

For more information, refer to the [documentation](/cms_trial/space/TTSC/2969239557/SLA+Duration+field/).

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue where SLA panels were not visible after recalculation. In some cases, SLA panels would appear correctly when recalculating a single issue, but disappear when recalculating multiple issues. This could also incorrectly show *“SLA has never been in start”*. This behavior has been resolved.
- The SLA panel is now accessible to unlicensed users on the customer portal. Customers can view SLA information without requiring a license.
- Resolved an issue where the SLA Date custom field could display inconsistent data depending on the user.
