# Release notes 14 July 2026

**Release date**: July 14, 2026

This page outlines the updates included in the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### Reorder rows in Executive reports

You can now reorder rows in the Executive Report summary table to present grouped data in the order that works best for you.

### Default names for migrated SLA goals

When SLAs were migrated from Data Center to Cloud using the Jira Cloud Migration Assistant or export and import process, goal names could be left empty. Migrated goals now receive the default name **Migrated Goal**, which you can update when needed.

---

## Bug fixes

The following bugs are fixed in this release:

- Cloning a default notification incorrectly copied its default status, including the **Default** lozenge, and prevented the cloned notification from being deleted. Cloned notifications now behave like standard notifications and can be deleted.
- During SLA calculations, the Time to SLA API could retain work item SLA records associated with deleted SLAs. These obsolete records are now removed automatically.
