# Release notes 18 August 2025

**Release date**: August 18, 2025

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## New features

### Ability to ignore issue updates from specific users

You can now configure your project to ignore updates made by specific users. This helps reduce unnecessary noise in your workflow (for example, automated bot updates or bulk changes), ensuring that only meaningful updates reach your reports and SLA tracking.

For more information, refer to the [documentation page](/cms_trial/space/TTSC/37290034/Administration/).

---

## Bug fixes

The following bugs are fixed in this release:

- We’ve fixed an issue where some users encountered an `ECONNREFUSED` error while retrieving secret values from the Lambda layer. The retrieval process is now more stable and reliable, preventing unexpected interruptions.
