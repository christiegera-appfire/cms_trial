# Release notes 29 October 2024

**Release date**: October 29, 2024

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- We’ve resolved an issue where SLAs were not visible on the customer portal for all users due to permission restrictions. We removed the SLA panel permission check on the portal. Now, if an SLA is shared on the customer portal for a specific request type, all users with access to the portal will be able to see the SLA panel.
