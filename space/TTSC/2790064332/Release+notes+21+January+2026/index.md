# Release notes 21 January 2026

**Release date**: January 21, 2026

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Resolved an issue where periodic reports were running inconsistently and were not always triggered as expected.
- Fixed a problem where customer (portal-only) users couldn’t see the SLA panel even when it was configured to be visible on the portal.
- Fixed a timeout issue during group retrieval in JCMA, improving reliability for instances with large numbers of groups.
- Addressed errors related to ElastiCache to improve overall system stability.
- Fixed an issue where generating a report from the UI could result in an *Internal server error*. This was caused by a bulk fetch timeout and has now been resolved.
