# Release notes 3 December 2024

**Release date**: December 3, 2024

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Resolved an issue where the presence of identical holidays in the calendar led to incorrect SLA computations. The system now accurately processes SLA timings, even when multiple instances of the same holiday are present.
