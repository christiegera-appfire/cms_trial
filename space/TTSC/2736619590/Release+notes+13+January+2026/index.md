# Release notes 13 January 2026

**Release date**: January 13, 2026

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an issue where notifications continued to be sent in reset-related scenarios after a Forge migration, even when recalculation was triggered.
- Fixed a permission issue that allowed users with *Viewer* access to update scheduled reports via the REST API, even though they didn’t have *Editor* permissions.
- Fixed an issue where migrated “Associate with goals” IDs were incorrect in notifications after JCMA migration.
- Fixed an issue that prevented editing notifications migrated via JCMA.
