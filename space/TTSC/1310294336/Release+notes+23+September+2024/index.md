# Release notes 23 September 2024

**Release date**: September 23, 2024

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed an error that was causing the SLA panel to not appear on the customer portal.
- Resolved a calculation error involving nested conditions.
- Fixed an issue with the Met/Exceeded gadget that caused errors when redirecting users to the Reports page.
- Corrected an error related to SLA state updates for "changed to/from" type conditions.
