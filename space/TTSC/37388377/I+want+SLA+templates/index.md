# I want SLA templates

🤔 **Context:** A user wants to configure Time to First Response and Time to Resolution.

🌧️ **User Problem:** I want to track response times and resolution times, but I need a roadmap to follow before I can set SLAs by myself.

☔ **Solution:** Use Time to SLA's SLA templates!

Time to SLA offer templates for the most commonly used scenarios: Time to resolution, Time to first response, and Time in "In Progress".
