# Release notes 19 February 2026

**Release date**: February 19, 2026

Our team is thrilled to announce the latest release of Time to SLA for Jira Cloud.

---

## Enhancements

### **Improved REST API routing and new** `whoami` **script**

Disabled REST API region routing and introduced a new `whoami` script to help identify API context more easily.

### **Updated documentation links**

- The documentation link on the landing page now directs you to the correct resource for automated email alerts.
- The escalation rules documentation link has also been updated to ensure it points to the right page.

---

## Bug fixes

The following bugs are fixed in this release:

- Resolved an issue where select list conditions were not displaying properly.
- Fixed an issue with Excel exports to ensure data types are handled correctly in generated reports.
