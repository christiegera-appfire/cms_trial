# Filter and search priorities

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

Each tab (Tasks, Boxes, Goals) offers different filtering options. Check the table to see the available filters.

| **Element** | **Tasks** | **Boxes** | **Goals** |
| --- | --- | --- | --- |
| **Available filters** | - Filter by name - Basic filters:    - Project   - Issue type   - Status   - More filters - Advanced Filters - Saved Filters | - Filter by name - Filter by:    - Status   - Box type   - Parent box | - Filter by name - Filter by:    - Status   - Owner   - Period   - Label   - OKR type   - Goal type |

## Tasks

There are multiple filter views for tasks:

- **Basic filters** allow you to quickly select filters from preselected options like projects, assignees, fixed versions, and more.
- **Advanced filters** allow you to use JQL search to filter by anything you want. You also get hints while typing your search to make it much easier.
- **Saved filters** allow you to select any of your saved filters in Jira, which is ideal for quickly switching between the views.

### Basic filters

With basic filters, you can filter tasks by:

- Project
- Issue type
- Status
- More filters:

  - Assignee
  - Component
  - Epic
  - Label
  - Status category
  - Versions

![image-20250708-081907.png](/cms_trial/assets/d0e00eeb-338c-4574-9f34-00722471b306.png)

### Advanced filters

Advanced filters allow you to enter a JQL query in the search field. Hints will appear when you enter your query.

![image-20250708-082041.png](/cms_trial/assets/a8ce6ba0-fc23-40fa-97c0-9dad51ecbdf5.png)

### Saved filters

Click **Saved Filters** to see a list of the filters saved in Jira projects. If you have private filters saved, they will be visible only to you.

![image-20250708-082243.png](/cms_trial/assets/63c90caf-9d69-4a23-accf-2678af1fecc9.png)

## Boxes

You can filter boxes by:

- Status
- Box type
- Parent box

![image-20250708-074838.png](/cms_trial/assets/6acab925-a041-40fb-825d-e5f5c6b492cf.png)

## Goals

You can filter goals by:

- Status
- Owner
- Period
- Label
- OKR type
- Goal type

![image-20250708-075049.png](/cms_trial/assets/d3d1d134-7215-40fb-814a-180255fbdc68.png)

## Filter by name

You can filter tasks, boxes, and goals by name.

1. Type a name.
2. Click **Enter** to see the results.

![image-20250708-075314.png](/cms_trial/assets/53fed738-f47b-4ae4-9725-a51d8401d6cb.png)

## Clear filters

To clear applied filters, click the **Clear filters** button.

![image-20250708-075448.png](/cms_trial/assets/da42b27c-dc5b-43fb-aed3-6ec5f6ef5b4e.png)
