# Manage risks

You can [add](/cms_trial/space/SPM/1918833525/Add+risks/), [edit, and delete risks](/cms_trial/space/SPM/1918669632/Edit+and+delete+risks/) in the Risks module.

Your work items will only appear on the risk matrix if you set values for the fields used by the matrix. If you want to change the matrix's dimensions, change the number of select options of the configured field.

Any Jira work item can be presented on the matrix. Depending on the risk management process you use, you can create a separate work item type to represent identified risks, or simply set the risk probability and consequence for at-risk tasks.
