## Access and permissions

To access the **My settings** page, you need the BigPicture User role, as it lets you open the BigPicture app.

To access your personal BigPicture settings:

1. Click **App Settings**.
2. Mouse over **My settings**.
3. From the dropdown, select one of the **My settings** tabs: **Profile**, **Absences**, **Preferences**, or **API tokens**.

![My settings page, Profile tab. On the right-hand side, App settings dropdown is expanded to show how to access the My settings page.](/cms_trial/assets/d0fff792-ebe2-4f3f-98ed-2f4fd5ba3c80.png)

## My settings

The **My settings** page lets you:

- Check your profile details.
- Add personal absences, and check profile details.
- Set preferences.
- Create API tokens for BigPicture.

In addition, you can also enable/disable [notes](/cms_trial/space/SPM/2372665547/Create+notes/) that are displayed on boxes, reports, and tasks.

This page consists of the following tabs:

- [Profile](/cms_trial/space/SPM/1918667643/Profile/)
- [Absences](/cms_trial/space/SPM/1918764834/Absences/)
- [API tokens](/cms_trial/space/SPM/1918666949/API+tokens/)
- [Preferences](/cms_trial/space/SPM/2811363451/Preferences/)
