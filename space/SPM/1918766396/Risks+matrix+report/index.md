# Risks matrix report

## About the Risks matrix report

The **Risks matrix** report gives you a quick overview of existing risks.

![New report window](/cms_trial/assets/0a652b21-16d4-450c-92f5-0299d17ad6e0.png)

This Risks matrix displays the risks present in the Risks module of a given Program or Project and iterations on a lower hierarchy level (on the ART level, the report will also display risks from the PI iterations and the PI sprints).

The intersections of the axes display the number of risks matching the risk criteria (probability and consequence).

![Risks matrix](/cms_trial/assets/9d18f025-64d4-4fd5-b0a4-49c610d485db.png)

The tile coloring scheme depends on the level of probability and impact (just as in the Risks module).

To view the risks under a given number, click it, and an appropriate list of risks with their statuses will appear (as an inline dialog).

![Risks in Risks matrix](/cms_trial/assets/ff7398d4-88bb-48b1-92a2-866b5a898422.png)

To open a task in Jira, click a task summary.

Use the arrow icon in the dialog to go to the Risks module.

## **Report configuration**

To configure your Risks matrix report, click the pencil icon in Edit mode (Box Admin or Box Editor permissions are required).

You can modify the report title or rotate the matrix axes by checking appropriate checkboxes (as in the Risks module).

![Risks matrix configuration](/cms_trial/assets/92cbbb78-ea09-4fb2-9897-88beebe786c1.png)
