# Keyboard shortcuts (Board module)

## Display available keyboard shortcuts

Click the **Get help** ( **i** )button in the upper-right corner menu (or press **Shift + /**) to display the keyboard shortcuts dialog box.

![Menu with options under the et help button.](/cms_trial/assets/73fe1edb-6b0c-42f2-80e0-35f68afa570b.png)

## Board module shortcuts

The shortcuts listed in the box will only show the shortcuts applicable to the module you are viewing. The app will adjust the displayed shortcuts to your device system (Mac and Windows). Also, depending on your Windows device, you may need to use the **Fn** button in place of **Ctrl**.

The Board module’s keyboard shortcuts are divided into the following categories:

![bA list of keyboard shortcuts in the Board module.](/cms_trial/assets/b2c65b1a-abaf-4820-886e-35c47d522b8c.png)

### Navigation

| Select box | Mouse **left-click** |
| --- | --- |
| Context menu | Mouse **right-click** |
| Item navigation | **↑** / **↓** |
| Collapse / expand | **→** / **→** |
| Remove selection | **Esc** |
| Select task | Mouse **left-click** |
| Select multiple tasks | **Shift** + mouse **left-click** |

**Item actions**

|  |  |
| --- | --- |
| New item | **Enter** |
| New sub-item | **Shift** + **Enter** |

### Task actions

| Move to previous team | **Shift** + **↑** |
| --- | --- |
| Move to next team | **Shift** + **↓** |
| Move to next timebox | **Shift** + **→** |
| Move to the previous timebox | **Shift** + **←** |
| Create link from task | **L** |
| Send to backlog | **Shift + B** |

### Backlog

| Show or hide planned task(s) | **P** |
| --- | --- |

### Teams

| Allocate team | **Shift** + **T** |
| --- | --- |

### Timeline

| Today | **Shift** + **0** |
| --- | --- |
| Zoom in | **Shift** + = |
| Zoom out | **Shift** + - |

### View

| Show or hide backlog | **]** |
| --- | --- |
| Show or hide markers | **M** |
| Collapse or expand dependencies | **D** |
| Toggle reports | **Shift** + **Alt** or **Option** + **R** |
| Show or hide full scope | **Shift** + **S** |

### Layout

Change the row height of the layout.

| Compact | **Shift** + **C** |
| --- | --- |
| Regular | **Shift** + **R** |
| Wide | **Shift** + **W** |

### Others

| Show/Hide menu | **Z** |
| --- | --- |
| Undo | **Ctrl** or **Cmd** + **Z** |
| Open the System-info dialog box | **Shift** + **I** |
| Play the BigPicture game | **Shift** + **Ctrl** or **Cmd** + **G** |
| Re-synchronize data | **Alt** or **Option** + **R** |
