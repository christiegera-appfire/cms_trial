# Field mapping

## Field mapping (old navigation)

Click to expand the guide

Configuring the field mapping ensures that the data from Jira fields inside your Jira issues corresponds to the fields in BigPicture.

For example, the End date field stores planned completion data. When you expand or shorten a taskbar on the Gantt timeline, the app can automatically update the task’s End date field. But at the same time, you want that new date to be also reflected in the same project in Jira.

Proper field mapping enables this synchronization. So whenever you make changes to a task date in Jira, you’ll see those changes in your project in the app—and other way around.

Jira admins can configure field mapping on the **App configuration** > **General** > **Fields** page. For more details, see the [Field mapping (configuration)](/cms_trial/space/SPM/1918635376/Fields/) page.
