# Assign skills to individuals

## Assign skills to individuals (old navigation)

You can assign skills to individuals directly from the Gantt and Scope modules.

1. Go to the **Gantt** or **Scope module**.
2. Click the **+** button.
3. Add the **Skills** column to the current view.

   ![gantt-add-skills-column.png](/cms_trial/assets/e3b41715-67d9-4cc7-80d9-6a58e3d4afb6.png)
4. Double-click the **Skills** column to prompt the dropdown list.
5. Select the skills you want to add.

   ![inline-edit-assign-skill.png](/cms_trial/assets/77e028cd-18c0-4114-98ec-91bab404f8b1.png)
