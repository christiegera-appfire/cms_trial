# Resources

## What can I find in the Resources section?

![Screenshot of the Individuals tab in BigPicture Administration.](/cms_trial/assets/fb7890c6-3d6c-4a5d-b434-3fe0507611c1.png)

The *Resources* tab of BigPicture *Administration* contains four tabs:

- [Individuals](/cms_trial/space/SPM/1918700744/Individuals/) - view and manage resources; assign absences, workload plans, holiday plans, and skills
- [Workload plans](/cms_trial/space/SPM/1918506352/Workload+plans/) - manage workload plans
- [Holiday plans](/cms_trial/space/SPM/1918505164/Holiday+plans/) - manage holiday plans
- [Skill management](/cms_trial/space/SPM/1918636059/Skill+management/) - manage skills

## Who can access the Resources section?

| The *Resources* tab can be accessed by: |
| --- |
| [BigPicture app roles](/cms_trial/space/SPM/1918535770/App-level+permissions/) | - **App Admin** - **App Resource Admin** |
| [BigPicture box roles](/cms_trial/space/SPM/1918797447/Box-level+permissions/) | - n/a   **Note:** Access to administrative settings is independent of box roles. |

## How to access the Resources section?

### Wrench icon at top right

1. Go to **App Settings** > **Resources.** The *Individuals* tab of the *Resources* section on the *Administration* page opens.
