# Goal types

On April 9, 2026, the **Objectives module** was renamed to the **Goals module** to better differentiate it from the OKR module. Items created within this module are now called goals.

## Goal types (old navigation)

Click to expand the guide

You can use Jira issues as goals or create basic goals that do not sync with Jira and connected tools.

There are two types of goals that you can define:

- Regular
- Uncommitted

The 'uncommitted' goals are not included in the achievement calculation.

You can assign an goal to a box (main goals) or a Team (Team goals).

![Objectives module, Objectives are highlighted](/cms_trial/assets/f8d3bac6-d533-4ab7-916a-33a2a5d3da99.png)

## Main goals

Main goals are not assigned to any team, meaning multiple teams contribute to achieving them.

![Objectives module, Main Objectives are highlighted](/cms_trial/assets/a6898bf0-be5b-4fac-8989-2352dea0fd46.png)

## Team goals

Team goals can be used to determine team commitment during a particular Program Increment or Iteration.

![Objectives module, Team Objectives are highlighted](/cms_trial/assets/5f272842-a503-4ba6-b444-1a325540b599.png)

## Task-based goals

Any task in a box scope can be added as a goal in the **goals module**. That includes both Jira and Trello tasks.

**Method 1:**

To add a task-based goal in the **Goals module**:

1. Click **+** to **add a new goal.**
2. **Toggle the switch** next to the goal name field.
3. Search for a task.

![Objective, search field is highlighted](/cms_trial/assets/680dbf55-d511-4921-a6d8-87ba1add0993.png)

**Method 2:**

You can create task-based goals directly in the Board module.

1. Find a task (Jira issue/basic task).
2. Right-click on a task and select **Create goal based on this task**.

   ![Screenshot of creating an objective based on the task in the Board module.](/cms_trial/assets/64187bfe-5c8e-45c6-a3a1-9a639c4b6b2c.png)
3. A new goal is immediately visible in the [goals module](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=spm&title=Objectives%20module&linkCreation=true&fromPageId=1918505418).

   ![Screenshot of a new objective added in the Board module.](/cms_trial/assets/d8e90cec-c196-4cc5-9d5f-1420293eeb3c.png)

## Basic goals

Basic goals (like [basic tasks](/cms_trial/space/SPM/1918405930/Basic+tasks+%2F+BigPicture+tasks/)) are stored by the App and do not sync with connected tools (Jira/Trello).

To add a basic goal:

1. Navigate to the **Goals** module.
2. Click **+** to **add a new goal.**
3. Click the **don't toggle switch** next to the goal name field.
4. Create a "Basic goal name".

![Objectives, adding new objective](/cms_trial/assets/e26cc659-5cf7-40d4-96c9-4c7223f77d56.png)

## Regular and uncommitted goals

The difference between regular and uncommitted goals is that the Planned Business Value of the uncommitted goals is not included in the achievement calculation. The uncommitted goals are separated from the regular ones using a dashed line:

![Objectives module, line dividing commited and uncommited objectives marked](/cms_trial/assets/ebc2a5f5-b65d-4069-a354-70e8eb7d6892.png)

To change the goal type:

1. Double-click on the goal you want to edit.
2. Click "Positions" to expand the details.

![Objective details window](/cms_trial/assets/efa447ac-ff9d-4092-89d9-97ac1aae1325.png)
