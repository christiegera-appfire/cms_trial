# Dependencies in the Board module

The Board module dependencies are color-coded so that you can easily find the tasks that need your attention.

## Create dependencies (Board module)

To create dependencies between tasks:

**Method 1:**

Click and drag → click on a grey dot and drag an arrow to a card to create a dependency.

See the video![Video of creating dependencies in the Board module.](/cms_trial/assets/bf7d67a5-fd4a-43e8-b148-01a4b5f3a0b0.mp4)

**Method 2:**

Click on the grey circle → a pop-up appears. Fill in the fields to create a dependency.

See the screenshot![Screenshot of creating dependencies in the Board module.](/cms_trial/assets/94a878d3-0ff3-4791-b3b8-95410fbd1bf1.png)

The task you have clicked on is automatically selected as a source task.

Note: To use this feature, make sure the **Expand dependencies**option is selected.

## Dependencies tab in Infobar

One of Infobar's sections focuses on task dependencies. The dependencies fall into four categories and resemble links configured in dependency configuration.

The **Dependencies** tab contains all information on task dependencies:

- Dependencies between the tasks in the scope of the current box.
- Dependencies between the tasks in the current box and other boxes (indicated by an icon).

### Dependency details

Expand a dependency to see the following information:

- Source task
- Target task
- Task key
- Task dates
- Team code
- Timebox

### Search

The **search bar** allows you to find a specific task (or tasks) whose dependencies you want to inspect.

![image-20240925-075530.png](/cms_trial/assets/efbbdb52-7601-4a9a-b3cc-2e0e9059e77f.png)

### Focus on task

Use the focus feature to select the source or target tasks. The app will highlight the task.

![image-20240925-075724.png](/cms_trial/assets/879b9842-f9f7-4161-87d6-f68a7f3a82f9.png)

### Edit dependency

To edit a dependency:

1. Click **More actions (…)** > **Edit dependency**.
2. Make changes.
3. When ready, click **Save**.

![2024-09-25_11-13-46.mp4](/cms_trial/assets/49baf2b8-a63e-45a3-9073-f01f38bb7a62.mp4)

### Out-of-view dependencies

A dependency doesn’t appear on the board when at least one task is from an external box. Such dependencies are listed under the **Dependencies out of view** section.

When you click **Focus on source/target**, you can’t be taken to a task in a different box.

![image-20240925-075924.png](/cms_trial/assets/9efdca36-177a-43cf-8743-eb6bea93c60d.png)

### Filter based on swimlanes

Dependencies are filtered based on the swimlane type and values selected.
