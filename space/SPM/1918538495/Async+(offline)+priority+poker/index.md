# Async (offline) priority poker

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

By choosing asynchronous planning poker, you allow your team to vote calmly and independently, decreasing the duration of planning meetings. This type of poker lets users vote in their own time, giving them more flexibility.

## Create async priority poker game

To create a new priority planning poker game:

1. In the Priorities module, click **Priority poker** in the top right.
2. Click **Create a new game** and enter a game name.
3. Select **Async poker** to let your team prioritize in their own time and review the results later.
4. Click **Next: Select metrics**.

   Image — asset pipeline pending  
   Screenshot of creating an async poker game in the Priorities module.
5. Select metrics to prioritize and click **Next: Select issues**.
6. Select work items you want to prioritize. Use filters to find the necessary issues.
7. When ready, click **Create game**.
8. You’ve created a new poker game.

Invite other players to the game via the link, and once you’re ready, click **Join the poker game**to begin voting. New players can join anytime until a game administrator hasn’t closed voting.

## Administer async poker game

Once you’ve created a new game as admin, you are taken to the **Game Admin View** screen, which includes the following information:

- Pie chart with players' vote status (finished, in progress, or not started).
- List of players participating in the game, their vote progress, and completion status.

From the Admin page, you can invite other players, close voting, and review results.

## Vote on work item metrics

Once you’ve joined the game you are taken to the voting screen, where you can choose what work items to vote for.

1. Choose work item metrics and add values to them.
2. Filter work items s by **Voted** and **Pending**.

   Image — asset pipeline pending  
   Screenshot of the Filter dropdown menu in the Issues for prioritization panel.
3. Click **Submit my vote** after you finish voting on the work items.

## Review and accept results

Once you close the voting, you will be directed to the **Game Results** screen.

1. Review voting details by clicking the **details** next to each work item.
2. Inspect voting statistics in the report section.
3. Close the game by clicking **Accept results**.
