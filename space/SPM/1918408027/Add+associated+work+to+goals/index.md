# Add associated work to goals

On April 9, 2026, the **Objectives module** was renamed to the **Goals module** to better differentiate it from the OKR module. Items created within this module are now called goals.

## Add associated work to goals (old navigation)

Click to expand the guide

## Attached tasks

You can attach existing tasks to your goals. Tasks are visible under the respective goals but can be collapsed.

To use associated work, ensure it has been [enabled for a relevant box type](/cms_trial/space/SPM/1918701325/Objectives+-+Business+value+and+associated+work/).

![Team Objectives, existing tasks](/cms_trial/assets/1c07ebe9-b9bb-49f2-8442-eacaac1d1a5a.png)

Only tasks that are in a Box can be added as associated work.

## Task status

Status is displayed for tasks attached to goals.

![Objectives, status of the associated work](/cms_trial/assets/8edff98f-b5b2-40d9-925b-2db0376e0577.png)

## Associating work

### From the main screen

**Steps**

1. Right-click on an goal. A pop-up menu will appear:

   ![Objectives, add associated work button](/cms_trial/assets/8bd5317c-ad24-4c18-a227-97449ca19417.png)
2. Select **Add Add associated work**.

   ![Add associated work option](/cms_trial/assets/97189cbd-a7bf-45c9-91b8-a9221b4fa57a.png)
3. Select tasks from the list. Use the search field to narrow down the options.

   ![add-initiative.png](/cms_trial/assets/fef5fc1d-4e8e-4362-b2f8-6c32f52109d9.png)
4. Click outside of the list to close the task list.

   ![Add associated work form](/cms_trial/assets/a4e705ba-ba5d-4c98-a614-ff858d25363d.png)
5. Hit "Save" to add associated work.

### Using the details pop-up box

**Steps**

1. Double left-click on a given goal. An editing box will open.

   ![Details of associated work](/cms_trial/assets/bf92ec9f-d25e-4500-b634-e72e82cdfbd4.png)
2. Click on the 'Associated work' field.

   ![Associated work field](/cms_trial/assets/2242a267-81ae-4569-8fe9-e65e843106ae.png)
3. Select tasks from the list. Use the search field to narrow down the options.
4. Click on a task to select it. The task will be displayed in the associated work field.

   ![Chosen associated work](/cms_trial/assets/0ee97128-dcc7-49e4-89b4-594506a8bb0c.png)
5. Hit 'Save' to confirm. Associated work has been added.

   ![Details form, save button](/cms_trial/assets/6809eb9c-de40-423d-bb38-0e5a8f8aaaf7.png)

## Deleting associated work

### From the main screen

Right-click on an associated work item > **Remove from this goal.**

![Remove from objective option](/cms_trial/assets/fcda9afc-5c0e-4b1b-90a7-ff301f618f54.png)

### **Using the details pop-up box**

**Steps:**

1. Double left-click on a given goal. An editing box will open.

   ![Details form with added work](/cms_trial/assets/ffd83bfc-8360-4ac9-8bf1-25e48f83c09a.png)
2. Click the X to remove an associated work item from the list.

   ![Removing work from the list](/cms_trial/assets/2e65393d-d9b3-41d0-bf50-a6492174ac20.png)
3. Hit **Save**.

   ![Details form, save button](/cms_trial/assets/2a628ae2-95ea-413a-8c4d-d2e0994676b8.png)

## Associating work

### From the main screen

**Steps**

1. Right-click on a goal. A pop-up menu will appear:
2. Select **Add associated work**.

   ![Screenshot of the Add associated work in the Goals module.](/cms_trial/assets/594629b5-2c00-4629-b3f6-734c3e557d44.png)
3. Select tasks from the list. Use the search field to narrow down the options.

   ![Screenshot of adding associated work in the Goals module.](/cms_trial/assets/436c5d4e-f1cc-44bf-973e-dd5d6cdf7293.png)
4. When ready, click **Save**.

### Using the details pop-up box

**Steps**

1. Double left-click on a given goal. An editing box will open.
2. Click **Associated work**.

   ![Screenshot of adding associated work for a goal in the Goals module.](/cms_trial/assets/104f43c5-d324-49af-bb94-f07bf4dbc1c9.png)
3. Select tasks from the list. Use the search field to narrow down the options.

   ![Screenshot of selecting associated work items for a goal in the Goals module.](/cms_trial/assets/800d685a-3344-4f29-86d7-79b27c6e0ec8.png)
4. Click on a task to select it. The task will be displayed in the associated work field.
5. When ready, click **Save**.

## Delete associated work

### From the main screen

Right-click on an associated work item > **Remove from this goal.**

![Screenshot of the Remove from this goal button.](/cms_trial/assets/3f71f814-38d0-4e0a-ae23-3ef6150e27bb.png)

### **Using the details pop-up box**

**Steps:**

1. Double left-click on a given goal. An editing box will open.
2. Click the X to remove an associated work item from the list.

   ![Screenshot of deleting associated work items from a goal.](/cms_trial/assets/1643d335-5d18-4958-9987-1474b3ed3acb.png)
3. To confirm, click **Save**.
