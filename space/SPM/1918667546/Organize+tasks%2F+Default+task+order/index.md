# Organize tasks/ Default task order

The **Organize tasks** function is renamed to **Default task order** as part of the new navigation rollout.

Both names refer to the same functionality. You may see either term depending on whether you’re using the previous navigation or the new navigation that is currently being rolled out in BigPicture.

## Organize tasks (old navigation)

Click to expand the guide

**The Organize tasks is irreversible**

If you want to **temporarily change** the task order, use the ‘**sort by**’ option.

## Organize tasks

You can organize your tasks in ascending or descending order. Tasks are sorted at each level of the hierarchy separately: sub-tasks are organized within the higher-level task, and organizing does not break the tree structure.

To enable the option, click the Data button in the upper menu, select the sorting method (ascending or descending), and choose a column to sort by. The active sorting in the “Organize tasks A-Z”/“Organize tasks Z-A” list is indicated by the icon next to the column name (mouse over it to see a tooltip showing the date of the last change).

The **Organize tasks** action is irreversible. Once done, you can change the organization by choosing another option from the list.

The Organize tasks feature is the same for the Gantt and Scope modules.

![image-20241004-084229.png](/cms_trial/assets/20dd3f66-ff1b-416d-8640-274814740946.png)

### More sorting options

If a field you want to sort by is missing, add it as a column. The sorting stays active after removing the sorting column.

You can use both built-in and integration-specific fields. The field type is indicated by an icon next to a field in the list.

Changing task details does not automatically affect the order.

![image-20241004-084625.png](/cms_trial/assets/25396e91-1ed7-4e06-9e52-9d118e2d8685.png)

### Column view

You can organize tasks using only visible columns. If you want to organize tasks by another column, you need to add it in the table settings.

The task order set by a specific column stays the same after deleting the column from the view.

### Organize sub-tasks

You can also organize just sub-tasks within a specific task. Right-click a parent task, choose “Organize children A-Z” / “Organize children Z-A”, and children organization method:

![Screenshot 2024-02-08 at 10.59.51.png](/cms_trial/assets/a4adb7b5-ee70-4838-b30f-441c2bce33b8.png)

Using the **Organize children** option overwrites the **Organize tasks** action for sub-tasks of a specific task.

Using **Organize tasks** after **Organize children** overwrites the **Organize children** order.

### What can be sorted?

All tasks from integrations (Jira, Trello) can be sorted.

Basic tasks can be sorted.

### Who is affected?

The **Organize tasks** action affects all users because it changes the sorting settings globally.

## Restore Jira tasks order

To see the same order of tasks as in Jira:

1. Expand the **Data** drop-down menu.
2. Click **Restore Jira task order**. This operation will affect all users' tasks.
3. To confirm, click **Restore anyway**.

When you restore the tasks order, any previously applied tasks order will be deactivated.

It's not possible to apply the BigPicture task order to Jira.

See the video.

![2024-10-04_10-49-48.mp4](/cms_trial/assets/76e3b532-2aee-4d8f-85b5-d9f2595afed9.mp4)

## Constraints

- When tasks are grouped, the **Organize tasks** and **Restore Jira task order** features are unavailable.
- The **Organize tasks** feature is **not** available for portfolio boxes (none-scope boxes).

## Default task order

**The Organize tasks is irreversible**

If you want to **temporarily change** the task order, use the ‘**sort by**’ option.

You can organize your tasks in ascending or descending order. Tasks are sorted at each level of the hierarchy separately: sub-tasks are organized within their higher-level task, and this organization does not break the tree structure.

To enable the **Default tasks order**:

1. Click the **View** button in the upper menu
2. From the dropdown, select **Default tasks order**.
3. Select the sorting method (ascending or descending), and choose a column to sort by. The active sorting in the “Organize tasks A-Z”/“Organize tasks Z-A” list is indicated by the icon next to the column name (mouse over it to see a tooltip showing the date of the last change).

The **Default tasks order** action is irreversible. Once done, you can change the task order by choosing another option from the list.

The **Default task order** feature is the same for the Gantt and Scope modules.
