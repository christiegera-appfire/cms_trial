# Assign skills

To assign a resource to a skill, the App admin must first [add skills](/cms_trial/space/SPM/1918669478/Add%2C+edit%2C+and+delete+skills/) on the **Administration** > **Resources** > **Skills** page.

## Assign skills to individuals

You can assign skills to an individual:

- When adding a new individual on the Administration > Resources > Individuals page.
- On the individual’s details page.
- Using the Skills column in the Gantt and Scope modules.

### Method 1: Assign skills when adding a new individual

1. Go to the **Administration** > **Resources** > **Individuals** page.

   ![Screenshot of the Individuals page in Administration.](/cms_trial/assets/02861808-b86d-4cb6-a588-a66191dc74b9.png)
2. Click **+Add new individual**.
3. Select a user from the drop-down menu.
4. Choose the **workload** and **holiday plans**.
5. Assign **skills**.
6. When ready, click **Add**.

   ![Screenshot of the Add Resource window.](/cms_trial/assets/b46bfade-0e83-4620-a4d6-9fd41a8324f3.png)

### Method 2: Assign skills on the individual’s page

1. Go to the **Administration** > **Resources** > **Individuals** page.
2. Click an individual’s name to go to a details page.

   ![Screenshot of the Individuals page in Administration.](/cms_trial/assets/3b0eb66c-1c0b-4a48-ad85-8b939fe81dee.png)
3. Click **+Add new** in the Skills section.

   ![Individual resource details page where, among many others, you can assign skills.](/cms_trial/assets/aead13ed-6d7d-4e60-ab48-113475bd746b.png)
4. Select a skill from the dropdown menu.
5. Complete start and end dates.
6. When ready, click **Add**.

   ![Screenshot of the Add Skill window.](/cms_trial/assets/d208c8bc-dba1-4705-9c1c-c91668b1d41c.png)

#### Edit assigned skills

1. Click the **Edit** icon to modify a skill entry.

   ![Screenshot of the Edit icon when modifying assigned skills. ](/cms_trial/assets/e3908aa3-52a4-46c0-9f56-7108e57702d2.png)
2. A details pop-up will appear.
3. After making adjustments, click **Save**.

   ![Screenshot of saving changes after editing assigned skills.](/cms_trial/assets/752c74be-df70-4b3a-963a-8ce132f5f652.png)

#### Unassign skills

1. Click the **Delete** icon to unassign a skill from an individual.
2. Confirm the operation.

   ![Screenshot of unassigning skills. ](/cms_trial/assets/c7c564a6-badf-4fec-a132-79290a9bf4ca.png)

See the [Assign skills to individuals](/cms_trial/space/SPM/1918862960/Assign+skills+to+individuals/) page for more information.
