# Edit tasks in the Calendar module

You can edit task details in the following ways:

- Click the task on the calendar or in the **Upcoming Tasks** section. A task details dialog box will appear.

You can inline edit the **summary**, **start date**, **end date**, **assignee**, and **status** directly on the task details dialog box.

![Screenshot of inline editing a task in the Calendar module.](/cms_trial/assets/e859e8a4-c647-45a5-9f68-bd6559b0b878.png)

- Click the task on the calendar or in the **Upcoming Tasks** section, and then press the **e** button on your keyboard. A task details screen will appear.
- Right-click the task on the calendar or in the **Upcoming Tasks** section (anywhere but the Jira key). A context menu will appear. Select the **Edit** option.

![Video of right-clicking a task and making edits in the Calendar module.](/cms_trial/assets/a3f4b48f-cd41-4d71-befd-ef7ecffd6caa.mp4)
