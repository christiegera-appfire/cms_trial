# Manage absences

## Manage absences (old navigation)

A Jira or app Admin must first enable users to self-manage their absences in their profile settings by toggling the [Absences are self-managed by App’s user](/cms_trial/space/SPM/1918636014/Resources+(App+configuration)/) option.

## How to access the Absences page

To access your settings and see the absence cards, you can use the following methods:

### **Method 1: Dropdown menu**

Click your avatar in the top right corner and select **Absences**:

![Accessing the Absences page via the dropdown.](/cms_trial/assets/131ae1ed-a7de-4992-9aaf-240aad943f5f.png)

### **Method 2 (Data center): My settings**

Click **BigPicture** > **My** **settings** > **Absences**.

![Accessing personal settings for managing personal absences.](/cms_trial/assets/6c8e8985-8d60-45b2-936a-56a605119da7.png)

## Add absences

### From the My settings page

To add an absence:

1. Go to the *Absences* page.
2. Click **+Add new**.
3. Provide the following data:

   - Name
   - Start date
   - End date
   - Comment (optional)
4. For a partial absence, use the **Partial absence on selected days (in hours)** toggle.
5. To add another absence, check the **Add another** box.
6. Click **Add** to confirm.

   ![Screenshot of the Add absence window.](/cms_trial/assets/bc808da3-aabd-4445-b1ab-55f030413d52.png)

The absence will immediately be visible on the list.

### Partial absences (in hours)

You can plan partial absences for individuals. Enable the **Partial absence on selected days (in hours)** toggle and specify the absence duration in hours. Use the +0.5h, +1h, +2h, or +4h buttons to quickly adjust the duration.

![Screenshot of adding a partial absence.](/cms_trial/assets/9bae2e11-63f4-4e79-8c10-74937064ea81.png)

The maximum allowed duration is 8 hours. If you exceed this limit, an error message appears.

![Screenshot of an error message that appears if the entered partial absence is more than 8 hours. ](/cms_trial/assets/5ef3776f-c1aa-4017-a21e-632285b46899.png)

### From the Resources module

In the Resources module, you can right-click on the resource name > **Add absence** to access the form.

![resources-module-add-absence.png](/cms_trial/assets/a6d43b4f-2629-4e21-8ab6-3830d5f1d33e.png)

## Edit absences

To edit an absence:

1. Go to the *Absences* page.
2. Find an absence to edit and click the **Edit** icon on the right.
3. Make changes in the dialog.
4. Click **Save** to confirm.

## Delete absences

To delete an absence:

1. Go to the *Absences* page.
2. Find the absence you want to delete and click the **Delete** icon on the right.
3. Click **Delete** to confirm.

![Absences screen with the absence deletion confirmation box.](/cms_trial/assets/55496ddb-e552-4e28-baca-932e5e04a9d6.png)
