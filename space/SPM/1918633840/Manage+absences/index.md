# Manage absences

Jira/App Admin must first enable the users to self-manage their absences in their profile settings by toggling the [Absences are self-managed by App’s user](/cms_trial/space/SPM/1918636014/Resources+(App+configuration)/) option.

## How to access the Absences page

To access your settings and see the absence cards, you can use the following methods.

### **Method 1: Dropdown menu**

Click your avatar in the top right corner and select **Absences**:

![Accessing the Absences page via the dropdown.](/cms_trial/assets/93c8845e-e131-461b-9016-f15beb61393f.png)

### **Method 2 (Data center): My settings**

Click **BigPicture** > **My** **settings** > **Absences**.

![Accessing personal settings for managing personal absences.](/cms_trial/assets/95e0c441-4afe-498a-b3df-6c5a6e063134.png)

## Add absences

### From the My settings page

To add an absence:

1. Go to the **Absences** page.
2. Click **Add new** on the right.
3. Provide the following data

   1. Name
   2. Start date
   3. End date
   4. Comment (if needed)
4. To add another absence, check the **Add another** box.
5. Click **Add** to confirm.
6. The absence will immediately be visible on the list.

   ![Screen Recording 2022-01-28 at 10.48.27.mov](/cms_trial/assets/aa43dc4b-89dc-4f54-ade6-f2641cbb7a67.mov)

### Half-day absences

You can also submit absences for half a day only. To do so, toggle the **Half-day absence in selected days** slider on the **Add Absence** screen.

![Half-day absence switch.](/cms_trial/assets/dbf42b51-c48e-43fb-8dfa-ad8f61ea325f.png)

Note that entering a date range and selecting a half-day absence will decrease the capacity for each specified day by 50%. This means that half-day will apply to each day within the selected date range.

### From the Resources module

In the Resources module, you can right-click on the resource name > **Add absence** to access the form.

![resources-module-add-absence.png](/cms_trial/assets/f289db00-058f-46ed-aa37-8f8a2a65c5ea.png)

## Edit absences

To edit an absence:

1. Go to the **Absences** page.
2. Find an absence to edit and click the **Edit** icon on the right.
3. Make changes in the dialog modal box.
4. Click **Save** to confirm.

![A Modify Individual's Absence details screen.](/cms_trial/assets/f82abfdf-2bb6-41ea-bbcb-25c99b49dd06.png)

## Delete absences

To delete an absence:

1. Go to the **Absences** page.
2. Find an absence to edit and click the **Delete** icon on the right.
3. Click **Delete** to confirm.

![Absences screen with the absence deletion confirmation box.](/cms_trial/assets/8d9703b4-b907-4216-8dba-8fc220377270.png)
