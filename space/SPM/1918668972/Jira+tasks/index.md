# Jira tasks

You can [create Jira tasks](/cms_trial/space/SPM/1918800322/Create+tasks/) in BigPicture and [add the existing ones to a box](/cms_trial/space/SPM/1918667878/Add+existing+tasks+to+a+box/).

Connecting a Jira project to BigPicture automatically imports and syncs your existing Jira work items, including Epics, Stories, Tasks, and Bugs. Updates made in Jira—such as status changes or due date updates —are reflected in BigPicture and the other way around.

Once imported or created, you can manage Jira tasks through various modules:

## Scope module

- Displays issues in a hierarchical structure (for example, Epic → Story → Sub-task).
- Enables you to group, filter, and reorganize tasks for improved visibility.
- Allows adding custom hierarchy levels (for example, Initiative → Epic → Story).

[**Read more**](/cms_trial/space/SPM/1918666763/Scope+module/)

---

## Gantt module

- Visualizes Jira work items on a timeline.
- You can schedule tasks by changing the taskbar’s position and length on the Gantt chart.
- Add start/end dates and dependencies or create milestones based on Jira issues.

[**Read more**](/cms_trial/space/SPM/1918797129/Gantt+module/)

---

## Board module

- Provides an Agile view for tracking work using Scrum boards or Kanban boards.
- Syncs with Jira boards and supports sprint planning directly within BigPicture.

[**Read more**](/cms_trial/space/SPM/1918796888/Board+module/)

---

## Resources modules

- Visualizes Jira work items on a resource grid and in the Backlog panel.
- Enables you to group, filter, and reorganize tasks for improved visibility.
- You can schedule tasks by changing the taskbar’s position and length on the resource grid.
- Assigning and re-assigning tasks by moving them to the respective swimlane.

[**Read more**](/cms_trial/space/SPM/1918535629/Resources+module/)
