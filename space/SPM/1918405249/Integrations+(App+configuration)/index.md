# Integrations (App configuration)

## Integrations (App configuration) (old navigation)

## About integrations

You can connect with platforms other than your Jira instance to plan and coordinate your team's work if they prefer to use different tools, such as Trello or other Jira instances. You can connect to [Trello Boards](/cms_trial/space/SPM/1918536760/Connect+Trello/) and [additional Jira Cloud instances](/cms_trial/space/SPM/2214658323/Connect+another+Jira+instance+to+BigPicture/).

## Security and access

You add a new integration using the **+Add new integration** button in:

- **Box configuration** > **Tasks** > **Scope definition**
- **App configuration** > **Integrations** > **Connections**

## Manage connections

### Main connection

Your host platform, or, in other words, the Jira instance you are currently using.

![Screenshot of the Integrations page in App Configuration.](/cms_trial/assets/6062759a-af10-4d25-b4db-9abe62c77d0d.png)

### Edit connections

Click the pen button (icon) to change the connection name.

![Screenshot of the Edit icon in the Integrations page of App Configuration.](/cms_trial/assets/310b1ee7-d3fb-4730-935a-1d68270e454c.png)

### Add new connections

Read about adding new connections on the next pages:

- [Connect another Jira instance to BigPicture](/cms_trial/space/SPM/2214658323/Connect+another+Jira+instance+to+BigPicture/)
- [Connect Trello](/cms_trial/space/SPM/1918536760/Connect+Trello/)

### Delete connections

If you delete a connection, all the tasks added to the scope of the box and its sub-boxes will be removed.

Before you terminate a connection, make sure that users confirm that it is no longer used; otherwise, they will be required to redefine the scope and lose some of the current task structure.

![Screenshot of deleting a connection on the Integrations page in App Configuration.](/cms_trial/assets/1bf87d63-42ce-4d33-b39f-66327483c285.png)
