# Edit risk calculation

## Edit risk calculation (old navigation)

Click to expand the guide

To learn more about risk calculation attributes, see the [Risk register frameworks](/cms_trial/space/SPM/1918865091/Risk+register+frameworks/) page.

To edit a risk calculation:

1. From the **Risk management** module, click the risk register name.

   Image — asset pipeline pending  
   Risk management module showing an example register name.
2. Click the **Settings** button.

   Image — asset pipeline pending  
   A Risk Register showing the Settings button.
3. Select the template you want to edit.

   Image — asset pipeline pending  
   Risk register settings page showing where to select the template you want to edit.
4. Make changes. See the [Risk register frameworks](/cms_trial/space/SPM/1918865091/Risk+register+frameworks/) page to see what changes you can make to risk calculation attributes.
5. When ready, click **Save changes** at the top.

   Image — asset pipeline pending  
   Risk Register settings page showing the Save changes button.

## Edit risk calculation (new navigation)

Click to expand the guide

To learn more about risk calculation attributes, see the [Risk register frameworks](/cms_trial/space/SPM/1918865091/Risk+register+frameworks/) page.

To edit a risk calculation:

1. From the **Risk Management** module, click the risk register name.
2. Select **Configuration** from the dropdown menu.

   Image — asset pipeline pending  
   Screenshot of selecting the Configuration button from the drop-down menu in the Risk Management module.
3. Select the template you want to edit.

   Image — asset pipeline pending  
   Risk register frameworks are highlighted on the risk register page.
4. Make changes. See the [Risk register frameworks](/cms_trial/space/SPM/1918865091/Risk+register+frameworks/) page to see what changes you can make to risk calculation attributes.
5. When ready, click **Save changes** at the top.
