# Plan delay report

## About the Plan delay report

Plan delay reports provide information on task delays on all hierarchy levels, with a set **Baseline End Date**field.

![Plan delays window with one row highlighted](/cms_trial/assets/4a336a9a-7dfc-4131-84bf-b02a353029df.png)

Hold the pointer over a task name to display a tooltip with the task's status in round brackets.

Tasks are sorted by **End Date.**

## **Report configuration**

In the plan delays report, you can edit the report configuration to:

- show **only the open delayed tasks** versus the plan - to monitor current delays
- show the **closed delayed tasks** - to check the number of delayed tasks versus the plan after finishing the project
