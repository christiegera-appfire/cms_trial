# Column views

## Column views (old navigation)

Click to expand the guide

## Overview

Column views organize your project data in a clear, table-like format. Each column has a title, and each row shows information for one box or task’s item, such as Assignee, Start Date, Duration, etc., making your projects and portfolios easier to scan and manage.

You can customize the view by adding new and deleting existing columns and customizing their aggregation method (if applicable).

You can find column views in the modules and features that support tree data structure. These are:

- [Overview module](/cms_trial/space/SPM/1918700155/Column+view+(Overview+module)/)
- [Scope module](/cms_trial/space/SPM/1918666763/Scope+module/)
- [Gantt module](/cms_trial/space/SPM/1918668270/Column+view+(Gantt+and+Scope+modules)/)
- [Board module](/cms_trial/space/SPM/1918537147/Column+view+in+backlog+(Board+module)/) (**Backlog** section in the Infobar panel)
- [Risks module](/cms_trial/space/SPM/1918666681/Risks+module/) (**Table** view)
- Gantt gadget
- App widget
- WBS widget

## Source of data in column views

The data in the columns comes from the in-app fields and Jira fields. What you see in each column depends on how your fields are mapped in the app. To ensure your columns display the correct data, be sure to check your [field mapping settings](/cms_trial/space/SPM/1918700586/Field+mapping/).

## Configure column views

Only Jira/App Admins and Box Editors can configure and save column views.

### Box/Box type configuration page

Column views for the Overview, Scope, and Gantt modules can be configured on the individual box and the box type [configuration pages](/cms_trial/space/SPM/1918503715/Manage+column+views/).

Image — asset pipeline pending  
Box configuration page.

### Module, gadget, and widget pages

You can also [customize the column view](/cms_trial/space/SPM/1918504788/Customize+column+views/) directly on the view while in the selected module, gadget, or widget. Save your changes as a new view, so that you can switch to that view again when you need it. Note that you cannot save changes in the column view in the Board module, Risks module, and Gantt gadget.
