# OKR report

The OKR report in the Reports module is available onlyin [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). This feature is not available in BigPicture Standard.

## About the OKR report

The OKR report available in the Reports module provides an overview of Objectives and Key Results (OKRs) within a selected box, helping you monitor progress and identify areas that need attention.

The OKR report respects your OKR permissions. You can only see Strategic Themes, Objectives, and Key Results that you have permission to access.

![Screenshot of the OKR report in the Reports module.](/cms_trial/assets/74301002-b0e9-4379-bf8f-5b1bd2881f14.png)

## Add OKR report

To add the OKR report to your dashboard:

1. In **Edit mode**, click **+Add report**.

   ![Screenshot of the Add report button in the Reports module.](/cms_trial/assets/b43e0ac1-57af-4282-b2ab-f9d72e4d9c37.png)
2. Select **OKR** from the list.

1. In the *OKR report configuration* window, configure the report by selecting one or more filters:

   1. **Periods** – filter OKRs by their assigned periods.
   2. **Labels** – include OKRs with specific labels.
   3. **OKR types** – filter by OKR type.
   4. **Owners** – display OKRs assigned to selected owners.
   5. **Teams** – filter OKRs by associated teams.
   6. **Statuses** – include OKRs with selected statuses.
   7. **Expected start date** – specify a date range for the expected start date.
   8. **Expected end date** – specify a date range for the expected end date.

![Screenshot of the OKR report configuration window in the Reports module.](/cms_trial/assets/dd01954e-ffa9-48f2-8a8e-276b179c8ad6.png)

1. When ready, click **Save**.
2. The OKR report will be added to your dashboard.

## OKR report details

The OKR report consists of the following sections:

- OKR status overview
- Detailed OKR breakdown

### OKR status overview

At the top of the report, donut charts summarize the status of Objectives and Key Results separately. The charts also display the number and percentage of items in each status, making it easier to assess overall OKR performance.

![Screenshot of the OKR status overview section.](/cms_trial/assets/99b9d831-8dd3-4048-8fbb-597e8af61a6f.png)

### Detailed OKR breakdown

Below the charts, the report displays the OKR hierarchy, including Strategic Themes, Objectives, and their associated OKRs.

Each Strategic Theme and Objective is presented with its name, description, progress percentage, and status, helping you understand how progress is distributed across different levels of your OKR hierarchy.

![Screenshot of the Strategic theme description in the Reports module.](/cms_trial/assets/9f8d8e58-bc3d-4bcb-a8bd-cf08b64fe036.png)

The associated OKRs are displayed in tables with the following information:

- Key and name
- Status
- Progress
- Owner
- Expected start and end dates

![Screenshot of the OKR report with the OKR table highlighted.](/cms_trial/assets/1b2931c3-dbff-48b9-8d23-423eff9d969c.png)
