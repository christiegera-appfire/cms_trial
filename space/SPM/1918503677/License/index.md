# License

The **License** page provides information about the current app license.

It shows:

- App tier product license
- License status

![License page on the app configuration page.](/cms_trial/assets/35705b1a-a24c-4eaf-b2f3-798516fa32b2.png)

## Security and access

Only Jira/App Admins can manage the app on the global (app) configuration level.

To access the license page:

1. Click the **wrench icon** in the top right corner.
2. Select **License** from the dropdown.
