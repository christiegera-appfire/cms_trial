# Move tasks (swimlanes, timeline)

In the **Resources module**, you can change the following details of a task:

- assignee
- team
- skills

You **CAN’T** change the project. Project swimlane switches are blocked.

## Multiassignment

Multissignment is possible for:

- skills - one task can have many skills assigned
- boxes - one task can be in many boxes

## Move tasks

You can move tasks between swimlanes and from the Backlog panel. See the [Move tasks page](/cms_trial/space/SPM/1918864819/Move+tasks/) for more information.
