# Multi-team planning

## Multi-team planning fields

You can allocate multiple teams to selected tasks to **perform long-term planning** without dividing initiatives into small tasks for separate teams. Calculate how many resources the plan requires and how many remain for other topics.

![image-20260309-133152.png](/cms_trial/assets/664c3a9c-7ae1-455d-8755-0a8c294866cb.png)

Two fields can be used:

- **Multi-team planning (Story Points)**
- **Multi-team planning (Time Estimates)**

The fields allow you to assign a team and its effort to a task:

![image-20260309-133752.png](/cms_trial/assets/e8014aaf-ef93-4f08-b843-e4c8ca961ceb.png)

**Note**: The **multi-team estimates are stored in BigPicture** and aren’t connected to any Jira field - they do not affect the estimate and team fields of tasks. This lets you later easily compare the initial plan to the actual execution. This lets you easily compare the actual work done to the initial plan later.

![image-20260309-135518.png](/cms_trial/assets/32b6b5d9-236a-4e61-8bf2-6152a0106321.png)

## Workload vs capacity estimations

Use the **resources panel** to see how the workload estimation calculations. Make sure to adjust the view settings to see the calculations for the planning data.

**Note**: For the calculations to work, the tasks need to have start and end dates.
