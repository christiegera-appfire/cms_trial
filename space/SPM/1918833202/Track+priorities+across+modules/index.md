# Track priorities across modules

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

## Track the progress of priorities

### Tasks and goals

You can track the progress of prioritized tasks (Jira work items) and goals (OKRs) by switching to the predefined **Priorities column view** in the **Gantt and Scope modules** or by adding the **Priority score** column to the module view.

Recommended use of the Priority score column in the Gantt module:

- Use the Priority score column during planning to focus on high-impact tasks and goals and ensure your efforts are aligned with key priorities.
- In status sync meetings, use the Priority score column to stay informed about potential blockers in high-priority initiatives and swiftly adjust delivery plans throughout the year.

### Boxes

You can track prioritized boxes by adding the **Priority score** column to the Overview module.

## Predefined Priorities column view

To enable the predefined **Priorities** column view in the Gantt module:

1. Go to the Gantt module.
2. Expand the column view dropdown menu.
3. Select **Priorities**.

   ![Screenshot of switching to the Priorities view in the Gantt module.](/cms_trial/assets/26233749-0395-40ec-b3c2-37f61e69f6af.png)
4. Once applied, you can track priorities using the Gantt module.

   ![Screenshot of the Priorities column view enabled in the Gantt module.](/cms_trial/assets/43f8bfee-96bd-43a2-a32d-a242b4be9ab6.png)

## Priority score column

You can add the **Priority score** field to a column view in the Overview, Gantt, Scope, Board Backlog, and Risks modules.

![Screenshot of adding the Priority score to the column view in the Gantt module.](/cms_trial/assets/367cffe3-5608-4650-a376-c4690b50b1f5.png)

### Inline edit Priority score details

To inline edit Priority score details:

1. Click the **Priority score value**.
2. Inline edit values in a new window.

   ![Screenshot of inline editing a priority values in the Gantt module.](/cms_trial/assets/23ac8ea5-243e-4266-b26e-9b1d6a9faac9.png)
3. Click the **Go to priorities** button to move to the **Priorities** **module**.

   ![Screenshot of the Go to priorities button when editing priority values in the Gantt module.](/cms_trial/assets/9758412c-8867-4be9-b895-ebc51f3a0ad1.png)

### Customize the Priority score column in Gantt and Scope

When you add the **Priority score** column in the Gantt and Scope modules, you can customize it using the following actions:

- Pin column
- Sort tasks
- Customize aggregation and display options
- Resize all columns to fit
- Remove column

![Screenshot of customizing the Priority score column in the Gantt module](/cms_trial/assets/61712ca5-9276-4470-b301-b05ea98029fb.png)

#### Sort by the Priority score column

Sort tasks and initiatives by the Priority score column to see the most important tasks at the top of the Gantt structure.

![Screenshot of sorting tasks and initiatives by the Priority score column in the Gantt module.](/cms_trial/assets/6077c46d-1966-4ec9-a3c0-5d3a02ea5ad6.png)

### Jira Priority column

The priority scores you assign to your tasks do NOT affect the Jira native **Priority** column. You can manually inline edit the Priority column in the Gantt and Scope modules.
