## About box scope

The box scope is a defined collection of tasks. Tasks can be added to the scope manually or automatically synchronized with Jira or connected tools such as Trello.

In the scope definition, you can specify what range of tasks is included in the scope of a given box (or a sub-box) - those are the tasks you will be able to work on in the App (visualize them on a Gantt chart, manage risks, distribute workload, etc.). You can include multiple Jira projects, simultaneously include tasks from different external tools (such as Trello and Jira), or include only some tasks that meet your particular specifications. The flexibility of the setup ensures that a box can be configured to contain exactly the tasks you need to fit your work.

Less frequently used settings have been hidden under **Advanced configuration**.

There are three different scope types (those settings are [adjusted for a box type](https://appfire.atlassian.net/wiki/spaces/SPMDRAFT/pages/1858864073/Scope+definition+box+types?force_transition=71b47b01-cff8-41bd-bee2-c5d1099fd965)):

- [Own-scope](/cms_trial/space/SPM/1918765868/Own-scope/)
- [Sub-scope](/cms_trial/space/SPM/1918799715/Sub-scope/)
- [None (aggregations only)](/cms_trial/space/SPM/1918537743/None+(aggregations+only)/)

## Security and access

Keep in mind:

- A box type contains the default settings applicable to multiple boxes (all boxes of a given type). Those settings are adjusted in the BigPicture Administration. See the <https://appfire.atlassian.net/wiki/spaces/SPMDRAFT/pages/1858864073/Scope+definition+box+types?force_transition=8029dab3-2973-4917-8212-7611da489c8a> page for more information.
- Box configuration refers to the settings of a single, individual box. They are dependent on the box type settings.

The table presents what you can configure on the box configuration page.

| **Area** | **Security and access** | **What can be configured** |
| --- | --- | --- |
| Box configuration | Box admins, Jira admins, and BigPicture admins can access and manage the box configuration.
