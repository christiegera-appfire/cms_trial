## Create a portfolio box in the Overview module

### +Add new (button)

1. Go to the **Home (root) box** > **Overview module**.
2. Click the **+Add new** button.
3. Select the **Portfolio** box type.
4. Enter:

   1. Name (required)
5. Start and end dates are automatically set to today. You can edit start/end dates now or later.
6. Change:

   1. Icon (optional)
   2. Icon color (optional)
7. Click **Create**.

The interactive tutorial presents how to create a portfolio box.

### +Add new (contextually)

1. Mouse over the line separating the boxes until the **plus** (**+**) **icon** appears.
2. Click it.
3. Select the **Portfolio** box type.
4. Enter:

   1. Name (required)
5. Start and end dates are automatically set to today. You can edit start/end dates now or later.
6. Change:

   1. Icon (optional)
   2. Icon color (optional)
7. Click **Create**.

## Create a portfolio box in the Overview module

### Create new (via button)

1. Go to the **Main box** > **Overview module**.
2. Click the **Create new** button.
3. Modal displays. On the modal, under the **Type**, select **Portfolio**.
4. In the **Name** field, enter the name of your portfolio box. You can leave the default name and edit it later.
5. Start and end dates are automatically set to the current date. You can edit them now or later.
6. Optionally, change the icon and the icon background color to improve identification within the box hierarchy.
7. Click **Create**.

<https://app.arcade.software/share/wsy9gFH9PWktRfvc88Bn>

### Create new (via quick action)

1. Go to the **Main box** > **Overview module** (Hierarchy mode).
2. Click the middle arrow to expand **Quick actions**.
3. Open a dropdown on the **Create new** tile.
4. Select **Portfolio** from the list.
5. Modal displays. On the modal, in the **Name** field, enter the name of your portfolio box. You can leave the default name and edit it later.
6. Start and end dates are automatically set to the current date. You can edit them now or later.
7. Optionally, change the icon and the icon background color to improve identification within the box hierarchy.
8. Click **Create**.

<https://app.arcade.software/share/GRri7jKp8D3NcJq9UW9n>

### +Add new (contextually)

1. Go to the **Main box** > **Overview module** (Hierarchy mode).
2. Mouse over the line separating the boxes until the **plus** (**+**) **icon** appears. Click it.
3. Modal displays. On the modal, under the **Type**, select **Portfolio**.
4. In the **Name** field, enter the name of your portfolio box. You can leave the default name and edit it later.
5. Start and end dates are automatically set to the current date. You can edit them now or later.
6. Optionally, change the icon and the icon background color to improve identification within the box hierarchy.
7. Click **Create**.

![create-box-inline.png](/cms_trial/assets/7baa26e1-ca11-4da1-abbd-676ef6b36ecc.png)

## Limitations

- You **cannot create a sub-box** under a closed or archived parent box. The plus icon is grayed out.
