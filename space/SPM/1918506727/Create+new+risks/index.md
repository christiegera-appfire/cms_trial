# Create new risks

## Create new risks (old navigation)

Click to expand the guide

You can create new risks directly in the Risk management module.

1. From the **Risk management** module, click the risk register name.
2. You are redirected to the risk register table.
3. Click **Create new risk**.
4. Select a project where you want to create a new risk.
5. Define an issue type.

Select from the issue types defined during the risk register setup. If an issue type does not appear on the list, it is either not selected in the risk register settings or unavailable in the Jira project.

1. Complete **Summary**.
2. When ready, click **Create**. The newly created risk appears at the top of the table.
3. To provide more details, click it to see a full-size view.

See an interactive demo on how to create a new risk.

## Create new risks (new navigation)

Click to expand the guide

You can create new risks directly in the Risk Management module.

1. From the **Risk Management** module, click the risk register name.
2. You are redirected to the risk register table.
3. Click **+** **Create risk**.
4. Select a space where you want to create a new risk.
5. Define a work item type.

Select from the work item types defined during the risk register setup. If a work item type does not appear on the list, it is either not selected in the risk register settings or unavailable in the Jira space.

1. Complete **Summary**.
2. When ready, click **Create**. The newly created risk appears at the top of the table.
3. To provide more details, click it to see a full-size view.

See an interactive demo on how to create a new risk.
