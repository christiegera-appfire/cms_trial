# Overdue tasks (Infobar)

## Overdue tasks (Inforbar) (old navigation)

The **Overdue task** tab of the Infobar displays the following information:

- [The overdue task](/cms_trial/space/SPM/1918537803/Overdue+tasks/) (the due date of the task has elapsed and the task hasn't been completed)
- Overdue task’s end date
- Total number of overdue days
