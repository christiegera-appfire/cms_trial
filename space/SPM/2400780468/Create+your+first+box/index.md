# Create your first box

## What will I learn on this page?

> 💡 On this page, we will show you how to get tasks from your Jira space into BigPicture.

You will learn:

- What **boxes** are in BigPicture.
- How to **create** a box.

In this example, you will work with a Waterfall box, but the process of creating a box is the same for other box types. You can apply this knowledge later when creating other boxes.

## Why do I need boxes?

A box lets you select and store data you want to work with.

It is a customizable, structured space (a container) for organizing and visualizing your project, program, and portfolio elements, such as tasks, deliverables, resources, risks, and even sub-boxes.

Boxes are equipped with all the essential tools for efficient management, allowing you to adapt to various project management approaches, including Agile, scaled Agile, Hybrid, and Waterfall. You can also customize them to support unique methodologies that do not fall into any of those categories.

Each box can be customized based on the specific tools (modules) needed for your project, the scope of work, and the security roles required to view and manage the box. When you set up a box for your project, you can track its status and progress in the Timeline view of the Overview module.

## Create a box step-by-step

Boxes are typically created in the Overview module, but other methods are available. Check the **Learn more** section at the bottom to read about methods.

You automatically become a Box Admin of any box you create. This role lets you fully manage the box settings and box contents.

### Access the app

### Create a box

1. Open the BigPicture app from the **Jira header** > **Apps**. You are now in the Overview module.
2. Click the **+Add new** button.
3. The modal displays. On the modal, you are asked to provide the following box details (the asterisk \* indicates mandatory fields):

   1. **Type\***: From the dropdown, select a box type for your tasks. In this example, we will choose the **Classic project** as a boxfor the Waterfall project.
   2. **Name\***: Name your new box, for example, *Financial and Risk Assessment*.
   3. **Icon and color**: Icons are optional, but they are a handy visual element that helps to recognize the box on the list. For this project, we will leave the default icon and color.
   4. **Start date\***: Click the date field to activate the date picker. Select the start date for the box, or manually type the date.
   5. **End date\***: Activate the date picker and select the end date for the box.
   6. **Jira Spaces**: Select one or several Jira spaces from the dropdown that you want to add to the box, or leave it blank for now.  
      important The tasks in your box can be based not only on Jira spaces, but also on Jira boards, which can be narrowed down by labels and JQL filters. In the [next course](/cms_trial/space/SPM/2400714956/Populate+a+box+with+Jira+work+items/), you will learn how to use the advanced box configuration to add the exact tasks you want.
4. Click the **Create** button to finish creating the box.

The box is now listed in the Overview module (root box). You can see it was automatically assigned the **Not started** status. Once you move on to further courses, you will learn how to change the box status.

## Prerequisites

- You already [have a Jira space](https://support.atlassian.com/jira-software-cloud/docs/create-a-new-project/). Your Jira space and BigPicture must be present on the same Jira Cloud instance.
- Jira/App Admin granted you access to BigPicture.
- You are permitted to create boxes under the Home/root box.
