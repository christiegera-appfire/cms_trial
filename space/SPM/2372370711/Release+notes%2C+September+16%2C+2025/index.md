# Release notes, September 16, 2025

**Release date**: September 16, 2025

Our team is thrilled to announce the latest release of BigPicture Enterprise Cloud.

---

## New

## AI Agent

rolling out

We’re introducing an **AI Agent** to help you quickly get in-context answers from our documentation. The agent provides direct responses with links for deeper reading. You can access the agent by using a dedicated icon in the top menu, which opens a popover where you can ask questions, use suggested prompts, and provide feedback on responses.

This feature is rolling out gradually, starting with a limited group of customers.

The AI Agent does not access your company’s instance, so it can’t help with custom implementations or data-specific issues. For those, contact our [support team](https://appfire.atlassian.net/servicedesk/customer/portal/11).

## Notes

You can create notes for Jira work items, BigPicture boxes, and basic tasks. Notes are useful for documenting details, capturing decisions, and sharing updates. Because they are public, they also act as a communication channel, ensuring everyone is up-to-date.

Learn more on the [Create notes](/cms_trial/space/SPM/2372665547/Create+notes/) page.

![Screenshot presenting the new option to add notes to tasks.](/cms_trial/assets/8f96176d-58db-4701-bca1-ba2a863b35f1.png)

## Priority icon next to the taskbar (Gantt module)

Select the **Taskbar > Priority** option to display the **Priority icon** on the left side next to the taskbar on the Gantt timeline. The value is taken from the built-in Priority field.

Learn more on the [Taskbar](/cms_trial/space/SPM/1918637856/Taskbar/) page.

![Screenshot presenting the Priority icon next to the taskbar in the Gantt module.](/cms_trial/assets/c0206fb2-5cde-441a-ae27-f3c7b87caf26.png)
