# Convert milestone to task

In the Gantt module, you can convert a milestone to a task (and a [task to a milestone](/cms_trial/space/SPM/1918537200/Convert+task+to+milestone/)). Milestones can be converted to tasks in [bulk](/cms_trial/space/SPM/1918832779/Multiselect+tasks/).

A task converted from a milestone will have the start and end dates the same as the date of the milestone it was converted from.

## Context menu

1. Right-click a milestone or a diamond on the timeline to prompt the context menu.
2. Select **Convert to task**.

![A menu from where you can select to convert a milestone to a task.](/cms_trial/assets/a72e9d15-2215-42c6-b3b7-be1235297eab.png)

## [Editor slider](/cms_trial/space/SPM/1918635307/Editor+slider/)

1. Select a milestone or a diamond on the timeline to highlight it and prompt the editor slider.
2. From the editor slider, select **More actions** (**…**) > **Convert to task**.

![A menu from where you can select to convert a milestone to a task.](/cms_trial/assets/451d429b-9a18-4191-a280-7323c99b2009.png)
