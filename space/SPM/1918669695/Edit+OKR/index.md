# Edit OKR

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

You can modify the details of Strategic themes, sub-themes, Objectives, sub-objectives, and Key Results on the fly.

## Edit OKR field

Similar to Jira fields, OKR fields can be [edited inline](/cms_trial/space/SPM/1918637324/Inline+edit/). To edit a field value, click it and enter a new value. Depending on the field type, you can:

- Enter a value manually (Text, Number)
- Select a value from the dropdown (Select, Multiselect)
- Use a date picker to specify the value (Date)

Some OKR updates must be completed in a separate modal window.

NOTE You cannot add/change the parent and edit OKR details of a [closed OKR](/cms_trial/space/SPM/1918800058/Close+OKR/). Also, after selecting a new period for the parent OKR, you will be asked whether you want to move all child OKRs to the new period as well.
