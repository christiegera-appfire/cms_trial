# Edit OKRs

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

Once created in the OKR module, you can modify the Objectives, sub-objectives, and Key Results. You can only edit one OKR at a time on its respective [*OKR details*](/cms_trial/space/SPM/1918536390/OKR+details+page/) page.

In addition to editing OKR details, you can carry out the following actions on the *OKR details* page:

- Update status
- Update progress (of a manual OKR)
- Restrict
- Convert
- Clone
- Close
- Delete
- Clear update history
- Add child OKRs (to a parent OKR)
- Add dependency link
- Add contribution link

## Edit OKRs

To edit Objectives, sub-objectives, and Key Results on their respective details pages:

1. On the *OKR details* page, click the respective field (or the pen icon, if applicable) to edit the details. OKR details are divided into the following sections:

- **Progress**
- **Info**
- **Alignment**
- **Linked work items** and **Linked boxes**

## Edit OKR field inline

Similarly to Jira fields, OKR fields can also be [edited inline](/cms_trial/space/SPM/1918637324/Inline+edit/). To edit a field value, left-click it and enter a new value. Depending on the field type, you can:

- Text, Number - enter a value manually
- Select, Multiselect, User - select a value from the dropdown
- Date - use a date picker to specify the value

![Date picker in the OKR module.](/cms_trial/assets/f27470f4-ec26-4edc-a9b0-4882a2c201c1.png)

You can edit field values in the OKR module on the following:
