# Effort modes

## About the effort modes

Effort modes in BigPicture determine the source of data used to calculate resource workload distribution. They let you estimate tasks and track the time your team members spend on them in three different ways:

- [Original estimate mode](/cms_trial/space/SPM/1918407058/Original+estimate+(Effort+mode)/): it shows the planned workload versus the resource capacity.
- [Remaining Estimate mode](/cms_trial/space/SPM/1918863764/Remaining+estimate+(Effort+mode)/): it shows resource workload history (Spent time) and the remaining workload versus the resource capacity.
- [Story Points mode](/cms_trial/space/SPM/1918506126/Story+points+(Effort+mode)/): it shows the planned workload versus the resource capacity expressed in story points.

The effort mode can be expressed in the following units:

- Hours
- Man-days
- Percent
- Story points

Note that not all units are available in every effort mode.

| **Effort mode** | **Unit** |
| --- | --- |
| Hours | Man-days | Percent | Story points |
| Original Estimate | Yes | Yes | Yes | No |
| Remaining Estimate | Yes | Yes | Yes | No |
| Story Points | No | No | Yes | Yes |

## Access the effort modes and units

You can find the effort mode and unit from the dropdown menu under the button with the “speedometer” icon on it.
