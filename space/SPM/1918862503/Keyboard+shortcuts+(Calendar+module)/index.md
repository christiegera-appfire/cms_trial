# Keyboard shortcuts (Calendar module)

## Keyboard shortcuts - Calendar module (old navigation)

Click to expand the guide

## Display available keyboard shortcuts

Click the **Get help** ( **i** )button in the upper-right corner menu (or press **Shift + /**) to display the keyboard shortcuts dialog box.

![Menu with options under the get help button.](/cms_trial/assets/6bd296c4-4057-4718-854a-e1762a3c2b7a.png)

## Calendar module shortcuts

The shortcuts listed in the box will only show the shortcuts applicable to the module you are viewing. The app will adjust the displayed shortcuts to your device system (Mac and Windows). Also, depending on your Windows device, you may need to use the **Fn** button in place of **Ctrl**.

The Calendar module’s keyboard shortcuts are divided into the following categories:

![A list of keyboard shortcuts in the Calendar module.](/cms_trial/assets/e48c8e3d-4b94-4b26-818a-6c8185ef6ab5.png)

### Task actions

| Add basic task | **Enter** |
| --- | --- |
| Edit task | **E** |

### Timeline

| Today | **Shift** + **0** |
| --- | --- |
| Previous small time period | **Shift** + **,** |
| Next small time period | **Shift** + **.** |
| Previous big time period | **Shift** + **Alt** or **Option** + **,** |
| Next big time period | **Shift** + **Alt** or **Option** + **.** |

### View

|  |  |
| --- | --- |
| Show or hide upcoming tasks | **]** |
| Show or hide heatmap | **H** |

### Layout

Change the row height of the layout.

| Compact | **Shift** + **C** |
| --- | --- |
| Regular | **Shift** + **R** |
| Wide | **Shift** + **W** |

### Navigation

|  |  |
| --- | --- |
| Context menu | Mouse **right-click** |

### Others

| Show/Hide menu | **Z** |
| --- | --- |
| Undo | **Ctrl** or **Cmd** + **Z** |
| Open the System-info dialog box | **Shift** + **I** |
| Play the BigPicture game | **Shift** + **Ctrl** or **Cmd** + **G** |
| Re-synchronize data | **Alt** or **Option** + **R** |
