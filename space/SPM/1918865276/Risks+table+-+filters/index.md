## Filtering options

The table presents the filtering options you can use to filter risks in the risk register.

| **Filtering option** | **Description** |
| --- | --- |
| Filter by name | To filter by a risk register name, start typing in the field to see the results. Risk register showing the search field. |
| Filter by status | Filter by statuses that issue types have assigned. Risk registers showing filtering by statuses. |
| Filter by assignee | Start typing a name to find the issue types to which a person is assigned. Check **Unassigned** to find risks without an assignee. Risk register showing risks filtered by assignee. |
| Filter by reported | Start typing a name to find the issue types reported by this person. Risk register showing risks filtered by issue type reported by a specific person.. |
| More filters | From the **More filters** button, you can select:   - Issue type - Component - Status category - Label - Epic   Once you select a particular filter, you’ll see a new button where you can choose elements to filter by. You can combine many filters at once. See the video below. 2025-03-20_16-32-12.mp4 |
