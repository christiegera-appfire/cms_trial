Risks table - filters

2 min read

Risks table - filters (old navigation)

Click to expand the guide

Filtering options

The table presents the filtering options you can use to filter risks in the risk register.

Filtering option

Description

Filter by name

To filter by a risk register name, start typing in the field to see the results.

Filter by status

Filter by statuses that issue types have assigned.

Filter by assignee

Start typing a name to find the issue types to which a person is assigned. Check Unassigned to find risks without an assignee.

Filter by reported

Start typing a name to find the issue types reported by this person.

More filters

From the More filters button, you can select:

  • Issue type

  • Component

  • Status category

  • Label

  • Epic

Once you select a particular filter, you’ll see a new button where you can choose elements to filter by. You can combine many filters at once. See the video below.

Sort by columns

Sort risks by column values in ascending and descending order.

Clear filters

To clear the applied filter, click the Clear filters button.
