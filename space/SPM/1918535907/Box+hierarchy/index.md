# Box hierarchy

## Box hierarchy (old navigation)

Click to expand the guide

In BigPicture, the box hierarchy provides a structured way to organize and manage projects, tasks, and teams within a larger framework. The hierarchy lets you create multiple levels of boxes, with each level containing relevant tasks, projects, or teams, enabling clear visualization and control.

By grouping related items together, you can easily manage complex portfolios and projects, ensuring better alignment and focus. The box hierarchy offers flexibility, allowing you to scale and adapt as your project needs to grow.

The diagram below shows an example of the Box hierarchy created using the default configuration.

## Portfolio

Company-wide portfolios often use different methodologies, including Agile, Waterfall, and Hybrid ones. If you want to manage all the projects and programs in the organization, you need a tool that accommodates all three approaches.

With the right PPM tool, you can display the entire portfolio of initiatives along with all the related data. You should also be able to aggregate the data to support easier decision-making. BigPictureallows for the creation of an entire landscape of programs, projects, and portfolios.

### Organize boxes into programs and portfolios

In BigPicture, the Program and [Portfolio boxes](/cms_trial/space/SPM/1918634872/Create+portfolio+box/) aggregate data from within the child boxes. To organize your boxes into portfolios, use drag and drop in the [Hierarchy mode](/cms_trial/space/SPM/1918799130/Hierarchy+mode/) of the [Overview module](/cms_trial/space/SPM/1918502655/Overview+module/). You can [add new boxes](/cms_trial/space/SPM/1918406376/Create+box/) to the Portfolio or move existing boxes.

## Example: Agile project

Visit the [Create box](/cms_trial/space/SPM/1918406376/Create+box/) page to explore all methods for creating a BigPicture box.

To create an Agile project box, follow the steps below:

1. Open the Main box in the Overview module.
2. Click the **Create new** button.
3. Select **AGILE - Agile Project** from the dropdown under **Type**.

![A modal for creating a new box i nthe Overview module. The box type dropdown lists various box types.](/cms_trial/assets/58238ba6-88c4-4208-b563-121099f9526e.png)

1. Name your box.
2. Enter start and end dates.

![Screenshot showing setting up the start and end date for Agile box type in BigPicture.](/cms_trial/assets/d5251acb-4f94-43c4-b612-b6a47b00c841.png)

1. Click **Create**.

### Adjust dates on the timeline

In the Overview module (Main box), switch to the [Timeline mode](/cms_trial/space/SPM/1918538282/Timeline+mode/) to adjust the dates directly on the timeline.

![Overview module, Main box, timeline mode.](/cms_trial/assets/f31babf5-bde6-468f-bde7-3aff177260ba.png)
