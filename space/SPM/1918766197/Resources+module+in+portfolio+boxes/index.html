Resources module in portfolio boxes

5 min read

Resources module in portfolio boxes (old navigation)

Click to expand the guide

Portfolio boxes help you organize your work and provide you with reporting capabilities. 

To find out more, check the Create portfolio box page.

Manage Portfolio box in Resources module

You can create a Portfolio box in the Overview module.

If you open a Portfolio box in the Resource module, you may encounter the following issues:

There is no data to aggregate - add boxes

The Resources module in a Portfolio box aggregates data from sub-boxes. No sub-boxes were detected. The Portfolio box is empty. To use the Resources module, add sub-boxes to a Portfolio.

Create new boxes

  1. Click Add items.

  2. Select Import Jira Projects and click Add.

  3. Select one or more Jira projects to import.
    If you select multiple projects, you can enable the toggle switch to create a separate box for each Jira project.

  4. Define the box type.

  5. When ready, click Import.

  6. New sub-boxes are now visible.

Move existing boxes

  1. Click Add items.

  2. Select Add existing.

  3. Select boxes. You can move multiple boxes at the same time.

  4. Click Add.

There is no data to aggregate - add tasks

The Resources module in a Portfolio box aggregates data from sub-boxes. Sub-boxes are empty. To use the Resources module, add tasks to boxes.

Add tasks (Overview module)

Add tasks to boxes in the Portfolio. Repeat for all boxes. 

  1. Go to the Overview" module.

  2.  Right-click OR the More actions button.

  3. Go to Tasks > Scope definition

  4. Define the scope - you can use Jira projects, Jira boards and Jira filters.

  5. Optional: Use the "narrow down" field to exclude tasks.

Add tasks (already existing in Jira)

To add tasks to the first Box you can use the following process.

  1. Click the "Add tasks".

  2. Select a box (step available only when you have multiple boxes).

  3. Click Add tasks.

  4. Click Manage Scope definition.

  5. Define the scope - specify which Jira tasks should be included. You can add entire Jira projects, Jira boards or use Jira Filters. 

  6. Optional: Use the Narrow down field to exclude tasks.

  7. Click Save.

Filters

Use filters for portfolio boxes in the Resources module. Filters allow you to narrow down the data you display.

Resources module in Portfolio - troubleshooting and setup

The Resources module in a Portfolio box aggregates data from all boxes in the portfolio.

The view is based on individual users or teams.

Portfolio box teams

A portfolio should have the same teams as the boxes it contains.

Issue: Capacity can't be calculated because there are no team members in Portfolio teams.

Solution: Assign teams to the portfolio Box.

  1. If the Teams module is not active, activate it.

  2. Go to the Teams module in the Portfolio.

  3. Use the "Assign existing team" option.

  4. Add teams that match the boxes in the portfolio. Teams have to be added one by one.

Failed to reassign a task

The resources module allows you to move a task (a task gets reassigned).

Issue: A task cannot be assigned to a team because that team doesn't exist in both boxes (Portfolio and the task the box is in).

Manage portfolio box in the Resources module

You can create a portfolio box in the Overview module.

If you open a portfolio box in the Resources module, you may encounter the following issues:

There is no data to aggregate - add boxes

The Resources module in a Portfolio box aggregates data from sub-boxes. No sub-boxes were detected. The Portfolio box is empty. To use the Resources module, add sub-boxes to a Portfolio.

Create new boxes

  1. Click Add items.

  2. Select Import Jira Spaces and click Add.

  3. Select one or more Jira spaces to import.
    If you select multiple spaces, you can enable the toggle switch to create a separate box for each Jira space.

  4. Define the box type.

  5. When ready, click Import.

  6. New sub-boxes are now visible.

Move existing boxes

  1. Click Add items.

  2. Select Add existing.

  3. Select boxes. You can move multiple boxes at the same time.

  4. Click Add.

There is no data to aggregate - add tasks

The Resources module in a Portfolio box aggregates data from sub-boxes. Sub-boxes are empty. To use the Resources module, add tasks to boxes.

Add tasks (Overview module)

Add tasks to boxes in the Portfolio. Repeat for all boxes. 

  1. Go to the Overview module.

  2.  Find a sub-box and right-click on it. Alternatively, you can click the (…) More actions button.

  3. Click Configure. You’ll be redirected to the box configuration.

  4. Go to Tasks > Work items from Jira.

  5. Define the scope - you can use Jira spaces, Jira boards, and Jira filters.

  6. Optionally, use the Additional filters for work items section to narrow down the scope.

  7. When ready, click Save.

Add work items (new or already existing in Jira)

To add tasks to the first box, you can use the following process.

  1. Click the Add tasks.

  2. Select a box (step available only when you have multiple boxes).

  3. Click Add tasks.

  4. Click:

    1. Create new to create a Jira work item or a BigPicture task,

    2. Define scope to add existing Jira spaces, Jira boards, and Jira filters.

Portfolio box teams

A portfolio should have the same teams as the boxes it contains. Capacity can't be calculated because there are no team members in the portfolio teams.

Assign individuals to tasks, create a new team, or assign an existing one.

Resources module in portfolio - troubleshooting and setup

The Resources module in a Portfolio box aggregates data from all boxes in the portfolio. You can switch between views: Individuals, Teams, Projects, or Skills.

Failed to reassign a task

The resources module lets you move a task (a task gets reassigned). Note that a task cannot be assigned to a team if that team doesn't exist in both boxes (the portfolio box and the box the task is in).
