# Additional tasks based on sprints, versions ect.

The following elements can be displayed as tasks. You can add them to the scope of a box on the [Scope definition](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=spm&title=Select%20tasks%20to%20work%20with%20%28scope%20definition%29&linkCreation=true&fromPageId=1933967698) page.

- Projects
- Sprints
- Components
- Objective & Key Results
- Versions (start date and release date can be synchronized)
