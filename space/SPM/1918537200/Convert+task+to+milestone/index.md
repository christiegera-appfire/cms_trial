# Convert task to milestone

## Convert task to milestone (old navigation)

Click to expand the guide

In the Gantt module, you can convert a Jira work item or [basic task](/cms_trial/space/SPM/1918405930/Basic+tasks+%2F+BigPicture+tasks/) to a milestone. Jira work items and basic tasks can be converted to milestones in bulk.

Visit the [Multiselect tasks](/cms_trial/space/SPM/1918832779/Multiselect+tasks/) page to learn how to select multiple tasks in the Gantt module.

After the conversion, the task’s end date becomes the milestone’s date.

## Context menu

1. **Right-click** on a task or taskbar you want to convert (anywhere but the issue Key link) to prompt the context menu.
2. From the menu, select **Convert to milestone**.

![Context menu that you can use to convert a task to a milestone.](/cms_trial/assets/7a2588c6-d28a-43ae-9621-c0bf86e8f709.png)

## Editor slider

1. Select a task to highlight it and prompt the editor slider.
2. From the [editor slider](/cms_trial/space/SPM/1918635307/Editor+slider/), select **More actions** (**…**) > **Convert to milestone**.

![A menu for converting a task to a milestone.](/cms_trial/assets/53cbbd5f-459e-45e7-a967-cf9672663275.png)

## Inline edit

1. Click the **Add or edit columns** button (▢) in the upper-right corner of the column view.
2. Locate the **Milestone** field (scroll down or type the name into the search bar).
3. Add the column.
4. To [edit the field inline](/cms_trial/space/SPM/1918637324/Inline+edit/), click the milestone field and select a milestone from the dropdown.

![Milestone column being inline edited.](/cms_trial/assets/dd8917f6-970c-4f88-a519-aa44e44e0143.png)
