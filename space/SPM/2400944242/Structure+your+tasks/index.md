# Structure your tasks

## What will I learn on this page?

> 💡 On this page, we will show you what task structure is and how to adjust it to your business needs. You need at least a box admin security role to access and manage the task structure configuration.

You will learn:

- What **task structure** is in BigPicture
- How to reflect the **Space / Epic / Sub-task** structure of your tasks in a box

## Why do I need a task structure?

### Organization

The Gantt module in BigPicture displays the task structure as a hierarchical tree on the left. This helps you understand how work is organized and what’s happening in your project. The task structure allows you to organize work items into parent-child relationships such as projects, epics, and sub-tasks.

### Scheduling

The task structure is connected with [scheduling](/cms_trial/space/SPM/1918831395/Scheduling+mode/). On the right, the Gantt timeline visually presents each task’s duration, dependencies, and progress. You can easily visualize how tasks are related and keep an eye on the structure of elements coming from Jira without losing the context of the Gantt timeline.

### Automatic task structure

With automatic task structure, the app can [automatically generate the task structure](/cms_trial/space/SPM/1918536846/Automatic+task+structure+(structure+builders)/) or hierarchy within a box. You can set the rules to structure your tasks by activating the respective structure builders.

With the bi-directional sync, you can add new Jira work items and sub-items directly in BigPicture, and they’ll be automatically added to a proper project in Jira. When you add new elements in Jira, they will also show up in BigPicture.

## Change task structure step-by-step

In this scenario, we’ll change the task structure to reflect the **Space / Epic / Sub-task** structure.

1. Go to **box configuration** > **Tasks** > **Task structure**.
2. Select the **Agile - multiple projects** option.
3. Click **Save**.

The changes are immediately reflected on the Gantt chart.

See an interactive demo on how to make changes to the task structure.
