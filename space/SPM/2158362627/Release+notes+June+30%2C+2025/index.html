Release notes June 30, 2025

2 min read

Release date: June 30, 2025

Our team is thrilled to announce the latest release of BigPicture Enterprise Cloud.

New

Financials module

Create custom expenses to track costs that aren’t associated with tasks

Custom expenses associated with a given box are listed in the work cost breakdown. They are also included in the cost distribution diagram and the total cost over time breakdown.

Custom expenses are managed globally in BigPicture Administration.

You can create the following types of custom expenses:

  • One-time costs (the toggle switch off).

  • Recurring (toggle switch on): Recurring expenses can be automatically added at the start of each month, quarter, or year.

Step-by-step:

To easily add the first custom expense:

  1. Click Manage. You are taken to the Financials tab in Administration.

  2. Click Add new expense.

  3. Fill out the expense information. Make sure to associate the cost with the correct box (the Initiative field).

  4. Click Save. The new cost is visible on the list of all expenses.

    It is also immediately visible in the associated box:

Track costs on a timebox level

The Financials module is available in the lower-level timeboxes, such as Iterations.

How does it work

  • A timebox uses the calculation settings (such as the hourly rate) of the parent.

  • The Financials module calculates costs for the tasks in a given timebox.

Note: Budget cannot be configured on a timebox level.

Enhancements

New view of the Resources module

Click the timeline to automatically adjust the time range of the grid

Click a time period to automatically set the displayed date range to a:

  • quarter

  • mondth

  • week

Aggregation:

  • if aggregation is less than or equal to the selected time range, it remains unchanged

  • if the aggregation is greater than the selected time range, it changes to match the time range.

BigPicture Enterprise

Clicking on the timebox sets the aggregation to “By timeboxes” and does not change the time range.
