# Create new prioritization templates

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

## Create new prioritization templates (old navigation)

Click to expand the guide

When none of the default prioritization templates works for you, you can always create a new one from scratch or edit existing ones.

When creating your own prioritization templates, you must define prioritization metrics and a formula for calculating the final score.

The Priorities module lets you select from different metrics to make your prioritization template unique. You just pick the one that’s best suited for your use case.

## Create new prioritization template

Before you begin, see the [Priority attributes](/cms_trial/space/SPM/1918539369/Priority+attributes/) page to learn more about available metric types and score formulas.z

To create a new template:

1. In the **Priorities module**, click **Configuration** in the top-right corner.
2. Click the **Select prioritization template** drop-down menu.
3. Select **+ Create a new template** option.
4. Provide a **Template name**.
5. Add at least one metric using the **+ Add new metric** option.
6. Create a scoring formula.
7. Click **Save changes**.
8. The template is created and applied to your project.

![priorities-module-create-template.png](/cms_trial/assets/b87ba06d-c591-419b-929f-872b382dbbdc.png)
