# OKR Overview

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

The *Overview* page offers a comprehensive view of your company’s Strategic themes, Objectives, and Key Results in a hierarchical structure, showing how smaller goals contribute to larger ones. This flexible hierarchy can also reveal boxes and work items directly linked to their respective Key Results.

The following video gives an at-a-glance view of the *Overview* page.

The *Overview* page is helpful for:

- Monitoring progress: Track the status of objectives and key results. This is an ideal view for OKR review meetings and team planning sessions at every level.
- Planning your team's work: Use the *Overview* page to help prioritize and focus on the right Objectives for your team.

## Overview

The *Overview* page houses a wide range of options and features to help you create, manage, find, and track OKRs.

Visit the [OKR Filters, search, and saved views](/cms_trial/space/SPM/1918637654/OKR+Filters%2C+search%2C+and+saved+views/) page to learn more details about filtering and saving views in the OKR module.

The top-right corner houses the following options:

![okr-overview-options.png](/cms_trial/assets/04068cfd-b0da-4cf0-8061-5b9e3db9e21d.png)

- **Filters:** Lets you select and apply global filters to all OKRs in your current view.
- **Import**: Click to open the [OKR import](/cms_trial/space/SPM/1918406659/Import+OKRs/) screen, where you can upload the .csv file with the OKRs you want to import.
- **Export**: Click to see the [OKR export](/cms_trial/space/SPM/1918668919/Export+OKRs/) options, where you select or deselect the data you want to export.
- **Share view:** Click to copy a link you can use to [share your current OKR view](/cms_trial/space/SPM/1918408436/Share+view+(OKR+module)/).
- **Documentation link:** Click to open product technical documentation.

### Period filter

The **Period filter** narrows down the visible scope of OKRs by the selected period.

![Period filter.](/cms_trial/assets/9437dcbc-6471-4e49-bc82-ac0b3bf7e1dd.png)

### Filters

The filtering options under the **Filters** button narrow down the visible scope of OKRs by the selected filter.

![okr-overview-filters.png](/cms_trial/assets/7c72fc38-6310-40c7-b863-11c5051b898f.png)

### View

The options under the **View** button let you customize item visibility in your current view. They control the filtering results and the visibility of the [linked boxes](/cms_trial/space/SPM/2229665803/Link+boxes+to+Key+Results/) and [linked Jira work items](/cms_trial/space/SPM/1918507296/Link+work+items+to+Key+Results/).

For the linked issues to become visible, you must enable their visibility in:

- **Settings** > **General** > switch **Displaying connected issues in the OKR Overview**.
- **Layout** > **Display settings** > check **Show connected Jira issues**.

![okr-overview-view.png](/cms_trial/assets/7de7164f-374f-4fb6-a4d7-c7a42e3a6b28.png)

### Save as new view

You can save the filters, search query, and column layout you apply to your current view. You can switch to the saved view whenever you need it. Saved views are global, meaning permitted users can switch to a saved view created by another user in their organization.

![okr-save-as-new-view.png](/cms_trial/assets/23a7190b-c554-46a0-b565-dc8dd3647c20.png)

### OKR Details side panel

The [Details side panel](/cms_trial/space/SPM/1918865686/OKR+Details+side+panel/) displays details for the Objective or Key Result, depending on which OKR you selected. It also lists comments associated with the selected OKR.

You can also use the panel to update the OKR or access additional options.

### Column layout

The column layout on the *Overview* page displays OKRs in a structured tabular format. Each column represents one type of data you can search or filter.

You can also customize the view by adding or removing selected columns, locking them, hiding them, and rearranging their order.

Selecting the **plus icon** in the table header opens a separate panel that displays all columns in the column view. You can customize individual columns in the following ways:

![okr-column-layout.png](/cms_trial/assets/c2ed8f4d-8cc6-4d29-b36e-ff8b0cd6c1e5.png)

- Click the **padlock icon** to lock a column (a locked column cannot be repositioned but can be hidden).
- Check or clear to show or hide a column.
- Drag and drop a column up/down to change the column order in the view.

![okr-column-layout-new.png](/cms_trial/assets/ed3d644e-f979-4591-84f2-36b28a503c0d.png)

Click the **Save** button to save your changes.

The OKR column layout consists of the following columns:

- OKR Name
- Period
- Owner
- Labels
- Teams
- OKR Type
- Progress
- Collaborators
- Status
- Weight
- Latest Update
- Days since last update
- Date of last update
- Expected start date
- Expected end date
- Grade
- Start Value
- Current Value
- Target Value
- Assigne

### Rearrange column order

Drag a column and drop it in a new location to manually change the order.

![How to manually change the column order on the OKR Overview page i nthe OKR module.](/cms_trial/assets/6273ee35-4b24-4ca2-a7c2-70c356bb04f4.mp4)

### Change column width

You can expand the column to increase its width. However, columns cannot be shorter than their default width.

![How to manually change the column width on the OKR Overview page i nthe OKR module.](/cms_trial/assets/5fd996b0-1348-4adc-a9c1-b8b445f994ac.mp4)

### Context menu

Click the **More actions** (**…**) button next to an OKR to open additional options. This button is always visible for Strategic themes and Objectives; it appears for Key Results when you mouse over them.

![okr-context-menu.png](/cms_trial/assets/7fb40054-c7b5-4625-a5fd-5ed03518f313.png)
