# List view

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

In the **List view**, tasks, boxes, or goals appear together with metrics and the priority score in the table view.

Click the fields to assign metrics to an element. Once all metrics are filled in, the [score is automatically calculated](/cms_trial/space/SPM/1918638055/Use+prioritization+templates/).

![image-20250708-085052.png](/cms_trial/assets/367e28c9-ddca-4e1a-bed6-11d621b79a25.png)

## Add fields to the list view

In the List view, you can add or hide additional columns with information.

1. Click the **Columns** button.
2. Select fields from the dropdown menu.

The Priorities module remembers your last selected columns and filters, so you don’t need to choose them every time you access the module.

![image-20250708-085458.png](/cms_trial/assets/47a3b03c-3b76-4da4-92ff-03b5ea1ae6be.png)

### Available fields

The available columns differ between tasks, boxes, and goals. See the table below.

| **Element** | **Tasks** | **Boxes** | **Goals** |
| --- | --- | --- | --- |
| **Available fields to add as columns** | You can add Jira fields of the following type:   - Radio buttons - Single select list - Cascading select list - Parent link - Description   The **Description** field truncates in the row for longer descriptions**.** To see more details, click the **work item** to view the full description. | You can add the following fields:   - Box type - Parent box - Status | You can add the following fields:   - Status - Owner - Period - Label - OKR type - Goal type |

## Flagged work items

The Priorities module displays flagged work items. You can flag work items in Jira’s backlog or board. Flagged work items are visible to all users.
