# Customize prioritization templates

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

## Customize prioritization templates (old navigation)

Click to expand the guide

If the selected prioritization template doesn’t work for you, you can [select a different one](/cms_trial/space/SPM/1918766042/Prioritization+templates/) or even [create your own](/cms_trial/space/SPM/1918506690/Create+new+prioritization+templates/).

Prioritization templates are set per box, allowing different teams to work on their templates without conflicts. You can switch templates whenever needed, and all data entered in the previous template is saved.

See the video on how easily you can customize prioritization templates.

## Customize prioritization template

Before you begin, see the [Priority attributes](/cms_trial/space/SPM/1918539369/Priority+attributes/) page to learn more about available metric types and score formulas.

To customize a prioritization template:

1. In the **Priorities module**, click the **Configuration** button.
2. Choose one of the predefined [prioritization templates](/cms_trial/space/SPM/1918766042/Prioritization+templates/).
3. Customize the predefined template if needed.
4. Alternatively, select the **Create a new template** option to [create a new template](/cms_trial/space/SPM/1918506690/Create+new+prioritization+templates/) from scratch.

You can customize your template in the following ways:

- Change the template name.
- Change the score formula.
- Add new prioritization metrics (Label, Number, Rating, Short text, or Jira field).
- Remove the predefined metrics.
- Map Jira custom fields to label metrics.
- Add Jira fields as columns to the prioritization table.

The video presents how to customize a prioritization template.

## Duplicate prioritization templates

Use the **Save as new template** option to duplicate prioritization templates based on existing ones.

To duplicate a prioritization template:

1. In the **Priorities module**, click the **Configuration** button.
2. Choose a template you want to duplicate.
3. Change the **Template name**.
4. Add, update, or delete metrics.
5. Check if the **Score formula** is correct.
6. When ready, click **Save as new template**.
