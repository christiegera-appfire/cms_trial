# Task period alignment (Automation)

## About the task period alignment

The scheduling mechanism can align or adjust the start/end dates of tasks assigned to a box with the box's own start/end dates.

The task period alignment can be set to:

- **No alignment** - task dates and duration aren’t adjusted to timeboxes.
- **Precise alignment** - task dates and duration are adjusted to be exactly the same as the dates and duration of timeboxes.
- **Smart adjustment** - task dates entirely or partially adjust to the dates of timeboxes, keeping task duration as close to the original as possible.

## Configuration

The Task period alignment feature is set in the box configuration. For more information, check the [Define task period alignment](/cms_trial/space/SPM/1918830096/Define+task+period+alignment/) page.
