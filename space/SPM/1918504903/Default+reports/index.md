# Default reports

The standard BigPicture App includes five pre-configured reports. Click one of the values presented on the chart to drill down.

![Default reports](/cms_trial/assets/3e4841ae-9de7-4623-8641-98d909c7ee59.png)

## Status per Assignee

The chart shows the distribution of issues across different status categories. You can click a category to show the distribution of issues for assignees in a selected timebox.

Use this report to measure the relative workload for each assignee.

Click the buttons next to each chart, and select the type you want to use – a pie chart, a column chart, or a tree view.

## Issue Type per Status

This chart shows the issue distribution within different issue types.

Select an issue type to see the distribution in different status categories.

Use this report to measure relative progress.

## Fix Versions per Status

This chart shows the task distribution in different versions.

Click the version to drill down and display the issue distribution across different statuses.

## Assignee per Status

This chart shows the distribution of issues for assignees and assigned tasks per status category.

Use this report to measure the relative workload for each assignee.

## Issue Priority Distribution and Issues with Selected Priority per Assignee

Use this report to compare issues with different states and priorities.
