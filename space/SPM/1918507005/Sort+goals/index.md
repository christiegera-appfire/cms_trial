# Sort goals

On April 9, 2026, the **Objectives module** was renamed to the **Goals module** to better differentiate it from the OKR module. Items created within this module are now called goals.

## Sort goals (old navigation)

Click to expand the guide

You can sort goals by the Planned or Actual Business Value in ascending or descending order.

## Configuration

- To display Business Value score fields, go to Administration > Box types > click on a Box type name > goals > Basics
- Actual business value will only be displayed if the Timebox status is other than Not Started

You can only sort the goals that are currently visible – this way, you'll avoid unintentionally sorting some past or future goals.
