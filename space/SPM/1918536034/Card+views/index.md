## Card views (Risks module)

You can change the layout of your risk cards at any time.

You can set the default configuration using:

- [Box types](/cms_trial/space/SPM/1918830000/Box+types/) (App admin security role required); or
- Edit the layout in the [Box configuration](https://appfire.atlassian.net/wiki/spaces/SPM/pages/1918830445) section (Box admin security role required)

![Screenshot of the current view in the Risks module.](/cms_trial/assets/7e98093b-6f68-45f0-8b47-c421fa44caf7.png)

### Favorite card views

Mark your favorite configuration with a star to find the view you like most. Each user can have different favorite views. All your favorite card views will be listed in a separate section of the card view drop-down.

![Screenshot of the favorite card views in the Risks module.](/cms_trial/assets/2d782f0c-2d98-4bed-b6bc-c3d3ab62ca17.png)
