# WBS widget

The **WBS** **widget** (Work Breakdown Structure widget) provides a low-level view of the currently viewed task’s structure directly on the Jira issue detail page. It visualizes the task within the structure of its closest parent and children (if there are any).

## Access WBS widget configuration page

Click the **App settings** button (**wrench** **icon**) in the top right corner and select**Widgets** from the drop-down list. Next, go to the **WBS Widget** tab.

Only Jira and App Admins can access the App Configuration page.

![App Configuration page. Here, you can find settings for the WBS widget.](/cms_trial/assets/cee881df-6798-4dc2-a842-717aff07222a.png)

## Configure WBS widget

The widget configuration page offers a few general options that you can apply to your projects and Jira issue types.

### Enable WBS widget on Jira issue detail page

To activate the WBS widget, toggle on the **Enable WBS on issue page** button. This will add the WBS Widget to your Jira issue details pages. To deactivate the widget, toggle off the button.

![Toggle the button on the app configuration page to enable wbs widget on issue pages.](/cms_trial/assets/121d8585-9b4d-47a9-aa33-f779966735bf.png)

### Enable WBS widget even if an issue is not in any scope

The second toggle option lets you enable or disable the WBS widget even if an issue is not in the scope of any box.

![WBS widget configuration options.](/cms_trial/assets/328efcd7-bc14-4dbc-852f-72ee6019f3a8.png)

### Maximum issues to load

This option lets you limit the number of issues loaded on the WBS widget. It is useful for large and complex projects whose WBS is composed of multiple levels of nestings and many subtasks.

![You can reduce the number of issues that your WBS widget will display.](/cms_trial/assets/7245b5b5-85b5-4f43-978b-0f14419b85ca.png)

### Enable WBS widget in all Jira projects

You can set the WBS widget to appear on issue pages in all Jira projects or only in the selected ones.

If you want to activate the widget for specific Jira projects, toggle off the **Enable WBS in all Jira Project** button. A list of available Jira projects will appear. Scroll to find the project(s), or use the search box to find them faster.

When you find the right project(s), toggle the button next to it. Then, save your settings.

![You can activate WBS widget to appear only in selected projects.](/cms_trial/assets/08229b76-c913-4ff8-9609-abb195903c4f.png)

### Enable WBS widget in all issue types

You can also set the WBS widget to appear on the issue detail page for all issue types or only the selected ones.

If you want to activate the widget for specific issue types, toggle off the **Enable WBS in all Jira Issue types** button. A list of available Jira issue types will appear. Scroll to find the issue type(s), or use the search box to find them faster.

When you find the right issue type(s), toggle on the button next to it. Save your settings.

![You can activate WBS widget to appear only for the selected Jira issue types..](/cms_trial/assets/d314d2db-e055-4041-87fb-24050f466559.png)

## WBS widget on Jira issue page

Similarly to the task lists in the Gantt and Scope modules, the **WBS widget** displays the selected issue's hierarchical task structure, offering a concise view of the task’s relationships directly on the Jira issue detail page. The widget also visualizes different fields as columns you can customize and aggregate.
