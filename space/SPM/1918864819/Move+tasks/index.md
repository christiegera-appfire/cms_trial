# Move tasks

## Move tasks in the Backlog tab (Board module)

### Drag-and-drop

The drag-and-drop option allows you to move and change the indentation of tasks manually.

![2024-01-16_11-24-38.mp4](/cms_trial/assets/b29c0489-3c3e-403b-bedc-dbf3918bc780.mp4)

### Right-click

Right-click on the task in the backlog to change the position (**do NOT** right-click on inline editable and key fields).   
The following options are available:

- Move to top
- Move up
- Move down
- Move to bottom

It **is NOT** possible to change the indentation of tasks with the right-click menu.

![image-20240116-103508.png](/cms_trial/assets/9ee53098-0c71-4a08-96ed-4e810ae385d6.png)

## Move tasks in the Calendar module

You can reschedule your tasks by dragging and dropping them:

- From the initial day to another one directly on the calendar.

  ![Drag a task on the calendar to reschedule it.](/cms_trial/assets/526672ab-b12a-497b-a420-431e72cb211d.mp4)
- From the task list to another day on the calendar.

  ![Drag a task from a task list to reschedule it.](/cms_trial/assets/6912d3e5-f766-4d55-ba5a-d94456f4eb55.mp4)

You cannot reschedule tasks if it creates a scheduling conflict. For example, the task's scheduling mode can restrict changes in its dates. All the changes in the task’s schedule are reflected in other modules.

## Move tasks between swimlanes (Resources)

### Change the task period

Use drag and drop to re-position a task on the timeline – simply drop the tasks into a new spot.

![Resources - change task period.mov](/cms_trial/assets/edb11bd5-3c92-4a7c-9e6c-44359990b402.mov)

### Move task between swimlanes

Use drag-and-drop to change the task:

- assignee
- team
- skill

**Note**: you can’t use drag-and-drop to move a task between project rows.

![Resources - change the person.mov](/cms_trial/assets/16a8a047-292d-43ab-a1ee-f29cb435c965.mov)

Tasks without a value are in the "Unassigned" row.

![image-20250303-093410.png](/cms_trial/assets/f406158f-b1c1-4f89-910e-31d0110160d6.png)

Remember:

- Assigning a task to a team **doesn't** result in assigning it to a person.
- Assigning a task to a person **doesn't** always assign a task to a team.

Click on a task to see a pop-up Box and easily check the team and assignee details. Use [the find a perfect match feature](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=DLPDRAFT&title=Find%20the%20perfect%20match) to assign a task to a team or assignee.

![Find perfect match.mov](/cms_trial/assets/c05c050a-2691-417f-9bfb-069e08784bd6.mov)

Only active team members are visible in the swimlanes**.** Once an individual resource is no longer a member of the team, the Box Admin should close their [team membership](/cms_trial/space/SPM/1918537450/Manage+team+membership/).

## Move tasks from the Backlog panel (Resources)

You can schedule tasks by moving them from the Backlog panel. Depending on the swimlane setup, you can change

- date
- team
- assignee.

1. Drag a task onto the grid.

   ![Drag a task from a backlog to the resources grid to schedule it.](/cms_trial/assets/bc71ca03-25d9-414f-97c6-e5fa5e62fc99.png)
2. Make changes if necessary.
3. To confirm, click **Save**.

   ![backlog-plan-task.png](/cms_trial/assets/59f14f50-5dfa-430d-9687-1e95ab386004.png)

Read more

Dates **cannot** be added to parent tasks set to Auto bottom-up scheduling mode. A warning appears as the parent’s dates depend on the dates of its subtasks.

## Move tasks (Resources module)

### Move tasks

You can move tasks between swimlanes and from the Backlog panel.

In the **Resources module**, you can change the following details of a task:

- assignee
- team
- skills

You **CAN’T** change the project. Project swimlane switches are blocked.

### Multiassignment

Multissignment is possible for:

- skills - one task can have many skills assigned
- boxes - one task can be in many boxes
