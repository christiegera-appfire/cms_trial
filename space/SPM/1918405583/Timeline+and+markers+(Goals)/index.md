# Timeline and markers (Goals)

## Timeline and markers - Goals module (old navigation)

Click to expand the guide

The timeline adjusts dynamically to match the [timebox](/cms_trial/space/SPM/1918766987/Timeboxes/) dates. It lets you add [markers](/cms_trial/space/SPM/1918699490/Markers/) by clicking directly on the timeline.

For example, markers can represent milestones. *'Milestones are used to track progress toward a specific goal or event. There are three types of SAFe milestones: Program Increment (PI), fixed-date, and learning milestones.'* © Scaled Agile, Inc.

![safe-audit.png](/cms_trial/assets/83b9d64e-c604-419b-9627-a5a1ff5ce5dd.png)

If multiple markers fall on the same date, you will see a number indicating them:

![timeline-markers.png](/cms_trial/assets/c5bfc9f2-14a8-4c96-8920-4facee587b3c.png)

## Timeline

The Timeline begins at the start date of the earliest Timebox on the Board and ends together with the end date of the latest timebox.

### Current date

The current date is displayed as a number in a circle on the leftmost side of the timeline.

### Today button

Click this button to move to the current Program Increment or Iteration.

### Zoom in / Zoom out buttons

You can zoom in or out to change the number of Program Increments or Iterations displayed simultaneously. Depending on your screen resolution (above 2400 pixels in width), the maximum number of elements you can display is 7.

## [Markers](/cms_trial/space/SPM/1918699490/Markers/)

Markers can indicate important events on the timeline, such as dates or milestones. You can add and edit them using the Gantt, Board, and Goals modules.

To add a marker, click the timeline and enter the following information in the dialog box:

- Name
- Color
- Description
- Date

![edit-marker.png](/cms_trial/assets/ca2ea71e-6d3c-451c-92ae-14d80880f859.png)

### Actions on a marker

**Right-click** a marker to see options:

![actions.png](/cms_trial/assets/e48876a5-ec70-440d-93a7-4d30b0309a3b.png)

- Edit
- Show markers list
- Add new marker
- Delete

#### Edit or delete a marker

Change marker details and/or delete the marker.

![edit.png](/cms_trial/assets/4ef51f87-6dcd-49c6-9cb5-3b9318ad26fd.png)

#### Show markers list

The **Show markers list** will bring up the list of markers that fall on a given date.

![show-marker-list.png](/cms_trial/assets/e3763b9f-a57a-4731-a1cc-f34f9fa05031.png)

You can also edit or delete the markers directly from the markers list.

![review.png](/cms_trial/assets/16b0882b-864a-4786-964e-13b35a1758f1.png)
