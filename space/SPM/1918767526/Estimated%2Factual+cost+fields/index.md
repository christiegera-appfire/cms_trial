# Estimated/actual cost fields

When fields are set to "Not Synchronized", the values are stored only in BigPicture.

![contentId-1918767526](/cms_trial/assets/0b59ecd9-305f-4e76-bd3b-0997d2612cc8.png)

**Estimated cost and Actual cost can each be mapped to a Jira issue field -** this means you can associate cost with individual tasks and further automatically aggregate (roll up) the values in your boxes.

Cost values need to be manually entered for tasks.

![contentId-1918767526](/cms_trial/assets/1229f40f-048d-4713-9a44-20cb4e3cb940.png)

## Use

**Cost columns**

To edit the values, edit the column view (Overview/ Gantt/ Scope/ Board modules)

![contentId-1918767526](/cms_trial/assets/01da6eed-cc0f-49b3-b8d0-39112e76e9c5.png)

## Limitations

**Estimated cost** and **Actual cost** are **NOT** automatically calculated based on the cost rate of the assigned resource.
