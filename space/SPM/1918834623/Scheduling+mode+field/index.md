# Scheduling mode field

The scheduling mode determines the behavior of your tasks, and you can use it to auto-schedule your work based on the defined dependencies.

You can synchronize it with Jira using a [Single List (single choice) type](https://confluence.atlassian.com/adminjiraserver/configuring-a-custom-field-938847235.html) field with the following options:

- Auto bottom up
- Auto top down
- Manual
- Lock

The **--Not Synchronized--** option is active by default.
