# Add, edit, and delete holiday plans

## Add new holiday plans

To add a new holiday plan:

1. Go to **Administration** > **Resources** > **Holiday plans**.
2. Click the **Add new plan** button and enter the name and code (max. 10 characters).

The name of the currently active plan is displayed in the resource list on the **Administration > Resources > Individuals** page.

![contentId-1918864322](/cms_trial/assets/751edd58-59ca-4a98-9c0c-d388d857a7c9.png)

## Edit holiday plans

Click the **plan's name** or the **Details** button to view and edit the holiday dates. If you want to change the name or the code, click the **Edit** button.

Click the **Edit details** button to change holidays in the detail view. Click the dates that you want to convert to holidays and select the holiday mode:

![contentId-1918864322](/cms_trial/assets/f2f011e6-0ab8-49b9-95e4-f3c231658c1b.png)

Use the arrows in the top right corner to move the calendar to the next year:

![image2022-1-26_18-42-28.png](/cms_trial/assets/30d60562-4b5c-4b97-92b0-06e26da8703c.png)

For example, Angela is assigned to a Holiday plan with holidays on the 3rd and 4th of August:

![contentId-1918864322](/cms_trial/assets/e65a2696-1e33-4e60-89e0-5db22175225e.png)

On these dates, the daily capacity in the Resources module is reduced to zero, and the scheduling mechanism moves the tasks to start on the first working day.

![image2022-1-26_18-46-12.png](/cms_trial/assets/97986261-a805-4984-a2b9-eb5c4433f1d0.png)

## Delete holiday plans

To delete a plan, click the **Delete** on the details page or on the **Holiday plans** page. You can’t delete the default plans.

If a resource was assigned to a deleted plan, BigPicture assigns the default holiday plan instead.
