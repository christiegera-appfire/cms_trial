## Automatic linking of the original and cloned tasks

When you clone tasks, the original task and the new task can be linked, depending on the settings.

### Default settings

By default, a 'Cloners' link is used.

### How to change the settings

Use the drop-down menu to change the link setup or turn it off.

**Limitations**:

Only links not mapped or otherwise used as structure builders can be selected.

Links **can’t** be used for synchronization and as structure builders simultaneously. When a link is synchronized, you cannot use a structure builder based on that link.
