New navigation - redesigned module layouts

6 min read

The new navigation provides a clearer structure and more intuitive access to key functionalities. Below, you’ll find detailed information about the changes in each module.

Overview module

  • Features have been reorganized into logical categories to make navigation more intuitive:

    • View mode - access the Hierarchy, Timeline, and Kanban board modes.

    • Current view - switch to another view or manage column views.

    • Create new - use the button to create a new box.

    • View - sort, change the layout of displayed boxes, and show archived boxes.

    • Toolbar icons – the Filters, Search, Starred, Export (available with BigTemplate), and Share features are now located on the left.

  • Wrench icon - click to access Box configuration, Field mapping, Administration, App configuration, or My settings.

  • Quick access to contextual reports.

Gantt module

  • Features have been reorganized into logical categories to make navigation more intuitive.

    • Change scenario - create a new scenario or switch between existing ones.

    • Current view - switch to another view or manage column views.

    • Tasks - access all task-related features.

    • View - displays features that help you organize your data.

    • Indicators - planning indicators that allow you to control what is displayed on the Gantt timeline.

    • Toolbar icons – the Filters, Search, Undo, Export (available with BigTemplate), and Share features are now located on the left.

  • Wrench icon - click to access Box configuration, Field mapping, Administration, App configuration, or My settings.

Scope module

  • Features have been reorganized into logical categories to make navigation more intuitive.

    • Current view - switch to another view or manage column views.

    • Tasks - access all task-related features.

    • View - displays features that help you organize your data.

    • Arrows - use arrows to move to the top, move up, move down, move to the bottom, outdent, indent, or delete tasks.

  • Toolbar icons – the Filters, Search, Export (available with BigTemplate), and Share features are now located on the left.

  • Wrench icon - click to access Box configuration, Field mapping, Administration, App configuration, or My settings.

Board module

  • Use the arrow next to the module name to access the Swimlanes, Capacity planning, or Reports view.

  • Features have been reorganized into logical categories to make navigation more intuitive.

    • Swimlane type - switch to another swimlane.

    • Select swimlane value - select swimlane value from the menu.

    • Current view - switch to another view or manage card views.

    • Tasks - access all task-related features.

    • View - displays features that help you organize your data.

    • Units (Capacity planning) - choose between Story points or Man-days.

  • Toolbar icons – the Filters, Search, Export (available with BigTemplate), and Share features are now located on the left.

    • Highlight changes icon (Capacity planning) is also available on the left.

  • Wrench icon - click to access Box configuration, Field mapping, Administration, App configuration, or My settings.

Objectives module

  • Use the arrow next to the module name to access the Swimlanes or Reports view.

  • Features have been reorganized into logical categories to make navigation more intuitive.

    • Swimlane type - switch to another swimlane.

    • Select swimlane value - select a swimlane value from the menu.

    • View - displays features that help you organize your data.

  • Toolbar icons – the Export (available with BigTemplate), and Share features are now located on the left.

  • Wrench icon - click to access Box configuration, Field mapping, Administration, App configuration, or My settings.

Resources module

  • Features have been reorganized into logical categories to make navigation more intuitive.

    • Change scenario - create a new scenario or switch between existing ones.

    • View - switch between Individuals, Teams, Projects, and Skills.

    • Group - enables two-level task grouping.

    • Tasks - access all task-related features.

    • View - customize how data is displayed.

    • Modes - select the effort mode and its unit.

  • Timeline settings and aggregation options are available right above the resource grid on the right.

  • Toolbar icons – the Filters, Search, Export (available with BigTemplate), and Share features are now located on the left.

  • Wrench icon - click to access Box configuration, Field mapping, Administration, App configuration, or My settings.

Teams module

  • Features have been reorganized into logical categories to make navigation more intuitive.

    • Teams - access all team-related features.

    • View - display archived resources.

  • Toolbar icons – the Search and Share features are now located on the left.

  • Wrench icon - click to access Box configuration, Field mapping, Administration, App configuration, or My settings.

Risks module

  • Features have been reorganized into logical categories to make navigation more intuitive.

    • Matrix/Table - switch between the matrix and table views.

    • Current view - switch to another view or manage card views.

    • Risks - access all risk-related actions.

    • View - allows you to sort tasks and customize the data displayed.

  • Toolbar icons – the Filters, Search, Export (available with BigTemplate), and Share features are now located on the left.

  • Wrench icon - click to access Box configuration, Field mapping, Administration, App configuration, or My settings.

Calendar module

  • Features have been reorganized into logical categories to make navigation more intuitive.

    • Navigation buttons - use the navigation buttons (today, previous year, previous month, next year, next month) or select a date to navigate the calendar.

    • Tasks - access all task-related features.

    • View - customize how data is displayed.

    • Toolbar icons – the Filters, Search, Export (available with BigTemplate), and Share features are now located on the left.

    • Wrench icon - click to access Box configuration, Field mapping, Administration, App configuration, or My settings.

Reports module

  • Features have been reorganized into logical categories to make navigation more intuitive.

    • Preview mode/Edit mode - switch between the preview and edit modes.

    • Reports - access all report-related features.

  • The auto-refresh button is available on the right.

  • Wrench icon - click to access Box configuration, Field mapping, Administration, App configuration, or My settings.
