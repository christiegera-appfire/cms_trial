# New navigation - redesigned module layouts

The new navigation provides a clearer structure and more intuitive access to key functionalities. Below, you’ll find detailed information about the changes in each module.

[Overview module](/cms_trial/space/SPM/1918502655/Overview+module/)

- Features have been reorganized into logical categories to make navigation more intuitive:

  - **View mode -** access the **Hierarchy**, **Timeline**, and **Kanban board** modes.
  - **Current view** - switch to another view or manage column views.
  - **Create new** - use the button to create a new box.
  - **View** - sort, change the layout of displayed boxes, and show archived boxes.
  - Toolbar icons – the **Filters**, **Search**, **Starred**, **Export** (available with [BigTemplate](https://appfire.atlassian.net/wiki/spaces/BTc)), and **Share** features are now located on the left.
- Wrench icon - click to access **Box configuration**, **Field mapping**, **Administration**, **App configuration**, or **My settings**.
- Quick access to contextual reports.
