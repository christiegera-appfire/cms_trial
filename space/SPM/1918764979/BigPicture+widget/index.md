# BigPicture widget

The **BigPicture widget** (often referred to as the App widget) allows you to use the BigPicture app directly on the Jira project screen.

## Access BigPicture widget configuration page

Click the **App settings** button (**wrench** **icon**) in the top right corner and select**Widgets** from the drop-down list. Next, go to the **BigPicture Widget** tab.

Only Jira and App Admins can access the App Configuration page.

![You can configure BigPicture widget on the App Configuration page.](/cms_trial/assets/496c4858-2da6-4db3-803f-2961fd2c25d9.png)

## Configure BigPicture widget

The widget configuration page offers two general options that you can apply to your projects and Jira issue types.

### Enable BigPicture widget in all Jira projects

You can set the BigPicture widget to appear on issue pages in all Jira projects or only in the selected ones.

![Toggle the button on the widget configuration page to activate BigPicture widget in every Jira project.](/cms_trial/assets/4e4bd86a-965a-4574-b2bc-22e01ed73447.png)

If you want to activate the widget for specific Jira projects, toggle off the **Enable BigPicture widget in all Jira Project** button. A list of available Jira projects will appear. Scroll to find the project(s), or use the search box to find them faster.

When you find the right project(s), toggle the button next to it. Then, save your settings.

![On the widget configuration page, you can select specific projects for which you want to enable the widget.](/cms_trial/assets/0175b779-c53b-4799-90db-100c614ee82d.png)
