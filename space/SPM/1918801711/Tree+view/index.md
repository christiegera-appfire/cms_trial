# Tree view

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

In the Tree view, you can see all the Strategic Themes, sub-Strategic Themes, Objectives, sub-objectives, and Key Results (OKRs) you created in a single session.

This is the final page you land on when you finish creating an OKR. You can review the details of the OKR you created, add more sub-items, and create a top-level Objective (only for OKRs that are not children of the Strategic Theme).

When you are done creating your OKRs, you can revisit this page and continue building the structure for the selected OKR.

![Tree view page.](/cms_trial/assets/f3921aee-3257-4693-bae9-1f4797e79cab.png)

1. OKR hierarchy. Review the closest hierarchy for the selected OKR (immediate parent and children). Click the OKR key to open the OKR details page.
2. [Create OKR](/cms_trial/space/SPM/2324726248/Create+OKR/). Click the **plus** (**+**) icon to create a new child item.
3. Manage OKR. Click **More actions** (**…**) to clone or delete a selected OKR.
4. [Suggest key results](/cms_trial/space/SPM/2193818158/OKR+AI+(Suggest+Key+Results)/). This function is available only for parent OKRs. Select the Strategic theme or Objective in the hierarchy to activate the button.
5. Create a new parent OKR. Click Create top-level objective to create a new strategic theme/Objective in the current hierarchy.
6. OKR details. Click the OKR key to open the OKR details page. You can also edit the weight of the selected OKR inline.

## Access the Tree view

### After creating an OKR

When you finish creating an OKR, you automatically land on the Tree view page. You can stay on this page to continue adding more OKRs or click the **Finish & Go Back** button to return to the [*OKR Overview*](/cms_trial/space/SPM/1918834317/OKR+Overview/) page.

### From the OKR Overview page

You can revisit the Tree view page by clicking the **Edit tree** option for the respective OKR. You can find the **Edit tree** option in the [OKR details side panel](/cms_trial/space/SPM/1918865686/OKR+Details+side+panel/) and the OKR context menu.
