# Box attributes

## About basic box settings

Box configuration refers to the settings of an individual box, which are based on the box type settings.

The basic box details include such attributes as the box type name, icon, and description. Those details are displayed in the Overview module and the box switcher.

Below, you can see an overview of the general basic box configuration options on the individual box configuration page.

## Security and access

Only a user with at least a Box Admin security role can access and manage the box configuration.

To change the basic box data, go to **box configuration** > **General** > **Basics**.

## Box icon and color

Each box can be identified not only by its **name** but also by its unique **icon**, which is further distinguished by color coding.

A colored icon appears in both the Overview module and the box switcher, allowing for quick and easy identification of a specific box. Additionally, you are not restricted by the default settings based on the box type configuration, as you can manually adjust them.

![Box type settings, icon and icon background color.](/cms_trial/assets/7c514106-e084-4b13-8ce7-c0209878a959.png)

## Box name

The box name is useful when searching with filters in the Overview module or using the search bar in the box switcher. It helps you organize and sort boxes by name.

The box name is displayed:

- In the **Name** column in the Hierarchy and Timeline modes in the Overview module.
- On the box card in the Kanban board mode in the Overview module.
- In the box switcher.

![The Overview module in the kanban board mode with a box switcher expanded.](/cms_trial/assets/d2c2b895-d62d-408b-bf55-b05b4c8b20a8.png)

To rename the box, Box Admins can:

- Inline edit (double left-click) the box name in the Overview module (Hierarchy mode) on the root level.
- Select the **Edit** option from the context menu (right-click the box swimlane).

![Context menu for the selected box.](/cms_trial/assets/043aff77-5ebe-43de-ab34-637a72f5a7b8.png)

## Box start and end dates

The start and end dates indicate the duration of a given box. These dates are not synchronized with Jira or other tools. Box start/end dates are displayed:

- In the **Start Date** and **End Date** columns in the Hierarchy and Timeline modes in the Overview module.
- On the box card in the Kanban board mode.
- On the taskbar sides, when you mouse over the taskbar (left for the start date; right for the end date) in the Timeline mode in the Overview module.

![Box hierarchy in the Overview module, the Timeline mode.](/cms_trial/assets/361bcab8-28ba-4d9a-9808-d80617b2b8d1.png)

Depending on the box type configuration, the start/end dates of the timeboxes (such as Sprints, Iterations, Stages) can either overlap or be arranged sequentially (like in the screenshot below).

![Box hierarchy in the Overview module, the Timeline mode, showing sequential timeboxes (Iteration boxes).](/cms_trial/assets/3563cdb0-6df1-4682-8e39-5e462de7628f.png)

## Box leader

Box leader is not a security role. For that reason, it does not automatically grant access to the app or box.

The box leader is displayed in all view modes of the Overview module. Use the drop-down menu to assign or change the box leader. Adding a box leader is optional.

![Screenshot of the box leader field. ](/cms_trial/assets/fbf474ab-1c5a-4e4e-84df-0b1db198c989.png)

## Box description

You can add a box description to provide details about the box's content or purpose. The description is displayed in all view modes in the Overview module. Adding a box description is optional.

You can inline edit the box description directly on the **Description** column in the Hierarchy mode in the Overview module.

![The description column in the Overview module.](/cms_trial/assets/d1157297-4f73-4935-9b45-d6e3692d68bf.png)
