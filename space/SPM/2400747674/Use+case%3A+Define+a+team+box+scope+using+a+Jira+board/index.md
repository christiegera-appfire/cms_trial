# Use case: Define a team box scope using a Jira board

## Use case: Define a team box scope using a Jira board (Old navigation)

|  |  |
| --- | --- |
| **Goal** | To configure a BigPicture Box for a specific team so that its scope automatically syncs with the tasks present on the team's designated Jira Board. |
| **Scenario** | Imagine you have a team, *Phoenix*, that uses a specific Jira Software board to manage their backlog, plan sprints, and track their work. You want to create a dedicated box in BigPicture for the Phoenix team to utilize BigPicture's advanced planning, resource management, and reporting features specifically for their tasks. By defining the Box scope using their Jira board, you ensure that the Phoenix box in BigPicture always reflects the current state of their work in Jira. |
| **Key benefits** | - Automatic Synchronization: The box scope stays automatically updated as the team works on their Jira board (adding/removing tasks, changing statuses, etc.). - Focused team view: The box provides a dedicated space in BigPicture for the team to visualize, plan, and manage only the tasks relevant to them. - Simplified configuration: Defining the scope based on an existing board is often simpler than using complex JQL queries covering multiple projects or filters. - Improved team workflow: The team can leverage BigPicture's features (such as Gantt, Resources, and Reporting) on their familiar set of tasks from their Jira board. |

## Preconditions

- app user You were granted the [App User role](/cms_trial/space/SPM/1918535770/App-level+permissions/) (to open BigPicture)
- box admin You were granted a [Box Admin](/cms_trial/space/SPM/1918797447/Box-level+permissions/) role of the Home box / the required box (to access box configuration)

## Define a team box scope using a Jira board step-by-step

1. **Choose your box** (or create a new one).
2. Go to **Box configuration** > **Tasks** > **Scope definition**.
3. Choose the right board in the **Boards** field.
4. Click the **Save** button.
