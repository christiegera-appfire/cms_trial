# Tasks, milestones

Tasks are fundamental to managing work and progress. They help organize, track, and execute various activities across projects and teams.

This section provides an overview of tasks, including different task types, such as basic/ BigPicture tasks and milestones, and the actions you can perform on them.

Use the links below to explore detailed information on how to create, edit, synchronize, and manage tasks, and other key features.

## Task types

BigPicture supports several task types, not just Jira work items or other work items from external platforms. Although all of them are collectively termed as “tasks,” each task type is designed for different purposes:

- Jira work items
- Basic tasks/ BigPicture tasks
- Milestones
- Other items that can serve as tasks
- Trello tasks

[**Read more**](/cms_trial/space/SPM/1918700059/Types+of+tasks/)

## Task change history

You can track the changes in your tasks in the Gantt module’s Infobar panel. The history of changes shows the following data:

- The date of the change
- The reason for a change (for example, the task was moved)
- The author of the change

[**Read more**](/cms_trial/space/SPM/1918503025/Change+history/)

Task structure is the way the task hierarchy is organized. In BigPicture, you can build a structure for your tasks manually or automatically based on one of the pre-defined structure templates. It is also possible to have a mix of manual and automatic structures.
