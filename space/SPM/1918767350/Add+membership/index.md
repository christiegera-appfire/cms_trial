# Add membership

### Start date

A membership entry must have a start date. This allows the app to include the member in calculations.

A start date must also be provided when adding a new team member.

![Screenshot of adding a new team member in the Teams module.](/cms_trial/assets/d2ead74e-66d2-4a83-aac9-33e3f6138a27.png)

### End date

The membership end date is calculated automatically when you add a new membership. The end date is set as new membership start date - 1 day:

![Screenshot of a team member's memberships.](/cms_trial/assets/233ac8e0-4f9f-469c-913c-56be5653b3d4.png)

### Availability

When you add a team member, specify the availability for that period.
