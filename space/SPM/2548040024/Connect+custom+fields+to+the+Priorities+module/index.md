# Connect custom fields to the Priorities module

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

## Connect custom fields to the Priorities module (old navigation)

Click to expand the guide

You can connect numeric fields (such as Story Points, Task Progress, etc.) and single-select custom fields to the Priorities module metrics to use them in calculating the **Priority Score**.

![Configuration page in the Priorities module.](/cms_trial/assets/ab96ee15-e791-49c6-ab11-bc966f9d1d94.png)

## Connect numeric fields to the Priorities module

This feature is great for synchronizing metrics such as Story Points across Jira and the Priorities module.

1. To create a Priorities module metric <> Jira field connection, click **Configuration.**

   ![Screenshot of the Configuration button in Foxly.](/cms_trial/assets/bf9a425e-edda-4bba-a31c-2657ad141c18.png)
2. Click **+Add new metric**.
3. A drop-down should appear under the [edit pencil icon]icon, but if it doesn’t, click the [edit pencil icon] icon and select *Number*.

   ![Screenshot of the Add a new metric option in Foxly Priorities Configuration.](/cms_trial/assets/ccd78e17-eb08-430c-95cb-9b1d5158b488.png)
4. Enter a name for the metric.
5. Select which number-based metric you want to link to Jira. A confirmation box will appear.
6. Click **Save changes**.

Once this connection is made, you can update the linked field in either the Priorities module or Jira. It will seamlessly sync to the other one, eliminating the need for complicated automation.

## Connect single-select custom fields to the Priorities module

Connect Jira single-select custom fields to the Priorities module metrics and use them in calculating the **Priority Score**.

1. To create a Priorities module metric <> Jira field connection, click **Configuration.**

   ![Screenshot of the Configuration button in Foxly.](/cms_trial/assets/bf9a425e-edda-4bba-a31c-2657ad141c18.png)
2. Click **+Add new metric**.
3. A drop-down should appear under the [edit pencil icon], but if it doesn’t, click the [edit pencil icon] icon and select *Jira field*.

   ![Screenshot of the Add a new metric option in Foxly Priorities Configuration.](/cms_trial/assets/23d8d4ce-fb23-443e-8dd2-810d5ebf383e.png)
4. Enter a name for the metric.
5. Select which Jira custom fields you want to use. Only single-select dropdown fields are available.
6. When ready, click **Save changes**. A confirmation box appears.

   ![image-20251121-100427.png](/cms_trial/assets/53dc81d7-049e-4e59-910f-6c692ae15e80.png)
7. To confirm, click **Save Changes**.
