# Update OKR status

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

You will regularly update two main OKR areas: Status and progress.

This page covers status updates.

## OKR statuses

All the available default statuses are the only statuses you can assign to your Strategic Themes, Objectives, and Key Results. The module does not support custom statuses. Statuses are not updated automatically.

You can assign one of the following statuses to the OKR during the update process:

![OKR progress statuses.](/cms_trial/assets/d52dca7e-dbb0-4566-a03e-cbf8ba79ed9a.png)

- **Not started** - This is the default status automatically assigned to all the new OKRs.
- **On track** - This status indicates that the OKR is progressing as planned.
- **At risk** - This status indicates a significant chance that the Objective or Key Result will not be met within the set timeframe. It signals the need to reassess priorities, make adjustments, or take corrective action to get the OKR back on track.
- **Off track** - This status warns that progress toward achieving the OKR is not aligning with the expected timeline. An off-track Objective indicates a misalignment with the Key Results. It indicates a critical moment to course-correct before the OKR falls too far behind.

When you update the OKR status, the update screen will also show the previous status for reference.

## Status update from Not started

### Sub-Strategic Theme

If you update a sub-Strategic Theme’s status and a parent Strategic Theme’s status is also **Not started**, you will be asked if you want to update the parent’s status as well.

If you decide to update a parent’s status, you will see an additional update dialog showing the same status and description you selected for the "Not started" sub-objective. But you can change the status to a different one on the next screen.

![Update a parent OKR message.](/cms_trial/assets/69f7f8e8-68b7-46a0-a5fb-cfde31fa33b3.png)

### Sub-objective

Likewise, if you update a sub-objective’s status and a parent Strategic theme’s or Objective's status is also **Not started**, you will be asked if you want to update the parent’s status as well.

If you decide to update a parent’s status, you will see an additional update dialog showing the same status and description you selected for the "Not started" sub-objective. But you can change the status to a different one on the next screen.

![Update a parent OKR message.](/cms_trial/assets/69f7f8e8-68b7-46a0-a5fb-cfde31fa33b3.png)

### Key Result

When updating a KR's status from **Not Started**, you will be asked if you want to update the parent Objective(s) as well. This helps quickly start related objectives, especially when updating several KRs at once.

![Update a parent OKR message.](/cms_trial/assets/7a521810-4378-4737-8d84-1a318d17807a.png)
