# Convert milestone to Jira work item

## Convert milestone to Jira work item (old navigation)

Click to expand the guide

In the Gantt module, you can convert a milestone to a Jira issue (and a [Jira issue to a milestone](/cms_trial/space/SPM/1918537200/Convert+task+to+milestone/)). Milestones cannot be converted to JIra issues in [bulk](/cms_trial/space/SPM/1918832779/Multiselect+tasks/).

- A Jira issue converted from a milestone will have the start and end dates the same as the date of the milestone it was converted from.
- Only milestones that were created or converted from [basic tasks](/cms_trial/space/SPM/1918405930/Basic+tasks+%2F+BigPicture+tasks/) can be converted to Jira issues.

## Context menu

1. Right-click a milestone or a diamond on the timeline to prompt the context menu.
2. Select **Convert to Jira issue**.

![A menu for converting a milestone to Jira issue.](/cms_trial/assets/2a7928c6-b0e7-402b-a642-8993c199def1.png)

1. On the **Convert Basic task to Jira issue** screen:

- select Jira project from the dropdown
- select Jira issue type from the dropdown

1. Provide Jira issue details.
2. Click **Create** to finish the process.

## [Editor slider](/cms_trial/space/SPM/1918635307/Editor+slider/)

1. Select a milestone or a diamond on the timeline to highlight it and prompt the editor slider.
2. From the editor slider, select **More actions** (**…**) > **Convert to Jira issue**.

![A menu for converting a milestone to Jira issue.](/cms_trial/assets/65c6eb27-363c-444c-8a55-1ab6a4a49934.png)

1. On the **Convert Basic task to Jira issue** screen:

- select Jira project from the dropdown
- select Jira issue type from the dropdown

1. Provide Jira issue details.
2. Click **Create** to finish the process.

## Convert milestone to Jira work item (new navigation)

Click to expand the guide

In the Gantt module, you can convert a milestone to a Jira work item (and a [Jira work item to a milestone](/cms_trial/space/SPM/1918537200/Convert+task+to+milestone/)). Milestones cannot be converted to Jira work items in [bulk](/cms_trial/space/SPM/1918832779/Multiselect+tasks/).

- A Jira work item converted from a milestone will have the start and end dates the same as the date of the milestone it was converted from.
- Only milestones that were created or converted from [BigPicture tasks](/cms_trial/space/SPM/1918405930/Basic+tasks+%2F+BigPicture+tasks/) can be converted to Jira work items.

## Context menu

1. Right-click a milestone or a diamond on the timeline to prompt the context menu.
2. Select **Convert to Jira issue**.

   ![Screenshot of the Convert to Jira issue option.](/cms_trial/assets/1b0aff13-6bd1-43bc-8477-162bb16a504a.png)
3. On the **Convert BigPicture task to Jira issue** screen:

   1. select Jira space from the dropdown
   2. select Jira work item type from the dropdown
4. Click **Next**.

   ![Screenshot of the Convert BigPicture task to Jira issue window.](/cms_trial/assets/bd58ab1a-d776-4e22-b410-9069161ed33e.png)
5. Provide Jira work item details.
6. Click **Create** to finish the process.

## [Editor slider](/cms_trial/space/SPM/1918635307/Editor+slider/)

1. Select a milestone or a diamond on the timeline to highlight it and prompt the editor slider.
2. From the editor slider, select **More actions** (**…**) > **Convert to Jira issue**.

   ![Screenshot of the Editor slider with the More actions menu button highlighted in the Gantt module.](/cms_trial/assets/29879e07-e82a-43f9-9ebf-af906c60b42b.png)

1. On the **Convert BigPicture task to Jira issue** screen:

   1. select Jira space from the dropdown
   2. select Jira work item type from the dropdown
2. Click **Next**.
3. Provide Jira work item details.
4. Click **Create** to finish the process.
