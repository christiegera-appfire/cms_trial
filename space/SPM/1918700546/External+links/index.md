# External links

## About external links

External links show dependencies between tasks across different boxes.

![External link icon next to dependency](/cms_trial/assets/338d6238-2c8f-4310-b06c-7c225010beab.png)![An external links between two tasks in the Gantt module.](/cms_trial/assets/6ac254dd-5bdf-41f2-831b-efe10791d1ff.png)

External dependencies are listed in the dependency dialog. They are marked with a crossed-eye symbol because they can't be visualized.

![External link in dependency dialog](/cms_trial/assets/cd59b9c8-9e71-488a-938f-441bbc1f4bf6.png)
