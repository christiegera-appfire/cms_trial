# Play with sample data

## Play with sample data (old navigation)

Click to expand the guide

The **Play with sample data** is one of the quick action tile options available in the Overview module at the Home (root) box level.

This option creates a new box with Jira data that is stored only in BigPicture. This way, you can poke around the app without worrying about affecting any real data on your Jira instance.

## Create a box with sample data

1. Navigate to the Home box and open it in the Overview module, Hierarchy mode.
2. Open the **Quick actions** panel. If you cannot see the panel, click the arrow at the top of your box hierarchy to open it.

![The expand button for opening the Quick actions panel.](/cms_trial/assets/c10a4236-44e8-42f5-9eeb-6930a3f832a2.png)

1. From the **Quick actions** panel, select the **Play with sample data** tile.

![Quick action tiles in the Home box.](/cms_trial/assets/e66dbf73-2aed-4b65-abe1-20d59951ab16.png)

1. Choose the type of data you want to play with. You can create a test box with:

- Agile Project
- Classic Project
- Hybrid Project
- Portfolio
- SAFe ART
- Resource management

![Play with sample data box type options.](/cms_trial/assets/bac7506b-4be1-471a-999a-7950cd65842f.png)

1. Click the **Play Now** button.
2. Your sample box is now displayed in the [box hierarchy](/cms_trial/space/SPM/1918535907/Box+hierarchy/) in the Home box in the Overview module. You can start playing with it.

![A sample box displayed in the box hierarchy.](/cms_trial/assets/b488b86b-3be3-4448-9e1d-0247b9a5ebf5.png)
