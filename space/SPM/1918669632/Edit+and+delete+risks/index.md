## Delete risks

You can remove the risk (any issue) from the matrix and the register by clicking the "Delete" button. The issue will not be deleted from your Host platform but the values of the mapped fields, such as "Risk probability" and "Risk consequence" will be cleared.

![contentId-1918669632](/cms_trial/assets/b2e63fc2-8318-45c6-be9f-b3254c81ca22.png)

Consequence and probability values set for a risk need to be consistent with the configuration of both axes. If you delete a consequence or probability value from the axis configuration, a risk that has such a value set is removed from both the matrix and table view.

## Delete risks

You can remove the risk (any work item) from the matrix and the table.

The work item will not be deleted from Jira, but the values of the mapped fields, such as "Risk probability" and "Risk consequence", will be cleared.

Consequence and probability values set for a risk need to be consistent with the configuration of both axes. If you delete a consequence or probability value from the axis configuration, a risk that has such a value set is removed from both the matrix and table views.

### Matrix
