# Navigation and interface (Overview module)

## Navigation and interface - Overview module (old navigation)

Click to expand the guide

The Overview module offers three distinctive view modes and view customization options, each suitable for performing a specific set of actions. This helps you manage your boxes effectively.

In the respective view mode

- Hierarchy
- Timeline
- Kanban

The upper menu lets you do the following:

![Overview module upper menu.](/cms_trial/assets/454a3b80-b937-4c20-8357-e281f4a28b04.png)

- Switch between the view modes
- [Create a new box](/cms_trial/space/SPM/1918406376/Create+box/)
- Sort visible boxes
- Adjust the view (Hierarchy and Timeline modes) and show [archived boxes](/cms_trial/space/SPM/1918634657/Archive+box/)
- [Export](https://appfire.atlassian.net/wiki/spaces/BTc/pages/3536224346) the current view
- Switch the [column view](/cms_trial/space/SPM/1918700155/Column+view+(Overview+module)/) (Hierarchy and Timeline modes)
- Mark favorite boxes
- [Search and filter](/cms_trial/space/SPM/1918503449/Filters+and+search/) boxes
- Hide the upper menu
