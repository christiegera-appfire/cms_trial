# Manage team membership

You can define a membership period for each team member using date pickers and add, edit, or delete memberships.

Once you define a membership period, skills available in that timeframe are automatically added based on the skill's start/end dates set on the **Administration > Resources** page.

Team memberships must be edited where they were created. Membership editing is disabled when a team is inherited (made in a different box but assigned to another).
