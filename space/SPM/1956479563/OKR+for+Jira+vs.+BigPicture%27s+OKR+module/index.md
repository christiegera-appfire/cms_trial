# OKR for Jira vs. BigPicture's OKR module

On this page, you’ll find a detailed comparison between the standalone [OKR for Jira](https://marketplace.atlassian.com/apps/1221776/okr-for-jira?tab=overview&hosting=cloud) application and the [OKR module](/cms_trial/space/SPM/1918535397/OKR+module/) within BigPicture Enterprise. The table presents the key elements, such as navigation, context, visibility settings, permissions, and feature parity.

| **Compared element** | **OKR for Jira (standalone)** | **OKR module in BigPicture Enterprise** |
| --- | --- | --- |
| **Navigation** | Access OKR for Jira:   - Click the **OKR** tab on the left-side menu, or - Click **Apps** > **OKR**. | Access the OKR module:   - Click the **BigPicture** tab on the left-side menu and go to the **OKR module**, or - Click **Apps** > **BigPicture** > **OKR module**. |
| **Context** | All Objectives and Key Results. | In BigPicture [boxes](/cms_trial/space/SPM/1918404963/Concept+of+a+box/), you can have a collection of tasks coming from one or multiple Jira projects, boards, or JQL filters.  When you navigate to the OKR module at the Home box level, you will see all available Objectives and Key results.  When you go to the module within a specific box, you will see only the OKRs associated with that box. There are 2 ways how OKRs can be linked to a box:   - By linking specific Jira tasks to the OKR, OKRs associated with tasks from the box will be visible in the module. - Manually selected OKRs that will be visible in this particular box (use the [**Link to Box**](/cms_trial/space/SPM/1918834116/Link+OKR+to+box/) button at the top-right corner).   The video presents a short overview of the OKR module. |
| **Visibility settings** | - | Users with box editing permissions can enable or disable the OKR module for each BigPicture box. See the [Define available modules](/cms_trial/space/SPM/1918503298/Define+available+modules/) page. |
| **Permissions** | App permissions allow you to restrict certain actions from certain users or teams. | - Box access (box viewer permissions are required). - The same app permissions are available within the OKR module.   To learn more, see the [OKR module permissions](/cms_trial/space/SPM/1918765815/OKR+module+permissions/) page. Modules in BigPicture Enterprise. |
| **Feature parity** |  | All features besides the Timeline page are also included in BigPicture Enterprise, along with the following enhancements:   - Objectives and Key Results columns in the Gantt and Scope modules to track the progress of OKRs across the entire company portfolio. - Objective & Key Result structure builder to see the task hierarchy based on the relationships between the Objectives, Key Results, and the issues linked to them. - Linking entire projects and initiatives, represented as BigPicture boxes, to Key Results will be available soon.  Objective and Key Results columns in the Gantt module. Click the Objective or Key Result to open a dialog with details. |
