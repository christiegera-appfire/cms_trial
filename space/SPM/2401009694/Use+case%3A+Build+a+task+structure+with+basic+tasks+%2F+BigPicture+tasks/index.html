Use case: Build a task structure with basic tasks / BigPicture tasks

5 min read

Basic tasks have been renamed to BigPicture tasks as part of the new navigation rollout.

Both names refer to the same functionality. You may see either term depending on whether you’re using the previous navigation or the new navigation that is currently being rolled out in BigPicture.

Build a task structure with basic tasks (old navigation)

Click to expand the guide

Goal

Create extra levels of structure with basic tasks without affecting your Jira space.

Create additional hierarchy levels using basic tasks in BigPicture and quickly organize data independently of Jira, with the flexibility to convert these tasks into Jira work items as needed.

Scenario

A project manager manages a complex project with many Jira work items. They find the Jira task hierarchy somewhat limiting when visualizing the different stages. To make the task structure more manageable, they use BigPicture's basic tasks, which exist only in BigPicture and are not synced with Jira. Basic tasks serve as high-level placeholders to categorize the existing Jira tasks better.

When needed, the project manager converts some of these basic tasks into real Jira work items directly from the BigPicture interface.

Key benefits

  • Simplified organization - create extra structure levels without modifying the actual Jira space.

  • Flexible planning - test ideas or restructure your plan without impacting your Jira backlog.

  • Quick conversion - convert basic tasks into Jira work items when you need.

  • Visual clarity - improve navigation across complex projects by grouping them.

Preconditions

Role You need at least a Box Editor role to add basic tasks.

box The box needs to be populated with a Jira space.

Build a task structure with basic tasks step-by-step

Add basic tasks

With basic tasks, you can simulate extra levels in the structure of your Jira tasks. It’s a quick way to organize data. Basic tasks are stored only by BigPicture and are not synchronized with Jira.

  1. Open a box in the Gantt or Scope module.

  2. Click the + (plus icon) > Create task > Basic task.

  3. Fill in the task information. It is not mandatory to add the Start date and End date.

  4. Click Create. A newly added basic task is highlighted in the task structure.

  5. To move a task higher in the hierarchy, right-click on the task > Position > Move to top or Move up.

The video presents how to create and move a basic task in the structure.

Convert basic tasks to Jira work items

You can convert a basic task into a real Jira work item at any time.

  1. Find a basic task to convert.

  2. Right-click on a basic task and select Convert to Jira issue.

  3. Select a Jira space and a work item type.

  4. Click Next.

  5. Complete details and click Create.

The video presents how to convert a basic task into a Jira work item.

Tip: You can use a basic task as a parent for other tasks and aggregate data from nested tasks.

Expected outcomes

  • Basic tasks are visually distinguishable from Jira work items.

  • A task structure with additional levels and placeholders created using basic tasks improves project clarity without modifying the actual Jira space.

  • When necessary, selected basic tasks can be converted into Jira work items.

  • Project managers get greater flexibility and visual control over task planning and structure.
