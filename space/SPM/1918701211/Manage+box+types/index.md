# Manage box types

## About managing box types

Use box types to customize the App and match your management framework. You can create new box types from scratch or duplicate existing ones. Once you define at least one parent type for them, your box types are ready to use in the Overview module.

![Screenshot of the Box types page in Administration.](/cms_trial/assets/2067d696-3832-4b65-9454-58995f439ec2.png)

## Security and access

Only the App admin can access and change the box type configuration.

1. Click the wrench icon and select **Box types** from the dropdown list.

   ![Screenshot of selecting the Box types option from the drop-down menu.](/cms_trial/assets/2b8e9a85-e008-4927-99d4-fe6e4cfc88b7.png)

## Box type attributes

See the [Box type attributes](/cms_trial/space/SPM/1918832188/Box+type+attributes/) page.

## Status

A box template status can:

- Exists as a draft - a box type is not used by any box and can be deleted.
- Be in use - a box type is used by at least one box.

Even if you archive a box type, if any existing box uses it, the status remains **In use**, and a type can't be deleted.

## Add new box type

1. To add a new box type, click **+Add new box type**.
2. Provide **Box type name** and **Box prefix**.
3. Select an icon and a box type color.
4. To confirm, click **Create**.

   ![Screenshot of creating a new box type in Administration.](/cms_trial/assets/dd312d46-b124-4d4a-96b6-1ef0f439d5b4.png)

## Duplicate box types

To simplify setup, you can duplicate an existing box type (all settings are copied) and make needed adjustments.

1. Click the **Duplicate** button.

   ![Screenshot of duplicating a box type in Administration. ](/cms_trial/assets/1cb1c928-5218-4757-9520-85f0931c9a6a.png)
2. A box type duplicate is automatically created with a "-copy" suffix added to the name (no creation pop-up appears).

   ![Screenshot of a duplicated box type in Administration.](/cms_trial/assets/5477a371-7b5e-415b-908d-a72ba91567c9.png)

## Archive box types

Archiving a box type doesn't affect existing boxes that use the configuration - an archived box type can still be in use but won't be available when creating a new box. Only the box types in the "IN USE" status can be archived.

You can restore archived box types at any time.

1. Click the **Archive** button.

   ![Screenshot of archiving a box type in Administration.](/cms_trial/assets/b1f17071-808b-4245-9b6c-bfc78447ee8a.png)

## Delete box types

You can delete a box type only when no boxes use it, and the box type status is set to "DRAFT.” Deletion is irreversible.

1. To delete a box type, click the **Delete** button.

   ![Screenshot of deleting a box type in Administration.](/cms_trial/assets/6cbfc88d-2c74-442d-b728-09dbf70e9d43.png)

## Restore box types

You can restore box types that are archived. Toggle the "Show archived box types" switch to hide/show archived types.

1. To restore a box type, click the "curved arrow" button.

   ![Screenshot of restoring a box type in Administration.](/cms_trial/assets/62c33356-06b4-437a-852c-320fe81fb16d.png)
