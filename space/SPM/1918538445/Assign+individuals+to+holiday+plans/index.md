# Assign individuals to holiday plans

## Assign individuals to holiday plans

You can assign individuals to a holiday plan on the following pages:

- BigPicture Administration > Resources > Individuals
- BigPicture Administration > Resources > Holiday plans

### **On the Holiday plan page**

To assign an individual to a holiday plan from the **Holiday plans** page:

1. Go to **BigPicture Administration** > **Resources** > **Holiday plans** page.
2. Click **Assign individuals**.
3. Select the **holiday plan** from the list.
4. Define the **start date**. The end date will be adjusted automatically based on the start date of the previous plan.
5. Select **individuals** from the list or use the **search box** to find them faster. The **Select all** and **Deselect All** options are useful when assigning multiple individuals.
6. When ready, click **Assign**.

### **On a resource's page (individual’s details page)**

1. Go to **Administration > Resources > Individuals**.
2. Find a resource on the list.
3. Click on the name of that resource.
4. Manage holiday plans directly on the resource’s page.

The table presents how to manage holiday plans on an individual’s details page.
