# Task warnings (Resources module)

## About task warnings

Warnings help you spot common issues and errors when working with tasks in the Resources module.

If there is an issue with any part of the task:

- Estimate
- Assignment
- Workload contour

the task is highlighted with a yellow outline.

![Taskbar magnified to show the yellow outline signifying a warning.](/cms_trial/assets/3083ba89-5ec8-43bc-9da9-f8e4d6bff8a0.png)

## View the warning details

To see the warning details, click the taskbar to open the task information.

![Task warning explained in the task details.](/cms_trial/assets/4c6ec6c1-8abd-4b35-b83c-c99dc367caaa.png)

## Examples of warnings

### **Estimates**

The "Estimates" warnings appear based on the Effort Mode to notify you about missing estimates (Original or Remaining) for certain tasks.

![An example of the Estimates warning.](/cms_trial/assets/bcbf3784-13fa-41b5-914a-6fe2a882353b.png)

### Assignment

The “Assignment” warnings inform you when there is a problem with the task assignment in terms of teams or skills.

![An example of the Assignment warning.](/cms_trial/assets/f73f868c-6640-4d28-b9ed-b2590f5fee7c.png)

### Workload contour

The “Assignment” warnings appear when there is a problem with the workload distribution contour.

![An example of the Workload contour warning.](/cms_trial/assets/4228749c-8563-4ebc-a4c0-6e825518f2a3.png)
