# Task warnings (Resources module)

## About task warnings

Warnings help you spot common issues and errors when working with tasks in the Resources module.

If there is an issue with any part of the task:

- Estimate
- Assignment
- Workload contour

the task is highlighted with a yellow outline.

To see the warning details, click the taskbar to open the task information.

## Examples of warnings

### **Estimates**

The "Estimates" warnings appear based on the Effort Mode to notify you about missing estimates (Original or Remaining) for certain tasks.
