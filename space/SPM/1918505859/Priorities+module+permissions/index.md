# Priorities module permissions

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

## Default permissions

By default, every user has full permissions (Administer BigPicture Enterprise Priorities).

## Change permissions

To change permissions, you need to be a Jira Administrator.

1. Go to **Jira settings** > **System** > **Security** > **Global permissions**.

![Screenshot of the available permissions for the Priorities module in BigPicture Enterprise.](/cms_trial/assets/f6dfd741-ffe6-47dc-95b9-122b034cf6e0.png)

## Available permissions

| **Permission** | **Description** |
| --- | --- |
| Administer BigPicture Enterprise Priorities | Users with this permission can:   - Configure prioritization templates (edit, create, delete). - Prioritize issues. - Access the priority matrix in the BigPicture Priorities module. |
| Manage BigPicture Enterprise saved views | Users with this permission can:   - Create, edit, and delete saved views in the BigPicture Priorities module.   All users have permission to view saved views. |
| Access BigPicture Enterprise priority poker | Users with this permission can:   - View, create, delete, and play poker games in Priority Poker, in the BigPicture Priorities module.   Users can only delete games they created. |
