# Resources (App configuration)

## Absences are self-managed by App’s user

Jira/App Admin must first enable the users to self-manage their absences in their profile settings.

To access the global settings for the Resources module:

1. Click the **wrench icon** in the top right corner.
2. Select **Modules** from the dropdown.
3. Go to the **Resources** page.
4. On the **Resources** page, enable the **Absences are self-managed by App’s user** option.

Once enabled, users can add absences in their profile settings. For more information, see the [Manage absences](/cms_trial/space/SPM/1918633840/Manage+absences/) page.

![app-config-modules-resources-absences.png](/cms_trial/assets/3e1b3590-b0a8-408d-96d7-09bc5f19ad55.png)

## Tasks assigned to an individual are auto-assigned to their team

When this option is enabled, the team is automatically assigned a task based on the task assignee. For more information, see the [Automatic assignment](/cms_trial/space/SPM/1918408224/Automatic+assignment/) page.

The option is **switched ON** by default for all new instances.

![App Configuration, Modules, Resources, Tasks assigned to an individual](/cms_trial/assets/3366fff8-433f-4bf3-bf55-fcf8a43ba49b.png)

### Team member assigned belongs to more than one team, team field was not updated

If the task assignee is a member of more than one team in the box, the team is not updated, and the following message is displayed: Team member assigned belongs to more than one team, team field was not updated.
