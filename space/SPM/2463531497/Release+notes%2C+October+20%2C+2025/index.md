# Release notes, October 20, 2025

**Release date**: October 20, 2025

Our team is thrilled to announce the latest release of BigPicture Enterprise Cloud.

---

## New

## Clone tasks

Cloning tasks now supports cloning Jira epics. To learn more about supported fields, see the <https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=spm&title=Clone%20tasks&linkCreation=true&fromPageId=2463531497> page.

## Manage milestones (Financials module)

Navigate directly to the **Budget milestones** page from the chart in the Financials module. To learn more, see the [Actual vs Planned](/cms_trial/space/SPM/2265252322/Actual+vs+Planned/) page.

![right-click-manage-milestones.png](/cms_trial/assets/60015273-3019-4c64-a51c-dd197d9c3cc5.png)

## Enhancements

## Resources panel in Gantt

The redesigned Resources panel in the Gantt module provides enhanced customization and allows you to switch between the individual’s and team’s workload views. To learn more, see the [Resources panel in Gantt module](/cms_trial/space/SPM/1918798033/Resources+panel+in+Gantt+module/) page.

### View the team’s workload

You can now view the team’s workload, which can be displayed in hours, man-days, percent, or Story Points.

![image-20251008-074454.png](/cms_trial/assets/9ee49e74-4ce6-4c25-aab4-c275f8c71abe.png)

### More aggregation options

New aggregation options available in the Resources panel:

- Quarterly
- Yearly
- By timeboxes

![image-20251008-075351.png](/cms_trial/assets/5b04fd78-e7a6-418a-9c6b-5ee9f770e747.png)

## Capacity calculation

Improved individual capacity calculation when grouping by [*Individuals then Projects*](/cms_trial/space/SPM/1918701793/Swimlanes+and+grouping/) in the Resources module. To learn more about calculating individual capacity in different grouping combinations, see the [Capacity calculation](/cms_trial/space/SPM/1918765081/Capacity+calculation/) page.
