Navigate between boxes (box switcher)

6 min read

Box switcher (old navigation)

Click to expand the guide

The box switcher, located in the upper-left corner of the app, displays the name of the current box you are viewing. When you click it, a drop-down list containing the box hierarchy tree is displayed. You can then select a specific box from the hierarchy to switch to.

Use the box switcher to switch between different boxes. Once opened, the active box is highlighted, so you can switch to a sub-box or a different box.

You can only browse through the boxes for which you have permission.

The box switcher is displayed in the app’s header for each module, as well as in the WBS and Skill widgets; both can be added to the issue screen.

Watch the interactive tutorial on accessing and using the box switcher.

Security and access

  • The box switcher is always displayed in the left corner of every module. Click to expand the dropdown.

  • To view the boxes, you need a box viewer security role.

Breadcrumbs navigation

Above the box switcher, you can see the breadcrumb trail: a path that leads from the root box to the current box, showing every level. Each element is a clickable link that leads to the corresponding level.

Box details

The following information is presented for each box on the list: 

Box ID

The box IDs are composed of a box type prefix and a sequentially generated number automatically generated by the app. These IDs are displayed next to the box switcher within the module. You can enter the box ID into the search box in the module, next to the box switcher, to find a specific box.

For example, the Hybrid Project’s box ID is HYBR-1, as this box was created based on the Hybrid box type.

Box name 

In the Overview module and the box switcher, you can search for a specific box by entering its name. Whenever a new sibling box is included, the app automatically appends a number to the description.

For example, if the box name is Iteration, the automatically generated name of a same-level box would be Iteration 1.

Box status

The box status is displayed next to the box name in the box switcher. You can change the box status in different sections of the app. In the Overview module, use the right-click or drag-and-drop option when in the Kanban mode. You can also change the status in the Board module or on the scope definition page in the box configuration.

The status is indicated using colors, and the following color-coded statuses are available:

  • Not started (gray)

  • In progress (blue)

  • Done (green)

Favorite (star) 

Mark the boxes as your favorites and filter out all other boxes using the switcher or the module's filters.

Hierarchy

The box hierarchy can be modified in the Overview module’s Hierarchy mode. You can expand and collapse it to see the level of information you want.

Home button

Use the home button to navigate back to the Home screen.

Search boxes

If you can't find what you are looking for by scrolling, use the search bar. It works with the box name and ID.

Filtered view in box switcher

Favorite boxes

In the filtered view, the box tree structure is not shown (only the boxes that match the filter).

Click the star button next to the search bar to narrow the list to your favorite boxes.

The favorite filters are found in the box switcher and the Overview module.
