# Heatmap (Calendar)

## About the Calendar heatmap mode

When the Calendar heatmap is on, tasks are color-coded like in the Gantt module. When it's off, all tasks appear gray.

![Screenshot of the heatmap mode in the Calendar module.](/cms_trial/assets/5b5f0953-d81a-42e3-8f5a-9821325bebad.png)

## Activate the heatmap mode

Go to the **View** dropdown and click **Heatmap mode** (or press the **H** button on your keyboard).

![Screenshot of activating the heatmap mode in the Calendar module.](/cms_trial/assets/ae3f4449-b6bf-436b-813d-774d0b07ab7b.png)

A checkmark indicates whether the **Heatmap mode** is currently:

|  |  |
| --- | --- |
| ON | Heatmap checkbox checked. |
| OFF | Heatmap checkbox unchecked. |

## Task color

Task color can be displayed based on the following:

- Task status
- Manually selected colors

### **Task status**

- **To do** (gray)
- **In progress** (blue)
- **Done** (green)

![Screenshot of the Task color settings in the View menu of the Calendar module.](/cms_trial/assets/b79bbee2-3366-41de-bcfd-ff9b9be5991e.png)![Screenshot of status-based tasks view in the Calendar module.](/cms_trial/assets/de2b0456-d703-447b-a5b0-aa491fcb5e0c.png)

### **Manually selected colors**

![Screenshot of the Task color settings in the View menu of the Calendar module.](/cms_trial/assets/fdde160a-7eae-4185-a053-9af0868427df.png)

Below, you can see how manual colors translate to the Calendar module:

![Data from Gantt chart represented in the Calendar module.](/cms_trial/assets/ec9ad96c-5643-4760-b384-6d5f61b279e6.png)

You can change the task color directly in the Calendar module.**Right-click** on a task to see a dialog menu. The selected task will be highlighted in blue.

![Screenshot of changing the task color in the Calendar module.](/cms_trial/assets/a89e74fc-938e-4690-a00a-d899efd486e3.png)

Once you select a color, click outside the dialog menu to close it. The task is no longer highlighted, and a new color is visible.

![Screenshot of the Calendar module with manually set task colors. ](/cms_trial/assets/672eb2e8-6124-4def-8bb2-a71417747447.png)

You can change the manually selected task colors, even when the Heatmap mode is inactive. The dialog menu is still accessible, and changes can be made. The manual task color changes will affect other modules (such as the Gantt module).
