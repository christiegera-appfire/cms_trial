# Overview gadget

**Depreciated** **by Atlassian**

[Atlassian ended support for gadgets in Confluence 7.0](https://confluence.atlassian.com/doc/gadgets-moved-to-a-marketplace-app-from-confluence-9-2-onwards-1431545691.html) and completed their removal in Confluence 9.0 to reduce technical debt.

In Confluence 9.0, pages that were using gadgets show a grey ‘Unknown macro’ placeholder where gadgets were embedded.

The Overview gadget (the former Boxes gadget) shows the box hierarchy, just like the hierarchy mode of the home view. Use this gadget to navigate between modules or configurations and check the status of your work.

![big-picture-overview-gadget.png](/cms_trial/assets/9a0a6dab-7c8e-4a27-856d-d3f334aa6ea0.png)

## Security and access

You need at least a Box Viewer security role to view the Gadgets on the Confluence pages and Jira Dashboards.

## Box Hierarchy

Click the tree next to the Box Name column to expand or collapse the hierarchy to the required level.

### Collapse / Expand All

Click the ">" next to the Name (column header) to expand or collapse all the Boxes.

![big-picture-overview-gadget-expand.png](/cms_trial/assets/128a03d9-5512-442c-be79-07ff04ad46ea.png)

## Sorting Boxes

You can sort the list by:

- name
- ID
- type
- status
- start date
- end date
- leader

The sorting does not impact the order of the Boxes presented in the Overview module.

![big-picture-overview-details.png](/cms_trial/assets/c73cffcc-264a-4d75-bf14-9cba75a4006a.png)
