# OKR fields vs BigPicture fields

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

The OKR module includes fields for storing information specific to your OKRs. Some OKR fields are available in the Gantt and Scope modules.

When the [Objectives & Key Results structure builder](/cms_trial/space/SPM/1918863661/OKRs+as+task+structure+builders/) is active, OKRs are visible in the task tree in the Gantt and Scope modules.

## The OKR <> BigPicture fields

Some OKR fields can be edited in multiple BigPicture modules, but you’ll find them under a different name.

| **OKR field** | **BigPicture field** |
| --- | --- |
| **Owner** | **Assignee** |
| **OKR name** | **Summary** |
| **Expected start date** | **Start date** |
| **Expected end date** | **End date** |

Some OKR fields are available in other BigPicture modules, but have different names. For example, in the OKR module, you’ll find the **Owner** field.

![okr-fields.png](/cms_trial/assets/f5e50c0d-191d-49f4-aead-f88dc1e12658.png)

In other BigPicture modules, such as Gantt, use the built-in Assignee field to display the same information for your Objectives and Key Results.

You can edit the fields listed below only in the OKR module. In other modules, they are read-only.

- Status
- Progress
- OKR type
