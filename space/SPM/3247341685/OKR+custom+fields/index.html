OKR custom fields

5 min read

OKR custom fields empower organizations to track specialized data points—such as strategic alignment, risk levels, or department-specific tags—directly within their OKRs. By capturing information that standard fields might miss, they enable you to adapt BigPicture to your unique framework.

  • Tailored reporting: Categorize and filter OKRs based on the specific business criteria that matter most to your leadership.

  • Enhanced context: Centralize all relevant OKR details in a single view to improve transparency and decision-making during quarterly reviews.

See the video to learn more.

Video transcript

Managing complex strategic frameworks at scale requires more than just tracking standard goals; it demands the flexibility to capture your unique organizational context.

With OKR Custom Fields in BigPicture, you can tailor your Strategic themes, Objectives, and Key Results with bespoke metadata—such as budget allocations, regional tags, or custom risk parameters.

To create a custom OKR field, head over to OKR Settings and select the Fields tab. Next, click the Create new button. On the creation screen, name your new field and select its data type from the dropdown menu.

For example, we’re going to create a Region field and choose Select as the data type.

By tagging goals with a Region custom field, you can seamlessly slice massive global portfolios into localized dashboards for AMER, EMEA, or APAC teams.

This ensures that geographic dependencies, regional regulatory compliance, and localized market ownership are clearly mapped and tracked without cluttering top-level corporate Objectives.

Next, decide whether this custom field should apply to all OKR levels, only to Strategic Themes and Objectives, or exclusively to Key Results.

Let’s leave both boxes checked. You can also add an optional description if you need to provide additional context for your teams.

Click Create to finish. Your new custom field is now active and visible in the list.

Let’s head back to the Overview screen.

By default, all new custom fields appear at the end of your column layout. You can also find them on the side panel and details page.

You can rearrange their order directly within the view or via the column layout configuration menu.

To add the field value for a specific OKR, simply click into the column and select your desired option from the dropdown.

If you ever find that you no longer need this field, you can easily hide it within the settings or column layout view. Hiding the field removes it from active display while securely retaining all underlying historical data associated with it.

Alternatively, you can edit or permanently delete the field altogether back in the OKR Settings.

Ready to unlock deeper context across your enterprise portfolio? Start building your own OKR Custom Fields in BigPicture today, and transform the way you measure strategic success.

Access and permission

You create OKR custom fields in the OKR module > Settings > Fields tab.

For that reason, you need one of the permissions to access the OKR module Settings (basic or advanced). The Fields tab requires the Manage custom fields advanced permission (unless the user is already granted a sufficient basic permission, for example, Full Access).

Create a new OKR custom field

To create a new OKR custom field:

  1. In the Fields tab, click the Create new button. A Create custom field modal displays.

  1. Enter a Field name.

  2. Select field Type from the dropdown:

  • Text

  • Number

  • Hyperlink

  • Select

  • Multi-select

  • User

  • Date

  1. Select Used in:

    • Objective/ Strategic theme, and/or

    • Key result

This option determines whether this field will be applicable to Objectives/ Strategic themes or Key Results or both.

Double-check your Type and Used in selections before saving, as these cannot be changed once the field is created.

  1. Optional: Provide a Description for your custom field. This can help other users understand the purpose of this field.

  2. Click Create.

Your new custom field is now visible in the Fields tab.

Hide/Show OKR custom field

Hiding an OKR custom field is an ideal way to temporarily disable it without losing its data or configuration. This lets you customize your view for the current needs while preserving the field for future use.

To hide and OKR custom field:

  1. In the Fields tab, click the eye icon next to the OKR custom field you want to hide.

  1. The custom field is now hidden, and the eye icon changes to an eye-slash.

To make the OKR custom field visible again, click the eye-slash icon next to the hidden field.

Edit OKR custom field

To edit an OKR custom field:

  1. In the Fields tab, click More actions (…) next to the OKR custom field you want to edit.

  2. Select Edit.

  3. On the Edit custom field modal, you can edit the following:

    • Field name

    • Description

  1. Click Save to finish.

Delete OKR custom field

To permanently delete a custom field and all data associated with that field from your OKRs:

  1. In the Fields tab, click More actions (…) next to the OKR custom field you want to delete.

  2. Select Delete.

  3. A confirmation modal displays. Click Delete to confirm.

Add custom field to OKR

You can add OKR custom fields on the Overview page in the OKR module. Before you add a custom field to your column layout on the Overview page, ensure the custom field is not hidden.

  1. On the Overview page, click the plus icon to open column layout options.

  2. By default, OKR custom fields are enabled and located at the bottom of the list. You can move them up, unselect (to remove from the column layout view), and lock them in place in your view.

  1. All OKR custom fields that you select appear in:

  • Overview > Column layout

  • Overview > OKR details side panel

  • Overview > Tree view

  • OKR details page > Info section

Import/ Export OKR custom fields

  • You can import and export OKR custom fields to and from BigPicture using API endpoints. Visit BigPicture Developer Portal for details.

  • You can also import and export OKR custom fields and their values using a CSV file. Before you begin your import, make sure the OKR custom fields in your CSV file match the fields configured in the OKR module’s Settings.

Visit Import OKRs and Export OKRs for more information.
