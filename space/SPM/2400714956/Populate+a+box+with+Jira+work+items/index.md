# Populate a box with Jira work items

## What will I learn on this page?

> 💡 On this page, we will show you how to get tasks from your Jira project into BigPicture.

You will learn:

- What is a scope.
- How to add work items from Jira to a box.

## Why do I need to define the scope for my box?

Before planning, scheduling, or analyzing your work in BigPicture, you need to tell the app which tasks you want to include in your box. In other words, you need to define the scope of your box.

BigPicture gives you flexibility in selecting the tasks. Whether you're working from a single Jira project or combining work across boards or filters, it's easy to fine-tune what’s included.

---

## Start simple: One Jira space, narrowed down

Let’s walk through a typical scenario: You want to visualize tasks from a single Jira space - but you don’t need to include everything, like bugs.

Here’s how to do it:

1. **Choose your box** (or create a new one).
2. Go to **Box configuration** > **Tasks** > **Work items from Jira**.
3. Choose a **Jira space**.
4. Use **Filters** to remove certain issue types (for example, Bugs).
5. Click **Save**.

Your box now includes only relevant work items from the project tailored to your current planning needs.

---

## Box scope types – behind the scenes

Each box has a [scope type](/cms_trial/space/SPM/1918766536/Scope+types/) (Own scope, Sub-scope, None) that defines how the scope behaves (and which options are available) based on the box type (for example, Program, Iteration, ART).  
By default, BigPicture sets this for you, so you rarely need to change it - but it helps power features like task synchronization and structure building.

---

## Explore other ways to add work items

BigPicture supports a wide range of setups beyond the default project-based scenario:

- **Jira boards**: Great for Agile teams using Scrum or Kanban. Pull in all work associated with a board.
- **Jira filters**: Use saved filters or JQL to define highly customized views of your data.
- **Multiple projects**: Combine tasks from several Jira projects in one place.
- **Labels**: Exclude work items with specific labels.

> 💡 **BigPicture is flexible** - you can adjust the scope anytime as your planning needs evolve.

---

## Prerequisites

- Make sure your box is created and active.
- Make sure you are a Box Admin.
- Need help setting a box up? Visit [Create your first box](/cms_trial/space/SPM/2400780468/Create+your+first+box/).

In addition, check that you have access to at least one Jira space, board, or saved filter. You’ll need this to define your scope.

---

## Troubleshooting scope issues

If work items aren’t showing up as expected:

- Make sure the correct **data source** is connected.
- Check that **filters or exclusions** aren’t removing the items you’re looking for.
- Confirm that the **scope owner** (the person who added the source) still has permission to access the Jira space or filter. If they don’t, the box can lose visibility into that data.

---

## Feature highlight: Scope definition panel

The **Scope definition panel** in each box gives you complete control over which tasks are included:

- Add or remove data sources (projects, boards, filters)
- Exclude issue types or apply JQL
- View current scope owner and permissions

You’ll find it under:  
**Add task** > **Manage scope definition**
