# Customize cost calculations

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

## Change period

In the Financials module for portfolio and for initiative, you can change the period for which the data is displayed by choosing it in the upper-left corner of the module:

![change-period.png](/cms_trial/assets/beef664b-8331-4f8a-bd4c-57422d766843.png)

## Calculation settings and details

You can display and edit the calculation settings in the Financials module for a single initiative. To do this, click the **Cost calculations** icon: ▢ in the upper-left corner of the module:

![edit-calculations.png](/cms_trial/assets/5f64628a-f0c8-4948-8b04-d53dbaec287c.png)

The Edit calculation settings option:

![Edit calculation settings dialog showing the 'How do you estimate work effort', and 'Which hourly rate should we use' options.](/cms_trial/assets/df09d442-7b08-4bbc-b197-d3fe1e8fd9a2.png)

### How do you estimate work effort?

- Man-days
- Story points

### Which hourly rate should we use?

- **Flat hourly rate** - use a single hourly rate for all tasks if the tasks are not assigned to teams
- **Team hourly rate** - use the team hourly rate if the tasks are assigned to teams and each team needs a different rate. If the team’s hourly rate is chosen and a team has not been set, the app sets $100 for the calculations. You can define hourly rates for teams on the [Financials (Administration)](/cms_trial/space/SPM/1918830158/Financials+(Administration)/) page.

### Box hourly rate ($)

Set an hourly rate for the current box (initiative).

## Custom expenses

Custom expenses are one-time or recurring expenses that are not associated with specific work items. They can be beneficial for monitoring flexible or miscellaneous project-related expenditures.

For more information, check [Financials (Administration)](/cms_trial/space/SPM/1918830158/Financials+(Administration)/) .
