# Heatmap mode (Risks module)

**About this page**

This page describes the Risks module, which is available only for legacy customers. For new implementations of BigPicture, use the [**Risk Management**](/cms_trial/space/SPM/1918798201/Risk+management+module+(new+module)/) module instead.

## Heatmap mode - Risks module (old navigation)

Click to expand the guide

Use the Heatmap mode to color the cards so the risk level is signified with color based on risk probability and consequence.

There are four default colors available (presently, non-editable):

- Green
- Yellow
- Orange
- Red

## Heatmap mode - Risks module (new navigation)

Click to expand the guide

Use the Heatmap mode to color the cards, with the risk level indicated by color based on risk probability and consequence.

Click **View** > **Heatmap mode**.

There are four default colors available (presently, non-editable):

- Green
- Yellow
- Orange
- Red
