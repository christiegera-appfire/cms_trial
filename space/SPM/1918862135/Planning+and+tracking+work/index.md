# Planning and tracking work

Effective project management starts with clear planning and consistent tracking. Whether you are assigning tasks or monitoring progress, having the right tools in place ensures your team stays aligned and on schedule.

This page provides detailed information about the BigPicture features that can help you effectively plan and track your work.

## Objectives

### Box objectives

In the Objectives module, you can set and manage basic and task-based box objectives.

[**Read more**](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=spm&title=Box%20objectives%20%28Objectives%20module%29&linkCreation=true&fromPageId=1918862135)

### Objectives and Key Results

If your organization uses the OKRs framework, you can set and track individual Objectives, sub-objectives, and Key Results in the OKR module.

[**Read more**](/cms_trial/space/SPM/1918405440/Objectives+%26+Key+Results+(OKR+module)/)

---

## Priorities

Set up priorities using one of the templates based on the popular prioritization methods (such as RICE and Quick Wins). You can edit the existing template and create a custom one. The module also offers priority poker.

[**Read more**](/cms_trial/space/SPM/1918504313/Priorities/)

---

## Critical path

Display the critical path for your tasks directly on the Gantt chart in the Gantt module. This feature highlights the tasks that have no room for delay, so that you know you need to carefully manage them to keep the project on schedule.

[**Read more**](/cms_trial/space/SPM/1918405060/Critical+path/)

---

## Task progress

Display task progress on a column in the Gantt module’s column view, on the taskbar, and on the task details.

[**Read more**](/cms_trial/space/SPM/1918764665/Task+progress/)

---

## Baselines

You can create and delete baselines in the Gantt module for all the tasks you added to the box or individually for the selected tasks only.

[**Read more**](/cms_trial/space/SPM/1918404564/Baselines/)

---

## Scenarios

The scenario mode lets you explore possible outcomes by changing variables or assumptions in your plan or project, such as task dates or scheduling modes. This feature is available in the Gantt and Resources modules.

[**Read more**](/cms_trial/space/SPM/1918634045/Scenarios/)

---

## Dependencies

Dependencies are relationships between tasks in the Gantt and Board modules to determine the order in which they need to be completed in a project. Dependencies can be strong (impact the schedule) and soft (cause no impact on the schedule).

[**Read more**](/cms_trial/space/SPM/1918536086/Dependencies/)

---

## Plan tasks in the Board module

Plan your tasks individually or in bulk using the Kanban board in the Board module—create new work items or schedule existing ones from the backlog.

[**Read more**](/cms_trial/space/SPM/1918831262/Planning+in+the+Board+module/)

---

## Warnings

In this section, you can find the warning messages that can appear in the app. These messages help you prevent errors, keep you informed, and explain how to respond to issues that require attention.

[**Read more**](/cms_trial/space/SPM/1918764811/Warnings/)

## Markers

Marker is a cross-module feature that highlights key dates—like events or deadlines—and serves as a reminder for those that require special attention.

[**Read more**](/cms_trial/space/SPM/1918699490/Markers/)
