## Gantt

![contentId-1918800322](/cms_trial/assets/84f9771b-26e2-4f4b-a143-25e0a07fefdf.png)

When you use Gantt's interface, you can create Jira or Basic tasks (which will only be displayed using the App).

### Jira tasks

Create a new Jira task (issue) using the task creation screen. Any issue type can be added as a task. If a task is already selected, the new task will be added just beneath it on the same level in the hierarchy.

Depending on the project synchronization settings, adding new tasks might update different fields mapped as start and end dates. To learn more, go to the [Fields](/cms_trial/space/SPM/1918635376/Fields/) page.

For example: If the "Start Date" field is not synchronized or it is not added to the appropriate issues screen when you add a task, there will not be any update of the "Start Date" field. However, when the "Start Date" is synchronized, adding a task without setting the start date estimate will result in a task update, and the "Creation Date" will be used as the "Start Date" (the "Creation Date" will also be used as the "End Date" if the task is not resolved).

![contentId-1918800322](/cms_trial/assets/fa15d50f-af20-4f21-a789-adea90a66c44.png)

Make sure you have selected the correct Jira project. Otherwise, you might unintentionally create a task in the wrong place.

If the App overwrites the manually specified start/end dates, verify box scheduling settings and task scheduling mode.

### Basic tasks

Create a basic task and add it to the list of tasks. Such tasks will not be synchronized with your Jira or connected tools. For example, you will not see a basic task in your Jira project.

![contentId-1918800322](/cms_trial/assets/55b21bfe-2933-48f0-9d06-44f24617d744.png)

### Task templates

This requires you to create a template first using the Task Template Creation menu in the Box configuration.

![contentId-1918800322](/cms_trial/assets/6175c4f8-d08b-4959-8bc3-880200f7ec24.png)

### Import from file

You can import your task templates from other tools, such as MS Project, MS Excel, or a CSV file. For more information, see the [Import from a file](/cms_trial/space/SPM/1918800781/Import+from+file/) page.

![contentId-1918800322](/cms_trial/assets/1232edeb-c76b-421a-a7fe-046633fcd69d.png)

### Clone existing scope

Use your existing Boxes as templates and clone the scope to a different box. As data needs to be stored in Jira projects, ensure your project settings are the same as the source project. For more information, check [the Clone existing scope (Gantt) page](/cms_trial/space/SPM/1918636677/Clone+tasks+%2F+Clone+from+another+box/).

![contentId-1918800322](/cms_trial/assets/ceb3ee21-9cbb-4581-a17f-b30491b11d8b.png)

## Board

The Board's backlog displays tasks that someone has added to the [scope of the Box.](/cms_trial/space/SPM/1918634319/Populate+a+box+with+tasks+(work+items+from+Jira)/) You can add tasks using the Board module in different ways.

You can't add tasks to Boxes in the "Closed" status.

## Financials

You can create a task by clicking **Create new** in the Financials module open in an empty box (during an [Initiative Financials onboarding](/cms_trial/space/SPM/2269872177/Financials+module+onboarding/)).

## Create new tasks in the host platform

You can add new tasks in the host platform (the host platform is the Jira instance you are currently using) in a few ways.

### "+Add" button

Click the "**+Add**" button and choose "**Create task**".

![contentId-1918800322](/cms_trial/assets/b3f9f8d1-9386-458e-a813-6c19d6a19916.png)

### Cards section

Click the "+" icon to add a task.

![contentId-1918800322](/cms_trial/assets/759a6910-d4a7-419b-a869-c63c35fce26b.png)

Once the task is added, it is assigned to a Box and will appear in the Backlog when the "Show already planned task" feature is enabled:

![contentId-1918800322](/cms_trial/assets/c0d86dfe-efb4-4071-bb4a-654f4f39624f.png)

### Infobar > Backlog

You can add tasks and subtasks directly from the **Backlog** section.

Expand the **Infobar** section and navigate to "**Backlog**". Decide where to add a task (or a subtask) and click the "+" icon.

![contentId-1918800322](/cms_trial/assets/21ddd69c-6f5b-44a2-9ba5-1aa649efd28d.png)

Next, decide what type of task/subtask you want to add. Complete the details and click "**Create**".

![contentId-1918800322](/cms_trial/assets/ad566abb-3c44-4a9b-97f0-844fc06fcce0.png)

## Create tasks - Gantt module

In the Gantt module, you can create Jira work items or BigPicture tasks (which will only be displayed using the App).

![Screenshot of the Tasks menu in the Gantt module.](/cms_trial/assets/ef9bfd66-4327-4fa4-8a99-1f2d56829604.png)

### Jira work items

Go to **Tasks** to create a new Jira work item. Any work item type can be added. If a work item is already selected, the work item will be added just beneath it on the same level in the hierarchy.

Depending on the space synchronization settings, adding new tasks might update different fields mapped as start and end dates. To learn more, go to the [Fields](/cms_trial/space/SPM/1918635376/Fields/) page.

Make sure you have selected the correct Jira space. Otherwise, you might unintentionally create a work item in the wrong place.

If the App overwrites the manually specified start/end dates, verify the box scheduling settings and task scheduling mode.

### BigPicture tasks

Create a [BigPicture task](/cms_trial/space/SPM/1918405930/Basic+tasks+%2F+BigPicture+tasks/) and add it to the list. Such tasks will not be synchronized with your Jira or connected tools. You will not see a BigPicture task in your Jira space.

### Task templates

This requires you to create a template first, using the [task template](/cms_trial/space/SPM/1918503892/Manage+task+templates/) creation menu in the box configuration.

### Import from file

You can import your task templates from other tools, such as MS Project, MS Excel, or a CSV file. For more information, see the [Import from a file](/cms_trial/space/SPM/1918800781/Import+from+file/) page.

### Clone from another box

Use your existing boxes as templates and clone the scope to a different box. For more information, see the [Clone tasks](/cms_trial/space/SPM/1918636677/Clone+tasks+%2F+Clone+from+another+box/) page.

## Create tasks - Board module

The Board's backlog displays tasks that someone has added to the [scope of the Box.](/cms_trial/space/SPM/1918634319/Populate+a+box+with+tasks+(work+items+from+Jira)/) You can add tasks (Jira work items or BigPicture tasks) using the Board module in different ways.

- **Click Tasks** > **Create new** > **Jira work item / BigPicture task.**

  ![Screenshot of the Tasks menu in the Board module.](/cms_trial/assets/bae7fc79-a529-48e5-9309-e4018f91e0a8.png)
- Inline create tasks in the Board’s backlog.

  ![Screenshot of creating a task incline in the Board module.](/cms_trial/assets/3520603c-ceef-401d-8c46-fbaed3d42596.png)

You can't create tasks in boxes with the "Closed" status.
