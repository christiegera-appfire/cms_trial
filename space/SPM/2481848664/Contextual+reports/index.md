# Contextual reports

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

## Contextual reports - old navigation

Click to exoand the guide

The following modules:

- Overview
- Gantt
- Scope
- Resources
- Board

offer advanced contextual reporting capabilities for quick lookups of key metrics applicable to the selected project, program, portfolio, and sub-box.

The contextual reports cannot be customized, but you can choose which ones to view, refresh them to show the most up-to-date data, and enlarge them for better visibility.

The following reports are available:

- [Boxes by status](/cms_trial/space/SPM/2913436083/Boxes+by+status/)
- [Teams capacity](/cms_trial/space/SPM/2913829054/Teams+capacity/)
- [Effort progress](/cms_trial/space/SPM/2911535555/Effort+progress/)
- [OKRs by Status](/cms_trial/space/SPM/2913599687/OKRs+by+Status/)
- [Project health (RAG)](/cms_trial/space/SPM/2988179457/Project+health+(RAG)/)

We plan to add more contextual reports in the coming months. If you haven’t found the report you need, it may be available soon. In the meantime, we encourage you to contact our [Support Team](https://appfire.atlassian.net/servicedesk/customer/portal/11) to drop your suggestion on the report you would like to see in BigPicture.

## Permissions and access

### Permissions

To view the contextual reports, a user must have at least the [Box Viewer](/cms_trial/space/SPM/1918668158/Box+security+roles/) role. To manage and edit contextual reports in any module, the user must have the Box Admin or Box Editor role.

When the user lacks permissions to certain boxes, tasks, or OKRs, the report displays data for the boxes/tasks/OKRs to which the user can access.

In such a case, the "Only your set of data is taken into account" message displayed at the bottom of the report informs you of this.

### Access

Contextual reports are available in every [box scope type](/cms_trial/space/SPM/1918766536/Scope+types/) and [box type](/cms_trial/space/SPM/1918830000/Box+types/) except the Home/root box.

- Overview (top of the module)
- Scope (Details View > Reports)
- Gantt (Infobar > Reports)
- Board (Infobar > Reports)
- Resources (Backlog > Reports)

|  |  |  |
| --- | --- | --- |
| **Scope type** | **Report** | **Modules** |
| **Overview** | **Gantt, Scope, Board, Resources** |
| - None scope (portfolio) - Own-scope (project, program) - Sub-scope (timebox) | Boxes by status | **Yes** (active by default) | **Yes** |
| OKRs by status | **Yes** (active by default) | **Yes** |
| Team capacity | **Yes** (active by default) | **Yes** (active by default) |
| Effort progress | **Yes** | **Yes** (active by default) |
| Project health | **Yes** | **Yes** |

Contextual reports are not available in the Root box.

## Enable or disable contextual reports

Each module displays a specific set of default reports. To hide or enable other reports, click the **plus (+)** button and select or unselect the report from the dropdown.
