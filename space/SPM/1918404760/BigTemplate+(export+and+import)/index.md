# BigTemplate (export and import)

## About BigTemplate

Don't be limited by a pre-defined export document style offered in Jira. Install **BigTemplate** and enjoy saving unlimited custom templates tailored to your needs.

BigTemplate has been designed to empower you to:

- Export all management data from BigPicture and BigGantt to preferred file formats (.xlsx, .odt, .csv, .mpp, .mpx, .pdf).
- Export Jira work item content to MS Word, MS Excel, or PDF.
- Import management data from the MS Project or MS Excel file to BigPicture.
- Create export templates for your Jira work items and all management data from BigPicture.

For more information, check [the BigTemplate documentation](https://appfire.atlassian.net/wiki/spaces/BTdc).
