# Navigation and interface (Risks)

## Navigation and interface - Risks module (old navigation)

Click to expand the guide

## View options

The **Risks module** can be adjusted to resemble your organization's risk matrix. You can change the view options to include more cards on the matrix using the compact mode or enable the [heatmap mode](/cms_trial/space/SPM/1918767574/Heatmap+mode+(Risks+module)/) to color-code your cards.

### Settings saved per user

The risks matrix view settings are saved per user and propagated to all the boxes that the user has access to.

![Screenshot of the View options in the Risks module.](/cms_trial/assets/04d3a6a8-f88b-49aa-89a8-f35a8bbc0f2d.png)

### Matrix and table views

Use the buttons in the top right corner to change how risk information is visualized.

| **Matrix view** | **Table view** |
| --- | --- |
| Screenshot of the Matrix view in the Risks module. | Screenshot of the Table view in the Risks module. |

## Invert and transpose

You can adjust the matrix to your needs by inverting and transposing the axes. To change the dimensions of the matrix, edit the select options of the mapped fields. The default dimensions are 5x5, as the risk fields have 5 select options.

![Screenshot of the View settings in the Risks module.](/cms_trial/assets/7b5dccf4-91b6-48b4-85ac-44021c63fee6.png)

### Transpose

Use the transpose option to change which field is presented as the X and Y axis.

### Invert

Invert the axis if you want to have the highest values shown first.

![Screenshot of the inverted axes in the Risks module.](/cms_trial/assets/9668f4b4-0d67-4ad9-983b-9305ddafef1d.png)
