# OKR details page

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

The OKR details page refers to the page that displays data for the Objective, sub-objective, or key result, depending on which item you are viewing. On the OKR details page, you can:

- Edit most of that data.
- Lock the OKR (if [OKR restriction](/cms_trial/space/SPM/1918864985/OKR+restrictions+(per+OKR)/) is enabled).
- [Update OKR](/cms_trial/space/SPM/1918637972/Update+OKR/)
- Launch the [Strategic Area](/cms_trial/space/SPM/2325217590/Strategic+Areas/) for the parent Strategic theme (only on the sub-Strategic and sub-Objective details pages).
- Access **More actions** (**…**):

  - Strategic theme details page:

    - [Close](/cms_trial/space/SPM/1918800058/Close+OKR/)
    - [Clone](/cms_trial/space/SPM/1918864386/Clone+OKR/)
    - Clear update history
    - [Delete](/cms_trial/space/SPM/1918408286/Delete+OKR/)
  - Objective details page:

    - Close
    - Clone
    - Clear update history
    - Delete
  - KR details page:

    - [Convert](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=spm&title=Convert%20KR&linkCreation=true&fromPageId=1918536390) to manual KR/ Convert to auto KR
    - Clone
    - Clear update history
    - Close
    - Delete

| Strategic Theme details page. | Objective details page. | Key Result details page. |

## Access the OKR details page

You can access the **OKR details page** through the:

- [OKR details side panel](/cms_trial/space/SPM/1918865686/OKR+Details+side+panel/)
- OKR key link

### OKR details side panel

The OKR details side panel must be enabled in the [OKR Overview settings](https://appfire.atlassian.net/wiki/spaces/SPM/pages/1918408551).

1. On the *OKR Overview* page, select the OKR you want to inspect.
2. In the *OKR details side panel*, click the **More actions** (**…**) button.
3. Select **Details** from the dropdown.

![OKR details side panel. The additional menu is opened.](/cms_trial/assets/f2867e7a-d4d9-431b-87be-4b4b0a83243c.png)

### OKR key link

The OKR key link can be found next to the OKR, wherever the OKR key is mentioned, including:

- [OKR Overview](/cms_trial/space/SPM/1918834317/OKR+Overview/)
- [OKR Hierarchy](/cms_trial/space/SPM/1918669889/OKR+Hierarchy/)
- [Progress Dashboard](https://appfire.atlassian.net/wiki/spaces/SPM/pages/1918801225)
- [Tree view page](/cms_trial/space/SPM/1918801711/Tree+view/)
- OKR details side panel.

Similar to the Jira work item key link, the OKR key link is unique and opens the details page for the selected OKR.

![OKR key link on the progress dashboard page.](/cms_trial/assets/f173f23b-10d1-4f33-b77c-230f476a08b6.png)

## OKR details page sections

Below, you can find a quick guide through the main sections, helping you understand how to use them to stay on top of your goals. Note the small difference between the Objective details page and the key result details page.

| **Section on the OKR details page** | **Description** |
| --- | --- |
| **Strategic theme/sub-theme** | **Objective/sub-objective** | **Key result** |

| Objective details page:   - This dropdown lets you add a parent Objective to the top-level Objective. Open a dropdown and select an Objective from the list. |
| sub-theme, sub-Objective, key result details pages:   - This dropdown lets you change the current parent Strategic theme or Objective of a key result or a sub-objective (depending on which OKR is being edited). Open a dropdown and select a Strategic theme or Objective from the list. |
| Progress | Progress | Progress | A line chart showing the progress of a Strategic theme/Objective/key result over time. |
| Info | Info | Info | Presents the details that were entered during the Strategic theme/Objective/ key result creation process. |
| Alignment | Alignment | Alignment | Strategic theme details page:   - This section consists of the following tabs that show:    - **Key results** - all KRs directly aligned to the current Strategic theme. You can also view basic [progress](https://appfire.atlassian.net/wiki/spaces/SPM/pages/1918834052) data for each KR, [update the KR's status](/cms_trial/space/SPM/1918865790/Update+OKR+status/) and [weight](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=spm&title=Add%20weight%20to%20OKR&linkCreation=true&fromPageId=1918536390), or [delete](/cms_trial/space/SPM/1918408286/Delete+OKR/) it.   - **Sub-themes and sub-objectives** - all sub-themes and sub-objectives are directly aligned to the current Strategic theme. It also shows basic progress data for each. It also shows basic progress data for each linked OKR.  There are two types of dependency links:      - **Blocks** -OKR A impedes the progress of OKR B.     - **Blocked by** - OKR B's progress is blocked by OKR A. Dependency links are bi-directional, meaning adding a link from OKR A to OKR B also creates a link from OKR B to OKR A. You can add and remove dependency links here.     - **Contributions** - all OKRs linked to the current one using a contribution link.  Two types of contribution links exist:        - **Supports** - OKR A contributes to the progress of OKR B.       - **Supported by** - OKR B's progress is supported by OKR A. Contribution links are bi-directional and show OKRs that support each other, even if they are not in a direct hierarchy. You can add and remove contribution links here. An Objective can contribute to another Objective or key result.       - **Copies** - displays Strategic themes that are copies of the current one. |

Two types of contribution links exist:      - **Supports** - OKR A contributes to the progress of OKR B.     - **Supported by** - OKR B's progress is supported by OKR A. Contribution links are bi-directional and show OKRs that support each other, even if they are not in a direct hierarchy. You can add and remove contribution links here. A key result can contribute to another key result or Objective.   - **Copies** - displays KRs that are copies of the current one. |
