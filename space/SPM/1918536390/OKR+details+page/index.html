OKR details page

7 min read

About this page

This page describes features that are supported only in BigPicture Advanced. These features are not available in BigPicture Standard.

The OKR details page refers to the page that displays data for the Objective, sub-objective, or key result, depending on which item you are viewing. On the OKR details page, you can:

  • Edit most of that data.

  • Lock the OKR (if OKR restriction is enabled).

  • Update OKR

  • Launch the Strategic Area for the parent Strategic theme (only on the sub-Strategic and sub-Objective details pages).

  • Access More actions (…):

    • Strategic theme details page:

      • Close

      • Clone

      • Clear update history

      • Delete

    • Objective details page:

      • Close

      • Clone

      • Clear update history

      • Delete

    • KR details page:

      • Convert to manual KR/ Convert to auto KR

      • Clone

      • Clear update history

      • Close

      • Delete

Access the OKR details page

You can access the OKR details page through the:

  • OKR details side panel

  • OKR key link

OKR details side panel

The OKR details side panel must be enabled in the OKR Overview settings.

  1. On the OKR Overview page, select the OKR you want to inspect.

  2. In the OKR details side panel, click the More actions (…) button.

  3. Select Details from the dropdown.

OKR key link

The OKR key link can be found next to the OKR, wherever the OKR key is mentioned, including:

  • OKR Overview

  • OKR Hierarchy

  • Progress Dashboard

  • Tree view page

  • OKR details side panel.

Similar to the Jira work item key link, the OKR key link is unique and opens the details page for the selected OKR.

Strategic theme details page:

  • This section consists of the following tabs that show:

    • Key results - all KRs directly aligned to the current Strategic theme. You can also view basic progress data for each KR, update the KR's status and weight, or delete it.

    • Sub-themes and sub-objectives - all sub-themes and sub-objectives are directly aligned to the current Strategic theme. It also shows basic progress data for each. You can also update a sub-theme’s or sub-objective’s status and weight, or delete it.

    • Dependencies - all OKRs linked to the current one with a dependency link. It also shows basic progress data for each linked OKR.
      There are two types of dependency links:

      • Blocks - OKR A impedes the progress of OKR B.

      • Blocked by - OKR B's progress is blocked by OKR A.
        Dependency links are bi-directional, meaning adding a link from OKR A to OKR B also creates a link from OKR B to OKR A. You can add and remove dependency links here.

      • Contributions - all OKRs linked to the current one using a contribution link.
        Two types of contribution links exist:

        • Supports - OKR A contributes to the progress of OKR B.

        • Supported by - OKR B's progress is supported by OKR A.
          Contribution links are bi-directional and show OKRs that support each other, even if they are not in a direct hierarchy. You can add and remove contribution links here.
          An Objective can contribute to another Objective or key result.

        • Copies - displays Strategic themes that are copies of the current one.

Objective details page:

  • This section consists of the following tabs that show:

    • Key results - all KRs directly aligned to the current Objective. You can also view basic progress data for each KR, update the KR's status and weight, or delete it.

    • Sub-objectives – all sub-objectives directly aligned to the current Objective. It also shows basic progress data for each. You can also update a sub-objective’s status and weight, or delete it.

    • Dependencies - all OKRs linked to the current one with a dependency link. It also shows basic progress data for each linked OKR.
      There are two types of dependency links:

      • Blocks - OKR A impedes the progress of OKR B.

      • Blocked by - OKR B's progress is blocked by OKR A.
        Dependency links are bi-directional, meaning adding a link from OKR A to OKR B also creates a link from OKR B to OKR A. You can add and remove dependency links here.
        An Objective can have a dependency only on a key result.

    • Contributions - all OKRs linked to the current one using a contribution link.
      Two types of contribution links exist:

      • Supports - OKR A contributes to the progress of OKR B.

      • Supported by - OKR B's progress is supported by OKR A.
        Contribution links are bi-directional and show OKRs that support each other, even if they are not in a direct hierarchy. You can add and remove contribution links here.
        An Objective can contribute to another Objective or key result.

    • Copies - displays the Objectives that are copies of the current one.

Key result details page:

  • This section consists of the following tabs that show:

    • Dependencies - all OKRs that are linked to the current one with a dependency link. It also shows basic progress data for each linked OKR.
      There are two types of dependency links:

      • Blocks - OKR A impedes the progress of OKR B.

      • Blocked by - OKR B's progress is blocked by OKR A.
        Dependency links are bi-directional, meaning adding a link from OKR A to OKR B also creates a link from OKR B to OKR A. You can add and remove dependency links here.
        A key result can have a dependency link only with the Objectives.

    • Contributions - all OKRs that are linked to the current one using a contribution link.
      Two types of contribution links exist:

      • Supports - OKR A contributes to the progress of OKR B.

      • Supported by - OKR B's progress is supported by OKR A.
        Contribution links are bi-directional and show OKRs that support each other, even if they are not in a direct hierarchy. You can add and remove contribution links here.
        A key result can contribute to another key result or Objective.

    • Copies - displays KRs that are copies of the current one.

  • This section shows all Jira work items and boxes linked to the KR that contribute to achieving your KR. You can edit linked work items here.

Strategic theme details page:

  • This section lists the latest Strategic theme updates for each day. You can view, add, and delete your own update comments here.

Objective details page:

  • This section lists the latest Objective updates for each day. You can view, add, and delete your own update comments here.

Key result details page:

  • This section lists the latest key result updates for each day, including the updates on the auto-KRs. You can view, add, and delete your own update comments here.
