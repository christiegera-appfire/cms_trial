OKR details page

Updated 7 days ago · 6 min read

About this page

This page describes features that are supported only in BigPicture Advanced. These features are not available in BigPicture Standard.

The OKR details page displays data for the Strategic theme, Objective, or Key Result, depending on which item you are viewing. On the OKR details page, you can:

  • Carry out all actions throughout the OKR lifecycle (such as create, close, delete, link, and more)

  • Launch the Strategic Area (only on the Strategic theme details page)

  • Restrict OKR

  • The scope of your actions on this page depends on your role/granted permissions.

  • Visit the Edit OKRs page to learn more about editing details on the OKR Details page.

Access the OKR details page

You can access the OKR details page through the:

OKR details side panel

  1. On the OKR details side panel, click the More actions (…) button.

  2. Select Details from the dropdown.

OKR key link

Similar to the Jira work item key link, the OKR key link is unique and opens the details page for the selected OKR.

OKR details page

Below, you can find a quick guide through the main sections and tabs, helping you understand how to use them to stay on top of your goals.

OKR key, status, name, and description

1. Breadcrumbs

Use the breadcrumbs section to:

  • View the current OKR hierarchy.

  • Navigate back to the Overview page.

  • Add or update the parent OKR.

2. OKR name and description

View and edit the OKR name and description inline. You cannot change the name and description of a closed OKR.

3. Manage OKR

The buttons let you perform actions related to the OKR you're currently viewing.

  • Update progress for manual OKRs and the status of auto/manual OKRs.

  • Restrict the OKR.

  • Launch Strategic Areas (Strategic themes only).

  • Convert, close, clone, and delete the selected OKR.

  • Clear update history.

Details

The Details section displays all OKR attributes for the selected OKR, including custom fields.

You can edit all fields inline except Last updated. If the item you are viewing is a Strategic theme, you cannot edit its Type.

Progress (tab)

The Progress tab displays details about the selected OKR and its progress.

1. Progress chart

The progress line chart visualizes the actual OKR progress and calculated expected progress based on the elapsed period. It also maps OKR milestones on the timeline.

2. Child statuses/ KR values

If you are viewing a Strategic theme or Objective, the chart displays status tags you can click to filter and view child items with that specific status (a list opens in the Child OKRs tab). If a Strategic theme or Objective is in manual mode, it displays the mode type instead.

If the OKR you are viewing is a Key Result, the chart displays Start, Current, and Target values.

3. Milestones

The Milestones section tracks OKR milestones.

In this section, you can:

  • Add, edit, and delete milestones.

  • Review the health of milestones.

  • Filter milestones by the Upcoming, Achieved, Missed statuses.

  • Sort milestones by Due date, Name, or Status.

Learn more about OKR milestones.

4. Activity

The Activity section tracks all manual and automated status and progress updates of the OKR.

In this section, you can:

  • View and add updates.

  • View and leave comments.

  • Filter activities by All updates and Manual updates. (see: Update OKR)

  • Pin activities.

  • Edit and delete activities.

Child OKRs (tab)

The Child OKRs tab is available only for Strategic themes and Objectives. It displays all direct child items for the selected OKR.

In this tab, you can:

  • Review key details of child OKRs.

  • Filter the list of child OKRs by the status and OKR type.

  • Hide closed OKRs.

  • Add a new OKR.

Linked work (tab)

The Linked work tab displays all work items and boxes connected directly to the Key Result (KR). For Strategic Themes or Objectives, the tab aggregates all work items linked to their child KRs.

1. Jira work items

The Jira work items section lists up to 50 Jira work items associated with this OKR, including those linked directly or aggregated through child KRs.

In this section, you can:

  • Review the status and progress of the linked Jira work items without switching to Jira or other BigPicture modules.

  • Click the Jira key to view the full work item details in Jira.

  • Filter linked work items by their Jira status category (To do, In progress, and Done).

  • Sort linked work items (A-Z/ Z-A).

  • Link and unlink work items (only at the KR level).

  • Refresh the list.

2. BigPicture boxes

The BigPicture boxes section lists all boxes associated with this OKR, including those linked directly or aggregated through child KRs.

In this section, you can:

  • Review the status and progress of the linked boxes without switching to other BigPicture modules.

  • Click the BigPicture key to open a box in the default module.

  • Filter linked boxes by their box status (To do, In progress, and Done).

  • Sort linked boxes (A-Z/ Z-A).

  • Link and unlink boxes (only at the KR level).

  • Refresh the list.

3. External links

The External links section lists links to external sources relevant to the current OKR. For example, strategic plans, designs, spreadsheets, etc.

In this section, you can:

  • Add, edit, open, and delete links.

  • Refresh the list.

Linked OKRs (tab)

The Linked OKRs tab lists OKR dependencies, contributions, and copies of the OKR you're currently viewing.

Dependency and contribution links do not affect OKR progress.

1. Dependencies

The Dependencies section lists all OKRs linked to the current one via a dependency link. This section also shows the status, progress, and owner of each linked OKR.

There are two types of dependency links:

  • blocks - OKR A blocks OKR B's progress.

  • blocked by - OKR A's progress is blocked by OKR B.

Dependency links are bi-directional, meaning adding a link from OKR A to OKR B also creates a link from OKR B to OKR A. You can add dependencies between cloned OKRs and OKRs in a different box.

In this section, you can:

  • Add and remove dependency links.

  • Sort listed OKRs.

2. Contributions

The Contributions section lists all OKRs that contribute to—or receive contributions from—the OKR you are currently viewing.
Two types of contribution links exist.

There are two types of contribution links:

  • supports - OKR A contributes to OKR B's progress.

  • supported by - OKR B supports OKR A's progress.

Contribution links are bi-directional and show OKRs that support each other, even if they are not in a direct hierarchy or even in the same box. Each child OKR automatically contributes to its direct OKR parent.

In this section, you can:

  • Add and remove contribution links.

  • Sort listed OKRs.

3. Copies

View the copies (clones) of the OKR you are currently viewing.
