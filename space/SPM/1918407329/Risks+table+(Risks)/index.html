Risks table (Risks)

2 min read

About this page

This page describes the Risks module, which is available only for legacy customers. For new implementations of BigPicture, use the Risk Management module instead.

Risks table (old navigation)

Click to expand the guide

Switch to the table view

To switch to the table view:

  1. Click the Table button at the top.

Add fields as columns

To customize the table:

  1. Click the Manage columns button.

  2. Find fields you want to add as columns.

A box admin sets the default column view. Box editors and viewers can modify the columns visible to them and restore the column view to the one set by a box admin.

Use drag and drop to change the column order. Click the wrench icon to adjust the display options.

The video presents how to customize the column view.

Sort risks

Click the column header to sort the items in ascending or descending order. See more about sorting on the Sorting page.

Inline edit and delete risks

You can inline edit and delete risks. See more on the Edit and delete risks page.

Compact mode

Make the cards more compact to fit more information on the screen.

Displayed Information

In Compact mode, you can adjust the add/remove columns as needed.
