# Risks table (Risks)

**About this page**

This page describes the Risks module, which is available only for legacy customers. For new implementations of BigPicture, use the [**Risk Management**](/cms_trial/space/SPM/1918798201/Risk+management+module+(new+module)/) module instead.

## Risks table (old navigation)

Click to expand the guide

## Switch to the table view

To switch to the table view:

1. Click the **Table** button at the top.

![Screenshot of the table view in the Risks module.](/cms_trial/assets/1eaf4c33-f581-462a-a5c5-3664bf2a6daa.png)

## Add fields as columns

To customize the table:

1. Click the **Manage columns** button.
2. Find fields you want to add as columns.

A box admin sets the default column view. Box editors and viewers can modify the columns visible to them and restore the column view to the one set by a box admin.

![Screenshot of adding a new column to the Risks module.](/cms_trial/assets/6efc613a-51bf-4366-afec-3ac4d18f8381.png)

Use drag and drop to change the column order. Click the wrench icon to adjust the display options.

The video presents how to customize the column view.

## Sort risks

Click the column header to sort the items in ascending or descending order. See more about sorting on [the Sorting page](/cms_trial/space/SPM/1918833145/Sort/).

![Screenshot of sortng tasks in the Risks module.](/cms_trial/assets/4d4b8ecb-8d46-491b-852b-ae945fc5d832.png)

## Inline edit and delete risks

You can inline edit and delete risks. See more on [the Edit and delete risks page](/cms_trial/space/SPM/1918669632/Edit+and+delete+risks/).
