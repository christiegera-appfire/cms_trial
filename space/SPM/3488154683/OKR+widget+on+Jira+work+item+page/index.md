# OKR widget on Jira work item page

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

The OKR widget on the Jira work item details screen provides a direct view into the OKRs the work item is linked to. The widget displays a snippet of the OKR hierarchy of the associated KRs with the following information:

- KR’s direct parent
- KR status
- OKR Owner (for an Objective and Key Result)
- OKR period
- OKR progress (for an Objective and Key Result)
- OKR key (for an Objective and Key Result); click it to open the [OKR details page](/cms_trial/space/SPM/1918536390/OKR+details+page/)

## Security and access

The OKR widget is enabled by default for all Jira projects. The widget respects [OKR permissions](/cms_trial/space/SPM/1918765815/OKR+module+permissions/); a user will see only those linked OKRs they are permitted to view.

## View OKR widget

The OKR widget is located on the right-hand side panel of the Jira work item details issue screen. At the top of the widget, the total number of KRs linked to the work item is displayed.

![OKR widget on the Jira work item details screen.](/cms_trial/assets/2bd80eec-c615-4d2e-85b8-55966248b920.png)

If the work item is not linked to any KR, the widget displays a **Not linked to any Key Result** splash screen.
