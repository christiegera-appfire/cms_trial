# None (aggregations only)

## None (aggregations only) (old navigation)

## About the non-scope type

When the scope definition of the box type is set to **none (aggregations only)**, the box scope can’t be defined (it doesn’t exist in the box configuration), as the scope is based strictly on all sub-boxes. You will not see any task in any of the modules because such a scope type can only aggregate data - there is no need to add any tasks to the scope.

Boxes with **none** scope definition show the aggregated status and time-tracking reports in the Hierarchy mode of the Overview module.

The **Scope definition** tab is hidden (can't be accessed in Box configuration > Tasks).

![image-20240213-135243.png](/cms_trial/assets/5440090e-9ad5-492c-9607-fd8a04120b88.png)

Box configuration refers to the settings of a single, individual box. They are dependent on the box type settings. See the [Scope types](/cms_trial/space/SPM/1918766536/Scope+types/) page for more information.
