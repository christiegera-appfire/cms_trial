# Assign skills to tasks

## Skill widget

If the Skill widget is enabled on the **App Configuration** > **Widgets** > **Skill widget** page, you can add skills to a task directly on the Jira issue page.

![A screenshot of the Jira issue page featuring Skill widget.](/cms_trial/assets/1e506f42-04bc-495d-a59b-9f775bbcd1ae.png)

## Jira label

When the **Required Skills** BigPicture field is synchronized with the **Labels** field in Jira, you can:

- Execute bulk changes to assign and remove skills from multiple issues simultaneously.
- Search for tasks with specific skills.
- Automate skill assignments with third-party add-ons such as Script Runner and Adaptavist.
