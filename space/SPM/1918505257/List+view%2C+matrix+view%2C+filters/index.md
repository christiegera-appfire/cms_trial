# List view, matrix view, filters

[Excerpt "app\_editions\_advanced\_page" from page "Get started" not found]

In the Priorities module, you can display your priorities in two ways.

- **List view (table view)** - elements and metrics are displayed in a structured list format.
- **Matrix view** - elements are plotted visually based on customizable metrics like impact or reach.

You can also review the history of prioritization for a selected element and apply [filters](/cms_trial/space/SPM/1918539227/Filter+and+search+priorities/).
