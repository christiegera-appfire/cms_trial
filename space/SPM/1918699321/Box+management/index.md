# Box management

## Actions on boxes

The list of actions you can carry out in relation to boxes.

| **Action** | **Description** |
| --- | --- |
| [Create](/cms_trial/space/SPM/1918406376/Create+box/) | Create a new box based on the [box type](/cms_trial/space/SPM/1918830000/Box+types/). Before you add a new box to the box structure, check whether it will be accepted by the target parent box (for example, a program or portfolio box). |
| [Duplicate](/cms_trial/space/SPM/1918635048/Duplicate+box+and+box+scope/) | Duplicate the existing box to create a new one. Only some of the box settings are duplicated; the box scope must be duplicated separately. |
| [Edit](/cms_trial/space/SPM/1918635162/Edit+box+details+(name%2C+start%2Fend+dates)/) | Edit the box name and start/end dates. Changes in the box start/end date trigger a validation check. |
| [Move](/cms_trial/space/SPM/1918406916/Move+box+in+box+hierarchy/) | Move a project box and place it under another one. This action changes the box’s position in the hierarchy and gives it a new parent. |
| [Archive](/cms_trial/space/SPM/1918634657/Archive+box/) | Archive a box when it’s no longer needed. Archives boxes are hidden and can be restored if needed. |
| [Delete](/cms_trial/space/SPM/1918635005/Delete+box/) | Deleting a box deletes box configuration but it does not delete the tasks in its scope. |
