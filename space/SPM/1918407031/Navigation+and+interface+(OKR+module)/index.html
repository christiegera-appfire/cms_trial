Navigation and interface (OKR module)

7 min read

About this page

This page describes features that are supported only in BigPicture Advanced. These features are not available in BigPicture Standard.

Navigation and interface - OKR module (old navigation)

Click to expand the guide

The OKR module interface is divided into three main pages (modes), each providing unique features to help you track and manage your OKRs for individual projects and the entire portfolio. The interface also houses individual module settings that are applicable only to the OKR module.

OKR module pages

The OKR module consists of several unique pages and a sidebar that lets you track and manage your OKRs in multiple ways. Those are:

  • Overview

  • Hierarchy

  • Progress Dashboard

In addition, there is a Tree view page that can be accessed from the Overview content menu or by clicking the OKR key.

Overview

The Overview is where you can carry out all the actions on the OKRs. It consists of two main elements:

  • Customizable column layout shows all OKRs linked to a box and their details, such as Name, Owner, Progress, Weight, and so on.

  • The OKR details side panel displays a set of details for the selected OKR.

Column layout

OKR column layout displays OKRs in a structured tabular format. Each column represents one type of data you can search or filter. You can customize the view by:

  • expanding or collapsing the OKRs

  • adding or removing selected columns from the layout

  • locking the individual columns

  • rearranging column order

  • sorting the OKRs by the column

In addition, you can manually change the order of the OKRs by moving them up/down on the column layout. New column layout views can be saved so that you and other users can apply them anytime they need them.

OKR details side panel

With the OKR details side panel, you can:

  • See basic OKR details

  • See OKR progress

  • See, comment, and reply to OKR updates

  • Update an OKR

  • Access a dropdown menu to:

  • Open a Strategic Area (if the selected OKR is a Strategic Theme, or a sub-Strategic Theme, or a sub-Objective that belongs to a Strategic Theme)

    • Open the OKR details page

    • Add a sub-Strategic Theme (if the selected OKR is a Strategic Theme)

    • Add a sub-objective (if the selected OKR is a Strategic Theme, sub-Strategic Theme, Objective, or sub-objective)

    • Add Key Result (if the selected OKR is a Strategic Theme, sub-Strategic Theme, Objective, or sub-objective)

    • Edit linked issues (if the selected OKR is the Key Result)

    • Edit linked boxes (if the selected OKR is the Key Result)

    • Create a new issue (if the selected OKR is the Key Result)

    • Clone OKR

    • Open the Tree view page

    • Delete OKR

All of these actions and more can also be executed on the OKR details page.

Context menu

Open a context menu by clicking More actions (…) next to the chosen OKR. The “triple dots” are always visible for the Objectives; they become visible for Key Results only when you mouse over the Key Result.

Overview settings

The Overview settings provide additional options for the Overview page:

  • Detail panel settings (Personal)

  • Export

  • Import

Hierarchy

The Hierarchy visualizes goals like a family tree.

It shows how big, ambitious goals (like the company vision) are broken down into smaller, actionable steps for different teams. This view helps everyone understand how their work fits into the bigger picture.

You can zoom in or out of the view, collapse or expand sub-item cards, and filter the view.

Progress Dashboard

The Progress Dashboard provides a clear, visual overview of your OKRs. It visualizes team progress, successes, and areas for improvement as pie charts, bar charts, and lists.

Data displayed on this page can only be viewed. If you want to update a status or review an OKR, go to the Overview page or visit the OKR details page for the individual OKR.

Tree view

On the Tree view page, you can see all the OKRs you created in a single session. This is the page you land on when you finish creating a Strategic Theme, Objective, or Key Result. You can review the details of the OKR you created, add more sub-items, and create a top-level Objective (for any OKR but Strategic Theme).

When you are done creating your OKRs, you can revisit this page and continue building the structure for the selected OKR.

OKR details page

The OKR details page refers to the pages that display data for the Strategic Theme, sub-Strategic Theme, Objective, sub-objective, or Key Result, depending on which item you are viewing.

You can edit most of that data on the respective OKR page.

Search bars and filters

OKR search bars filters can be found on all three OKR pages: Overview, Hierarchy, and Progress Dashboard. When you apply a period from the period selector or filter the view, these settings will be shared across all three pages.

The Overview page has additional search bars on selected columns, but the column settings do not affect the Hierarchy and Progress Dashboard pages.

Saved views (view switcher)

You can switch between the default and saved views using the view switcher. The view switcher houses a search bar, a list of all saved views, and a list of favorite saved views. Each view can be contextually deleted, edited, shared, and starred (added to favorites).

Link to box

The Link to box button (Overview, Hierarchy, Progress Dashboard pages) lets you link any OKR to your box, even if it was originally created by somebody else in another box.

Strategic Areas

Strategic Areas display aggregated data for a selected Strategic Theme. The data aggregated is displayed on charts and in columns and is divided into the following tabs:

  • OKRs (shows aggregated data for all the OKRs associated with a selected Strategic Theme)

  • Initiatives (shows aggregated data for all the boxes associated with KRs that belong to the selected Strategic Theme)
