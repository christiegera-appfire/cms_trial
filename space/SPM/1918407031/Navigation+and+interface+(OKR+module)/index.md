# Navigation and interface (OKR module)

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

## Navigation and interface - OKR module (old navigation)

Click to expand the guide

The OKR module interface is divided into three main pages (modes), each providing unique features to help you track and manage your OKRs for individual projects and the entire portfolio. The interface also houses individual [module settings](/cms_trial/space/SPM/1918797926/OKR+Settings/) that are applicable only to the OKR module.

## OKR module pages

The OKR module consists of several unique pages and a sidebar that lets you track and manage your OKRs in multiple ways. Those are:

- Overview
- Hierarchy
- Progress Dashboard

In addition, there is a Tree view page that can be accessed from the Overview content menu or by clicking the OKR key.

### Overview

The [Overview](/cms_trial/space/SPM/1918834317/OKR+Overview/) is where you can carry out all the [actions on the OKRs](/cms_trial/space/SPM/1918863610/OKR+lifecycle+and+management/). It consists of two main elements:

- Customizable column layout shows all OKRs [linked to a box](/cms_trial/space/SPM/1918834116/Link+OKR+to+box/) and their details, such as Name, Owner, Progress, Weight, and so on.
- The OKR details side panel displays a set of details for the selected OKR.

#### Column layout

![OKR column layout with options.](/cms_trial/assets/5675bf8f-7ad4-4dd4-bf75-49e45a754ef4.png)

OKR [column layout](https://appfire.atlassian.net/wiki/spaces/SPM/pages/1918835243) displays OKRs in a structured tabular format. Each column represents one type of data you can search or filter. You can customize the view by:

- expanding or collapsing the OKRs
- adding or removing selected columns from the layout
- locking the individual columns
- rearranging column order
- sorting the OKRs by the column

In addition, you can manually change the order of the OKRs by [moving them up/down](/cms_trial/space/SPM/1918637466/Move+OKR/) on the column layout. New column layout [views can be saved](/cms_trial/space/SPM/1918637654/OKR+Filters%2C+search%2C+and+saved+views/) so that you and other users can apply them anytime they need them.

#### OKR details side panel

![okr-details-side-panel.png](/cms_trial/assets/abec6f46-4d77-4384-bb9f-a55dd47b1d3c.png)

With the [OKR details side panel](/cms_trial/space/SPM/1918865686/OKR+Details+side+panel/), you can:

- See basic OKR details
- See OKR progress
- See, [comment](/cms_trial/space/SPM/1918670327/Comment+OKR+update/), and reply to [OKR updates](/cms_trial/space/SPM/1918637972/Update+OKR/)
- Update an OKR
- Access a dropdown menu to:
- Open a [Strategic Area](/cms_trial/space/SPM/2325217590/Strategic+Areas/) (if the selected OKR is a Strategic Theme, or a sub-Strategic Theme, or a sub-Objective that belongs to a Strategic Theme)

  - Open the [OKR details page](/cms_trial/space/SPM/1918536390/OKR+details+page/)
  - Add a sub-Strategic Theme (if the selected OKR is a Strategic Theme)
  - Add a sub-objective (if the selected OKR is a Strategic Theme, sub-Strategic Theme, Objective, or sub-objective)
  - Add Key Result (if the selected OKR is a Strategic Theme, sub-Strategic Theme, Objective, or sub-objective)
  - [Edit linked issues](https://appfire.atlassian.net/wiki/spaces/SPM/pages/1918670410) (if the selected OKR is the Key Result)
  - [Edit linked boxes](/cms_trial/space/SPM/2229665803/Link+boxes+to+Key+Results/) (if the selected OKR is the Key Result)
  - Create a new issue (if the selected OKR is the Key Result)
  - [Clone OKR](/cms_trial/space/SPM/1918864386/Clone+OKR/)
  - Open the [Tree view](/cms_trial/space/SPM/1918801711/Tree+view/) page
  - [Delete OKR](/cms_trial/space/SPM/1918408286/Delete+OKR/)

All of these actions and more can also be executed on the OKR details page.

#### Context menu

![A context menu on the overview page in the okr module.](/cms_trial/assets/0a645379-4558-403e-af1b-cb590aea4ec7.png)

Open a context menu by clicking **More actions** (**…**) next to the chosen OKR. The “triple dots” are always visible for the Objectives; they become visible for Key Results only when you mouse over the Key Result.

#### Overview settings

![OKR Overview settings on the OKR Overview page in the OKR module.](/cms_trial/assets/02014f2f-290c-49c3-8dd6-7cc7d71d2bcc.png)

The [Overview settings](https://appfire.atlassian.net/wiki/spaces/SPM/pages/1918408551) provide additional options for the Overview page:

- Detail panel settings (Personal)
- Export
- Import

### Hierarchy

![Hierarchy page.](/cms_trial/assets/085eac54-f7c8-413e-afd4-1e5d11223f6c.png)

The [Hierarchy](/cms_trial/space/SPM/1918669889/OKR+Hierarchy/) visualizes goals like a family tree.

It shows how big, ambitious goals (like the company vision) are broken down into smaller, actionable steps for different teams. This view helps everyone understand how their work fits into the bigger picture.

You can zoom in or out of the view, collapse or expand sub-item cards, and filter the view.

### Progress Dashboard

![An overview of the Progress Dashboard page in the OKR module.](/cms_trial/assets/786fe744-decf-4e39-8d16-ff8c67a51794.png)

The [Progress Dashboard](/cms_trial/space/SPM/1918801225/Progress+Dashboard/) provides a clear, visual overview of your OKRs. It visualizes team progress, successes, and areas for improvement as pie charts, bar charts, and lists.

Data displayed on this page can only be viewed. If you want to update a status or review an OKR, go to the Overview page or visit the OKR details page for the individual OKR.

### Tree view

On the [Tree view](/cms_trial/space/SPM/1918801711/Tree+view/) page, you can see all the OKRs you created in a single session. This is the page you land on when you finish [creating a Strategic Theme](/cms_trial/space/SPM/2324726248/Create+OKR/), [Objective](https://appfire.atlassian.net/wiki/spaces/SPM/pages/1918702275), or [Key Result](https://appfire.atlassian.net/wiki/spaces/SPM/pages/1918538655). You can review the details of the OKR you created, add more sub-items, and create a top-level Objective (for any OKR but Strategic Theme).

When you are done creating your OKRs, you can revisit this page and continue building the structure for the selected OKR.

![Tree view page.](/cms_trial/assets/82537b40-52eb-4c0d-9bb1-e89c4e540251.png)

### OKR details page

The [OKR details page](/cms_trial/space/SPM/1918536390/OKR+details+page/) refers to the pages that display data for the Strategic Theme, sub-Strategic Theme, Objective, sub-objective, or Key Result, depending on which item you are viewing.

You can edit most of that data on the respective OKR page.

| **Strategic Theme details page** | **Objective details page** | **Key Result details page** |
| --- | --- | --- |
| Strategic Theme details page. | Objective details page. | Key Result details page. |

## Search bars and filters

OKR [search bars filters](/cms_trial/space/SPM/1918637654/OKR+Filters%2C+search%2C+and+saved+views/) can be found on all three OKR pages: Overview, Hierarchy, and Progress Dashboard. When you apply a period from the period selector or filter the view, these settings will be shared across all three pages.

The Overview page has additional search bars on selected columns, but the column settings do not affect the Hierarchy and Progress Dashboard pages.

## Saved views (view switcher)

![A list of saved views with options.](/cms_trial/assets/f0f58da9-6791-4d72-ace0-069cc6bc6712.png)

You can switch between the default and saved views using the view switcher. The view switcher houses a search bar, a list of all saved views, and a list of favorite saved views. Each view can be contextually deleted, edited, shared, and starred (added to favorites).

## Link to box

The [**Link to box**](/cms_trial/space/SPM/1918834116/Link+OKR+to+box/) button (Overview, Hierarchy, Progress Dashboard pages) lets you link any OKR to your box, even if it was originally created by somebody else in another box.

## Strategic Areas

[Strategic Areas](/cms_trial/space/SPM/2325217590/Strategic+Areas/) display aggregated data for a selected Strategic Theme. The data aggregated is displayed on charts and in columns and is divided into the following tabs:

- OKRs (shows aggregated data for all the OKRs associated with a selected Strategic Theme)
- Initiatives (shows aggregated data for all the boxes associated with KRs that belong to the selected Strategic Theme)
