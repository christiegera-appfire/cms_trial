Customize column views

4 min read

Customize column views (old navigation)

Click to expand the guide

Overview

To customize the column view means to:

  • make temporary changes to an existing view,

  • update an existing column view, 

  • create a new column view.

Column views can be customized on the respective modules pages in the box and box type configuration, but also directly in the following modules:

  • Overview module (Hierarchy and Timeline view modes. These two views are independent and are customized separately)

  • Scope module

  • Gantt module

  • App widget

  • WBS widget

In addition, you can customize but cannot save column views in the following:

  • Board module (Backlog section in the Infobar panel

  • Risks module (Table view)

  • Gantt gadget

Existing views

At the top, you can find a list of available views. 

You can freely switch between the views, as it won't affect other users.

Temporary changes to the current view

Any user can temporarily modify the current view.

When you make changes to the active (in-use) column view:

  • A red asterisk appears next to the column view name:

  • When you open the dropdown, you see the current view is modified warning:

Restore

To undo the temporary modifications, use the Restore option:

Edit existing views

To permanently update a column view:

  1. Select a view from the drop-down at the top (only an active view can be modified).

  2. Add/remove columns.

  3. Click the Save icon.

Create a new column view

Edit a current view and use the "save as" option to save it as a new column view.

Box configuration

Complete management of the column views, including deleting the views, can be done in the box configuration.

Reorder columns

Left-click on the column name (hold the button) and drag the column into a new position. 

Customize columns

Click the wrench icon next to a column name; an additional drop-down menu will appear. 

Customization options vary depending on the column.

Non-customizable columns:

  • Fav

  • Icon

  • ID

  • Name

  • Type

Custom column 

Go to box columns to create custom fields that you can use as columns in the Overview module to see the most critical information and metrics related to your Project, Portfolio, or any other type of box you want to manage.
