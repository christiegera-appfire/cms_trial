# Customize column views

## Customize column views (old navigation)

Click to expand the guide

## Overview

To customize the column view means to:

- make temporary changes to an existing view,
- update an existing column view,
- create a new column view.

Column views can be customized on the respective modules pages in the box and box type configuration, but also directly in the following modules:

- [Overview module](/cms_trial/space/SPM/1918700155/Column+view+(Overview+module)/) ([Hierarchy](/cms_trial/space/SPM/1918799130/Hierarchy+mode/) and [Timeline](/cms_trial/space/SPM/1918538282/Timeline+mode/) view modes. These two views are independent and are customized separately)
- Scope module
- [Gantt module](/cms_trial/space/SPM/1918668270/Column+view+(Gantt+and+Scope+modules)/)
- App widget
- WBS widget

In addition, you can customize but cannot save column views in the following:

- [Board module](/cms_trial/space/SPM/1918537147/Column+view+in+backlog+(Board+module)/) (**Backlog** section in the Infobar panel
- Risks module (**Table** view)
- Gantt gadget

![overview-display-mode.png](/cms_trial/assets/e2134945-5f9a-41dd-8775-2c88df818ed4.png)

## Existing views

At the top, you can find a list of available views.

![agile-view.png](/cms_trial/assets/8c986789-aaae-4fc3-ab20-ee7dd7eae27f.png)

You can freely switch between the views, as it won't affect other users.

## Temporary changes to the current view

Any user can temporarily modify the current view.

When you make changes to the active (in-use) column view:

- A red asterisk appears next to the column view name:

  ![agile-red-asterisk.png](/cms_trial/assets/738cb8da-f4b1-4512-8e13-0651e9d40702.png)
- When you open the dropdown, you see the **current view is modified**warning:

  ![current-view-is-modified.png](/cms_trial/assets/3781178c-43e2-4fb7-b287-c32fac0b5d8e.png)

### Restore

To undo the temporary modifications, use the **Restore**option:

![agile-restore.png](/cms_trial/assets/446158d4-1303-428a-aab6-304e6dc7f2d6.png)

## Edit existing views

To permanently update a column view:

1. Select a view from the drop-down at the top (only an active view can be modified).

   ![agile-time-tracking.png](/cms_trial/assets/ee6debf5-836c-4c40-8120-cf4dba64011b.png)
2. Add/remove columns.

   ![add-remove-column.png](/cms_trial/assets/6fd4fb1a-fab6-4a60-8dee-682c1e943dfa.png)
3. Click the **Save**icon.

   ![save-icon.png](/cms_trial/assets/d3cac305-1de9-4e81-8b94-8495e24754b9.png)

## **Create a new column view**

Edit a current view and use the "save as" option to save it as a new column view.

![save-as.png](/cms_trial/assets/4ec6ef91-d241-4810-baab-1bed3ffdadb5.png)![save-current-view-as.png](/cms_trial/assets/61029622-9661-408a-82e7-d7041ae98995.png)

## Box configuration

Complete management of the column views, including deleting the views, can be done in the [box configuration](/cms_trial/space/SPM/1918503715/Manage+column+views/).

![manage-column-view.png](/cms_trial/assets/eb061571-2ded-49af-b373-e0e027dd5918.png)

## **Reorder columns**

Left-click on the column name (hold the button) and drag the column into a new position.

![reorder-columns.mp4](/cms_trial/assets/f4a9e64c-8dd7-4375-af0e-118f325fe092.mp4)

## **Customize columns**

Click the **wrench icon** next to a column name; an additional drop-down menu will appear.

Customization options vary depending on the column.

![aggregation-none.png](/cms_trial/assets/1105612f-fb4c-4e3b-b560-346da0129271.png)![agreggation-sum.png](/cms_trial/assets/bcebc984-01b5-4bef-b8c5-7d18ec778ab5.png)

**Non-customizable columns:**

- Fav
- Icon
- ID
- Name
- Type

## **Custom column**

Go to [box columns](/cms_trial/space/SPM/1918406508/Custom+box+columns/) to create custom fields that you can use as columns in the Overview module to see the most critical information and metrics related to your Project, Portfolio, or any other type of box you want to manage.

To undo the temporary modifications, use the **Restore**option.

To permanently update a column view:

1. Select a view from the drop-down at the top (only an active view can be modified).
2. Add/remove columns.
3. Click the **Save**icon.

Click the **Customize column (…)** next to a column name; an additional drop-down menu will appear. Customization options vary by column.
