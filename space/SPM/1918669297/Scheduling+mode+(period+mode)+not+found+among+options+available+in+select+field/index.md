# Scheduling mode (period mode) not found among options available in select field

![contentId-1918669297](/cms_trial/assets/8e50b999-d17c-4e2a-b9df-36a484f429f6.png)

Verify the settings of the **task mode** **custom field** (Jira Admin permissions needed).

1. Go to **Jira Administration**> **Issues**

   ![contentId-1918669297](/cms_trial/assets/2036264d-1d34-409e-af53-f345e08e4286.png)
2. Select **Custom fields**on the left.

   ![contentId-1918669297](/cms_trial/assets/1344c160-ebaf-4ed7-b7f7-d7d1424bf654.png)
3. Find the **task mode** field

   ![image2023-2-2_11-41-51.png](/cms_trial/assets/dd01b147-5da9-436d-b26d-f9bdb0562385.png)
4. Go to **Actions**> **Configure**

   ![contentId-1918669297](/cms_trial/assets/efafb765-b4bd-40b8-96d4-9d2a79fddb73.png)
5. Verify the following settings

   1. Go to **Edit** **Options**

      ![contentId-1918669297](/cms_trial/assets/b1906f41-078c-4d23-a3c9-bf72ce149004.png)

      make sure all four **period modes** are listed and enabled.

      ![contentId-1918669297](/cms_trial/assets/b63aa38e-fd7f-4070-bb5d-d18541d5b50e.png)
   2. Change applicable contexts for the scheme.

      ![contentId-1918669297](/cms_trial/assets/684572e9-559a-4482-9b73-74bbf5096030.png)

      Ensure the fields are available for **all issue types** and the **context is global.**

      ![contentId-1918669297](/cms_trial/assets/ced0d741-8869-4962-8ecd-99d63212bb1a.png)
