# Baseline start/end date fields

This field determines the start/end position of the task's baseline on the timeline. The following field types can be synchronized:

- Date Picker
- Date Time Picker

The **Date Time Picker** fields are only available on Jira server versions.

Disabling synchronization with Jira is possible by selecting the '--Not Synchronized--' option.

By default, the Baseline start/end date custom fields are selected. These fields are created during the App installation.
