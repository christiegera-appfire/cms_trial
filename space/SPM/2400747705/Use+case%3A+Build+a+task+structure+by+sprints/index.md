# Use case: Build a task structure by sprints

|  |  |
| --- | --- |
| **Goal** | **Structure and visualize work within BigPicture according to Jira sprints.**  Organize and manage project tasks by sprints in BigPicture, align work with Agile delivery cycles, and improve sprint planning, tracking, and visibility. |
| **Scenario** | A project manager coordinates several development teams working on a shared product. They want to improve planning and execution, so they structure tasks by sprints in BigPicture. Each sprint presents Jira work items and allows the project manager to organize work with Agile delivery cycles. With such a structure, they can assign tasks to sprints, track progress, and manage dependencies without leaving BigPicture. |
| **Key benefits** | - **Agile alignment** - structure tasks according to Agile sprints to support consistent delivery and sprint planning. - **Better visibility** - get a high-level view of progress across multiple sprints and teams in one place. - **Improved sprint planning** - sprint-based task structure provides a clear overview of each sprint's scope and supports more effective planning. |

## Preconditions

Role You need at least a Box Admin role to manage the box configuration.

box The box needs to be populated with a Jira space.

Jira sprints You need to have sprints defined in Jira. You can’t create Jira sprints directly in BigPicture.

## Build a task structure by sprints step-by-step

1. Go to **box configuration** > **Tasks** > **Task structure**.
2. Expand **Advanced Configuration**.
3. Disable currently active structure builders.
4. Enable **Jira Sprint** and **Sub-tasks**. This way, you’ll see your Jira sprints and assigned tasks to these sprints.
5. Click **Save**.
6. Once saved, sprints are added as task types on the **box configuration** > **Tasks** > **Scope definition** page.
7. The changes are immediately reflected on the Gantt chart, and Jira sprints are visible as [basic tasks](/cms_trial/space/SPM/1918405930/Basic+tasks+%2F+BigPicture+tasks/).

**Tip:**

- Click the **Key** link on the Gantt’s task list to be redirected to a selected sprint in Jira.
- You can move tasks between sprints in BigPicture. All changes are instantly reflected in Jira.

- Tasks are successfully organized by sprints in BigPicture.
- A project manager gains a clear view of planned work aligned with each Jira sprint.
- A project manager can monitor sprint progress, adjust plans, and move tasks between sprints in BigPicture as needed. All changes are instantly reflected in Jira.
