## About the dark mode

Dark mode primarily uses dim, dark, and gray color schemes for its elements that reflect less light, which minimizes screen glare. In dim environments, turning on dark mode can help you alleviate eye strain caused by bright displays.

![A view of the box contents with the dark theme turned on.](/cms_trial/assets/6b6de40b-a3de-4e7b-a0f9-345caad3c060.png)

## Change the color theme

When you enable dark mode on your Jira cloud instance, it will automatically activate for the app.

1. Navigate to **Your profile and settings**
2. From the dropdown menu, select **Theme**.
3. Activate one of the three color modes: **Light**, **Dark**, or **Match** **browser**.

![Accessing dark mode on the cloud instance.](/cms_trial/assets/b13286e0-7570-45c2-a90a-a70c82733bcf.png)
