# Keyboard shortcuts (Scope module)

## Keyboard shortcuts - Scope module (old navigation)

Click to expand the guide

## Display available keyboard shortcuts

Click the **Get help** ( **i** )button in the upper-right corner menu (or press **Shift + /**) to display the keyboard shortcuts dialog box.

![Menu under the Get help button.](/cms_trial/assets/568730fb-c6c6-4921-ae98-8c11cbe62929.png)

## Scope module shortcuts

The shortcuts listed in the box will only show the shortcuts applicable to the module you are viewing. The app will adjust the displayed shortcuts to your device system (Mac and Windows). Also, depending on your Windows hardware, you may need to use the **Fn** button in place for **Ctrl**.

The Scope module’s keyboard shortcuts are divided into the following categories:

![A list of keyboard shortcuts in the Gantt module.](/cms_trial/assets/af7768f3-3ee9-4ecb-9ce0-30a0725d4f4e.png)

### Navigation

A set of general navigation shortcuts.

|  |  |
| --- | --- |
| Select box | Mouse **left-click** |
| Select work item | Mouse **left-click** |
| Remove selection | **Esc** |
| Context menu | Mouse **right-click** |
| Item navigation | **↑** / **↓** |
| Collapse/ Expand a task | **←** / **→** |

### Item actions

Those shortcuts speed up task-related actions directly on the task tree.

| New item | **Enter** |
| --- | --- |
| New sub-item | **Shift** + **Enter** |
| Create a basic task | **Crl** or **Cmd** + **Enter** |
| Create a basic subtask | **Crl** or **Cmd** + **Shift** + **Enter** |
| Move a task up | **Shift** + **↑** |
| Move a task down | **Shift** + **↓** |
| Indent a task | **Shift** + **→** |
| Outdent a task | **Shift** + **←** |
| Move a task to the top | **Crl** or **Cmd** + **Shift** + ↑ |
| Move a task to the bottom | **Crl** or **Cmd** + **Shift** + **↓** |
| Edit task details | **E** |

### View

| Show or hide task details | **]** |
| --- | --- |

### Layout

Change the row height of the layout.

| Compact | **Shift** + **C** |
| --- | --- |
| Regular | **Shift** + **R** |
| Wide | **Shift** + **W** |

### Others

| Show/Hide menu | **Z** |
| --- | --- |
| Undo (only on Jira Cloud) | **Ctrl** or **Cmd** + **Z** |
| Open the System-info dialog box | **Shift** + **I** |
| Play the BigPicture game | **Shift** + **Ctrl** or **Cmd** + **G** |
| Re-synchronize data | **Alt** or **Option** + **R** |
