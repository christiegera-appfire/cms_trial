# Archived boxes

## Archived boxes (old navigation)

Click to expand the guide

When a box is no longer being used, it can be archived.

[Archive a box](/cms_trial/space/SPM/1918634657/Archive+box/) if there are many boxes in the app that are no longer being used—it might significantly improve the app's performance.

By default, an archived box is **hidden** in the Overview module, making it easier to manage your current work without it getting in the way.

## Synchronization and scheduling of tasks in archived boxes

|  | **The task is only in the archived boxes** **(all boxes that contain the task are archived)** | **Task is in at least one archived box** |
| --- | --- | --- |
| Synchronization | The task is NOT synchronized | Task is synchronized |
| Scheduling | Scheduling block → The task period is unaffected by scheduling rules | The task period adjusts according to scheduling rules |

## Restore an archived box

Boxes have to be restored manually in the [Overview module](/cms_trial/space/SPM/1918502655/Overview+module/):

- Once you restore an archived box, all its sub-boxes are restored, and the aggregations are recalculated.
- On the Overview module, you can't restore boxes if their parent box is still archived. The **Restore** button is disabled.

![Restoring option in the box configuration](/cms_trial/assets/25826765-ddda-4630-9c4a-63069c89b53f.png)![Confirmation message for restoration](/cms_trial/assets/e900e35c-8267-4c5d-b80f-754891509390.png)

## Archived box limitations

- Once a box is archived, the aggregations can no longer be calculated, and the box will no longer contain valuable business information.
- If a task belongs only to **archived** or **closed boxes**, then that task has a **scheduling block** applied to it.
- Box configuration cannot be accessed, box attributes cannot be edited, and inline editing of box column values is disabled.

![Archived box in the box list](/cms_trial/assets/62ef19d1-a36d-40f8-beb4-60ee8722e9b3.png)

## Restore an archived box

Boxes have to be restored manually in the [Overview module](/cms_trial/space/SPM/1918502655/Overview+module/). Click **More actions** (**…**) next to the box you want to restore, and select the **Restore** option from the dropdown menu.

![Restore options on the dropdown menu under More actions.](/cms_trial/assets/1e32ce39-50d9-4c7b-9565-9c5b3b137593.png)

- Once you restore an archived box, all its sub-boxes are restored, and the aggregations are recalculated.

![Confirmation message for box restoration.](/cms_trial/assets/e900e35c-8267-4c5d-b80f-754891509390.png)

- In the Overview module, you can't restore boxes if their parent box is still archived. The **Restore** button is disabled.

- Once a box is archived, the aggregations can no longer be calculated, and the box will no longer contain valuable business information.
- If a task belongs only to **archived** or **closed boxes**, it has a scheduling block applied to it.
- Box configuration cannot be accessed, box attributes cannot be edited, and inline editing of box column values is disabled.
