# Data residency, collection, and analytics overview

## Purpose of data collection

We collect analytics to enhance our product performance, ensure operational stability, and improve user experience. Our data collection is governed by the End User License Agreement (<https://appfire.com/eula>) section 16, which allows us to compile statistical insights while ensuring customer anonymity.

## Data collection components

We utilize the following third-party services for analytics and operational monitoring:

**Amplitude**: Provides insights into feature usage and user flows, enabling us to improve the overall user experience.

**Fingerprint**: Supports analytics structuring, ensuring better data organization.

**Datadog**: Monitors key operational performance metrics, ensuring system stability and rapid issue detection.

## Data sources and transmission

| **Component** |  |  |
| --- | --- | --- |
| Amplitude | Feature usage, user flows | Amplitude Servers |
| Fingerprint | Device identifiers | Fingerprint Servers |
| Datadog | System performance metrics, error logs | Datadog Servers |

All collected data remainsanonymous and is used for aggregated analyses. No customer-created content is collected.
