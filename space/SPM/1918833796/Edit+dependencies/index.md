# Edit dependencies

## Introduction

You can modify a dependency using the dialog box when you click a dependency arrow. Once you create dependencies, you can click them to edit or remove them. When editing, you can change the following attributes:

- Source task
- Target task
- Dependency type
- [Lag time](/cms_trial/space/SPM/1918406747/Lag+time/)
- [ASAP mode](/cms_trial/space/SPM/1918764948/ASAP+mode/) on/off
- Description

## Task dependencies list

1. Click the **dot** to open the dialog box.
2. From the **More actions …** menu, click the **Edit**button.
3. A dialog box will appear.
4. Make changes. The source/target tasks are marked when scrolling the drop-down menu.
5. When ready, click **Save**.

## Infobar

1. Expand the **Infobar** panel on the right.
2. Find task:

   1. Scroll down to find a task.
   2. Use the **search**bar.
3. From the **More actions …** menu, click the **Edit**button.
4. A dialog box will appear.
5. Make changes. The source/target tasks are marked when scrolling the drop-down menu.
6. When ready, click **Save**.

## Dependency arrow

Make sure that dependencies are expanded (displayed as arrows):

1. Expand the **Dependencies** menu from the top.
2. Under the **Display** option, click **Expanded**.

![Screenshot of selecting expanded dependencies in the Gantt module.](/cms_trial/assets/a1592a35-2df2-4b4f-a7d8-77a65304e18b.png)

To edit a dependency:

1. Click an arrow.
2. A dialog box will appear.
3. Make changes. The source/target tasks are marked when scrolling the drop-down menu.
4. When ready, click **Save**.
