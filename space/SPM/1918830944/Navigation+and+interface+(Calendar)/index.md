# Navigation and interface (Calendar)

## Navigation and interface (Calendar) (old navigation)

## Navigation

You can navigate the Calendar in the following ways:

- Scroll while hovering your mouse over it to move forward or backward by one month.
- Use the navigation buttons or [keyboard shortcuts](/cms_trial/space/SPM/1918862503/Keyboard+shortcuts+(Calendar+module)/) to move forward or backward by one month.

| **Button** | **Action** | **Keyboard shortcut** |
| --- | --- | --- |
| Previous year button. | Previous year | Shift + Alt + , |
| Previous month button. | Previous month | Shift + , |
| Today button. | Today | Shift + 0 |
| Next month button. | Next month | Shift + . |
| Next year button. | Next year | Shift + Alt + . |

- Select the date from the date picker. The calendar will adjust the month and year.

## First day of the week

In the **View** dropdown menu, you can set the first day of the week to Saturday, Sunday, or Monday.

![A dropdown menu where you can set the first day of the week.](/cms_trial/assets/b174eca0-bd76-49e2-8221-9ffbdbfd9164.png)

## Upcoming tasks

Open the sidebar to see the list of upcoming tasks that are counted for each day starting from today.

The tasks will be displayed on the list just like in the Gantt module, which means that the day on the list falls into the duration of the task (between the start and end dates of the task):

![Video presenting the Upcoming tasks panel in the Calendar module.](/cms_trial/assets/265ff104-8051-44cf-a312-eba00a1b144c.mp4)

## Full task list for a selected day

Click **Show all tasks** on the calendar to view all tasks scheduled for a given date. A task list is displayed in a separate window.

![Opening a full task list scheduled for a given day.](/cms_trial/assets/7a7987f8-735d-4521-bc97-11bb98c63df6.mp4)

## End date mode

The end date mode displays tasks as one-day events based on their end date. This view mode lets you focus on task deadlines.

| **End date mode ON** | **End date mode OFF** |
| --- | --- |
| Screenshot of the Calendar module when end end date mode is on. | Screenshot of the Calendar module when end end date mode is off. |

### Activate end date mode

To activate the end date mode:

1. Expand the **View** menu at the top of the **Calendar module**.
2. Check the **End date mode** feature.

To activate the **End date mode**, you can use the **Shift** + **D** keyboard shortcut.

![Screenshot of the end date mode in the Calendar module.](/cms_trial/assets/e063c3f5-d2d5-4478-8548-566a515c9f67.png)
