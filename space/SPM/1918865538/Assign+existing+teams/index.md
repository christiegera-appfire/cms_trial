# Assign existing teams

## Assign existing teams (old navigation)

Use this option to assign existing teams.

1. Click the **plus** button at the top left corner of [the Teams module](https://appfire.atlassian.net/wiki/spaces/DLPDRAFT/pages/296978099).
2. Select the **Assign existing teams** from the drop-down menu.
3. Select teams from the dropdown list. Use the search box to find teams faster. You can assign multiple teams at once.
4. When ready, click **Assign**.

   ![Screenshot of assigning an existing team in the Teams module.](/cms_trial/assets/bc5cdb0f-fe36-4d65-b244-7f453127a7cc.png)

You can add:

- Teams from upper-level boxes:

  ![contentId-1918865538](/cms_trial/assets/91d5f9e3-8c6b-48a8-9162-ad19cf8d1862.png)
- Teams from lower-level boxes:

  ![contentId-1918865538](/cms_trial/assets/8ab72287-e6df-44b6-afc9-132aeefcb6e5.png)

#### Preconditions

If you want to allow users to manually add an upper/lower level team to a box, make sure that the **Manually allocated teams** option in **Administration** > **Box types** > **Resources** > **Basic** is active.

![Screenshot of enabling the Manually allocated teams option in the Administration for a box type in BigPicture.](/cms_trial/assets/78d729d4-b14b-42a5-810b-bc0d63db691d.png)

## Assign existing teams (new navigation)

Use this option to assign existing teams.

1. Select **Teams** at the top left corner of [the Teams module](https://appfire.atlassian.net/wiki/spaces/DLPDRAFT/pages/296978099).
2. Select **Assign existing teams** from the drop-down menu.
3. Select teams from the dropdown list. Use the search box to find teams faster. You can assign multiple teams at once.

   ![teams-dropdown.png](/cms_trial/assets/e449b2ff-d4e0-4b9a-85d4-0a7da9a87afd.png)
