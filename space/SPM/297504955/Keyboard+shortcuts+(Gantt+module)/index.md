# Keyboard shortcuts (Gantt module)

## Keyboard shortcuts - Gantt module (old navigation)

Click to expand the guide

## Display available keyboard shortcuts

Click the **Get help** ( **i** )button in the upper-right corner menu (or press **Shift + /**) to display the keyboard shortcuts dialog box.

![Menu under the Get help button.](/cms_trial/assets/d85f978d-537a-4037-a7b1-b77de1534fa6.png)

## Gantt module shortcuts

The shortcuts listed in the box will only show the shortcuts applicable to the module you are viewing. The app will adjust the displayed shortcuts to your device system (Mac and Windows). Also, depending on your Windows device, you may need to use the **Fn** button in place of **Ctrl**.

The Gantt module’s keyboard shortcuts are divided into the following categories:

![A list of keyboard shortcuts in the Gantt module.](/cms_trial/assets/cf5f1f65-de4c-4fee-ad5d-77c197a4ab0c.png)

### Item actions

Those shortcuts speed up task-related actions directly on the task tree.

| Create a Jira issue | **Enter** |
| --- | --- |
| Create a subtask | **Shift** + **Enter** |
| Create a basic task | **Crl** or **Cmd** + **Enter** |
| Create a basic subtask | **Crl** or **Cmd** + **Shift** + **Enter** |
| Move a task up | **Shift** + **↑** |
| Move a task down | **Shift** + **↓** |
| Indent a task | **Shift** + **→** |
| Outdent a task | **Shift** + **←** |
| Move a task to the top | **Crl** or **Cmd** + **Shift** + ↑ |
| Move a task to the bottom | **Crl** or **Cmd** + **Shift** + **↓** |
| Edit task details | **E** |

### Scenario mode

| Create a new scenario | **Alt** or **Option** + **N** |
| --- | --- |
| Return to Live mode | **Alt** or **Option** + **L** |
| Merge scenarios | **Alt** or **Option** + **M** |

### Navigation

A set of general navigation shortcuts.

|  |  |
| --- | --- |
| Select box | Mouse **left-click** |
| Select work item | Mouse **left-click** |
| Remove selection | **Esc** |
| Context menu | Mouse **right-click** |
| Item navigation | **↑** / **↓** |
| Collapse/ Expand a task | **←** / **→** |

### Timeline

Perform common actions on the Gantt timeline using the keyboard.

| Today | **Shift** + **0** |
| --- | --- |
| Zoom in | **Shift** + = |
| Zoom out | **Shift** + - |
| Scale to fit | **F** |
| Show weeks on a scale (timeline) | **W** |

### View

| Show or hide box highlights | **B** |
| --- | --- |
| Show or hide assignee | **A** |
| Show or hide markers | **M** |
| Expand or collapse dependencies | **D** |
| Show or hide task structure | **[** |
| Show or hide infobar | **]** |

### Layout

Change the row height of the layout.

| Compact | **Shift** + **C** |
| --- | --- |
| Regular | **Shift** + **R** |
| Wide | **Shift** + **W** |

### Others

| Show/Hide menu | **Z** |
| --- | --- |
| Undo | **Ctrl** or **Cmd** + **Z** |
| Open the System-info dialog box | **Shift** + **I** |
| Play the BigPicture game | **Shift** + **Ctrl** or **Cmd** + **G** |
| Re-synchronize data | **Alt** or **Option** + **R** |
