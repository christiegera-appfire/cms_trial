# Add, edit, and delete skills

To add, edit, and delete skills, go to the **Administration** > **Resources** > **Skills** page. To learn more about skill attributes, go to the [Skill management](/cms_trial/space/SPM/1918636059/Skill+management/) page.

## Add new skills

To add a new skill:

1. Click the blue **+Add new skill** button.
2. The modal box will appear.
3. Fill in the required fields - **Skill name**, **Skill code**, and **Skill color**.
4. **Skill description** is optional.
5. To create several skills one after another, check the **Create another** box.
6. When ready, click **Create**.

![A modal where users can define new project skill.](/cms_trial/assets/33b10315-1e93-4a27-bb48-a7ee24cc7ca5.png)

## Edit skills

You can inline edit skill name, skill code, skill color, and skill description. Double-left-click on a field you want to edit and enter a new value for that field.

![Uou can double-left-click using a mouse to edit any skill-related value.](/cms_trial/assets/89f3a41d-32f8-47e0-948e-035c9b29e3f6.png)

## Delete skills

Click the **Delete skill** button next to a skill to delete it. When you click it, a modal will inform you if the skill you want to delete is assigned to any resources or tasks.

Once you confirm, the skill will also be removed from the associated resources and tasks. You **can’t** revert this action. If you change your mind, you will need to add a skill again and assign it to each resource and task.

![Click the delete button (trash icon) to delete a skill.](/cms_trial/assets/b23fa75c-a0bf-40fb-a58b-d48a967dabe3.png)
