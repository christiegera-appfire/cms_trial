# Priority poker game list

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

The**Priority poker game list**screen allows you to find the game you already created, see the list of the games you can join, or inspect the games that were already finished and prioritized work items. Once you create some poker sessions, you can view, join, or invite others to the game.

## List of poker games

To see a list of active and finished poker games:

1. In the Priorities module, click **Priority poker** in the top right.
2. The **Active games** and **Finished games** sections are displayed on the page.
3. You can also check the following information: **Poker game name**, **Issues to prioritize**, **Poker admin**, **Created at**.

![Screenshot of active and finished poker games in the Priorities module.](/cms_trial/assets/281cb62c-2ff8-440a-a1b6-4959301e0c4a.png)

### Active games

The following actions are available on active games:

- **Join** - if you want to participate in an active game.
- **Invite** - if you want to let others in.
- **Delete game** - if you want to permanently delete an active game with its progress.

![Screenshot of available actions on active games in the Priorities module.](/cms_trial/assets/4b065492-f7f8-40da-9835-201423d5f0f9.png)

### Finished games

The following actions are available on finished games:

- **See report** - if you want to display a report.
- **Delete game** - if you want to permanently delete a finished game with its progress.
