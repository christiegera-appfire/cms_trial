## Roles and permissions

### Sub-box creator in a Home box has readonly access to Global Teams

When someone has been assigned the sub-box creator role in the Home box, they can see the Global Teams details in the Home box, but they cannot edit the Global Teams.

### When a user is added to a box, they automatically gain access to the app

When an **app admin** adds a new user to a box, the new user is also added as an **app user** and gains access to the app.

**Note**: Works only when the app admin is the person who performs the action.

### A warning is shown if an app user doesn’t have access to any boxes

When a user has been granted access to the app (has been assigned an **app user** role), but they haven't been assigned any boxes (the user doesn’t have any box roles) a message is shown in the *Security* tab of App Administration.
