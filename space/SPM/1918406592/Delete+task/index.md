# Delete task

## Delete task (old navigation)

The **Delete** option deletes atask from a box. This action cannot be undone. If the task is based on the Jira issue, it will also be deleted from the Jira project. This operation is not the same as removing a task from the board or the risk matrix.

You can delete a task in the following modules:

- Scope
- Gantt
- Calendar

## Scope module

You can delete a task in the Scope module in the following ways:

### Delete button

1. Click the **Delete** button located in the upper menu.
2. Click **Delete** on the modal to confirm the action.

![A confirmation dialog that appears after a user clicks the delete button.](/cms_trial/assets/8504df93-3abc-477b-93f3-83447cbdd1b9.png)

### Context menu

1. **Right-click** the task.
2. Select **Delete** from the context menu.
3. Click **Delete** on the modal to confirm the action.

![A confirmation dialog that appears after a user clicks the delete button on the context menu..](/cms_trial/assets/2ae21e10-357a-4af1-a4c9-e775279c2519.png)

## Gantt module

### Scope definition page (exclude a task from the scope)

You can exclude a task from the scope of the box without deleting it on the [scope definition](/cms_trial/space/SPM/1918634319/Populate+a+box+with+tasks+(work+items+from+Jira)/) page (**box configuration** > **Tasks** > **Scope definition**).

If the task you want to delete is a parent task:

- Child tasks will outdent by one level
- The structure present under that task will be preserved

You can delete a task in the following ways:

### Context menu

1. **Right-click** the task.
2. Select **Delete** from the context menu.
3. Click **Delete** on the modal to confirm the action.

![Right-click on a task to prompt context menu. Then, click Delete.](/cms_trial/assets/03fb9f1c-52c9-4104-98d1-3380caaa1706.png)

### Editor slider

1. Click a task or taskbar to select it.
2. Select **Delete** on the editor slider.
3. Click **Delete** on the modal to confirm the action.

![Delete a task using the editor slider.](/cms_trial/assets/96d2fb3d-7903-4518-88cd-f0fc28d3d8bd.png)

It is possible to delete tasks in bulk using the context menu and editor slider.

## Calendar module

To remove a task:

1. **Right-click** the task on the calendar or in the **Upcoming Tasks** section (anywhere but the Jira key).
2. Select **Delete** from the context menu.

![A context menu with the delete option.](/cms_trial/assets/6cd89efa-5e15-4206-aaf4-bd4222540c81.png)

1. Click **Delete** on the modal to confirm the action.

## Connected tool

To delete a task in BigPicture, delete it directly in the connected tool (for example, Jira).
