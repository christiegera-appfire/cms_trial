# Goal's lifecycle

## Goal definition

A goal is a high-level analogy to work that needs to be done in a given period. They are a short summary highlighting what needs to be achieved, but do not determine the way it should be done.

Such an approach provides more flexibility and team empowerment and allows you to focus on transparent, specific goals simultaneously.

![Objectives module, general view](/cms_trial/assets/87817da9-5cf8-4249-b550-c9b249c804ce.png)

## Right-click dialog menu

Right-click on an existing goal to see a list of available operations:

![Objectives, context menu](/cms_trial/assets/538fc6d6-98c5-4eb1-8e6d-fc75efd699b3.png)

### Goal statuses

The goal can have one of the following statuses, which you can update manually by right-clicking on it or dragging the progress slide bar.

The list of possible statuses is outlined in the table below:

| **goal status** | **Description** |
| --- | --- |
| Open | The default status of a new goal. Open objective |
| Completed | The goal was completed and will not be moved to the next box. Completed objectives |
| Failed | The goal was not completed. It can be copied to the next Box (continued) or failed and left where it currently is. Failed objectiveSystem message on failed objective |
| Abandoned | The goal was not completed and will not be moved to the next box. Abandoned objectives |
| Continue | The goal will be continued in the next box. |
| Uncommitted goal | An additional goal with variable value (if time permits). Uncommitted objectives |

When achieving a goal takes more than a single iteration, you can:

- select `Continue`... option or
- use drag and drop, holding the left Alt key.

## Open goals - updating progress

The progress bar can be updated using inline editing - click (left mouse button) on the percentage number and enter a new value.

![Objective, setting up progress percentage](/cms_trial/assets/bb2472a2-4f2a-49c1-a165-4a97c71c9f67.png)

## Manual change of goal status

When a Box is "Closed", goals are in a read-only mode:

- goals can't be added
- goals can't be modified

  ![Objective in read-only mode](/cms_trial/assets/e9e42e54-c84b-47e4-8106-396e5af05b59.png)

**Method 1:**

Right-click a goal. Select an option from the pop-up menu:

![Context menu on an objective](/cms_trial/assets/511970fc-6e98-437d-96c8-da4fd14bc543.png)

**Method 2:**

### Double-click on a goal (left mouse button). A details box will appear:

![Details of objective](/cms_trial/assets/f33b492c-19e4-45ab-a4f7-a2b100aec748.png)

### goal status set to Failed

When you set the goal status to "Failed" the following pop-up will appear:

![objectives-system message.png](/cms_trial/assets/bb692126-ccb1-4fd6-8b71-1d72c1d24b5e.png)

- **Keep in current Box** (use this option if you don't intend to continue working on a goal. The goal won't be moved or copied - status set to "Failed")
- **Continue** (use this option if you intend to continue working on the goal. **The goal is copied** to the next Box - status set to "Open")

  ![Failed objective](/cms_trial/assets/1f8ed58d-1440-4c8a-96c8-6f379e7a2281.png)

## Automatic change of status

### Progress based transition

When an Open goal progress reaches 100% goal status is automatically changed to Complete.

When the progress bar is at 100% and you lower it, the status is changed to Open.

![objectives-progress-based-transition.mov](/cms_trial/assets/be21078f-b0eb-4cb9-9f1d-81f889765770.mov)

### Box status transition to Closed

![Objective in In Progress status](/cms_trial/assets/d450239f-2512-4272-b2fd-47f04cd91837.png)

When you change the status of a Timebox to Closed and at least one of the goals is marked as Open, you will see a dialog with possible actions:

- Mark open goals as "Failed" and continue
- Mark open goals as "Abandoned"
- Do not modify the status of open goals

![Closing message](/cms_trial/assets/d6c0bc2f-a289-4b2e-901a-e7150f4a5bab.png)

## Achievement Progress

The [Achievement of goals](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=spm&title=Achievement%20of%20Objectives&linkCreation=true&fromPageId=1918505492) feature will help you track the progress of your Goals and goals as well as calculate the planned vs actual business value metric.

![Roadmap module, progress percentage](/cms_trial/assets/d219f73a-e7ad-4f0d-802c-e051f3722a0b.png)

## Affected by

### Box status

After a Box status is set to Closed you can't:

- change the goal status
- modify the progress of "Open" goals
- change the type (regular/uncommitted)
- change the color

![Objective details, completed status](/cms_trial/assets/fdc0c78c-e86b-44c6-adba-1fc93da3ee30.png)

In Closed Boxes, you still can:

- Change goal details (name and note)
- Add and remove associated work
- change the goal's owner

![Objective details, title, note and associated work highlighted](/cms_trial/assets/71310acd-d16c-489b-af17-80f9f1e9c68e.png)
