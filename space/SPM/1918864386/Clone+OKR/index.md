# Clone OKR

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

Cloning OKRs lets you quickly replicate existing OKRs for a new cycle or project, saving time and effort. This is especially useful when the Objectives and Key Results are similar or carry over from one period to the next.

Cloning (and rescheduling) helps maintain consistency, ensures alignment, and makes it easier to adapt to previous goals without starting from scratch. It also promotes efficiency and reduces the risk of errors when setting new OKRs.

## Clone OKR

Once you clone an OKR, it will be placed in the selected period. On the cloned OKR's detail page (the **Info** section), you'll find a link to the original OKR from which it was cloned.

You can clone an OKR, even if it is closed.

You can clone an OKR on the following pages:

### On the OKR Overview page

1. Click **More actions** (**…**) next to the OKR.
2. Select **Clone strategic theme**/**clone objective**/**Clone key result**.

   ![Screenshot of the Clone objective button,](/cms_trial/assets/5ea20479-cddb-40ce-9f69-065619c969e4.png)

1. The **Clone strategic theme**/**clone objective**/**Clone key result** screen displays.
2. Fill in the details.
3. Clickthe **Clone strategic theme**/**clone objective**/**Clone key result** button to finalize the process.

### In the OKR details side panel

1. Click the OKR to open its details on the side panel.
2. On the panel, click **More actions** (**…**).
3. Select **Clone strategic theme**/**clone objective**/**Clone key result**.

   ![Screenshot of the Clone objective button.](/cms_trial/assets/727d3138-aa72-4707-82a4-44307b1e9f90.png)

1. The **Clone strategic theme**/**clone objective**/**Clone key result** screen displays.

3. Clickthe **Clone strategic theme**/**clone objective**/**Clone key result** button to finalize the process.

## Clone OKR (screen)

You can enter the following data on the **Clone OKR** screen:

| **Strategic theme/Objective** | **Key Result** |
| --- | --- |
| Clone Objective dialog. | Clone Key Result dialog. |
| **Select a new parent for this strategic theme/objective** - Assign a new parent to the cloned Objective/ sub-objective.   - By default, the cloned OKR will have the same parent OKR as the original one. You can leave it as it is or select another Strategic theme or Objective. - If you are not sure which parent to assign it to yet, select **Remove current objective** from the dropdown. This will make the Strategic theme or Objective you are cloning a top-level one. You can edit it and add a new parent later. | **Select a new objective for this KR** - Assign a new parent to the cloned Key Result.   - You cannot create or clone a Key Result without an Objective, so you must select an Objective first. |
| **Select a period** - Choose the new period from the list or click **Set as parent** to clone the Strategic theme/Objective to the same period as the selected parent OKR. | **Select a period** - Choose the new period from the list or click **Set as parent** to clone the Key Result to the same period as the selected parent Objective. |
| **History of updates** - Choose whether you want to clone the history of updates along with the OKR.   - This option is useful when you want to continue working on a Strategic theme/Objective from another period and keep all the context. You can clear the history later if you no longer need it. | **History of updates** - Choose whether you want to clone the history of updates along with the Key Result. |
| **Contributing items** - Choose whether to clone individual Key Results and sub-objectives. Their progress history will be copied based on the settings of the Strategic theme/Objective you are cloning. |  |
