# Warnings

## Warnings (old navigation)

Click to expand the guide

This section provides an overview of the warning messages that can appear in the app. These messages are designed to help users avoid errors, stay informed, and take action when something needs attention. Each warning is explained with its purpose, when it appears, and how users can resolve or respond to it.

---

## Gantt module

The **Overdue tasks** and **Period warnings** can be enabled on the dropdown under the **View** options in the Gantt module.

![View options in the gantt module where you can enable warnings.](/cms_trial/assets/93dcc73c-aa3e-447c-8e97-d78b53642cb3.png)

### [Overdue tasks](/cms_trial/space/SPM/1918537803/Overdue+tasks/)

Overdue tasks are all those that have been due in the past but whose progress status is currently below 100% and/or whose status is still **To do** or **In progress**.

### [Period warnings](/cms_trial/space/SPM/1918832897/Period+warnings+%2F+Parent+task+conflicts/)

Period warnings appear when a parent task can not be recalculated due to a constraint, such as a blocking task resulting from the scheduling mode.

### [Dependency loops](/cms_trial/space/SPM/1918700470/Dependency+loops+and+cross-box+relationship/)

If you add predecessor relationships between tasks, you might encounter a dependency loop. This happens when two or more tasks depend on each other. BigPicture prevents you from creating these loops to keep your task flow working properly.

---

## Resources module

The **Estimates**, **Assignment**, **and Workload contour** warnings can be enabled on the dropdown under the **View** options in the Resources module. They are generally referred to as task warnings.

![View options in the resources module where you can enable warnings.](/cms_trial/assets/fcb96d19-9513-4b5a-815e-d629004bdfb3.png)

### [Task warnings](/cms_trial/space/SPM/1918538128/Task+warnings+(Resources+module)/)

Task warnings help you spot common issues and errors when working with tasks in the Resources module. They can be enabled for task estimates, assignments, and workload contour.
