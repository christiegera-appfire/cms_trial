# Connect Trello

New connections are temporarily unavailable. If you have already configured multiple connections, they will continue to work. However, you cannot create new connections at this time.

## Connect Trello (old navigation)

## About the Trello integration

You can connect BigPicture with platforms other than your Jira instance to plan and coordinate your team's work. Currently, you can connect to Trello Boards and another [Jira Cloud instance](/cms_trial/space/SPM/2214658323/Connect+another+Jira+instance+to+BigPicture/).

Once connected, you can add Trello Boards (including Cards, Lists, Check items, Checklists) to the scope of your boxes and have all your work in one place.

Each connection has dedicated sections to define the scope and types of synchronized tasks and the task structure.

## Security and access

You add a new integration using the **+Add new integration** button in:

- **Box configuration** > **Tasks** > **Scope definition**
- **App configuration** > **Integrations** > **Connections**

## Set up the connection

You can add or remove connections from the box configuration or the App configuration pages. Once added, new sections appear on the Scope definition and Tasks structure pages of the box configuration and the Task structure page of the Box type configuration.

To connect Trello using the Box configuration page:

1. Click the **Add new integration**.
2. Select **Trello**.

Once you choose the platform, click the 'Add new connection' box. To add a new tool, you need to allow pop-ups in your browser as the authentication screen opens in a new window:

![Screenshot of adding a new integration on the Scope definition page.](/cms_trial/assets/fcfac601-8208-4895-b528-0114192115de.png)![contentId-1918536760](/cms_trial/assets/fbb71c78-1ac6-49de-aad2-e07625c27f3e.png)

You can connect your Trello accounts, so there is no need for additional authorization, but you can also switch to a different Trello account. The next step is to accept the relevant policies and grant access to your Trello account:

![contentId-1918536760](/cms_trial/assets/c174789b-0d59-484b-8b2f-d3cb0d17ded4.png)

Next, select the team to connect with; let's choose the 'BigPicture' team and click the Connect button. The connection name is generated based on the team name, but you can rename it anytime.

![contentId-1918536760](/cms_trial/assets/046d9bc1-547c-4ff4-a932-725219332d4c.png)

The new connection is now established and appears in the Connection box. Select the connection and click the **Add** button:

![contentId-1918536760](/cms_trial/assets/fcfac601-8208-4895-b528-0114192115de.png)

 You can now select from the list of available Boards and add different task types such as Cards, Lists, CheckItems, Boards, and Checklists.

When you map a new Trello instance connection, its Start Date and End Date fields are set to 'Not Synchronized' by default.

This means that when you change the dates of your Trello tasks in BigPicture, the changes will not be transferred to Trello (and vice versa).

The mappings need to be set manually when connecting with Trello.

You can leave the '[Not Synchronized](/cms_trial/space/SPM/1918507050/Start%2Fend+date+fields/)' status if you don't want to set dates from the BigPicture level.

![contentId-1918536760](/cms_trial/assets/afddad82-ddf4-405b-aa25-ccbed56639f3.png)

To structure your Trello tasks, go to **Box configuration > Tasks > Task structure** page and activate the structure builder. Let's structure the tasks using the Boards and Lists structure builders, so it resembles the Trello board:

![contentId-1918536760](/cms_trial/assets/7acddb0d-7fe4-4519-9381-a1e17b00ac28.png)

Now, let's compare the result using the Gantt module with the connected Trello Board:

You can add different fields specific to the platform you connect using the Column Views. Alternatively, you can use the built-in fields added by the App, which show information from all connected platforms.

## Trello field synchronization

When you map a new Trello instance connection, its **Start Date** and **End Date** fields are set to **Not Synchronized** by default. You can leave the **Not Synchronized** status if you don't want to set dates from the BigPicture level. This means that when you change the dates of your Trello tasks in BigPicture, the changes will not be transferred to Trello (and vice versa).

The mappings need to be set manually when connecting with Trello. See the [Fields](/cms_trial/space/SPM/1918635376/Fields/) page to learn more.

![Screenshot of the Trello field mapping.](/cms_trial/assets/894445ed-8b24-4120-8c9f-99f724998de6.png)

## Trello structure builders

When you connect to Trello, you will see an additional section with the specific structure builders. In the case of Trello, these include boards, lists, checklists, and checklist items. See the [Manage task structure](/cms_trial/space/SPM/1918667217/Manage+task+structure/) page to learn more.

![Screenshot of available structure builders for Trello.](/cms_trial/assets/7acddb0d-7fe4-4519-9381-a1e17b00ac28.png)

## Terminate Trello connection

You can remove the connection from the list by clicking the '...' button next to the connection name > remove.

Before you terminate a connection, make sure that users confirm that it is no longer used. Otherwise, they will be required to redefine the scope and lose some of the current task structure.

![image2021-12-23_14-47-42.png](/cms_trial/assets/020fcd42-685c-4e3d-91d9-20b9d7e876fc.png)

## Connected instance requires your attention

The App works with the connected tools (such as Jira or Trello). However, certain situations may render this connection unusable. The App cannot correctly communicate with the connected instance.

Causes:

- Authorization failed, for example:

  - Token expired
  - Application permissions have been revoked
- A valid installation of the App can't be detected:

  - The App hasn't been installed
  - The license expired or is otherwise invalid
  - The license is valid, but the pricing plan doesn't match it.
