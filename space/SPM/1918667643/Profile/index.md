## Refresh profile cache

If a user does not have access to a box or sufficient permissions (for example, a user is a box viewer but has the box editor permissions), it is recommended to refresh the cache to fetch fresh data from Jira.

Users can perform this action independently to ensure all permissions are up to date. Running the refresh will not slow down BigPicture's performance.

To refresh profile cache:

1. Go to **BigPicture** > **My settings** > **Profile**.
2. Click **Refresh profile cache**.

   ![Screenshot of refreshing profile cache in My settings.](/cms_trial/assets/7c759fcc-e678-4f78-b8f8-8e2b1b929d35.png)

### Refresh cache

The profile cache refresh option ensures all your permissions are up to date by fetching fresh data from Jira. Cache refresh is useful when you have been granted all necessary permissions but still cannot view or edit a box.

Running the refresh will not slow down BigPicture's performance.
