OKR Settings

4 min read

About this page

This page describes features that are supported only in BigPicture Advanced. These features are not available in BigPicture Standard.

The OKR module has separate settings that allow users to customize features such as visualizing linked work items, defining timelines, and adjusting notification preferences. These options provide flexibility and ensure the module meets the unique needs of different teams or organizations.

OKR module Settings are global—any changes you introduce also affect the organization's settings. The only exception is the Time and language setting, which is local (per account).

Security and access

Only permitted users can edit the OKR module settings:

  • Jira Admin

  • In-module Admin

  • Users granted the Change company settings basic permission

  • Users with setting-related advanced permissions:

    • Periods: Manage periods

    • Labels: Create labels, Manage labels

    • Teams: Create teams, Manage all teams

    • OKR types: Manage OKR types

    • Saved views: Manage Custom views

    • Notifications: Manage notifications

    • Permissions: Manage general permissions

    • Time & language: Manage Date&time settings

    • Fields: Manage Custom fields

Switch to the Settings tab in the OKR module.

Available OKR module settings

The Settings page has several sections, each handling different aspects of the module.

Section

Settings

Notes

Screenshot

General

  • Displaying connected issues in the OKR Overview - Activate to view the linked issues under their respective KRs on the Overview page.

  • Allow restricting OKRs - Activate to enable OKR restriction.

  • OKRs can be restricted on the OKR Overview page at any time, during or after creation.

Fields

  • Your custom fields - Here, you can add an OKR custom field. You can edit the name and description of any custom period. You can hide custom fields from view by clicking the eye icon next to a field.

  • Custom fields can be imported/exported via the API and a CSV file.

Periods

  • Your custom periods - Here, you can add custom OKR periods. You can edit the name, start date, and end date of any custom period.

  • Default periods - This section displays periods generated by the system. Default periods cannot be edited, but you can hide them from view by clicking the eye icon next to a period.

  • Changes to a custom period affect all OKRs using that period.

  • Deleting a custom period removes it from all associated OKRs.

  • Hiding a default period does not delete it; it just carries it to the end of the list.

Labels

  • Labels - Labels let you tag specific aspects of your OKRs for better organization and filtering. You can search for labels and create them for projects, sprints, departments, products, or any other category.

  • You can edit or delete any label you created.

  • Editing a label will update it wherever it is used, while deleting it will remove it from all OKRs it's applied to.

  • Labels can be added when creating or editing an OKR.

Teams

  • Teams - You can assign an OKR to a specific team and then filter the main view by the team, creating a focused team view.

  • Only Jira Admin/in-module Admin, team creators, team admins, team managers, and users with Manage all teams permission can edit and delete teams.

OKR types

  • OKR types - OKR types help categorize objectives by scope and focus, distinguishing between company-wide, team-specific, and individual OKRs. You can also create custom types for departmental or squad-level goals.

  • Check the Enable inheritance of colors from OKR types by Objective icons option if you want your Objectives to match the colors of the OKR type they are assigned to.

Saved views

Saved views - They store specific OKR setups for quick access without applying all changes, such as filters or column widths. All views are visible and editable to everyone on your Jira instance.

  • You customize and save your views on the OKR Overview and Progress Dashboard pages.

  • Saved views are stored separately for both pages on the Settings page.

  • On the Settings page, you can only rename or delete the view from the list.

Notifications

  • OKR update reminder: You can schedule regular emails to remind OKR Owners (and Collaborators) to update their OKRs. This is a global setting affecting all OKR Owners/Collaborators.

  • Comments & discussions - Individual users can receive email notifications about their OKR updates and comments.

  • Each OKR Owner/Collaborator will get a personalized email reminder regarding their OKR.

  • The email will highlight OKRs that have not been updated since the last notification.

  • It will also show the progress of each Key Result and the date and time of the last OKR update.

Permissions

  • Permissions - Permissions control access to the module and actions selected users can make.

Time & language

  • Date format - Select the date format from the dropdown menu to set it.

  • Time format - Select the time format from the dropdown menu to set it.

  • Language - Select English or Portuguese based on your preference.

  • By default, your date and time settings are set based on your browser's configuration.

  • These settings are local.

API

  • Organization’s tokens - All requests made to the app require authentication using your generated API token.

  • REST API provides a convenient way to integrate your OKR data with external tools and workflows.
