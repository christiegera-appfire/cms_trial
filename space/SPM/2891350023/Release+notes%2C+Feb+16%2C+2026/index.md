## Custom filters

### Filter tasks by OKRs

Use custom filters to filter tasks based on:

- Objectives
- Key Results
- Strategic Theme
- OKR type (strategic theme, objective, key result

![image-20260216-144447.png](/cms_trial/assets/cb9117d9-dc92-4f7f-8050-935f71158309.png)![image-20260216-144739.png](/cms_trial/assets/02e24c37-a7dc-442f-ac73-9c072f967c0f.png)

**Note**: Only values associated with tasks in the box are on the list. For example, if a Key Result isn’t linked to any tasks, the Key Result can’t be used to filter tasks.

![image-20260216-145120.png](/cms_trial/assets/a57a3030-5e28-404b-9844-741c630940ad.png)
