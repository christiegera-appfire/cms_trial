# OKR attributes

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

This page lists and explains the properties defining all OKRs (Strategic themes, sub-themes, Objectives, sub-objectives, and Key Results) throughout their lifecycle in the OKR module.

## OKR attributes

### OKR creation

The following attributes are defined on the respective [OKR creation](/cms_trial/space/SPM/2324726248/Create+OKR/) screen. You can edit each of these characteristics on the [OKR details page](/cms_trial/space/SPM/1918536390/OKR+details+page/).

note A Strategic theme and sub-themes, as well as Objectives and sub-Objectives, share the same attributes and behavior throughout the app.

| **OKR attribute** | **Description** |
| --- | --- |
| Name | A descriptive name for your OKR. |
| Description | A brief description of the OKR for stakeholders. |
| Progress tracking | Determines whether the OKR’s progress is to be automatic or manual. |
| [Period](/cms_trial/space/SPM/1918797926/OKR+Settings/) | Defines the timeframe for completing the OKR. |
| Expected start | Expected start date of the OKR. |
| Expected end | Expected completion date of the OKR. |
| [Type](/cms_trial/space/SPM/1918635736/OKR+types/) | OKR type (for example, the default types are Company, Team, Personal. You can customize OKR types in the module settings).  note You cannot edit the OKR type for Strategic themes and sub-themes. Their type is always the “Strategic theme” type. |
| Owner | The assignee responsible for delivering the OKR.  By default, it is the person who created the OKR, but you can edit it later. |
| Collaborators | Team members/ other stakeholders responsible for delivering the OKR. |
| [Teams](/cms_trial/space/SPM/1918701406/OKR+Teams/) | Teams involved in delivering the OKR. |
| [Labels](/cms_trial/space/SPM/1918797926/OKR+Settings/) | A descriptive tag that is used for categorizing and organizing the OKR. |
| Contribution ([Weight](/cms_trial/space/SPM/1918636591/Add+weight+(contribution)+to+OKR/)) | It reflects how much a child OKR contributes to its parent OKR’s progress upon full completion.  note By default, all OKRs under the same Strategic theme share the contribution equally, but you can edit contribution values for individual OKRs. Top-level parent OKRs have no contribution. |

### OKR update

The following attributes are updated on the [OKR update](/cms_trial/space/SPM/1918637972/Update+OKR/) screen.

| **Attribute** | **Description** |
| --- | --- |
| Date of update | Date when the change in OKR’s status or progress was made. By default, the date is set to the current date. |
| (Progress) Status | OKR’s status that reflects its standing in relation to progress: Not started; On track; At risk; Off track.  Progress statuses cannot be customized. |
| Progress | Update the progress value for a manual OKR. |
| [Comment](/cms_trial/space/SPM/1918670327/Comment+OKR+update/) | Comments provide more information about the update. |

### OKR closure

The following attributes are updated on the [OKR closure](/cms_trial/space/SPM/1918800058/Close+OKR/) screen.

| **Attribute** | **Description** |
| --- | --- |
| Completion date | Date when the OKR was closed. By default, the date is set to the current date. |
| (Closure) Status | OKR’s status that indicates the reason for closing it: Success; Incomplete; Failed; Rescheduled; Canceled.  Statuses cannot be customized. |
| Description | Description provides more information about why the OKR was closed. |
| Final grade | An arbitrary grade on a scale of 0 to 1 reflects the level of goal achievement. |
