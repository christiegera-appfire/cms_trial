# Convert basic task to Jira work item / Convert BigPicture task to Jira work item

Basic tasks have been renamed to **BigPicture tasks** as part of the new navigation rollout.

Both names refer to the same functionality. You may see either term depending on whether you’re using the previous navigation or the new navigation that is currently being rolled out in BigPicture.

## Convert basic task to Jira work item (old navigation)

Click to expand the guide

In the Gantt module, you can convert a single basic task into a Jira work item, or convert multiple basic tasks into Jira work items of a chosen type.

See how it works in the video below.

## Context menu

1. Right-click on a task or taskbar you want to convert to prompt the context menu.
2. From the menu, select **Convert to Jira issue**.

![A context menu for converting basic task to jira issue in the Gantt module.](/cms_trial/assets/514a3ef8-77ea-4281-a3ea-227ae532056c.png)

1. On the **Convert Basic task to Jira issue** screen:

   1. Select the Jira project from the dropdown.
   2. Select the Jira issue type from the dropdown.
2. Enter the Jira issue details.
3. Click **Create** to finish the process.

## [Editor slider](/cms_trial/space/SPM/1918635307/Editor+slider/)

1. Select a task or taskbar to highlight it and prompt the editor slider.
2. From the editor slider, select **More actions** (**…**) > **Convert to Jira issue**.

![contentId-1918863006](/cms_trial/assets/3bfa929b-bb0a-4196-b188-0bf9fda0080b.png)

1. On the **Convert Basic task to Jira issue** screen:

   1. Select the Jira project from the dropdown.
   2. Select the Jira issue type from the dropdown.
2. Enter the required Jira issue details.
3. Click **Create** to finish the process.

## Bulk convert of basic tasks

You can convert a number of basic tasks at once. To do this, choose tasks from the list (by clicking with Shift or Control button to highlight more than one basic task) and choose **Covert to Jira issue** from the context menu.

Here you can choose:

- **Space** - A Jira space in which the task is created.
- **Issue Type** - The list is based on the space’s issue types. Choose one for all tasks.
- **Label** - An optional field to help you mark converted tasks.

## Convert BigPicture task to Jira work item (new navigation)

Click to expand the guide

In the Gantt module, you can convert a single BigPicture task into a Jira work item or convert multiple BigPicture tasks into Jira work items of a chosen type.

See how it works in the video below.

## Context menu

1. Right-click on the BigPicture task in the WBS and select **Convert to Jira work item.**

   ![Screenshot of the Convert to Jira work item option.](/cms_trial/assets/8ed3baa7-989b-4bb7-a663-4a8b6a775239.png)
2. Select a Jira space and work item type.

   ![Screenshot of the convert to Jira work item window.](/cms_trial/assets/f3e4f679-4252-46c7-a57b-e728451ce1a3.png)
3. The Jira work item creation dialog opens. Fill out and modify the fields. Once you're done, click **Create**.

   ![Screenshot of the Jira work item creation dialog.](/cms_trial/assets/99df7b3b-3297-4277-8b07-9274386627c8.png)

## [Editor slider](/cms_trial/space/SPM/1918635307/Editor+slider/)

1. Select a BigPicture task or taskbar to highlight it and prompt the editor slider.
2. From the Editor slider, select **More actions** (**…**) > **Convert to Jira work item**.

   ![Screenshot of the Convert to Jira work item option.](/cms_trial/assets/51c45c77-34b9-4783-be6c-7e6ed26d99ce.png)

1. On the **Convert BigPicture task to Jira work item** screen:

   1. Select the Jira space from the dropdown.
   2. Select the Jira work item type from the dropdown.
2. Provide Jira work item details.
3. Click **Create** to finish the process.

## Bulk conversion of BigPicture tasks

You can convert multiple BigPicture tasks at once. To do this, choose tasks from the list (by clicking with the `Shift` or `Control` key to highlight more than one BigPicture task) and choose **Convert to Jira work item** from the context menu.

Here you can choose:

- **Space** - A Jira space in which the work items is created.
- **Work item type** - The list is based on the space’s issue types. Choose one for all the tasks.
- **Label** - An optional field to help you mark converted tasks.

![Screenshot of the bulk conversion of BigPicture tasks to Jira work items.](/cms_trial/assets/49b9bcd4-21cc-43de-9daf-c5e85a6f6c2b.png)
