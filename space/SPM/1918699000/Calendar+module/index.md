# Calendar module

## Calendar module (old navigation)

## About the Calendar module

The calendar module helps you stay organized by showing all your tasks and important dates from the connected platforms in a traditional calendar view.

See the video below for a short overview of the Calendar module.

## Main features

| **Feature** | **Description** |
| --- | --- |
| View adjustments:   - First day of the week - End date mode | In the View dropdown menu, you can set the first day of the week to Saturday, Sunday, or Monday. |
| The end date mode displays tasks as one-day events based on their end date. This view mode lets you focus on task deadlines. |
| [Navigate the calendar](/cms_trial/space/SPM/1918830944/Navigation+and+interface+(Calendar)/) | You can navigate the Calendar in the following ways:   - Scroll while hovering your mouse over it to move forward or backward by one month. - Use the navigation buttons or keyboard shortcuts to move forward or backward by one month. - Select the date from the date picker. The calendar will adjust the month and year. |
| Show all tasks | Click **Show all tasks** on the calendar to view all tasks scheduled for a given date. A task list is displayed in a separate window. |
| Upcoming tasks panel | Open the sidebar to see the list of upcoming tasks that are counted for each day starting from today. |
| [Heatmap mode](/cms_trial/space/SPM/1918633596/Heatmap+(Calendar)/) | When the Calendar heatmap is on, tasks are color-coded like in the Gantt module. When it's off, all tasks appear gray. Screenshot of the Heatmap mode option enabled in the Calendar module. |
| [Create tasks](/cms_trial/space/SPM/1918800322/Create+tasks/) | You can create new tasks (both Jira issues and basic tasks) directly in the Calendar module. |
| [Move tasks](/cms_trial/space/SPM/1918864819/Move+tasks/) | You can reschedule your tasks by dragging and dropping them. |
| [Edit tasks](/cms_trial/space/SPM/1918669751/Edit+tasks+in+the+Calendar+module/) | You can edit tasks from the **Upcoming tasks** panel.  You can also inline edit the summary, start date, end date, assignee, and status directly on the task details dialog box. |
| [Delete tasks](/cms_trial/space/SPM/1918406592/Delete+task/) | You can delete a task from the Upcoming tasks panel. |
| [Quick filters](/cms_trial/space/SPM/1918635901/Quick+filters/) | Quick filters are available in the Calendar module.  Only the tasks that match the filter are displayed (parent tasks of the filtered tasks are hidden if they do not match the filter criteria). Screenshot of quick filters in the Calendar module. |
| [Search](/cms_trial/space/SPM/1918407393/Search+box/) | The search functionality is available in the Calendar module. The search bar operates in the text and JQL modes.  Only the tasks that match the search are displayed (the parent tasks of the searched tasks are hidden if they do not match the search criteria). Screenshot of the search bar in the Calendar module. |
| [Markers](/cms_trial/space/SPM/1918699490/Markers/) | Date markers are available in the Calendars module.  You can create, edit, and delete each marker directly on the calendar. Screenshot of markers in the Calendar module. |
| [Calendar gadget](/cms_trial/space/SPM/1918504663/Calendar+gadget/) | You can add the Calendar gadget in Jira to monitor your upcoming tasks. |
| [Export](https://appfire.atlassian.net/wiki/spaces/BTc) | To unlock the export features, you need to install the [BigTemplate](https://marketplace.atlassian.com/apps/1215229/bigtemplate-export-to-pdf-word-excel?hosting=cloud&tab=overview) app.  You can export your Calendar to a PDF image. |
| [Keyboard shortcuts](/cms_trial/space/SPM/1918862503/Keyboard+shortcuts+(Calendar+module)/) | The Calendar module’s keyboard shortcuts are divided into the following categories. Screenshot of keyboard shortcuts in the Calendar module. |
