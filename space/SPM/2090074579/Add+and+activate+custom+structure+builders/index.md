# Add and activate custom structure builders

The following instruction presents how to add and activate a custom structure builder. These steps are dependent on Jira and may change with future Jira updates.

To add and activate a custom structure builder:

1. Go to **Jira Settings** > **Work items**.

   ![Screenshot of selecting Jira Settings and Work items menu.](/cms_trial/assets/d4db846b-e8b0-4cfc-81e5-71987b71fb41.png)
2. Under the **Work types**, click **Add work type**.

   ![Screenshot of clicking the Add work type button in Jira settings.](/cms_trial/assets/9d8b3d41-4a37-403f-bc1a-73fd5fe17917.png)
3. Complete the N**ame** field, and set the type to **Standard work type**. Click **Add**.

   ![Screenshot of adding a new work type in Jira settings.](/cms_trial/assets/71c9da28-2514-45e7-a1f3-3f9e40bd6a17.png)
4. Go to the **Work type schemes** tab and click **Add work type scheme** to add a work type scheme related to your project (or to the default one).

   ![Screenshot of adding a work type scheme in Jira settings.](/cms_trial/assets/c533a1bd-6164-4321-9261-730a9f27551c.png)
5. Complete the **Scheme Name** field and define issue types for the scheme. When ready, click **Save**.

   ![Screenshot of adding a newly created work type to project in Jira settings.](/cms_trial/assets/04222bad-63a7-4d50-81cf-e85dd514a4a5.png)
6. Go to the **Work item linking** tab and create a custom link. When ready, click **Add**.

   ![Screenshot of adding a new link type in Jira settings.](/cms_trial/assets/9353fc54-ed97-46b0-86cd-a91da3d33851.png)
7. You need to set the proper task structure in BigPicture now. To do so, go to the **box configuration** > **Tasks** > **Task structure** > **Advanced Configuration** page.   
   note If you can’t see the custom link, refresh the page. It may take a few minutes until your newly created custom link appears in BigPicture.  
   note The **Structure Preview** on the right will not display the custom link, but if it’s available to be activated on the left, it is working.

   ![Screenshot of the Task structure page in BigPicture with the newly created link-based structure builder enabled. ](/cms_trial/assets/c1be62c4-ff3d-4ef0-82ce-a263c790a965.png)
8. When creating a BigPicture box based on a Jira project associated with the previously set type scheme, you’ll be able to create the desired work item types and select the preferred link type.   
   See the video below.

   ![Screenshot of adding a new work item and selecting the previously created link type.](/cms_trial/assets/ddd7cfba-514b-4561-aa0d-5ae318e875fd.mp4)
9. When creating work items using the **+Add task** button in BigPicture, you may need to move the work items manually to achieve a desired structure.

   ![Screenshot of the Gantt module with link-based structure.](/cms_trial/assets/d412ae3d-d85d-48c5-b6dc-b80f6be27566.png)
10. You’ll see the following window, where you can select the link type.

    ![Screenshot of the Select the link type window.](/cms_trial/assets/a4360d8a-d8b1-4e2d-8931-f2b9ed173614.png)
