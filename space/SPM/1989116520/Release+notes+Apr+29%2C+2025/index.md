## Timebox schedules

The **timebox schedule** (TS) feature helps standardize planning across teams working in recurring cycles, like sprints, program increments, or quarters. It's especially useful for organizations following Agile, SAFe, or similar frameworks, where consistent time-based structures are key. But it can also be utilized by organizations working in classic frameworks like Waterfall to visualize fiscal years or quarters on the timeline. To learn more, see the [Timebox schedules](/cms_trial/space/SPM/1989214530/Timebox+schedules/) page.

With timebox schedules, you can:

- Define a timebox schedule with multiple levels and sequential dates.
- Apply schedules to multiple boxes.
- Ensure the same timebox structure across multiple projects, with a single place to manage those timeboxes.

![contentId-1989116520](/cms_trial/assets/7ef28107-f51d-494b-a097-93e108e95a5c.png)

Additionally, for each timebox schedule, you can perform the following actions:

- Change the TS name
- Add or change a description
- Add or remove global teams
- Remove boxes associated with the selected TS

## 7pace Timetracker for Jira integration

[7pace Timetracker for Jira](https://appfire.atlassian.net/wiki/spaces/7TFJ) is a streamlined, intuitive time-tracking app for recording, managing, and reporting time. Designed to support managers and individual contributors, it simplifies time-tracking tasks across the board.

Add 7pace Timetracker columns to break down logged time by person or category (e.g., billable hours). Easily compare time spent against individual capacity in 7pace’s Times Explorer to monitor workload. This integration offers detailed visibility into effort distribution and helps align time tracking with resource planning.

See more on the [7pace Timetracker for Jira integration](/cms_trial/space/SPM/1961656332/7pace+Timetracker+for+Jira+integration/) page.

## New swimlane filters in the Resources module

You can now filter each swimlane individually by:

- Individuals
- Teams
- Projects
- Skills
- Workload and capacity

In addition, you can **Hide unassigned swimlanes** and **Hide swimlanes with no tasks**.

To learn more, see the [Swimlane filters (Resources module)](/cms_trial/space/SPM/1989083455/Swimlane+filters+(Resources+module)/) page.

## Filter by empty values in the custom filter panel

You can filter the result by empty value for the following fields:

- Assignee
- Milestone
- Risk consequence
- Risk probability
- Any external platform field based on the *select* data type

To learn more, see the [Custom filters](/cms_trial/space/SPM/1918504733/Custom+filters/) page.
