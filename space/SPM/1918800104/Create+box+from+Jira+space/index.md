# Create box from Jira space

## Create a box from the Jira project (old navigation)

Click to expand the guide

The **Import Jira Spaces** is one of the quick action tile options available in the Overview module on the Home (root) box level.

This option creates a new box that pulls Jira work items from the Jira space or spaces specified by the user.

## Create a box with data from the Jira space

1. Navigate to the Home box and open it in the Overview module, Hierarchy mode.
2. Open the **Quick actions** panel. If you cannot see the panel, click the arrow at the top of your box hierarchy to open it.

![The expand button for opening the Quick actions panel.](/cms_trial/assets/a1d13c7d-8ec5-44d2-9730-1b8fb1eb13df.png)

1. From the **Quick actions** panel, select the **Import Jira Spaces** tile. A modal displays.

![Quick action tiles.](/cms_trial/assets/d5bf10f9-81fb-4a3e-9983-da881ff12d17.png)

1. **Jira Spaces to import**: Select one or multiple Jira spaces whose work items you want to include in the box.
2. **Type**: From the dropdown, select the [box type](/cms_trial/space/SPM/1918830000/Box+types/) you want to create for your work items.
3. **Create a separate <box type> for each Jira Project**: This toggle appears only if you select more than one Jira space to import. Toggle it off to import work items from all spaces into one box. Otherwise, toggle it on; this will create as many boxes of the same type as the number of Jira spaces you added for import.

![Import Jira ](/cms_trial/assets/ee942bd3-740d-464e-853e-1f5e027f3d28.png)

1. Click the **Import** button.
2. Your box or boxes are now displayed in the [box hierarchy](/cms_trial/space/SPM/1918535907/Box+hierarchy/) in the Home box in the Overview module. The new boxes inherit their names from the Jira space, but you can rename them by [editing them inline](/cms_trial/space/SPM/1918637324/Inline+edit/). You can also move the boxes to nest them under another box, for example, a [portfolio box](/cms_trial/space/SPM/1918634872/Create+portfolio+box/).

![The two new boxes created using the import jira spaces option.](/cms_trial/assets/4ca2f7cb-af2b-4c68-9e3d-561a92fc488a.png)

The work items you added to the box are arranged in the same order as in Jira: Spaces > Sprints > Versions > Components > work items that have hierarchy, and then the rest of the items.
