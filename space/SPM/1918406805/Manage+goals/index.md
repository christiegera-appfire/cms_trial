# Manage goals

On April 9, 2026, the **Objectives module** was renamed to the **Goals module** to better differentiate it from the OKR module. Items created within this module are now called goals.

## Manage goals (old navigation)

Click to expand the guide

## Set up goals

Each goal can be set using:

- Basic goals – just like with BigPicture tasks, such goals will be only visible via the app and not in the Host Platform (your Jira Instance)
- task-based goals – pick from the list of existing tasks in the scope of a Box.

## Security

You can configure the Security settings in the [Box Configuration](/cms_trial/space/SPM/1918535770/App-level+permissions/) and [Business Administration](/cms_trial/space/SPM/1918535770/App-level+permissions/).

To Add, Edit and Delete goals you need one of the following Security roles:

- Box Editor
- Box Admin

## Moving goals: drag-and-drop

When you hover the mouse over an goal, six dots appear on the left of it. Click them (left mouse button) and move an goal into a new position. You can:

- change the order of goals
- move an goal to a different swim lane
- move an goal to a different column

![Objective page, move button highlighted](/cms_trial/assets/b6386326-91df-462d-9986-73177fee4fab.png)

## Basic and Task-Based goals

Each goal can be set using basic goals which are stored by the App and will not synchronize with Jira or other connected tools.

### Task-Based goals

Any task that is in a Box scope can be added as an goal in the [goals module](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=spm&title=Objectives%20module&linkCreation=true&fromPageId=1918406805). That includes both Jira and Trello tasks.

To add a task-based goal:

1. Navigate to the **goals** module
2. Click **+** to **add a new goal**
3. Click the **toggle switch** next to the goal name field
4. Search for a task

![Searching for task drop-down list](/cms_trial/assets/91cdccaa-ac67-41f7-a003-df9201f36534.png)

### Basic goals

Basic goals are added manually directly in the app. They don't correspond to any tasks or other items in your integrations.

Just like with BigPicture tasks, such goals will be only visible via the app and not in the Host Platform (your Jira Instance)

![Objective, basic objective toggle switch](/cms_trial/assets/5d12853e-a80b-4f26-bd06-4c834513ee2d.png)![Objective based on Jira issue is highlighted](/cms_trial/assets/c03da45b-b063-4b6a-a96c-2fe62c8197d3.png)

#### Associated work

Associated work can be added to all goals (basic goals and task-based goals).

Basic goals cannot be added as associated work - only tasks can be nested under goals.

![Add associated work window, drop-down list](/cms_trial/assets/84ced26f-74cc-44c5-8548-1a43e25816e6.png)

### goal Owner

You can associate resources with goals. User avatar will be shown next to an goal.

![Objective owner highlighted](/cms_trial/assets/b94d509d-7912-4870-bf56-504424d6b248.png)

**Steps**

1. Double left-click on a given goal. An editing box will open.

   ![Details window for objective](/cms_trial/assets/9aed7363-3c67-4bc6-9f08-d5105c271a96.png)
2. Click on 'Positions' to expand.

   ![Objective details window, Position option](/cms_trial/assets/d28456a8-0a62-4bac-92f1-7bde245d8381.png)
3. Click the 'Select user' drop-down.

   ![Objective details, Owner selection](/cms_trial/assets/d49a24a2-dce8-4c7b-8ad5-e2fc1baf3719.png)
4. Use the search box to find a user. Click on the user to select them.

   ![Objective Details, starting typing name](/cms_trial/assets/f31ea5fe-ad71-4f9f-8e45-587bcf80535f.png)
5. Hit 'Save' to confirm.

   ![Objective details, save button](/cms_trial/assets/2d50ff34-5fb8-49e2-9dd3-e365fd618480.png)
