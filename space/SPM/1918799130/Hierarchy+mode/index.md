# Hierarchy mode

## Hierarchy mode (old navigation)

Click to expand the guide

## About the Hierarchy view mode

The structure of boxes in the Hierarchy mode is visualized in a [column view](/cms_trial/space/SPM/1918700155/Column+view+(Overview+module)/), which shows a hierarchy of boxes and their [attributes](/cms_trial/space/SPM/1918404836/Box+attributes/).

![Overview module, root box, hierarchy mode.](/cms_trial/assets/194864d3-fd24-4e32-8901-4cf1e9c7f8ad.png)

## Actions in the Hierarchy mode

You can carry out the following actions while in the Hierarchy mode in the Overview module:

### Change [box hierarchy](/cms_trial/space/SPM/1918535907/Box+hierarchy/)

The hierarchy of boxes visualized in the Hierarchy mode reflects the relationships between the parent boxes and child boxes (sub-boxes). Those relationships, represented as nestings, are governed by the [parent type](/cms_trial/space/SPM/1918832188/Box+type+attributes/) boxes.

You can rearrange the box hierarchy by manually moving (dragging) the boxes from one place to another. This can be especially helpful when you want to quickly organize stand-alone projects into programs and portfolios.

### Manage [box lifecycle](/cms_trial/space/SPM/1918829911/Box+lifecycle/) (context menu)

Jira/App/Box Admins can change the status of the box and [archive](/cms_trial/space/SPM/1918634657/Archive+box/) it. This can be done by:

- prompting the context menu under the **More actions** (**…**) button next to the box
- **right-clicking** the box swimlane (anywhere but the box name link)

![context menu with the box status options.](/cms_trial/assets/924f4d74-567e-431a-8668-9e38e6fdd4ad.png)

### Manage boxes (context menu)

Jira/App/Box Admins can [manage their boxes](/cms_trial/space/SPM/1918699321/Box+management/) by using the same context menu to:

- configure a box
- edit a box
- duplicate a box
- archive a box
- delete a box

In addition, they can click the **Add new** (**+**) in the upper menu to [create a new box](/cms_trial/space/SPM/1918406376/Create+box/).

### Open a box in the last module used

Click the box name to open it in the last module used. Alternatively, right-click and open it in a new browser window or tab to keep the screen with the box hierarchy open.

![Box links highlighted.](/cms_trial/assets/23a527ba-6edd-4b64-a15c-c6354d598b31.png)

### Open a box in a specific module

Click the **Open in module** button and select the module from the list to launch your box in that module. [Module availability](/cms_trial/space/SPM/1918535028/BigPicture+modules/) depends on the box type or box configuration.

### Mark a box as favorite

Open the [box switcher](/cms_trial/space/SPM/1918667414/Navigate+between+boxes+(box+switcher)/) and click the **star icon** next to the box name to mark it as a favorite. It will help you find the marked box easily later. The list of favorite boxes is local and not shared among other users.

### Filter the box hierarchy

Use the search and [filter functionalities](/cms_trial/space/SPM/1918505078/Favorite+%2F+Filter+by+(Overview+module)/) to narrow down the scope of visible boxes.

- When the parent boxes do not fit the applied filter or search criteria, they are faded.

![Parent boxes are slightly faded when a filter is applied.](/cms_trial/assets/27481d68-58e0-45cf-905f-25c1c86ea421.png)

- If it is the child boxes that do not fit the filter or search criteria, the children will not be displayed.

![when a parent box is a match, its children are hidden.](/cms_trial/assets/dd60173f-f8a3-4d6d-8227-3f6d17df926f.png)

### Adjust the view

Under the **View** options, you can adjust the layout of the column view by setting it to:

- **Compact**
- **Regular**
- **Wide**

In addition, you can also check the **Show archived boxes** option to see archived boxes in the box hierarchy.

![View settings in the Overview module, hierarchy mode.](/cms_trial/assets/3a337412-be5e-4d9c-90d2-953fbc2017c6.png)

### Sort the boxes

Click the **Sort by** button to sort the boxes by:

- **Name**
- **ID**
- **Type**
- **Status**
- **Start date**
- **End date**
- **Leader**
- **Manual** (re-order boxes using a drag-and-drop mechanism).

You can switch between sorting and manual modes without losing the manual data order.

![Sort boxes by option.](/cms_trial/assets/4268ab23-7bf8-4a33-97d8-0e61dfe210f1.png)

### Export the view

Click the **Export** button to [export](https://appfire.atlassian.net/wiki/spaces/BTc/pages/3536224346) your current view to:

- pdf (image)
- csv
- xlsx
