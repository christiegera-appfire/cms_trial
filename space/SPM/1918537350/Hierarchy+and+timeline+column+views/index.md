# Hierarchy and timeline column views

In the **hierarchy and timeline modes**, the column views configuration lets you perform the following actions:

- Add new column views
- Edit column views
- Change the name, visibility, and description of the existing views
- Duplicate a view
- Delete existing views

![Screenshot of the Timeline column views page. ](/cms_trial/assets/0db0c966-b54c-478a-99a6-13190c885613.png)

## Available fields

A list of available fields is on the right during column view creation/editing. Additional Jira fields can be [added to the list](/cms_trial/space/SPM/1918406508/Custom+box+columns/), allowing users to add them to their column views in their own boxes.

## Column view creator

The column view creator works exactly the same at the box type and box levels. To learn more about managing hierarchy and timeline column views, see the [Column view creator](/cms_trial/space/SPM/1918668503/Column+view+creator/) page.
