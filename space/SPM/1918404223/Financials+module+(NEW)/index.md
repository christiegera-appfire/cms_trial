## About the Financials module

In most organizations, managing a portfolio of projects goes beyond tracking tasks and deadlines; it also involves monitoring the financials. Traditionally, this requires separate tools for finance tracking, but BigPicture’s Financials module integrates [financial management](/cms_trial/space/SPM/1918633194/Financials+management/) directly into your project workflow.

The Financials module lets you track both **actual costs** (for completed tasks) and **estimated costs** (for upcoming tasks). These costs are calculated based on hourly rates assigned to teams or resources, and estimated time and effort. This provides an up-to-date view of project expenses, helping you compare actual spending with the planned budget.

BigPicture’s cost calculations can be applied to individual projects or an entire portfolio, offering real-time insights into the financial health of your initiatives. This feature helps you monitor whether projects are on a budget and allows for early detection of potential cost overruns.

By incorporating financial tracking into the project management process, BigPicture empowers teams to make informed decisions, streamline workflows, and reduce financial risks, ensuring projects stay on track and within budget.

## Security and access

### App-level security roles

Access to the financial information is restricted. Only people who have been assigned a financial role can interact with the information.

The following permissions are required for the Financial module:

- **App Financial Viewer** - can open the Financials module and view the information but can’t make any changes.
- **App Financial Admin** - can set up the Financials module itself and configure the rates.

  - Financial module access.
  - Editing hourly rates in App Administration.
  - Edit Financial data in the Financial panel, including budget and cost calculation.

### Role in box configuration

A user has to have access to a specific box (for which calculations are made) or to the Home box (which gives access to all the boxes).
