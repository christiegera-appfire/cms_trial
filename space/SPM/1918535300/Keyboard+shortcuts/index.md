# Keyboard shortcuts

By using specific key combinations, you can perform many actions without needing to use a mouse to speed up your workflow and enhance productivity. Mastering these shortcuts can reduce the number of mouse clicks and save you time, making your experience with the app smoother and more intuitive.

Each module has its own set of keyboard shortcuts. Visit the individual module pages to learn more.
