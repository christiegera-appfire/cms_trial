About the Overview module

The Overview module, or command center, provides both a high-level view of the box you are currently viewing, as well as the fine details about the box and its content.

On the home screen (Home/root box level), the Overview lists all the boxes created in your organization. On the individual portfolio box level, you will see project boxes along with the sub-boxes that belong to that portfolio. While on the individual project box level, you will see project sub-boxes, such as iterations or Program Increments.

The Overview module provides three different view modes:

  • Hierarchy

  • Timeline

  • Kanban board

Add new (+)

Click to open the create new box dialog. In this dialog, you can enter the basic box information:

  • Type - a clickable icon with a drop-down menu. Box type can be used as a template for newly created boxes or bulk configuration of the existing ones. Use different icons and colors to differentiate between different box types.

  • Name - box name displayed in the box switcher. The name is visible in every view mode of the Overview module. 

  • Start and end date - the period defining the duration of a box. These dates determine the box position on the timeline in the Timeline mode. The start/end dates are displayed as columns in the Hierarchy mode and on the box tiles in the Kanban mode.

  • Icon and color - a colored icon is shown next to the box name in the box switcher and in different view modes of the Overview module. You can use colors and icons to categorize your boxes by type, domain, etc., to quickly find the one you are looking for. There are many different icons to choose from.

Inline add a new box

Click the plus (+) icon between the lines to open the create new box dialog. The box will be created in the box hierarchy where you click.

Depending on where you want to create a new box, a different set of boxes you can create will be available. If you click in between the sub-boxes, you will be able to add sub-boxes only.

Column view

Column views can be customized (you can add/remove/and aggregate columns to adjust the view). You can also switch to the default column views by choosing one of the views available:

  • Financial

  • Time Tracking

  • Agile

  • Essentials

Inline edit

Click the box details to edit it inline in the column view. You can inline edit box information such as description, name, status, start/end dates, and so on. The inline edit applies only to the Hierarchy and Timeline view modes.

Context menu

Right-click a selected box or click More actions (…) next to the box to open the box context menu. The following box management actions are available:

  • Configure - open the box configuration.

  • Edit - change the box name, start and end date.

  • Duplicate - duplicate the box settings but not the scope.

  • Archive - archive the box you no longer need but don’t want to delete yet.

  • Delete - permanently delete the box from the box hierarchy.

  • Status - each status has a different color which will be shown:

    • in the box switcher next to the box name

    • in the Timeline mode as the color of the box bar

    • in the Gantt module, when the timeboxes are enabled

    • in the Board and Objectives modules as the color of the box.

The following statuses are available: Not started (gray), In progress (blue), and Closed (green).

Boxes in the Closed status cannot be configured and edited.

Sort by

Change the order of the boxes visible in the Overview module.

Boxes can be sorted in all view modes (Kanban, Timeline, and Hierarchy) ascending or descending:

  • Name

  • ID

  • Type

  • Status

  • Start date

  • End date

  • Leader

  • Manual box order (re-order boxes using a drag-and-drop mechanism).

You can switch between sorting and manual modes without losing the manual data order. 

View modes

Visualize your boxes in three ways (view modes). Each mode provides a different view and options:

  • Kanban

  • Hierarchy

  • Timeline

View

Each view mode comes with different view adjustment options.

Hierarchy:

  • Layout: Compact, Regular, Wide

  • Show archived boxes

Timeline:

  • Grid lines: Horizontal, Vertical

  • Hierarchy lines: Horizontal, Vertical

  • Label position: Hidden, On taskbar, Next to taskbar

  • Layout: Compact, Regular, Wide

  • Show: Period warning, Show archived boxes

Kanban board:

  • Show archived boxes

Filters

Filter the list of boxes based on selected criteria:

  • Favorite - filter out all boxes that are not marked as your favorite. Each user can mark their own favorite boxes. The filtered boxes can be used in different modes of the Overview module and in the box switcher.

  • Filter by - filter based on active columns. Only boxes matching the criteria are displayed. Select a column and field values. You can combine multiple different rules.

  • Date filter - filter boxes list based on the boxes' start or end dates. The date range filter affects only the module in which you have applied it.

  • Search box - filter by the box name.

When a filter is applied:

  • the parent boxes of the child matching box are slightly faded

  • the child boxes of the parent matching box are hidden
