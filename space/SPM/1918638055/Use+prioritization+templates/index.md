# Use prioritization templates

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

## Use prioritization templates (old navigation)

Click to expand the guide

When your template is ready, you can start assigning values to your tasks, boxes, and goals. The score will be automatically calculated.

The priority score shows if all metrics are filled.

To add or update the priority metric value:

1. Navigate to one of the tabs (Tasks, Boxes, Goals).
2. Click the field under the respective metric column.
3. Select the value from the dropdown menu.
4. The score is automatically calculated.

## Delete metric values

To delete a value:

1. Click the field under the respective metric column.
2. Click the **X** icon to delete.

Image — asset pipeline pending  
Screenshot of deleting metric values in the Priorities module.

## Clear all metrics

To clear all metrics for a selected work item, box, or goal:

1. Find an element (work item, box, or goal) for which you want to clear all metrics.
2. Click the **… More actions** menu.
3. Click **Clear all metrics**.

Watch an interactive demo on how to clear all metrics for a given work item.
