Track OKRs across modules

8 min read

About this page

This page describes features that are supported only in BigPicture Advanced. These features are not available in BigPicture Standard.

Track OKRs across modules (old navigation)

Click to expand the guide

Overview

The Gantt and Scope modules list all tasks and display Objectives and Key Results next to the associated tasks. Since both modules are available in all box scope types, including portfolios, you can use them to track the progress of OKRs across the entire company portfolio(s).

With regards to OKRs, in the Gantt and Scope modules, you can:

  • Track individual work items that contribute to the completion of the associated KR.

  • View and track all the tasks under specific KRs or all the tasks and KRs that belong to a given Objective and/or strategic theme.

  • Display all the OKRs and the tasks associated with them as a group on the Gantt timeline (Gantt module).

Objectives, Key Results, OKR Type columns

In the Gantt and Scope modules, you can add the following columns associated with the OKRs:

  • Objectives

  • Key Results

  • Strategic theme

  • OKR Type

Objectives, Strategic Themes, and Key Results

If you have linked Jira work items to Key Results (KRs), you can have these KRs, strategic themes, and Objectives displayed in the Gantt module by adding the Objectives, Strategic Themes, and Key Results columns.

To add these columns:

  1. Activate the Objectives and Key Results column view.

    1. Alternatively, click the Add or edit columns (+) button and add these columns to your view.

Customize the Objectives, Strategic Themes, and Key Results columns

When you add the Objectives, strategic themes, and Key Results columns in the Gantt and Scope modules, you can check their type (Column info) and customize them using the following actions:

  • Pin

  • Resize all columns to fit

  • Remove column

Open the OKR details dialog

Click the OKR name link in the Objective/Strategic Theme/Key Result column to open a dialog box with the OKR details. The dialog resembles the OKR details side panel you can find in the OKR module.

You cannot edit the OKR details directly in the details dialog box. To edit the selected OKR, click the icon in the upper right corner to open the OKR details page in the OKR module.

Show all OKRs the work item is linked to

If the work item is linked to more than one Key Result, a blue counter appears in the Key Results column. Click it to see the list of all the KRs the work item is linked to. If the KRs belong to different parent Objectives and strategic themes, the counter also appears in the Strategic Theme and Objective columns.

Group work items by the Objectives and/or Key Results

When you add the Objective and/or Key Results columns to your active view, you can group your tasks by them.

Go to Data > Group Tasks and toggle the column(s) of your choice (you can group tasks by one or multiple columns depending on your needs).

For example, if you group your tasks only by the Objectives column, you will have a clear distinction between the individual Objectives and the tasks that are linked to them (along with their respective KRs).

The groups of tasks are also displayed on the Gantt timeline.

For example, tasks grouped by the Key Results column let you collect and view all KR-related tasks under their respective KR, making KR tracking much easier.

The columns (the grouping factors) act as parents for the tasks under them. You can achieve a similar effect by using the Objective & Key Result structure builder template.

OKR Type

The OKR Type column displays the OKR type next to the task that is linked to a Key Result. If the KR has no type assigned but the task is linked to it, the column shows no data.

OKR module

Scope/Gantt module

Customize the OKR type column

When you add the OKR Type column in the Gantt and Scope modules, you can customize it using the following actions:

  • Pin

  • Sort

  • Resize all columns to fit

  • Remove column

Group work items by the OKR Type

When you add the OKR Type column to your active view, you can group your tasks by it.

Go to Data > Group Tasks and toggle the column. You can group your view only by these columns or combine it with other columns (for example, with Objectives, Key Results, and any other column).

Limitations

The Objectives, Key Results, and OKR Type columns:

  • Cannot be field mapped with any other Jira field.

  • Cannot be edited inline. You can edit OKR data only in the OKR module.

  • Cannot be aggregated. But you can pin them to keep them always visible in your current view.
