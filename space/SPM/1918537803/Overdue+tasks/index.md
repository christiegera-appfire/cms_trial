# Overdue tasks

## Introduction

An overdue task is one whose finish date is earlier than today and whose status is other than closed. You can see all work items that are running late in the Infobar.

Overdue tasks are sorted in descending order, with the most overdue tasks at the top of the list.

The overdue tasks feature **works** for:

- Tasks that have start and end dates

  ![contentId-1918537803](/cms_trial/assets/747435ad-dec5-49cd-988f-c9cf8b1849a5.png)
- Tasks that have only an end date (the task is semi-transparent)

  ![contentId-1918537803](/cms_trial/assets/88b5e93c-feba-439d-89f1-ebbb7e9eea62.png)

The overdue tasks feature **does NOT work** for:

- Tasks without start and end dates
- Tasks with a start date, but no end date

  ![contentId-1918537803](/cms_trial/assets/7a5577eb-a95d-4559-8d29-57018838b6da.png)

## Overdue task color coding

On the timeline, overdue tasks are red or yellow and include the number of days overdue:

- Red—overdue > 7 days
- Yellow—overdue  3 -7  days

The tasks in grey are either completed on time or not running late.

## Finding overdue tasks on the timeline

To find overdue tasks on the timeline, click anywhere on the task row. If you click on the issue key, you will open the detailed view in a new window.
