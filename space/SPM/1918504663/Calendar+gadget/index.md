# Calendar gadget

**Depreciated** **by Atlassian**

[Atlassian ended support for gadgets in Confluence 7.0](https://confluence.atlassian.com/doc/gadgets-moved-to-a-marketplace-app-from-confluence-9-2-onwards-1431545691.html) and completed their removal in Confluence 9.0 to reduce technical debt.

In Confluence 9.0, pages that were using gadgets show a grey ‘Unknown macro’ placeholder where gadgets were embedded.

You can add a Calendar gadget in Jira to monitor your upcoming tasks.

The Calendar gadget mirrors the Calendar module and displays upcoming tasks from a selected Box.

## Adding a gadget

1. Go to your dashboard. Click the 'Add gadget' button.  
   Use the search functionality to find the BigPicture Calendar gadget and click 'Add gadget'.

![contentId-1918504663](/cms_trial/assets/7a135f11-db45-4f72-aef3-8288ba94c600.png)

1. If the gadget is not showing up, click 'Load all gadgets'.
2. Configure the gadget and hit 'Save'.

## Editing a gadget

1. Click the three dots in the top right corner.
2. Select 'Edit' from the drop-down menu.
3. After making the changes, hit 'Save'.

## Deleting a gadget

1. Click the three dots in the top right corner.
2. Select 'Delete' from the drop-down menu and confirm.

## Filtering

The calendar gadget has the same set of filters as the Calendar module (Quick filters, Date range, text and JQL search).

Filtering in a gadget is independent of filtering in the Calendar module view (you can activate a different set of filters in a gadget and in a module).

### Filters activated per user

Each user can activate a different set of filters. It won't affect what other users see. Each user has their own view.

### Multiple gadgets with different filters

Filters are set separately for each gadget. You can add multiple Calendar gadgets to your Dashboard and change scope/filters separately for each of them.

![contentId-1918504663](/cms_trial/assets/b00dd81b-ddb0-45c7-bb12-d9773de12ea7.png)

### Scope definition change = filter reset

When you change the scope definition of a Box, filters of gadgets based on that Box will be reset (gadget filters will be cleared).
