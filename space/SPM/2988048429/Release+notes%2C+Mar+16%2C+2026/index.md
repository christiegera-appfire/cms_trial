## RAG report

### Project health report

We’ve introduced a new project health (RAG) report that gives you a clear, visual overview of project status using the classic Red–Amber–Green system. The status is derived from three key indicators: progress burndown, capacity vs. workload, and high-severity risks.

The color-status thresholds for each indicator can be customized by a Jira Admin.

![image-20260309-130533.png](/cms_trial/assets/3e926346-88dd-4ae2-b2ae-54c9693ce657.png)

To see which sub-boxes fall within the selected RAG category, click the corresponding color on the pie chart or the status in the pie chart view.

![image-20260309-130836.png](/cms_trial/assets/6b672753-4152-481a-a7e8-0d90bcaee48a.png)

Box Admins and Box Editors can customize the report.

## Custom fields

### Multi-team planning field

Now you can allocate multiple teams to selected tasks, to **perform long-term planning** without having to divide initiatives into small tasks for separate teams. Calculate how many resources are needed to implement the plan and how many resources are left for other topics.

![image-20260309-133152.png](/cms_trial/assets/636c01bd-45fc-4649-8d73-474ac3400008.png)

Two new fields have been added:

- **Multi-team planning (Story Points)**
- **Multi-team planning (Time Estimates)**

The new fields allow you to assign a team and its effort to a task:

![image-20260309-133752.png](/cms_trial/assets/f93c04ff-9b31-4ba7-bd1a-c40c30db0698.png)

**Note**: The **muti-team estimates are stored in BigPicture** and aren’t connected to any Jira field - they do not affect the estimate and team fields of tasks. This lets you easily compare the actual work done to the initial plan later.

![image-20260309-135518.png](/cms_trial/assets/18374e97-5662-4426-8f2d-6f19e711898a.png)

Use the **resources panel** to see how the workload estimation calculations. Make sure to adjust the view settings to see the calculations for the planning data.

**Note**: For the calculations to work, the tasks need to have start and end dates.

![image-20260309-134713.png](/cms_trial/assets/dee43242-6b6f-4fb8-b3e1-e6d315ca4935.png)

## OKR module

### When objective progress is set to manual, the progress of its child OKRs is ignored

The displayed progress value **is across all areas** of the app.

You can **convert objectives** between auto to manual tracking:

- Default state - auto Objective (progress tracking based on child OKRs).
- When Objective progress is set to manual, progress of its child OKRs is ignored.
