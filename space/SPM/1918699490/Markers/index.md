# Markers

## Introduction

Markers highlight important dates, such as events or deadlines. They remind you about dates that call for special care or attention. Once created, markers become instantly visible to everybody who can access BigPicture and has the proper security roles to see the box content.

With live synchronization and a variety of colors to choose from, your timeline can be a complete source of information for everyone.

You can see markers only in BigPicture. Markers are visible on the timeline of the following modules:

- Overview ([Timeline mode](/cms_trial/space/SPM/1918538282/Timeline+mode/))
- Gantt
- Board
- Objectives
- Calendar
- Resources (only the **Today** marker is displayed on the timeline)

## Security and configuration

You need at least the Box Editor security role to add, edit, and remove markers.

### Live sync on markers

New markers are instantly displayed in the Gantt module when live synchronization is on.

To enable live synchronization:

1. Open **BigPicture.**
2. Go to **App settings** (wrench icon in the top right corner)> **General** > **Live sync** > **Markers.**
3. Activate the **Enable Live sync on markers** toggle.
4. Click **Save**.

## Display markers

The Board, Objectives, and Calendar modules display markers by default.

To see markers in the Gantt and Overview modules, you need to enable them first:

1. Open the **Gantt module**.
2. Click the **More actions** **…** button in the top right corner.
3. Activate the **Markers** option.

![Screenshot of the Gantt's timeline when markers are enabled.](/cms_trial/assets/a279380f-ad30-4d74-9d4e-cbf594495130.png)

Click on the marker to expand it, or mouse over it to display additional information:

### Inherited markers

Sub-boxes inherit markers so that all important dates are visible to users.

However, if you create a marker when working with a sub-box will not show in the upper-level box.

![Screenshot of the Gantt's timeline with inherited markers.](/cms_trial/assets/3311c6e9-e3c6-414d-a3b0-6d9ae0f7eebc.png)

### Current date marker

The current date is indicated with a purple marker, which you cannot edit. It's graphically represented by a circle outline with a dot at the center.

![Screenshot of the Gantt's timeline with a purple marker indicating the current date.](/cms_trial/assets/5fad8ef0-cf5e-4ae2-9602-63c731cafbe8.png)

## Add custom markers

### Gantt module

Before you begin, make sure that markers are enabled on the timeline.

See how to enable markers

1. Open the **Gantt module**.
2. Click the **More actions** **…** button in the top right corner.
3. Activate the **Markers** option.

To add a new marker in the Gantt module:

1. Open the **Gantt module**.
2. Mouse over the timeline date area.
3. When you see a blue indicator with the **+** icon, click it.
4. Complete the details:

   1. Provide a name.
   2. Adjust the date.
   3. Add the description (optional).
   4. Change the color (optional).
5. When ready, click **Create**.

![Screenshot of the Gantt's timeline when creating a new marker.](/cms_trial/assets/e7fd4995-3f63-4827-8f81-c2745a097fb6.png)

### Board and Objectives modules

To add a new marker in the Board/Objectives module:

1. Go to the **Board/Objectives module**.
2. Click the timeline when the **+** icon appears.
3. Complete the details:

   1. Provide a name.
   2. Adjust the date.
   3. Add the description (optional).
   4. Change the color (optional).
4. When ready, click **Create**.

![Screenshot of the Board module when creating a new marker.](/cms_trial/assets/b59f888d-429e-4cea-b398-405f53ad10b6.png)

### Overview module

To add a new marker in the Overview module:

1. Switch to the **timeline** mode in the top left corner.
2. Click the timeline when the **+** icon appears.
3. Complete the details:

   1. Provide a name.
   2. Adjust the date.
   3. Add the description (optional).
   4. Change the color (optional).
4. When ready, click **Create**.

![Screenshot of the Overview module when creating a new marker.](/cms_trial/assets/3eeada41-21a9-4b5f-a986-35ebbac8e8c8.png)

## Actions on markers

The table presents the actions you can perform on markers in BigPicture.

| **Action** | **Description** |
| --- | --- |
| Mouse over a marker | Display marker details (date, name, and description): Screenshot of the marker's details. |
| All markers for the same date | Click the number to expand a list of all markers created on the same date.  A list with own and inherited markers appears: Screenshot of the list with all markers. |
| Move on top | Change the order of own markers displayed: Screenshot of moving a marker on top. |
| Left-click on a marker | Unfold or collapse a marker: Recording of unfolding and collapsing a marker on the Gantt's timeline. |
| Right-click on a marker | Expand a list with the following actions:   - Edit an existing marker - Show markers list (own markers - editable and inherited markers - uneditable) - Expand all markers - Collapse all markers - Add a new marker - Delete a marker  Screenshot of right-clicking on a marker. |
| Double-click on a marker | Double-click to open and edit the marker: Screenshot of double-clicking on a marker. |
