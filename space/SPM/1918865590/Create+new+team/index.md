# Create new team

## Create new team (old navigation)

Use this option to create a new team in [the Teams module](https://appfire.atlassian.net/wiki/spaces/DLPDRAFT/pages/296978099).

1. Click the **plus** button at the top left.
2. Select the **Create new team** from the drop-down menu.

   ![Screenshot of the Add menu in the Teams module.](/cms_trial/assets/7c0c89b1-bbf9-4b22-a4d7-ea4b9c2e2521.png)
3. Complete the team information:

   1. Team name
   2. Team code and color
   3. Board
4. If you want a new team to be based on a Jira group, enable the **Create team based on Jira group** option.

   1. Select a Jira Cloud group.
   2. Complete the start date for the team membership.
5. When ready, click **Create**.

   ![Screenshot of creating a new team in the Teams module.](/cms_trial/assets/57390a9f-16e4-4b03-a676-cf7ee19068bc.png)

## Create new team (new navigation)

Use this option to create a new team in [the Teams module](https://appfire.atlassian.net/wiki/spaces/DLPDRAFT/pages/296978099).

1. Click the **Teams** button at the top left.
2. Select **Create new** from the drop-down menu and select **Team**.

   ![create-new-team.png](/cms_trial/assets/8bf49f8c-1f2d-4f42-9b1b-3bf7bd3f114f.png)
3. Complete the team information:

   1. Team name
   2. Team code and color
   3. Board
4. When ready, click **Create**.

   ![create-new-team-2.png](/cms_trial/assets/16a4b5e7-9581-4729-b6cc-b9034d65636f.png)
