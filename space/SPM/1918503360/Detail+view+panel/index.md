# Detail view panel

## Detail view panel (old navigation)

Click to expand the guide

The **Detail view** panel is located on the right. It consists of the Details and Reports tabs. By default, it is closed if no tasks are in scope.

![An expanded view on the Scope Detail View showing currenly available tabs.](/cms_trial/assets/b45ef134-c432-45eb-ab8d-fe99003066df.png)

## Expand the panel

To expand (open) the panel, click the **Detail View** vertical bar on the right-hand side.

![Screenshot highlighting where to click to open the Detail View panel.](/cms_trial/assets/68029650-8f12-4fe8-bbe8-2a1096b99d9e.png)

## Close the panel

Click the arrow on the left of the sidebar to close the panel.

![Screenshot showing the sidebar arrow used to close the Detail View panel.](/cms_trial/assets/953da265-3608-4e0b-bb09-01325d32ae0d.png)

## Details

### Jira work items

The Details tab displays Jira work item details.

To view a Jira work item:

1. Open the panel on the right.
2. Select an item by clicking on it.

#### Editable fields

You can make changes to a Jira issue directly from the detail view panel.

The following fields can be inline edited:

- Summary
- Start Date
- End Date
- Status
- Progress
- Priority
- Assignee
- Team
- Estimations: Original Estimate, Remaining Estimate, Story Points
- Labels

![contentId-1918503360](/cms_trial/assets/67fec36e-adfb-4b5b-8454-e017e6d65ebd.png)

#### Quick preview

Click the **Quick preview** button in the top-left corner to preview a Jira issue.

![Screenshot highlighting the Quick preview button.](/cms_trial/assets/b1e83059-f598-4a97-8285-45cb13f0dd8f.png)

Once a separate preview screen opens, you can freely make changes without leaving BigPicture.

![contentId-1918503360](/cms_trial/assets/d635c49d-996e-4d21-8fc9-8c3b25493136.png)

#### Go to the Jira issue page

To be redirected to a Jira issue page, click the issue key:

![image-20240131-095414.png](/cms_trial/assets/a2ad9e2b-700d-46ab-86df-8ce207a14394.png)

### Basic tasks

Basic task information is displayed in the panel.

#### Editable fields

You can make changes to a basic task directly from the detail view panel.

The following fields can be inline edited:

- Summary
- Start Date
- End Date
- Status
- Progress
- Assignee
- Team
- Estimations: Original Estimate, Remaining Estimate, Story Points

![image-20240131-095635.png](/cms_trial/assets/001d59d7-7b1d-44ab-8d08-34a733561cae.png)

#### Convert to Jira issue

Click **Convert to Jira issue** to convert a basic task to a Jira issue (work item).

![image-20240131-095800.png](/cms_trial/assets/6db13026-ab79-4254-8abe-d4e7fb236478.png)

Choose the project and an issue type. Click **Next**.

![image-20240131-095904.png](/cms_trial/assets/97bf6c98-b18a-4b0d-8937-13a1584f2321.png)

Complete the details and click **Create**.
