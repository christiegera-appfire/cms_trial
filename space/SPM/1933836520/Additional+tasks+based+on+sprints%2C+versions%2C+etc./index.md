# Additional tasks based on sprints, versions, etc.

## Additional tasks based on sprints, versions, etc. (Old navigation)

Click to expand

The following elements can be displayed as tasks. You can add them to the scope of a box on the [Scope definition](/cms_trial/space/SPM/1918634319/Populate+a+box+with+tasks+(work+items+from+Jira)/) page.

- Projects
- Sprints
- Components
- Objective & Key Results
- Versions (start date and release date can be synchronized)
