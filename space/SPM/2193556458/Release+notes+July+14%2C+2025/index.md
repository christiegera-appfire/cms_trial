## Priorities module

### Prioritize objectives, key results, and boxes

In the Priorities module, you can prioritize these key elements:

- **Tasks** (Jira work items)
- **BigPicture boxes**
- **Goals** (OKRs)

You can easily switch between the tabs to manage the priorities of different items.

### Preview the timebox schedule before creating a box

rolling out

A user without admin permissions can click **Preview details of the timebox schedules** to open a modal with the list of existing timebox schedules. Click the name of a schedule to see more details.

![image-20250714-123935.png](/cms_trial/assets/20762c38-acf8-4fb7-8be1-746cd0e395d4.png)

**Limitations of the preview:**

- No button “Add new”
- No column with assigned boxes
- No three dots to manage a schedule

### Convert local teams to global when converting boxes to a new timebox schedule

A local team with a unique code (no global team with the same code) can be converted to global and used in a timebox schedule.

## OKR module

### Use AI to create key results

OKR AI helps you generate Key Results quickly and with less manual effort. Based on the Objective’s summary and description, it suggests up to five relevant Key Results you can edit, refine, and create in one go.

### The user interface has been updated

We’re excited to roll out the brand-new OKR Overview experience! This update brings greater flexibility and efficiency to managing your OKRs, with:

- A redesigned table
- Advanced filtering and saved views
- Enhanced customization options

Plus, the OKR details page now has an improved view of higher-level objectives, making parent-child relationships more visible at a glance.
