# Types of tasks

The app supports managing tasks across platforms and methodologies, particularly in portfolio and program management. It integrates with Jira and Trello and can organize tasks using the Work Breakdown Structure (WBS). Here’s a summary of the task types available in BigPicture:

## Jira work items

Any type of Jira tasks (for example, Tasks, Epics, Bugs).

[**Read more**](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=spm&title=Jira%20task&linkCreation=true&fromPageId=1918700059)

---

## Basic tasks/ BigPicture tasks

Non-Jira tasks that exist only in the app.

[**Read more**](/cms_trial/space/SPM/1918405930/Basic+tasks+%2F+BigPicture+tasks/)

---

## Milestones

A task without a duration is used to mark significant points on a timeline.

[**Read more**](/cms_trial/space/SPM/1918537479/Milestones/)

---

## Additional tasks based on sprints, versions, etc.

The following elements can be displayed as tasks, which you can add to the scope of a box on the [Add work items from Jira](/cms_trial/space/SPM/1918634319/Populate+a+box+with+tasks+(work+items+from+Jira)/) page:

- Projects
- Sprints
- Components
- Objective & Key Results
- Versions (start date and release date can be synchronized)

[**Read more**](/cms_trial/space/SPM/1933836520/Additional+tasks+based+on+sprints%2C+versions%2C+etc./)
