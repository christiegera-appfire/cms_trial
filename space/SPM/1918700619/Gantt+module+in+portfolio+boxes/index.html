Gantt module in portfolio boxes

7 min read

Gantt module in portfolio boxes (old navigation)

Click to expand the guide

Visualize your portfolio in the Gantt module

Discover the power of the Gantt module in portfolio boxes and unlock a new level of project management efficiency. Use the Gantt module for portfolio boxes to:

  • Coordinate work across multiple projects simultaneously, including planning dependencies between tasks from different projects.

  • Track the progress of different projects in a single, unified view without switching between boxes.

  • Gain insight into the progress of initiatives, versions, epics, or milestones across various boxes.

  • Determine when a project will end or when a specific team member will be available.

To learn how to create portfolio boxes, see the Create a new portfolio box page.

Common use cases

Group by sub-boxes

Add the Sub-box column to see the name of the sub-box in which a task is located. To have a more organized view of the portfolio within the Gantt module, group tasks by sub-boxes.

To group tasks by sub-boxes:

  1. Add the Sub-box column to the current view.

  2. Expand the Data drop-down menu.

  3. Click Group tasks.

  4. Activate the Sub-box grouping element and adjust the color.

  5. Click Apply.

The interactive tutorial presents how to group tasks by sub-boxes within the portfolio box.

https://demo.arcade.software/oD5bdpVlTKuaThPVg0nW

Group by milestones

To get a clear visual representation of how tasks are progressing towards each milestone within the portfolio box, group tasks by the Milestone column.

To group tasks by milestones:

  1. Add the Milestone column to the current view.

  2. Expand the Data drop-down menu.

  3. Click Group tasks.

  4. Activate the Milestone grouping element and adjust the color.

  5. Click Apply.

The integractive tutorial presents how to group tasks by milestones within the portfolio box.

https://demo.arcade.software/tMzzEBSRyLqWwpflqipx

Manage baselines

Display, edit, and delete baselines for tasks from multiple boxes within one portfolio box.

Apply quick filters

Use quick filters to narrow down the data displayed within one portfolio box. By default, the following quick filters are available for portfolio boxes in the Gantt module:

  • Epics only

  • Milestones only (with label)

  • Tasks in active sprint

  • My tasks

  • Not started tasks

  • In progress tasks

  • Resolved

Workload and capacity

Enable the Resources panel in the Gantt module to preview the work assigned to team members within one portfolio box.

Default portfolio box type settings

To learn more about the default settings for portfolio boxes, see the Default box type settings page.

Available modules

The following modules are available for portfolio boxes by default:

  • Overview

  • Gantt

  • Scope

  • Resources

  • Teams

  • Risks

  • Reports

Column views

The following column views are available for portfolio boxes by default:

  • Essentials Portfolio

  • Agile Portfolio

  • Classic Portfolio

To manage the default column views, go to Administration > Box type > select Portfolio box type > Gantt > Column views.

Constraints

One task in multiple boxes

When one task is duplicated in multiple boxes within one portfolio box, it will be displayed only once in that portfolio box in the Gantt module.

Task structure / Scope definition

  • You can't modify the task structure settings of a portfolio box in the Gantt module because it includes boxes of different box types with individual settings.

  • You can’t manually move or reorder tasks.

  • You can’t manage the scope definition in portfolio boxes (none scope boxes). The Manage scope definition feature and the Scope definition page in the box configuration are unavailable.

To move or reorder tasks, go to the sub-box level where a task is located.

To move or reorder tasks:

  1. Go to the sub-box where a task is located. To find it faster, add the Sub-box column to the view.

  2. Make changes to a task at the sub-box level.

  3. Return to the portfolio box to see the updated view.

Organize tasks

The Organize tasks feature is not available for portfolio boxes (none scope boxes).

Resynchronization

The Resynchronize feature is not available for portfolio boxes (none scope boxes).

‘+Add task’ menu unavailable

You can’t add tasks to portfolio boxes (none scope boxes). The +Add task and inline create features are disabled.

To add new tasks, go to the sub-box of the portfolio box.

To add new tasks:

  1. Go to the sub-box where you want to add new tasks. To find it faster, add the Sub-box column to the view.

  2. Add tasks at the sub-box level.

  3. Return to the portfolio box to see the updated view.
