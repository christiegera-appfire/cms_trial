## OKRs by status

The OKR by status report visualizes the number of OKRs in each status and the percentage of all OKRs in each status.

![OKRs by status report.](/cms_trial/assets/b03f8e9c-c279-45f7-87b9-e113c2464681.png)

This report displays the following data points:

- Total number of OKRs linked to tasks in this box.
- Total number of OKRs in their respective status (including [update statuses](/cms_trial/space/SPM/1918865790/Update+OKR+status/) and [closure statuses](/cms_trial/space/SPM/1918800058/Close+OKR/)).
- Percentage of OKRs in their respective status.
