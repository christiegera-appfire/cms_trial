# Editor slider

## Editor slider (old navigation)

Click to expand the guide

The **editor slider** provides similar options to the right-click contextual menu. It appears at the border between the task structure and Gantt timeline sections.

## Enable editor slider

To enable the editor slider, go to the **View** options and check **Editor slider**.

![Where to enable the editor slider in the Gantt module.](/cms_trial/assets/deb337c8-422d-4f58-8174-789786872a99.png)

The editor slider appears when you:

- Click the whitespace in the Gantt timeline section.
- [Multiselect](/cms_trial/space/SPM/1918832779/Multiselect+tasks/) or [select in bulk](/cms_trial/space/SPM/1918506627/Bulk+change/) work items on the task structure.

## Actions with the editor slider

With the editor slider, you can carry out several different bulk operations on the selected work item or items. The available options depend on whether it is a single item selected, multiple, and whether it is a parent or child work item:

- Move it up or down the hierarchy (with arrows).
- [Indent or outdent it](/cms_trial/space/SPM/1918669003/Manual+task+structure/) (with arrows).
- Create or delete a [baseline](/cms_trial/space/SPM/1918404564/Baselines/) for it.
- Change its [scheduling mode](/cms_trial/space/SPM/1918831395/Scheduling+mode/) (regardless of the relationship of selected tasks).
- Convert

  - [a task to milestone](/cms_trial/space/SPM/1918537200/Convert+task+to+milestone/).
  - [a milestone to task](/cms_trial/space/SPM/1918863029/Convert+milestone+to+task/).
  - [a basic task to Jira issue](/cms_trial/space/SPM/1918863006/Convert+basic+task+to+Jira+work+item+%2F+Convert+BigPicture+task+to+Jira+work+item/).
- Manually select the [task color](/cms_trial/space/SPM/1918636160/Task+color/).
- [Delete](/cms_trial/space/SPM/1918406592/Delete+task/) it.

![Editor slider options for bulk operations on tasks in the Gantt module.](/cms_trial/assets/1858776c-1daf-4b71-a51e-cf80839f263a.png)

If you select a single task that has no tasks nested under it, the editor slider additionally displays:

- Edit.
- Create dependency.
- Convert to Jira issue (applies to [basic tasks](/cms_trial/space/SPM/1918405930/Basic+tasks+%2F+BigPicture+tasks/) only).

![Editor slider options for a single task in the Gantt module.](/cms_trial/assets/829fb95d-2698-4514-b35a-60b19135fbfc.png)

For parent tasks, you can additionally:

- Organize children tasks (A-Z or Z-A) by one of the columns available in the current column view.
- Create and delete a baseline for a parent task or both parent and children tasks.
- Change the scheduling mode for a parent task or both parent and children tasks.
