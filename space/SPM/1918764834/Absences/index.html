Absences

Updated 1 month ago · 2 min read

The list of user absences is visible on the individual’s details page.

Where to add absences

Individual absences can be added by:

  • The App admin or App resource admin on the BigPicture Administration > Resources > Individuals page.

  • Users on their My settings page. Once a user adds an absence, it automatically appears on the individual’s details page in Administration. See the Manage absences page.

  • Users in the Resources module. See the Manage absences page.

Absence days are automatically greyed out on the timeline as non-working days and reduce resource capacity. The App will prevent you from scheduling a task on a non-working day. 

Absence types

There are five types of absences available:

  • Holiday

  • Leave at request

  • Maternity leave

  • Sick leave

  • Other reason

Absences are sorted based on their start date (chronological) - the newest items are at the top, and the oldest items are at the bottom (regardless of the order in which items were created). 

Add absences

On a resource's page (individual’s details page)

  1. Go to the Individual’s details page.

  2. Click +Add new.

  3. Provide the following data

    1. Name

    2. Start date

    3. End date

    4. Comment (if needed)

  4. Adjust the Half-day absence in selected days toggle if needed.

  5. To add another absence, check the Add another box.

  6. Click Add to confirm.

  7. The absence will immediately be visible on the list.

Absences can't overlap. If you try to add an absence, you will see a warning message at the bottom of the pop-up box. 

User-submitted absences

Absences can also be submitted on the My Settings page and in the Resources module. To learn more, see the Manage absences page.

Jira/App Admin must first enable the users to self-manage their absences in their profile settings by toggling the Absences are self-managed by App’s user option.

Half-day absences

Partial absences can be planned for individuals. When adding an absence, enable the Half-day absence in selected days toggle. Individual’s capacity (based on their workload plan) is halved for the absence period. A full day off is greyed out in the Resources module. A half-day off is not greyed out. 

Edit absences

Click the Edit icon to modify an absence.

Delete absences

Click the Delete icon to remove an absence.

Own absences

In My settings (icon in the upper right corner of the main view), Absences, you can view and manage your own absences:
