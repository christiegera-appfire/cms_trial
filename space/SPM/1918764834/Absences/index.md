# Absences

The list of user absences is visible on the individual’s details page.

![Absences section on an individual's details page in BigPicture.](/cms_trial/assets/3c80eddc-b8a6-440f-9e3a-c843279bd480.png)

## Where to add absences

Individual absences can be added by:

- The App admin or App resource admin on the BigPicture Administration > Resources > Individuals page.
- Users on their My settings page. Once a user adds an absence, it automatically appears on the [individual’s details page](/cms_trial/space/SPM/1918637190/Individual%27s+details+page/) in Administration. See the [Manage absences](/cms_trial/space/SPM/1918633840/Manage+absences/) page.
- Users in the Resources module. See the [Manage absences](/cms_trial/space/SPM/1918633840/Manage+absences/) page.

Absence days are automatically **grayed out** on the timeline as non-working days and reduce resource capacity. The App will prevent you from scheduling a task on a non-working day.

## Absence types

There are five types of absences available:

- Holiday
- Leave at request
- Maternity leave
- Sick leave
- Other reason

Absences are sorted based on their start date (chronological) - the newest items are at the top, and the oldest items are at the bottom (regardless of the order in which items were created).

![Absences tab showing recorded absences and their dates.](/cms_trial/assets/de626ac2-7114-41c0-9406-565ec0cc57d2.png)

## Add absences

### **On a resource's page (individual’s details page)**

1. Go to the **Individual’s details page**.
2. Click **+Add new**.
3. Provide the following data:

   1. Name
   2. Start date
   3. End date
   4. Comment (if needed)
4. For a partial absence, use the **Partial absence on selected days (in hours)** toggle.
5. To add another absence, select the **Add another** checkbox.
6. Click **Add** to confirm.

   ![Screenshot of the Add absence window.](/cms_trial/assets/dffe88b8-32d0-4748-bc51-dc8ccf5e689f.png)
7. The absence will immediately be visible on the list.

Absences can't overlap. If you try to add an absence, you will see a warning message at the bottom of the pop-up box.

### User-submitted absences

Absences can also be submitted on the **My Settings** page and in the **Resources module**. To learn more, see the [Manage absences](/cms_trial/space/SPM/1918633840/Manage+absences/) page.

A Jira/App Admin must first enable the users to self-manage their absences in their profile settings by toggling the [Absences are self-managed by App’s user](/cms_trial/space/SPM/1918636014/Resources+(App+configuration)/) option.

### Partial absences (in hours)

You can plan partial absences for individuals. Enable the **Partial absence on selected days (in hours)** toggle and specify the absence duration in hours. Use the +0.5h, +1h, +2h, or +4h buttons to quickly adjust the duration.

![Screenshot of adding a partial absence.](/cms_trial/assets/dcf5150f-8c42-43ca-93ef-6b67be0c462d.png)

The maximum allowed duration is 8 hours. If you exceed this limit, an error message appears.

![Screenshot of an error message that appears if the entered partial absence is more than 8 hours. ](/cms_trial/assets/d841fbf4-8d30-4d9a-a205-0e12db7288fd.png)

Click the **Delete** icon to remove an absence.

![Screenshot of the Delete icon next to the absence line.](/cms_trial/assets/76d295f0-ad43-45c4-9083-4a7b93c60183.png)

## Own absences

In **My settings** (icon in the upper right corner of the main view) > **Absences**, you can view and manage your own absences:

- Add new absences
- Edit existing absences
- Delete existing absences
