Individual's details page

2 min read

On the individual’s details page, you can assign an individual to predefined skills, workload plans, and holiday plans or plan absences.

Security and access

Only a person with the App admin and App resource admin security role can access the Administration > Resources > Individuals > click the resource name > Individual’s details page.

Current assignment

At the top of a page of a given resource, you can see their current absences, holiday plans, workload plans, and skills.

The timeline on the right helps you visualize absences, holiday plans, and workload plans:

Additionally, current items can be highlighted if the Highlight present data option on a timeline is selected.

Teams

The total team assignment of an individual (across all boxes) is displayed under the Teams section.

The table presents the information that can be found under the Teams section.

Columns

Description

Created in

Team assignment (availability, period, etc.) has to be edited in a box where it has been added. This information is in the Created in column. Listed items work as links that take you to the box in question.

Related to

The Related to column contains info about what sub-boxes are affected by team assignments. Click on the number to see a pop-up containing the list of boxes that inherited the assignment. The ID column works as a link to a given box.

Skills

To assign a skill to an individual, the App admin must first add skills on the Administration > Resources > Skills page. Each skill has a start date (required field) and end date. Resources can be assigned to multiple skills at the same time.

See the Assign skills page to learn how to assign skills to individuals.

Workload plans

The App admin must first add workload plans on the Administration > Resources > Workload plans page. When adding a resource to a workload plan, both start and end dates are required, and the App will automatically set the end date when a new plan is added.

See the Assign individuals to workload plans page to learn how to assign workload plans to individuals.

Holiday plans

The App admin must first add holiday plans on the Administration > Resources > Holiday plans page.

See the Assign individuals to holiday plans page to learn how to assign holiday plans to individuals.

Absences

See the Absences page to learn more about absences.
