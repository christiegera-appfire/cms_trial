# Use case: Create timeboxes based on Jira sprints

## Use case: Create timeboxes based on Jira sprints (old navigation)

Click to expand the guide

|  |  |
| --- | --- |
| **Goal** | **Create and automatically sync consecutive sub-boxes with Jira sprints**  BigPictures timeboxes let you divide and structure your work. Learn how to create timeboxes and sync their dates and tasks with Jira Sprint boards. |
| **Scenario** | A Project Manager runs an Agile or Hybrid project and wants to manage tasks for each sprint in their respective timeboxes. |
| **Key benefits** | - Boxes are created automatically whenever a new sprint is added to Jira - Change in tasks is updated bi-directionally - Change in sprint/timebox status is updated bi-directionally - Easy task assignment for individual sprints (for example, you can drag tasks from the backlog and drop them onto the board in the Board module) |

## Preconditions

- box admin sub-box creator You are a Home [Box Admin or Sub-Box Creator](/cms_trial/space/SPM/1918797447/Box-level+permissions/) (to create boxes under the Home box), or
- box admin If the Agile project box already exists, you are its Box Admin.
- You have a space with Sprints and a backlog of tasks set up in Jira.

## Create Sprint-based timeboxes step-by-step

1. Create a new Agile Project box under the Home box in the Overview module:

   1. Select Agile or Hybrid **project type.**
   2. **Name** your box.
   3. Define the box **start** and **end dates**. Make sure these two dates encompass all the sprints you plan to have in Jira.
   4. Select a **Jira space** to add it to the scope of the box, or leave it blank if you want to define your box scope with **Jira** **board** and/or **filters** later.
   5. Optionally: Change the **box icon** and **color.**
   6. Click **Create**.

Remember that your Jira board can contain tasks, tasks of specific assignees, and task types from other projects.

For that reason, if the scope of the Jira board differs from the scope of the Jira project, add the project's board name to the **Board** in the Add work items from Jira. This will ensure all tasks from this board are included in the scope of the box.

![Box scope based on jira project and jira board.](/cms_trial/assets/fb27a443-109e-4e5c-88e0-2219037b65c5.png)

![Create new box modal where you fill in box details.](/cms_trial/assets/0245d6a0-ea01-4eba-8f36-a1a7a263562a.png)

Your box is now created, and you are the Box Admin of this box.

1. Open your box and go to the **box configuration** > **Tasks** > **Work items from Jira** page.
2. Enable the **Timeboxes** option at the bottom of the page, and leave the **Automatic sprint-based timeboxes** checked.
3. Add the Jira board under the **Board** and leave the **Box type** set to *Iteration*.

![Timeboxes settings on the Add work items from Jira page.](/cms_trial/assets/db2c496e-4391-42b2-8194-93b713387868.png)

Once BigPicture finds the selected Jira board, it lists the sprints that have been created so far.

![A list of Jira sprints detected by BigPicture on the Add work items from Jira page.](/cms_trial/assets/9e99bd15-8842-4577-b41d-a1a066f15e0c.png)

1. **Save** your settings.

Your Jira sprints are now organized into Iteration boxes and visible in the Overview module (on the Home and parent project box levels).

![A list of timeboxes based on Sprints under a parent project box.](/cms_trial/assets/7c6932fc-7570-4a3c-8d3f-3457910fe7cf.png)

The video below recaps the entire process of creating sprint-based timeboxes in BigPicture.

## What’s next?

- BigPicture will add a corresponding timebox under your project box whenever you create a new sprint in Jira.
- If you update a task in Jira, the change will be reflected in BigPicture and other way around.
- When you change the status of a sprint, the box status will also be updated.
- You can change individual timeboxes' names by [editing them inline](/cms_trial/space/SPM/1918637324/Inline+edit/) or using the **Edit** option in several modules.
