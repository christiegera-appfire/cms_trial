# OKR widget

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

The OKR widget on the Jira work item details screen provides a direct view into the OKRs the work item is linked to. The widget displays a snippet of the OKR hierarchy of the associated KRs.

## Access the OKR widget configuration page

Click the **App settings** button (**wrench** **icon**) in the top right corner and select**Widgets** from the drop-down list. Next, go to the **OKR Widget** tab.

Only Jira and App Admins can access the App Configuration page.

![App configuration, OKR widget page.](/cms_trial/assets/b5c1b39e-5903-4d0f-918f-5f9623ba7205.png)

## Configure OKR widget

The widget configuration page offers a single general option you can apply to your projects and Jira issue types.

### Enable the OKR widget in all Jira projects

You can set the OKR widget to appear on issue pages in all Jira projects or only in the selected ones.

The toggle is on by default.

If you want to select specific Jira projects (spaces) for which the OKR widget will be enabled:

1. Toggle the **Enable OKR widget in all Jira Projects** off.

![okr-widget-config.png](/cms_trial/assets/ca4f0abf-896f-4740-ae58-c9b4d1f75587.png)

1. Toggle the switch on next to Jira Project or Projects.
2. Click **Save**.

## View OKR widget

To view an OKR widget for a linked Jira work item:

1. Open the Jira work item details page.
2. Scroll to the widget section in the right-hand pane. Click **Open BigPicture - OKR**.

![Open BigPicture - OKR option on Jira work item details page.](/cms_trial/assets/5c3e4bfa-7cfc-43ef-a589-310b290ec931.png)

1. OKR widget displays.

![OKR widget.](/cms_trial/assets/8a854daa-5dac-4082-8072-2140b3a7f290.png)

If you want to view this item in the OKR module, click the **Open in BigPicture** button in the widget’s top right corner. Alternatively, click the OKR key to open its [details page](/cms_trial/space/SPM/1918536390/OKR+details+page/).

## Troubleshooting

If the OKR widget shows no data, check whether the [work item is linked to a Key Result](https://appfire.atlassian.net/wiki/pages/createpage.action?spaceKey=SPM&title=Link%20issues%20to%20Key%20Results).
