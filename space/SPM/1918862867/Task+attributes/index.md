## About task attributes

In project management, a task can be defined by several key attributes, including its description, assigned individuals, start and end dates, priority, status, dependencies, and many more. From the perspective of task management, a task can be considered an item that has a certain number of attributes that are crucial for organizing, tracking, and managing tasks effectively within a project.

Attributes are also helpful when you want to filter, sort, and organize tasks.

In BigPicture, the set of basic task attributes depends on the [task type](/cms_trial/space/SPM/1918700059/Types+of+tasks/).

| **Attribute** | **Task type** |
| --- | --- |
| **Jira task** | **Basic task** | **Milestone** | **Project, Sprint, Component, OKR, Version** |
| Name (Summary) | Yes | Yes | Yes | Yes |
| Description | Yes | No | No | Yes |
| Start date | Yes | Yes | One date that is both a start and an end date | Project, Sprint, OKR, Version |
| End date | Yes | Yes | Project, Sprint, OKR |
| Color | Yes | Yes | Yes | No |
| Status | Yes | Yes (can be added inline) | Yes (can be added inline) | Project, Sprint, OKR |
| Icon | Yes | Yes | Yes | Yes |
| Key | Yes (based on Jira project) | Yes (based on BigPicture box) | Yes (based on BigPicture box) | Yes |
| Assignee/ Owner/ Driver | Yes | Yes (can be added inline) | Yes (can be added inline) | Yes |
| [Note](/cms_trial/space/SPM/2372665547/Create+notes/) | Yes | Yes | No | Yes |

Jira tasks can have more attributes based on the field configuration. You can also add more attributes on the Gantt timeline or by inline editing a Jira task, basic task, or milestone, including:

- Skill
- Baseline
- Dependency
- Duration
- Priority Score

and many more.
