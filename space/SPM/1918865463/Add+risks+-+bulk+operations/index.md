# Add risks - bulk operations

**About this page**

This page describes the Risks module, which is available only for legacy customers. For new implementations of BigPicture, use the [**Risk Management**](/cms_trial/space/SPM/1918798201/Risk+management+module+(new+module)/) module instead.

[Jira bulk change](https://support.atlassian.com/jira-work-management/docs/edit-multiple-issues-at-the-same-time/) functionality allows you to edit multiple work items at once, setting a change risk probability and a change risk consequence for multiple work items during a single bulk operation.

Each bulk operation adds the same field values to all selected tasks. To add different values, perform multiple bulk operations.

## Steps

1. In Jira, click **Search for Jira work items**.

   ![Screenshot of searching for Jira work items.](/cms_trial/assets/f612f595-a09f-4f5b-8299-786befdeda51.png)
2. Run a search to narrow down the results.

   ![Screenshot of using the JQL search to narrow down the list of Jira work items.](/cms_trial/assets/cba1cd4c-feea-4f34-b6b9-35b49f18f240.png)
3. Click **More actions (…)** > **Bulk change work items**.

   ![image-20260324-093845.png](/cms_trial/assets/e83c5fab-2897-4912-aa95-ff595a4fe8ad.png)
4. Select work items by checking the boxes (to select all, check the box at the top of the list).
5. When ready, click **Next**.

   ![Screenshot of selecting work items in Jira.](/cms_trial/assets/ea3207c7-7913-4894-a89a-89782a7b8180.png)
6. Select **Edit work items** and click **Next**.

   ![Screenshot of choosing bulk action for work items in Jira.](/cms_trial/assets/4989c847-4bfa-40c9-93cc-f819100f66b6.png)
7. Find the risk field on the list. Select it by checking the box. Select a field value. You can select and edit multiple fields at the same time.

   ![Screenshot of changing the risk fields for work items in Jira.](/cms_trial/assets/e559b877-af0a-445c-a6cc-824b7821ad1e.png)
8. Click **Next**.
9. Review and click **Confirm** to finish the process.

   ![Screenshot of finishing the bulk change process for work items in Jira.](/cms_trial/assets/f0718684-96d6-4ea0-bea3-3314f13736da.png)
