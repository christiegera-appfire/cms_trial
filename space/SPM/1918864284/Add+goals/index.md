# Add goals

On April 9, 2026, the **Objectives module** was renamed to the **Goals module** to better differentiate it from the OKR module. Items created within this module are now called goals.

## Add goals (old navigation)

Click to expand the guide

## Create task-based goals in the Board module

You can create task-based goals directly in the Board module.

1. Find a task (Jira issue/basic task).
2. Right-click on a task and select **Create goal based on this task**.

   ![Screenshot of creating an objective based on the task in the Board module.](/cms_trial/assets/d75fd513-c330-4957-89a8-47cbe8943f1c.png)
3. A new goal is immediately visible in the goals module.

   ![Screenshot of a new objective added in the Board module.](/cms_trial/assets/010e7add-0110-4536-b9f6-3e7a7e8a7553.png)
