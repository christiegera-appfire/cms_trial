# Use case: Create a box with sample data

|  |  |
| --- | --- |
| **Goal** | **Get a hands-on experience with BigPicture in a safe environment**  Playing with sample data when getting to know a new app is a great way to explore its features without risking your actual data. It provides an opportunity to get hands-on experience with the app's interface and functionality in a safe, low-stakes environment.  By experimenting with sample data, you can familiarize yourself with key processes to build confidence, discover shortcuts, and get a feel for how tasks are handled in the app, all while avoiding the stress of making mistakes with real data. |
| **Scenario** | A new BigPicture user creates a new box quickly without the hassle of creating dummy data. They select the type of box they want to try. Shortly after, the box is ready, and they can explore every module and box settings in BigPicture.  Users must have access to the app and be granted permission to create boxes on the Home/root level. |
| **Key benefits** | - Quick access to a realistic box - No actual Jira data required - Focus on a specific type of project, portfolio, or resource management |

## Preconditions

- app user You were granted the [App User role](/cms_trial/space/SPM/1918535770/App-level+permissions/) (to open BigPicture).
- box admin sub-box creator You were granted a [Box Admin or Sub-box Creator](/cms_trial/space/SPM/1918797447/Box-level+permissions/) role of the Home/root box (to access BigPicture and create new boxes).

## Create a sample box step-by-step

The steps will vary depending on your Home/root box role, but both will lead you to create a sample box you can play with.

### As a Box Admin of the Home box

1. Open BigPicture by selecting it from the **Apps** list in Jira. This will take you to the Home box in the Overview module. If you are already in the app, navigate to the Home box using the breadcrumbs or the [box switcher](/cms_trial/space/SPM/1918667414/Navigate+between+boxes+(box+switcher)/).
2. A full box hierarchy is displayed along with the top panel, with the following tiles:

- **Play with sample data**
- **Import Jira Spaces**
- **Create new Portfolio**

![Quick action tiles in BigPicture Enterprise cloud.](/cms_trial/assets/e8d5cbad-1480-4294-bb2f-748bd69fdff2.png)

If you cannot see the top panel, it is currently hidden. Click the arrow at the top-center of the screen to open it.

![An arrow for expanding the top panel in the Overview module on the Home box level.](/cms_trial/assets/f7b18aaf-1f38-4554-a33f-07ec0e88b8e4.png)

1. Click the **Play with sample data** tile.
2. A modal with checkboxes appears.

- Agile Project
- Classic Project
- Hybrid Project
- Portfolio
- SAFe ART
- Resource management

![Play with sample data options for Box Admins.](/cms_trial/assets/da2efb10-3fc6-47ab-a28e-19683576175b.png)

1. Check the one (or multiple) options to create the boxes of your choice. Confirm your choice with the **Play now** button.
2. The app processes your request. The wait time is longer if you selected multiple options. A message appears when the box is created.
3. Your new box appears on the list. Click it to open and start exploring it.

The interactive tutorial below walks you through the sample box creation process from the Box Admin's perspective.

### As a Sub-box Creator of the Home box

1. Open BigPicture by selecting it from the **Apps** list in Jira. This will take you to the Home box in the Overview module.
2. A splash screen with tiles is displayed:

- **Select Jira Space**
- **Play with sample data**

![A partial selection of tiles in the Overview module.](/cms_trial/assets/d05f96fd-3ef4-4cc2-8647-7ff726254cc8.png)

1. Select the **Play with sample data** tile and click **Next**.
2. A splash screen with options is displayed.

- **Agile Project**
- **Classic Project**
- **Resource management**

![Play with sample data options for Sub-box Creators.](/cms_trial/assets/7137d19e-2645-43ad-a629-d2e5683c933b.png)

1. Select one of the options to create the boxes of your choice. Confirm your choice with the **Start working** button. The app processes your request. A message appears when the box is created.

You are now in your new box.

The video below shows the sample box creation process from the perspective of the Sub-box Creator user.

![Play with sample data as a sub-box creator in BigPicture.](/cms_trial/assets/a613140a-90c8-44fe-a23a-4bd70b77d103.mp4)

## Expected outcomes

- The sample box you created contains sample data that lives only in BigPicture. Therefore, you do not risk affecting any real data on your Jira instance.
- Regardless of your Home box role, you become a Box Admin of your sample box; you can freely add, edit, and delete the tasks, change the box configuration, and try all the options the BigPicture modules have to offer.
