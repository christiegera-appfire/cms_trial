# Priority poker

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

Priority planning poker is a technique that allows everyone on the team to contribute equally to the prioritization process while removing bias.

Watch the video on how the priority planning poker works.

The priority poker game is available only for the **Tasks** tab.

![Screenshot of the List view in the Priorities module.](/cms_trial/assets/08449ea6-68c3-459f-8a81-7cd0c5c99c60.png)

Here are some benefits of using priority planning poker:

- Speed up prioritization sessions.
- Give everyone the option to contribute to the final priorities.
- Highlight outside opinions to guide the discussion in the right direction.
- Bring fun and gamify the prioritization meetings.

![Screenshot of the priority poker in the Priorities module.](/cms_trial/assets/644fed48-0738-42f5-bc45-7b4166ded160.png)

## Poker game rules

The high-level steps of playing priority planning poker are:

1. Create a poker room with selected work items.
2. Invite team members.
3. Everyone votes on metrics for selected work items in real-time.
4. Present the results of the voting, together with each member’s votes.
5. Discuss when necessary and accept the votes. Or retake voting if outliers are prominent.

## Roles in priority planning poker session

Everyone with Administer Priorities module permission can create a poker session. When you create a session, you automatically become the session admin.

**Session admin** controls the game, chooses work items that are currently being prioritized, closes voting, reveals vote results, and accepts the votes.

**Players** can only vote on the work item selected by the session admin at that time and view the results once voting is closed.

| **Roles** | **Session admin** | **Player** |
| --- | --- | --- |
| Vote on metrics  Skip vote | ✅  ✅ | ✅  ✅ |
| Close the voting and reveal score | ✅ | ❌ |
| View results | ✅ | ✅ |
| Change or accept voting results | ✅ | ❌ |
| Select work item that is being voted on | ✅ | ❌ |
| Invite other players | ✅ | ✅ |
| Finish the game | ✅ | ❌ |
| Start the game | ✅ | ❌ |

## Available poker game types

When creating a poker game, you can choose between:

- [Real-time poker](/cms_trial/space/SPM/1918801308/Real-time+poker/)
- [Async (offline) poker](/cms_trial/space/SPM/1918538495/Async+(offline)+priority+poker/)

## Limitations

- The priority poker game is not available for boxes and goals.
