# OKR Dependencies

**About this page**

This page describes features that are supported **only** in [**BigPicture Advanced**](/cms_trial/space/SPM/3451617346/BigPicture+Standard+vs+Advanced/). These features are not available in BigPicture Standard.

Visual dependency and contribution mapping provides a transparent view of how OKRs connect across teams and strategic initiatives.

Designed to support both Portfolio Leaders and PMO Managers, this capability makes it easy to track cross-functional relationships centrally, identify blockers early, and ensure work is properly sequenced.

By clarifying how individual efforts contribute to broader company goals, leaders can proactively manage risks, coordinate cross-team planning, and keep strategic execution aligned.

For data to appear on the *Dependency* page, you must first create dependency or contribution links between two OKRs, or both. You can create dependencies between all OKRs (Strategic themes, sub-themes, Objectives, sub-Objectives, and Key Results).

OKR dependency and contribution links do not affect OKR progress.

## Create OKR dependency link

To create a dependency between two OKRs:

1. Go to the *OKR Details* page of the source OKR.
2. Open the **Linked OKRs** tab > **Dependencies** section.
3. Click the **Add dependency** button (or **+Add**; this button appears when no dependency link exists for the selected OKR).

![OKR Details page, Linked OKRs tab, Dependencies section.](/cms_trial/assets/e7b1bca5-08ef-416e-953a-2dc368897439.png)

1. Select the relationship type from the dropdown:

   1. **blocks** -OKR A blocks OKR B's progress.
   2. **is blocked by** - OKR A's progress is blocked by OKR B.
2. Select the target OKR from the **Search for OKRs** dropdown.

![Dependency selection dropdowns.](/cms_trial/assets/f13b4fb7-f111-4826-a173-cdd9c3cea64d.png)

1. Click **Link** to finish.
2. The linked OKR is listed in the **Dependencies** section.

## Create OKR contribution link

1. Go to the *OKR Details* page of the source OKR.
2. Open the **Linked OKRs** tab > **Contribution** section.
3. Click the **Add contribution** button (or **+Add**; this button appears when no contribution link exists for the selected OKR).

![OKR Details page, Linked OKRs tab, Contributions section.](/cms_trial/assets/60ad90d6-7ef6-4641-ba53-ba3cd025c7b8.png)

1. Select the relationship type from the dropdown:

   1. **supports** - OKR A contributes to OKR B's progress.
   2. **is supported by** - OKR B supports OKR A's progress.
2. Select the target OKR from the **Search for OKRs** dropdown.

![Dependency selection dropdowns.](/cms_trial/assets/e348d7dc-4fa1-4289-8511-ffc8d8708c87.png)

1. Click **Link** to finish.
2. The linked OKR is listed in the **Contributions** section.

## Unlink OKRs

To remove a dependency or contribution link between two OKRs:

1. Go to the source or target *OKR Details* page > **Linked OKRs** tab.
2. In the **Dependencies**/**Contributions** section, click **More actions** (**…**) next to the link you want to remove.

![Contextual menu for dependency or contribution links.](/cms_trial/assets/21b4a3bc-4fbb-4b81-9037-82306731be32.png)

1. Select **Unlink** from the contextual menu.
2. The modal appears. Confirm your action with the **Unlink** button.
3. The dependency/contribution link between the source and target OKRs is removed.

The Parent type of a contribution link is added automatically to every OKR that has a parent. This relationship cannot be unlinked. You can, however, change the parent of the current OKR on its [*OKR Details*](/cms_trial/space/SPM/1918536390/OKR+details+page/) page (in the page breadcrumbs or in the **Details** section).

## Track OKR dependency and contribution links

Once you create at least one dependency or contribution link, you can view it on the *Dependency* page.

![access-okr-dependency-page.png](/cms_trial/assets/5174c7b3-6849-455d-91d3-ad0a55229f5d.png)

This page groups all dependency and contribution links by their type. On this page, you can:

### Filter visible OKR links

Use the top header action buttons—including the **Period** filter—and column-specific [OKR filters](/cms_trial/space/SPM/1918637654/OKR+Filters%2C+search%2C+and+saved+views/) to display only the OKR links matching your criteria.

In addition, you can use the tile filters to group the links by:

- **Total** (shows all dependency and contribution links)
- **Blocked by something** (shows OKRs that are blocked by another OKR)
- **Blocks something** (shows OKRs that block other OKRs)
- **At Risk or Off Track** (shows all linked OKRs with the [At Risk and Off Track status](/cms_trial/space/SPM/1918865790/Update+OKR+status/))

### Customize column layout

Just like on the [*Overview*](/cms_trial/space/SPM/1918834317/OKR+Overview/) page, you can select which columns to include in your view and reorder them as needed. The column layout on the Dependencies pages comes with four additional columns:

![The four okr link-related columns in the column layout settings.](/cms_trial/assets/c0583f00-24fa-4bf6-880d-9c5b923c3948.png)

- **Blocked by**
- **Blocks**
- **Supports**
- **Supported by**

These columns are enabled by default, but you can hide them in the Column layout settings if needed. You can also collapse and expand data in these columns for better visibility.

![An expanded and collapsed column.](/cms_trial/assets/873e9e0f-1278-4ad7-892b-4d9c32124f5c.png)
