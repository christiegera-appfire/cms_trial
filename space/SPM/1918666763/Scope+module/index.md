## About the Scope module

The **Scope module** is a customizable task list. It lets you freely [arrange columns](/cms_trial/space/SPM/1918504788/Customize+column+views/), switch between views, and show aggregated values. Double-click on a column's edge to adjust its width to the longest record in the current view.

You can also [edit task details inline](/cms_trial/space/SPM/1918637324/Inline+edit/) and [export](https://appfire.atlassian.net/wiki/spaces/BTc/pages/3536519213) the view for reporting.

The module's key features are the multi-level hierarchies, quick filters, and [advanced aggregation](/cms_trial/space/SPM/1918636993/Column+data+aggregation+methods/).

See the video to learn more about the module.

## Permission role-based constraints

**Box viewers**

- Are not permitted to change the [task structure](/cms_trial/space/SPM/1918832018/Task+structure/) (they cannot indent/outdent tasks or use the drag-and-drop functionality to move the tasks within the structure).
- Are not permitted to delete tasks (the **Delete** button is unavailable).

## Scope module in portfolio boxes

You can use the Scope module to visualize the entire scope of your projects across multiple sub-boxes of one portfolio box. To learn more, visit the [Gantt module in portfolio boxes](/cms_trial/space/SPM/1918700619/Gantt+module+in+portfolio+boxes/) page.
