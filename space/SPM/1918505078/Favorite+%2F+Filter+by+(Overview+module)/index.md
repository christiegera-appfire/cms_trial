## Overview module

In the Overview module, two additional filters are available (in addition to the standard cross-module filters).

### Filter by (columns)

You can filter data using active columns.

![The filtering option highlighted in the Overview module](/cms_trial/assets/c3ff76ad-8cda-4a57-9fc2-0d61b5d2131a.png)![The chosen filtering conditions are displayed](/cms_trial/assets/da571a58-8f45-47a7-a4c5-384ec6af3b91.png)![Available filtering option](/cms_trial/assets/1c29fc7d-3f6a-469a-bed9-aaa1a97d5755.png)

**Available column data types to filter**

You can filter the following column data types:

| **Column data type** | **Field** |
| --- | --- |
| Status | "Status" |
| Number | e.g., "Actual Cost”, "Budget" |
| Estimation | e.g., "Original Estimate (Tasks)", "Time Spent (Tasks)" |
| Date | e.g., "Start Date”, "End Date”, "Created Date”, "Closed Date". |
| String | e.g., "Period mode”, "Scope Type”, "Sequentiality”, and "Inactive For". |
| User | "Leader" |
| Entity Key | "ID" |
| Built-in Icon | "Icon" |
| Box Type Value | "Type" |
| Time Tracking | "Time Tracking (Tasks)" |

**Adjust available filtering options**

Adjust a column view - Add columns to enable the use of their values for filtering.

**Combine filters**

You can combine filters using more than one column value (only boxes that meet all selected conditions are shown).

### Favorites

The App allows users to add Boxes to their favorites, regardless of their security role. There are three ways to add a Box to your favorites:

| **App element** | **preview** |
| --- | --- |
| Overview module (hierarchy mode) | Favourite projects marked with stars in the Overview module |
| Overview module (Kanban mode) | Favourite projects marked with stars in the Overview module |
| Box switcher | Favourite boxes marked in the box switcher |
