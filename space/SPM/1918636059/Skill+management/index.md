# Skill management

Skills are key in project planning and execution. For each role your project needs, you can create a skill and add it to your respective resources (individuals and teams). For example, you can create skills for developers, designers, construction managers, plumbers, etc.

When you have project skills added to BigPicture and assigned to your resources, you can then match people's and teams' skills with the skills the tasks require for completion.

The effort required for task completion is used to calculate the skill demand and is distributed over the task's duration.

## Security and access

The App admin can manage project skills on the **Administration** > **Resources** > **Skills** page.

## Skill attributes

The table presents attributes you can manage when creating or editing skills.

| **Skill attribute** | **Description** |
| --- | --- |
| Skill name | Provide a meaningful name for a skill. Skill names help to recognize a skill when assigning it to the tasks and resources. |
| Skill code | The skill code is currently not used by any feature, but it has to be unique. If you enter a skill code that is already in use, a validation error will appear. |
| Skill color | A skill color is a visual aid that helps you quickly locate a skill on the list. This is particularly helpful when you have numerous skills to scroll through or when the skills have similar names. This way, you can assign skills to tasks and resources faster. |
| Description | Optional description for a skill. |
