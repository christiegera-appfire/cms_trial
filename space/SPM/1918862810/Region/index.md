# Region

On the **Region** page, you can configure [week numbering](/cms_trial/space/SPM/1918833426/Week+numbering/).

## Security and access

Only Jira/App Admins can manage the app on the global (app) configuration level.

To access the global settings for the app region:

1. Click the **wrench icon** in the top right corner.
2. Select **Region** from the dropdown.
