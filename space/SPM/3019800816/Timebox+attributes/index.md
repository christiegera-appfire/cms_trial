## About timebox attributes

The box details dialog in the Board module provides the following information about the timebox (such as Sprint, Iteration, and PI):

- box ID
- box name
- box start and end dates
- task period alignment

![Box details up-close.](/cms_trial/assets/315721a9-f204-4041-ae33-2fc0d067c1fa.png)

## Access box details

To prompt the box details dialog:

1. Click **triple dots** (**More actions**) on the selected timebox.
2. Select **Edit** from the dropdown menu.

![A wideo showing how to prompt box details dialog.](/cms_trial/assets/bdd53cc3-b3b0-4650-bb99-8df9bb2ccc57.mp4)

## Manage box details

All data displayed on the task details dialog are editable, allowing you to manage your timebox details on the fly.

### Box ID

Click the icon next to the ID to copy it. You will need the box ID to synchronize tasks in the scope of your box.

### Box name

The default name for the Iteration box type is “Iteration.” Inline edit the box name to better reflect your organization's terminology.

### Box start and end dates

The start and end dates of the timebox depend on the task period alignment. However, you can manually change one or both dates should your current iteration require it.

### Task period alignment

You can also change the task period alignment directly in the box details dialog. For more information, see the [Task period alignment](/cms_trial/space/SPM/1918830096/Define+task+period+alignment/) page.

## Box status

The dropdown menu under the **More actions** (…) lets you change the status of the box. Alternatively, **right-click** the timebox heading to prompt the box status menu.

![Changing the box status using the dropdown menu.](/cms_trial/assets/98b8c8dd-f6b2-49f7-8dc6-bfdad4b0aa1b.mp4)

The status-related properties are described in the table below:

| **Box status** | **Description** |
| --- | --- |
| **Not started** (gray) | When you set the timebox status to "Not started," you can:   - modify the scope and objectives - set the Planned Business Value for objectives |
| **In Progress** (blue) | When you set the Timebox status to "In Progress," you can:   - modify the scope and objectives - set both Planned and Actual Business Value for objectives |
| **Closed**(green) | When you set the Timebox status to "Closed":   - you cannot modify the scope and objectives - you can set both Planned and Actual Business Value for objectives |
