Release notes, Nov 3, 2025

3 min read

Release date: November 3, 2025

Our team is thrilled to announce the latest release of BigPicture Enterprise Cloud.

New

Reports

New automatic contextual reports are available in app modules

rolling out

We are introducing new, quick, and easy reports that are displayed as individual gadgets in the app modules.

[Unmapped macro: button-handy — no content to fall back on]

Effort progress

The Effort progress report displays the project's progress in terms of effort according to the following formula: timeSpent / (remainingEstimate + timeSpent).

Boxes by status

The Boxes by status report displays the number of boxes in each status and the percentage of all boxes in each status.

Teams capacity

The Teams capacity report displays the teams' capacity. The allocation is color-coded to help you quickly spot over- and underallocation.

Team dependencies

The Team dependency report displays cross-team dependencies in the project on a project and portfolio level.

OKRs by status

The OKR by status report displays the number of OKRs in each status and the percentage of all OKRs in each status.

OKRs

OKR widget for Jira work items

The OKR widget on the Jira work item details screen provides a direct view of the OKRs to which the work item is linked. The widget displays a snippet of the OKR hierarchy of the associated KRs with the following information:

  • KR’s direct parent

  • KR status

  • OKR Owner (for an Objective and Key Result)

  • OKR period

  • OKR progress (for an Objective and Key Result)

  • OKR key (for an Objective and Key Result); click it to open the OKR details page

The OKR widget is located on the right-hand side panel of the Jira work item details issue screen. At the top of the widget, the total number of KRs the work item is linked to is displayed.

Enhancements

Shareable links

Shareable link is valid for 360 days after last use

The shareable link expires 360 days after its last use. If the link is frequently used, it remains valid and there is no need to manually generate a new link every 360 days.

Task details window

The task details window has been updated

The task details window contains more fields. The fields have been grouped into collapsible sections. The window is available in the Gantt, Resources, and Calendar modules. The window can be opened for tasks without dates from the right-click menu,

Data residency

The OKR and Priorities are included in the standard data residency management

rolling out

Residency of data from the Priorities and OKR modules can be managed with the rest of the BigPicture data. Data residency settings can be adjusted by a Jira admin in the App configuration > Region > Data residency tab.
