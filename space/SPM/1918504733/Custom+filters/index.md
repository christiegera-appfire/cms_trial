## Available filtering options

The filtering covers all the task types: Jira issues, basic tasks, sprint versions, etc.

Look at the [Concept of a field](/cms_trial/space/SPM/1918633429/Concept+of+a+field/) page for more information on built-in and native external tool fields.

### Filter by

You can filter data using active columns.

![The filtering option highlighted in the Overview module](/cms_trial/assets/57974d02-4458-4362-8691-56b970791efc.png)![column-filters.png](/cms_trial/assets/5ea5432e-9a75-4ecd-9484-7183aae13144.png)

If the value is numeric, you can choose a modifier:

![Available filtering option](/cms_trial/assets/315046be-2dfe-4156-b018-bbf7f3dbc435.png)

If the value is enumerated (for example, field: Leader, value: Mark), you can choose a value from a drop-down list:

![enum-value.png](/cms_trial/assets/8830ee53-fb86-4c40-93c8-8e783d081ed8.png)

You can filter the result by empty value in the following cases:

| **Field** | **Placeholder displayed in the search field** |
| --- | --- |
| Assignee | Unassigned |
| Milestone | (empty) |
| Risk consequence | (empty) |
| Risk probability | (empty) |
| [any external platform field based on select data type] | (empty) |

### OKRs

Use OKR information through the app to control what you see on the screen. You can filter by:

- Objective
- Key result
- Strategic theme
- OKR type (strategic theme, objective, key result)
