Risks table (Risks Management)

4 min read

Risks table (old navigation)

Click to expand the guide

About the risks table

When you select a risk register from the list, you'll be taken to the risks table, where you can track all risks within the selected register. This view lets you apply filters to narrow the results, customize the table by adding columns, generate reports, and create new risks without leaving the module. Most importantly, you can assign values to the metrics, ensuring comprehensive risk assessment and management.

The table consists of issue types defined when creating the risk register (you can customize it anytime). The issue types come from the Jira projects that are in the scope of the box you’re in.

Access

To access the risks table:

  1. From the Risk management module, click the risk register name.

  2. You are redirected to the risks table.

Assign values to risk metrics

Once you provide values for the risk metrics on the right, the Risk score and Risk level columns are automatically calculated.

See the video on how to assign values to risk metrics.

Edit risk details

You can edit risk details without leaving the module.

  1. In the risks table, click the selected risk.

  2. A full view of the selected Jira issue appears.

  3. Once changes are made, click X to return to the table view.

See the video on how to edit risk details.

Filtering options

See the Risks table - filters page to learn more about the filtering options in the risks table.

Add columns to the table view

Enhance the risks table by choosing additional columns such as status, component, fix version, assignee, project, priority, epic link, parent link, and labels. With this feature, you can better understand each risk without accessing the risk details in Jira separately.

  1. In the risks table, click the Columns drop-down in the top right corner.

  2. Search for the necessary column (Jira field).

  3. Click the checkbox next to the column to add it to the table.

Risk reports

See the Risks table - reports to learn more about reports.

Create new risks

See the Create new risks page to learn more about creating new risks within the risks table.

Export to CSV

You can export the risks table in a CSV file. If you apply filters or add columns to the table, they’ll also be included in the exported file.
