Release notes, Dec 29, 2025

1 min read

Release date: December 29, 2025

Our team is thrilled to announce the latest release of BigPicture Enterprise Cloud.

New

New homepage

Filter out the list of boxes

You can switch between seeing:

  • all boxes

  • your favourite boxes (starred boxes)

  • boxes assigned to you (boxes where you are the box lead)

Customize the layout

Hide or display the sections as needed.

Customize the quick links section

Adjust the quick links section to have easy access to commonly used shortcuts.

Enhancements

Filters

Filter items by a component

Use the custom filters to filter by a component field.

Filter for empty values of numeric and date fields

It is possible to filter by an empty value for:

  • numeric field (Story Points, Original Estimate, Actual Cost, Duration Working Days, etc..)

  • date field (Start Date, Baseline Start Date, etc..)

Resources module

When effort is expressed as a percentage, the infinity symbol on a red background indicates that even though capacity is zero, the workload is nonzero

The infinity symbol is used only when you select the “Percent” effort mode unit:

  • When the team’s capacity is zero

  • When the skill’s capacity is zero

  • When the project’s capacity is zero

  • AND workload is > 0

Note: For “Individuals”, the cell will contain “N/A”
