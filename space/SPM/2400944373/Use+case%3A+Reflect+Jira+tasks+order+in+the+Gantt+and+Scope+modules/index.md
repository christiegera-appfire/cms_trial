# Use case: Reflect Jira tasks order in the Gantt and Scope modules

|  |  |
| --- | --- |
| **Goal** | **Align the task structure in BigPicture with the task order in Jira.**  Reflect the Jira task order in the Gantt and Scope modules to maintain consistency and simplify navigation. |
| **Scenario** | globally A project manager organizes tasks manually in Jira. When viewing the same project in BigPicture, the tasks appear in a different order due to custom sorting. To align both views, the manager uses the **Restore Jira tasks order** feature, ensuring BigPicture mirrors the task sequence from Jira. The change is applied to all box users. |
| **Key benefits** | - **Consistency** - task order is consistent across Jira and the Gantt/Scope module in BigPicture. - **Better collaboration** - no confusion by different task orders, and better collaboration between team members. |

## Preconditions

Role You need at least a Box Editor role to use the Restore Jira tasks order feature.

box The box needs to be populated with a Jira space.

## Reflect Jira tasks order in the Gantt and Scope modules step-by-step

globally This operation will affect the tasks for all users of a given box.

1. Go to the **Gantt** or **Scope module**.
2. Click **Data** > **Restore Jira tasks order**.
3. To confirm, click **Restore anyway**.
4. That’s all. The change will apply immediately.

## Expected outcomes

- The task structure in the Gantt/Scope modules in BigPicture reflects the order of tasks from Jira.
- Box users experience a more intuitive and familiar structure when switching between Jira and BigPicture.
