# Tempo authorization - troubleshooting

This section lists the possible solution paths in case you encounter issues with the Tempo synchronization.

## Error message: Due to integration issues, the synchronization has failed

Solution: 

Contact our Support Team. See the Support request - details to include section for more information.

## Error message: Tempo requires authorization. Make sure necessary credentials have been granted to enable synchronization



Problem:

No credentials were entered (the value fields in the Technical configuration are empty).

Solution:

Fill in the fields correctly following the process described above.



Problem:

Incorrect credentials. This may be due to a mistake in copy-pasting from Tempo to BP, a change in credentials in Tempo, or removing BigPicture from the OAuth2.0 app list in Tempo.

Solution:

Go through all the steps of the authorization process described above.

## Error message: Due to unexpected issues, the authorization has failed. Close the window and try again

Solution 1:

Try to authorize BigPicture again.

Solution 2:

Contact our Support Team. See the Support request - details to include section for more information.

Solution 3:

You may also try to set a correct Authorization grant type in Tempo (see the process described above).

Solution 4:

Go through all the steps of the BigPicture registration in Tempo.

## Error message: Tempo requires authorization, but your credentials are insufficient. You need full access credentials for Tempo synchronization

Solution 1:

Contact our Support Team. See the Support request - details to include section for more information.

Solution 2:

Check the redirect URL (see the process described above).

Solution 4:

Contact the person managing permissions in Tempo. It may happen that the user who first registered BigPicture in Tempo had not been granted the required permissions.
