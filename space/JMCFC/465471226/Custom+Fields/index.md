# Custom Fields

**JMCF for Jira Cloud** provides several custom field types that are above and beyond the standard ones provided by Jira. This section includes details on each of the available custom field types.

## Formatters

![JMCFC-Formatters.png](/cms_trial/assets/cd382ced-572f-4031-b7b5-349954f71f96.png)

Formatters enable you to control several aspects of your custom field appearance, including font size, font weight, background and font colors, and more. See [Formatters](/cms_trial/space/JMCFC/1559003309/Formatters/) for more information.
