# Custom Fields

**JMCF for Jira Cloud** provides several custom field types that are above and beyond the standard ones provided by Jira. This section includes details on each of the available custom field types.

Transcript

JMCF for Jira Cloud is a no code solution for advanced custom fields. These fields allow customized filters, dashboards, and extended reporting. The current collection tracks status changes, such as who, when, and times, and parent status, all without coding. In this video, we will see how to create custom fields. Once you log into your Jira instance as an administrator, click Apps. From the left hand pane, select **Jira Miscellaneous Custom Fields**, and click **My custom fields**. Click **New custom field** from the upper right corner to open the Create Custom Field wizard. Enter a name and description. These fields will display on the Administration screen. Select the custom field type. For this video, I'll select the **Parent Status** type. Click **Next**. Now, select the scope of your custom field, including the project where the field will be added and the issue types it applies to. Click **Next** and select the Jira screens the custom field will be added to. Here, screens can be added individually or use the checkbox at the top to select all screens. Click **Next** and set the configuration options for the field. Note that the options will vary depending on the field type chosen. Click **Save**. In the Parent Status field there is nothing to configure, but in another example where I am creating a custom field based on Last Field Changed by a User, I can select a Field to watch from the dropdown list. Click **Save**. To summarize, there are several reasons to create custom fields with JMCF, including track who changes a status and what the new status is, and also track the history of the status changes, Display the current status assigned to an issue's parent, all of this without coding.
