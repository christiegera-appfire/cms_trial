# Help and Support

This section details several steps you can take to troubleshoot any issues you may encounter while using **JMCF for Jira Cloud** custom fields. If any of the custom fields you configured don’t seem to be giving the expected results, there are a few steps you can take initially:

1. The first thing to do is log into Jira as an Administrator and check the [Error logs](/cms_trial/space/JMCFC/465436864/Error+Logs/) administration page. This page lists any errors that have occurred with custom fields, including the date and time of the error and the specific error message.
2. The next step is to search the [Atlassian Community](https://community.atlassian.com/t5/tag/addon-com.innovalog.jmcf.jira-misc-custom-fiel/tg-p) for existing answers to the issue you are experiencing. You can also [ask the community](https://community.atlassian.com/t5/forums/postpage/choose-node/true/interaction-style/qanda?add-tags=addon-com.innovalog.jmcf.jira-misc-custom-fie) for help with the specific error you are experiencing.
3. If you believe you have encountered a bug in **JMCF for Jira Cloud**, or if you would like to suggest a new feature, don’t hesitate to [open a support request](https://appfire.atlassian.net/servicedesk/customer/portal/11) with us.
