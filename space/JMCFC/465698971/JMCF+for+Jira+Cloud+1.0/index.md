# JMCF for Jira Cloud 1.0

## 🌎 Hello World!

This version, release on July 31, 2023, is the **initial release**.

Today we’re thrilled to share that **Jira Misc Custom Fields (JMCF)** is available to Jira users on Cloud!

With over 4,000+ installs on Atlassian Marketplace, JMCF has established itself as the go-to app to help Jira users and organizations make more informed business decisions and estimations through the power of calculated custom fields!

This is a big day not just for JMFC customers looking to migrate their operations to Cloud, but also anyone new looking to explore the potential of calculated custom fields in Jira.

## Custom Fields for Jira Cloud

The initial release of **JMCF for Jira Cloud** includes several custom field types enabling enhanced screens, reports, and dashboards. Custom fields are created without code using only a few clicks; just go to the JMCF administration section, select **My custom fields**, and click **New custom field**! See [Create Custom Field](/cms_trial/space/JMCFC/465405703/Create+Custom+Field/) for more detailed steps.

For this release, please note that scripted fields are not supported; however, a number of custom field types are available! These custom field types include:

- Last field change Date/Time and User
- Parent Status
- Status Entered Date/Time and User
- Transition Count
- Time in Status

Among several others! For a full list of the available custom fields, see [Custom Fields](/cms_trial/space/JMCFC/465471226/Custom+Fields/).

## JMCF Administration

This release includes four administration pages, providing a central location for creating, managing, and troubleshooting all of your JMCF custom fields. The administration pages include:

- **Getting Started** - Find quick links for product demonstration videos, resources, and to open support requests.
- [**My custom fields**](/cms_trial/space/JMCFC/465471321/My+Custom+Fields/) - A complete list of all JMCF-created custom fields, including screen associations, contexts for each field, and shortcuts for working with each field.
- [**Calculations**](/cms_trial/space/JMCFC/465633417/Calculations/) - A list of all ongoing calculations or recalculations of custom fields.
- [**Error logs**](/cms_trial/space/JMCFC/465436864/Error+Logs/) - All error logs for JMCF custom fields.
