# Installation Guide

![Jira Misc Custom Fields (JMCF) Cloud product logo and branding](/cms_trial/assets/ae1b2b85-527a-4d59-b1b9-6891f92e9873.png)

**Jira Miscellaneous Custom Fields (JMCF) for Jira Cloud** is a no-code solution for adding custom fields to your Jira instance. JMCF includes advanced custom fields not available in native Jira that automatically update based on changes and actions your users perform. These custom fields include calculating the user who triggered a transition, the amount of time an issue has spent in a status, and the date (and time) when a transition occurred, among others!

The pages below will walk you through the process of installing, uninstalling, or disabling **JMCF for Jira Cloud** on your Jira instance.
