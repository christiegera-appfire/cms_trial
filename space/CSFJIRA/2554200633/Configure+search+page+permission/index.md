# Configure search page permission

As an administrator, you can enable Jira users to search for Salesforce pages directly from Jira. Permissions are granted at the Jira group level, not individually.

## Before you start

Make sure that:

- You have [installed the Connector in Jira](/cms_trial/space/CSFJIRA/1873412370/Install+the+Connector+in+Jira+Cloud/).
- You have Jira administrator rights.

## Follow the steps to grant the search page permission

1. Navigate to **Apps** in the left-hand sidebar of Jira.
2. Next to *Connector for Salesforce,* click **Menu** (▢) > **App settings**.
3. Under *Connector for Salesforce*, select **Settings**.
4. In the **Search Page Permission** section, select the Jira groups you want to grant access to.

   ![Search Page Permission section](/cms_trial/assets/1e5a6151-b3e5-40a7-b9bc-e98c8441fcc7.png)
5. Click **Apply Changes**.

Users in the selected groups can now search for Salesforce records from within Jira.
