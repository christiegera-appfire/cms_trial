# Release notes 21 October 2026

**Release date**: October 21, 2026

This page outlines the updates included in the latest release of Connector for Salesforce & Jira Cloud.

**Marketplace version:** 29.10.0

**Salesforce version:** 4.84

---

## **Enhancements**

### SALESFORCE **Forge migration banner**

As part of our move to Atlassian Forge, Salesforce users now see a banner asking them to update to the latest app version. You must complete the update by **31 December 2026**. After that date, the app will stop working, and data syncing will break.

To avoid disruption, update the app before the deadline by selecting **Update now** in the banner. If you’re sure you’re already on the Forge version, you can close the banner.

To learn more, see [Migration to Forge](https://appfire.atlassian.net/wiki/pages/resumedraft.action?draftId=3319464284).

---

## Bug fixes

- JIRA CLOUD **Push to Salesforce post function**: Fixed an issue where the Push to Salesforce post function sent outdated field values to Salesforce when it ran right after another action in the same workflow transition, such as Update a work item field. The post function now pushes the updated values.
