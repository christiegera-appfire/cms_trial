# Release notes 6 July 2026

**Release date**: July 6, 2026

This page outlines the updates included in the latest release of Connector for Salesforce & Jira Cloud.

**Marketplace** **version:** 22.0.0

---

## Jira Cloud Bug fixes

- Fixed an issue where authorizing a Salesforce connection could show the success message multiple times instead of once.
- The mapping editor now loads correctly for large Salesforce orgs that previously failed due to a response size limit, restoring the ability to view and edit field and object mappings on connections with many custom objects.
- The Salesforce security compliance banner is now shown only on admin pages instead of appearing on issue panels for all users. It can also be dismissed and remembers your preference, reducing unnecessary interruptions for non-admin users.
- Security vulnerability fixes have been added.
