# Configuration settings in Jira is not available

Only Jira Administrators can access the Connector for Salesforce & Jira configuration settings.

Regular users are unable to view configuration options:

- Connections
- Bindings
- Settings

## For non-administrator users

If you need configuration changes and are not a Jira administrator:

- Contact your Jira administrator
- Request the necessary permissions be granted to your account
