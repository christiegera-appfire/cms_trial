# Why would two users have different levels of visibility to Jira tickets and comments?

## Purpose

User profile setups can have some level of impact on the ability to see certain Jira issues and comments. It is necessary to ensure authorized users have all the JCFS classes added correctly.

## Answer

Please follow the steps at the documentation [Create Jira issues and associate buttons are visible to Jira admins only](https://appfire.atlassian.net/wiki/spaces/470745117/pages/1463976474/Create+Jira+Issues+and+Associate+buttons+are+visible+to+admins+only?atlOrigin=eyJpIjoiM2RmMWI5MmM4YmRmNDg4Mjg5ZGYyZWVlZTE2ZWUxMjkiLCJwIjoiYyJ9).

We have clearly highlighted how to add these apex classes to the impacted user profile. This will enable the user to see all Jira issues and comments.
