## **Enhancements**

### JIRA CLOUD Delete invalid mappings

We've added the **Delete all invalid** button to help you quickly remove invalid mappings. When you select **Show only invalid mappings**, you can remove every entity mapping with an unavailable Jira work item type or Salesforce object type in one click, instead of deleting them one by one.

The button only removes entity mappings that can no longer work. It keeps valid mappings that contain invalid field mappings, so you can fix those field mappings yourself.
