# Release notes 28 July 2026

**Release date**: July 28, 2026

This page outlines the updates included in the latest release of Connector for Salesforce & Jira Cloud.

**Marketplace** **version:** 27.2.0

---

## Jira Cloud Bug fixes

- **Bulk Operation:** Fixed an issue where pushing updates to Salesforce using the Bulk Operation option didn’t update the expected fields in Salesforce. Bulk pushes now synchronize all fields for selected work items as expected.
- **Security fixes**: Security vulnerability fixes have been added.
- **Data Center to Cloud migration status:** Migrations that have stalled without updates are now shown as **Failed** in the Migration Hub after 10 minutes of inactivity. They no longer remain stuck in an **In Progress** state. This makes it clear that the migration can be safely retried.
