# Get started for users

When you open Connector for Salesforce in Jira, the **Get started** page guides you through the key features and helps you quickly set up your first association.

## Before you start

- You must be a Jira user with the Edit Issue permission.
- Your administrator has created a [binding between Jira space and a Salesforce connection](/cms_trial/space/CSFJIRA/1873379785/Bind+a+space+to+a+connection+(Jira+Cloud)/).

## Associate Jira issue with a Salesforce record

Associating a Jira issue with a Salesforce record creates a direct link between the two, making it easy to track progress, share updates, and maintain visibility across teams. Instead of switching between systems or manually sharing updates, you can access relevant information from within Jira or Salesforce.

1. Click **Associate Jira issue.**

   ![image-20260320-061229.png](/cms_trial/assets/9508fce4-ba7e-478c-841b-d3599ff8d099.png)
2. In the **Associate Jira issue** window, search for a Jira issue you want to associate.
3. Select the issue.
4. Click **Go to Jira issue.**  
   The selected Jira issue opens.
5. Go to the **Connector for Salesforce Associations** tab.

Follow the detailed instructions to [associate a Salesforce record from Jira](/cms_trial/space/CSFJIRA/3092284964/Associate+a+Salesforce+record+from+Jira/).

## Bulk associate from Jira

If you manage multiple Jira issues related to a single Salesforce record, the bulk association feature helps you save time by linking multiple issues simultaneously. This is especially useful for large projects where different Jira issues correspond to different aspects of a Salesforce case, opportunity, or account.

1. Click **Associate Jira issue**.
2. Search and select a Jira issue you want to associate in the **Associate Jira issue** pop-up window.
3. Click **Go to Jira issue.**  
   The selected Jira issue opens.
4. Go to the **Connector for Salesforce Associations** tab.

Follow detailed instructions to [Bulk association from Jira](/cms_trial/space/CSFJIRA/3091432552/Bulk+association+from+Jira+Cloud/).

## Create a Salesforce record from Jira

You can also create a Salesforce record directly from Jira.

1. Click **Associate Jira issue**.
2. Search and select a Jira issue for which you want to create a Salesforce record in the **Associate Jira issue** pop-up window.
3. Click **Go to Jira issue.**  
   The selected Jira issue opens.
4. Go to the **Connector for Salesforce Associations** tab.

Follow detailed instructions to [Create a Salesforce record from Jira](/cms_trial/space/CSFJIRA/3091465546/Create+a+Salesforce+record+from+Jira/).
