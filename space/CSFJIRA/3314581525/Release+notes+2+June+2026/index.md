## Enhancements

## Jira Cloud Chat support

The support chat is now available across all admin and user pages.

- For admin pages, click the **Appfire** (▢) button and select **Chat with support**.

  ![Chat with support for admins](/cms_trial/assets/7823a773-2067-4ba8-9111-9f620b5353a9.png)
- For user pages, click the **Help** (**?**) button and select **Chat with support**.

  ![Chat with support](/cms_trial/assets/ee2faee4-7a6c-48fc-b789-0d7a3c370c69.png)

This upgrade provides a more reliable and consistent support experience directly within the app.
