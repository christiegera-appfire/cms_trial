# Work with comments

This page documents features regarding comments in Connector for Salesforce & Jira.

Using the Connector, you can view Salesforce comments in Jira, or vice versa. The comments are not synchronized into native comments in the opposite system but instead are displayed as read-only.

Note that administrators can configure a number of [Connection settings](/cms_trial/space/CSFJIRA/1853653945/Configure+connection+settings/) to control comment privacy and visibility.
