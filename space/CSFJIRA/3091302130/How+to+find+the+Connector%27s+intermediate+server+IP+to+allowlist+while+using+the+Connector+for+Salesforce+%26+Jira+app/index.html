How to find the Connector's intermediate server IP to allowlist while using the Connector for Salesforce & Jira app

6 min read

When utilizing the Connector for Salesforce & Jira Cloud, we employ the following intermediary server as the Remote Site in Salesforce.

Depending on your data residency, you need to add a US or EU Jira instance:

  • https://sfjc.integration.appfire.app/

  • https://eu-sfjc.integration.appfire.app

To comply with security policies, it can be necessary to allowlist the intermediary server to establish a successful connection between Jira and Salesforce.

The sfjc.integration.appfire.app intermediary server is hosted in the AWS us-west-2 region; you should allowlist the following AWS IPs:
