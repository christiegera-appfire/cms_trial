# How to add fields to Jira issues Lightning components

## Purpose

This article explains how to add and configure fields displayed on the Salesforce Lightning components.

## Answer

You can configure the available fields on the installed package. The configurable fields are highlighted below:

![contentId-1596752516](/cms_trial/assets/5444956c-4e40-493e-b43b-ca646fbc7394.png?version=1&modificationDate=1678856755031&cacheVersion=1&api=v2)

In the Salesforce package (Salesforce Setup > Installed Packages > JIRA Cloud for Salesforce, click on the **Configure** link), you will find a section called **Available Fields**, as shown in the image below:

Fields cannot be re-ordered by dragging the fields.  The Salesforce user must delete the fields then re-add them according to the correct sorted order.

![contentId-1596752516](/cms_trial/assets/1b3e6e1b-a0a5-4f39-a0bc-3911e45a6817.png?version=1&modificationDate=1678856754902&cacheVersion=1&api=v2)

This section shows you what fields are being displayed in the lightning component. Also, you can add fields by pressing the **Add Jira Fields** button and looking for the field available on Jira that you want to add.

![contentId-1596752516](/cms_trial/assets/2d31601c-79c9-4105-abb0-90df5932f3a3.png?version=1&modificationDate=1678856754966&cacheVersion=1&api=v2)

Once you've added the wanted field to the available fields, this can be confirmed by going back to the Lightning component and checking if the field has been added. In this example you can see that the **Reporter** field was added.

![image-20241213-123929.png](/cms_trial/assets/42a838db-f0d8-435a-a526-24a228f98141.png)
