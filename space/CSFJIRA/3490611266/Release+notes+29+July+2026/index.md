## Salseforce Jira Cloud **Enhancements**

## **Rich text in comments**

- Connector for Salesforce & Jira now supports rich text formatting in the Jira Comments (Next Gen) component in Salesforce, synchronizing it and displaying it in Jira under the Salesforce Comments option. Formatted comments created in Salesforce, including styles and tables, appear rendered in Jira and in the Salesforce connector panel.   
  Images in rich text comments are displayed inline when hosted on Salesforce domains. Images hosted elsewhere appear as links instead.  
  To learn more about comments, see [Work with Jira comments (NextGen) with Lightning Experience](/cms_trial/space/CSFJIRA/1873478551/Work+with+Jira+comments+(NextGen)+with+Lightning+Experience/)

## Object types

- We are using Salesforce API version 67: the latest Salesforce object types are now available in Connector for Salesforce & Jira.

## In-app banner for Connect versions

- We added an in-app banner to announce that the latest version of Connector for Salesforce & Jira fully runs on Atlassian Forge. This is a reminder to customers running on Connect, to upgrade to the latest version.
