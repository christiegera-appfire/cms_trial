# Work with associations

This page documents features regarding associations in Connector for Salesforce & Jira.

An association is a core element in the integration features provided by the Connector. It functions as a link between a Jira issue and a Salesforce object when there is a need to share, retrieve, send, or view information between the two systems.

Associations can be created and configured both in Jira and Salesforce. Plus, any Jira issue or Salesforce object created through the Connector, is also an association by default.

To do this in Jira, see:

- [Create a Salesforce record from Jira](/cms_trial/space/CSFJIRA/3091465546/Create+a+Salesforce+record+from+Jira/)
- [Associate a Salesforce record from Jira](/cms_trial/space/CSFJIRA/3092284964/Associate+a+Salesforce+record+from+Jira/)

To do this in Salesforce, see:

- [Create a Jira Issue from Salesforce](/cms_trial/space/CSFJIRA/3091792703/Create+a+Jira+work+item+from+Salesforce/)
- [Associate a Jira Issue from Salesforce](/cms_trial/space/CSFJIRA/3091301556/Associate+a+Jira+Issue+from+Salesforce/)

You can configure the behavior of each association. See [Configure an association](/cms_trial/space/CSFJIRA/3091956652/Configure+an+association/).

Each Jira issue can be associated with a maximum of 1000 Salesforce records due to a storage limitation imposed by Jira Cloud.
