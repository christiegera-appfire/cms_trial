## Answer

To ensure

is functioning correctly, please ensure the Project Role (*atlassian-addons-project-access*) has all permissions for Jira projects.

1. Locate **Projects** and open the Project desired to configure the Permissions.
2. In the sidebar, click **Project Settings >** **Permissions**.
3. Ensure that the *atlassian-addons-project-access* roleis granted with all permissions.  
   If not, edit the permission scheme and add the role.
