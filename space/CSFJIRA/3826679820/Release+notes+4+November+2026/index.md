# Release notes 4 November 2026

**Release date**: November 4, 2026

This page outlines the updates included in the latest release of Connector for Salesforce & Jira Cloud.

**Marketplace version:** 29.15.0

---

## JIRA CLOUD Enhancements

### Improved scrolling in the binding wizard

In the binding create and edit wizards, long content previously made the whole page scroll. Each section now scrolls independently, so key controls and context stay visible.

---

## JIRA CLOUD Bug fixes

- Fixed an issue where Jira and Salesforce values could appear in the wrong columns when configuring value mappings. Value mappings now retain the correct values, preventing synchronization errors.
- Fixed an issue where creating a Jira work item from Salesforce could fail with a validation error when an empty Salesforce text field was mapped to an optional Jira User Picker field.
