## **Enhancements**

### JIRA CLOUD Easier troubleshooting of invalid bindings and mappings

We've added new filters to help you quickly identify and resolve invalid bindings and mappings.

Use **Show only invalid bindings** on the Bindings page to find bindings that contain invalid configuration. Within a binding, use **Show only invalid mappings** to locate affected entity and field mappings.

![image-20261027-094056.png](/cms_trial/assets/c26b8df2-3683-4e7b-8636-01d02e1e4755.png)

This is especially useful when Jira or Salesforce configuration changes, or after migrating from Jira Data Center to Jira Cloud.

For more information, see [Troubleshoot invalid bindings and mappings](/cms_trial/space/CSFJIRA/3784114479/Troubleshoot+invalid+bindings+and+mappings/).

## JIRA CLOUD **Bug fixes**

- Fixed an issue where pushing updates from Jira to Salesforce could fail silently after a Salesforce domain change. Domain changes are now handled more reliably and provide clearer feedback if reconnection fails.
