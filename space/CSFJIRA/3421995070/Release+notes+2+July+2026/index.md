# Release notes 2 July 2026

**Release date**: July 2, 2026

This page outlines the updates included in the latest release of Connector for Salesforce & Jira Cloud.

**Marketplace** **version:** 21.0.0

## Jira Cloud Bug fixes

- Added progress tracking for Connector for Salesforce & Jira migrations on the Migration Hub, enabling admins to identify when a JCMA migration from Data Center to Cloud has stalled and initiate a retry.
- We've fixed an issue where custom fields and their data failed to migrate correctly for JSM-managed projects during the app upgrade.
