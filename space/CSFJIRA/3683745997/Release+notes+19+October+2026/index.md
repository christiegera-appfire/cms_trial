# Release notes 19 October 2026

**Release date**: October 19, 2026

This page outlines the updates included in the latest release of Connector for Salesforce & Jira Cloud.

**Marketplace version:** 29.1.0

---

## Bug fixes

- JIRA CLOUD **JCMA migration**: Connections migrated from Data Center to Cloud were missing their Salesforce instance URL and environment, and these values could not be edited afterward. Migrated connections now keep the same Salesforce instance URL and environment as in Data Center.   
  As before, they remain unauthorized after migration and need to be re-authorized.
