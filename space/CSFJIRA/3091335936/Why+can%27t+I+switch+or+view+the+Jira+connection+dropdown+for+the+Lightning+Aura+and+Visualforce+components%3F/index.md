# Why can't I switch or view the Jira connection dropdown for the Lightning Aura and Visualforce components?

## Purpose

The Jira Issues and Jira Comments components do not have the option to switch the Jira connection via the dropdown option as shown in the following screenshot.

![image-20241213-094024.png](/cms_trial/assets/f4c83586-7bd1-47c3-b876-3d789d60aee7.png)

## Answer

Only default connections will be shown in the Lightning Aura and VisualForce components. The connection shown can be confirmed by hovering over the ℹ️ tool tip.

To change the default connection, read [How do I connect more than one Jira connection in my Salesforce environment?](/cms_trial/space/CSFJIRA/3091827403/How+do+I+connect+more+than+one+Jira+connection+in+my+Salesforce+environment%3F/)
