# How do I change the Issue Type order in the Salesforce Create Jira issue screen?

## Purpose

While creating a Jira Issue in Salesforce, you may want to have the **Issue Type** dropdown menu options in a specific order.

![contentId-1596588728](/cms_trial/assets/5c2313fa-c284-45e6-872a-d619a537a9c5.PNG)

## Answer

You can reorder them in the **Issue Type Scheme** configuration of your Project.

1. In Jira, click ▢**Setting** > **Work items** > under **Work types**, click **Work type schemes.**
2. In the *Work type scheme* window, under **Actions**,click **Menu** and select**Edit.**

   ![work type schemes.png](/cms_trial/assets/4987d49f-5600-4130-ba37-5807aa16b26d.png)
3. Change the order by dragging the issue type in the **Issue Types for Current Scheme** section.

   ![2025-08-07_08-28-57.png](/cms_trial/assets/75efb19e-4f08-4739-9242-071da7db42c7.png)
