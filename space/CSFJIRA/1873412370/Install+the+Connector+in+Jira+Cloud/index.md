# Install the Connector in Jira Cloud

Install the **Connector for Salesforce and Jira** in your Jira Cloud instance, ensuring a seamless setup for integrating the two platforms.

## Before you start

- You must be:

  - An admin of the Jira Cloud instance.
  - Either a technical contact or billing contact of the Jira Cloud instance. To verify, log in to [MyAtlassian](https://my.atlassian.com) and ensure the Jira Cloud instance appears on the **Licenses** page.

**Data location setup (optional):** You can store your data in a specific geographic region, but only during initial installation. The location cannot be changed later or during reinstallation.

To set your preferred location:

1. Configure your Jira instance data residency location.
2. Install the Connector (it will automatically use your Jira instance location).

For more details, see [Data residency and realm persistence](https://appfire.atlassian.net/wiki/x/XQCbhg).

For installations related to Salesforce and Jira Service Management, review [Working with Jira Service Management projects](/cms_trial/space/CSFJIRA/1873510574/Work+with+Jira+Service+Management+projects/).

## Steps

1. Log into your Jira Cloud admin page.
2. Go to **Site settings** > **Connected apps**.
3. Click **Explore apps**.
4. In the **Search for apps** field in Marketplace, enter `Connector for Salesforce & Jira`.
5. Select the app when it appears in the results list.
6. Click **Try it free** to download and install your add-on.
7. Select a site where you want to install it.
8. Click **Review** and  **Start free trial**.
9. If you're using Jira Service Management, refer to  [Working with Jira Service Management projects](/cms_trial/space/CSFJIRA/1873510574/Work+with+Jira+Service+Management+projects/) for more information.

## Next steps

Once you’ve installed Connector on Jira, switch to Salesforce and [Install the Salesforce Package](/cms_trial/space/CSFJIRA/1758232704/Install+the+Salesforce+package+in+Salesforce/). Installing the Salesforce Package allows the Connector on your Jira instance to interface with Salesforce properly.

If you have already installed the Salesforce Package, proceed to [Set up a connection to Salesforce](/cms_trial/space/CSFJIRA/1873772649/Set+up+your+integration+in+Salesforce/).
