## New features

## Natural language search for Extended Search - Beta

You can now use natural language prompts to search for issues without prior knowledge of JQL functions and syntax.

To try it out, go to the *Extended Search* page, select the **AI** **Search** option, then describe what you are looking for. For example, `I am looking for the epics of all the tasks that are due next month`.

![Screenshot of JSE's Extended Search page with the AI Search option selected.](/cms_trial/assets/95acb31a-6275-4111-86fb-3ed708d34ff7.png)

See [Natural language search - Beta](/cms_trial/space/JQLSEARCH/2225438776/Natural+language+search+-+Beta/) to learn more.
