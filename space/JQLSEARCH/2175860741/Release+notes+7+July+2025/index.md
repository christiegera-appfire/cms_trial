# Release notes 7 July 2025

**Release date**: July 7, 2025

Our team is pleased to announce the latest release of JQL Search Extensions for Jira Cloud.

---

## Enhancements

## JSE shortcut added to Jira Apps menu

You can now access JSE from the Apps menu in the left sidebar of Jira, providing faster navigation to all app features.

![Screenshot of the JSE app menu in the left sidebar in Jira.](/cms_trial/assets/27f1cba3-9356-49b5-ab03-7def9e54de69.png)

## Bug fixes

The following bug fix is included in this release summary:

- Escape characters in regular expression (Regex) functions are correctly processed. Previously, they returned a validation error.
