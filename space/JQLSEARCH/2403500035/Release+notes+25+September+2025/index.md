# Release notes 25 September 2025

**Release date**: September 25, 2025

Our team is pleased to announce the latest release of JQL Search Extensions for Jira Cloud.

---

## Enhancements

### Filter scheduling

We improved the performance of the filter indexing process so that filters are indexed exactly every three minutes. If an indexing cycle takes longer than three minutes, the next indexing process will begin only when the previous one is finished.
