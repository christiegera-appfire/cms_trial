# Release notes 11 February 2025

**Release date**: February 11, 2025

Our team is pleased to announce the latest release of JQL Search Extensions for Jira Cloud.

---

## Bug fixes

The following bug was fixed in this release:

- Resolved an issue where detached parent issues were not re-indexed if a child issue was moved or deleted. This affected the keywords that use the parent-child relationships to return issues.
