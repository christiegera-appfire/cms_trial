# Release notes 9 December 2025

**Release date**: December 9, 2025

Our team is pleased to announce the latest release of JQL Search Extensions for Jira Cloud.

---

## Bug fix

The following fix is included in this release summary:

### **Extended Search Filters page**

- Resolved an issue that caused a limit of 50 owners available in the Owner filter dropdown. Now, when a user selects the filter owner option, the list is refreshed and the full list of owners displays.
