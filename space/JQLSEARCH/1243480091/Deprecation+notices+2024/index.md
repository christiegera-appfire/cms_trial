# Deprecation notices 2024

---

### September 30, 2024

## Deprecated keywords

From September 30, 2024, the`movedProjects`and`movedProjectsCount`keywords are not supported for new customers in the latest version of the app. They will not be indexed and using them in a query will not return any issues. New customers will see the keywords in the cheat sheet with a deprecated status.

This release does not impact existing customers. Please contact our support team if this change causes any issues. Refer to our [full list](/cms_trial/space/JQLSEARCH/604209395/JQL+functions+and+keywords+reference/) of JQL keywords and functions to learn more about how JQL Search Extensions delivers more precision and clearer project insights to your Jira instance.
