# Get started with JQL Search Extensions for Jira

JQL Search Extensions (JSE) expands Jira's search capabilities with additional JQL keywords and functions, allowing you to find work items using criteria that aren't available through standard JQL. JSE remembers your queries and delivers fast, precise search results. You can save your queries as filters for future searches and reuse them across other Appfire apps. ## Before you begin

You should be familiar with the basic structure of Jira Query Language (JQL) to follow the examples in this guide. [Refer to this page](https://support.appfire.com/space/JQLSEARCH/2225438776/Natural+language+search+-+Beta) for more information about building queries with JQL.

If you are new to JQL queries, please review [this Atlassian Support page.](https://support.atlassian.com/jira-software-cloud/docs/use-advanced-search-with-jira-query-language-jql/)

Follow the guides in this section to:

- [Install and prepare JQL Search Extensions](/cms_trial/space/JQLSEARCH/3677651309/Copy+-+Install+JQL+Search+Extensions+and+start+indexing/)  
  Install JSE and make sure your Jira data is ready to search.
- [Run your first extended JQL search](/cms_trial/space/JQLSEARCH/3680174082/Run+an+extended+JQL+search/)  
  Use a JSE keyword to find issues based on information that isn't available through standard JQL.
- [Search related issues with a JSE function](/cms_trial/space/JQLSEARCH/3680174342/Find+work+items+linked+to+epics/)  
  Use a JSE function to perform a more advanced search across related issues.
- [Save and reuse an extended search](/cms_trial/space/JQLSEARCH/3680174212/Save+and+reuse+an+extended+search/)  
  Save a successful extended search as a filter so you can reuse it.
