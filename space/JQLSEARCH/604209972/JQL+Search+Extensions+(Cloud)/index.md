# JQL Search Extensions (Cloud)

JQL Search Extensions for Jira Cloud (JSE) adds 50+ JQL functions and keywords not available in native Jira advanced search to improve the speed, precision, and relevance of your issue searches. Your queries can be saved as filters and used anywhere you would use a standard Jira filter.

## What’s the difference between Extended Search and Jira’s advanced search?

### **Extended Search**

Extended Search is JSE’s issue search feature for Jira Cloud. Here, you can expand on Jira’s native search using JSE functions and keywords, save your queries as [filters](/cms_trial/space/JQLSEARCH/604209567/Extended+Search+filters/). You can use these filters in future searches and reporting and in other third-party apps.

To open the *Extended Search* page, in the top navigation bar in Jira, select **Apps** > **JQL Search Extensions for Jira**. Go to the [*Extended Search*](/cms_trial/space/JQLSEARCH/604209464/Extended+Search/) topic to learn more.

JSE Cloud functions can only be used in the Extended Search page.

### **Advanced search**

Advanced search is Jira’s native JQL issue search feature. It lets you search across all projects in your instance using Jira Query Language (JQL). You can save your queries as filters then use them in reporting features and share them with others to facilitate their searching and reporting tasks. JSE Cloud keywords can be used in Extended Search and Advanced search.
