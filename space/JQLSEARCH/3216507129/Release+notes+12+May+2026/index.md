# Release notes 12 May 2026

**Release date**: May 12, 2026

This page outlines the updates included in the latest release of JQL Search Extensions (JSE).

---

## New features

### **Use JQL Search Extensions custom functions in native Jira search**

You can now use JQL Search Extensions (JSE) custom functions directly in Jira advanced search.

Previously, JSE custom functions only worked on the **Extended Search** page. Using them in Jira advanced search resulted in an error.

![JSE-custom-jql-function-error.png](/cms_trial/assets/c65418bf-80c6-48e6-ba08-70ed7bbf2529.png)

You can now enter JSE custom functions directly into Jira advanced search. The app translates these functions into native JQL, so you can search without leaving your Jira search.

![JSE-jql-custom-function-success.png](/cms_trial/assets/5c965801-5a80-4272-8216-3dc4f44a302f.png)

JSE custom functions also work with other Appfire apps that use Jira advanced search, such as **Jira Misc Workflow Extensions (JMWE)** and **BigPicture**.

Jira search requests time out after 25 seconds. If a query exceeds this limit, JSE continues processing it in the background. Run the search again after a few minutes to view the result.
