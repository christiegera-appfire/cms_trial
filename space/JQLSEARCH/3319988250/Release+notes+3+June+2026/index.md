# Release notes 3 June 2026

**Release date**: June 3, 2026

This page outlines the updates included in the latest release of JQL Search Extensions (JSE).

---

## Enhancements

### **Use JQL Search Extensions for enhanced AI Search**

JQL Search Extensions (JSE) expanded function guides and examples help AI Search generate more accurate and consistent JQL syntax.

![AI Search interface showing a natural-language query and the generated JQL search syntax.](/cms_trial/assets/369b50ad-d07b-484e-a41d-f3fd5213080c.png)

### **Use JQL Search Extensions AI Search with enhanced Natural Language Query**

JQL Search Extensions (JSE) AI Search now better interprets complex relationships and user intent in natural language queries. Enhanced AI decision-making improves query interpretation and helps deliver more relevant results. AI Search also supports natural language queries in multiple languages.

### Get started section - tutorial availability in restricted environments

Added a fallback for the app’s *Get started* embedded product tutorial when iframe content is blocked. If the tutorial content can’t load, the app now displays alternate guidance instead of a blank or broken frame.
