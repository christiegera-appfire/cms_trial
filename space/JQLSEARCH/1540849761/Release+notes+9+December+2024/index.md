# Release notes 9 December 2024

**Release date**: December 9, 2024

Our team is pleased to announce the latest release of JQL Search Extensions for Jira Cloud.

---

## Bug fixes

The following bug was fixed in this release:

- The indexing process in JQL Search Extensions now runs successfully on instances where the [issue linking](https://support.atlassian.com/jira-cloud-administration/docs/configure-issue-linking/) feature is turned off.
