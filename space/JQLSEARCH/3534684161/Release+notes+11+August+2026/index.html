Release notes 11 August 2026

1 min read

Release date: August 11, 2026

This page outlines the updates included in the latest release of JQL Search Extensions (JSE).

Enhancements

The following enhancements are included in this release:

Forge migration

JQL Search Extensions now runs on Atlassian Forge, Atlassian’s Cloud development platform. This release brings enhancements to meet Forge’s technical and security standards.

Moving to Forge allows JQL Search Extensions to use Atlassian's built-in security, compliance, and scalability features. This migration helps Appfire continue delivering secure, enterprise-grade apps that stay aligned with Atlassian's platform.

Connect End of Support

  • Atlassian has announced the end of support for the Connect framework at the end of 2026.

  • For more information about the Connect end-of-support timeline, see Announcing Connect End of Support: Timeline and Next Steps.
