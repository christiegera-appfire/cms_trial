# Release notes 17 December 2025

**Release date**: December 17, 2025

Our team is pleased to announce the latest release of JQL Search Extensions for Jira Cloud.

---

## Bug fix

The following fix is included in this release summary:

### **Global permissions in Jira**

- Following updates to our app architecture, we introduced an issue where the JSE app was not available to admins in Jira’s *Global Permissions* page. This has been resolved, and admins can set permissions for JSE’s Extended Search using Global Permissions.
