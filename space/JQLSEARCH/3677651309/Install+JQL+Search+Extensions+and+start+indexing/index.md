# Install JQL Search Extensions and start indexing

Before you can use JQL Search Extensions (JSE), install the app and allow it to index your Jira data. JSE uses indexed Jira data to support its extended JQL keywords and functions. Initial indexing starts automatically after installation.

To install the JQL Search Extensions, you must be a Jira administrator.

1. Log in to your Jira instance as an administrator.
2. From the Jira administration menu, go to **Apps**.
3. Find [**JQL Search Extensions for Jira**](https://marketplace.atlassian.com/apps/1214791/jql-search-extensions-for-jira?hosting=cloud&tab=overview) in the Atlassian Marketplace.
4. Select the app.
5. Select **Try it free**.
6. Follow the prompts to start your free trial and install the app.
7. After installation, go to **Manage apps** and open JQL Search Extensions.
8. Select **Get started**.

![The JQL Search Extension Marketplace page](/cms_trial/assets/b9e783cc-6298-4cfc-91f2-bc2eb7531bf5.png)

JQL Search Extensions automatically begins indexing your Jira data.

## Prioritize projects for indexing

After installation, JQL Search Extensions automatically begins indexing your Jira data. The time required for initial indexing depends on your Jira instance size. You can prioritize up to five projects for initial indexing.

Start using JSE with those projects before the entire Jira instance is indexed. Choose projects that contain issues you can use while following the examples in this Get Started guide.

If you use JSE while initial indexing is still in progress, searches include only data already indexed. Your search results may therefore be incomplete. Also, after prioritized indexing starts, you can’t add or remove projects from the prioritized list.

## Check indexing progress

You can monitor indexing progress from the JQL Search Extensions **Get Started** page. Wait until the project you want to use for the following examples has been indexed before continuing.

![JQL Search Extensions indexes projects after installation.](/cms_trial/assets/5314f8cc-83c0-4d93-b372-20706802da6d.png)

You’re ready to continue when you have:

- Installed JQL Search Extensions.
- Opened the app successfully.
- Indexed at least one project that contains issues you can search.

Click **Start searching** to run your first extended JQL search and see how JSE expands what you can find in Jira. Visit the [Run an extended JQL search](/cms_trial/space/JQLSEARCH/3680174082/Run+an+extended+JQL+search/) page for an example.
