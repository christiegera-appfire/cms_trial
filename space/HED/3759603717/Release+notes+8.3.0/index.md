# Release notes 8.3.0

**Release date**: October 15, 2026

This page outlines the updates included in Hedge 8.3.0.

---

## Enhancements

This release includes the following enhancement.

### Copy settings from an existing risk register

When you create a risk register, you can now copy the configuration from another register instead of setting up each option from scratch. This helps you keep configurations consistent across registers. Choose an existing register during creation to copy its risk calculations, matrix settings, issue types, and columns. For more details, see [Copy a risk register configuration](https://support.appfire.com/space/HED/3759734785/Copy+a+risk+register+configuration).
