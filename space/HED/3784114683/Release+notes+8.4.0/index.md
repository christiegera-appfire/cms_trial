# Release notes 8.4.0

**Release date**: October 19, 2026

This page outlines the updates included in Hedge 8.4.0.

---

## Enhancements

This release includes the following enhancement.

### Display more than 10 risk registers per page

You can now display more than 10 risk registers per page in the risk register list. Choose 10, 20, 35, or 50 risk registers per page, so you can review more registers without paging through the list.
