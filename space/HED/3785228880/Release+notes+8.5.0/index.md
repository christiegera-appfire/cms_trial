# Release notes 8.5.0

**Release date**: October 22, 2026

This page outlines the updates included in Hedge 8.5.0.

---

## Enhancements

This release includes the following enhancement.

### Define a risk register's scope with a JQL query

You can now narrow a risk register's scope with a Jira Query Language (JQL) query, instead of filtering by work item type only. This lets you split risks into separate registers by department, component, team, priority, or any other criteria, without creating extra work item types. When you create a register or edit its settings, you still select one or more projects, and you can optionally choose work item types and add a JQL query. Hedge combines all three with AND to decide which risks appear in the register. For more details, see [Create risk register](https://support.appfire.com/space/HED/2292088952/Create+risk+register) and [Customize the risk register](https://support.appfire.com/space/HED/602865672/Customize+the+risk+register).
