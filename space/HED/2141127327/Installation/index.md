# Installation

To install Hedge, you must have Administrator Global Permissions.

1. Go to **Apps** > **Find new apps**. The Atlassian Marketplace page displays.
2. Search for and select Hedge.
3. Click **Try it free**. The *Add to Jira* window displays. Alternatively, click [here](https://marketplace.atlassian.com/apps/1227408/hedge-risk-management-risk-register-risk-matrix-for-jira?hosting=cloud&tab=overview) to go to the Hedge marketplace listing.
4. Click **Start free trial**. You will be notified when the installation is completed.
