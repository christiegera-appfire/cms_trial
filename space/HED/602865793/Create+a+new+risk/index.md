# Create a new risk

In Hedge, you can assess any type of Jira issue as a risk, or you can use the default type called *Risk* that is automatically generated for Company-managed projects.

## Create new risk

1. Click the **Create new risk**button in the top right corner of the Risk Register.
2. Select the projects where you would like to create a risk.
3. Select theissue types you would like to log as risk.
4. Fill in the summary and click the **Create** button.

Risk will then appear in the Risk Register.

![create new risk button and fields](/cms_trial/assets/b935f186-9eda-4016-be78-5552ad7e49ec.png)

If you select an issue type with required fields, such as Epics, Jira automatically opens the issue creation panel, and you can create the risk from there.
