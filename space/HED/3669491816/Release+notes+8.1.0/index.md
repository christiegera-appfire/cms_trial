# Release notes 8.1.0

**Release date**: September 16, 2026

This page outlines the updates included in the latest release of Hedge.

Version: 8.1.0

---

## Enhancements

### Display more than 10 risks per page

You can now display more than 10 risks per page in the risk register. Choose 10, 25, 50, or 100 risks per page.

### Filter state is saved per user

The filter state for the risk register is now saved per user. Leaving and returning to the risk register no longer clears your column list, active filters, sorting options, or number of entries per page.
