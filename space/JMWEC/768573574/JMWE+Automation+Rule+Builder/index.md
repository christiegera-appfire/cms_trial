# JMWE Automation Rule Builder

![admin-EventBasedActionEditorClean.png](/cms_trial/assets/2226343f-46c1-4fc1-89f0-05bfb4462f04.png)

The **JMWE Automation Rule Builder** is an improved editor for building and visualizing actions for your workflows, including [Shared Actions](/cms_trial/space/JMWEC/466288975/Shared+actions/), [Scheduled Actions](/cms_trial/space/JMWEC/466321868/Scheduled+actions/), and [Event-based Actions](/cms_trial/space/JMWEC/465473524/Event-based+actions/). The new, two-panel layout simplifies the configuration of actions by separating the components of the action into categories on the left, and each category's configurations on the right. Using a `WHEN-IF-THEN` format, each automation rule is clearly laid out and can be created or updated quickly.

## Where is the Automation Rule Builder?

Currently, the Automation Rule Builder is available when configuring [Shared Actions](/cms_trial/space/JMWEC/466288975/Shared+actions/), [Scheduled Actions](/cms_trial/space/JMWEC/466321868/Scheduled+actions/), and [Event-based Actions](/cms_trial/space/JMWEC/465473524/Event-based+actions/). All actions - new and existing - use the new Automation Rule Builder interface. Do not worry, the updates are to the interface only! All existing actions have been preserved and can be updated without issue.

## How does the Automation Rule Builder Work?

Each of the different actions implement the Automation Rule Builder in a slightly different way; please refer to their specific documentation for specific instructions.

Overall, the new UI is split into two side-by-side panels. The left panel is the outline of the action, formatted in a `WHEN-IF-THEN` format, includes the general configuration categories (e.g. the **Schedule** for a Scheduled Event or the triggering **Event** for an Event-Based Action). The left panel also includes general configuration options for each of the categories. When you select a configuration category in the left panel, the right panel will display the specific configuration options for that category.

## Feature Requests

![admin-FeatureRequest.png](/cms_trial/assets/0757d436-0113-4f0a-95ca-9dfe9049f7b5.png)

The new Automation Rule Builder includes and updated feedback form for making feature requests of the development team. Using this form, you can now provide feedback on the functionality of the Automation Rule Builder!

The **JMWE Feature Request** form (pictured, left) is located at the bottom of the right panel of the Automation Rule Builder. Clicking the **Let us know** link will open the form.
