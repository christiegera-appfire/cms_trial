JMWE for Jira Cloud 1.2.23-AC Release Notes

1 min read

This version, released on August 7, 2023, brings the following changes:

Improved Cloud Migration Process - Expanded JCMA Support!

This version of JMWE for Jira Cloud brings much improved support for migration from Jira Data Center/Server to Jira Cloud. Improvements include expanded support for Jira Cloud Migration Assistant (JCMA) to complete a more thorough migration of your Data Center/Server instance to a new Cloud instance. Additionally, this update includes improved tools for post-migration checks.

Along with improvements to pre- and post-migration, this release includes greatly expanded support for migrating JMWE data and configurations, including:

  • JMWE Extensions (Conditions, Post-functions, and Validators)

  • Shared Actions

  • Scheduled Actions

  • Event-based Actions

Bug fixes
