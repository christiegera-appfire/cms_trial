# Limited support for Internet Explorer 11

## Problem

Atlassian officially retired support for Internet Explorer 11 in Jira Cloud on March 31, 2020. See this [Atlassian Blog post](https://blog.developer.atlassian.com/retiring-ie11-support-for-atlassian-cloud-server-and-data-center-products/) for details.

As a result, some JWME workflow extension configuration screens don’t fully work when using Internet Explorer 11.

## Solution

Use another [supported browser](https://confluence.atlassian.com/cloud/supported-browsers-744721663.html) such as Microsoft Edge, Google Chrome or Firefox.
