# Get ID of a Priority

This article provides the steps to retrieve the ID of a Priority on Jira Cloud.

## \uD83D\uDCD8 Instructions

Here, we’re retrieving the ID of “Medium” Priority.

1. Log in as a Jira admin in your cloud instance.
2. Click on the admin icon (cog wheel) at the top right and click on “Issues”.

   ![JMWE for Jira Cloud field configuration panel for priority and option settings](/cms_trial/assets/0533ebcc-3534-4fff-9361-43553bfb2f38.png)
3. Click on “Priorities” under “ISSUE ATTRIBUTES” in the left panel.

   ![Priority options list for JMWE for Jira Cloud field configuration](/cms_trial/assets/679035d4-0d47-4dbe-b4f3-81cac833f85d.png)
4. Click “Edit” next to the desired priority (“Medium” in the given screenshot).

   ![JMWE for Jira Cloud priority configuration interface with ID management options](/cms_trial/assets/cdfcae1d-ffae-445a-90fe-0e1d678e40f9.png)
5. The ID of this priority is the number after "?id=" at the end of the URL.

   ![JMWE for Jira Cloud priority field setup showing configuration and selection options](/cms_trial/assets/d2e5829d-746a-4e7d-a83d-ca33941cfae0.png)
