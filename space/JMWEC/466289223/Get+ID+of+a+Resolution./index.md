# Get ID of a Resolution.

This article provides the steps to retrieve the ID of a Resolution on Jira Cloud.

## \uD83D\uDCD8 Instructions

Here, we’re retrieving the ID of the “Declined” Resolution.

1. Log in as a Jira admin in your cloud instance.
2. Click on the admin icon(cog wheel) at the top right and click on “Issues”.

   ![JMWE for Jira Cloud resolution field configuration panel for issue management](/cms_trial/assets/c0628e85-64bf-4186-b0dd-f6e6ca38b428.png)
3. Click on “Resolutions” under “ISSUE ATTRIBUTES” in the left panel.

   ![Resolution options list for JMWE for Jira Cloud issue configuration](/cms_trial/assets/bfa982b6-e0ab-486d-93f6-8e5b06ce16b2.png)
4. Click “Edit” next to the desired resolution (here, “Declined”)

   ![JMWE for Jira Cloud resolution configuration interface with selection options](/cms_trial/assets/1977a57f-b27c-4c05-b529-cb462996b278.png)
5. The ID of this resolution is the number after "?id=" at the end of the URL.

   ![JMWE for Jira Cloud resolution field setup showing configuration parameters](/cms_trial/assets/19415885-ed28-4dc7-8014-853202153324.png)
