# Workflow Extensions for Jira Cloud

## Powerful, all-in-one Jira automation app to customize and expand your workflows

### Unlimited automations!

JMWE for Jira Cloud has no restrictions on the number of automations you run. Execute all of your workflows without concerns!

- **Unmatched collection doubles post function choices**  
  Rapidly build and configure your workflows your way with an ever-growing suite of post functions, conditions, and validators that go well beyond native Jira functionality.
- **Supercharge automations with simplified scripting**  
  With on-the-fly syntax checking, inline help, and script tester, even non-coders can easily customize workflows using [Jira expressions](/cms_trial/space/JMWEC/465241623/Using+Jira+Expressions/) or [Nunjucks](/cms_trial/space/JMWEC/465503811/Using+Nunjucks+Templates/). Or build your own conditions, validators, and post functions.
- **Automation beyond workflows**  
  Go beyond native workflow automation with:

  - [Event-based automation](/cms_trial/space/JMWEC/465473524/Event-based+actions/) triggered by field/issue changes
  - [Shared Actions](/cms_trial/space/JMWEC/466288975/Shared+actions/) to reuse post functions in workflows
  - JQL-based [Scheduled Actions](/cms_trial/space/JMWEC/466321868/Scheduled+actions/)
  - Simple Jira API for common tasks
