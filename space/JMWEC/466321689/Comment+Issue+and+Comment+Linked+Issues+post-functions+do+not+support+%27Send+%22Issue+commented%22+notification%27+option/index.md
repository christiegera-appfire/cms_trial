# Comment Issue and Comment Linked Issues post-functions do not support 'Send "Issue commented" notification' option

## Problem

Notifications triggered by the post-functions *Comment linked issues* and *Comment Issue* cannot be disabled. This is because these post-functions in Connect add-on do not support the option '`Send "Issue commented" notification`'. Therefore, workflows using these functions might generate unwanted notifications.

## Solution

None. JIRA Cloud doesn't support disabling these notifications.
