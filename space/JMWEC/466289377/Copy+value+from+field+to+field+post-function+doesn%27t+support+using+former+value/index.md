# Copy value from field to field post-function doesn't support using former value

## Problem

The *Copy value from field to field* post-function does not support the 'Use value before current transition' option. Therefore, workflows using this option won't work as before.

## Solution

None. This functionality is not supported by JIRA Cloud.
