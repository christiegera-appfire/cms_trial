## Extensions

### Additional options added to ‘Last role member’ assignment option

The Assign issue(s) post function has been updated with additional options for the ‘Last role member’ assignment behavior, adding options to include reporters, exclude the current assignee, and skip inactive users when searching for the last member to be assigned the issue. These options have been added to bring the functionality of the post function closer to its counterpart in JMWE Data Center to aid in migration to Jira Cloud. See [Assign issue(s)](/cms_trial/space/JMWEC/1133772861/Assign+issue(s)/) for more information.
