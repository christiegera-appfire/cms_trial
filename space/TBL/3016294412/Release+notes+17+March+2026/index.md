# Release notes 17 March 2026

**Release date**: March 17, 2026

Our team is thrilled to announce the latest release of Advanced Tables for Confluence.

Version: 3.2.0

---

## Enhancements

### Easy access to the Get started page

The *Advanced Tables Get started* page is now available from the **Apps** menu for quick onboarding and configuration.

To open the page, navigate to **Apps** > **Advanced Tables for Confluence**.

![Advanced Tables Get started page with Advanced Tables for Confluence option selected in the left sidebar.](/cms_trial/assets/a8ce455b-0ebd-4912-979e-31f37a30743f.jpg)

### In-app banner to update to the Forge remote version

An in-app banner now guides you to [update](/cms_trial/space/TBL/2766798931/Release+notes+February+2026/) the app to the latest **Forge remote** version.

![Table macro displaying warning banner about updating to the Forge remote version.](/cms_trial/assets/235d4f79-19c9-4395-8854-3a00460a30c5.png)

### Improved macro parameter descriptions

We updated parameter descriptions across all macros to provide a more intuitive configuration experience.

### Advanced Table Viewer macro

The **Advanced Table Viewer** macrois now fully supported and out of Beta. We continue to improve the macro with additional features in upcoming releases.
