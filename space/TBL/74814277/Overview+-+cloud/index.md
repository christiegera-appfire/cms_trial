# Overview - cloud

TheAdvanced Tables for Confluence app by Appfire, provides macros that enhance the look and feel of tables within Confluence pages. This guide contains instructions on how you can use each of the four macros to display content from multiple sources. The macros available through the app are:

- [Table Plus macro](/cms_trial/space/TBL/74812542/Table+Plus+macro+-+Cloud/) - perform advanced functions and apply formatting to Confluence tables
- [CSV Table macro](/cms_trial/space/TBL/74812384/CSV+(Comma+Separated+Values)+macro+-+Cloud/)- import, format and display comma-separated values (CSV) data
- [JSON Table macro](/cms_trial/space/TBL/74812316/JSON+Table+macro+-+Cloud/)- import, format and display JSON (JavaScript Object Notation) data
- [Attachment Table macro](/cms_trial/space/TBL/74812217/Attachment+Table+macro+-+Cloud/) - renders a table of attachments based on various selection criteria, including powerful space and page selection
- [Advanced Table Viewer macro](/cms_trial/space/TBL/1531117698/Advanced+Table+Viewer+macro/) - enables you to import and display CSV, Excel, and JSON data as a structured table, making it easier for your team to view and analyze data directly within Confluence.
