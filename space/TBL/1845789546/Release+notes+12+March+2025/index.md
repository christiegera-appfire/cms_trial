# Release notes 12 March 2025

**Release date**: March 12, 2025

Our team is thrilled to announce the latest release of Advanced Tables for Confluence.

AC version: 1.2.18-AC

---

## Hot fixes

The following are the hotfixes in this release:

- Resolved the issue faced with the attachments and images in the Table Plus macro.

  - Clicking an attachment now opens the file without redirecting to an unexpected URL.
  - Resolved the *unknown attachment* error for images, now the images render correctly on the published Confluence page.
