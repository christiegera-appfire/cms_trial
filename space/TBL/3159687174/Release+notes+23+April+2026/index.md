# Release notes 23 April 2026

**Release date**: April 23, 2026

This page outlines the updates included in the latest release of Advanced Tables for Confluence.

Version: 7.0.0

---

## New features

## Advanced Table Viewer macro - Excel URL data source

The Advanced Table Viewer macro now supports a new Excel URL data source option, in addition to the existing Upload file and Attachment options.

### URL

- You can now import data using a direct URL of an Excel file in .xls or .xlsx format of up to 10 MB.
- Paste the direct link to your Excel file, and click **Import data**. For more information, refer to [URL](/cms_trial/space/TBL/3122888898/Configure+Excel+data+source+in+Advanced+Table+Viewer+macro/).

## Bug fixes

The following bugs are fixed in this release:

- The **Advanced Table Viewer macro** skipped importing empty columns from the CSV data source.

  - This has been resolved, and the macro imports CSV data with empty columns as expected.
- The **Attachment table macro** caused extra whitespaces to appear below the macro container in both Confluence page edit and view mode.

  - This has been resolved, and the macro no longer inserts whitespaces below the container.
