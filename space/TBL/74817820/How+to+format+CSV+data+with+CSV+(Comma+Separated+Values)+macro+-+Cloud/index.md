# How to format CSV data with CSV (Comma Separated Values) macro - Cloud

## Overview

This page provides an example of converting CSV data into a table and formatting the table using [CSV (Comma Separated Values) macro](/cms_trial/space/TBL/74812519/CSV+(Comma+Separated+Values)+macro+examples+-+Cloud/).

Watch this video to see how the CSV macro imports and displays the comma-separated values entered in the macro body — as a structured table with applied row and column styles.

## Macro browser input

### Select this macro

|  |  |
| --- | --- |
| **Macro name** | *Advanced Tables - CSV Table* |
| **Macro syntax (Old editor)** | *{csv}* |
| **Macro syntax (New editor - case insensitive)** | */CSV (Comma Separated Values)* |

### Define these parameters/values

|  |  |
| --- | --- |
| ***Auto number on each row*** | On |
| ***Row styles*** | *font-size:1.5em;font-style:italic,, background:lightyellow, background:lightblue* |
