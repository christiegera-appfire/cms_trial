# Release notes 28 March 2024

**Release date**: March 28, 2024

Our team is thrilled to announce the latest release of Advanced Tables for Confluence.

AC version: 1.2.16-AC

## Bug fix

The following bug is fixed in this release:

- Resolved the error thrown while exporting the Confluence page as a PDF when the page included the Table Plus macro. The Confluence page action "Export as PDF" now exports the content of the Table Plus macro.
