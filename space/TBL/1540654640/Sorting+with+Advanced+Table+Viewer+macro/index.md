# Sorting with Advanced Table Viewer macro

The Advanced Table Viewer macro enables you to sort the column values on the Confluence page and organize table data efficiently.

- The macro enables the sort feature by default when you insert it for the first time.
- The macro saves the sort configuration set in macro setup mode as the default.
- When sorting is enabled, you can sort table data without edit permissions.
- When sorting is enabled, you can sort columns in both the **Edit** and **View** modes of the Confluence page.

## Using Sort in the Advanced Table Viewer macro

[Unmapped macro: refined-tab — no content to fall back on]

You need edit permissions to access the setup mode.

- Edit the macro to open the setup mode. Refer to [Setup the Advanced Table Viewer macro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).
- The macro enables the sort feature by default when you insert it for the first time.

  ![Sort is enabled by default](/cms_trial/assets/5cc8ae3c-a03c-4538-b5ef-5d5f70b066c3.jpg)
- To disable sorting, click the Sort icon (▢).
- Click **Save**.

[Unmapped macro: refined-tab — no content to fall back on]

- To sort a column, click its column header. The macro sorts the column and displays the sort icon.

  - You can click the specific column header to switch between ascending and descending order.

    - Ascending order (▢ ): Sorts column values from lowest to highest (A–Z or 0–9).
    - Descending order (▢ ): Sorts column values from highest to lowest (Z–A or 9–0)
- The table rows reorder based on the sorted column. For example, the **Item** column is sorted in ascending order.
- Click **Save**. The macro saves the sort configuration set in macro setup mode as the default for every refresh of the Confluence page.

  ![Advanced Tables Item column sorted in ascending order](/cms_trial/assets/d6aa2e20-72ab-4e04-b8a5-c7e3feb3fdf3.jpg)

If you disable the sort feature in macro setup mode, it is unavailable in both the edit and view mode of the Confluence page.

- Once sort is enabled, you can sort the columns in Confluence page edit, view, and full-screen mode.
- For example, in the page view mode, the column **Tax** is sorted in descending order.
