## CSV macro

### Enhanced CSV file parsing

The CSV macro now preserves the extra spaces in CSV data between delimiters as valid column values by default, ensuring the data displays correctly in tables.

For more information on the CSV macro and delimiters, refer to the [CSV (Comma Separated Values) macro](/cms_trial/space/TBL/74812384/CSV+(Comma+Separated+Values)+macro+-+Cloud/).
