## New features

## Advanced Table Viewer macro now supports JSON data source

- The Advanced Table Viewer macro now supports JSON as a data source in addition to CSV and Excel.
- You can configure the JSON data source using the available options, specify the JSON data path to select the required columns, and import data as a structured table.

  - Upload file
  - Attachment
  - URL
  - Insert JSON
- For more information, refer to [Configure JSON data source in Advanced Table Viewer macro](/cms_trial/space/TBL/3297017872/Configure+JSON+data+source+in+Advanced+Table+Viewer+macro/).

### Upload file

Use a JSON file from your computer as your data source.

![Advanced Table Viewer_Import JSON data using Upload file option](/cms_trial/assets/e6d43f13-5cbf-4c11-ac72-787a173e4bb8.jpg)

### Attachment

Use a JSON file attached to the current Confluence page as your data source.

![Advanced Tables JSON attachment source with Row data path and columns](/cms_trial/assets/c8c0001d-8a83-456c-b792-477358b23e89.jpg)

### URL

Use the URL of a JSON file as your data source.

![Advanced Tables JSON URL source with Row data path and columns](/cms_trial/assets/c2bc45d8-1ffe-4a75-be52-bef3a6f74594.jpg)

### **Insert JSON**

Type or paste JSON code directly into the macro.

![Advanced Tables Insert JSON source with Row data path and columns](/cms_trial/assets/1de9eac3-81d9-492f-afb0-af7a78a902e6.jpg)
