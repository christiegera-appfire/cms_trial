# Release notes October 2026

**Release date**: October 8, 2026

This page outlines the updates included in the latest release of Advanced Tables for Confluence.

Version: 8.3.0

---

## Enhancements

## Advanced Tables Configuration

Administrators can now access the Advanced Tables Configuration page directly from **Confluence administration** > **Apps** > **Advanced Tables Configuration**. [Learn more.](/cms_trial/space/TBL/74812041/Configuration+-+Cloud/)

![AT_Global configuration page.png](/cms_trial/assets/563e38b4-3ac9-47df-97c5-d4c5bae246e7.png)

### Column filters for Advanced Tables macros

- The **CSV**, **Table Plus**, **JSON Table,** and **Attachment Table** macros now include the **Display column filters** option on the **Sort and Filter** tab.

  ![CSV macro_display column filters](/cms_trial/assets/a75d36d5-693d-4f6f-bf9e-010e1af21bb6.png)

- When you select the **Display column filters** option, a dropdown appears under each column header so you can filter rows by unique column values.

  ![When column filters is enabled, it display a dropdown under column header to filter rows by column values](/cms_trial/assets/6126bd33-78e8-44b3-88d6-56a8ea7fb06f.png)

## JSON Table macro

### Display JSON data as plain text in JSON Table macro

The JSON Table macro now includes the **Show result as table** option on the **Structure and Data** tab. Clear this option to display JSON data as plain text, without whitespace or column delimiters. For more information, refer to [JSON Table macro - Cloud](/cms_trial/space/TBL/74812316/JSON+Table+macro+-+Cloud/).

![JSON macro configuration_Show result as table](/cms_trial/assets/6fa35bab-1b95-4cee-b954-c7a4ef7cdece.png)

## Bug fixes

The following bugs are fixed in this release:

**Table Plus macro**:

- The **Auto total row** that displays totals for numeric columns in the **Table Plus macro** intermittently failed to render values on Confluence page loads.

  - This issue is resolved, and the **Auto total row** now displays the totals consistently.
