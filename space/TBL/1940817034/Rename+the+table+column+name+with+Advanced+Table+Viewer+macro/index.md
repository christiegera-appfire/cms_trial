# Rename the table column name with Advanced Table Viewer macro

The Advanced Table Viewer macro enables you to rename column names after importing data from the data source.

## **Rename heading overview**

- You can rename the column heading only in macro setup mode.
- You cannot change the configured column name in Confluence page edit and view mode.

## Rename column heading

- You need edit permissions to access the setup mode.
- To rename the column, edit the macro to open the setup mode. Refer to [Setup the Advanced Table Viewer macro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).
- For each column in the table, you will see the *Edit column (*▢ *)* option.
- To rename the column heading, click **Edit column** > **Rename heading**.

  ![Rename heading](/cms_trial/assets/c451e812-e5f8-46c5-8777-dad571699c77.jpg)
- The *Edit column* dialog opens. Enter a new name for the **Column heading** and click **Save**.

  ![ATV_Edit column_column heading.jpg](/cms_trial/assets/e3c23194-bb11-4366-bb9b-d08d17128121.jpg)
- The macro updates the column heading. For example, the **Item** column heading is now displayed as **Item name**. To save the macro configuration, click **Save**.

  ![ATV_updated header name.jpg](/cms_trial/assets/e17769a1-a100-4ef4-9228-a8301638f229.jpg)
