# Release notes 19 March 2025

Our team is thrilled to announce the latest release of Advanced Tables for Confluence.

---

## New features

## Advanced Table Viewer macro BETA

The Advanced Table Viewer macro Beta now includes the row styling feature to apply custom row styles to table rows.

### Row styling

- The macro setup mode provides the row styling feature. For details, refer to [Setup the Advanced Table Viewer macro [Beta] features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).
- Once you enable **Row styling**, the right panel allows you to choose colors for row coloring and highlighting. For more information, refer to [Row styling with Advanced Table Viewer macro [Beta] - cloud](/cms_trial/space/TBL/1864990849/Row+styling+with+Advanced+Table+Viewer+macro/).

  - **Row coloring** enables you to define the colors for the table header, odd, and even rows.
  - **Row highlighting** enables you to define a hover color for table rows.

## Bug fixes

The following bugs are fixed in this release:

- The Attachment Table macro was throwing an error when using the regex pattern in the *Attachment label regex* field. The issue is fixed, and now the macro displays the attachments matching the Attachment label regex pattern.
