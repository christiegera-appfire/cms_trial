Release notes 27 August 2026

Updated 11 days ago · 3 min read

Release date: August 27, 2026

This page outlines the updates included in the latest release of Advanced Tables for Confluence.

Version: 8.0.0

New features

Introducing the Native Table Enhancer (Beta) macro

We are happy to introduce the beta release of the Native Table Enhancer macro, which is available to all cloud users of the Advanced Tables for Confluence app.

Overview

The Native Table Enhancer macro transforms your first native Confluence table in the macro body with advanced formatting and calculations for custom views and data analysis. Read more.

Beta release notice: The Native Table Enhancer macro is currently in beta.

  • While we strive to deliver a seamless experience, some features are subject to change, and minor issues can arise.

  • We encourage you to explore the macro and share your feedback to help us improve the final release. Thank you for your support and understanding!

Beta limitations

  • The macro supports only plain text and converts the content of each cell to plain text if other attributes are present.

  • The macro does not support attachments, data profiles, external URLs, and multiple tables.

Macro features

  • The macro includes features such as sorting, searching, column filtering, row styling, row numbering, grouping, column and group calculations, downloading, and pagination.

Get started

Insert the Native Table Enhancer macro in a Confluence page, add the Confluence table, and configure the features in setup mode. For more information, refer to Set up the Native Table Enhancer macro features.

Advanced Table Viewer macro now supports Jira work items

The Advanced Table Viewer macro now supports Jira work items as a data source in addition to CSV, Excel, and JSON. Refer to Configure Jira work items in Advanced Table Viewer macro.

Prerequisite: Make sure your organization or site administrator has established the app connection between the Advanced Tables for Confluence app and the Jira instance. Learn more.

  • Insert the macro, enter the JQL query, and select Jira fields to import Jira work items from the Jira instance linked to the current Confluence site.

  • In the macro setup mode, configure various available features, such as column filtering, grouping, row styling, search, row numbering, sorting, download, and column and group calculations. Refer to Set up the Advanced Table Viewer macro features.

Enhancements

Get started page improvements

Quickly get started with configuration guidance for the Native Table Enhancer (Beta) macro and support for Jira work items in the Advanced Table Viewer macro.

  • To open the page, navigate to Apps > Advanced Tables for Confluence.

Bug fixes

The following bugs are fixed in this release:

  • Attachment Table macro: Clicking the file link in the macro did not trigger the attachment download. This issue is resolved, and clicking the file link now downloads the attachment as expected.
