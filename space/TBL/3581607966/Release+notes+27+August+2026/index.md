## New features

## **Introducing the Native Table Enhancer (Beta) macro**

We are happy to introduce the **beta** release of the **Native Table Enhancer** macro, which is available to all cloud users of the Advanced Tables for Confluence app.

### Overview

The **Native Table Enhancer** macro transforms your first native Confluence table in the macro body with advanced formatting and calculations for custom views and data analysis. [Read more](/cms_trial/space/TBL/3520037211/Native+Table+Enhancer+%5BBeta%5D+macro/).

**Beta release notice:** The Native Table Enhancer macro is currently in **beta**.

- While we strive to deliver a seamless experience, some features are subject to change, and minor issues can arise.
- We encourage you to explore the macro and share your [feedback](https://appf.re/support) to help us improve the final release. Thank you for your support and understanding!

### Beta limitations

- The macro supports only plain text and converts the content of each cell to plain text if other attributes are present.
- The macro does not support attachments, data profiles, external URLs, and multiple tables.

### Macro features

- The macro includes features such as sorting, searching, column filtering, row styling, row numbering, grouping, column and group calculations, downloading, and pagination.

### **Get started**

Insert the Native Table Enhancer macro in a Confluence page, add the Confluence table, and configure the features in setup mode. For more information, refer to [Set up the Native Table Enhancer macro features](/cms_trial/space/TBL/3568173057/Set+up+the+Native+Table+Enhancer+%5BBeta%5D+macro+features/).

## Advanced Table Viewer macro now supports Jira work items

The Advanced Table Viewer macro now supports **Jira work items** as a data source in addition to CSV, Excel, and JSON. Refer to [Configure Jira work items in Advanced Table Viewer macro](/cms_trial/space/TBL/3510927447/Configure+Jira+work+items+in+Advanced+Table+Viewer+macro/).

**Prerequisite**:Make sure your organization or site administrator has established the app connection between the Advanced Tables for Confluence app and the Jira instance. [Learn more](/cms_trial/space/TBL/3510698190/How+to+connect+the+Advanced+Tables+for+Confluence+app+to+the+Jira+application/).

- Insert the macro, enter the JQL query, and select Jira fields to import Jira work items from the Jira instance linked to the current Confluence site.

  ![The Advanced Table Viewer macro configured to import Jira work items using a JQL query and selected Jira fields.](/cms_trial/assets/7807baec-decd-42c5-996f-26016b870004.png)

- In the macro setup mode, configure various available features, such as column filtering, grouping, row styling, search, row numbering, sorting, download, and column and group calculations. Refer to [Set up the Advanced Table Viewer macro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).

  ![The Advanced Table Viewer macro setup showing options to configure filtering, grouping, sorting, styling, and calculations.](/cms_trial/assets/da53b73c-6150-4d7d-b2ce-16b6f9892411.png)
