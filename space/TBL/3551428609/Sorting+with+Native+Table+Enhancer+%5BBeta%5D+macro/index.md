# Sorting with Native Table Enhancer [Beta] macro

The Native Table Enhancer macro enables you to sort column values on the Confluence page and organize table data efficiently.

- The macro enables the sort feature by default when you insert it.
- The macro saves the sort configuration set in macro setup mode as the default.
- When sorting is enabled, you can sort columns in Confluence page view mode without edit permissions.

The Native Table Enhancer macro is currently in beta. [Learn more](/cms_trial/space/TBL/3520037211/Native+Table+Enhancer+%5BBeta%5D+macro/).

## Using sort in the Native Table Enhancer macro

[Unmapped macro: refined-tab — no content to fall back on]

You need edit permissions to access the setup mode.

- Edit the macro to open the setup mode. Refer to [Set up the Native Table Enhancer macro features](/cms_trial/space/TBL/3568173057/Set+up+the+Native+Table+Enhancer+%5BBeta%5D+macro+features/).
- The macro enables the sort feature by default.

  ![Sort is enabled by default in Native Table Enhancer macro](/cms_trial/assets/ce531bf4-2fa0-4f62-9183-a840818743f3.png)
- To disable sorting, click the Sort icon (▢).
- Click **Save**.

[Unmapped macro: refined-tab — no content to fall back on]

- To sort a column, click its column header. The macro sorts the column and displays the sort icon.

  - You can click the specific column header to switch between ascending and descending order.

    - Ascending order (▢ ): Sorts column values from lowest to highest (A–Z or 0–9).
    - Descending order (▢ ): Sorts column values from highest to lowest (Z–A or 9–0)
- The table rows reorder based on the sorted column. For example, the **Category** column is sorted in ascending order.
- Click **Save**. The macro saves the sort configuration set in macro setup mode as the default for each Confluence page refresh.

  ![Save the macro sort configuration](/cms_trial/assets/2c1b870f-c354-41f2-bb91-256181283729.png)

If you disable the sort feature in macro setup mode, it becomes unavailable in the Confluence page view mode.

- Once sort is enabled, you can sort the columns in Confluence page view mode and full-screen mode.
- For example, in the page view mode, the **Category column** is sorted in descending order.

  ![Sort columns in page view mode](/cms_trial/assets/03fb8821-dc04-48b7-81f9-2dd004bf7a10.png)
