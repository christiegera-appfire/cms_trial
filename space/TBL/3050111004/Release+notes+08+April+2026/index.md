## New features

## Advanced Table Viewer macro - CSV data connector

The Advanced Table Viewer macro now supports three new CSV data source options in addition to Insert CSV and Profiles:

- [Upload file](#Upload-file)
- [Attachment](#Attachment)
- [URL](#URL)

### Upload file

Use a CSV file from your computer as your data source. For more information, refer to [Upload file](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).

![Advanced Table Viewer macro configuration showing the Upload file CSV data source option selected.](/cms_trial/assets/d63fbcf8-40ff-487f-9c1b-be089b139f12.jpg)

### Attachment

Use a CSV file already attached to the current Confluence page as your data source. For more information, refer to [Attachment](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).

![Advanced Table Viewer macro configuration showing Attachment selected as the data source.](/cms_trial/assets/3094d912-67ba-4ee3-b6d7-73e90674bffb.jpg)

### URL

Use the URL of a CSV file as your data source. For more information, refer to [URL](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).

![Advanced Table Viewer macro showing a CSV file URL configured as the data source.](/cms_trial/assets/733e3196-2449-4ddf-a893-268ae7f94546.jpg)
