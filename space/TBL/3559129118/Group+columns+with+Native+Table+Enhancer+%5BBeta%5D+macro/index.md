# Group columns with Native Table Enhancer [Beta] macro

The Native Table Enhancer macro’s column grouping feature lets you interactively group and organize table data on the Confluence page.

## Column grouping overview

- Column grouping can be enabled in macro setup mode.
- Once enabled, you can group and remove column grouping in setup mode and in the Confluence page view mode.
- Grouping changes made in page view mode are session-only and will not be saved to the grouping configuration.
- On every page refresh, the column grouping configured in macro setup mode is applied.

The Native Table Enhancer macro is currently in beta. [Learn more](/cms_trial/space/TBL/3520037211/Native+Table+Enhancer+%5BBeta%5D+macro/).

## Configure grouping

[Unmapped macro: refined-tab — no content to fall back on]

You need edit permissions to access the setup mode.

- To group columns, edit the macro to open the setup mode. Refer to [Set up the Native Table Enhancer macro features](/cms_trial/space/TBL/3568173057/Set+up+the+Native+Table+Enhancer+%5BBeta%5D+macro+features/).

  ![Edit Native Table Enhancer macro to open setup mode](/cms_trial/assets/1b216e5a-54ee-4f73-bb58-2c691b6b9aa8.png)

- To start grouping, click **Enable grouping** (▢).

  ![Enable column grouping](/cms_trial/assets/6ea4498c-7359-4020-9df3-e9c7e664d20d.png)
- Once enabled, hover over any column header, and you will see the grouping icon.
- On the column you want to group, click the grouping icon to group table data by that column.

  ![Hover any column header and click grouping icon to group table data by that column](/cms_trial/assets/bd341158-352a-4f96-aa2f-0ffffc9fab04.png)
- You can nest grouping across multiple columns, up to one less than the total number of columns. The nesting hierarchy follows the order in which columns are selected.
- The grouped column headers have a blue background in comparison to other column headers to indicate grouping.

  ![Nest grouping across multiple columns](/cms_trial/assets/0530ed10-ea38-4a10-851b-13fed3dff3d3.png)
- Click **Save** and **Publish** the page.
- You can view the configured column grouping in the Confluence page view mode.

  ![Nested column grouping in page view mode](/cms_trial/assets/187f8030-c7cf-45a6-9b81-4b9788ed09bc.png)

- To disable column grouping for all columns in the table, edit the macro and click **Disable grouping** (▢).

  ![Disable_grouping](/cms_trial/assets/bef2249e-b185-4ede-8a82-a430be26bb7b.png)
- To disable grouping on a specific column, click the grouping icon in that column’s header.
