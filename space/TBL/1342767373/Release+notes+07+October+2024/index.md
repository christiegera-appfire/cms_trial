# Release notes 07 October 2024

**Release date**: October 7, 2024

Our team is thrilled to announce the latest release of Advanced Tables for Confluence.

AC version: 1.2.16-AC

---

## Bug fixes

The following bugs are fixed in this release:

- Resolved the issue where the CSV macro inserted blank rows when the attached CSV file contained CR+LF line breaks. Now, the CR+LF is handled as expected, and the macro loads content correctly.
- Now, both the JSON and CSV Table macros display appropriate error messages if the specified profile in the macro is not found.

  ![Advanced Tables error message for missing profile in release notes](/cms_trial/assets/402bbded-c468-4ac9-acf9-80a553bd8320.jpg)
- Resolved an issue where the JSON Table macro failed to render data when the profile was configured with a base URL, and additional URL details were added in the **"**URL to JSON data**"** macro field. Now, the macro handles the extra URL details correctly and renders the data from the endpoint.
- Minor security fixes.
