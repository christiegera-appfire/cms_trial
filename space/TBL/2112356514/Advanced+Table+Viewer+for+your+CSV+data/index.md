# Advanced Table Viewer for your CSV data

The Advanced Table Viewer macro supports importing data from the **CSV** data source.

## Why use the Advanced Table Viewer instead of the CSV Macro?

- ✅ **Modern and actively developed**  
  The Advanced Table Viewer macro is the future of Advanced Tables. It's where new features and improvements are being added, unlike the older CSV macro.
- ✅ **Paste CSV directly in the macro**  
  With the new **Insert CSV** option, you can add CSV content directly into the macro without uploading a file – quick, flexible, and attachment-free.
- ✅ **Cleaner, responsive table formatting**
- The macro features improved styling and formatting, with better support for large datasets, making it easier for users to read and interact with data effectively.
- ✅ **Compatible with Advanced Tables features**  
  Once inserted, your data works seamlessly with core features like sorting, filtering, conditional formatting, and more.
- ✅ **Live preview in the editor**  
  You can view your formatted table while editing, making it much easier to build and update tables accurately.
- ✅ **Full-screen data view for analysis**  
  Switch to full-screen mode to analyze data with fewer distractions and more focus, directly within Confluence.
- ✅ **Intuitive setup and customization**  
  Easily configure macro settings with an intuitive setup mode and access the configured properties in the Confluence page view and edit mode.

## Configure the CSV data source and import data

### Import CSV data

You can import and format the comma-separated values (CSV) using one of the following methods:

- **Upload file**: Upload a CSV file from your computer. Refer to [Upload file](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).
- **Attachment**: Use a CSV file attached to the current Confluence page. Refer to [Attachment](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).
- **URL**: Provide a direct URL to your CSV file. Refer to [URL](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).
- **Insert CSV**: Type or paste CSV code directly into the macro. Refer to [Insert CSV](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).
- **Profiles**: Select a predefined profile for the CSV file. Refer to [Profiles](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).

To configure the CSV data source, refer to [Configure CSV data source in Advanced Table Viewer macro](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).

### Format table data

- Once you configure the CSV data source, you can format the table data with the Advanced Table Viewer macro's **Table** and **Column** **Properties**.
- To format and enhance your table view, refer to [Setup the Advanced Table Viewermacro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).
