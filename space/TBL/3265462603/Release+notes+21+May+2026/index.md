## Enhancements

## Advanced Table Viewer macro

### Full screen view

The full screen view on the Confluence page view mode now opens as a modal rather than an overlay, providing a more focused data analysis experience.

## Bug fixes

The following bugs are fixed in this release:

- The Table Plus macro was not displaying the **Auto total row**, even when configured.

  - The issue is now resolved, and the macro now displays the **Auto total row** as expected.
