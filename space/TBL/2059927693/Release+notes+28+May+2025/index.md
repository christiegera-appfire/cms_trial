## Advanced Table Viewer BETA macro

### Insert CSV in the macro

The CSV data connector in the Advanced Table Viewer macro now supports the **Insert CSV** option to add or paste CSV code directly into the macro. For more information, refer to [Configure Advanced Table Viewer [Beta] macro - cloud](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).
