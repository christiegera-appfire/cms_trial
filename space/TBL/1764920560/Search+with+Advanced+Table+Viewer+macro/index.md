# Search with Advanced Table Viewer macro

The Advanced Table Viewer macro search feature enables you to perform a dynamic search on the imported table data.

- The macro enables the search feature by default when you insert it for the first time.
- When search is enabled, the search bar is accessible to you without edit permissions.

You need edit permissions to access the setup mode.

- Edit the macro to open the setup mode. Refer to [Setup the Advanced Table Viewer macro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).
- The macro enables the search feature by default when you insert it for the first time.

  ![Advanced Tables search icon in Advanced Table Viewer](/cms_trial/assets/3397f9d7-83c3-4a2f-9be1-4f91ec8919bc.jpg)
- To disable search, click the **Search** icon (▢).
- Click **Save**.

[Unmapped macro: refined-tab — no content to fall back on]

- Search is available in both **edit** and **view** mode of the Confluence page.

  ![Advanced Tables search feature shown on a Confluence page in edit mode](/cms_trial/assets/2f03cb3c-f757-4325-97b9-043d30574541.jpg)![Advanced Tables search feature shown on a Confluence page in view mode](/cms_trial/assets/a63e90d5-636c-486d-a9f5-0f590b556274.jpg)

- To perform a search, enter a keyword in the search box. The macro dynamically displays the search results.
- Once you perform a search and continue editing the Confluence page, the macro maintains the search state during further page edits until you clear the search text field.

  ![Advanced Tables search state shown in Advanced Table Viewer edit mode](/cms_trial/assets/817af9a1-08b5-40be-8c7c-39d38b3ef764.jpg)
- **Full-screen view** mode: You can open the macro in full-screen mode from the page view mode. The search bar is available in full-screen mode as well.

  ![Advanced Tables Advanced Table Viewer fullscreen search view](/cms_trial/assets/2b86520f-f8c8-4673-8a2c-2f6068c7c294.jpg)
