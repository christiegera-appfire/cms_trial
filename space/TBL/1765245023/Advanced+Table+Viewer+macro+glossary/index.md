# Advanced Table Viewer macro glossary

This page provides definitions for key terms used in the Advanced Table Viewer macro and in documentation that require additional clarification.

[Unmapped macro: refined-tab — no content to fall back on]

- The setup mode enables you to configure macro features for using the Advanced Table Viewer macro.
- You need Confluence space edit permissions to access the setup mode.
- Edit the macro to open the setup mode. Refer to the page, [Setup the Advanced Table Viewer macro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).
- The setup mode displays contextual messages based on user interaction.

  - No configuration changes: *Setup mode active. You are now editing the table.*
  - With configuration changes: *Some changes added. Click Save to apply.*

    ![Advanced Table Viewer in setup mode with status bar and Save button](/cms_trial/assets/01d6680b-293b-4069-9730-3f9c7e2ac3d3.jpg)

[Unmapped macro: refined-tab — no content to fall back on]

- The Confluence page edit mode displays the table data and features as configured in the setup mode.
- You can interact with the data, but cannot save changes while in page edit mode. On every page refresh, the page displays the table data and features as configured in the setup mode.

[Unmapped macro: refined-tab — no content to fall back on]

- The Confluence page view mode displays the table data and features as configured in the setup mode.
- You can interact with the data, but cannot save changes while in page view mode. On every page refresh, the page displays the table data and features as configured in the setup mode.

[Unmapped macro: refined-tab — no content to fall back on]

The **Full screen** feature lets you view the macro with the table data and all configured features in a maximized view.

- The Full screen view always displays the table data as configured in the macro setup mode. For details, refer to [Setup the Advanced Table Viewer macro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).
- The Full screen view on the Confluence page view mode opens as a modal.
- It maximizes data visibility and minimizes distractions, allowing you to focus on data analysis and work more efficiently.
- You can switch to **Full screen** view from the Confluence page view mode. To view the data in full screen, click **Full screen**.
- To exit the **Full screen** view, click **Close**.

  ![Advanced Table Viewer in page view mode with Full Screen button](/cms_trial/assets/826e913d-973e-4332-aa79-531c9baefc30.jpg)
- The full screen view displays the contextual message:

  - *View mode. You are now viewing the table.*
- You can interact with your data, but you cannot save changes while in full screen view. To exit the **Full screen** view, click **Close**.

  ![Advanced Table Viewer in full screen view with Close button](/cms_trial/assets/dae063a3-e0fe-4699-83c4-e0e4495a94cd.jpg)
