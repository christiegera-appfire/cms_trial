# Release notes March 2025

**Release date**: March 4, 2025

Our team is thrilled to announce the latest release of Advanced Tables for Confluence.

AC version: 1.2.18-AC

---

## New features

## **Advanced Table Viewer** BETA macro new features

The Beta version of macro includes three new features, row numbering, search, and download.

- **Row numbering**: Display a column with row numbers. For details, refer to [Setup the Advanced Table Viewer macro [Beta] features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).
- **Search**: Perform a dynamic search on the table data. For details, refer to [Search with Advanced Table Viewer macro [Beta] - cloud](/cms_trial/space/TBL/1764920560/Search+with+Advanced+Table+Viewer+macro/).
- **Download**: Download the current table data as a CSV file. For details, refer to [Setup the Advanced Table Viewer macro [Beta] features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).

## Enhancements

The Beta version of **Advanced Table Viewer** BETA macro is enhanced to provide:

- Improvedmacro configuration interface.
- Macro setup mode for feature configuration.
- Full screen view of configured macro in confluence page edit and view mode.

**Beta notice:** The Advanced Table Viewer macro is currently in its **Beta** version.

- While we strive to deliver a seamless experience, some features are subject to change, and minor issues can arise.
- We encourage you to explore the macro and share your [feedback](https://appf.re/support) to help us improve the final release. Thank you for your support and understanding!

## Macro setup mode

- The macro setup mode is a full screen view to provide data visibility and a smoother configuration experience of data sources and features.
- The features configured in macro setup mode are saved as the default for every refresh of the Confluence page.
- For more information about how to configure the macro features in setup mode, refer to

  - [Configure Advanced Table Viewer macro [Beta]- cloud](/cms_trial/space/TBL/1782972884/Configure+CSV+data+source+in+Advanced+Table+Viewer+macro/).
  - [Setup the Advanced Table Viewer macro [Beta] features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).

![Advanced Table macro setup mode](/cms_trial/assets/76407d70-198c-474d-aa4e-60d5d4b28fbe.jpg)

## Full screen view

The full screenview is available in both page view and edit mode, allowing you to:

- Expand the macro for a maximized view of data and configured features.
- Focus on data analysis and work more efficiently.

For more information, refer to the [Advanced Table Viewer macro glossary](/cms_trial/space/TBL/1765245023/Advanced+Table+Viewer+macro+glossary/).
