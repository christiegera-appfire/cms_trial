# Column drag and drop with Advanced Table Viewer macro

The Advanced Table Viewer macro provides an intuitive way to reorganize table columns using drag-and-drop.

- The drag-and-drop column feature is available only in macro setup mode.
- The macro saves the column order configured in macro setup mode as the default.

## Drag-and-drop columns

- Edit the macro to open the setup mode. Refer to [Setup the Advanced Table Viewer macro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).

You need edit permissions to access the setup mode.

- Hover any column header to view the drag icon (▢ ), then drag the column to the preferred position.
