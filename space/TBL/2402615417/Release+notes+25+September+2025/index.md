# Release notes 25 September 2025

**Release date**: September 25, 2025

Our team is thrilled to announce the latest release of Advanced Tables for Confluence.

Version: 2.8.0

---

## Bug fixes

The following bugs are fixed in this release:

- The Attachment Table macro was throwing an error when the page was specified in the **Page to list attachments from** parameter. This issue is resolved, and the macro now correctly displays the attachments from the specified page as expected.
