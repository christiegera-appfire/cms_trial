# Row styling with Native Table Enhancer [Beta] macro

The Native Table Enhancer macro's row styling feature lets you apply custom colors to table rows using a simple selection interface.

- You can configure row styling only in the macro setup mode.
- When row styling is enabled, you can choose colors to apply to rows and highlight table rows.

The Native Table Enhancer macro is currently in beta. [Learn more](/cms_trial/space/TBL/3520037211/Native+Table+Enhancer+%5BBeta%5D+macro/).

## Configure row styling

[Unmapped macro: refined-tab — no content to fall back on]

You need edit permissions to access the setup mode.

To enable row styling:

- Edit the macro to open the setup mode. Refer to [Set up the Native Table Enhancer macro features](/cms_trial/space/TBL/3568173057/Set+up+the+Native+Table+Enhancer+%5BBeta%5D+macro+features/).
- To enable the **Row styling** option, click **Row styling** (▢). The row styling configuration panel appears on the right side.

  ![Enable row styling in Native Table Enhancer macro](/cms_trial/assets/86908eff-9022-4d15-b9c1-5eb6867a1d77.png)
- To apply row styling, refer to the **Row coloring** and **Row highlighting** sections.

To disable row styling, click **Row styling** (▢ ).

[Unmapped macro: refined-tab — no content to fall back on]

The row styling includes two features: **Row coloring** and **Row highlighting**.

- Enable the **Row coloring** toggle to see the **Change color** palette for **Header**, **Odd**, and **Even** rows.

  - **Header**: Defines the color for the table header.
  - **Odd**: Defines the color for the odd rows of the table.
  - **Even**: Defines the color for the even rows of the table.
- To choose a color for the table header, odd, and even rows, click **Change color** palette for each and choose the color.
- Preview the chosen row colors in the left panel.

  ![Enable Row coloring to change color palette for Header, Odd and Even rows](/cms_trial/assets/348e4a93-d04d-4a12-ae22-b4729fba0505.png)
- To save the row styling changes, click **Save.**

[Unmapped macro: refined-tab — no content to fall back on]

The row styling includes two features: **Row coloring** and **Row highlighting**.

- Enablethe **Row highlighting** toggle to define a hover color for table rows.
- Click the **Change color** palette for the **Hover** option and choose the color to highlight rows.

  ![Choose the row highlighting color](/cms_trial/assets/7d2218c3-305f-4cc9-9071-bd710275bdca.png)
- Once you choose the hover color, hover over the table rows in the left panel to preview the row highlighting.

  ![Preview row highlighting](/cms_trial/assets/7d7b1cd2-2d84-43c2-b2e2-f3ade8621904.png)
- To save the row styling changes, click **Save**.

[Unmapped macro: refined-tab — no content to fall back on]

- Once you have configured row coloring and row highlighting, save the macro and publish the page.
- The page displays the selected colors for the table header, odd, and even rows. Hover over the table rows to view the row highlighting.
