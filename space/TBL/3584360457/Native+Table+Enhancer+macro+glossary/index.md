# Native Table Enhancer macro glossary

This page provides definitions for key terms used in the Native Table Enhancer macro and in documentation that require additional clarification.

[Unmapped macro: refined-tab — no content to fall back on]

- The setup mode enables you to configure the Native Table Enhancer macro features.
- You need Confluence space edit permissions to access the setup mode.
- Edit the Native Table Enhancer macro to open the setup mode. Refer to the page [Set up the Native Table Enhancer [Beta] macro features](/cms_trial/space/TBL/3568173057/Set+up+the+Native+Table+Enhancer+%5BBeta%5D+macro+features/).
- The setup mode displays the contextual message:

  - With configuration changes: *Changes appear on the published page after save and publish*.

    ![NTE_setup mode.png](/cms_trial/assets/cd6a15bf-11ea-4727-9abf-27e5e404be8d.png)

[Unmapped macro: refined-tab — no content to fall back on]

- The Confluence page edit mode displays the native Confluence table data. It does not show the macro feature configurations applied in setup mode.
- You can edit the table data and save changes.

[Unmapped macro: refined-tab — no content to fall back on]

- The Confluence page view mode displays the table data and features as configured in the setup mode.
- You can interact with the table, but cannot save changes while in page view mode. Refreshing the page resets the table back to its default feature configuration set in setup mode.

[Unmapped macro: refined-tab — no content to fall back on]

The **Full screen** feature lets you view the macro with the table data and all configured features in a maximized view.

- The Full screen view always displays the table data as configured in the macro setup mode. For details, refer to [Set up the Native Table Enhancer [Beta] macro features](/cms_trial/space/TBL/3568173057/Set+up+the+Native+Table+Enhancer+%5BBeta%5D+macro+features/).
- The Full screen view on the Confluence page view mode opens as a modal.
- It maximizes data visibility and minimizes distractions, allowing you to focus on data analysis and work more efficiently.
- You can switch to **Full screen** view from the Confluence page view mode. To view the data in full screen, click **Full screen**.

  ![NTE_Page View mode.png](/cms_trial/assets/d23c9676-8aa5-4816-9082-9e9d61eff73e.png)
- The full screen view displays the contextual message:

  - *View mode. You are now viewing the table.*
- You can interact with your data, but cannot save changes while in full screen view. To exit the **Full screen** view, click **Close**.

  ![NTE_Full screen_close.png](/cms_trial/assets/7e5832b9-384f-4e5b-9be8-40c44db4d67d.png)
