# Release notes 14 April 2026

**Release date**: April 14, 2026

This page outlines the updates included in the latest release of Advanced Tables for Confluence.

Version: 5.0.0

---

## New features

## Advanced Table Viewer macro now supports an Excel data source

The Advanced Table Viewer macro now supports Excel as a data source in addition to CSV. You can configure the Excel data source using two options:

- [Upload file](#Upload-file)
- [Attachment](#Attachment)

### Upload file

Use an Excel file from your computer as your data source. For more information, refer to [Upload file](/cms_trial/space/TBL/3122888898/Configure+Excel+data+source+in+Advanced+Table+Viewer+macro/).

![Advanced Tables Excel upload file source in Advanced Table Viewer](/cms_trial/assets/6f715ad0-8d89-4006-8de8-cd1c46b71851.jpg)

### Attachment

Use an Excel file attached to the current Confluence page as your data source. For more information, refer to [Attachment](/cms_trial/space/TBL/3122888898/Configure+Excel+data+source+in+Advanced+Table+Viewer+macro/).

![Advanced Tables Excel attachment source with columns and sheet selection](/cms_trial/assets/b4fb51bc-6471-4625-b56b-ff4a93614229.jpg)
