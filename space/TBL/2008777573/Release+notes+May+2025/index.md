## New features

## Advanced Table Viewer BETA macro

The Advanced Table Viewer BETA macro now includes **Column filtering** to filter table data based on the values in specific columns.

### Column filtering

- The macro setup mode provides the **Column filtering** feature. For details, refer to [Setup the Advanced Table Viewer macro [Beta] features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).
- Once you enable the column filters, you can choose the filters for each column as required.
- The available column filter types are:

  - Dropdown filter
  - Free text filter
  - Number filter
  - Date range filter
  - None
- As you apply filters, the table data is dynamically filtered. For more information on how to apply column filters, refer to [Filter columns with Advanced Table Viewer [Beta] macro - cloud](/cms_trial/space/TBL/2001437596/Filter+columns+with+Advanced+Table+Viewer+macro/).
