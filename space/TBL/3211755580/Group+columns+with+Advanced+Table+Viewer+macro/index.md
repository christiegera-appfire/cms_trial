# Group columns with Advanced Table Viewer macro

The Advanced Table Viewer macro provides a column grouping feature that lets you interactively group and organize table data on the Confluence page.

## Column grouping overview

- Column grouping can be enabled in macro setup mode.
- Once enabled, you can group and remove column grouping in setup mode and in the Confluence page Edit and View mode.
- Grouping changes made in page view and edit mode are session-only and will not be saved to the grouping configuration.
- On every page refresh, the column grouping configured in macro setup mode is applied.

## Configure grouping

[Unmapped macro: refined-tab — no content to fall back on]

You need edit permissions to access the setup mode.

- To group columns, edit the macro to open the setup mode. Refer to [Set up the Advanced Table Viewer macro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).

  ![Advanced Tables edit macro option for column grouping](/cms_trial/assets/6c873fce-5199-4d2d-b0df-4dbe1a990c67.jpg)

- To start grouping, click **Enable grouping** (▢).

  ![Advanced Tables Enable grouping option in setup mode](/cms_trial/assets/456ecb4e-20b9-4c9a-980d-204c795373aa.jpg)
- Once enabled, hover over any column header, and you will see the grouping icon.
- On the column you want to group, click the grouping icon to group table data by that column.

  ![Advanced Tables Group by this column option in the table header](/cms_trial/assets/7c624cff-426f-46f0-95fd-c06f3db73645.jpg)
- You can nest grouping across multiple columns, up to one less than the total number of columns. The nesting hierarchy follows the order in which columns are selected.
- The grouped column headers have a dark gray background in comparison to other column headers to indicate grouping.

  ![Advanced Tables column grouping shown in setup mode](/cms_trial/assets/600fc1ed-d415-4dbf-8822-bdf995f1e980.jpg)
- Click **Save** and **Publish** the page.
- You can view the configured column grouping in both edit and view modes on the Confluence page.

  ![Advanced Tables grouped column table shown in page view](/cms_trial/assets/42fac36a-f834-4691-ae10-fe699cd47ba4.jpg)

- To disable column grouping for all columns in the table, edit the macro and click Disable grouping (▢).

  ![Advanced Tables grouping disabled in column menu](/cms_trial/assets/a81a8411-caf5-472e-aefa-46d09e527375.jpg)
- To disable grouping on a specific column, click the grouping icon in that column’s header.

  ![Advanced Tables Remove group option in column menu](/cms_trial/assets/98e83ece-8ea7-4f9e-a4fe-8aaeeea2306b.jpg)
