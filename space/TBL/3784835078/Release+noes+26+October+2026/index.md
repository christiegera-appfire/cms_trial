## New features

## **Advanced Table Viewer macro now supports Page properties**

The Advanced Table Viewer macro now supports **Page properties** as a data source in addition to CSV, Excel, JSON, and Jira work items. Refer to [Configure Page properties data source in Advanced Table Viewer macro](/cms_trial/space/TBL/3770810371/Configure+Page+properties+data+source+in+Advanced+Table+Viewer+macro/).

**Prerequisite:** Make sure the pages include the Page properties macro and the labels you plan to select in the Advanced Table Viewer macro.

- Insert the macro, select the space and page labels, search for pages, and choose the properties to import as table columns. The macro imports Page properties data from up to 200 pages.

  ![Insert the Advanced Table Viewer macro, select the space and page labels, search for pages, and choose the properties to import as table columns](/cms_trial/assets/92dc2c87-b1b6-4489-91d1-48d7b6de0f4c.png)
- The macro setup mode displays the table with the page title, selected column names, and values.
- In macro setup mode, you can configure macro features such as column filtering, grouping, column calculations, column reordering, row styling, search, row numbering, sorting, and download. Refer to [Set up the Advanced Table Viewer macro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).

  ![Page properties data imported using the Advanced Table Viewer macro](/cms_trial/assets/d01ba2f4-b0ee-468e-b1a0-a17eb50f14e4.png)
