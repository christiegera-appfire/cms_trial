# Installation

Perform the following to install the app:

1. Login to your Confluence instance as an administrator.
2. Select ⚙️ > **Settings** >**ATLASSIAN MARKETPLACE** > **Find new apps**.
3. Enter the name of the Appfire app to be installed in the search box.
4. Click **Try it free** to begin a free trial for a month and convert to a chargeable licensed version for the mentioned price.
