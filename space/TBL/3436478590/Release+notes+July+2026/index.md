## New features

We’re excited to introduce the **ATV Data Analyst**, an AI companion for the Advanced Table Viewer macro that helps you quickly get data insights using custom prompts—leveraging Atlassian Rovo.

## Introducing the ATV Data Analyst

### Why ATV Data Analyst

- **Save time:** Analyze imported CSV, Excel, or JSON data without leaving your page.
- **Quick insights:** Use custom prompts and quickly generate summaries, identify trends, make comparisons, and perform calculations.

**Prerequisite:**

- The **Enable Ask Rovo** togglemust be enabled under the app’s [**Global configuration**](/cms_trial/space/TBL/74812041/Configuration+-+Cloud/) settings by your Confluence administrator.
- **Atlassian Rovo** must be enabled for your organization by an organization administrator.

Administrators can disable the **Enable Ask Rovo** toggle at any time in the Global Configuration settings to manage Rovo usage.

### How it works

- Navigate to the Confluence page view or edit mode containing the Advanced Table Viewer macro.
- Filter your table to share only the required data you want to analyze. Click the **Ask Rovo** button embedded in the macro interface.
- This opensthe **ATV Data Analyst** agent chatwindowandautomaticallyshares the current table dataset context.
- Type custom prompts to start analyzing your data instantly.
- For more information, refer to [Analyze Advanced Table Viewer data with Atlassian Rovo](/cms_trial/space/TBL/3429499007/Analyze+Advanced+Table+Viewer+data+with+Atlassian+Rovo/).
