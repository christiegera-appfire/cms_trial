# Search with Native Table Enhancer [Beta] macro

The Native Table Enhancer macro enables you to perform a dynamic search on the table data.

- The macro enables the search feature by default when you insert it.
- The search bar is available without edit permissions.

The Native Table Enhancer macro is currently in beta. [Learn more](/cms_trial/space/TBL/3520037211/Native+Table+Enhancer+%5BBeta%5D+macro/).

[Unmapped macro: refined-tab — no content to fall back on]

You need edit permissions to access the setup mode.

- Edit the macro to open the setup mode. Refer to [Set up the Native Table Enhancer macro features](/cms_trial/space/TBL/3568173057/Set+up+the+Native+Table+Enhancer+%5BBeta%5D+macro+features/).
- The search feature is enabled by default.

  ![Search is enabled by default in Native Table Enhancer macro](/cms_trial/assets/e97da4b3-45a6-457d-b657-c102f3067dd2.png)
- To disable search, click the **Search** icon (▢).
- Click **Save** and **Publish** the page to view the table with all applied feature configurations.

[Unmapped macro: refined-tab — no content to fall back on]

- The search bar is available in Confluence page view mode and Full screen view.

  ![Search in Page View mode in Native Table Enhancer macro](/cms_trial/assets/a32d611b-ce9a-4ed2-b046-f38ffa4bb129.png)

- To perform a search, enter a keyword in the search bar. The macro dynamically displays the search results.
- Once you perform a search and continue editing the Confluence page, the macro maintains the search state during further page edits until you clear the search bar.

  ![NTV_Page view mode_Search state_in multiple tables](/cms_trial/assets/67c55a36-f482-45fb-9bb9-24cf548acc7f.png)
