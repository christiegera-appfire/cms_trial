## Introducing the Advanced Table Viewer macro BETA

We are happy to introduce the **Beta** release of the **Advanced Table Viewer** BETA macro, which is available to all cloud users of the Advanced Table for Confluence app!

**Beta release notice:** The Advanced Table Viewer macro is currently in its **Beta** version.

- While we strive to deliver a seamless experience, some features are subject to change, and minor issues can arise.
- We encourage you to explore the macro and share your [feedback](https://appf.re/support) to help us improve the final release. Thank you for your support and understanding!

### Advanced Table Viewer macro BETA

The Advanced Table Viewer macro allows you to import data from external sources into Confluence tables using predefined profiles. It provides customizable views of tables to help you work with your data more effectively. [Read more](/cms_trial/space/TBL/1531117698/Advanced+Table+Viewer+macro/).

## What’s in the Beta release?

### Supports CSV external data source

- The macro currently supports importing data only from the CSV data connector.

### Macro features

- The macro includes the streamlined version of the formatting features **Sorting** and **Sum-up**.
- The **Sum-up** in Beta provides only **sum** and **average** calculations and applies only to columns with numeric data.

## How to get started?

### Configure profiles

- To import the data, configure profiles for the CSV data source. For more information, refer to [Configuration - cloud](/cms_trial/space/TBL/74812041/Configuration+-+Cloud/).

### Import data using profiles

Insert the Advanced Table Viewer macro, and configure and import CSV data as tables in the confluence page. Refer to the page [Advanced Table Viewer macro - cloud](/cms_trial/space/TBL/1531117698/Advanced+Table+Viewer+macro/).

![Advanced Tables Advanced Table Viewer columns selected in release notes](/cms_trial/assets/bf4e3530-193c-407f-9c1a-721e3c244b34.jpg)

### Work with your table data and create customizable views

Advanced Table Viewer macro enables you to work with your data directly on the Confluence page without switching to edit mode.

**Sorting**

- The macro enables you to efficiently organize table data by sorting rows based on column values; click a column header to switch between ascending and descending order. For more information, refer to [Sorting with Advanced Table Viewer macro [Beta]](/cms_trial/space/TBL/1540654640/Sorting+with+Advanced+Table+Viewer+macro/).

  ![Advanced Tables Advanced Table Viewer sort feature animation](/cms_trial/assets/098cff9e-a722-4ac4-97ed-bbb1c12d3999.gif)

**Sum-up**

- The Sum-up feature automatically calculates and displays the sum (Sum) or average (Avg) for numeric columns, which you can change using the *Edit column* dialog or by clicking the column's Sum-up value. For more information, refer to [Summarize numeric column values with Advanced Table Viewer macro [Beta]](/cms_trial/space/TBL/1540654683/Column+calculation+with+Advanced+Table+Viewer+macro/).

  ![Advanced Tables Advanced Table Viewer sum up feature animation](/cms_trial/assets/fb726d26-74a9-4c30-be96-28a9b042f948.gif)

The macro formatting features are available in both the **Edit** and **View** modes on the Confluence page.
