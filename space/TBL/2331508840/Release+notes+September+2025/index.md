## Enhancements

### **Advanced Tables Configuration** page

The Advanced Tables for Confluence configuration page has been moved from the navigation path **Settings** > **Atlassian Marketplace** to **Settings** > **Configuration**.

Now, to view the Advanced Tables Configuration page, navigate to **Settings** > **Configuration** > **Advanced Tables Configuration**.
