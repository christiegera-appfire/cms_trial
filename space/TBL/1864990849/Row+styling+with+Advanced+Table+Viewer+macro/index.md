# Row styling with Advanced Table Viewer macro

The Advanced Table Viewer macro provides a row styling feature to apply custom row styles to table rows using a simple selection interface.

- You can configure row styling only in the macro setup mode.
- When row styling is enabled, you can choose colors to apply row colors and highlight table rows.

## Configure row styling

[Unmapped macro: refined-tab — no content to fall back on]

You need edit permissions to access the setup mode.

To enable row styling:

- Edit the macro to open the setup mode. Refer to [Set up the Advanced Table Viewer macro features](/cms_trial/space/TBL/1765147138/Set+up+the+Advanced+Table+Viewer+macro+features/).
- Enable the **Row styling** option.
- Once you enable the row styling option, the row styling features appear in the right side panel.

  ![Advanced Tables row styling settings in Advanced Table Viewer](/cms_trial/assets/118b8067-9155-475b-96a1-1966c40591cf.jpg)

[Unmapped macro: refined-tab — no content to fall back on]

The row styling includes two features: **Row coloring** and **Row highlighting**.

- Enable **Row coloring** to see the **Change color** option for Header, Odd, and Even to define the colors of table rows.

  - **Header**: Defines the color for the table header.
  - **Odd**: Defines the color for the Odd rows of the table.
  - **Even**: Defines the color for the even rows of the table.
- To choose a color for the header, odd, and even rows of the table, click the **Change color** palette for each and choose the color.
- Preview the chosen row colors in the left panel.

  ![Advanced Tables row coloring settings in Advanced Table Viewer](/cms_trial/assets/dba76955-2f55-421c-bdf6-4dfa0d0cbd69.jpg)

[Unmapped macro: refined-tab — no content to fall back on]

The row styling includes two features: **Row coloring** and **Row highlighting**.

- Enable **Row highlighting** to define a hover color for table rows.
- Click the **Change color** palette for the **Hover** option and choose the color to highlight rows.

  ![Advanced Tables row highlight hover color settings](/cms_trial/assets/56bd01ef-bedc-4443-97da-de0d37106985.jpg)
- Once you choose the hover color, hover over the table rows in the left panel to preview the row highlighting.

  ![Advanced Tables row highlight settings in Advanced Table Viewer](/cms_trial/assets/eb77ebb9-487d-4a86-a3d6-34d7f7558675.jpg)
- To save the row styling changes, click **Save** and update the page.
