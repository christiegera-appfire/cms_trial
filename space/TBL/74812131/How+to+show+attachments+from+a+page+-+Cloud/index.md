# How to show attachments from a page - Cloud

## Overview

This page demonstrates how to use the [Attachment Table macro](/cms_trial/space/TBL/74812217/Attachment+Table+macro+-+Cloud/), part of the [Advanced Tables for Confluence](https://appfire.atlassian.net/wiki/spaces/TBL) app, to display a list of attachments on the current page. This macro is similar to the *Attachments* macro that comes with Confluence, but has some additional customization capabilities.

Watch this video to see how the Attachment Table macro displays attachments from a Confluence page.

## Macro browser input

### Select this macro

|  |  |
| --- | --- |
| **Macro name** | *Advanced Tables - Attachment table* |
| **Macro syntax (Old editor)** | *{attachment-table}* |
| **Macro syntax (New editor - case insensitive)** | */Attachment Table* |

### Define these parameters/values

|  |  |
| --- | --- |
| *Page to list attachments from* | empty |
| *Space key or space name regex* | empty |
