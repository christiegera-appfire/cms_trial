# Release notes 14th July 2025

**Release date**: July 14, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Bug Fixes

**Cleaned Up Document Activity in Duplicated Pages**

When duplicating a page, the most recent custom content from the original page was incorrectly copied to the new one, causing the duplicated page to display document activity entries from the source page. The issue is now fixed.

**Removed redundant data from Space Settings**

During the Data Center migration process, workflows with large volumes of data caused inconsistencies and clutter in the administrator’s view. Unnecessary and outdated information has been removed to improve performance and clarity, especially in spaces with a high number of workflows.
