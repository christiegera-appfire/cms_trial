# Release notes 6th March 2025

**Release date**: March 6, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## New features

### New workflow trigger actions

#### Add Restrictions action

The [Add Restrictions trigger action](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1731526706) lets you add page-level **view** or **edit** restrictions to a document. It can be used to add, view, or edit permissions for one or more Confluence users or groups.

![Comala visual editor add view restrictions trigger with recipient examples](/cms_trial/assets/5c490026-77a1-4be8-82b7-729fc5295174.png)

#### Set Restrictions action

The [Set Restrictions trigger action](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1775730689) removes existing page-level **view** or **edit** restrictions for a document before adding new page-levelrestrictions **of the same type** for one or more Confluence users or Confluence groups.

![Comala visual editor set view restrictions trigger with recipient examples](/cms_trial/assets/8c504daf-9bf8-46e6-9af3-2b64154dd5bf.png)

## Enhancements

### App space settings UI update

The **Labels** column is now always displayed in the app space settings. Previously, it was only displayed when at least one workflow included a label condition.

![Comala space settings with one custom workflow and label column shown](/cms_trial/assets/99354490-adb9-4f04-8fd8-a7b71496d623.png)

This update ensures consistency in the settings interface.

The application of workflows conditioned by labels is being gradually rolled out, and the **Labels** column might not be displayed on all customer sites.

### Maintenance updates

Updated the usage of API v2
