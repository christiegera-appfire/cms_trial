# Release notes 4th April 2025

**Release date**: April 4, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

## Bug Fixes

The following issue is fixed in this release:

When creating a custom workflow, the **Select** transition did not appear if notransitions were manually added. This issue is now fixed—**Select** transition is applied by default, ensuring smooth state transitions in the workflow.
