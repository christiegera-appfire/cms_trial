# Release notes 8th April 2025

**Release date**: April 8, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Bug Fixes

The following issues are fixed in this release:

### Email notification disabled for deleted/archived pages

Fixed an issue where reminders were still being sent for pages that had been *deleted or archived*. Email notifications will not be sent for these pages.

### Document approvals macro loading fix

Addressed an issue where the **Document Approvals macro** failed to load in certain spaces using pageworkflows. The macro now loads as expected across all affected spaces.
