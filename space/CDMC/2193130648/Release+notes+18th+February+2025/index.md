# Release notes 18th February 2025

**Release date**: February 18, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Enhancements

### Updated app icons

The Comala Document Management app icons have been updated in the Confluence **Space apps** and **Apps** menus.

![Comala app icons in the Confluence space apps menu](/cms_trial/assets/9749701a-7c56-4317-87af-9ff729bfdb80.png)

### Atlassian dark features removal

Atlassian has removed app vendors' access to add dark features in Confluence Cloud. If you still require access to any Comala Document Management dark features, you can submit a request to [Appfire Support](https://appf.re/support) to activate them for your Confluence Cloud site.

---

## Bug fixes

The following issue is fixed in this release:

- fixed a recently introduced issue that prevented the document report from loading
- resolved an issue where the document activity report displayed an incorrect version when the workflow automatically assigned a reviewer. This issue occurred if the document had previously been in the final workflow state
