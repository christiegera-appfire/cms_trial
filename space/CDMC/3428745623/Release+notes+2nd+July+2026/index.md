# Release notes 2nd July 2026

**Release date**: July 2, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Version:** 5.0.2

---

## Bug fixes

### **Metadata Report macro now includes the space homepage**

The Metadata Report macro now includes the space homepage when the **Ancestors** (`@ancestors`) pages option is selected. Previously, the homepage was omitted from the report.

### **Approvers now display without a recorded assigner**

Approvers are now shown in the **State Dialog** and **Approvals** view even when no assigner is recorded for their decision. In these cases, the **Assigned by** column remains empty.
