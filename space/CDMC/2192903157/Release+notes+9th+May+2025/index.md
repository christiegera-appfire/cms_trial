## New approval filters added for better visibility

We’ve updated the names and functions of some filters in the Document Report to make it easier to manage approvals in the Comala cloud apps.

**My Pending Approvals** is now **My Assigned Approvals**

This updated filter shows all the approvals where you are assigned—whether you’ve approved, rejected, or haven’t taken any action yet.

We’ve added a new filter, **My Pending Approvals,** right next to **My Assigned Approvals**. This filter shows only the approvals for which you are assigned as a reviewer but haven’t approved or rejected the document yet.
