## Bug fixes

The following issues are fixed in this release:

### Improved space mapping during migrations

Resolved an issue where spaces with similar names could cause mapping errors during migrations, resulting in misplaced or lost data. Space identification has been improved to use unique internal identifiers instead of names, ensuring accurate data mapping and more reliable migrations.

### Improved API reliability and error handling

Fixed an issue where the connection with Confluence could intermittently slow down or disconnect, making it unclear whether requests had completed successfully. The app now communicates with Confluence more reliably, reducing unnecessary interruptions.
