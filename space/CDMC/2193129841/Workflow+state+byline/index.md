# Workflow state byline

## Overview

When Comala Document Management is installed in your instance, you can use the **No workflow enabled** byline on a page to add a workflow to the page.

![image-20260629-175518.png](/cms_trial/assets/5d75a8e2-0ce1-48b3-a870-f71ca2ac55a7.png)

The **No workflow enabled** byline appears under the following conditions:

- There is no active workflow applied to the page.
- There is no active space-level workflow assigned.
- The user viewing the page has **edit permissions**.

Depending on your Confluence permissions, the byline lets you:

- Apply a workflow directly to the current page.
- Open **Comala Document Management** from *Space apps* to apply a workflow to all pages and blog posts in the space.

Only the **“Apply to Content”** option is active in the dialog box for a user with Confluence edit permission for the page.

Both options (**Apply to Content** to **Apply to Space)** are active if you’re a space administrator.
