# Release notes 4th February 2025

**Release date**: February 4, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Bug fixes

The following issues are fixed in this release:

- updated the visual editor to fix an issue that prevented removing or updating parameter dropdown values for approval-related [workflow trigger actions](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614010216), including assign, unassign, approve, and reject
- improved the [visual editor](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614009868) to ensure the **Changes not applied** dialog box appears only when unsaved modifications exist, preventing it from being displayed unnecessarily when exiting the trigger editor without making changes
- optimized the loading of the **Delete Document Activity** checkbox option in the [Confirm Remove Page Workflow](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614009844) dialog box, enabling editors to promptly select this option
