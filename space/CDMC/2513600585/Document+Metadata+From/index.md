# Document Metadata From

## Overview

The **Document** **Metadata From** macro retrieves metadata values from a specific Confluence page. It can be used to retrieve only one metadata value at a time.

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| **Space** *(required)* | The space where the target page is located. Defaults to **@self**, which points to the current space. |
| **Page** *(required)* | The page to retrieve the metadata from. The default value **@self** points to the current page. |
| **Value** *(required)* | The name of the metadata to retrieve. |

## Add the macro

To add the Document Metadata Set macro,

1. On a draft page, type `/document metadata from`.

   ![Document metadata from macro.](/cms_trial/assets/aff13361-1c31-4968-8274-90b0c451e7de.png)
2. Click the macro to edit the required values, and click **Insert**.

![The Insert Metadata From window showing the Space, Page, and Value fields.](/cms_trial/assets/692b462e-aecb-4149-9883-8368b0bcc33e.png)
