# Release notes 2nd October 2026

**Release date**: October 2, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**App version:** 52.1.0

**Release version:** 5.0.33

---

## Bug fixes

The following issues are fixed in this release:

- Global Workflows now open in a new browser tab when accessed from Space Workflows, instead of loading in the current tab.
- When you add a comment while approving a page, and that approval also changes the page state, the comment now appears only under the approval in Document Activity, not under both the approval and the state change.
- Publishing a page through the Comala Publishing integration works again on Commercial Cloud.
