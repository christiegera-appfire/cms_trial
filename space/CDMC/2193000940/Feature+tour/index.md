# Feature tour

## Streamlined and flexible solutions for **effortless** document control.

Automate your document lifecycle by automating approvals, notifications, and deadlines, so you have time to focus on your high-value tasks.

---

## Automated reviews and approvals

Manage your documentation by automating approvals, notifications, and deadlines, allowing you to focus on value-added activities.

- Assign reviewers to approve or reject content.
- Set expiry dates for the content to be reviewed.
- Track all document changes for better visibility.

## Custom workflow parameters and triggers

**Create workflows that target and cater to a specific audience using custom workflow parameters and triggers.** Configure *workflow parameters* to define and control the values used in your documentation process, ensuring consistency for your team, reviewers, and project deadlines.

Use *workflow triggers* to monitor specific events and automatically perform actions, such as sending custom email notifications, displaying on-screen alerts, setting expiry dates, or removing page restrictions.

## Workflow version control

Track version history and revert changes for [Global Workflows](/cms_trial/space/CDMC/2276786309/Global+workflows/). Every edit is saved as a new version. View any previous version’s definition and revert to it if needed; no history is lost.

## Customized notifications

Comala Document Management sends email notifications for key events. On-screen notifications appear for users assigned to approve a page.

For example,

- Assignees are notified when assigned to review a page or blog, and
- Notifications are sent when the expiry date is reached for content with the *Content Expiry workflow*.

![CDM workflow notifications.](/cms_trial/assets/e166c74c-2e70-4765-82f5-6eb7e6d71278.png)

## Detailed reporting options

Track and report on changes, reviews, and approvals with Comala Document Management. Space administrators can view the current workflow status on pages and blog posts across the space using document reporting options.

You can also export both Document Report and Document Activity data to CSV for custom dashboards and cross-space reporting.
