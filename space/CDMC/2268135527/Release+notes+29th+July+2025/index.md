# Release notes 29th July 2025

**Release date**: July 29, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Bug Fixes

### **Document Approvals macro not displayed when workflow is active in space settings**

Resolved an issue where the **Document Approvals** macro was not visible on the editor or published page when the workflow was enabled through **Space Settings**. The macro now displays correctly in both views when a space-level workflow is active.

### **Updated the font size in Space Workflows and Workflow Builder**

Following a recent update from Atlassian that increased the default text font size by 1px, the UI in **Space Workflows** and the **Workflow Builder** has been adjusted to maintain consistent layout, spacing, and visual alignment.

### **Page workflow removal option disabled for page creator**

Resolved an issue where users with **Edit** permissions were unable to remove an applied workflow from a page they created. The **Remove Workflow** option was incorrectly disabled. This issue has been fixed.

### **Missing expiration column in Document Report**

The **Expiration** column was previously excluded from the **Document Report**. This has now been resolved, and the column is now visible, allowing users to view expiration details as expected.

### **Inaccurate status filtering in Document States Report**

Resolved an issue where the **Document States Report** sometimes failed to filter results based on the selected status. The filtering logic has been improved to ensure more accurate and consistent results.
