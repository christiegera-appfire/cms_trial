# Release notes 9th September 2025

**Release date**: September 9, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Bug Fixes

### All workflow states are now available in the Document Report filter

Previously, when multiple workflows were applied in a space, some states were missing from the state filter in the Document Report. This issue has been fixed

### Group members are now displayed correctly in the Document Approvals macro

When an approval was configured with a group, the Document Approvals macro did not display all group members. This has been fixed, and all members of the group now appear as expected.
