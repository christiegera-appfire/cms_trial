# Release notes 21st October 2026

**Release date**: October 21, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Release Version:** 52.7.0

---

## Bug fixes

The following issues are fixed in this release:

- Data Center to Cloud migrations now preserve the original workflow markup, which remains available in the workflow builder.
- Removing a reviewer from an approval no longer causes repeated app processing.
- Workflow actions now resolve Confluence groups correctly. You can assign group members as approval reviewers, apply restrictions to groups, and use groups as email recipients.
