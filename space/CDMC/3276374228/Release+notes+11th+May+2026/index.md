# Release notes 11th May 2026

**Release date**: May 11, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

---

## Migration Enhancements

### Migration framework and compatibility enhancements.

Fixed an issue where migrations from unsupported CDM Data Center versions could result in incompatible data. The migration process now validates the source version; if the instance is below **7.14.4**, the migration will stop and prompt the user to upgrade before retrying.
