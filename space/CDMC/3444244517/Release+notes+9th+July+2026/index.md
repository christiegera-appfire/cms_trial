# Release notes 9th July 2026

**Release date:** July 9, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Version:** 5.0.5

---

## Bug fixes

- Documents no longer switch to the wrong state when a delayed update is processed after newer edits are made. For example, a late update could previously move a document from *Review* back to *Draft*. This issue is now fixed.
- Pages whose workflow was removed, or that were moved out of a space with a global workflow, no longer cause repeated background errors.
