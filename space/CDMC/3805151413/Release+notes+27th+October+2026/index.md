# Release notes 27th October 2026

**Release date**: October 27, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Release Version:** 52.8.0

---

## Enhancements

### Configure label removal conditions in Visual Builder

- Space admins can now configure conditions for the On label removed event in the Visual Builder, without editing the workflow JSON. Choose `equals` or `not-equals` and enter one or more labels. This condition appears only for this event, and the builder prevents saving it without a label.

## Bug fixes

- Fixed an issue where workflows could stop transitioning without displaying an error if an assign trigger referenced an approval that didn't exist.
