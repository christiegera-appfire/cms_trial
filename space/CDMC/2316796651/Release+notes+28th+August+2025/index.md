## Bug Fix

### **Document Report – Fix filters that show only the current page states for Page Workflows**

The dropdown previously displayed only the states available on the current page. As a result, some valid states did not appear when filters were applied. This issue has been resolved, and all valid states now remain visible in the dropdown after filtering.
