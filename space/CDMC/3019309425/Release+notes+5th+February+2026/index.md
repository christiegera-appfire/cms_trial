## Bug fixes

The following issue is fixed in this release:

### **State changes are now registered with the correct document version**

Resolved an issue where state changes could be registered with an outdated document version in the Document Activity log when you update a page in one tab and a state change was submitted from another. State change actions (Approve, Reject, Assign, Unassign, and Select) now always use the latest document version, keeping the Document Activity log consistent and reliable.
