# Use the Comala Document Management App with Confluence Live Pages

If your team is using Confluence Cloud and has enabled the new Live Pages (Live Docs) feature, you may notice that Comala Document Management workflows are disabled while editing a Live Page. This article explains what this means, what is supported, and how to continue using Comala workflows alongside Live Pages.

## Information:

1. **What Happens When You Edit a Live Page?**

When a Confluence Live Page is in edit mode, you will see the following message:

> "Live Editing  
> Interaction with Comala Document Management is disabled in edit mode."

![Comala Document Management with Confluence Live Pages enabled](/cms_trial/assets/a99a7496-df25-4044-a4dd-13b99c789db9.png)

This means:

- Comala workflows (state transitions, approvals, etc.) are temporarily disabled.
- You cannot interact with the workflow status or triggers while editing.
- This limitation applies only during the Live Page edit session.

1. **Does This Affect Workflow Data or History?**

No. Comala Document Management continues to track the workflow history and state of the page. Once editing ends, workflow functionality resumes outside of edit mode.

1. **What Is the Recommended Workflow?**

If you want to use Comala workflows fully on a Live Page, follow these steps:

- Step 1: Use the Live Page feature to take real-time notes or collaborate quickly.
- Step 2: When you're ready to apply formal workflows (e.g., for review or approval), convert the Live Page to a regular Confluence page.
- Step 3: Comala Document Management will now be fully functional on the converted page.

1. **Can I Keep Using My Existing Pages?**

Yes. Your existing Confluence pages (created before enabling Live Docs) are not affected. Comala Document Management works normally on those pages.

1. **Is It Safe to Enable Live Pages?**

Enabling Live Pages will not affect your existing workflow-enabled content. You can enable Live Docs across your site and continue using them alongside traditional pages.
