# Create and edit workflows

You can create and customize workflows that control how your content moves through review, approval, and final stages using Comala Document Management for Cloud.

You can create and edit custom workflows visually using the **Visual builder editor**, which offers an intuitive, flowchart-based interface for adding states, transitions, approvals, and triggers.

For more advanced configuration or precise control, the **JSON code editor** allows you to edit the workflow’s underlying JSON directly.

For more details, refer to the following help pages:

- [Visual builder editor](/cms_trial/space/CDMC/2193162438/Visual+builder+editor/)
- [JSON code editor](/cms_trial/space/CDMC/2192837873/JSON+code+editor/)
