## Bug Fix

### Set all reviewers that have to approve option for an approval incorrectly allowed any user approve when no reviewers were assigned

Previously, if no reviewers were assigned under the **Set all reviewers that have to approve** option, **any user** could approve the page. This has been fixed:

- Only the explicitly assigned reviewers can now approve or reject
- If the list of assigned reviewers is empty (the `preassignedUsers` parameter is empty), the **Approve** and **Reject** buttons are disabled
