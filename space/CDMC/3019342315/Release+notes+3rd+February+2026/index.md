## Bug fixes

The following issue is fixed in this release:

### Completed migrations are now visible in the migration dashboard.

Previously, completed DC to Cloud migrations were not displayed in the Migration Dashboard after a successful migration. The dashboard now correctly shows all completed migrations, including those with skipped errors, improving visibility into migration status.
