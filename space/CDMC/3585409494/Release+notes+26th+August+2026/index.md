# Release notes 26th August 2026

**Release date**: August 26, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**App version:** 50.18.0

**Release version:** 5.0.25

---

## Enhancements

### Clearer Document Activity for first-time state entry

Document Activity now distinguishes a page’s first state from later changes. The first entry reads *Initialized state to [X]*, instead of *Changed state to [X]*.

---

## Bug fixes

- The Document Approvals macro now shows the approved or signed status for legacy activity, including cases where approval records were stored under the post-transition state name.

---

## Security and privacy

- Strengthened permission handling across the workflow engine, state dialog, macros, and other modules, so actions consistently run with the correct user permissions.
