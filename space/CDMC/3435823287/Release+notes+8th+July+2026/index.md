# Release notes 8th July 2026

**Release date:** July 8, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Version:** 5.0.4

---

## Bug fixes

### Expiration date cannot be set in the past

The expiration date can no longer be set to a date that has already passed.

### Anonymous and deleted users display correctly

Anonymous users and deleted users now display correctly in the **Updated by** column, including on pages migrated from Data Center. Previously, these users were not shown correctly.

### CSV export no longer duplicates responsible actor

When exporting approval events, the CSV export no longer lists the responsible actor twice as a contributor.

---

## Enhancements

### Better handling of large reviewer groups

Group membership is now limited to 400 users, matching the behavior of the legacy Comala Workflows Cloud app. This reduces timeouts when working with large reviewer groups.
