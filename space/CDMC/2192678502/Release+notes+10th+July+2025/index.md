# Release notes 10th July 2025

**Release date**: July 10, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Enhancement

### **Improved access to Comala Document Management Space Settings**

To enhance usability and reduce navigation steps, the **Comala** **Document Management** is now linked under the **Space** **Apps** section. This takes the users directly to the *Space Settings* page, improving discoverability and streamlining access to configuration options.

![Comala release notes July 2025 feature update](/cms_trial/assets/a6a4481b-4c7f-4886-98f5-f3524beb9bf7.png)

## Bug Fixes

### **Scroll Functionality in Visual Builder**

Resolved an issue where scroll functionality was not available when a workflow contained a large number of **States** or **Triggers**. Now, individual vertical scroll bars are displayed for **States** and **Triggers** sections in the Visual Builder when more than nine items are added, ensuring all elements remain accessible.

### Added a fallback to prevent Document Report failure

We've now added a fallback to keep the Document Report running smoothly in cases where workflow states are missing after migration. This prevents the report from failing and ensures it remains accessible.

### Updated error message in Space Settings

We've updated the message displayed in the Space Settings once a migration is complete to help users understand the migration status more easily.
