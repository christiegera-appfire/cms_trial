**App version:** 50.21.0

**Release version:** 5.0.28

---

## Bug fixes

The following bugs are fixed in this release:

**Workflow now reapplies correctly when a disabled version already exists**

Fixed an issue where applying a workflow to content could create a duplicate when a matching disabled workflow was already present. The existing workflow is now safely reactivated instead.

**Improved reliability of installation checks under heavy load**

Improved how the app verifies its installation status, reducing occasional errors that could appear when many requests were processed at the same time.

**Improved the Document State macro performance**

Optimized how the Document State macro loads, reducing background processing so pages using the macro render more efficiently.
