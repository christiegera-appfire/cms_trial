# Release notes 17th February 2025

**Release date**: February 17, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

This release introduces the ability to **activate multiple workflows in a space** and apply them **conditionally using a content label filter**. One or more workflows can be automatically applied to document types within the same space.

---

## New feature

### Activate multiple space workflows and apply them by label

GRADUAL rollout

A space administrator can [activate multiple space workflows](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1751810236) in the app space settings and apply them conditionally using **labels**.

![Comala document report with multiple active workflows](/cms_trial/assets/3ea0f14b-720c-4546-86a3-3bfe05bab831.png)

- **Multiple active workflows**: You can enable more than one workflow at the same time
- **Label-based workflow application**: Each workflow can be assigned a **content label**, ensuring it applies only to pages with that label.
- **Priority order**: Workflows are applied in the order defined in the app space settings, following their label conditions

Additionally, when a label is added to a workflow in the app space settings, the workflow cannot be applied as a page workflow.

This feature enables different documentation processes within the same space by automatically applying the appropriate workflow based on labels. It reduces confusion by ensuring that each document follows the correct workflow without manual selection, improving efficiency and compliance.

The ability to activate multiple workflows and apply them conditionally by the content label is part of a gradual rollout of new features. It is not immediately available to all our customers.

### Document report displays the applied workflow

The [document report](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1388216988) now includes the name of each workflow applied to a document in a space.

![Comala document report with multiple workflows and notinitialized pages](/cms_trial/assets/4dcf922a-2c0a-4beb-81cb-2ae6ef33857d.png)

This update lets you see which active space workflow is applied to a document. All pages in the space are displayed, but if no active workflow is applied, no workflow name is displayed, and the document has a **Status** of **Not Initialized.**
