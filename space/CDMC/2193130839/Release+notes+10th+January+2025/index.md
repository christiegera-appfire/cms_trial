## Bug fixes

The following issues are fixed in this release:

- resolved an issue in the [workflow state dialog box](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614009877) that occurred when the state included a long description or custom approval button labels. This issue prevented access to some elements in the dialog box
- the document activity report failed to display if a workflow state did not have a defined color
- the [document approvals macro](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614012920) in a PDF export of a page failed to display approval details when the state specified in the macro settings differed from the current workflow state
- the [document approvals macro](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614012920) did not work when the macro was configured for a state that included an accent or special character in the state name
