# Release notes 23rd September 2026

**Release date**: September 23, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**App version:** 51.2.0

**Release version:** 5.0.31

---

## New features and enhancements

### Advanced approvals

This release expands what you can configure for approvals in a workflow:

- Require reviewers to add a comment when they approve or reject.
- Allow reviewers to self-assign to an approval.
- Automatically reset approvals when a page is updated after approval.
- Use clearer approval labels in the workflow builder.

![advanced-approvals.png](/cms_trial/assets/28a8e753-d8a4-490c-b9c9-8fcf125f1743.png)

### Workflow engine improvements

This release includes several improvements to workflow configuration and processing:

- Use custom events in the workflow engine for more flexible workflow triggers.
- Compare multiple values in conditions with the `equals` and `not-equals` operators.
- Use clearer naming for state expiry settings.

### Document activity

- Automatic workflow synchronization entries are now hidden from the document activity log, keeping the log focused on user actions.

## Bug fixes

This release resolves the following issues:

- Approve, reject, and transition activities are now ordered correctly during workflow migration.
- The bottom border of the state dialog now displays correctly in dark mode.
- Slashes in **Send Email** action links are now encoded correctly.

## Security updates

- Workflows in *Space Settings* can now be accessed only from the space that owns them.

## Maintenance and platform updates

- Comala Document Management continues to support Isolated Cloud environments, with analytics disabled and no external data transfer.
