# Release notes 24th November 2026

**Release date**: November 24, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Release Version:** 56.0.0

---

**Important: Manual app update required**

This release requires additional app permissions and does not upgrade automatically. A Confluence site administrator must manually approve the update to enable the new features and enhancements. Until the update is approved, your site continues to use the previous version of Comala Document Management.

## New features

### New workflow trigger event: Attachment updated

The `on-attachment-updated` trigger event runs when a new version of an existing attachment is uploaded to a page. Use this event to automate workflow actions when an attachment is updated.

---

## Bug fixes

This release includes the following fixes:

- **Document Activity**

Fixed an issue where changing a workflow state using the workflow state override option was incorrectly recorded as a state override in the Document Activity history. The activity now correctly identifies the change as a workflow state override.

- **Workflow reliability**

Fixed an issue that prevented workflows from loading or being applied on Confluence sites with many workflows.
