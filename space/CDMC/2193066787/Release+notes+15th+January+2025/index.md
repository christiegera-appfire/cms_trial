## New feature

### New label actions for workflow triggers

GRADUAL ROLLOUT

You can now add label-related actions to a [workflow trigger](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614007410). You can use these trigger actions to add and remove one or more specified labels or clean all labels from a page. These label actions for a workflow trigger are:

- [add-labels](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1549533192)
- [remove-labels](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1549533255)
- [clean-labels](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1548877927)

You can configure each label action to add, remove, or clean labels on the page with the applied workflow or on all its **immediate child pages**.

Label-related workflow trigger actions can be added using the [visual editor](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614010813) or the [code editor](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1466237019).

These workflow trigger label actions are part of a gradual rollout of new features and are not immediately available to all our customers.
