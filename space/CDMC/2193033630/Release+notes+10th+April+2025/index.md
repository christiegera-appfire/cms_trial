# Release notes 10th April 2025

**Release date**: April 10, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Enhancements

### **Displaying the page workflow details in the Document Report**

The Document Report now includes the page workflow name and current state when a page has a page-level workflow applied and the space workflow does not apply. This improvement ensures clearer status visibility and helps prevent space confusion that uses labeled workflows.

## Bug Fixes

The following issues are fixed in this release:

### Improved compatibility with the Copy Space for Confluence app

- Resolved an issue where certain space properties were not correctly handled when cloning a space using the **Copy Space for Confluence** app. Spaces are now cloned accurately with all expected properties.

### Approval macro issue

- Fixed an issue where adding the **Approval macro** to a page would result in an error.The macro now functions as expected without displaying any errors.
