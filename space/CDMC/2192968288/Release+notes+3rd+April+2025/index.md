# Release notes 3rd April 2025

**Release date**: April 3, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Enhancements

### In-app guided prompt for Comala Publishing

Space administrators will now see a new button in **Space Settings** in instances where the *Comala Publishing* app is not installed. This button will directly link to the AtlassianMarketplace, allowing admins to install and explore the *Comala Publishing* appandstreamline their publishing workflows.
