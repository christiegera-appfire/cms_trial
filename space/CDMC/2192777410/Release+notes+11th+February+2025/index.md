## Enhancement

### Minimum approval setting behavior change

The [**Minimum approvals**](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1296662648) [setting](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1296662648) in the visual editor for a workflow approval is now ignored when set to zero. Previously, a workflow approval configured with a **Minimum approvals** value of zero was automatically approved.

![Comala visual editor approval with empty minimum approvals field](/cms_trial/assets/c24a2b66-f908-4e3d-a668-d90a757786d8.png)

This update prevents unintended automatic approvals. If automatic approval is required, you can add a workflow trigger with an [approve action](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614012750).
