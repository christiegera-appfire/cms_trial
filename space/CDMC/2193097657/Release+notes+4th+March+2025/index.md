## Enhancements

### Document report minor UI update

The [document report](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1388216988) filter **My pending approvals** is now named **My assigned approvals**.

![Comala document report with my assigned approvals filter](/cms_trial/assets/570a0f96-c725-44c6-8f46-5accad6bcc44.png)

This name reflects the functionality of the report filter, which, when applied, displays entries where the current user has been assigned as a reviewer and the approval is still pending, for example, when the approval has multiple reviewers.
