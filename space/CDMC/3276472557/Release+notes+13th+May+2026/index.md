# Release notes 13th May 2026

**Release date**: May 13, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

---

## Security fixes

The following security improvements are included in this release:

**Restricted access to Global Workflow settings**

Strengthened permission controls to ensure that only Confluence administrators can modify global workflow visibility settings. Non-admin users can no longer access these configuration endpoints.

**Updated third-party libraries to address known vulnerabilities**

Upgraded several backend libraries to their latest secure versions to resolve known security vulnerabilities, including issues related to HTTP response handling, data processing, and XML parsing.
