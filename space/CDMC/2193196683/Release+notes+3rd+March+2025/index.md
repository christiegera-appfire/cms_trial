# Release notes 3rd March 2025

**Release date**: March 3, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Enhancements

### An approval can now be added to the final state

When one or more approvals are added to the final state, the **Approve** and **Reject** buttons are now displayed in the state dialog box

![Comala page in final state with approval added](/cms_trial/assets/f4777955-8d1b-4d8a-bbaa-2f294a1ab0af.png)

In addition, the **Approve** and **Reject** buttons are always displayed, even if **approve** or **reject** transitions are not explicitly defined.

---

## Bug fixes

The following issue is fixed in this release:

- app icons are now displayed correctly for each workflow in the **Add Workflow** dialog box when adding a page workflow
