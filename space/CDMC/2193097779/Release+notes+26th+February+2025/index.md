## New feature

### New Exclude labels workflow condition

A space administrator can now [exclude a workflow from being applied to a document based on the document label](https://appfire.atlassian.net/wiki/spaces/CDMC/pages/1766719716/Activate+multiple+space+workflows+and+apply+them+based+on+labels#Exclude-labels-option).

![Comala visual editor workflow with two labels and exclude labels enabled](/cms_trial/assets/2824a06c-b2fe-4f99-9b01-265100dbe320.png)

You can set this condition for a workflow by adding one or more labels using the visual editor and enabling the **Exclude labels** checkbox. When the workflow is active in a space, it is not applied to a document with these labels.

![Comala space settings with two label workflows and exclude labels option](/cms_trial/assets/8daa0997-423d-4d25-b9fd-072923e7433d.png)

This option ensures the active workflow is applied only to documents without any of the excluded labels. By tailoring workflows to different documents, they can be applied automatically to the required documents.

When [multiple workflows are active in the app space setting](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1751810236)s, each workflow is applied in the order defined in the app space settings and subject to any label conditions.
