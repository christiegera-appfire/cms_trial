# Release notes 22nd September 2025

**Release date**: September 22, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## New feature

### Introducing increment-metadata trigger action

The [increment-metadata trigger action](/cms_trial/space/CDMC/2400584152/increment-metadata/) lets you automatically increase numeric metadata values, making it easier to manage custom versioning and other automated numbering needs.

![Comala release notes September 2025 feature update](/cms_trial/assets/701bd103-bdb6-430d-bb7c-9285709395aa.png)

---

## Bug Fix

Resolved an issue where large `spaceId` and `contentId` values were not processed correctly, causing errors. These values are now handled to prevent unexpected failures.
