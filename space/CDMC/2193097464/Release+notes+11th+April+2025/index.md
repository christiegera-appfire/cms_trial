# Release notes 11th April 2025

**Release date**: April 11, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Enhancements

### Implement sticky labels

Labels are used to determine which workflows apply to specific pages. Previously, any user could remove these labels, potentially causing pages to lose their assigned workflows. To address this, we’ve updated the behavior so only admins can remove any workflow labels, ensuring better control and stability of workflow assignments.

## Bug Fixes

The following issue is fixed in this release:

### Fix for document approvals macro in spaces with page workflows

Resolved an issue where the Document Approvals macro failed to load in spaces where the space admin configuration included a workflow array with an empty object. The macro now loads correctly in all affected spaces.

### **Document Report - fix missing workflow state filters**

Fixed an issue where certain workflow states were missing from the **Document Report** filters. To improve usability and accuracy, we’ve introduced a new filter selector that ensures all relevant states can be properly filtered.
