# Release notes 19th August 2026

**Release date**: August 19, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**App version:** 50.16.0

**Release version:** 5.0.23

---

## Bug fixes

- Resolved an issue where the **Copy Page** actiondid not run in certain cases.
- Resolved an issue in migrated spaces where re-running the **Copy Page** action created duplicate pages instead of updating the existing copy.
- Fixed an issue where the **Document Approvals** macro ignored its display options when a page was exported using **Scroll PDF Exporter**.
- Improved logging and internal data handling for greater security and reliability.

## Migration updates

- Added a warning message on pages affected by the earlier **Connect-to-Forge** migration incident, so affected content is clearly flagged.
