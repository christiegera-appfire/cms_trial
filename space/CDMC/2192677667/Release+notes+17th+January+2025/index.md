## Hot fix

The following issue is fixed in this release:

- fixed a problem introduced in some instances by a December 21, 2024 release that caused an approval with multiple reviewers assigned to transition after a single reviewer approval

This fix addresses an issue affecting documents assigned for review before December 21, 2024, where the approval required multiple approvers. If one assignee approved the document after December 21, 2024, the document was approved without waiting for input from all approvers.
