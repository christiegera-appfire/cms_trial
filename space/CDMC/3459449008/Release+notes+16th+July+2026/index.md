# Release notes 16th July 2026

**Release date:** July 16, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Version:** 5.0.9

---

## Bug fix

- Fixed an issue where the document report export could fail when a space contained pages in an approval state with no reviewers assigned yet.

## Improvements

- Workflow notifications and page flags, including state changes, errors, assignments, and related messages, now appear in the user’s Confluence language instead of English only.
