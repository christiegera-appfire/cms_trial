# Release notes 21 July 2026

**Release date**: July 21, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Version:** 5.0.11

---

## Enhancements

## Document Activity in a full-page view

You can now open the Document Activity report in a full Confluence page, making it easy to bookmark or share a direct link to it.

- Navigate to the **Document Activity** report and click **Open in full page**.

  ![Document Activity.png](/cms_trial/assets/5411382f-d095-4b1f-9e8a-be5aa3a27fad.png)
- The Confluence page displays the complete Document Activity. To return to the original Confluence content page, click **Back to page**. For more information, refer to [Document Activity](/cms_trial/space/CDMC/2193162907/Document+activity+(document-level)/).

  ![Document Activity full page view](/cms_trial/assets/52abe15c-4f49-4517-8356-23077238032e.png)

## **Workflow state consistency**

A background process now automatically detects and corrects pages where the displayed workflow state has drifted out of sync with the Document Activity history. This ensures workflow status stays accurate and consistent.

## **Improved page load performance**

The app no longer makes an unnecessary permissions check on every page load when it already has edit access, speeding up page load.
