# Release notes 7th July 2026

**Release date**: July 7, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Version:** 5.0.3

---

## Bug fixes

### **Document Activity columns display correctly with long comments**

Document Activity columns now display correctly, even when a transition includes a very long comment. Previously, a long comment could affect how the columns were displayed.

### The `on page updated` trigger appears in the Visual Builder

When a workflow using the `on page updated` trigger was migrated to the cloud app, the trigger worked but was not visible in the Visual Builder. It appeared only in the Code Editor. This issue is now fixed.

### Faster, more reliable transitions for workflows with large reviewer groups

Previously, workflows that assigned reviewers from a large group (such as an organization-wide group with hundreds or thousands of members) could time out and retry, preventing the transition from completing. Workflow transitions now process correctly when a large group is set as preassigned reviewers.
