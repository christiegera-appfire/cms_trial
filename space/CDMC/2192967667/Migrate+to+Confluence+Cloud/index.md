# Migrate to Confluence Cloud

Comala Document Management supports migration from Confluence **Data Center** to Confluence **Cloud** using the *Atlassian Confluence Cloud Migration Assistant (CCMA)*.

## Choose your migration guide

| **Migration path** | **Who this applies to** | **Guide** |
| --- | --- | --- |
| **DC to Cloud (Forge)** | All customers migrating on or after July 1, 2026 | [Migrate from Data Center to Cloud (Forge)](/cms_trial/space/CDMC/3446079850/Migrate+from+Data+Center+to+Cloud+(Forge)/) |
| **DC to Cloud (Connect)** | Exception customers who registered with Appfire Support to migrate to the Connect version after June 30, 2026 | [Migrate from Data Center to Cloud (Connect)](/cms_trial/space/CDMC/3446374401/Migrate+from+Data+Center+to+Cloud+(Connect)/) |

## Data Center to Cloud (Forge)

As part of Atlassian's platform modernization, Comala Document Management for Cloud has been rebuilt on the Atlassian Forge platform. Starting July 1, 2026, all new Data Center to Cloud migrations use this updated architecture.

Key improvements include faster migrations, a migration dashboard with batch-level retry, resilient retries, automatic metadata migration, and no page-restriction removal required.

**This migration requires Comala Document Management Data Center version 9.0.0 or higher.**

See: [Data Center to Forge migration guide](/cms_trial/space/CDMC/3446079850/Migrate+from+Data+Center+to+Cloud+(Forge)/)

## Data Center to Cloud (Connect)

This guide applies only to exception customers who are migrating from Data Center to the Connect version after June 30, 2026. These are customers who registered their migration with Appfire Support prior to that date. This guide will be retired on October 1, 2026.

For a DC to Connect migration, the CDM Cloud app must be on **v40 or lower**. Upgrading to **v41 or higher** installs the Forge version, which makes the Connect migration no longer possible. On the Data Center side, upgrading to the latest compatible version is strongly recommended.

See: [Data Center to Connect migration guide](/cms_trial/space/CDMC/3446374401/Migrate+from+Data+Center+to+Cloud+(Connect)/)
