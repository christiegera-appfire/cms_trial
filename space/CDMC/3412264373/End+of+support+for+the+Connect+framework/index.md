# End of support for the Connect framework

## End of support for the Connect framework and transition to Forge remote for Comala Document Management, Document Control, and Document Approval

Atlassian has [announced](https://www.atlassian.com/blog/developer/announcing-connect-end-of-support-timeline-and-next-steps) the end of support for the Connect framework in late 2026. As part of this transition, **Comala Document Management for Confluence Cloud** will move from the Connect framework to Atlassian’s Forge platform.

**Comala Document Control (CDC)** and **Comala Document Approval (CDA)** are following the same platform transition. Both apps will have their own Forge-based Cloud versions, and the Connect end-of-support timeline applies to them equally.

- A new **Forge-based version of Comala Document Management** is released on **June 30, 2026**. Current CDM Connect customers need to manually upgrade to the new Forge version. The upgrade period begins **July 1, 2026**, and the Connect version is expected to be retired on **October 1, 2026**.
- **Comala Document Control (CDC)** and **Comala Document Approval (CDA)** will have their own **Forge-based Cloud versions**, following the same platform transition. We will make these Forge versions available as soon as possible. Once available, customers on the Connect versions of CDC or CDA will need to **upgrade to the Forge versions** to continue receiving updates, security fixes, and support. The Connect versions of CDC and CDA are expected to be retired around **Q4, 2026**.
- Contact our [support team](http://appf.re/support) if you have any questions or need assistance planning your upgrade.

## Why Forge?

- **Enhanced security**: Forge apps run within Atlassian’s trusted infrastructure, ensuring your data is protected with built-in security and compliance controls. Your data stays within Atlassian’s platform boundary rather than being processed on external servers.
- **Improved performance and reliability**: The Forge platform is designed for enterprise-scale workloads, with better scalability and more reliable app performance within Confluence Cloud.
- **Tighter platform integration**: Forge enables deeper, more seamless integration with Confluence Cloud, providing a more native app experience.
- **Atlassian’s recommended standard**: Forge aligns with Atlassian’s highest standards for app security, trust, and compliance on the cloud platform.
- **Continued support**: Atlassian is [ending support for the Connect framework](https://www.atlassian.com/blog/developer/announcing-connect-end-of-support-timeline-and-next-steps) in late 2026. Upgrading to the Forge version ensures you continue to receive app updates and support.
