# Release notes 20th October 2026

**Release date**: October 20, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Release Version:** 52.4.0

---

## Bug fixes

The following bugs are fixed in this release:

- **Space Settings** now loads workflows correctly in spaces where the workflow list previously failed to load.
- A confirmation message now appears when you remove a reviewer from an approval.
- Workflow state repairs now order activity entries with matching timestamps correctly on older migrated pages, helping preserve the correct state and approval history.
