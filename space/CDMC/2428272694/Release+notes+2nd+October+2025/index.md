# Release notes 2nd October 2025

**Release date**: October 2, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## New

### **Workflow Builder – New “on page updated” Trigger**

We have now added support for a new trigger *event*, **'on page updated'**, in the **Workflow Builder**.

This event detects when a page with an active workflow is updated and lets you configure actions that run automatically after the update.

## Bug Fix

### **Set restrictions trigger action – Fix for multiple user configuration**

Resolved an issue where restrictions were not applied when configuring multiple users in a **set-restrictions** trigger action. The fix ensures that restrictions are now correctly applied to all specified users when the trigger is executed.
