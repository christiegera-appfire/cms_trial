## Bug Fix

### send-email trigger action now supports @assignee as a string

When creating a new **send-email** trigger in the builder, the **User** field did not accept `@assignee`. Instead, it required `@assignee@`, which was stored in JSON as an object instead of a string. This caused an error and prevented the email from being sent. The issue has been fixed, and you can now use `@assignee` as a string.
