## Enhancement

### Migration to Cloud now includes all the current workflow state data

The migration from a hosted Confluence instance to the Cloud now includes all current workflow state data. The **workflow state byline** and **document activity report** for the migrated page retain key workflow details, ensuring continuity.

When the workflow is applied in the Cloud on the migrated page, the workflow state byline and state dialog box display:

- state due date
- assignees of any approvals in the state
- status of each assignee in each approval

  - approved
  - rejected
  - pending
- the byline link to the last approved version of the page

![Comala review state dialog with two reviewers and partial approval](/cms_trial/assets/b8e82e0c-4f0d-4656-a986-7b0efcea92c1.png)

Additionally, all workflow activity entries from the hosted app for the current state are preserved in the **document activity report**, including:

- state transition
- state due date set
- approval reviewer assignments and unassignments
- approval reviewer decisions pending, approved, rejected

This applies only to pages and blog posts that currently have an **active** workflow. Workflow state data related to documents without an active workflow on the hosted Confluence instance is not migrated.

Migration to Cloud at least Comala Document Management for Data Center v7.8.0.
