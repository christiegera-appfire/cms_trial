# Release notes 3rd July 2025

**Release date**: July 3, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Bug fixes

- Previously, when the attribute scope was not declared, parameters were not populated in the code editor. This issue is fixed, and updating a parameter in the builder now correctly reflects the value in the Code Editor.
- When a metadata macro imported from the Data Center was added to a page, it incorrectly displayed the message “**Available soon**” instead of showing an error. This issue has now been fixed.
