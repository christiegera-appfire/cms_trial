## Bug fixes

The following issue is fixed in this release:

Resolved an issue where the Comala Document Management (CDM) metadata macros were not appearing in the macro browser for the Comala Document Control instances with the CDM features enabled. The following macros are now visible and fully functional for those instances: Set Metadata, Metadata Values, Metadata From, Metadata Report, Document Metadata Get, and Document Metadata List. These macros remain unavailable for standard Comala Document Control instances.
