## Enhancements

### UX improvement - updated the initialize states dialog box in the app space settings

We have updated the dialog box displayed when a space administrator chooses to use the [**Initialize states**](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1082949633) [utility](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/1082949633) for an active workflow. This has been renamed as the **Bulk State Override** dialog box.

![Comala space settings initialize states bulk override dialog](/cms_trial/assets/1a13ab72-bd60-43e6-a64e-d5e872698e53.png)

The **Stop** button displayed when the **Initialize** process is in progress now includes a tooltip warning that ending the process does undo any changes to the pages already processed.

These improvements provide greater clarity for the use of the utility.
