# Release notes 4th November 2026

**Release date**: November 4, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**Release Version:** 52.9.0

---

## Enhancements

### Workflow Visual Builder

- **Approval name conditions:** Add an Approval name condition to supported approval events directly in the Visual Builder, with no JSON editing required. Choose *equals* or *does not equal*, then select one or more approvals from the workflow. The trigger summary describes the condition in plain language, and if you rename an approval, matching conditions update automatically.
- **Duplicate approval name warning:** If renaming an approval would create a duplicate name, the Visual Builder now warns you before you save the workflow. You can fix the duplicate before it affects triggers or conditions that rely on unique approval names.

---

## Bug fixes

- Fixed an issue where some Data Center-to-Forge migrations timed out in CCMA after the data had been sent successfully. Migration messages are now tracked and processed more reliably.
