# Release notes 6th November 2025

**Release date**: November 6, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Bug Fixes

### Improved performance when adding approvers

Resolved an issue that caused excessive network requests when adding approvers in workflow parameters. This previously caused the page to become unresponsive. With this fix, the page now remains responsive, and user suggestions load as expected.

### Handling empty groups and undefined parameters

Fixed an issue where reviewers were not assigned if the group was empty or if workflow parameters were not defined.

### Validation for anonymous users

Fixed a validation issue that prevented anonymous users from loading page data. Anonymous users can now access the page data as expected.
