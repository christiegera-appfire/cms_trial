# Release notes 24th April 2025

**Release date**: April 24, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Bug Fixes

### State macro is not displayed after saving a page (Draft state)

After saving a page in draft mode, a broken icon appeared instead of the expected message from the newly added state macro. This issue has been resolved. The correct macro content is now displayed immediately after saving the page.

### Missing assignment notification

Assigned users now correctly see a floating notification message when visiting a page, ensuring precise and timely awareness of approval responsibilities.

### Resource map deletion fails with more than 25 pages in a space

Creating a new space with the same name as an existing one (containing over 25 pages) threw an error. This issue has now been resolved.
