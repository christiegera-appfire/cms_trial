# Release notes 22nd January 2025

**Release date**: January 22, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Bug fixes

The following issues are fixed in this release:

- resolved several issues affecting the [document approvals macro](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614012920)

  - default alphabetical ordering of multiple approvals in a state was not maintained in PDF or Word exports of a document containing the macro
  - the comment field, when set, was not displayed on the published document
  - PDF and Word exports of a document that include the macro incorrectly included the document version
