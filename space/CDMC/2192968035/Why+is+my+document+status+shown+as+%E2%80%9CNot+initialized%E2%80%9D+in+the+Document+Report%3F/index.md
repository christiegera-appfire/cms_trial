# Why is my document status shown as “Not initialized” in the Document Report?

### **What does “Not initialized” mean?**

The status **Not initialized** appears in the Document Report when a page or blog post has not yet been assigned a workflow state.

This happens when:

- A workflow was not enabled in the space at the time the page was created.
- You create a new page or blog post.
- A workflow is enabled later at the space level.
- The Document Report is viewed before the document is accessed by a user.

Since the document hasn’t been opened after the workflow was applied, the workflow state has not been set yet.

### **When does the status change?**

The status will automatically update the next time you open the document. At that point, the workflow assigns a state, and the status in the report will update accordingly.

### How can you initialize document states without opening each page?

Only a space administrator can initialize all document states from the app space settings, so users don’t need to access each document manually.
