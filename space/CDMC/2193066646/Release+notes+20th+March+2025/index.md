## New feature

### Copy Page workflow trigger action

The **Copy Page** workflow trigger action lets you automatically create a copy of a page.

You can copy the page as a child of a parent page within the same space or as a child of the homepage of another space.

![Comala visual editor add copypage trigger action](/cms_trial/assets/28cf9121-22fc-4d85-a464-29fad5d4f67f.png)

You can use the **Copy Page** trigger action to separate public content from work-in-progress versions without the need for an additional app. The copied page retains the same name by default, but you can assign a new page name if needed. The action can also be used to create multiple copies.
