## New feature

### copy-page workflow trigger action

The **copy-page** **workflow trigger** action lets you automatically create a copy of a page.

You can copy the page as a child of a parent page within the same space or as a child of the homepage of another space.

![Comala visual editor add copypage trigger action](/cms_trial/assets/9445bfa5-164c-4dbc-a820-1be8bac1f69b.png)

You can use the *copy-page trigger action* to separate public content from work-in-progress versions without needing an additional app. The copied page retains the same name by default, but you can assign a new page name if needed. The action can also be used to create multiple copies.
