**App version:** 50.14.0

## Bug fixes

The following issues are fixed in this release:

- Fixed an issue in the workflow code editor that allowed saving two approvals with the same name in the same state. Saving is now blocked, and a validation error is shown.
- Fixed an issue where some pages incorrectly showed “Installation in Progress” in Page Properties Reports after a Confluence re-index, even though the app was fully installed. Workflow status now displays correctly.
