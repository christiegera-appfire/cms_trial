# Document Metadata Set

## Overview

The Document Metadata Set macro lets you define metadata values on a page that can be referenced by other metadata macros or accessed in workflow definitions. It helps store and share structured information that can be reused in different parts of your documentation or workflow setup.

## Parameters

| **Parameter** | **Description** |
| --- | --- |
| **Metadata Name** *(required)* | The name of the metadata to be set. |
| **Metadata value** *(required)* | The value of the metadata. |
| **Hidden** | When selected, the metadata value is stored but not displayed as part of the page content. |

## Add the macro

To add the Document Metadata Set macro,

1. On a draft page, type `/document metadata set`.

   ![Document Metadata Set macro.](/cms_trial/assets/54178248-ee61-4989-97f8-314d7eed18d5.png)
2. Choose the **Document Metadata Set** macro. Click the macro to edit and add the **Metadata Name** and **Metadata Value.**

![Insert Set Metadata showing the Metadata Name and Metadata Vaule fields.](/cms_trial/assets/6ad22e27-7921-4a1a-96bf-07f379b1c665.png)

1. Click **Insert.**

![Document Metadata Set Metadata Value field.](/cms_trial/assets/ca2ccf99-3dd4-4132-9b80-65c16bf8b32c.png)

1. **Publish** or **update** the page to retrieve and render the metadata value on the page.
