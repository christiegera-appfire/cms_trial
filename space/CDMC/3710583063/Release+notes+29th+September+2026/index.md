# Release notes 29th September 2026

**Release date**: September 29, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

**App version:** 52.0.0

**Release version:** 5.0.32

---

**Important: Manual app update required**

This release requires additional app permissions and does not upgrade automatically. A Confluence site administrator must manually approve the update to enable the features described on this page. Until the update is approved, your site continues to run the previous version of the app.

## New features and enhancements

### Global Document Report

- View the status of documents and approvals across all your spaces in a single global report, instead of checking each space individually.

![Global Document Report showing document and approval status across spaces.](/cms_trial/assets/27753eba-cfdc-4adb-94d3-078426c1dcc0.png)

[Learn more about the Global Document Report](/cms_trial/space/CDMC/3713531915/Document+report+-+Global+level/)

### Onboarding experience

- A new onboarding experience helps you get started faster, with use-case cards and a guided Get Started flow that applies a recommended workflow to your space.

![Onboarding experience with use-case cards and the guided Get Started flow.](/cms_trial/assets/257b9af7-66f0-4763-a0b3-44f1ec33d65c.png)

### Workflow engine improvements

- General improvements to the workflow engine, including new smart value handlers and validation updates.

## Bug fixes

This release resolves the following issues:

- Blog post titles now display with their link in the Document Report.
- The Document Approvals export now includes the Status and Version columns.
- A confirmation message now appears when you assign a reviewer to an approval.
- State transition comments are again included in the default email notifications.
- Fixed display issues in the full Document Activity view when using dark theme.
- The linked spaces count for global workflows no longer includes content-scoped links.

## Security updates

- Viewing permission settings in Space Settings now requires space administrator access.
- Administrator checks now apply only to the current user.
- Document Report exports are now limited to the current space.

## Maintenance and platform updates

- Improved reliability in Isolated Cloud environments when the remote publishing service is unavailable.
