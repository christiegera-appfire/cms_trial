# Release notes 6th February 2025

**Release date**: February 6, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Enhancement

- Improvements have been made to the initialization of states in the app space settings for better performance and usability.

## Bug fixes

The following issues are fixed in this release for document state macro:

- **Incorrect change state date**: The macro previously displayed a more recent date than the actual state change. This has been corrected.
- **Missing workflow indication**: In some cases, the macro incorrectly showed that no workflow was applied, even when one was present. This issue has now been resolved.
