# Release notes 14th January 2025

**Release date**: January 14, 2025

Our team is thrilled to announce the latest releases of Comala Document Management Cloud.

---

## Bug fixes

The following issues are fixed in this release:

- resolved an issue introduced in a recent release, where the [document approvals macro](https://appfire.atlassian.net/wiki/spaces/CDMCD/pages/614012920) with a defined state showed incorrect information after a page transitioned to a new state
- fixed an issue where, in some instances, a description added to a custom workflow state in the visual or code editor was not saved successfully
