# Release notes 6th May 2026

**Release date**: May 6, 2026

This page outlines the updates included in the latest release of Comala Document Management Cloud.

---

## Bug fixes

The following bugs are fixed in this release:

**Document report: expiration dates not retained after refresh**

Fixed an issue where selecting **Refresh Data** cleared the expiration date values for all pages in the document report. This occurred even when the pages had an expiration date configured. The expiration dates on the affected pages were not changed.
