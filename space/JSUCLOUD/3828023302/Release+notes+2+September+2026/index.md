# Release notes 2 September 2026

**Release date**: September 2, 2026

Our team is pleased to announce the latest release of JSU Automation Suite for Jira Workflows.

This release note covers JSU Cloud version `9.3.0`.

---

## New features

### In-app guidance

The onboarding process has been completely reworked with better contextual banners and modals inside JSU to help discover features and complete setup.

### Easier migration from Connect to Forge

Migration support has been significantly improved when moving JSU from Connect to Forge on Jira Cloud.

## Improvements

The following improvement is available in this release:

### **Improved Conditions builder**

The “Add nested condition” section has been updated with labels that are more clear and more logical placement of add actions.

## Bug fixes

This release includes the following bug fixes:

- Update Any Issue Field - “Preconditions must be” defaults to the expected value again when configuring rules.
- User is in Any users - Older rule configurations are preserved and behave correctly after upgrade.
- Validators - Date expressions in validators evaluate correctly.
- Update Any Issue Field - Setting request type works as intended.
