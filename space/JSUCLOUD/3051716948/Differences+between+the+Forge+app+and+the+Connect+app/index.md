# Differences between the Forge app and the Connect app

JSU Automation Suite for Jira Workflows has moved to [Atlassian’s Forge platform](https://developer.atlassian.com/platform/forge/), a major infrastructure upgrade that ensures better performance, scalability, and security compliance with Atlassian’s latest standards.

After the migration to Forge, a few changes may affect how you use the app. Below is a summary of what has changed and what you may need to do.

## What’s different

### Hints & Tips feature removed

The Hints & Tips help banner will no longer appear on Jira workflow pages.

### Installation ID replaces Cloud ID

We’ve updated how installations are identified in Forge.

**IMPORTANT:**

Your previously saved user preferences in the app settings will be reset. You’ll need to reconfigure your preferences after the update.

### No reminder to publish workflows

JSU will no longer display reminders to publish workflows. You’ll need to rely on Jira’s native UI to publish workflow changes, as JSU will not prompt you to publish.

## What you need to do

- Upgrade the app to the latest version.
- Review your user preferences and reconfigure any preferences if needed.
