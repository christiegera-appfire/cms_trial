# Release notes 04 December 2025

**Release date**: December 4, 2025

Our team is pleased to announce the latest release of JSU Automation Suite for Jira Workflows.

This release note covers JSU Cloud version `4.6.0`.

---

## Bug fixes

The following fixes are included in this release summary:

- **Update Any Issue Field post function:** Resolved an issue where comments separated by commas for a single value were rendered in multiple lines. Now, when commas are used, JSU correctly reads the values surrounded by quotes and renders the comments as a single value.
- **Field Value condition:** Resolved an issue where a selected `empty` or `not empty` value wasn’t saved in the configuration.
