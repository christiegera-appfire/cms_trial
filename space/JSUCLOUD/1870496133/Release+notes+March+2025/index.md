# Release notes March 2025

**Release date**: March 17, 2025

Our team is pleased to announce the latest release of JSU Automation Suite for Jira Workflows.

---

## Bug fixes

The following fixes are included in this release summary:

- Resolved a minor issue where JSU could not read the value of a field even when the field was present on the Issue View screen. This occurred in cases where a project was using separate View Issue and Edit Issue screens.
- Resolved an issue with the onboarding modal for new users. Available issues are correctly displayed when you select a project.
