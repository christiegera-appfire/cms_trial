# Jira custom fields

This page is for users who need help with setting up custom fields in Jira. You can also refer to Atlassian's [Custom Field documentation](https://support.atlassian.com/jira-cloud-administration/docs/create-a-custom-field/).

Custom fields allow your team to add information specific to their needs and customize their issues. There are times when you will want to assign custom fields when configuring your JSU post functions. Custom fields should be created in advance in your Jira instance. You can choose any number of fields to appear when creating, editing, or transitioning issues.

To create Jira custom fields:

1. In your Jira Cloud instance, select the **Settings** cog, and then select **Issues**.

   ![The Jira Cloud Admin Settings menu.](/cms_trial/assets/589384ca-aa50-4a1b-ad25-43945532175a.png)
2. Under *Fields* in the *Issues* left sidebar menu, select **Custom Fields**, then select **Create custom field**.

   ![The Custom Fields page in Jira Cloud.](/cms_trial/assets/d22ff5c3-aa2f-49c6-812d-4dc34b2e6cdb.png)
3. Select the type of field you want to create, then select **Next**. Atlassian has a [list](https://support.atlassian.com/jira-cloud-administration/docs/custom-fields-types-in-company-managed-projects/) of available custom field types.

   ![The list of custom field types that you can select when creating a custom field.](/cms_trial/assets/77bcdec8-0a83-407e-a29a-cb909119d9a7.png)
4. Add a name and a description (optional) for your field, then select **Create**.

   ![The configuration form for a new Number Field custom field.](/cms_trial/assets/a78713db-01a6-4659-bd44-796660c3b895.png)
5. To add your new custom field to the screens of the projects where you want it to appear, select the corresponding checkboxes, and then select **Update**.

   ![A list of issue screens that you can select to use the new custom field.](/cms_trial/assets/ee5166e3-d6d2-4185-a8a2-100be6bd858c.png)

Your custom fields are now available when configuring your post functions.
