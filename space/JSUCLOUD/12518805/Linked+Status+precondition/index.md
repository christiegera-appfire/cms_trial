# Linked Status precondition

## Description

The Linked Status precondition verifies that all linked issues (of a certain link type), have a particular status.

## Configuration

![Example of the Linked Status precondition as described on this page.](/cms_trial/assets/731adafe-0dbc-4c5a-a882-02979454a50d.png)

## Example

Bug 'BF-25' has been resolved, and so have its linked support issues. If the bug is reopened, and not all support issues are still open, they will be re-opened.
