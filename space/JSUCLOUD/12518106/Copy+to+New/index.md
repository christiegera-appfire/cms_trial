# Copy to New

## Description

Use the Copy to New sub-function with the Create a Linked Issue post function to copy the value from a source field of the origin issue to a destination field of a new issue. You can add any number of Copy to New configurations.

## How to add a sub-function

To add Copy to New to your configuration, under *Sub-Functions*, click **Add Configuration**.

Follow the walkthrough below to see how to use sub-functions in JSU.
