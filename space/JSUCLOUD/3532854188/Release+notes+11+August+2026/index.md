# Release notes 11 August 2026

**Release date**: August 11, 2026

This release includes updates to JSU Automation Suite for Jira Workflows.

This release note covers JSU Cloud version `9.0.0`.

---

## Improvements

The following improvement is available in this release:

### Updated Jira terminology

JSU now uses Jira's updated terminology for **work items** and **spaces** throughout the app, replacing references to issues and projects where applicable. This provides more consistent terminology between JSU and Jira.

---

## Bug fixes

The following fixes are included in this release:

- [**Copy Value From Other Field**](/cms_trial/space/JSUCLOUD/12518474/Copy+Value+From+Other+Field+post+function/)

  - Fixed the **Separator** field so that it provides enough space to enter and review separator values when configuring the Copy Value From Other Field post function.
  - Fixed an issue where the **Perform As User** setting could incorrectly display the JSU Add-On User when you reopened the post function configuration for editing.
- **Create a Linked Issue:** Fixed an issue where setting the **Request Type** field with a **Set** subfunction could cause the [Create a Linked Issue](/cms_trial/space/JSUCLOUD/12518348/Create+a+Linked+Issue+post+function/) post function to fail for Jira Service Management work items.
