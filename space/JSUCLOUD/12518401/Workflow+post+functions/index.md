## JSU post functions

**Post functions** modify data in Jira *after* a transition is performed. You can add one or more post functions to a workflow transition to automate various tasks.

JSU provides the following post functions:

- [Calculated Field post function](/cms_trial/space/JSUCLOUD/12520029/Calculated+Field+post+function/)

- [Copy or Move Attachments post function](/cms_trial/space/JSUCLOUD/12518560/Copy+or+Move+Attachments+post+function/)
- [Create a Linked Issue post function](/cms_trial/space/JSUCLOUD/12518348/Create+a+Linked+Issue+post+function/)

### How to add a post function to your workflow

To add a JSU post function to a workflow:

1. Create a draft of your project workflow. If you're unsure how to get to this page, follow the onboarding steps in [Edit a Jira Workflow](https://appfire.atlassian.net/wiki/spaces/JSUCLOUD/pages/12519274). You can then view your workflow in Text or Diagram mode.
2. Select your transition, then select the *Post functions* tab. Existing post functions for the transition are listed.
3. Select **Add post function**.

   ![Screenshot of the Post functions tab highlighted in the Close transition of the Approvals workflow.](/cms_trial/assets/ce3d454c-d200-461a-9b01-509a896e6500.png)
4. Select the required post function, then select **Add** at the bottom of the page.

   ![Screenshot of a list of available post functions in Jira.](/cms_trial/assets/ec2bd5bf-6073-4c03-9d68-63119b9863af.png)
5. Customize the post function as required, and then select **Add**." You can find details on post function parameters on our dedicated pages for each post function.
