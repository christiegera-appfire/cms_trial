# Release notes 27 August 2026

**Release date**: August 27, 2026

Our team is pleased to announce the latest release of JSU Automation Suite for Jira Workflows.

This release note covers JSU Cloud version `9.2.0`.

---

## Bug fixes

This release includes the following bug fix:

- Fixed an issue during Jira Cloud Migration Assistant (JCMA) migrations where migration events could be processed out of order, causing mapping data to be fetched multiple times and potentially preventing migration report generation.
