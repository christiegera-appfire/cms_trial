# Installation and update guide

## Before you begin

- You must be a [Jira administrator](https://confluence.atlassian.com/adminjiracloud/managing-global-permissions-776636359.html) to carry out the instructions on this page.
- Browser requirements for JSU match the relevant Jira requirements. See the [Jira Supported Browser page](https://confluence.atlassian.com/cloud/supported-browsers-744721663.html) for the version of Jira you are using.
- You need a license for JSU. You can use a free Evaluation license for 30 days. Learn about our [pricing tiers](https://marketplace.atlassian.com/apps/5048/jsu-automation-suite-for-jira-workflows?hosting=cloud&tab=pricing) in our Marketplace listing.

## Install JSU

Installing JSU is similar to installing any other Jira app using the Universal Plugin Manager (see [Managing Add-ons](https://confluence.atlassian.com/adminjiracloud/managing-apps-776830283.html) in the Jira documentation).

**To install JSU:**

1. Log in to Jira as a Jira Administrator.
2. Select the **Jira** **Settings** cog in the top right of your Jira instance and select **Apps**. The *Find New Apps* page displays.
3. Type `JSU` in the search field and press `Enter`.
4. The JSU app displays. Select the app, then click **Try it Free** to install it.
5. Click **Start Free Trial**. A confirmation message and the app details display once the installation is successful.

## Update JSU

Updating JSU is similar to updating any other Jira app with the Universal Plugin Manager (see [Managing add-ons](https://confluence.atlassian.com/adminjiraserver073/managing-add-ons-861253081.html) in the Jira documentation).

**To update JSU:**

1. Log in to Jira as a Jira Administrator.
2. Select the **Jira Settings** cog and select **Apps**.
3. Select **Manage apps** under *Atlassian Marketplace* in the left sidebar.
4. LocateJSU in the list of installed apps and select **Update**.
