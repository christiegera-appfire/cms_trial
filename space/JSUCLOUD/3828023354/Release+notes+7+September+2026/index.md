# Release notes 7 September 2026

**Release date**: September 7, 2026

Our team is pleased to announce the latest release of JSU Automation Suite for Jira Workflows.

This release note covers JSU Cloud version `11.0.0`.

---

## Improvements

The following improvements are available in this release:

### In-app guidance

In-app guidance has been improved for more reliable display of guidance content, including images in surveys.

### Migrations using JCMA

Migrations from Connect to Forge have been improved, including:

- **Reliability** with fewer failures and conditions when migrating JSU workflow rules with Jira Cloud Migration Assistant.

- **Migration status and reports** including updated migration reports when migration events are duplicated or retried; reports are no longer overwritten or loaded incorrectly.

## Bug fixes

This release includes the following bug fixes:

- In-app guidance - Survey images now load correctly in Jira.
