## Scope added

- `read:user-configuration:jira` was added to the app permissions scope. This permission allows the reading of a user’s timezone and locale for use in future releases. If you are not automatically upgraded to the latest version of JSU for Jira Cloud (4.0.0), you can manually update it on the *Connect apps* page in Jira.
