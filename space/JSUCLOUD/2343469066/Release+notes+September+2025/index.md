# Release notes September 2025

**Release date**: September 8, 2025

Our team is pleased to announce the latest release of JSU Automation Suite for Jira Workflows.

## New features

## Copy all comments

- **Create a Linked Issue post function:** You can now copy all comments from one issue to another field in the same issue or to the new issue with the *Copy to New* subfunction. If you use the **Copy As Original Author** option, the author must have comment permissions on the new issue.

  ![Screenshot of the Copy All Comments option in the Create Linked Issue configuration page.](/cms_trial/assets/2c6d0137-6272-4285-b8d9-6a2ea1fad0a7.png)

  See [Create a Linked Issue post function](/cms_trial/space/JSUCLOUD/12518348/Create+a+Linked+Issue+post+function/) to learn more.
