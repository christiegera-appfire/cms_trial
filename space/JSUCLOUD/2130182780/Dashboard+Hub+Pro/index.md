# Dashboard Hub Pro

This page provides examples of how you can use Dashboard Hub’s [ITSM template](https://appfire.atlassian.net/wiki/spaces/RDD/pages/146309962?ref=xjsu) to visualize how JSU automation is performing in your project workflows. The template includes gadgets to support all aspects of an ITSM team's delivery of an excellent experience for employees and external customers.

You can combine JSU’s powerful automation with Dashboard Hub’s visual insights to enable support teams to work faster, smarter, and more transparently.

If you aren’t already using Dashboard Hub Pro, you can start a free trial from our Atlassian [Marketplace listing](https://marketplace.atlassian.com/apps/1223898/dashboard-hub-pro-charts-reports-time-in-status-tables?hosting=cloud&tab=overview).

## Accelerate first responses

Use JSU to assign or add a comment on ticket creation to reduce time to first response. Then, use Dashboard Hub’s *Time to First Response* gadget to demonstrate immediate improvements in SLA performance, critical for customer satisfaction.

|  |  |
| --- | --- |
| **JSU** | Add a comment using the [Update any issue field](/cms_trial/space/JSUCLOUD/12518373/Update+Any+Issue+Field+post+function/) post function |
| **Dashboard Hub** | [Time to first response](https://appfire.atlassian.net/wiki/spaces/RDD/pages/146309393?ref=xjsu) gadget |

![Screenshot of an example Time to First Response gadget.](/cms_trial/assets/fdb1ace0-8365-4365-a3d6-6edfb5d9ec8b.png)

## Automate issue triage

JSU can automatically assign new tickets based on group membership, ensuring the right agents receive tasks instantly. With Dashboard Hub's *Agent’s Workload* gadget, leads can monitor fair distribution and SLA compliance in real time, boosting motivation and reducing delays.

|  |  |
| --- | --- |
| **JSU** | Update the assignee with the[Update any issue field](/cms_trial/space/JSUCLOUD/12518373/Update+Any+Issue+Field+post+function/) post function and the [User in Groups](/cms_trial/space/JSUCLOUD/12517924/User+in+Groups+precondition/) pre-condition. |
| **Dashboard Hub** | [ITSM template](https://appfire.atlassian.net/wiki/x/SoO4C?ref=xjsu) and [Agent’s Workload](https://appfire.atlassian.net/wiki/x/uIC4C?ref=xjsu) gadget |

![Screenshot of the Agents' Workload gadget.](/cms_trial/assets/87ec5f47-e4df-4042-bbc9-76d4d841e6e7.png)

## Optimize ticket resolution

JSU automates actions like closing stale tickets or triggering follow-ups, which boosts the resolution rate. Dashboard Hub’s *Created vs Resolved Requests* gadget provides clear visibility into throughput, helping managers track and improve team efficiency.

|  |  |
| --- | --- |
| **JSU** | Add a comment with[Update any issue field](/cms_trial/space/JSUCLOUD/12518373/Update+Any+Issue+Field+post+function/) post function and trigger a [Linked transition](/cms_trial/space/JSUCLOUD/12518766/Linked+Transition+post+function/) post function. |
| **Dashboard Hub** | [Created vs Resolved Requests](https://appfire.atlassian.net/wiki/spaces/RDD/pages/146310463?ref=xjsu) gadget |

![Screenshot of the Created vs Resolved Requests gadget.](/cms_trial/assets/151da1bc-fe72-4a6a-9087-f5b426a56472.png)
