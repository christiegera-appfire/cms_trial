# Release notes November 2024

**Release date**: November 5, 2024

Our team is thrilled to announce the latest release of Planning Poker for Jira Cloud.

---

## New features

### Quick Add to Game Backlog

You can now quickly add individual items to the game backlog using the new **Add issue to backlog** option. This feature streamlines the process of updating your game backlog, saving you time when adding extra items on the go.

![image-20241105-181408.png](/cms_trial/assets/9853a0fe-f992-4ff3-8629-45034cad19f9.png)

### Sort Items in Game Backlog

The **Order by** option now enables you to sort items within columns in the game backlog. You can organize items based on variables such as Jira rank, priority, or status, and toggle between ascending or descending order. Sorting by one field also allows switching between filter mode and JQLmode. By default, items are ordered by rank in ascending order, consistent with JQL conventions.

![image-20241105-181620.png](/cms_trial/assets/e213609e-6437-4e0e-b2be-c07219571526.png)

**Note:** In JQL mode, you can sort by two fields simultaneously, but this is not available in filter mode. If you switch from JQL mode (where two fields are selected) to filter mode, ordering by multiple fields will be disabled.
