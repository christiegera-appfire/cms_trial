# Release notes 3.0.53

**Release date**: October 11, 2024

Our team is thrilled to announce the latest release of Planning Poker for Jira Data Center, version 3.0.53.

**Jira compatibility**:Jira 9 and Jira 10

---

## New features

Appfire is excited to introduce the following updates to Planning Poker for Jira DC.

### "Last used" filter

To enhance the convenience of finding games faster, we’ve introduced a “Last used” filter on the dashboard. By default, the filter shows games from the last 90 days to ensure that users can easily locate and load the most recent games.

![image-20241001-105930.png](/cms_trial/assets/9f11a2f0-6caf-47f5-a429-6d0a44aa265c.png)

![contentId-1336443112](/cms_trial/assets/c14c77c4-6775-4773-b1e7-f813655ca35b.png)

This feature helps you quickly access the games you need without having to scroll through older sessions, improving overall efficiency in game selection.
