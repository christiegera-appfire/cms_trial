# Release notes September 2024

**Release date**: September 6, 2024

Our team is thrilled to announce the latest release of Planning Poker for Jira Cloud.

---

## Enhancements

Appfire is excited to introduce the following updates to Planning Poker for Jira Cloud.

### Full-screen attachment viewing

You can now expand attachments within the description field and comments to full-screen size without leaving the planning poker session screen. This provides a more immersive and detailed view of important visual content, allowing users to discuss and collaborate on project details more effectively.
