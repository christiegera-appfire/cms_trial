# Release notes August 2024

**Release date**: August 22, 2024

Our team is thrilled to announce the latest release of Planning Poker for Jira Cloud.

---

## Enhancements

These new enhancements streamline the planning process and provide greater flexibility for teams.

## Game Management

### Save and Finish

The **Save** button is enabled when unestimated items are in the game backlog. In this situation, a specific button is provided for finishing the game.

![contentId-1234108523](/cms_trial/assets/b4f115b8-f04b-4469-884f-1b726f464edd.png)

The **Save & Finish** buttonwill only be visible if users estimate the last item from the backlog and all items above it have been estimated.

![contentId-1234108523](/cms_trial/assets/ede789cf-d4c3-42e1-8db2-7f61bfb61bc0.png)

### Direct Jira Access

After completing a game, users can easily navigate to Jira to view estimated items by clicking the **Open issues in Jira** button.

![contentId-1234108523](/cms_trial/assets/36c3682b-8032-4c8b-9614-79a0797d917d.png)

![contentId-1234108523](/cms_trial/assets/2e351884-4121-44f5-bc7d-dcd9e730cfd8.png)

## Game Cloning

### Backlog Duplication

When cloning a game, users now have the option to duplicate the game backlog as well, preserving the existing issue list for the new game.

![contentId-1234108523](/cms_trial/assets/f44caaa2-e8b5-4be2-82c9-1ec2d934cc83.png)

## Issue Search

### Keyword Search

The search field within the *Add issues* section supports searching by either issue summary or key, making it easier to find and add specific items to the game.

![contentId-1234108523](/cms_trial/assets/d468c6fb-2599-4ff9-a4b3-a805aa0ccc7b.png)
