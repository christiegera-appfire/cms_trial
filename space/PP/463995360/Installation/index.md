# Installation

This page applies to both **Planning Poker for Jira Cloud** and **Jira Data Center**.

Welcome to Planning Poker for Jira! We’re happy to see you here.

Planning Poker for Jira is an agile estimation tool designed by Scrum Masters for remote and co-located teams. It enables productive discussions within agile teams, leading to consensus-driven estimations. Development teams can collaboratively gauge the effort required for tasks, sub-tasks, or epics using story points, T-shirts, or customized values, all in real time.

This page contains step-by-step instructions on how to install Planning Poker for Jira.

## Prerequisites

- You must be a Jira administrator ([Cloud](https://confluence.atlassian.com/adminjiracloud/managing-global-permissions-776636359.html), [DC](https://confluence.atlassian.com/jirasoftwareserver/permissions-overview-939938996.html)) to carry out the instructions on this page.
- Installing Planning Poker is like installing any other Jira app (see Managing add-ons in the Jira documentation ([Cloud](https://confluence.atlassian.com/adminjiracloud/managing-apps-776830283.html), [DC](https://confluence.atlassian.com/adminjiraserver/managing-apps-938846929.html)).

## How to install Planning Poker for Jira Cloud

1. Log in to your Jira Cloud instance as a Jira Administrator.
2. Select the **Jira** **Settings** cog in the top right of your Jira instance and select **Apps**. The *Find New Apps* page displays.
3. Type `Planning Poker` in the search field and press **Enter**.
4. Click **Try it free** to install your app.
5. Click **Start Free Trial**. A confirmation message displays once it installs successfully.

Once installed, Planning Poker will add a new menu item to the Jira top menu Apps and project sidebar.

## How to install Planning Poker for Jira Data Center

1. Log in to your Jira Data Center instance as a Jira Administrator.
2. Select the **Jira** **Settings** cog in the top right of your Jira instance and select **Manage** **Apps**. The *Find New Apps* page displays.
3. Type `Planning Poker` in the search field and press **Enter**.
4. Click **Free trial** to start installing your app.

   ![contentId-463995360](/cms_trial/assets/d2890a92-6349-446d-bb28-cfcff652c056.png)
5. Click **Accept & Install**. A confirmation message displays once it installs successfully.

Once installed, Planning Poker will add a new menu item in the Jira top menu and project sidebar.
