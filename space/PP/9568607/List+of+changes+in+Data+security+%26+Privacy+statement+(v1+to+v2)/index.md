# List of changes in Data security & Privacy statement (v1 to v2)

This page outlines changes to **Data security & Privacy statement** for Planning Poker app introduced on January 29, 2022:

- v2 - new version of the statement: [Data security & Privacy statement v3](/cms_trial/space/PP/9568600/Data+security+%26+Privacy+statement+v3/)
- v1 - previous (old) version of the statement: [Data security & Privacy statement v1](/cms_trial/space/PP/9568453/Data+security+%26+Privacy+statement+v1/)

Please review the details of the changes below. We have indicated changes in the text by underlining them.

| **Change affects** | **New version** | **Previous version** | **Explanation of changes** |
| --- | --- | --- | --- |
| the whole document | - App - The App | - Add-on - The add-on | Wording update: we have unified the wording to be consistent with Atlassian’s glossary. |
| [Definitions](/cms_trial/space/PP/9568600/Data+security+%26+Privacy+statement+v3/) section | **Personal Information**: information that may be used to identify or contact you as a natural person | **Personal Information**: information that may be used to readily identify or contact you as an individual person | Minor wording update. |
| [Content](/cms_trial/space/PP/9568600/Data+security+%26+Privacy+statement+v3/) section | We collect and store Content that you create, input, submit, post, upload, transmit, store or display in the process of using our SaaS Products or Websites | We collect and store Content that you create, input, submit, post, upload, transmit, store or display in the process of using the App or Websites | Replaced reference to “SaaS Products” with “the App” to make it more precise. |
| [Web Logs](/cms_trial/space/PP/9568600/Data+security+%26+Privacy+statement+v3/) section | added  Logs are kept for past 30 days. | - | Added information about logs storage duration. |
| [Analytics Information](/cms_trial/space/PP/9568600/Data+security+%26+Privacy+statement+v3/) section | Analytics can be disabled from Global Configuration page of the App. | Analytics can be disabled from Global Configuration page of apps. | Wording correction. |
| [Service Providers, Business Partners and Others](/cms_trial/space/PP/9568600/Data+security+%26+Privacy+statement+v3/) section | added   - [Google Cloud Platform](https://cloud.google.com/gcp) - Cloud services provider - [MongoDB Atlas](https://www.mongodb.com/atlas) - Cloud Database storage   DROPPED   - [Digital Ocean](https://www.digitalocean.com/) - SSD Cloud Hosting decommissioning | - [Digital Ocean](https://www.digitalocean.com/) - SSD Cloud Hosting | Planning Poker data is migrated from [Digital Ocean](https://www.digitalocean.com/) service provider to [MongoDB Atlas](https://www.mongodb.com/atlas);  Planning Poker backend services are moved from [Digital Ocean](https://www.digitalocean.com/) to [Google Cloud Platform](https://cloud.google.com/gcp); as soon as the migration is complete we will remove [Digital Ocean](https://www.digitalocean.com/) from the service provides list. |
| [Data flow](/cms_trial/space/PP/9568600/Data+security+%26+Privacy+statement+v3/) section | The API services are hosted in Google Cloud Platform. Data is stored in MongoDB Atlas service with Google Cloud Platform as the actual storage. | The API server is hosted on DigitalOcean. | See above |
