# Release notes 4.0.4 and 3.1.4

**Release date**: August 18, 2026

Planning Poker for Jira Data Center versions 4.0.4 for Jira 11 and 3.1.4 for Jira 10 include a bug fix.

**Jira compatibility**: Jira 11 and Jira 10

---

## Bug fixes

This release includes the following bug fix:

- Fixed an issue where the backlog table didn't show issue type icons or summaries when you first opened the game screen. Those details now load immediately with the rest of the issue details (type, priority, key, and summary), instead of only appearing after you selected **Estimate** or **Estimate now** on a backlog item.
