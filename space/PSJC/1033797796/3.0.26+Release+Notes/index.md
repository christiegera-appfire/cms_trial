# 3.0.26 Release Notes

**Release date**: June 8, 2024

Our team is pleased to announce the 3.0.26 release of Power Scripts for Jira Cloud. This release is aimed to fix some security and UI bugs, and to improve operations over your containers.

---

## New features

- Better container management, the UI now gives clear messages when you need to restart your container or when you need to ask for a resize.

---

## Enhancements

- Panels have been improved and renamed to “Power Scripts“. Panels have now the ability to refresh the information (i.e. re-execute the template)
- When restarting the engine, the SIL Manager now keeps the page open, so if you were editing, you will have a chance to save your script after the engine started.
- SIL Manager buttons are now disabled when running scripts.
- Marked "description" as optional parameter for createCustomerRequest() routine

---

## Bug fixes

The following bugs are fixed in this release:

- Two relatively minor security flaws, one linked to the SIL panels.
