# 3.0.23 Release Notes

**Release date**: April 26, 2024

Our team is pleased to announce the 3.0.23 release of Power Scripts for Jira Cloud. This is a minor bug fix release carrying over some improvements as well.

---

## New features

- Added selectIssuesByFilter()

---

## Enhancements

- Groundwork improvements for **Scripted Custom Fields**. They will be available soon.
- Memory footprint lowered, again. We will continue to monitor this and identify where we may improve things.
- Execution advisor rules were reviewed to print more relevant messages.

---

## Bug fixes

The following bugs are fixed in this release:

- Scripted custom fields - delete issue type on edit screen, disappears completely from the options list.
- getFilterByName() was not returning the JQL in the JFilter structure.
