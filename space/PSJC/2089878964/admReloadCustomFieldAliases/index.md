# admReloadCustomFieldAliases

Reloads the sil.aliases file.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admReloadCustomFieldAliases() | **Package** | adm |
| **Alias** |  | **Pkg Usage** | reloadCustomFieldAliases() |

## Return Type

**boolean**

Returns true if the reload was started and false otherwise.
