# System Performance

This page offers some insights in the memory and CPU consumption of the system, as a whole.

We keep for 24h a record of the following characteristics:

1. JVM Memory usage (broke down in Heap and Non-Heap memory usage)
2. CPU Usage (System load)
3. Total number of threads created by the app

You can access these graphs from the **Performance Monitoring** > **System** menu:

![Power Scripts for Jira Cloud action script configuration](/cms_trial/assets/09ce58f4-707c-4f9b-9e70-7f7628a20583.png)

Total memory usage is always a bit greater than the actual sum of the Heap and Non-Heap memory, however the above is a good indicator of the constraints you face in the SIL Engine.

To examine the values at a certain time, drag the area below the graph right or left:
