# 7.2.2 Release notes

**Release date:** September 23, 2026

This page outlines the updates included in the latest release of Power Scripts for Jira Cloud.

---

## Bug fixes

This release resolves the following issues:

- Fixed an issue that could cause a Power Scripts execution container to be incorrectly identified as unused and shut down during a sandbox reset.
- Fixed a Jira Cloud Migration Assistant (JCMA) migration issue that could cause workflow post functions to have the wrong scripts attached after migration.
