# 3.1.3 Release Notes

**Release date**: September 18, 2024

Our team is pleased to announce the 3.1.3 release of Power Scripts for Jira Cloud. This is a minor maintenance release

---

## New features

- Added a new routine to delete directories, if they are empty: deleteDir. We are not sure how did we miss that so far.

---

## Enhancements

- userInGroup() routine was consuming too much memory, and it was inefficient, we optimized that

---

## Bug fixes

The following bugs are fixed in this release:

- Script templates now show immediately in SIL Manager
- Persistent variables panel was not treating values of persistent variables quite right
