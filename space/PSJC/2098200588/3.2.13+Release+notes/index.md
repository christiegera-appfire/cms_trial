# 3.2.13 Release notes

**Release date**: June 9, 2025

This release includes a hotfix for Power Scripts for Jira Cloud.

---

## Hotfixes

The following are the hotfixes in this release:

- Reverted a previous fix for struct parameter validation in SIL Manager script check due to introduced side effects. The script check will no longer validate array index references to non-existent struct parameters.
