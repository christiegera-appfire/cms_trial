# radians

## Description

Converts degrees into radians.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | radians(degrees) | **Package** |  |
| **Alias** |  | **Pkg Usage** |  |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| degrees | Number | Yes | Angle in degrees that you want to convert. |

## Return Type

**Number**

## Example

```javascript
number a = radians(180);
print("a= " + a);
```

Prints: a= 3.14159;
