# degrees

## Description

Converts radians to degrees.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | degrees(radians) | **Package** |  |
| **Alias** |  | **Pkg Usage** |  |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| radians | Number | Yes | Angle in radians you want to convert. |

## Return Type

**Number**

## Example

```javascript
number a = degrees(pi());
print("a= " + a);
```

Prints: a= 180;
