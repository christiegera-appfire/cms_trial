# 3.0.20 Release Notes

**Release date**: March 11, 2024

Our team is excited to announce the 3.0.20 release of Power Scripts for Jira Cloud.

---

## New features

- Added a token expiry mechanism so you can declare invalid webhook tokens
- Improved support, additional available options, and screens for custom fields
- Added more than 50 new routines
- Redesigned JQL page to make it more intuitive

---

## Enhancements

- Enhanced support for issue-type screen schemes and three new issue types routines
- Added and improved the following custom field routines:

  - admAddCustomFieldAlias
  - admCreateCustomField
  - admUpdateCustomField
  - admDeleteCustomField
  - admGetCustomFieldOptions
  - admAddCustomFieldOptions
  - admUpdateCustomFieldOptions
  - admDeleteCustomFieldOptions
- Added upload and download attachment routines
- Added getProjectIdByKey and getProjectKeyById routines
- JQL is now able to calculate properties just for selected projects/project categories

---

## Bug fixes

The following bugs are fixed in this release:

- Text-ADF was unable to parse non-header **##** constructs
- Get status by name was returning a 401 error
- The file creation failed to create a action using the wizard’s New Script option
- Users could not change the **Time Zone**
- Users could not load more than 5,000 issue worklogs
