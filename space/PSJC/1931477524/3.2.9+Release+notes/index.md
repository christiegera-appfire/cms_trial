# 3.2.9 Release notes

**Release date**: April 8, 2025

Our team is thrilled to announce the latest release of Power Scripts for Jira Cloud.

This release introduces the new *Forms and Wizards* feature and an enhancement to trace recording.

---

## New features

### Forms and Wizards

Introducing full support for Forms and wizards in Jira Cloud, bringing the popular Power Actions app for Jira DC functionality to cloud environments. Users can now create custom interactive forms and guided wizards directly within the Jira Cloud interface.

---

## Enhancements

### Traces recording time limit

Introduced an automatic time limit for trace recording to help preserve system performance. Users can now select a duration (ranging from 15 minutes to 24 hours), after which traces will automatically disable, preventing prolonged performance impact while collecting diagnostic information.
