# Managing persistent variables

New in 5.8.0.x, persistent variables can be managed directly from the SIL Manager!

![Power Scripts for Jira Cloud variable settings form](/cms_trial/assets/4668e790-978c-4d78-ac18-31ef67c53b59.png)

## Creating Variables

To create persistent variables from the SIL Manager:

1. Open the **Persistent Variable tab** by click the tab on the right side of the SIL Manager
2. Click the **plus icon** in the upper right corner of the panel

   ![Power Scripts for Jira Cloud variable value display](/cms_trial/assets/e12344cb-80c4-49da-a792-b171120e42cd.png)
3. A window will appear allowing a new variable to be created

   ![Power Scripts for Jira Cloud selfhelp interface overview](/cms_trial/assets/770d5e5f-1665-4bc4-b0d2-4333e78ec524.png)
4. Enter an issue key in the **Context** field is the variable should only apply to a *specific issue*
5. Give the variable a unique name in the **Name** field
6. Enter a value for the field in the **Value** field
7. Click **OK**

## Editing and Deleting Variables

To **edit** a persistent variable:

1. Open the **Persistent Variable tab** by click the tab on the right side of the SIL Manager
2. Click inside the field value to enable the inline editing mode

   ![Power Scripts for Jira Cloud monitoring dashboard interface](/cms_trial/assets/c14cf00b-e22a-427e-aa4c-ccb395002bfd.png)
3. One the new value is entered click the **check** icon

To **delete** a persistent variable:

1. Open the **Persistent Variable tab** by click the tab on the right side of the SIL Manager
2. Click **trash can** icon next to the persistent variable name

When editing or deleting a persistent variable that is in the **context of an issue**, those changes will only be applied for that specific issue.
