# Get started with Power Scripts for Jira Cloud

Power Scripts for Jira Cloud lets you automate Jira processes and customize how Jira works using Simple Issue Language (SIL) scripts. These quick-start guides walk you through common first tasks so you can start creating and running automations without needing to learn everything about Power Scripts first.
