# admRemoveFieldConfigDefaultITMapping

## Description

Removes the default issue type - field configuration mapping for a field configuration scheme

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admRemoveFieldConfigDefaultITMapping(schemeId) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [admRemoveFieldConfigDefaultITMapping(schemeId)] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| schemeId | int | Yes | Id of the config scheme |

## Return Type

**boolean**

Returns true if operation succeeded
