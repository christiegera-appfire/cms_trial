# admRemoveFieldConfigITMapping

## Description

Removes the issue type - field configuration mapping for a field configuration scheme

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admRemoveFieldConfigITMapping(schemeId, issueTypeId) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [removeFieldConfigITMapping(schemeId, issueTypeId)] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| schemeId | int | Yes | Id of the config scheme |
| issueTypeId | int | Yes | Id of the issue type |

## Return Type

**boolean**

Returns true if operation succeeded
