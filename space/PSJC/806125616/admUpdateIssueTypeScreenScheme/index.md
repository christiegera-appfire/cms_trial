# admUpdateIssueTypeScreenScheme

## Description

Updates an Issue Type Screen Scheme (ITSS)

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admUpdateIssueTypeScreenScheme(issueTypeScreenSchemeId, name, description) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | updateIssueTypeScreenScheme(issueTypeScreenSchemeId, name, description) |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| issueTypeScreenSchemeId | integer | Yes | The ID of the issue type screen scheme. |
| name | string | Yes | The new name of the scheme. |
| description | string | Yes | The description of the scheme. |

## Return Type

[**JIssueTypeScreenScheme**](/cms_trial/space/PSJC/435028065/Predefined+structure+types+reference/)

Returns an issue type screen scheme.
