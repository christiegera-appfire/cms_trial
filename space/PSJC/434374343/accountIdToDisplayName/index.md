# accountIdToDisplayName

## Description

Returns the display name for the provided user key.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | accountIdToDisplayName(userKey) | **Package** |  |
| **Alias** | userKeyToDisplayName(userKey) | **Pkg Usage** |  |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| user key | String | Yes | User key. |

## Return Type

**String**

## Example

```javascript
string displayName = accountIdToDisplayName("someUserKey");
```
