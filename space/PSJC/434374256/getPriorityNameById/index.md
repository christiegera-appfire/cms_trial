# getPriorityNameById

|  |  |  |  |
| --- | --- | --- | --- |

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| priorityId | String | Yes | Id of the priority. |

## Return Type

**String**

## Example

```javascript
return getPriorityNameById(3); //where 3 is the priority id for Medium
```
