# Live Fields

With **Live Fields for Jira Cloud**, customize field behaviors dynamically. Modify fields to show/hide, enable/disable, or auto-populate them across the Create Issue, Issue, or Transition View (coming soon).

Built as a separate Forge app to work seamlessly in Jira Cloud, **Live Fields is free** with a paid license for Power Scripts for Jira Cloud.

**Live Fields for Jira Cloud** enables you to customize your Jira interface extensively! Using JavaScript or TypeScript, Live Fields execute scripts on several Jira screens to hide or show, enable or disable, automatically calculate or validate fields, and more!
