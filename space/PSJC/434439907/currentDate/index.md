# currentDate

## Description

Returns the current date.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | currentDate() | **Package** |  |
| **Alias** |  | **Pkg Usage** |  |

## Return Type

**Date**

## Example

```javascript
dueDate = currentDate() + "3d";
```

Returns the 3rd day after the current day.
