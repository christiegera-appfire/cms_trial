# Keyboard Shortcuts

Keyboard shortcuts are available for frequently used SIL script operations.

## Most Popular

| Windows/Linux | Mac | Action |
| --- | --- | --- |
| Shift + Enter | Shift + Enter | Check the SIL code |
| Ctrl + S | Commans + S | Save |
| Ctrl + / | Command + / | Toggle line comment |
| Ctrl + Shift + / | Command + Shift + / | Toggle selection comment |
| Ctrl + Space | Command + Space | Show autocomplete suggestions |
| Ctrl + K | Command + K | Go to the next occurrence of the selection |
| Ctrl + Shift + K | Command + Shift + K | Go to the previous occurrence of the selection |
| Ctrl + L | Command + L | Jump to line |
| Tab | Tab | Indent selection |
| Shift + Tab | Shift + Tab | Outdent selection |
| Alt + Up/Down | Option + Up/Down | Move the line up/down |
| Alt + Shift + Up/Down | Command + Option + Up/Down | Copy line up/down |
| Ctrl + D | Command + D | Delete line |

## Line Operations

| Windows/Linux | Mac | Action |
| --- | --- | --- |
| Ctrl + D | Command + D | Remove line |
| Alt + Shift + Down | Command + Option + Down | Copy lines down |
| Alt + Shift + Up | Command + Option + Up | Copy lines up |
| Alt + Down | Option + Down | Move lines down |
| Alt + Up | Option + Up | Move lines up |
| Alt + Delete | Ctrl + K | Remove to the line end |
| Alt + Backspace | Command + Backspace | Remove to line start |
| Ctrl + Backspace | Option + Backspace, Ctrl + Option + Backspace | Remove one word left |
| Ctrl + Delete | Option + Delete | Remove one word right |
| + + + | Ctrl + O | Split line |

## Multicursor

| Windows/Linux | Mac | Action |
| --- | --- | --- |
| Ctrl + Alt + Up | Ctrl + Option + Up | Add multi + cursor above |
| Ctrl + Alt + Down | Ctrl + Option + Down | Add multi + cursor below |
| Ctrl + Alt + Right | Ctrl + Option + Right | Add the next occurrence to multi + selection |
| Ctrl + Alt + Left | Ctrl + Option + Left | Add previous occurrence to multi + selection |
| Ctrl + Alt + Shift + Up | Ctrl + Option + Shift + Up | Move the multicursor from the current line to the line above |
| Ctrl + Alt + Shift + Down | Ctrl + Option + Shift + Down | Move the multicursor from the current line to the line below |
| Ctrl + Alt + Shift + Right | Ctrl + Option + Shift + Right | Remove the current occurrence from the multi + selection and move to the next |
| Ctrl + Alt + Shift + Left | Ctrl + Option + Shift + Left | Remove the current occurrence from the multi + multi-selection and move to the previous |
| Ctrl + Shift + L | Ctrl + Shift + L | Select all from the multi + selection |
