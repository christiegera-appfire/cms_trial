# admCreateScreenTab

## Description

Creates a screen tab. Returns the id ot the tab.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admCreateScreenTab(screenId, tabName) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [use adm; createScreenTab(screenId, tabName);] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| screenId | int | Yes | The screen id. |
| tabName | string | Yes | The tab name. |

## Return Type

**int**
