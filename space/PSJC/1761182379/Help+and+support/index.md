# Help and support

## Request help

If you need assistance with the app, migrations, or have any questions, submit a request through our [support portal](https://appf.re/support). Our support team is always happy to help.

## Create a support request from the app

You can create a support request without leaving the Power Scripts app.

![Power Scripts Configurations section with the Help tab highlighted.](/cms_trial/assets/f4895626-a771-48d6-a34b-13169bb51852.png)

1. Go to **Apps** > **Manage apps** > **Power Scripts** > **Configurations**.
2. Click the *Help* tab.
3. Click **Marketplace apps** to open the support portal, or click **Docs** to go to our documentation.

## Send an email

You can reach out to our support team by sending an email to [support@appfire.com](mailto:support@appfire.com).

## Manage your solution with the Self Help tool

To manage your SIL Engine and related administrative functions, use the [Self Help](/cms_trial/space/PSJC/516456599/Managing+your+solution%3A+Self-Help/) tool. This feature provides access to engine operations, monitoring capabilities, backup and restore functionality, resource management, system messages, and security configurations, including Atlassian API token setup and TLS/SSL implementation.

![Power Scripts for Jira Cloud selfhelp resources panel](/cms_trial/assets/73a0ddb4-45ac-44c1-97c7-cb1bd7cadde7.png)

To access the Self Help tool:

1. Go to **Apps** > **Manage apps** > **Power Scripts** and click **Self Help**.
2. Use the *Self Help*menus to access the different functionalities of the tool.

For details, see the [Self Help feature page](/cms_trial/space/PSJC/516456599/Managing+your+solution%3A+Self-Help/).

## Get configuration details

The **Performance Monitoring > SIL Diagnostic** section provides a tool for users who need advanced scripting or configuration assistance.

![Power Scripts for Jira Cloud SIL diagnostic tools interface](/cms_trial/assets/da7c9c41-a245-4703-abde-c6717163d09e.png)

This tool makes it quick and easy to send your script environment information to the customer support team at Appfire, including:

- **SIL Parameters**: Configuration details such as script home location, database connections, caching settings, character encoding, and email configurations
- **SIL Environment**: Environment variables including timezone settings and directory paths that affect script execution

These technical details help the support team accurately diagnose script behavior in your specific environment.
