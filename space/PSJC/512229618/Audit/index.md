# Audit

Audit traces and configuration changes are recorded here.

We also keep a record of the boot times, the configuration changes and other administrative tasks actions that you may have taken. These messages can be found in **Settings** > **Audit**

![Power Scripts for Jira Cloud audit log interface showing script execution history](/cms_trial/assets/1d0bb723-97ad-4ce6-a0db-1f891085a2fd.png)

You may filter for INFO, WARN or ERROR messages
