# admDeleteScreen

## Description

Deletes a screen. Returns true if deletion was performed.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admDeleteScreen(screenId) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [use adm; deleteScreen(screenId);] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| screenId | int | Yes | The id of the screen to be deleted. |

## Return Type

**boolean**
