# 7.2.0 Release notes

**Release date:** September 7, 2026

This page outlines the updates included in the latest release of Power Scripts for Jira Cloud.

---

## Bug fixes

This release includes the following bug fixes:

- Fixed an issue where the `hasLinkType`JQL keyword did not update correctly.
- Fixed an issue where the **Issue Link Added** and **Issue Link Removed** listeners were not triggered.
- Fixed an issue with the SIL Manager download context menu button.
- Fixed an issue with the Self Help Upload/Restore functionality.
- Fixed an issue with the license check used by Live Fields.
- Fixed an issue where an error occurred when opening a post function or action link in a new tab.
