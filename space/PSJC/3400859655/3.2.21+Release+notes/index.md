## Enhancements

The following enhancements are included in this release:

### Introduced new workflow post function management functions

To make it easier to automate workflow configuration in Jira Cloud, we've added the following workflow post function management functions:

- [addSILWorkflowAction](/cms_trial/space/PSJC/3394306172/addSILWorkflowAction/): Adds a SIL post function to a specified workflow transition, registers the SIL script, and optionally configures it to run asynchronously.
- [getSILWorkflowActionPath](/cms_trial/space/PSJC/3394207925/getSILWorkflowActionPath/): Returns the SIL script path registered for a workflow post-function action by using its action ID.

This release makes it easier to automate workflow configuration in Jira Cloud by adding functions to create and manage SIL workflow post functions programmatically. These enhancements reduce manual configuration, simplify workflow maintenance, and help you build automation more efficiently.
