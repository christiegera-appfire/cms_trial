# rand

## Description

Returns a random number between 0.00 and 1.00.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | rand() | **Package** |  |
| **Alias** |  | **Pkg Usage** |  |

## Return Type

**Number**

## Example

```javascript
number a = rand();
print("a= " + a);
```

Prints: a= 0.2655790724320535;
