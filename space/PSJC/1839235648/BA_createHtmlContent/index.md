# BA_createHtmlContent

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | BA\_createHtmlContent(html) | **Package** | poweraction |
| **Alias** | form\_createHtmlContent | **Pkg Usage** | createHtmlContent(html) |

## Description

Adds a plain HTML content to the screen.

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| html | String | Yes | The HTML content. |

## Return Type

**None**

The returned value has no meaning

## Example

```javascript
BA_createHtmlContent("<h1>Title</h1>");
```
