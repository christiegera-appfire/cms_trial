## Forge migration

Power Scripts for Jira Cloud now runs on Atlassian Forge, Atlassian’s Cloud development platform. This release brings enhancements to meet Forge’s technical and security standards.

Moving to Forge allows Power Scripts for Jira Cloud to use Atlassian's built-in security, compliance, and scalability features. This migration helps Appfire continue delivering secure, enterprise-grade apps that stay aligned with Atlassian's platform.

**Note**: This version of Power Scripts for Jira Cloud is Forge-compatible, but it does include data actions on remote systems. It does not qualify as Runs on Atlassian. Additionally, Power Scripts does not support data residency with this release.

If you previously tested your Jira Cloud Migration Assistant (JCMA) migration before this release, test it again in a development or staging environment before migrating your production data. The migration process has been updated for the Forge architecture, so previous test results might not reflect the current migration behavior.
