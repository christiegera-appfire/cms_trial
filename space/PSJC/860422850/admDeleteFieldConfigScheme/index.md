# admDeleteFieldConfigScheme

## Description

Deletes a field config scheme

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admDeleteFieldConfigScheme(schemeId) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [deleteFieldConfigScheme(schemeId)] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| schemeId | int | Yes | Id of the config scheme |

## Return Type

**boolean**

Returns true if the scheme is deleted
