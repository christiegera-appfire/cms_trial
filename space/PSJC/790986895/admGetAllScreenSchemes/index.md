# admGetAllScreenSchemes

## Description

Returns an array of screen schemes. All of them

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admGetAllScreenSchemes() | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [use adm; allScreenSchemes();] |

## Return Type

[**JScreenScheme []**](/cms_trial/space/PSJC/435028065/Predefined+structure+types+reference/)

## Example

```javascript
JScreenScheme [] schemes = admGetAllScreenSchemes();
```

Returns the JScreenScheme objects.
