# admDeleteScreenScheme

## Description

Deletes a screen scheme. Returns true if deletion was performed.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admDeleteScreenScheme(schemeId) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [use adm; deleteScreenScheme(schemeId);] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| schemeId | int | Yes | The id of the scheme to be deleted. |

## Return Type

**boolean**
