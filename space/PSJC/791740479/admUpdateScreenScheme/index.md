# admUpdateScreenScheme

## Description

Updates a screen scheme. Returns the updated JScreenScheme structure.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admUpdateScreenScheme(scheme) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [use adm; updateScreenScheme(scheme);] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| scheme | JScreenScheme | Yes | The scheme to be updated. It must contain an valid id and you must specify the name and default screen id |

## Return Type

[**JScreenScheme**](/cms_trial/space/PSJC/435028065/Predefined+structure+types+reference/)
