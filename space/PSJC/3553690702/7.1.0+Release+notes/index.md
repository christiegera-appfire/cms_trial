# 7.1.0 Release notes

**Release date:** August 11, 2026

This page outlines the updates included in the latest release of Power Scripts for Jira Cloud.

---

## Bug fixes

This release includes the following bug fix:

### Fixed unavailable workflow validations after an update

- Fixed an issue that could cause Power Scripts workflow validations to appear as unavailable after an update, resulting in affected workflows no longer working as expected.
