# 3.2.16 Release notes

**Release date**: October 6, 2025

Our team is thrilled to announce the latest release of Power Scripts for Jira Cloud.

This release includes performance improvements and a bug fix.

---

## Enhancements

This release includes the following performance improvements:

### Added the getCustomerObject function

This function returns a JUser structure. Refer to the [getCustomerObject](/cms_trial/space/PSJC/2232811610/getCustomerObject/) page for a complete description.

### Added the admGetWorkflowsFromScheme function

This function retrieves a list of workflows associated to a workflow scheme. Refer to the [admGetWorkflowsFromScheme](/cms_trial/space/PSJC/2255552747/admGetWorkflowsFromScheme/) page for a complete description.

### Reorganized the Admin configuration menu

We’ve simplified the Admin section by splitting the tabs into multiple sections. This change reduces the number of tabs on a single page and makes the entire layout more intuitive.

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed a bug related to the JCMA Migration.

---

This release makes it easier to manage and automate Jira administration by adding new functions to retrieve customer information and workflow scheme details, while simplifying navigation in the Admin configuration menu. Together, these enhancements reduce manual effort and help you work more efficiently.
