# admGetJVMTimezone

## Description

Returns the JVM timezone. Normally this is GMT-0

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admGetJVMTimezone() | **Package** | adm |
| **Alias** |  | **Pkg Usage** | getJVMTimezone() |

## Return Type

**string**

## Example

```javascript
use "adm";
return admGetJVMTimezone()
```
