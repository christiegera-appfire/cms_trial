# userCurrentDate

## Description

Returns the user current locale date, in the time-zone of the user. If it is not set, returns a null date

| --- | --- | --- | --- |

| --- | --- | --- | --- |
| accountId | string | Yes | The account Id |

## Return Type

**date**

Returns the user local date
