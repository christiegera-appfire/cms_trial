# admUpdateScreen

## Description

Updates a screen. Returns the updated JScreen structure.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admUpdateScreen(screen) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [use adm; updateScreen(screen);] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| screen | JScreen | Yes | The screen to be updated. It must contain an valid id and you must specify the name |

## Return Type

[**JScreen**](/cms_trial/space/PSJC/435028065/Predefined+structure+types+reference/)
