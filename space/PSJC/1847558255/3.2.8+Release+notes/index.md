# 3.2.8 Release notes

**Release date**: March 22, 2025

Our team is thrilled to announce the latest release of Power Scripts for Jira Cloud.

This release introduces enhanced JCMA migration support and performance across multiple components, and includes other enhancements and bug fixes.

---

## Enhancements

[unmapped inline: placeholder]

### Enhanced migration support

Improved migration capabilities by adding Jira Cloud Migration Assistant (JCMA) support for listeners, schedulers, webhooks, SIL panel, SIL configurations, and settings. This enhancement streamlines the migration process and ensures your custom configurations transfer smoothly.

### SIL Runner Gadget optimization

Optimized loading of SIL Runner Gadget when the userPicker / multiUserPicker is present, resulting in improved performance.

### Workflow Editor compatibility

Updated the implementation of conditions, validators, and post functions to support the new Workflow editor.

### Customer Detail fields

Improved customer detail fields functions for better data handling.

### Increased archive size limit

Increased the Backup/Restore archive size limit from 2 MB to 5 MB, allowing for larger data transfers.
