# 3.1.2 Release Notes

**Release date**: August 23, 2024

Our team is pleased to announce the 3.1.2 release of Power Scripts for Jira Cloud.

---

## New features

- Added new project admin routines in to order easily get and set the schemes of a project
- Notification schemes support: added three new structures and the support for them in JPermissionScheme and routines to support the functionality.

---

## Enhancements

- toJson() routine now accepts an optional 'datesFormat' param to allow you to specify date formats
- Security, internal libraries were upgraded

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed dashboard gadget scripts that couldn't be set
- Project key now accepts underscore
