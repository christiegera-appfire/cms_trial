# Jira Product Discovery support

Jira Product Discovery is a specialized tool for capturing and prioritizing product ideas. While it appears as a project type within Jira, Product Discovery uses custom features that replace many standard Jira functionalities. Since Power Scripts was designed to work with standard Jira projects, this creates compatibility limitations.

## What’s included in this section

Some Power Scripts features work fully with Product Discovery, while others have limited functionality or don't work at all. We're actively working to improve compatibility, but in the meantime, this section documents what's currently supported so you can still create effective automation.
