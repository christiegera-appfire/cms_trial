# Install Power Scripts for Jira Cloud

The Power Scripts app installation follows the standard procedure for Jira Cloud applications.

The app is available through subscription, starting with a free trial that automatically converts to a paid subscription when it ends. Visit the [Power Scripts for Jira Cloud](https://marketplace.atlassian.com/apps/43318/power-scripts-jira-workflow-automation?hosting=cloud&tab=overview) page on Atlassian Marketplace for more information.

### **Installation steps**

1. In Jira Cloud, go to **Apps** **>** **Explore more apps** or go to **Settings** > **Marketplace apps** and select **Explore apps**.
2. In the *Explore apps for Jira* search type `Power Scripts`.
3. To start the installation, click **Try it free**.

When the installation completes, *Power Scripts* appears in the left menu.

You can restart your trial only during the original trial period. Once the trial expires, your only option is to subscribe through the **Manage apps** page. For more details, see the [Atlassian documentation](https://confluence.atlassian.com/adminjiracloud/managing-add-ons-776830283.html#Managingadd-ons-Findandaddnewapps).
