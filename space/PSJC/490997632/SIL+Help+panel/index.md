# SIL Help panel

The SIL Help tab provides quick reference for SIL functions and syntax while you're writing scripts. Use it to look up function parameters, return types, and basic examples without leaving your script.

The SIL Help panel shows essential information for immediate reference. For comprehensive examples and detailed explanations, use the online documentation link provided in each help entry.

![Power Scripts for Jira Cloud SIL Manager startup interface](/cms_trial/assets/60c59c87-6f29-4fd3-8d3a-bae3b1df9b9c.png)

Here are some examples of how you can use the SIL Help panel:

| **To…** | **Do this…** |
| --- | --- |
| Search for functions | Start typing function names (for example, `arraysize` or `getUsersInGroup`). The results show function syntax, required parameters, return type information, basic code examples, as well as links to complete online documentation for detailed explanations. |
| Find syntax help | Search for language elements like `array`, `loop`, or `conditional` to see code examples. |
| Check operators | Quickly reference information about mathematical and logical operators by typing `operator` in the Search field. |
