# admGetAvailableGadgets

## Description

Returns all the gadgets available in the system.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admGetAvailableGadgets() | **Package** | adm |
| **Alias** |  | **Pkg Usage** | availableGadgets() |

## Return Type

[**JGadget []**](/cms_trial/space/PSJC/435028065/Predefined+structure+types+reference/)

The gadgets. All structures returned have no id and no position and are ready to be used by filling those attributes.
