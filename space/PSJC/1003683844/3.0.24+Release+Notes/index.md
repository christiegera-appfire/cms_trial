# 3.0.24 Release Notes

**Release date**: May 25, 2024

Our team is pleased to announce the 3.0.24 release of Power Scripts for Jira Cloud. Major features added, some unique in Atlassian Marketplace, reflecting our continuous investment in the product. We have the smartest customers, and you were right to stay with us!

---

## New features

- Ability to process incoming emails. Check [Incoming Mail configuration](/cms_trial/space/PSJC/994018140/Incoming+Mail+configuration/) and [Incoming Mail Processing Functions](/cms_trial/space/PSJC/999162356/Incoming+Mail+Processing+Functions/)
- Added groupsInRole()
- Web link routines added getWebLink(), getWebLinksForIssue(), updateWebLink(), deleteWebLink()
- Issue types scheme functions added

---

## Enhancements

- **Scripted Custom Fields** - added project category filter and the ability to sync values on issues
- getEventIssueFieldChange() may be now called with customfield\_NNNNN or alias
- **Power Scripts** now use everywhere Atlassian API 3
- Default memory model for new installs is increased
- Added an auto-resize feature when restarting / installing the SIL Engine

---

## Bug fixes

The following bugs are fixed in this release:

- SIL Runner Dashboard Item - Programs select renders to top instead of bottom and paths are overlapping on edit screen
