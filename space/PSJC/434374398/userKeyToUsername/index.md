# userKeyToUsername

## Description

Returns the username for the provided user key.

|  |  |  |  |
| --- | --- | --- | --- |

| user key | String | Yes | User key. |

## Return Type

**String**

Returns the username

## Example

```javascript
string username = userKeyToUsername("someUserKey");
```
