# admDeleteIssueTypeScheme

## Description

Deletes an issue type scheme.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admDeleteIssueTypeScheme(id) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | deleteIssueTypeScheme(id) |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| id | int | Yes | Id of the issue type scheme. |

## Return Type

**boolean**

Returns true if the issue type scheme is deleted.

## Example

```javascript
deleteIssueTypeScheme(10204);
```
