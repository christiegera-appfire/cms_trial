# 3.2.15 Release notes

**Release date**: July 28, 2025

Our team is thrilled to announce the latest release of Power Scripts for Jira Cloud.

This release includes performance improvements and a bug fix.

---

## Enhancements

This release includes the following performance improvements:

### **Improved SIL Manager performance when running scripts in Default Script Context**

Improved performance when running scripts in Default Script Context in SIL Manager, eliminating unnecessary delays.

### **Improved the usersInGroups function performance**

Enhanced `usersInGroups` function to reduce memory usage and prevent "SIL Engine needs attention" errors.

---

## Bug fixes

The following bugs are fixed in this release:

- **Fixed JCMA migration issue with incorrect validators and conditions placement:** Fixed an issue where validators and conditions were incorrectly migrated as post functions during Data Center to Cloud migration.

To prevent this, you must update your Power Scripts apps to the latest versions before using JCMA. For details on how to fix this issue if it has already occurred, please refer to our [Known issue: Incorrect placement of validators and conditions after migration to Jira Cloud](/cms_trial/space/PSJC/2268889432/Known+issue%3A+Incorrect+placement+of+validators+and+conditions+after+migration+to+Jira+Cloud/).
