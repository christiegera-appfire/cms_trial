# 3.0.22 Release Notes

**Release date**: April 23, 2024 / ISO : Day 2 of week 17 of 2024 / Julian: April 10, 2024

Our team is pleased to announce the 3.0.22 release of Power Scripts for Jira Cloud. This is a minor bug fix release.

---

## New features

- There are no new features

---

## Enhancements

- Performance improvements for **Scripted Custom Fields**
- Performance improvements for **JQL**
- Memory consumption should be lower, we addressed some memory management issues

---

## Bug fixes

The following bugs are fixed in this release:

- Fixed a race condition which in rare occasions would lead to a half-baked communication layer.
- Fixed a bug in *userRoles()* routine which returned wrong results.
