# admDeleteIssueTypeScreenScheme

## Description

Deletes an Issue Type Screen Scheme (ITSS)

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admDeleteIssueTypeScreenScheme(issueTypeScreenSchemeId) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | deleteIssueTypeScreenScheme(issueTypeScreenSchemeId) |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| issueTypeScreenSchemeId | integer | Yes | The ID of the issue type screen scheme. |

## Return Type

**boolean**

Returns true if the issue type screen scheme is deleted.
