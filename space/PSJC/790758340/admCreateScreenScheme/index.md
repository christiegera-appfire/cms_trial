# admCreateScreenScheme

## Description

Creates a scheme. Returns the updated JScreenScheme structure.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admCreateScreenScheme(scheme) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [use adm; createScreenScheme(scheme);] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| scheme | JScreenScheme | Yes | The scheme to be created. You must specify the name and default screen id |

## Return Type

[**JScreenScheme**](/cms_trial/space/PSJC/435028065/Predefined+structure+types+reference/)
