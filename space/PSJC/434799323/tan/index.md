# tan

## Description

Returns the tangent of an angle, provided in radians.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | tan(number) | **Package** |  |
| **Alias** |  | **Pkg Usage** |  |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| number | Number | Yes | Angle to get the tangent for. |

## Return Type

**Number**

## Example

```javascript
number a = tan(4);
print("a= " + a);
```

Prints: a= 1.1578212823495777;
