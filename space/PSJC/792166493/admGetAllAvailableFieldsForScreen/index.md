# admGetAllAvailableFieldsForScreen

## Description

Returns all available customfields and system fields ids for the supplied screen.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admGetAllAvailableFieldsForScreen(screenId) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [use adm; allAvailableFieldsForScreen(screenId);] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| screenId | int | Yes | The id of the screen. |

## Return Type

**string []**
