# admCreateScreen

## Description

Creates a screen. Returns the updated JScreen structure.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admCreateScreen(screen) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [use adm; createScreen(screen);] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| screen | JScreen | Yes | The screen to be created. You must specify the name. |

## Return Type

[**JScreen**](/cms_trial/space/PSJC/435028065/Predefined+structure+types+reference/)
