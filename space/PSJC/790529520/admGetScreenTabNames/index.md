# admGetScreenTabNames

## Description

Returns the tab names for a screen, in the same order as their ids

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | admGetScreenTabNames(screenId) | **Package** | adm |
| **Alias** |  | **Pkg Usage** | [use adm; screenTabNames(screenId);] |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| screenId | int | Yes | The id of the screen. |

## Return Type

**string []**
