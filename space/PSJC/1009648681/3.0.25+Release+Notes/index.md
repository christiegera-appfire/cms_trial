# 3.0.25 Release Notes

**Release date**: May 29, 2024

Rushed release - an initialization bug in our latest addition, the incoming mail feature, was preventing the container to start up in certain conditions. Total intervention time (from bug discovery to release): 3h. The existing customers were not affected, partially affected: new containers.

## Bug fixes

The following bugs are fixed in this release:

- An initialization bug in the incoming mail subsystem was preventing the container to start up, in certain non-ideal conditions. There were a few containers affected, however we felt compelled to push it in the production right away.
