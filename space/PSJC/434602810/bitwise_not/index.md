# bitwise_not

## Description

Takes one number and inverts all bits of it.

|  |  |  |  |
| --- | --- | --- | --- |
| **Syntax** | bitwise\_not(int1) | **Package** | bitwise |
| **Alias** |  | **Pkg Usage** | b\_not(int1) |

## Parameters

| Parameter name | Type | Required | Description |
| --- | --- | --- | --- |
| int1 | Integer | Yes | Number to be inverted. |

## Return Type

**Integer**

The result of the bitwise operation (complement).

## Example

```javascript
use "bitwise";
int result = b_not(int1);
//------------or-----
//no package needed
int result = bitwise_not(int1);
```
