Saved views

The Saved Views feature allows quick navigation between different views and sets a Default view per project.

Saved views

With the Saved Views feature, users can quickly switch between views with a set of parameters, including:

Priority table

Priority matrix

  • Filters

  • X-axis

  • Table Layout

  • Y-axis

  • Sorting

  • Bubble size

  • Color

  • Labels

Create saved views

The Saved views selector is located at the top right of Priority matrix page.

  1. Click the view selector.

  2. Click create view.

  3. Each view can have custom filters, column selections, sorting preferences, and priority metric settings.

  4. Create a name for your view.

  5. Set your configurations and click save.

Selecting a Saved View instantly applies the configured settings.

Saved views can be easily shared with colleagues by sharing the parameterized URL in your browser.

Saved views are stored per project.

Default view

The Default View enhances the Saved Views feature by ensuring consistency across projects. When you mark a Saved View as Default, new users visiting the selected Foxly project will automatically land on that view.

We strongly recommend setting a Default View for every project using Foxly to provide a standardized experience for all team members.
