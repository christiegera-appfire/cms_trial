Delete a template

If you have a template that you don’t use or that you created by mistake, you can delete it from Foxly.

How to delete a template

From the Project menu, navigate to the Priorities tab.

  1. Click Customize.

  2. Click the Select prioritization template drop-down and choose a template you want to delete.

  3. In the Edit template section, click [actionmenu icon] in the top right corner and click Delete.

If the template isn’t used in any project, you will see this dialogue and confirm the Deletion of the template.

If the template is still used in some projects, you will see the following dialogue.

To enable the deletion of this template, you first need to assign a different template to each of these projects. Once the template isn’t used in any of your projects, you’ll be able to delete it.

TIP: You can quickly access Foxly in these projects by clicking on the project icon and assigning a different template from there.
